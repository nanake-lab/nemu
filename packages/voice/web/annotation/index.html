起点：第一个能听到的语音音，包括清辅音。终点：最后一个能听到的语音音。重读全部保留，取最后一次读音的末音。

排除无关的环境声、点击声和单独呼吸；不要只凭波形大小判断。听不准时放慢、放大，并写备注。

先选下方“起点”或“终点”，再点波形 / 频谱。放大以光标为中心；← / → 移动 1 ms，Shift + ← / → 移动 10 ms；空格播放 / 暂停，S / E 用光标设起点 / 终点。

关闭前导出 JSON。请用 Chrome / Edge 打开本地文件，将文件保存在 D:\NemuData\asr-evaluation\manual-labels\。未完成时可导出草稿，再次打开后导入继续。
