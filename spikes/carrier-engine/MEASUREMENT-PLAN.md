## 注入证据（优先级最高）

1. 位置：分别观测零起算第 17 层 attention 残差后/FFN 归一化前和整层残差后。相同输入、相同向量、相同 token 掩码做配对，保存注入前后激活、预期与实际差值、logits、token。上游 control vector 的整层位置不能直接视为旧 hook 的等价实现。
2. 掩码：P0-07 仅在完整 prefill 的最后位置和每个 decode token 注入；上游静态源码中的广播加法不能证明满足这个掩码。先观测实际覆盖位置，分清位置差和掩码差。
3. 零调制：同量化、同内核下，未安装向量、已安装全零向量、撤除向量三臂；保存 teacher-forced 每位置 logits 与 greedy 自由生成 token，分别报告最大差和不一致数量。跨引擎、跨量化差另列，不能混作通路失败或成功。
4. 每请求更新：同一已加载模型/上下文按 0→A→B→0→A 连续请求；每步与新上下文相应向量配对，记录设置返回码、向量摘要、实际激活和 logits。请求间清空 KV；保留不清 KV 的诊断对照，但不把它用作合法生成。另查 graph 复用是否仍读旧向量。仅有 C API 声明不算实测通过。
5. 方向重提取：在新位置按三语对比样本提取并单位化；这是可行性测量，不替代 P5-31 的四天性、全部学得方向、三语单调性与能力无损验证。没有这些证据不能批准 v2.0 §9.5 迁移。
