# P5-07 talk-only bridge foundation

This directory is a library, not a registered daemon or a helper executor. See
`reports/P5-07/REPORT.md` and `BLOCKED.md` for delivery and acceptance status.

`connect` requires explicit lock, helpers, catalog, owned home/scratch, deadlines and
capacity limits. It checks the installed CLI against `config/models.lock.json`, then
claims one dedicated `CODEX_HOME` with an exclusive file. A stale claim is never stolen.
No login, authentication copying or user/system configuration change is performed.

The catalog must already contain the P0-08 restricted metadata for the chosen model.
`config/helpers.json` does not yet exist on the baseline; there is no guessed fallback.
The selected model is checked again on each request. Each turn has a fresh temporary
working directory, read-only sandbox, no network tools, plugins, skills, environments,
MCP or native collaboration. Server requests are refused, never approved. Helper
approvals and authorized tool execution belong to P6-06 and are not routed here.

App-server request parameters use the exact transitive closure of types generated by
CLI 0.162.1. `generated/MANIFEST.json` records every retained file's SHA256. These files
are unmodified output of `codex app-server generate-ts --experimental`; their imports
are type-only and impose no runtime dependency. Runtime JSON boundaries use Zod.

Every completed turn must pass a fresh zero-MCP inventory check with no pagination.
Raw calls, unknown tool items, server approval requests, rerouting, malformed JSON,
identity mismatch, output overflow, deadline or disconnect fail the request and close
the connection. A disconnected request is never silently resubmitted. Reconnection
uses a new connection and a new request; callers must handle the prior unknown result.

Receipts contain the actual final text and available token counts. Unknown usage is
`null`; cached and reasoning counts remain subsets, not extra token charges. The
bounded usage journal contains only IDs, tier, model, result and token counts. It is
runtime accounting, not an authoritative quota store. Inference completion timing
excludes the post-turn inventory; the overall deadline includes it.

`replay.test.ts` contains explicitly synthetic protocol traces. They test local client
behavior without inference or quota use; they are not online measurements, a real
provider recording, or proof that every future provider response is safe.

Core/worker named-pipe service and Python/backend endpoint contracts remain blocked.
No private message schema, unauthenticated listener or authority-store handle is added.
