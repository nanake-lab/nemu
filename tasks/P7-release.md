## P7-01 性能与稳定性

- **负责：** Codex（主进程、语音、核心、worker、旁路服务）+ Antigravity（舞台进程的帧率自适应与内存）。两者各开一个分支，按本卡同样的验收执行。
- **依赖：** P6-13
- **工期：** 各 6 天
- **分支：** `task/P7-01-perf-app`（Codex）、`task/P7-01-perf-stage`（Antigravity）
- **目录：** Codex：`apps/desktop/src/perf/`、`tools/bench/`、`tools/soak/`；Antigravity：`apps/stage/src/perf/`

### 交付物
- **帧率自适应：** 根据物理状态和 `stage.frameStats` 在 60、30、12 fps 之间切换；角色完全被遮挡或隐藏时暂停渲染。
- **冷启动：** 先显示角色（VRM 缓存、延迟加载非关键模块），再启动核心、语音和 worker；目标 ≤ 4 秒。核心未就绪期间身体照常呼吸、眨眼。
- **内存：** 各进程堆快照对比，修复泄漏；检查 VRM、动作、音频缓冲、KV 缓存的生命周期。
- **8 小时浸泡脚本：**
  - 用 genesis 候选在临时目录里创建测试谱系，不碰她的存储；
  - 模拟真实使用：每 10 分钟一轮对话，随机拖拽，窗口开关，待机与睡眠交替，切换一次说话模式，断网一次；
  - 每分钟记录各进程的内存、CPU、GPU、显存。
- **`pnpm bench` 最终报告：** 对照完成标准第 8、19、20、21、22 项逐条给出结论，附原始数据。

### 验收
- 完成标准第 19、20、21、22 项全部通过，原始数据放进报告。
- 完成标准第 8 项在三种模式下复测通过。

## P7-02 安装包与更新

- **负责：** Codex
- **依赖：** P7-01（两部分）
- **工期：** 6 天
- **分支：** `task/P7-02-packaging`
- **目录：** `apps/desktop/build/`、`tools/installer/`

### 交付物
- electron-builder 生成 NSIS 安装包，按用户安装，不需要管理员权限。包内包括：
  - `nemu-core.exe`；
  - worker 与旁路服务（uv 管理的 Python 环境）；
  - 模型下载清单（来自 `config/models.lock.json`）。
- **首次运行向导：**
  - 麦克风测试；
  - 按显卡推荐说话模式（ADR 0003），你可以改；
  - 下载模型：断点续传，哈希校验，显示进度；
  - 检查 Codex CLI 版本并引导登录（模式 B、C 和助手需要）；
  - 导入内容包；
  - 快捷键说明。
- **谱系：**
  - 已有正式谱系时，安装和升级一律保留，升级前自动做本机备份；
  - 没有正式谱系时，进入排练；导入了签字的 genesis 清单时，可以在面板里执行诞生。
- **自动更新：** electron-updater，更新源可配置。私有时指向本地或私有目录，公开时可以切到 GitHub Releases。
- **卸载：**
  - 默认保留她的存储、设置和下载的模型；
  - 删除她的正式存储需要两次确认，第二次要输入她的名字。
- 设置与存储的版本迁移测试（SYS17）。
- 代码签名：写出步骤说明 `docs/SIGNING.md`，是否购买证书由你决定。未签名时，写清楚 SmartScreen 提示的处理方法。

### 验收
- 完成标准第 23 项：在全新的 Windows Sandbox 里完成以下流程。Windows 家庭版没有 Sandbox，可以改用虚拟机或新建的 Windows 用户账户。
  1. 安装；
  2. 冷启动到角色出现 ≤ 4 秒（模型已下载）；
  3. 升级一个测试版本，升级后 `echoctl verify` 通过，测试谱系完好；
  4. 选择删除时，卸载后不残留文件。
- 删除正式存储的两次确认有测试。

## P7-04 可公开准备

- **负责：** Codex
- **依赖：** P7-02
- **工期：** 3 天
- **分支：** `task/P7-04-publish-ready`
- **目录：** `tools/publish/`

### 目标
Nemu 默认私有。这张卡确保「哪天想公开，随时可以公开」：任何依赖或素材都不会成为障碍。代码、Nemu 本人、Echo Core 规格三者可以分开公开。

### 交付物
- 依赖许可扫描（Node、Python、.NET、Rust 四方）→ `THIRD_PARTY_NOTICES.md`；发现 GPL、AGPL 依赖时报错。
- 内容清单检查：`content/nemu/manifest.json` 每个条目都有许可证和 `redistributable` 字段；生成「可公开」「仅私有」两份清单。
- **「不含 Nemu 的公开版」构建脚本：**
  - 用一个许可清晰的示例 VRM 替换 Nemu，去掉内容包；
  - 默认不包含 `docs/echo-core/`（你的规格），除非你选择一起公开；
  - 不包含任何谱系数据；
  - 验证代码仓可以单独公开。
- `README.md`、`CONTRIBUTING.md` 草稿，公开时再用。
- 安全复查报告：权限分级、审计记录、密钥存储、日志脱敏、命名管道 ACL、worker 低完整性。

### 验收
- 完成标准第 24 项通过。
- 「不含 Nemu 的公开版」能完整构建和运行（在新的排练谱系上）。
