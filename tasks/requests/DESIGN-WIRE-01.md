## 2. ADR 0045 的其他内容
- **§2 与 ADR 0042 的关系：**
  - D1 偏离 ADR 0042 U5（本地模型负责独处思考与行动选择）。写明偏离了什么、为什么是过渡期、什么时候换回本地。
  - D2 是 ADR 0042 §1.3 资格规则的落地：对上外部事件的念头怎样证明有外根。没有外根的念头仍按 0042 排除，不另开例外。
- **§3 关系类型映射 v1：** 以 PLAN-CAUSE-WIRE-01 报告 Q2 的候选映射表为底稿，逐行对照现行代码和契约核实（带文件与行号）。核实不了的行，标「未核实」，不删。这张表就是 ADR 0042 要求运行前发布的「关系类型映射」资源的第一版内容。
- **§4 念头写回与身份：** 按报告 Q3，写清写回时用哪个现有契约消息，以及「她本人 / 用户 / 第三方」「念头 / 已说出口的话」靠什么区分。只用现有 IDL 推导。现有 IDL 确实表达不了的，列成「契约缺口」清单，每条写缺什么字段、为什么现有字段不够。不在本卡改契约。
- **§5 云端念头回执：** D1 下每次云端思考要记下什么，至少包括模型、参数、输入摘要、输出、时间，以及它没有被授权做什么。
- **§6 后果：** 按 AGENTS 黄金规则 17 三问作答。
