# P5-53 2/4 交接给终端契约所有者

[P6-02 的接线请求](P6-02-core-push.md)要求面板将解释失败、生成失败和空输出分别说明，并归到发起聊天的回合。现有 `OutputEnd` 带 `output_id` 与 DONE、CANCELLED 或 ERROR；`OutputChunk` 带 `action_id`、`snapshot_id`。这些字段足以保留输出前缀、按输出停止和报告通用错误。配对的 `ReceiptV2` 能把收件后的拒绝归到原输入事件。

请契约所有者明确从输出到输入事件的权威关联，以及无输出块时三类结果的依据。P5-53 2/4 仅传输已冻结的消息；桌面按已有标识呈现结果。生产者联测的输入和输出分别取独立标识。P6-02 的首次对话验收保留至有真实生成及上述接口时进行。[终端契约](../../docs/CONTRACTS.md)
