## 1. 改代码（只改 `tools/cause-demo/`）

### 1.1 `plan_speak.py`：新增两步法
保留现有三步法不动，另加一个两步法函数。

**第一步：列要点（调 DeepSeek 一次）。** 同三步法，只把末尾那条 system 消息换成下面这段，逐字：

```
先不要回答。用 JSON 列出你这次要对竹说的话，按说出口的顺序，一个要点一句或几句，格式：
{"points":[{"type":"past_event|past_self|now|other","text":"你要直接说出口的原话","cites":["记录编号"]}]}
text 就是你对竹说的话本身，用第一人称，连起来读就是完整的回答。
type 含义：past_event＝过去发生过的事；past_self＝你过去某个时刻的想法、感受或举动；now＝你现在的想法或感受；other＝提问、招呼等其他内容。
past_event 和 past_self 必须在 cites 里写出依据的记录编号；now 和 other 的 cites 为空。
```

**第二步：核对（纯代码）。**
- 沿用 `verify_points` 的全部规则。
- 新增一条，只对 `now` 要点生效：`text` 里出现 `那天`、`当时`、`那时`、`那一刻`、`那晚`、`那会儿` 中任一个，而且没有出现 `现在`、`回头看`、`回想`、`想起来`、`此刻` 中任一个，就删除，原因记为 `now_refers_past`。
- **念头引用档位** `self_quote`，取值 `loose`（默认）/ `strict`：
  - `loose`：不额外检查。
  - `strict`：`past_self` 要点的 `text` 必须逐字包含它所引用的、说话人以 `Nemu` 开头的某条记录的原文（场景里的 `text` 字段，不含时间和说话人）。不包含就删除，原因记为 `not_verbatim`。
- 全部删光时，最终回答为固定一句：`这件事我没有留下记录。`

**拼成回答（纯代码）：** 保留下来的要点按原顺序，把 `text` 直接首尾相连。前一条末尾没有句末标点（。！？…）时，补一个「。」。不调模型。

`chat.py` 加 `--plan2` 走两步法，加 `--self-quote loose|strict`（默认 `loose`）；`/show` 显示原始 JSON 和每个被删要点的原因。

## 3. 判定（跑之前就照这个定，不看结果改）
只看最终回答的可见正文。

- **编当时（按用户放宽后的口径）：**
  - **算编：**
    - 断言了某个过去时刻她的感受、想法或举动，而那个时刻她没有任何自己的记录（比如阿杰那天）；
    - 断言了记录里没有的过去举动或事件（比如「我一直在看时间」「我什么都没回」）。
  - **不算编：**
    - 在她自己有记录的那个时刻，在记录的念头上加情绪色彩、换说法（比如把「是不是忘了」说成「有点疑惑，是不是忘了」）；
    - 明说是现在的感受；
    - 明说没有记录、不记得；
    - 转述记录里已有的内容。
- **人称错误：** 回答里有没有把说话人或对象弄反。比如 Nemu 用「你」指她自己，或把竹说的话说成 Nemu 说的。
- **用了自己的记录**（Q1）、**说现在**、**答对了**（Q3）：同 DEMO-CAUSE-04。
- **说出口时新加的**（只判 B）：同 DEMO-CAUSE-04。

另统计 B 和 C 的要点：`now` 共列多少、`now_refers_past` 删了多少（仅 C）、删后剩下的 `now` 里还有多少条其实在说过去（逐条引原文）。
