# P6-01 的运行时与网关调用方

P6-01 的目录只覆盖 task-layer 与协议候选。以下调用方归外层事务、网关、生成器和行动生命周期。当前 [W03 准备事务](../../core/crates/core-runtime/src/store.rs) 沿用旧 staged_q，[网关 query 钩子](../../core/crates/gateway/src/hooks.rs) 的默认结果为能力拒绝。联调时请使用 [W21 接口](../../core/crates/task-layer/src/task/mod.rs)。

- 外层事务从有序提交读取本轮 RecordVersion、解释结果、运行状态与已授权前沿。协议、权限与输入变化写入 Q，持久保存终止的回合及故障回执。只有有效解释提交或合法无作用时才在实际生成时刻取投影；从 Q 恢复时保留已结束的状态。协议内容及本次设置、使用的样例和实发字节由宿主绑定并可取回。
- 网关的可信 CoreHandler 从同前缀提供 W19、Q 行动行（含拒绝）与状态切换记录；经身份鉴别后交给 UserView，先完成持久的 user_view 审计，再回送结果。状态推送取核心现有 RunStateV2 投影和协议草稿标志。
- P6-03/04/05 注册实际生成器。P6-04 写入实发请求、真实回执与计量资源，并提供 D6 所需的可信语义审核；P5-43/P5-53 提供同前沿的说话人和记录版本。计量、身份或补充来源无法验证时，停止对应请求。
- P5-14 接管原子登记、发送前再次核对、凭证、实际投递与 UNKNOWN 不重发。权限绑定来自 P5-40。依赖合入后联测 SYS08、SYS13，使用真实 outbox、临时谱系与实际故障点。
