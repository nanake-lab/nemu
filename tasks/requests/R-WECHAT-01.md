# R-WECHAT-01 后继请求：她的独立微信接入

日期：2026-11-01（Australia/Perth）。来源：[接入路线研究报告](../../reports/R-WECHAT-01/REPORT.md)及本次用户决定。本文只请求后继设计与选择，不认领实现、不新增契约、ADR 或验收阈值。

## 已确定的前提

她有自己的微信账号，用户主号永远不接入。ADR 0011 的历史共用账号表述在此微信场景由本次用户决定取代，正式文档修订留给后继卡；不顺带改变其他平台决定。

社交权限以 V2-89 为准；正常交往不设消息数或人数行为上限，以 V2-104 的防失控保险丝保护。诚实底线、用户秘密结构隔离、只有 u* 能管理权限保留。ADR 0032 的预设起点原则不授予适配器控制她的性格、自动问候或关系状态的权力。同一时刻只能有一个她，电脑停机时她无法回复。

## 先由用户选择，不自动开始

1. 是否接受企业微信体系内的微信客服身份、无需加好友的会话，以及 48 小时/连续 5 条回复限制？接受时，优先核查实际主体资格、费用与官方 API 可靠性。
2. 若必须是普通好友及自由主动联系，是否先由用户向平台确认可用官方能力和授权，再决定保留电脑版 UI 路线？本卡没有核实到满足全部需求的普通好友通用官方收发接口；UI 自动化也没有取得腾讯书面许可。
3. 离线体验选哪一种：接受上线后回复、用户安排在线窗口、单独批准只收件的中继，或以后迁移专用设备？不在 PC/手机/云端并行运行多个核心。

这些是后继工作的前置选择，不阻塞研究报告交付。合并本研究 PR 不等于选择路线、注册账号、付费、联系平台或批准实验。执行者在 PR 写“请审查”后停止，不代用户联系任何人。

## 所属后继卡需要提供的最小接口

| 责任范围 | 需要解决的缺口 | 不能假装已有的能力 |
| --- | --- | --- |
| P5-35/P5-03 的终端消费者与新契约卡 | 复用安装认证、连接 session、对象上传、`TerminalEvent`、`ReceiptV2`；为第三方消息定义说话人、她的账号、会话、平台消息标识、原文/派生文字、发生/观察时间、撤回/引用、来源和稳定重投合同 | 现有 `UserText` 不含第三方身份，不可伪装 u*；不在字符串或 bytes 塞私有 JSON 代替正式 IDL，不让 webhook 直接调用核心管理服务 |
| P5-40/P5-41、P5-14、网络生活后继 | 绑定账号/收件人/原样内容/操作种类、作用域/凭证/过期/撤销、Q/outbox 与执行结果；落实 V2-89 默认社交信任及事后通知，V2-104 只防失控 | P5-05 纯权限谓词不是认证；I26 进程内消费不是跨重启防重放。不能把所有联网发送都降为可信社交 |
| 官方 API 适配器（路线获选后开卡） | 校验平台来源，正确处理回调、拉取游标、背压、窗口、账号范围；API 自发消息不能从 `sync_msg` 回读，需行动记录保存原样输出；受理、失败、UNKNOWN 分开 | 不以群发、存档、内部应用消息冒充任意个人好友自动聊天；不绕过平台额度 |
| UI 执行器（路线获选及许可/风险决定后开卡） | 专用窗口的身份与收件人核对、UIA 能力探测、OCR 派生标注、前台占用协商、发送证据、未知结果处理 | 不提权所有 worker、不关闭 UIPI、不抢用户输入、不读数据库/进程内存、不注入，不靠文本去重把两条同文真消息删成一条 |
| 隐私/数据生命周期后继设计 | 最小读取、H 与诊断日志分离、截图原件策略、远程模型与中继副本、记录可见性问答、撤回/删除请求及适用法律 | ADR 0011 的记录可见性问答与第三方删除义务仍未决；不能承诺只有她看见或已经物理删除，也不把私人账号直接当法律豁免 |
| 生命周期/单实例后继 | 停机取回缺口、过期行动、接收暂存的权威归属；若迁移封存旧实例 | 只收件中继不得运行另一个她；不补写离线思考，不在恢复后盲发旧行动 |

涉及现有契约、存储、权限或对外行动的实施，按 AGENTS.md §6/§7 另开有目录授权的卡，先做必要 ADR/后继 IDL与交叉审查。本请求没有授权改 `tasks/cards.json`、既有文档、配置或任何实现。
