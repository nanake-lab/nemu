# R-WECHAT-01 后继请求：她的独立微信接入

日期：2026-11-01（Australia/Perth）。来源：[接入路线研究报告](../../reports/R-WECHAT-01/REPORT.md)及本次用户决定。本文只请求后继设计与选择，不认领实现、不新增契约、ADR 或验收阈值。

## 用户已选路线与 E5 后继卡清单（2026-11-01 追加）

用户选择专用安卓手机经 USB 调试操作手机版微信，使用她的独立账号，用户主号永不接入。电脑关机时她不回复，按单实例设计接受；手机常亮不锁屏，不运行第二个核心。用户知悉并接受无法控制、无公开数据可量化的封号风险；她按正常人际节奏使用，不群发、不研究规避检测。设备维护要求见[报告“用户选择”](../../reports/R-WECHAT-01/REPORT.md)。

此决定取代下文“先由用户选择”中的路线与离线体验待选状态；企业微信/API、电脑版 UI 执行器及其中继选项保留为未采用记录，不作为实施默认或自动回退。已有终端、权限、隐私与单实例边界仍适用；安卓能力不由 Windows UIA 资料推定。

## 已确定的前提

她有自己的微信账号，用户主号永远不接入。ADR 0011 的历史共用账号表述在此微信场景由本次用户决定取代，正式文档修订留给后继卡；不顺带改变其他平台决定。

社交权限以 V2-89 为准；正常交往不设消息数或人数行为上限，以 V2-104 的防失控保险丝保护。诚实底线、用户秘密结构隔离、只有 u* 能管理权限保留。ADR 0032 的预设起点原则不授予适配器控制她的性格、自动问候或关系状态的权力。同一时刻只能有一个她，电脑停机时她无法回复。

## 先由用户选择，不自动开始

1. 是否接受企业微信体系内的微信客服身份、无需加好友的会话，以及 48 小时/连续 5 条回复限制？接受时，优先核查实际主体资格、费用与官方 API 可靠性。
2. 若必须是普通好友及自由主动联系，是否先由用户向平台确认可用官方能力和授权，再决定保留电脑版 UI 路线？本卡没有核实到满足全部需求的普通好友通用官方收发接口；UI 自动化也没有取得腾讯书面许可。
3. 离线体验选哪一种：接受上线后回复、用户安排在线窗口、单独批准只收件的中继，或以后迁移专用设备？不在 PC/手机/云端并行运行多个核心。

这些是后继工作的前置选择，不阻塞研究报告交付。合并本研究 PR 不等于选择路线、注册账号、付费、联系平台或批准实验。执行者在 PR 写“请审查”后停止，不代用户联系任何人。
