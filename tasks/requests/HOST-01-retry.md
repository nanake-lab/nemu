# HOST-01 请求核定无根阶段的重发验收

ADR 0024 第 5 条与恢复表允许同键重试得到新的 D 位置，Γ 负责后续判重。当前 `core-store/src/ingress.rs` 的 `settle_duplicate` 读取待处理队首，`prior_fingerprint` 只查同设备、同 key 且已有 accepted 决定的记录。首次接收只追加 D 和见证。全新排练库中，首条记录等待处理时，后续同键重发也会排在它之后。

请决定何时观察去重。若要求在 1/2 等待初始根期间即可观察，请由入口与存储维护方给出与 ADR 0024 相容的接口，并说明重启、同键内容冲突和背压的语义。另一个选项是 1/2 在授权接入后核验回执、D 和重发键，2/2 接入真实处理后再核验 Γ 的重复终态。该拆分涉及验收时点，需要用户决定。

HOST-01 沿用原有入口和 Γ，不维护第二份键表。
