# R-THINK-LOCAL-01：本地 4B 怎样学会不编造地「想」——研究计划

- 只读规划。分支 `task/R-THINK-LOCAL-01`，从 `origin/main` 新建。目录只用 `reports/R-THINK-LOCAL-01/` 和 `tasks/requests/R-THINK-LOCAL-01.md`（本卡原文）。不改代码、契约、ADR、卡片。不用 GPU。

**背景。** ADR 0045 D1 定了：过渡期由云端 DeepSeek 写独处念头，研究线同时训练本地 4B，练好后换回本地。现行载体按 ADR 0034 是 Qwen3.5-4B（Q4_K_M、不思考模式，含 mmproj）。已有的实测见 `reports/` 下 DEMO-THINK-01～05（PR #247 的 DEMO-THINK-06 若已合并，也一起读）：本地未训练时，凭空感知 18/60、编事件 34/60；DeepSeek off 分别是 5/60、18/60；念头连写会越滚越大；两步法让模型自己贴标签，挡不住编造。

**要回答：**
1. **训练会不会动到「她」。** 对照 v2.0 §9.5（载体迁移）、ADR 0031、0034，以及 P5-13、P5-31 的方向提取与验证：微调载体权重算不算载体迁移，要不要重新提取方向、重做 J01/J05/AT13 和身份测试。列出不改载体权重的候选，比如另加一个只写念头的小模型、LoRA 只在思考时挂载、只做受约束解码，并逐个比较对 m 调制和方向资格的影响。
2. **数据。** DeepSeek 做老师时怎样过滤：只收经过独立核对、对照原始外部记录不含编造的念头。核对方法参考 DEMO-THINK-06。估算需要多少条、按什么分布覆盖场景和时刻，以及三语怎样处理。
3. **评测。** 沿用 DEMO-THINK-03/04 的判定口径，再加连写 30 轮的继承编造。判据先写定，并定下换回本地的门槛候选（例如不差于 DeepSeek off）。门槛由用户最后定，只列候选。
4. **资源。** 3080 上训练的显存、时长估计，以及和 runner、CI 怎样错开。
5. **需用户决定的事。** 只列真正影响她的项，每项给候选、后果和推荐。

交付 `REPORT.md`：开头白话三行；第 1–5 节；最后给出后继卡清单，每张写目标、目录、依赖、建议模型。开 draft PR，加 `needs-user`，写「请审查」后停下。
