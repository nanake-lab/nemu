# DESIGN-CAUSE-PROJ-01：文字路线「交来由，不交状态」

## 先答黄金规则 17 的三问

1. **能不能不加？** 不加新的心情状态、重要性分数或人格文本。复用 H、已有依据槽与淡化规律；有限上下文仍需要一条确定的取材规则，它是本卡要审查的新增投影机制，不能假称完全没有新增。
2. **一个人会怎样？** 可以说清发生了什么，而不先规定自己应该表现成什么样；记得原话也不等于今天仍有当时一样强的感受。这是设计类比，不是对模型反应的保证。
3. **加了以后，有什么从此改不掉？** 选择规则可以通过显式版本升级替换，H 不改；已经发给外部 API 的原文、已经说出的话及由此发生的后续经历不能靠换规则撤回。有限原文也不能无损承载全部心情，缺口必须明示。
