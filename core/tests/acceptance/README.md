# Acceptance evidence layout

Create one directory per original specification ID (F01, J05, SYS01, I01, etc.). Each contains README.md (construction, expected result, profile), test code, and generated result.json with passed, failed, not_run, or non_identifiable. Record positive and rejection cases. Structural fixtures cannot establish behavioral efficacy. P0-01 runs build checks only and claims no Echo Core acceptance IDs.
