## 集成责任

P5-03 提供可运行的 Gateway::serve 库服务。调用方注入唯一 Store 与可信 CoreHandler，后者必须
解析来源/历史引用/行动权威并执行真实 core transition；approval handler 使用已存在的一次性审批
上下文校验，defaults 拒绝。P5-08/P5-40/P5-41 的业务编排、执行凭证和成长管理不由网关虚构。
SYS01 在真实原生服务上用测试专用实际 Store 事务处理器，不声称行为有效或完整应用已接通。

验收代码按用户指定目录保留在 gateway crate，编号说明/原始输出在 reports/P5-03/SYS01 与
post-P5-35/runs/*/SYS01；未跨卡改 core/tests/acceptance，W16 后续中央登记引用本卡证据。
