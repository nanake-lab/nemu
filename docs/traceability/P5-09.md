## 不变量

| 编号 | 检查方式 |
| --- | --- |
| I06 | 只有 ACTIVE 的 R 作用进入有效集；shadow、qualified shadow、suspended 等全部过滤。测试 `i06_*` |
| I07 | θ 接管登记优先；同一责任在同端点、可能重叠的域内出现两个条目即 `DuplicateOwner`；候选重复责任被拒绝。测试 `i07_*` 两项与 `j06_candidate_over_budget_*` |
| I08 | 新的 evidence revision 不解除 θ 对该责任的接管。测试 `i08_*` |
| I12 | 失效屏障上的对象出现在依赖闭包里，立即阻止作用；θ 进入隔离。测试 `i12_*` |
| I21 | `compile_authorized_effects` 只借用输入，不写回；先读早时刻再读晚时刻，结果与直接读晚时刻相同。测试 `i21_*` |
| I22 | θ 无有限期限且无可验证条件、已到期或条件不满足时，返回 `ThetaInvalid`（全核心隔离请求）。测试 `i22_*` |

## 交叉审查修复后的对照（2026-10-19 追加）

上表中以下各行，以本节为准。来源是 PR #22 的交叉审查 B1–B7，详见 `reports/P5-09/REPORT.md` 末节。

| 规格条款 | 原文要点（一句话） | 实现位置 | 测试 |
| --- | --- | --- | --- |
| O 3.1、O 9、S 5 | 接管针对一个责任在一个可判定子域；子域与剩余 R 域必须不重叠，不能证明就不接管；未覆盖的部分仍由 R 承担；处置保留接管记录 | `effects/takeover.rs`（`check_binding`、`relation`）；`core-policy/src/overlap.rs` 的 `contains` | `review.rs` 中的 `b1_*` 六项；`i07_theta_takeover_suppresses_r_even_after_legal_disable` |
| S 12、I12 | 依赖 DAG 含资格、解释资源和来源；循环、未知边、断引用、失效均阻止授权 | `effects/objects.rs` 的 `closure_roots`、`digest_of`；`compile.rs` 中 R 与 θ 两条路径 | `review.rs` 中的 `b2_*` 六项；`i12_*`；`r_certificate_expiry_*` |
| O 10.2、I22 | θ 带显式 ValidityContract，声明作用域、依赖假设、有限期限或可验证条件；超出即严格隔离 | `types.rs` 的 `ThetaValidity`（`VALIDITY_TAG`）；`objects.rs` 的 `check_validity` | `review.rs` 中的 `b3_*` 两项；`i22_*` |
| O 3.3、S 12 | 每个端点有字段白名单，深度、节点、精度有限；所有加载与编译路径都执行同一套验证 | `objects.rs` 的 `check_scope`（编译和准入共用） | `review_scope.rs` 中的 `b4_*` 三项；`j06_candidate_with_non_whitelisted_field_is_rejected` |
| O 3.3、O 12.1 | 新候选连同既有作用接受冲突检查；已验证的冲突由资格过程选定唯一作用或经 composite 处理 | `CompiledEffect.conflicts`；`compile.rs` 的 `check_declared_conflicts`；`admission.rs` 双向检查 | `review_scope.rs` 中的 `b5_*` 三项 |
| S 6 | 浮点误差不得让边界判据时过时不过 | `core-policy/src/numeric.rs`（精确定点量化）；`scope.rs` 的 `evaluate_atom` | `review_numeric.rs` 中的 `b6_*` 两项（含性质测试）；`numeric.rs` 单元测试 |
