# P5-37 规格对照

字段逐组出处、编码与消费者职责见 [ADR 0030 字段表](../adr/0030-cognition-record-contracts.md#决策与字段出处)。所有新字段（包括共用 schema_version）均在表中列出。有效性按 [DOC-PRESETS-01](DOC-PRESETS-01.md)，不把 COG-07 至 COG-11 的旧权重/期限再次冻结。
