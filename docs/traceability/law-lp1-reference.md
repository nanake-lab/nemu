## PR #49 D1–D12 的逐项关系

固定对照版本：`d95f65c214897743133a3c525b550fda97cd010e:docs/traceability/P5-23.md`，包括末尾的审查后更正。这里的“保持”表示设计意图，不声称已实现或批准该分支里的全部待确认读法。

| 项 | 新参考形式的处理 |
| --- | --- |
| D1 组与位置 | 保持首次位置、分配 ordinal 不刷新；新增实际 q 与首次分配绑定 |
| D2 一步 | LP1 始终以一个已提交事件为边界；提议旧修订先完成，再处理新增的两阶段顺序 |
| D3 处理组 | 支持、强度、可信、可核实保持；份额数值改为显式 dyadic 量化。重新分摊与新增不交错，反事实复用同一计划 |
| D4 递推与初值 | A/V/M/U 乘实际 q；P/c 不乘；零有效信号 q=1。π、r 与 R⁺ 门槛代数保持。存 V，不从舍入的 B 减 c 反推 |
| D5 重放 | 改普通旧分配时使用首次实际 q，不由新份额重新估计；M/U 用同一 q；F/N 重新折叠用于未来估计。来源更正另从有效 H 完整重算 |
| D6 人际倾向 | 亲近/信任结构、方向、先验位置与读出不改；依恋 P 固定，信任初始证据仍是可遗忘证据。本文数值实验只测试标量 P |
| D7 容量 | 不改变移出范围与显式故障的意图；新 V 可直接用于证据量排序。容量引起的分摊须同样拆分审计；本次夹具未实现，不宣称通过 |
| D8 上限 | 不修改 w_max 或强度公式；q 不放大单个组的 W |
| D9 数值 | 有限 binary64、固定次序、−0、非有限故障保持；新增严格 LP1 精度故障与 dyadic 份额。M/U 次正规数合法例保留。精确均值与内积不另写一套 |
| D10 别名 | 保持 ADR 0014 与审查后代表优先级；本次未实现别名解析，不新增先验或计数 |
| D11 L | 保持全部实际变化和所涉组引用；建议记录 before/cf/after 的核验结果，记录格式留后续契约卡，不在此重复定义跨进程类型 |
| D12 类型 | 现有生成类型不改、不重解释。后继 q/V 字段需要独立契约变更与用户批准；本研究的 dataclass 仅为离线夹具 |

## 2026-10-23 第二轮分侧修复（本节优先）

第一轮的独立cf oracle只核验同计划下省去首次分配，没有证明分摊计划本身正确。第二轮新增的零支持、极小异号与未变侧量化边界已复现并保存；详见 [R2修复报告](../../reports/law-lp1-reference/review-20261023-r2/REPORT.md)。

- `_revise` 先直接比较支持符号，再选出新增成员所属的非零侧；只有该侧重新量化、写份额和重放。零支持仍首次记录，但不触发任何旧侧变化。
- `law_v2_side_checks.py` 独立从事件前的支持符号选出未变目标，比较其份额、所有旧分配位模式、全部倾向状态位模式和cf；同时检查计划没有列入未变目标。它补足“计划是否合法”，不复用实现的分侧选择。
- 三个审查见证、同侧应改变的正向控制，加四族各200个随机变体，总计804例；保留新候选首次分配、cf、I25和完整H重放检查，结果以attempt-07原始输出为准。
- 原LAW、三条LP1、第一轮回归和四世界对照全部复跑；旧LAW-6仍失败。ADR 0019全文件未变，A–D选项继续由用户决定。没有放宽LP1、拒绝合法零支持或提高弱证据下限。
