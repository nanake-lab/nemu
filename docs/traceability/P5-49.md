# P5-49 规格对照

本表对应第一份 PR 的设计决定。合成 IDL 验证归后两份 PR，实际管道与进程隔离归 P5-07 联测。

| 位置 | 依据 | 新读法及验收对象 |
| --- | --- | --- |
| 派发与取件 | P5-07 IPC 请求、I02、I14 | 角色来自本机认证；按本次调用和读集取回原件。后续正例含合法同请求取件，反例含串会话、跨前沿取件、长度或摘要错误、越权云端材料。 |
| 原文与语义 | ADR 0048 G01–G04、EV1 | 对照正式来源与注册表，检查汉字与多字节字符的原文区间；拒收错原件、拆字符、重复匹配未消歧及以 alias 充当正式身份。 |
| 实际生产者 | ADR 0046 §2.1、过渡期用户决定、EV6、I26 | 采用本地或远端的实况，测试 DeepSeek 未披露权重摘要、实请与实返名称不同、发送前中止及截断。拒绝伪造本地核验或把原始响应直接当作采纳。 |
| 核心与回复 | v2.0 §2.4、ADR 0048 G04、ADR 0042 U6、I16、I23 | 错调用、陈旧绑定、取消后迟到或仅有候选不能授权发布；重放消费已记录材料。真实生效前缀及回复时序归运行时接线验收。 |
| 生成与拒收 | ADR 0046 §4、SYS21 | 合法内部消息在三端同字节；三端用合法上传帧逐一替换为每个新增标签，均须拒绝。兼容检查基于最新 main，保留前驱写入与旧向量前缀。 |
| 真实命名管道 | P5-49 卡面、SYS02 | P5-07 补真实双端、来源注入、断线与录制回放。 |
