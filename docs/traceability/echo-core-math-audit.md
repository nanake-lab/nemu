### 2.2 第二类：证明缺前提

#### P-1 快状态收缩界只在无事件的区间成立

- **位置：** O §5.1 第 3 段；O §18 不变量 I05。
- **原文：** 「该表达式是 x 与 b 的凸组合，因此 X 前向不变；固定 θ 时具半群性。同一 R/θ 和未来条件下，两个初始 x 的差满足 ||δx(t)||∞≤exp(−λ_min t)||δx(0)||∞。T_x 和误差目标据此约束 λ_min」。I05：「x 有界且固定慢状态下快速收缩」，执行检查为「X、λ_min、数值检查」。
- **分析：** 这个不等式对纯时间投影 Φ_x 成立（证明 7.1）。但如果句中的「未来条件」包括相同的后续事件，轨迹还要经过 F_in 的事件映射：E_z(x̄) = Project_X(x̄ + g(z,x̄) ⊙ (B(θ)·tanh(W_z f(z) + W_x x̄ + a) + Σ residual))。按 O §5.2，A_x 读 x̄，事件门 g 也读 x̄，所以 E_z 可以把差值放大。
- **反例（PHI-7）：** 取 d=1，b=0，λ=1/s，每 0.1 s 来一个相同事件，g=1，B=1，u=tanh(5x̄)，无 residual。从 x(0)=0.01 和 y(0)=−0.01 出发，100 s 后 |δx| = 2.0000（两条轨迹分别停在 +1 和 −1），而该式给出的上界是 7.4×10⁻⁴⁶。同样的事件调度下改用 u=tanh(−0.5x̄)（非扩张映射），差值降到 10⁻³²³ 量级，满足该式。
- **成立条件（证明 7.3）：** 满足下面任一条时成立。
  - (a) [0,t] 内没有事件，也就是 F §2.2「无持续驱动时」和 F03「停止驱动」的语境；
  - (b) 每次事件映射对 x̄ 在 ∞-范数下的 Lipschitz 常数 L_k ≤ 1。

  一般情形下的界是 ‖δx(t)‖∞ ≤ (Π_k L_k)·e^{−λ_min t}·‖δx(0)‖∞。
- **影响：** 不与冻结条款矛盾，因为 F §2.1 只要求 x「在无持续驱动时衰减」。但在事件持续到来时，x 可以借扩张的事件映射长期保留历史差异（反例里是 1 比特的双稳态），而 I05 的执行检查只覆盖条件 (a)。这种保留能被 F04 和 F §17.7 的钳制消融发现，但 F04 属于 M7，v1.0 不签发。
- **建议改法：** 把该句改为「在不含事件的区间上，同一 R/θ 下，两个初始 x 的差满足……」，并在 I05 的执行检查一栏注明「仅纯时间区间」。是否要求事件期间也有渐消记忆是设计选择，见 D-1。

#### P-2 metaplastic 自排除须用传递闭包的祖先集判断

- **位置：** O §7.1 第 3、4 段；O §21「metaplastic K 换 lineage 或进入 θ」一行；I10；G06。
- **原文：** 「若 target 是调制机制本身、其机制祖先或同 authority lineage，关闭该项 meta influence。新生 K 和本事件刚接管的 θ module 不进入本事件 meta view。每项受影响修订记录实际使用的机制集合和版本」；「A 调制生成 B 后，B 的 ancestry 包含 A，因此 B 不能再通过 G_meta 调制 A 的修订」。
- **分析：** I10 要求不存在这样的回授环：A 经过其他机制，最终影响 A 自己的后续修订。要证明这一点，排除判断用到的「机制祖先」必须是沿修订和交接继承下来的传递闭包。但原文每次修订只记录「实际使用的机制集合」，也就是直接调制者，文中没有说明比对时要取闭包。
- **反例（META-1）：** 如果只按直接调制者判断，A→B、B→C、C→A 三步都会被允许，因为 C 的直接祖先只有 B。这样 A 的修订经 B、C 又回到 A。3000 次随机模拟中，2990 次出现这种「自己成为自己祖先」的环；按传递闭包判断时为 0 次。
- **证明（7.12）：** 每次接受 M→T 后把 anc(T) 更新为 anc(T) ∪ {M} ∪ anc(M)，并且只在 T ∉ {M} ∪ anc(M) 时接受。归纳可得，任何机制都不会出现在自己的祖先集中。
- **建议改法：** 在 O §7.1 写明「机制祖先指 mechanism_context 沿修订与交接继承后的传递闭包」。这与 O §8「受影响责任闭包」的写法一致。

### 2.3 第三类：跨文档冲突

#### X-1 全局测试机会编号 j 由谁分配、记在哪里

- **位置：** O §6.2 第 4 段对 S §15 第 4 段；相关条款为 O §2 的归属表和 I03。
- **原文：** O：「j 由 R 的版本化验证记录单调分配，换名称、split、重试或更换 scorer 不重置它」。S：「全局机会/执行分配记录在 Q 的治理记录，G 在 R 记录候选证书与其消费引用；C 在 L 引用相应长期/transfer 证书。runtime 与算子暂存结果同事务发布这些引用，避免 G 偷写 Q 或 C 偷写 R」。
- **冲突：** O 把机会计数放在 R，只有 G 能写；S 放在 Q，只有 runtime 能写。两种做法都满足 I03，但重放路径、机会去重方式和 C 侧证书的取号方式不同。按 O 的写法，C 发起的 transfer、behavior、plasticity 检验如果需要新机会，只能经后续事件由 G 在 R 里取号；按 S 的写法，由 runtime 在 Q 里取号。
- **数学影响：** α_j 的总错误率保证（7.5）要求 j 在整个分支上全局单调、不重复。只要其中一处是唯一权威，这个保证就成立。如果两处各自计数，同一个 j 可能分配两次，Σα_jn ≤ α 就不再成立。
- **建议改法：** 按 README §1 的优先级 O 高于 S，但这属于状态归属问题，建议登记为差异，由用户确认唯一归属。不论选哪一处，都写明另一处只保存引用。

#### X-2 `CompileAuthorizedEffects` 的 R 输入与时间投影

- **位置与原文（五处签名）：**
  - O §3.2：`CompileAuthorizedEffects(R_snapshot, theta_snapshot, validity_snapshot, t, config)`，同节说「R 可因时间投影得到不同有效幅度」；
  - O §10.1：`CompileAuthorizedEffects(R_next, theta_candidate)`；
  - O §12：`CompileAuthorizedEffects(R, theta, validity_snapshot, t, config)`；
  - O §15：先算 `R_bar = Phi_R(Delta; R)`，再算 `E_eff(t) = CompileAuthorizedEffects(R_bar, theta, validity(t), t, config)`；
  - S §12：`CompileAuthorizedEffects(stored_R,stored_θ,process_time,validity)`，并说「R 侧按 q 时间包络……得到 R_eff」。
- **冲突：** S §12 和 O §3.2 让 Compile 自己按 t 施加 q 包络；O §15 先用 Φ_R 投影，再把 R̄ 和 t 一起交给 Compile。如果 R̄ 不携带新的锚点，包络会被施加两次。
- **反例（PHI-9）：** q₀=1，γ=0.05/s，Δ=10 s。正确值是 q = e^{−0.5} = 0.6065；对仍带旧锚点的 R̄ 再按 t 投影，得到 e^{−1} = 0.3679。这违反 I04（一次时间区间）和 F01（读取不累计衰减）。如果 R̄ 把投影时刻记为新锚点，则 Compile∘Φ_R 幂等，两种写法结果一致（证明 7.1 第 (vi) 条）。
- **附注：** 已合并的 P5-09 按「存储 R + 锚点，在 Compile 内投影一次」实现（[P5-09.md](P5-09.md) 中 O 15 一行与 `i21` 测试），与 S §12 一致。
- **建议改法：** 统一为一个签名，并写明组合律 Compile(Φ_R(Δ; R), t) = Compile(R, t)，或者规定 Compile 只接受存储快照。O §10.1 的两参数写法补上 validity 和 t。

#### X-3 J 的数学签名缺少时间

- **位置：** F §10；O §4；O §12、§12.1。
- **原文：** F：「mₖ₊₁(s) = J(θₖ₊₁,xₖ₊₁(s),Rₖ₊₁(s))」。O §4：「m = J(theta_next, x_next, R_next)」。O §12：「J(theta, x, R; carrier_config) …… effects = CompileAuthorizedEffects(R, theta, validity_snapshot, t, config)」；O §12.1 末段断言「相同合法输入和载体版本必得相同 m」。
- **冲突：** J 的函数体用到了 t 和 validity_snapshot，签名里却没有。θ 在两次 C 之间不变，x、R 也可以固定，但 θ module 的 ValidityContract 到期（I22）或 R 的证书到期，都会让 m 随 t 改变。如果「合法输入」不包括 t，「相同合法输入必得相同 m」就不成立：同一个 (θ, x, R) 在到期前后给出的 m 不同。
- **建议改法：** 签名写成 J(θ, x, R, t; carrier_config)，或者把 t 和 validity 明确列进 `JStateView`。F §10 的 m(s) 同样处理。

## 7 证明（第 2 步）

记号：‖·‖∞ 是最大绝对分量，‖·‖₂ 是欧氏范数。以下证明都在精确算术下进行，binary64 的差别单独注明。

### 7.1 Φ_x 与 q 包络（O §5.1、§15；F §2.2、§5、§11）

设 Λ=diag(λ_i)，λ_i≥λ_min>0，b∈X=[−1,1]^d，Δ≥0，e_i=e^{−λ_iΔ}∈(0,1]。

- (i) **恒等：** Δ=0 时 e_i=1，Φ_0(x)_i=b_i+(x_i−b_i)=x_i。
- (ii) **半群：** Φ_t(Φ_s(x))_i = b_i + e^{−λ_i t}·e^{−λ_i s}(x_i−b_i) = Φ_{s+t}(x)_i。对任意矩阵 Λ 也成立，因为 e^{−Λt}e^{−Λs}=e^{−Λ(s+t)}。
- (iii) **盒不变：** Φ_Δ(x)_i=(1−e_i)b_i+e_i x_i 是 b_i 与 x_i 的凸组合，两者都在 [−1,1] 内，所以结果也在其中。非对角 Λ 不满足这一点（C-1）。
- (iv) **收缩：** Φ(x)_i−Φ(y)_i=e_i(x_i−y_i)，所以 |·| ≤ e^{−λ_minΔ}‖x−y‖∞。
- (v) **分段：** 被过滤的记录不调用 Φ，也不移动锚点。由 (ii)，纯时间维护把 [t_0,t_n] 切成多少段都给出 Φ_{t_n−t_0}，所以经过时间不丢也不重（F §5、§16.13）。
- (vi) **q 包络：** q(t)=q(t_a)e^{−γ(t−t_a)} 同样满足半群律。若投影结果 (q(t_1), t_1) 把 t_1 记为新锚点，再投影到 t_2 得 q(t_a)e^{−γ(t_2−t_a)}，即组合幂等。若保留旧锚点 t_a，则得到 q(t_a)e^{−γ(t_1−t_a)}e^{−γ(t_2−t_a)}，衰减被施加了两次（X-2）。

脚本：PHI-1 测得半群误差 ≤ 4.4×10⁻¹⁶；PHI-2 在 20 万例中没有越界；PHI-3 没有违反收缩界；PHI-6 测得分段与一次投影之差 ≤ 4.4×10⁻¹⁶；PHI-8 测得 q 包络半群误差 ≤ 2.2×10⁻¹⁶。

binary64 注：照字面计算的 b+e(x−b) 在 Δ=0 时不总等于 x（PHI-0），见 D-2。

### 7.2 驱动幅度界（O §5.2）

对每个坐标 i，|δ_i| = g_i·|Σ_k B_ik u_k + Σ_j r_{j,i}| ≤ Σ_k|B_ik| + Σ_j|r_{j,i}|，因为 g_i≤1、|u_k|≤1。由此 ‖δ‖∞ ≤ ‖B‖_{∞→∞} + Σ_j‖r_j‖∞。

再由三角不等式，‖B‖_{∞→∞} ≤ ‖B₀‖_{∞→∞} + Σ_j‖ΔB_j‖_{∞→∞}。若 residual 取 r_j = M_j x̄ + v_j，且 ‖x̄‖∞≤1，则 ‖r_j‖∞ ≤ ‖M_j‖_{∞→∞} + ‖v_j‖∞。

因此 η_x 取各项绝对值之和就是保守界。抵消不会被计入：B₀=1、ΔB=−1 时计为 2。Project_X 之后 x̃∈X，于是由 (iii) 和 F_out=Id 得到 O §18 的有界性。脚本：DRV-1 在 10 万例中没有违反。

### 7.3 事件驱动下的收缩（P-1）

设第 k 次事件的映射 E_k 在 ∞-范数下 L_k-Lipschitz（Project_X 为截断，是 1-Lipschitz）。相邻事件之间，Φ 按 e^{−λ_minΔt} 收缩，两者复合得 ‖δx(t)‖∞ ≤ (Π_k L_k)·e^{−λ_min t}·‖δx(0)‖∞。

若 g 和 residual 不依赖 x̄，E 的 Jacobian 为 I + diag(g)·B·diag(sech²(·))·W_x，所以 L = sup ‖I + diag(g)·B·diag(s)·W_x‖∞（s∈[0,1]^d）。

在反例中，d=1，B=1，W_x=5，在 0 附近 L=1+5=6>1。映射 x ↦ clamp(e^{−0.1}x + tanh(5e^{−0.1}x)) 有两个吸引不动点 ±1，所以差值不收缩（PHI-7）。

### 7.4 J 的幅度界（O §12.1、§13.1）

‖Wx‖₂ = ‖Σ_j x_j w_j‖₂ ≤ Σ_j|x_j|·‖w_j‖₂ ≤ Σ_j‖w_j‖₂（‖x‖∞≤1），所以 ‖W‖_{∞→2} ≤ Σ_j‖w_j‖₂。精确值是凸函数在立方体上的最大值，在顶点处取得。JW-1 用顶点枚举验证上界在 2000 例中成立；W=I_d 时上界比精确值大 √d 倍。

于是 ‖a_l‖₂ ≤ ‖W_l x‖₂ + Σ_r‖e_r‖₂ ≤ β_x,l + Σβ_r,l ≤ β_l，且 ‖U_l a_l‖₂ ≤ ‖U_l‖_op·‖a_l‖₂ ≤ β_l。用到的前提：x∈[−1,1]^d；参考点为 0（C-8）；每个 J_direct 项在 X 内所有 x、所有 t 下都不超过其 β_r,l。脚本：JW-3 在 3 万例中没有违反。

### 7.5 Hoeffding 半径与 α 分配（O §6.2）

对独立的 dᵢ∈[−1,1]（区间宽 2），Hoeffding 不等式给出 P(|d̄_n−μ|≥r) ≤ 2exp(−2nr²/2²) = 2exp(−nr²/2)。令右边等于 α_jn，解得 r = sqrt(2·ln(2/α_jn)/n)，正是原文的 radius（ST-2：相对误差 8×10⁻¹⁵）。

总错误率：P(∃ j,n：μ_j∉CI(j,n)) ≤ Σ_jΣ_n α_jn = Σ_j α_j·Σ_n 1/(n(n+1)) = Σ_j α_j = (6α/π²)·(π²/6) = α（ST-1）。这里用的是并集界，不需要各 (j,n) 之间独立。每个 (j,n) 都被覆盖，所以在可选停止（随时查看、随时停）下仍然成立，是时间一致的置信序列。

判据：「改进」要求下界 > margin，「等价」要求 CI ⊆ [−ε,ε]。在概率至少 1−α 的事件上，前者推出 μ>margin，后者推出 |μ|≤ε。不显著不能推出等价。

Monte Carlo（ST-3）：在 Rademacher 零假设下，j=1、每个 block 都查看、共 400 次，4000 条序列中误覆盖 0 次（上界 0.0304）。对照：不做校正、每次查看都用 95% 正态区间，误覆盖率为 0.462。

前提：block 间独立且有界；没有选择性缺失；discovery 数据与验证数据分开；每个 (j,n) 只结算一次；j 全局唯一（X-1）。这些都已在 O §6.2 写明，只有最后一条的归属有冲突。

### 7.6 有限根路径与 τ_θ（F §8；O §11、§15、§18）

path = Σ_j d_Θ(θ_{j+1},θ_j) ≤ Σ_j κΣ_e w_j(e) = κΣ_eΣ_j w_j(e) ≤ κΣ_e b(e)。前提是 w≥0、根集合固定、有限和可交换次序。按 O §11 的拆分，界为 κ_Θ Σ_e b_Θ(e)（BUD-1）。

若 [s,t] 上 path ≥ D，由任意区间界得 D ≤ v_Θ(t−s)+ε_Θ，所以 t−s ≥ (D−ε_Θ)/v_Θ。由三角不等式（7.8），位移 d_Θ(θ_s,θ_t) ≤ path，所以同一下界对位移也成立（TAU-1）。

### 7.7 P/A 前缀索引（S §18）

设已接受的更新为 (t_1,d_1),…,(t_n,d_n)，时刻不减，P_k=Σ_{i≤k}d_i，P_0=0。

约束：对所有 a≤b，P_b−P_{a−1} ≤ v(t_b−t_a)+ε。闭区间的上确界在更新时刻为端点时取得，因为缩短区间不会丢掉其中的更新，只会让右边变小。

移项得 (P_b − v t_b) + max_{a≤b}(v t_a − P_{a−1}) ≤ ε。记 A_b = max_{a≤b}(v t_a − P_{a−1})，则递推 A_b = max(A_{b−1}, v t_b − P_{b−1})。

新候选 (t,d) 的检查 P+d−vt+A_new ≤ ε 正是 b=n+1 时对所有 a 的约束；b≤n 的约束在之前已经检查过（归纳）。空序列时 A_new = vt，检查化为 d ≤ ε，即单步界。同一时刻的多次更新也被覆盖。

脚本：PA-1 用精确有理数，在 38495 次决策中与 O(n²) 暴力检查 0 处不一致。由此还可得出：任意区间界蕴含单步界 ε_Θ，也蕴含长度为 W 的滑动窗口界 v_ΘW+ε_Θ。

### 7.8 d_Θ 是度量（O §10.3）

在固定槽位布局的规范表示 (p,c)∈ℝ^m×Σ^k 上，‖·‖₁ 和 Hamming 距离都是度量，正系数加权和仍是度量：非负性、对称性和三角不等式逐项成立。d=0 时，由 w_p,w_c>0 得 p=p′、c=c′。

前提：w_p,w_c>0（DT-2）；比较原值而不是哈希（DT-3）；槽位布局固定，否则 Hamming 距离无定义。它是规范表示上的度量；只有当规范化是单射时，它才是 θ 本身上的度量（O §10.3「该规范化必须确定」）。

安装一个非零 module 至少改变一个离散字段，所以 d_Θ ≥ w_c > 0，不会因为即时等价而被算作 0（V-20）。脚本：DT-1 在 2 万组中没有违反。

### 7.9 行动时机（F §11；O §17.3；S §20）

- (a) **局部可积不够：** 设第 n 次行动后强度为 2ⁿλ₀，则 T_∞ = Σ_n τ_n，τ_n ~ Exp(2ⁿλ₀)，E[T_∞] = 2/λ₀ < ∞，所以 T_∞<∞ 几乎必然成立，即有限时间内发生无穷次行动（NX-1：2000 条路径都在 10 s 内达到 60 次）。
- (b) **充分条件：** 若 λ≤λ_max，用 thinning 可把行动嵌入速率为 λ_max 的 Poisson 过程，所以 N(t) 有限（几乎必然）。若再有最小间隔 δ>0，则 N(t) ≤ ⌊t/δ⌋+1（确定性），Pr(lim Tₙ=∞)=1（NX-2）。
- (c) **thinning 正确：** 以速率 λ_max 产生候选，再以概率 λ(s)/λ_max 接受，得到的过程强度为 λ(s)；对确定的强度路径，生存函数为 exp(−∫λ)（TH-1：最大偏差 1.52 个标准误）。
- (d) **最终行动：** Pr(Δ<∞) = 1 − exp(−∫₀^∞λ)，等于 1 当且仅当 ∫₀^∞λ = ∞。

### 7.10 尺度分离的方向（O §15）

x 最慢的模态以 λ_min 衰减，时间常数为 1/λ_min；R 最快的包络以 γ_max 衰减，时间常数为 1/γ_max。要求 1/λ_min ≤ (1/γ_max)/ρ，等价于 λ_min/γ_max ≥ ρ。O §15 取的正是这对保守组合（x 的最慢速率比 R 的最快速率），方向正确。structural_fixture 中该比值为 20。

### 7.11 接管的即时连续（O §10.2）

接管时刻 t_h 之前，R 在 slice 上贡献 q(t_h)K。接管后 R 被抑制，θ module 贡献同样的 q(t_h)K，所以在 t_h 处两者相等（复制编译的载体给出端点级精确相等）。

此后 θ 保持常值，而 R 原本会衰减为 q(t_h)e^{−γ(t−t_h)}K，两者之差为 q(t_h)(1−e^{−γ(t−t_h)})‖K‖ ≤ q(t_h)‖K‖。这就是需要申报的长期保持，计入 d_Θ 预算。若 q(t_h)=0，则 module 参数为 0，不能借接管重建非零作用（C04）。

### 7.12 单事件顺序与 meta 自排除（O §4、§7.1、§18）

按 O §4 给各阶段编号。每一次读取都指向快照 k 或编号更小的阶段（ORD-1），所以没有同事件环；G 读的是 θ_k，不是 θ_next。把 G 与 C 对调后，C 会读到尚未产生的 R_next；插入第二次 Φ 会被「时间推进一次」的检查发现（X06）。

meta 自排除：设不变式为「任何机制不在自己的祖先集中」。接受 M→T 的条件是 T ∉ {M}∪anc(M)，更新为 anc(T) ← anc(T)∪{M}∪anc(M)。由于 T∉anc(T)（归纳假设）、T≠M、T∉anc(M)，更新后仍有 T∉anc(T)，不变式保持。只用直接调制者判断时，归纳在第二步失效（P-2，META-1）。

### 7.13 谱系关系（F §13.1）

未定义的分支合并不是合法迁移，所以每个检查点至多有一个父检查点，来源图是森林。

- SameLineage(i,j) ⇔ root(i)=root(j)，这是等价关系。
- ValidContinuation(i,j) ⇔ i 是 j 的祖先或 j 本身。它是传递的、反对称的；若零长链也算合法链，它还是自反的（D-9），因此是偏序。
- 分叉后的兄弟检查点互不为祖先，所以互不为延续。
- 记录缺失时，验证器返回未知，不会给出与完整记录相反的结论。

脚本：LIN-1 在 200 棵随机树上没有违反。

### 7.14 入口与历史（F §4、§5、§16.1）

由定义，H_0=Π_Γ(∅)=()。处理下一条原始记录后，H_{k+1} = Π_Γ(D[0:ℓ_k+1]) = Π_Γ(D[0:ℓ_k]) ⊕ r_k = H_k ⊕ r_k，其中 r_k=⊥ 时被移除。两种情形下都有 ℓ_{k+1}=ℓ_k+1，所以 ℓ_k=ℓ_0+k。

同 ID 同载荷的记录被过滤；同 ID 异载荷时拒绝且不覆盖，所以总是先到者有效；重放结果确定。16.1 的例子得到 H=(e₁,e₂)、入口位置为 3（ING-1）。

### 7.15 ε 相容与细分（F §6.1；O §6.1、§6.3）

d 是度量，所以 ε 相容关系是自反、对称的，但不传递（G01-1）。极小的相容团划分不唯一（G01-2）。两个各自相容的叶域合并后可能不相容（G01-4）。这三点正是 O §6.3 闭合的内容。
