## 术语与起点

按 ADR 0032 §10，当前说明写「乎」，复数写四个「乎」；联结、共情、好奇、成事的顺序不改。文档旧术语与 `Nature*`、A、a(e) 的对应见该节术语表，标识符与公式不改。历史 ADR、历史追加、原始规格转换版、公式块和原始记录里的旧称只用于追溯。

按 ADR 0032 §§1–2，四个「乎」、依恋、数值与价值偏好、成事初始最弱、亲疏反应是起点；每条预设内容都须有经历改变路径。已知路径与缺口分列，不能因固定版本、参数合法或用户不能调就称其行为中立。此原则不授予改写历史、用户权限或核心写权限的能力。v2.0「她是谁」两处改为“她一开始只在乎四件事”“这份依恋一开始就很强”。

## R01–R03：主动、预算与任务后续

依据 V2-79、V2-104、V2-117（含其取代/保留/迁移表），以及 ADR 0032 §6 对教导的后续修订：

- v2.0 §9.4/15/16、ARCHITECTURE §6.5、ADR 0026 §8、P5-12/17/19/20/22、P6-01 中，固定主动强度、thinning、抽样机会前置条件不再是实施义务。她在持续认知中于 m 下决定是否开口、何时开口与做什么。P5-38/P5-39 完成前没有主动；不能用主动强度显示情绪或用定时器代替决定。
- 外部约束是用户边界、防失控保险丝、执行前复核。拒绝不积压为门控放开后的自动发送；反复提议或更换行动 ID 不刷新冷却、不绕过执行侧统一检查。对话追问、自主身体动作、内在活动不计主动保险丝次数的范围保留。
- CONTRACTS §8 与旧资源中的 180 秒、2 次/小时、安静因子 0.5 是待迁移旧值，不是新保险丝的已批准数值。正常相处中不应触发的保险丝值仍须用户按 ADR 设定；本卡不选值。V2-104 取消网络日联系人/消息行为上限，只留防失控保护。
- 助手独立预算与用量显示沿 ADR 0004 §5 保留；旧 30 次/日究竟是费用边界还是防循环、应如何迁移，已有决定不足以定案，见 BLOCKED。不能把审计建议变成新额度政策。
- `codex_needs_you` 不再产生立即主动机会；权限请求是认知材料，提醒与否、时机和内容由她在 m 下决定。`helper_done` 保留任务后续、实际结果与原行动权限路径，任务状态进入不等于必须立刻口头通知；表达仍受边界约束，不增特殊主动入口。教导按 ADR 0032 §6 记建议、由后续经历检验，不继续直接信任加权。
- Q 的已抽样状态、genesis 主动读出资源与旧契约的后继迁移另卡；本索引没有变更或重新解释旧 wire 字节。

## R05：结构事实与评价

依据 ADR 0014 §3/§5、V2-25、ADR 0032 §§1–2：送达、已读、触摸部位/力度、离开时长及其未知状态是观察事实；“必为负联结”或固定四通道数值是评价预设。未知不伪造成负面；确定发生某个观察，也不自动证明某种感受必须永久发生。

P5-11 的“固定规则表给出 a(e)”和“已读未回才评为负”不能被用作已经满足可改变起点原则的证明。保留当前通道、EV6/EV10、记录与重放约束；逐项列出评价预设如何由经历改变。缺失的评价机制交后继设计，本卡不写新的 a(e) 表、正负规则或接口，也不将未完成设计伪装成实现结果。

## R08：人格材料、声音能力与身体调控

依据 v2.0 §2.3/I28、ADR 0027、V2-106、ADR 0032 §§3、8：

- p 只含事实、用户边界、格式与语言规则。CONTRACTS §1.7 的“人设种子”“协议：说话风格”、P4-03 的“根据人设种子”不构成人格输入授权；音色身份、发音、语言能力和表达词汇仍保留，不重选声音、不废掉既有候选。
- 识别/文字的三语能力、声音模型实际支持的语言、默认回答语言分开。默认跟随用户语言，不是强制同语；旧回答同语 ≥98% 的行为要求待重写，不波及 P4-01 的语言识别准确率或 AC2-16 三语通路验收。其他语言“按最接近处理并标记”仍保留其标记与能力边界，不冒充已经识别正确。
- 表演提示、表情槽位和语气参考是表达能力。声音 A 表达层与 B 身体层沿 V2-106 分工：B 作用在 A 合成的声音上，不重复写入 A 指令；过渡期标签丢弃并记录。ADR 0032 §8 要求 B、身体读出、待机与社交反射的强弱和是否发生受她调控，经历可改变；固定映射与随机抽样不证明调控路径已经存在。
- 旧“每次语音结束必须看向用户/点头”、待机禁重复等要求须由后继卡对应上述决定重写。物理限位、碰撞、口型、合法消息、真实投递、无隐藏状态等结构要求保留。“光标停留自动躲开”与“鼠标是手”的冲突仍待用户决定，本卡保留原文，不选择方案。

<a id="r09"></a>
## R09：模式 C

依据 [ADR 0026 §7](../adr/0026-continuous-cognition.md)：云端/helper 可提供事实资料和建议；采纳为持续认知后继或对外行动的选择须由本地 m 载体重新作出。ADR 0003 与 P6-05 的“行动计划不变”不能要求本地接受远程决定；本地可拒绝建议，不只改口吻。

事实/数字/名称的保持、草稿与最终回执、J01/J05 和严格性标注仍按原范围验证；不能把“保留事实”扩大成“保留云端行动意图”。模式 B 的非严格标注、仅剩 B 时严格持续认知暂停，以及全部执行前权限复核保留。本卡不改生成接口。

<a id="r10"></a>
## R10：校准与模型先验的报告

依据 v2.0 §9.5–9.7、AC2-16/I17、ADR 0012 §§2–6、ADR 0014 §5 与 ADR 0032 §§1–2：

- 报告继续绑定模型/载体/语言/样本/方向/剂量和容差，说明对比样本、概念指标与样例来源；测量通路及能力，不能按喜欢的风格筛选结果。m = 0 只去掉本套调制，基础模型先验仍在。
- IRL/A/M 的三语人工标注集、各通道平均有符号偏差及语言差、μ 偏差、标注混淆矩阵沿 ADR 0014 §5 报告；不新增偏差门槛。覆盖盲区报告沿 ADR 0012 §6，不自动增删四个「乎」。
- 通路单调性、三语、能力无损要求完整保留；SYS10/COG-A05 的决定变化对照不替代 AC2-16。自动生成样例与锁模型版本也不证明没有先验。
- 载体迁移的连续性/判断一致性按已定口径验证；身份方向移除仍是看报告后再决定的研究候选。本卡不启用去偏器，不重开实验，不将预注册或结构检查写成行为结果。
