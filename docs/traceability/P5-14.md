# P5-14 行动生命周期与 outbox

交付对象为排练谱系的 W13。H、完整 Q 以及该次行动的登记、消费或结果记录共用一次 W02 外层提交。模块有两个入口。P 的生产者通过 `stage_local_plan` 暂存已选计划，事件处理者用 `ActionTransaction` 消费当前入口和读票。
