# P5-40 权限契约的规格对照

本卡对应差异登记 [V2-189](diff-register.md#p5-40-权限与成长管理的契约承接)。所有消息及其冻结类型标签见 [permission.proto](../../core/contracts/permission.proto)。对照右列区分本卡能检查的字段与需要真实会话、存储或连接器的判断。

| 条款 | 接口与可验证的约束 | P5-41 的联测入口 |
| --- | --- | --- |
| ADR 0024，CONTRACTS §4.3 | LocalUserBinding 绑定人员、认证记录、安装和会话。TerminalRequestV2 继承请求 ID、会话、协议及五条原分支。check_management_binding 与服务另行取得的 u*、入口、能力及帧预算比较。 | 通过仍存活的已配对连接解析发行方认可的认证记录，检查当前绑定的人员确是 u*。伪造 ID、旧连接、普通 worker、助手、网络均拒绝。 |
| ADR 0043 §4.1，ADR 0045 D9，I18 | DesktopPermissionPolicy 记录档位、版本与可挽回性资源。桌面 scope 同时携带判定结果。不可挽回且禁做时不能签发；先问且缺本次同意时拒绝。不可挽回且档位为直接做、可挽回且禁做档位均有合法向量。 | 以当前已发布资源重新判定同一载荷；服务从受信确认入口查出 approval_id，核对人、批准时间、action_id 和原样字节。用户切换档位后拒绝旧凭证。 |
| ADR 0045 D1，ADR 0046 §2.1，I02 | PermissionContext 只能选本地执行凭证或 RemoteCognitiveReceipt。后者沿用原 mode 与 local_pause_reason。执行请求只接收 ExecutionCredential。所有新标签均排除在终端对象上传入口外。 | 云端收到的请求仅供返回内部文字。核心审核文字；本地路径暂停时停掉依赖它的关注、查询、行动与投递，禁止将远端文字转换成指令或写 H/Q。 |
| 总方案 §20–21，I26，X04 | ActionRequestV2 要求显式凭证、原样载荷。跨三端复算 SHA-256 并与行动、期限比对。check_dispatch_binding 比较可信签发记录、持有会话与半开有效期。ExecutionBudget 要求记账单位、版本、限额和本次用量。 | P5-14 在发送前检查活跃执行器、精确作用域、协议/权限/撤销代际及未花预算，核对批准的是将要发送的同一份字节，一次消费和预留须抗竞争。回调失败不释放一次性权利。跨崩溃无法确定副作用时按 UNKNOWN 核对。 |
| CONTRACTS §6，V2-89/104，I18 | TrustMemory 仅接受 T1/T2。凭证中的信任须同作用域、同撤销代际、同 tier。ConnectorScope 分开她的社交、须事后通知的社交、小钱包支付及 u* 充值，钱包金额为正并绑定币种、对象，充值要求本机主体。 | 只从 Q 或显式版本资源取得外层事务提交过的有效信任，核对签发用户、适用资源版本。目录权威分类操作，不能用通用 CONNECTOR_OPERATION 绕过钱包、社交或桌面规则。检查真实余额、上限、充值人、事后通知与身份隔离。 |
| v2.0 §5.4、§10、§11，V2-87/97/101，I02、I23 | GrowthCommandV2 将复核绑定到报警 ID、报警系统记录引用、复核记录、规律版本与 H 前缀；仅规律有错时给出不同的新版本。面板的暂停/恢复必带二次确认标识；复核限 echoctl。TerminalResponseV2 把同请求的成功管理记录或拒绝原因带回。 | P5-29 逐报警核实端点、记录种类、当前规律与 H 前缀，核验挑战与完整命令、会话绑定，防止二次确认移用。报警只通知。成功命令审计/L 和 H 系统记录原子提交，不经过 F/G/C；拒绝只记拒绝审计，不制造已执行记录。P5-15 恢复与结构重放不重执行命令。 |
| ADR 0007，0046 §4，SYS17 | 冻结 #234 的 IDL 与四组黄金前缀。四个后继沿用旧字段号或 reserved，新字段从旧最大号之后分配。 | 迁移由 P5-41 在临时存储执行并测试失败回退。旧日志不能凭字段补全取得新权限。 |

合法/非法用例见 [黄金夹具](../../core/contracts/fixture_permission.py)，受信输入对照见 [Rust 测试](../../core/crates/core-types/tests/permission.rs)。
