## 2026-10-24 JSON 位值回归

ADR 0019 §8、ADR 0021 §8 的有限 binary64 输入：core-types 为既有 serde_json 启用 `float_roundtrip`，由 `p5_34_contract::json_roundtrip_preserves_adjacent_q_v_values` 核对 q 相邻值/次正规数的位模式，并验证 V 为1的前一值、A=±1的 JSON 输入仍被拒绝。首次冻结失败原文和全部旧向量复核结果见 `reports/P5-34/verification/idle-20261024/`；未替换旧期望或增加字段。

## 2026-10-24 审查修复

ADR0021 §9明确本次集合预算与历史总量的边界：普通提交按当前R的倾向索引流式核对最新关联，先选版本再筛关联，当前事务仍经原CanonicalV1预算检查；重放仍要求处理有分配的旧组，已空后继不重复发布。`r_review::retired_group_history_exceeds_message_budget_without_blocking_commits`在max_items=32下累计36个历史组并继续提交/恢复，且超限的本次集合在发布前拒绝。

v2.0 §2.4/§5.4、I23输入完整性（存储边界，未签发真实G）：RReplayEvent保留逐事件staged_concepts及其受摘要验证的资源闭包。`replay_keeps_each_events_staged_concepts_and_atomic_publication`核对历史/当前概念关联、独有signature/grounding/relations及失败原子性；`replay_hash_checks_staged_concept_resources_before_calling_kernel`以同长合法编码损坏证明摘要错误在回调前拒绝。三项定向回归通过，完整回归结果见P5-34当前报告。
