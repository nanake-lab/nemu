下面的 `REPORT.md` 模板只用于 AGENTS.md 第 6 节列出的需要写报告的卡：设计卡、研究卡、演示与实验卡（`DESIGN-`、`R-`、`DEMO-`、`MATH-`、`PLAN-`），以及含正式验收测量、GPU 测量的卡。普通代码卡不写 `REPORT.md`，使用文末的「代码卡 PR 描述」短模板。

报告模板：

```markdown
# <任务号> <标题> — 报告

## 当前状态
一段话：完成 / 部分完成（见 BLOCKED.md）；在等什么。

## 交付物
- 文件或目录：作用

## 验收
| 命令或检查（含 Echo Core 验收编号） | 结果 | 证据 |
| --- | --- | --- |

## 规格对照（Echo Core 相关的卡必填）
| 规格条款 | 实现位置 | 测试 |
| --- | --- | --- |

## 新增依赖
| 名称 | 版本 | 许可证 | 用途 |

## 待用户确认
- [ ] （阻塞）...
- [ ] （不阻塞）...

## 后续建议（不在本任务范围内）
- ...
```

代码卡 PR 描述短模板（不写 `REPORT.md` 时使用；白话三行之后的正文不超过十行）：

```markdown
做了什么：...
对她或对项目意味着什么：...
需要用户做什么：...（没有写「无」）

- 改动：`<模块或文件路径>` — ...
- 验证：`<命令>` 通过（或 CI 链接）
- 自行决定（预授权）：决定 / 理由（无则写「无」）
- 未完成与后续 PR：当前 `<n>/<m>`，后续 ...（单 PR 无未完成项写「无」）
- 证据索引：`<证据仓库路径 / SHA-256 / 提交号>`（无证据时删去此行）
```
