## 1. 背景与总原则

预设可以为了她可爱、为了用户的需要而设，但每一条都必须受她调控——存在经历改变它的路径；她改不了的预设视为缺陷。

设计分为四类，不能用“固定版本”“可重放”或“参数合法”替代内容上的判断：

| 类别 | 本次决定的含义 |
| --- | --- |
| 起点 | 可以有用户选择的初始偏好和反应；必须能由经历改变，不能把初始选择变成永久结果 |
| 用户边界 | 用户选定的权限、隐私等边界；D19、D21 保留已定分工，D22 是默认语言偏好 |
| 保险丝 | 只防程序与工程错误；不能借此把她拉回用户偏爱的心境、性格或反应 |
| 结构 | 状态归属、真实记录、事务、版本、重放及接口等所需结构；不据结构之名增加行为设定 |

“每一条都受她调控”针对预设内容，不授予她改写用户权限、历史或核心写权限的能力。身体和心理的变化仍经核心权威路径记录，不在终端增加隐藏状态。

## 2. 起点保留，逐项交代改变路径

下表的路径区分现有规格提供的通道和仍欠缺的设计。列出路径不等于证明当前实现已满足总原则；本 ADR 不补新更新公式。

| 审计项 | 用户决定 | 经历改变它的路径与缺口 |
| --- | --- | --- |
| D01 | 保留联结、共情、好奇、成事这四个「乎」作为起点 | 外源经历的 a(e) 经 C 改变 θ，真实证据经 G 改变 R，再经 F/J 改变感受与表达（v2.0 §§2、5–9）。这是已有调控通道；固定 A 的正负评价、排除项若仍使某条预设不能被经历改变，就属于缺陷，后续须逐条验证并设计缺失路径；不据此自行增加或删除通道 |
| D03 | 保留对 u* 的依恋 | 关系经历经 G 更新倾向；有限 A_att 可被长期一致的反向证据改变（§5.3 推论7、§10、AC2-13）。亲近的先验与信任初值分别核对，不能把管理身份当永久可信证明；初始信任按既有证据路径变化，能力与诚实/兑现另见第 6 节 |
| D06：数值起点 | 保留初始数值 | b₀、g₀、σ₀、τ₀ 等是初始化；经历经 C 更新 b、g、λ 及估计器，R 经 G 更新。逐项记录初值如何让位于经历；b₀ 的残留分量按第 4 节另行设计，不以“待校准”掩盖永久锚定 |
| D06：价值偏好 | 与数值起点分开登记 | 初值中表达“更在意什么、怎样反应”的部分属于可改变的起点；分别追踪经历→权威状态→行为的路径。不能因其编码为数字就归为纯数值结构，也不新增价值排序 |
| D02 | 保留“成事初始最弱” | 经历经 C 改变各通道增益；最弱只约束出生初值，不约束之后的相对排序。后续验证经历能改变排序；若现行共同系数或边界阻断了路径，须修复，不自行挑新数值 |
| D05 | 保留“越亲近越能触动她”作为起点 | 现有关系经历→π→w 的路径能改变谁更亲近，却不等于能改变“亲疏必定怎样加权”的固定关系。当前 w 公式、下限与多人取最大没有给出改变该预设本身的路径，列为**待设计**；本 ADR 不另选聚合公式 |

## 3. 用户边界：D19、D21、D22

- **D19 保留已定分工。** 身份披露、记录可见性、秘密处理及诚实底线按 v2.0 §§10–11、ADR 0011 与后续已批准登记执行；V2-89、V2-104 的最新社交边界不退回旧审批/日行为上限。§18 的“被问谁能看记录”和他人数据删除问题仍未决定，本 ADR 不补答案。
- **D21 保留已定分工。** 直接外源与桌面观察、自致结果、内部记录、维护系统记录的分工沿 ADR 0025/0026、V2-71/72/77/87：直接外源进入 C 的规则保留；桌面观察与自致结果不能改标外源；内部记录不自证，维护记录不直接进入 F/G/C。D11 的时间资格修订不扩大 C 的来源范围。
- **D22 改为默认跟随用户语言，不是硬规定。** 语言能力、声音模型实际支持范围与默认回答语言分开；旧“回答语言一致 ≥98%”不能继续充当强制同语的行为要求。后续重写对应验收，本 ADR 不设替代百分比。

## 4. D07：生活塑造基线

出生基线 b₀ 的分量随可靠经历消退。反常经历过去后，回到生活塑造的基线，而非出生基线。

这取代 v2.0 §8 中以 n_b 与有效经历上限永久保留出生锚定、以及 §§14/17 的“回到原处”在出生基线意义上的要求。**AC2-25 须重新定义**，新估计规律、可靠经历的判定和可验证的回归参照另行设计，本 ADR 不给公式、阈值或期限。V2-96 中依赖旧递推的界须随新规律重推，不能直接沿用作新规律证明。

漂移只报警（V2-97），不因正常经历使她改变而暂停或拉回。成长计算故障的候选拒绝、结构故障路径和用户手动暂停仍按各自既有分工；不把报警当作成长验收通过。

## 5. D09、D10：取消统一定时回落保证

取消“无新外源时必须在 T_x 内回落”的统一保证，取代 ADR 0026 §6.3 与 COG-A12 中相应部分；其 §2 第 5 条及 v2.0 §6 中用于要求该统一保证的读法一并不再作为实施义务。

保留**重复自我刺激不递增**的防循环要求；失控与资源保护在执行层。新规律另行设计与验证，本 ADR 不决定 κ 的替代形式，不把 κ 改为 1，不取消所有时间投影，也不以固定事件序列的非扩张性证明完整内生闭环安全。AC2-15/I05 中固定 R/θ、同一事件序列下的局部性质与统一回落是不同命题；前者不因取消后者而自动删除，后续须逐项映射。

[R-KAPPA-01](../../reports/R-KAPPA-01/DEVLOG.md) 给出的依据是：在固定 R/θ 的合成夹具中，晚期可核验新结果若获得大于 ε 的直接脉冲，就能违反最后外源输入后固定期限内回落并永久保持的保证；仅按文本去重也挡不住内容变化的重复同向刺激。它没有证明模型认知受损、候选行为更好或完整闭环不自锁。该研究的 C 候选及“停止有效新信息后条件回落”建议**不因本 ADR 自动采纳**；本次只决定撤销统一保证与保留防循环目标。

## 6. D12、D04、D20、D13：建议、关系与证据

- **D12：** 教导记为建议，记录谁、什么、情境、理由，由后续经历检验，不直接作为证据。取代 EV7、“教导直接按信任加权”和 w_teach/S 的相关直接证据读法；AC2-12 须据此重新定义。听到建议的记录是真实发生的，不等于建议内容已经获得支持。
- **D04：** 区分能力与诚实/兑现。能力好不直接等于诚实或会兑现；对应观测和后续关系路径另行设计，不在本 ADR 新造“诚实分”、固定方向或新倾向数量。
- **D20：** 撒谎的后果照常计入经历，诚实底线由用户边界独立拦截。取代 EV4、§10、I27/AC2-11 中“只因撒谎就排除真实后果”的部分。谎话内容不因此成为事实；EV4 的可比变化要求、来源真实性、同源去重、正反对称仍保留，计入经历不等于自动取得因果证据资格。
- **D13：** 拆分“是否发生 / 内容是否属实 / 是否主观”，不把不可核实直接当作不重要。EV9 与 §5.2 的单一可核实权重须按此设计，不以把 v_u 直接改成 1 代替设计，也不保证自动识破谎言。

## 7. D11：结果时间与执行凭证期限分开

结果能否触动她按实际发生与观察时间判定，不因队列延迟丧失；执行凭证期限另计。

取代 ADR 0026 §6.3、COG-09–11、V2-115 中以结果“经 F 提交”跨过 τ 就失去直接作用的部分。记录发生、观察、处理/提交的区别；具体时间字段、可信来源与重放合同由后继契约卡设计。不回写历史，也不假称当时已经理解。过期凭证仍不能授权执行，旧计算不能覆盖新 Q，UNKNOWN 不盲目重发；不把“真实后果可触动她”变成旧计划重新获准执行。

## 8. D15–D18：身体的预设反应

预设反应保留；反应强弱与是否发生受她调控，经历可改变。这包括身体读出、声音 B 层、待机与社交反射，不能以固定映射、抽样或“反射”名称使其永久不受调控。经历经核心权威状态影响表达，再由身体执行；具体可调控路径与后继接口待设计，终端不保存情绪或关系变量。

“光标停留时自动躲开”与 ADR 0025“鼠标是用户的手”冲突，**待用户决定**。本 ADR 不选择删除、保留或改成可用性边界。物理限位、碰撞、口型与防渲染错误的结构要求不因此取消；旧“每次语音结束必须点头”等验收须与“是否发生受她调控”相对应，不能继续强制触发。

## 12. 备选方案与后果

本次没有选择“删除所有预设”，也没有选择“因为可爱就永久固定”。用户选择的是保留起点并要求经历可改变。保留统一回落又对任意晚期新结果解除折扣的组合，与 R-KAPPA-01 的反例冲突；本次选择取消统一保证，不指定替代算法。

后果是部分现行公式、契约与验收尚不能实现这些决定，必须按第 11 节逐项设计与验证。旧公式和失败证据保留可追溯；不能用本 ADR 宣告已完成、删除测试或放宽未被本次决定取代的要求。D05 路径与新规律属于待设计；悬停自动躲开属于待用户决定，两者不混为已有答案。后续卡清单也不授权本 PR 接着改代码。
