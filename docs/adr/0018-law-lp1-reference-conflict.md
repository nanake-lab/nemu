# ADR 0018：LP1 与新近权重参考形式的冲突

- 状态：提议，待用户决定；本 ADR 不批准变更规律或冻结性质。
- 日期：2026-10-22
- 关联：P5-23、PR #49 审查第 2 项、V2-49、v2.0 第 0 节第 4 条、第 5.1–5.4 节、AC2-01。

## 问题与证据

LP1 与 AC2-01 要求支持使 π 增大、反对使 π 减小。参考递推先让旧证据乘 ρ，再加入新组。固定的复杂度基数 c = n₀ + κ 不衰减，因此弱正证据可以降低 π。这是参考形式的反例，不能靠调整 Rust 的计算次序修复。

取无依恋先验的合法倾向，c = 1、h₀ = 0.3、n_h = 10。先记入三组 (W = 3, S = 1)，再记入 (W = 0.01, S = 1)。实际 Rust 结果：π 从 0.87319884726224783 降到 0.84145111039659393。`reports/P5-23/verify_ac2_01.ps1` 执行实际 Rust 递推，并按未放宽的判据输出 `failed`、退出码 1。其内部单元测试通过仅表示这个反例被复现。

在实数算术中，对 S = 1 的新组：

```
A' = ρA + W
B' = c + ρ(B − c) + W
π' − π = [W(B − A) − A c(1 − ρ)] / [B(c + ρ(B − c) + W)]
```

当 A > 0、B > A、c > 0、ρ < 1 时，选取正的 W < A c(1 − ρ)/(B − A) 就得到下降。上述 binary64 实测表明这不是只存在于符号推导中的边界。

## 本次处理

1. 撤回 V2-49 中关于 LP1「验收的读法，不放宽」的判断；原来的相对衰减基线检查仍保留，标明只是参考形式检查，不证明 AC2-01。
2. 保留原反例断言、原 LAW-1 至 LAW-10 的规模与判据；新增独立的 AC2-01 失败结果，报告不再宣布本卡完成。
3. PR 保持草稿、`needs-user`，不合并、不接入正式成长。其余三个实现缺陷继续修复。
4. 不改 v2.0 原文，不改递推公式，不通过丢弃弱证据、调大 W/μ 下限、令 ρ = 1 或放宽断言来消除反例。

## 待决定的方案

### A. 保持 LP1，另行设计并验证参考形式（建议）

冻结的性质优先。新的参考形式必须按完整事件步比较 π_before 与 π_after，同时检验 LP2–LP8、I23、I25、数值故障及实验谱系。它需要新的规律版本，不能沿用当前版本的验证结论。LAW-1 至 LAW-10 的原始对照结果全部保留；如推论受到影响，逐项明确说明并审批，不能悄悄改旧判据。

批准 A 只确定方向，不能声称新形式已经设计完成或验证通过。P5-23 在该工作完成并交叉审查前仍然阻塞。

### B. 保留当前参考形式，明确修订 LP1 / AC2-01

拟议条文为：「在同样的旧证据衰减结果上，支持使 π 增大，反对使 π 减小；包含衰减的整步 π 不保证沿新证据方向变化。」这是对冻结性质和验收判据的实质修改，必须由用户明确批准；批准前不能用 V2-49 代替原文。

## 后果与边界

- 这两种方案都不是本次“修复实现”授权自动批准的架构决定（AGENTS.md 第 7 节）。
- LP7 的推论 4 原文明确写了「不计新近权重」，其无衰减上界检查与本反例分别处理。
- 本 ADR 不涉及 IDL、依赖、存储迁移或用户数据。待用户选择方案后再安排相应实现、实验和独立复审。

## 2026-10-22 用户选择 A（追加）

用户明确选择 A：保留 LP1 和 AC2-01，授权设计、比较、验证新的参考形式，**没有批准任何尚未提出的新公式**。新形式必须同时满足 LP2–LP8、I23、I25，不得以取消旧证据让位、削弱适应变化、丢弃弱证据、抬高权重下限或放宽验收来消除反例。

LP1 的新增审查要求为：无撤回/分摊时比较整步；新证据与回溯分摊同时发生时，比较同样分摊、同样次序而只去掉新证据的反事实；纯回溯分摊时，撤回支持不得使该倾向 π 上升，撤回反对不得使其下降。ADR 0019 以“提议”状态记录研究结果与推论 1–7 的影响。

交付包括至少两个候选、数学条件、原反例、原种子/规模/判据的 LAW-1…10、三条 LP1 随机检查，以及相同序列的稳定/突变/渐变/周期世界对照，全部失败保留。原 `check_law.py` 和 Rust 不改。P5-23 在新版本验证与 Claude 交叉审查完成前保持阻塞，PR 保持 `needs-user`，不合并、不接入正式成长。

本追加只记录方向授权，不把 ADR 0018 或后续候选标为公式已批准。
