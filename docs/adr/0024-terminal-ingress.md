# ADR 0024 — 终端接入契约与入口存储

状态：实施提案，等待用户与独立审查；迁移范围已由用户在 2026-10-27 明确批准。任务 P5-35，基线 main `32a5888`。

## 背景

P5-01/P5-22 定义了业务消息，但没有连接认证、上传与 dispatch 配对。EventEnvelope 的 raw_log_position 和 ingest_time_ns 属于服务端，不能作为终端可提交字段。P5-34 已允许 V3 状态写入，并明确拒写旧 V2 head；物理 SQLite 格式仍是 1。

## 决策

1. 协议版本为 1；新增独立认证请求，包含安装标识、32 字节安装令牌、请求 ID 和支持的版本集合。令牌只用于当前连接的认证，不进入对象存储、D、审计或日志。认证使用安全的本地管道边界；令牌生成、safeStorage 和恒定时间校验由 P5-03 实现，本卡不提供认证服务。认证前的帧长度与解码 Limits 由部署配置提供，必须先限长再解码，不能等待客户端协商预算。错误只返回类型化原因，不回显令牌。
2. 每次连接（含重连）重新认证并由服务端创建 session；session 绑定安装标识、连接、协议版本、能力集合与显式版本化预算。session ID 不是可跨连接使用的 bearer credential。解码成功不等于认证成功，dispatch 验证必须传入服务端已认证上下文。旧连接失效后，未完成上传丢弃；事件重试保持原 stable_source_key、event ID 和内容。
3. TerminalRequest/TerminalResponse 具有 request_id、session_id、协议版本和封闭 kind。响应必须对应原请求 kind 与 ID，业务对象 ID 也必须相同。事件、上传、查询、审批、取消输出、成长控制各有独立类型化载荷；不得夹带旧 Receipt 或私有 JSON。旧 Receipt 保留给既有内部接口与历史解码，新入口只发 ReceiptV2。
4. 上传对象为既有 CanonicalV1 的完整字节，ObjectRef 指明类型标签、资源版本、长度与域分离摘要。服务端在接收首块前预留整对象额度，并保留本连接的 upload_id/ObjectRef 声明；后续分块不得改变声明。分块必须连续、在预算内；最后一块完成长度和完整摘要验证后才可给 complete 回执。只允许已登记、可持久化的业务类型，认证与控制帧不是上传对象。上传完成不等于入 H；未被 D/提交引用的对象可按现有 pins/GC 规则回收。上传服务和断线清理由 P5-03 接续。
5. TerminalEvent 不含接收位置、接收时间、device 或 session。core-store 单写者从完整 D 尾部而非 processed head 分配下一位置，持久化之前取服务端时间；失败不缓存/消耗序号。成功回执必须在 WAL FULL 提交及回执见证之后。重复/冲突仍由既有 Gamma settlement 处理，不改变 stable-key 语义。
6. 拒绝审计是同库独立 append-only 域，只含服务端序号、时间、类型化原因及可选的已识别请求 kind，不保存原帧、token 或任意客户端字符串。显式 records/bytes 预算限制其增长；满、写失败或回执见证失败时，入口不得报告“已审计”或成功接收。它不改变 D、H、x、R、θ、L、Q 或 anchor。
7. 记录/字节背压是类型化失败，不解析错误字符串。容量恢复后用相同 stable_source_key 重试；非法格式、摘要不符、能力不符不可原样重试；认证失败先重新认证。I/O/SQL/见证失败结果未知，应使用原 ID 核对/重试，不能当作已安全拒绝并新建 ID。

## 物理迁移与回退

SQLite format=1→2 只新增入口审计表、不可变约束及格式标识，不重编码既有状态/事件/对象。显式迁移持有同一 writer lock，先以只读连接核验谱系、格式与 V3 可写资格，事务内改变 schema；故障前后只能为完整旧格式或完整新格式。普通 open 不暗中迁移。回退只在审计域为空时允许，原位保留所有既有权威行；已有审计回执时拒绝丢弃该域。旧 V2 head 在任何结构迁移/回退之前仍拒写、原字节只读，不默认填充 q/V。

用户批准将 V2→V3 历史状态转换、G/H 重放及其迁移/回退验收交给 P5-26（ADR 0021 §11），标为“后继未完成”，不作为 P5-35 合并阻塞。本卡仅验证 SYS17 的物理格式子项，不声称完整 SYS17 或真实断电通过。本卡自己的结构迁移、回退、故障测试失败仍阻塞。

## 七条路径

| 路径 | 要求 |
| --- | --- |
| 首次连接 | authenticate → 新 session/预算 → dispatch |
| 重连 | 再认证、新 session；业务 ID 保持 |
| 上传断线 | 未完成对象无 complete 回执；新 session 从 offset=0 重传 |
| 事件重试 | 相同来源键和内容；接收位置由新一次持久化分配 |
| 背压 | 类型化容量原因；恢复后同键重试 |
| 非法请求 | 无业务提交；独立有界拒绝审计 |
| 认证失败 | 无 session/dispatch；审计无原始凭据 |

## 备选方案与后果

拒绝继续让客户端分配 D 位置、把拒绝写入 H、用 reason 字符串控制重试，或借结构迁移转换 V2 状态。新契约保持旧字节与字段编号，新增 p5-34 冻结基线。连接生命周期与实网关验收由 P5-03 完成；本卡的纯验证器与存储接口不构成服务端部署验收。
