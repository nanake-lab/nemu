# ADR 0044：旧事淡化的尺度从她自己的生活里来

## 0. 先说结论

**建议从真实目标更新的间隔里取“中间那个”，未等到下一次的间隔只记“至少这么久”；只有这些资料足以确定这个中间值时，才用它作淡到一半的时间。** 不给出生的她塞一个天数，也不把没等到的长间隔丢掉。每份目标在形成时固定当时能学到的尺度，以后别的经历不追改它；真正更新目标时，整份目标才重新起算、重新取尺度。

推荐配套是：按坐标收集原始评估涉及的间隔，直接学时间，去掉淡化对 λ 的依赖；无法确定正尺度时 r=1。**这是建议，尚未采用。** 代价很实在：数据稀少时可能很久都学不到尺度；早期冻结为未知的旧事，没有真实更新就可能一直不淡。若不能接受这个后果，就必须另选会改动旧事的规则，不能同时承诺严格冻结与所有旧事最终趋零。

还有一个更早的限制：核心现有身份能准确认出“同次接触的后续报告”，却通常不能把“朋友又谈起同一件事”识别为同一个目标更新。前者的间隔可能只是报告节奏。因此推荐仅把可证明的更新间隔当作窄代理量，保留无数据结果；是否值得据此决定感受，仍须用户选和合成反例检验。本文没有声称找到人的情感定律。

## 2. 先比较路线，再推荐

| 路线 | 优点 | 代价与处理 |
| --- | --- | --- |
| 直接复用 λ：明确 α=1 或第一半衰期相等 | 无独立尺度参数，来源已有历史 | 两种等同并不等价；λ 的 τ₀ 先验及限幅仍在，学习的是同号持续而非重现。只留历史对照，不列待选；不同于 §5 从 H 学无量纲倍数 |
| 只取已完成间隔的均值/中位数 | 简单 | 短间隔先完成，删去未完成长间隔会产生选择偏差；排除 |
| **A：删失区间的可识别中位数（推荐）** | 不猜尾部、不假设独立删失；核心只需整数比较，尺度为实际观察时长 | 经常只能得到区间，须允许未知；估计的是已开启间隔队列的经验中位数，不是未经条件证明的总体参数 |

| C：KM 限制均值，截止取已观察最远时长 | 不另设天数截止，可得到面积 | 只估截止以前的面积，尾部未识别；全删失时面积等于观察窗，不是学到的真实均值。对数据随年龄伸长的依赖明显，非首选 |
| D：指数等待模型的总暴露/完成数 | 正确似然可把右删失暴露计入，零完成数明确无有限估计 | 恒定危险率是很强的新增假设；行动改变危险率时失配，不能因只有一个参数就默认采用 |
| E：最长未重现时长或存在年龄 | 无人为天数，出生可保持未知 | 它们不是总体中位数/均值的统计下界；只能作为额外的行为下限假设，见 §6 |
| F：直接拿经验生存曲线当 r | 连尺度映射也省掉 | 把“未来没重现概率”直接当感受比例，另改形状、阶梯与零点；超出当前形状候选，不推荐 |

“中间那个”选择了 1/2 这个分位，双曲选择了 β=1，把间隔中位数等同第一半衰期也选择了映射系数 1。**它们是公开的结构假设，不是从 H 学出的定理，也不是可在线校准的数。** 不开放别的分位、倍率或形状旋钮来修饰结果；用户不接受这些假设就改方案。

备选的数学对象也须明确：B 在各完整时长 t 处取风险数 n_t、完成数 e_t，生存函数 Ŝ(t)=∏(1−e_t/n_t)，中位数为首次 Ŝ≤1/2 的时长，未达到则 Unknown；C 取观察范围 τ=max l_j，计算 ∫₀^τ Ŝ(t)dt，不将尾部补零或把面积称为无限期均值；D 在同质指数等待假设下取 T_mean=(Σl_j)/(Σδ_j)，δ_j 表示已完成，分母零则 Unknown。D 若用中位数连接半衰期，还需乘 ln 2；直接用均值则换了代理量。这些候选没有获准的逐位算术合同，本稿的 §7 只闭合推荐 A 的合同要点。

## 3. 什么算一个间隔

### 3.1 三种身份不能混用

本文的“同一目标”指**同一 F 依据的目标沿革**，不是同一目标版本（更新即换版本）、同一 EV2 组、同一人、同一主题或同一文字。复用 0035 §4.2 的治理角色和 0041 M1 的成员/来源头；来源事件身份、阶段消费键与 F 依据身份各有职责。

候选最小入口只收有外部真实来源、确定性同根关联且获准的更新：同一 contact_id/已记录缺席段的连续真实观察，或已有明确来源关系的真实新增事实更新。**首次新依据可作间隔起点**，下一条合格目标更新结束间隔；把首次建立也算观察起点是本稿明示建议。若严格只收两次“更新”之间的间隔，则首个更新之前无样本，覆盖更少，见 U1。

| 记录 | F 沿原规则 | 尺度数据候选 A 的处理 |
| --- | --- | --- |
| 外部首次建立依据 | 新依据完整作用 | 有合格外源与身份时开观察段；不伪造出生至首次观察的一段 |
| 同根的真实外部后续报告/结束 | 目标更新、整份目标重起 | 结束前一观察段；非终结更新再开一段；明确结束记录不开“等同次接触再结束”的新段 |
| 迟到 A/M 首次补全 | 仍按 0038 更新整份目标 | 同一原始外部发生只算一次；补解释不是又发生，不能结束/重开统计间隔。目标新来源仍取得前缀尺度 |
| 内部念头、回想、反思、措辞/语言变化 | 保留既有角色与感受路径 | 不开段、不结束段、不追加样本；自己引用外部根也不取得外部发生资格 |
| 她触发的程序/工具结果 | 沿既有自致结果角色 | 推荐不入池；真正别人对她的新回应仍是外源，但须另外满足同根更新资格 |
| 重发、重复消费、别名合并、备用目标切换、失效/恢复、解释器维护 | 沿既有治理 | 不是新的重现，不能凭一次治理闭合一个间隔 |
| 相同事件被别人又说了一次 | 0035 通常为新依据 | 不能为了有尺度样本强并成旧目标更新；本路线不捕获这种语义重现 |

**窄入口的根本局限：**一次接触每秒报告和每分钟报告能产生不同间隔，两个接触反而是不同依据。这里只统计“已提交真实更新的间隔”，不能称为“朋友再次出现的周期”。若要跨不同 F 依据统计同一生活主题，须新定义独立的重现关系；不改变 F 同槽身份，不让“相似”自动产生证据。该路线增加理解错误和治理成本，本轮保留备选，未预造新模型或相似度阈值。

### 3.2 时间与观察充分性

在固定 H 前缀 p 下，以 E_p(a,b) 表示按 0038 §3.2 在两个真实作用提交锚点间截取的有效运行区间并集长度。段从合格外部记录**首次形成目标的提交**开始，下一个不同合格外部发生被理解并真实更新时结束；不是发生墙钟之差，也不是队列到达之差。排队仍可改变这个代理量，因此不同调度轨迹不保证同尺度，不用改变 D11 资格掩盖此代价。

对已经结束的统计段 j，若时钟与观察链足以证明该段，D_j=E_p(a_j,b_j)，给出 [D_j,D_j]。未结束而持续可观察的段给出 [E_p(a_j,p),+∞]。这里 +∞ 是“不知道上界”的数学标记，绝不写成权威 f64 Infinity。

运行过不等于能证明“没再发生”。来源流丢失、覆盖未知或时钟缺口时，只用**从起点到首次观察缺口之前**可证明的未重现下界；后面即使收到报告，也不能把跨缺口间隔标成精确的下一次间隔。缺口后合格更新可作新起点，旧段保留右删失；若连起点身份都不确定，标为不可用并保留原因。仅日历映射不补运行证据；已确认停机不计存在时长。

与 0038 年龄区分：年龄可以使用当前证明的运行并集；统计的精确间隔还要证明没有漏掉中间合格更新。未知运行部分不能被静默删去后把较短下界标成完整样本。同前缀重建两个端点；起点前补证不延长间隔，重叠只计一次。负定旧时间证明走既定故障/纠错，不把矛盾当新生活样本。

一次明确结束是前段的真实终点，不是可随意忽略的删失；根失效/撤权而中断观察可保留已有下界，但不可把这类有信息中断当 KM 的独立删失。恢复观察不自动拼接缺失段。

### 3.3 错误、别名与来源更正

- 错拆同根：短的完整段被拆成多个未完段，通常使尺度未知或偏大；也可能改变排序方向，不能承诺只单向偏差。
- 错并不同根：造出不存在的短间隔，可能使尺度偏小、淡得更快；跨长间隔错并也可能变慢。
- 把回想/补解释误标真实更新：内部活动可改变间隔统计并刷新目标，直接破坏防自证边界；必须用来源、记录阶段和治理质量分别检验。
- 确定性 ID 只保证同一字节、同一关系会被同样处理，不保证关系真实。没有可信同一身份就不配对；不拿最终 alias 代表 ID 串联所有成员历史。
- 合并时仍用 0041 的实际授权成员沿革。重复的同一外部发生去重；没有既存关系证明的跨成员相邻记录不造段。选出的组目标继承其原尺度引用，不取组均值。来源失效使未来统计按治理去除不真实发生并重建关系，不能跨不明空档补造“下一次”。
- 所有修订只从其生效前缀改变后续统计；普通反思不改本统计的冻结原始评估。技术纠错改变过去数据有效性时，需显式重算/迁移记录，见 §7.3；不能用“来源冻结”继续无声采用已证伪的值。

## 4. 推荐 A 的数学定义

### 4.1 先确定统计对象，而非事后挑样本

为避免每个短命 contact 都永远没有足够样本，推荐在她自己的 H 内**按坐标汇集**所有合格间隔；不按人物、正负、强弱分池，不借用别人的人生或排练数据。

间隔是否进入坐标 i 的池，在起点的原始有效 m=0 评估上确定：四个乎用 a_i≠0；学得概念 k 用已存在且记录的 μ_k>0（按稳定概念身份，不按当前 R⁺ 强度）。不读 v、g、b、λ、x、h、m 来决定成员和权重；缺失评估不猜 0，不在以后反思时补成自己的证据。新概念若没有当时已记录的 μ，则早期段不入该概念池；不为本统计重新调用模型。

每段在一个池中权重为 1、身份唯一；可同时进入多个坐标池，但池不是 G 的分摊或新增独立证据，不能相加后再作为“证据总量”。a_i=0 的排除是定义相关坐标的结构选择，不是证明那些经历不重要；若事件只有相对基线作用而原 a_i=0，该池会漏掉它。全部池、只按根分池、全局共同池的比较见 §5。推荐中全史等权，不加遗忘窗；故生活改变后的适应可能很慢，也不是自动估计“当下环境”。

### 4.2 删失的集合识别，而非填补

固定前缀 p、坐标 i，有 n 个已开启且合格的段，真实完成时长未知数 D_j 满足区间 I_j=[l_j,u_j]；完整段 l_j=u_j，右删失 u_j=+∞。允许未来永不重现的 D_j=+∞，不假定所有段最终完成。所有下界精确且非负，右删失边界使用闭区间外包；整数时钟的严格大于可给出更紧界，本稿不靠加 1 ns 推断未被证明的事件次序。

若 n=0，结果 Unknown。否则令 k=ceil(n/2)，定义

$$
L_{p,i}=\operatorname{ord}_k(l_1,\ldots,l_n),\qquad
U_{p,i}=\operatorname{ord}_k(u_1,\ldots,u_n).
$$

ord_k 是升序第 k 项；偶数 n 取较小的中间项，不取两项均值。这一约定保证尺度是已观察时长，不用插值。对于任何与全部记录相容的完成时长向量，经验下中位数必在 [L,U]：逐项 l≤D≤u，排序统计量单调。**仅当 L=U 且该值严格正，输出 Known(T=L)；否则输出 Unknown，保留 [L,U] 和原因。** L=U=0 表示可识别但退化，不偷偷改成最小正数或把零时长删掉。右删失很多也可能识别中位数：这不需要猜尾部多长。

这是一条集合识别规则，不是 KM、不含独立删失假设，不输出伪造置信区间。它保证的是“已开启这批间隔的中间值不会被未知尾部改变”，**不保证总体中位数、下一次间隔或当下环境已被准确估计**。重复根、报告频率和按当前年龄截取的队列都有选择效应；能否推及重现过程，按 §9 的已知真值世界分别验证。

**手算见证（单位任取同一存在时间单位，均非运行参数）：**

| 数据 | k、[L,U] | 推荐输出 | 若错误丢弃删失 |
| --- | --- | --- | --- |
| 完整 2、6、9；未完 ≥10 | 2，[6,6] | T=6 | 虽此例碰巧相同，不能据此一律丢弃 |
| 完整 2；未完 ≥3、≥4、≥5 | 2，[3,+∞] | Unknown | 会把 2 当尺度，实际该队列中位数至少 3 |
| 全部未完 ≥3、≥5 | 1，[3,+∞] | Unknown | 没有可用完成数 |
| 完整 0、0、8 | 2，[0,0] | Unknown（零尺度） | 删除零会错误地得到 8 |

### 4.3 以双曲候选连接 B

在目标来源提交 c 的**前态前缀 c⁻**求上述统计并冻结 σ_c,i；不先把本事务结束的间隔加入再给本目标用。当前真实外部更新提交后可成为以后目标的资料；这与 0038 不另读同事务 C 后态的选择一致，会有一次更新的学习滞后。冻结的是前缀/规则及可核验结果，不能只保存一个无出处数字。

候选 β=1 时，对合法纯重访：

$$
r_{c,i}(p)=
\begin{cases}
T_{c,i}/(T_{c,i}+d_c(p)),&\sigma_{c,i}=\mathrm{Known}(T_{c,i}>0),\\
1,&\sigma_{c,i}=\mathrm{Unknown}.
\end{cases}
$$

d_c(p) 仍按 0038 的当前证明前缀计算，与尺度冻结前缀不同。新依据/真实更新当次 r=1，再走原 B→A1。反思只依法改 v，不换 σ 或 c。r(T)=1/2 是把“典型间隔”当“补回减半时间”的假设；既未预设比 λ 的平复更慢，也未预设更快。换曲线须用户另定且另闭合数值合同。

## 5. 逐坐标和 λ：三条完整取舍

| 连接 | 数学与后果 | 本稿建议 |
| --- | --- | --- |
| 保留原 λ 连接、从 H 学无量纲倍数 | 对每段用起点原 λ_j,i 将时长变成 λ_j,i·D_j，按同一删失规则取 K_i；目标用 T_c,i=K_i/λ_c,i | 保留来源 λ 差异，无独立 α；却继承 λ 的出生先验/限幅、引入变换舍入，且假设“以恢复速度量过的更新间隔”可交换。新统计不送 G/C，但尺度会受 λ 影响，须明示；可选，非推荐 |
| **取代 λ，直接学各坐标 T_i** | 用 §4 各池的真实存在时长，分别求 r_i；当前 Φ 继续使用原 λ | **推荐**；保留逐坐标/N0，去掉两个不同时钟尺度的强绑定。新池及其 a/μ 相关性判断要用户批准；目标方向可随不同 r_i 改变，稀疏坐标可能一直未知 |
| 共同 T 或每根 T_c，所有坐标用同一 r | 全局池最简单；每根池最少混入无关经历 | 共同 r 保持目标方向，但明确取代逐坐标快慢；全局报告密集类主导所有旧事，每根又极稀疏。是候选，不把标量逐坐标相乘冒称保留原逐坐标决定 |

不建议把原 P(αλd) 再乘学得的 P(d/T)：那是双重淡化；不建议用 max(T,1/λ) 作隐含下限：它规定淡化不得快于恢复尺度。两者都新增行为假设而非必要数值结构。本稿不改变 λ、τ₀ 或 C 本身，也不把它们的已知先验欠账宣称一并解决。

## 6. 出生无数据：不能既不猜，又保证立即开始淡

| 做法 | 定义与依据 | 对冻结旧事的后果 |
| --- | --- | --- |
| **N：无可识别正尺度 r=1（推荐）** | Unknown 是缺知识，不是 T=∞ 的测量结果；不设出生伪样本 | 旧目标若冻结 Unknown，后来别的目标学到尺度也不追改；该目标可能永久不淡。原 Φ 仍平复，回想仍可补回 |
| B：最长未重现时长作下限 | B_p=max_j l_j（无段则 0）；可提出 T=max(T_est,B_p)，无估计时 T=B_p>0 | B_p 仅是最长某一段的下界，不是中位数/均值下界。例完整 1、1、1 加未完 ≥100，中位数仍 1；强取 100 就是选“最罕见决定尺度”。冻结时可有限，最初 B=0 仍须 Unknown |
| A：存在年龄作下限 | A_p=E_p(birth,p)；提出 T=max(T_est,A_p)，无估计时 T=A_p>0 | 存在年龄是所有已观察间隔的观察范围，不是典型重现间隔的统计下界；给晚年新事更慢的尺度是新增年龄偏置，稠密短周期生活也不能改掉这条下限 |

若 B/A 是“至少”的陈述而不选具体 T，则只得到尺度集合，不能算唯一 r；取下界、上界或 r=1 本身仍需决定。取 T=B/A 是额外的乐观尾部/年龄政策，不因没有新数字就变成已学得事实。用限制均值则必须承认估的是截断量，不能替这一问题改名。

**与 S1/S2 的冲突不能隐藏。** 若每次重访重算 T_now 并套整段年龄，同一 d 下 T 从 6 变 12 会使 r 在 d=6 时从 1/2 升为 2/3；后来生活把旧事重新变浓。若实时 T=A_now，则对固定来源年龄 a，d=A_now−a，r=A_now/(2A_now−a)→1/2，造成隐含永久底值。冻结 T=A_c 可避免这个底值，但保留出生为零和晚年更慢的偏置。

可替代的“不追改过去、只改今后速度”是 0038 的 S3 类：Z=∫dt/T(t)，Unknown 段积累零，r=1/(1+Z)。也可在首次得到有限尺度时另设淡化起点。二者都改变 S1，前者新增分段累计，后者新增第二起点并使普通新经历能改变旧事；不能悄悄作为冷启动实现。保留为 U4 备选，本轮不预留状态。

不同时要求这三项：零数据不猜有限尺度、严格冻结来源取值、每件旧事都随存在时间趋零。推荐优先前两项，并将第三项的例外明写；用户若保留第三项，须重选冷启动/更新政策。

## 7. H 重算、数值合同与纠错

### 7.1 最少记录和访问边界

复用 H 的原记录、原评估、治理/有效性、作用来源和提交锚点、运行/观察证明、规律/numerics_id。新增语义只有：获准的统计规则标识、目标尺度绑定的前态前缀与可验证结果/原因。段表、排序索引、池与 [L,U] 都可从该前缀重建，缓存删除不改她；不新增独立心理数据库、不让终端存尺度，不增 θ 字段。

F 内核不获得自由查询全部 H 的权限。可信编排按被冻结的投影合同提供尺度来源视图；算子只读该 DTO，仍是纯函数；哪些现有引用足够、哪些需要后继字段，由契约卡闭合。当前 H 不足以证明观察完整性时，不能声称已经可运行地学出尺度。

### 7.2 候选规范算术要点

1. 先在时钟合同的精确整数域截取、去重、求长度；排序、相等、k、成员数与 Unknown 标记都不经 f64。域/字节上限由时钟及契约承接，不用饱和截断、wrap 或 ε；计数/时间域耗尽显式故障。排序同值按来源提交、阶段、规范身份破同分，不影响 ord 的数值。
2. A 的规范定义是**每个前缀重新构造同一段集并取相同排序统计量**。增量索引必须逐项等价，不能另用在线均值近似；不因回想多而多追加一个右删失样本。同一开启段永远一行，其下界在投影时计算。
3. 有限支路 T 和 d 同用整数时间单位。建议比例一次正确舍入 `RN_even(T/(T+d))`，分母在受检的加宽整数临时域中精确形成，输出有限 binary64；不先把两个巨大时间转浮点，也不把 `RN(1/(1+RN(d/T)))` 当同一算法。未知支路直接 +1；d=0 直接 +1。精确整数临时运算不构成另一套浮点权威状态；其位宽、编码与跨平台黄金值须后继冻结。
4. 允许比例/乘 v 的渐进下溢，零规范为 +0，不用 FTZ、FMA 或 fast-math。即使极小参考舍零，仍执行 B/A1 的既定分支和消费；r=0、w=0、h=0 各不相同。异常非有限输入不夹成成功结果。
5. 对同一 T,d，正确舍入的比例误差 ≤u·r+2^-1075（数学界；u=2^-53），不把 2^-1075 在机器里舍零后漏算。w 的误差按 |v|ε_r+舍入界传播，clamp 不放大该差，原 A1 分支包络沿 MATH-U2U3-01。这个界不包括身份、时钟证据或统计模型错误，不能给这些错误塞一个数值容差。
6. Known 正 T 固定时，整数 d 非减使实数及正确舍入 r 非增；无 min(上次r,本次r) 状态。不能据此声称 x/h 非增、严格浮点非扩张或有限时间清零。长期浮点邻域仍须实际调度/槽幅度/Φ 误差预算，本文不填阈值。

### 7.3 来源冻结与正确性修复分开

普通新生活改变当前池，不改变已有目标的尺度绑定；当前年龄按新证明推进，不把最终统计倒灌进旧重访。迟到的运行补证可按 0038 改当前 d，不能顺带用更晚证据重估冻结 T。它对以后新目标的统计可生效。

若已冻结 T 的某个依据后来被证伪，**按原 H 前缀重放的旧结果仍保留**，但不能无声把它当当前可信输入继续用。推荐作为显式纠错迁移：当前 h/x 不回写；按纠错后的事实视图、仍限定原冻结前缀的成员范围重建 T，记录旧/新绑定及生效点，后续重访才用修复值；若无法重建，显式 Unknown/r=1。可能令未来参考升高或降低，属于纠正错误的例外，不是 S2 的一般成长追改；U5 须批准此政策。反思不是技术错误证明，不能走此入口。

旧版本、旧前缀使用当时输入、解释与数值版本；治理错误的修复不能补造没发生的感受或行动。已有谱系切换须新规律与 SYS17；缺原观察链时不猜旧样本。暂停成长原本只冻结 G/C，不自动决定这份 F 派生统计也停；推荐仍随真实 H 构造，但已绑定目标不变，须在后继暂停/恢复用例中明示，不将其冒称 θ 成长。

## 9. 行动反馈、验证与已有工程的关系

### 9.1 间接循环仍可能发生

典型路径：旧感受→回避→真实同根更新更少→未完段变长/有限尺度更迟可得→后来的目标取更长尺度或 Unknown→回想补回更多→继续回避。禁止把念头直接入池挡不住真实行动改变生活。

对**已固定有限 T、来源不再更新**的单件旧事，回避不能把它的 T 拉长；d 持续增长时 r→0，所以这个局部尺度回路被切断。它不证明整个人不锁定：Unknown 来源可永久 r=1；新目标不断取新尺度；回避可关闭观察；别人回应又影响 G/C；0041 已保留未淡化内部支路。这些都在 MATH-U2U3-01 的有限旧事定理之外。

具体反例候选：出生旧负目标冻结 Unknown，合法纯重访周期补回；回避使它再无真实更新，于是永远没有重取尺度的机会。0035 的同槽替换阻止无限叠加，却允许周期维持。即使以后无关池有有限 T，该旧目标也不受影响。另一方向是主动索取真实报告使间隔变短，影响未来目标淡化；不能把所有主动回应都当伪证排掉。报告节奏、理解延迟、观察中断的控制权也可能形成工程回路。

完整[验证设计](../../reports/DESIGN-FADE-SCALE-01/VALIDATION.md)将外生重现真值、观察/删失机制与行动策略分开，包含固定节奏、混合长短间隔、不可识别尾部、错并/错拆、报告频率变化、回避/寻求反馈、撤去反馈后的恢复及永久 Unknown 最小见证。全部 not_run；不加探索率、最低交往次数或强制快乐机制补救。

### 9.2 与 0041、0042、P5-30

- **0041 L1/M1：**尺度缓存也可逐出，但原 h 仍按完整历史精确恢复；小 r、Known/Unknown 均不是删槽条件。合并继承有效目标的原尺度，不平均、不重起；失效根不得复活。较弱 U4 保留的内部支路不被本设计抹去，不用本尺度压制全部念头。
- **0042：**仍按当前实际 h 选来由，不再乘 r；r 只在合法重访时影响补回。读取/发送旧原文不成为重现样本；生成文本、反思与 API 缓存不改变尺度。U3 接受文字不能传达淡化强弱、U4 接受覆盖缺口，均不重开。
- **P5-30：**验证“从规定的数据估出了什么”与“这个代理量是否值得用于感受”分开。运行速度不能改存在时间；世界真值是验证输入，不写成她出生的 T。现有 L0 首版不因此等待本草案；#195 已有输入偏差与冻结结果不改写、不借本卡重跑。采用后在新版本/预注册中加入本验证，不向现有运行追加样本或回调常数。

| U5 修错 | **证实尺度用错了事实时，是否明确记下修复、只改变以后回想，不改过去的感受？** | 推荐 §7.3 纠错重绑定；无法修复用 Unknown，可能使以后补回更强；这是纠错例外而非普通成长追改 |

## 11. 限制与参考

没有新测量、模型调用、产品代码或运行参数；文档设计完成不等于统计假设、数值合同、接线或体验通过。所有合成/真实时间验证 not_run。观察完整性当前未被证明可由所有 H 记录提供；若缺失，按 Unknown 或不可用报告，不把不可用数据包装成没有重现。推荐 A 能诚实保留删失，不会神奇恢复未活过的长间隔。

重现时间与触动强弱只是类比：它给了一个来自生活的时间单位，不能决定创伤、珍贵、关系意义或“该释怀多少”；相同重现统计可对应不同感受，罕见不必更重要，频繁也可能强化而非淡化。合成统计吻合只验证定义与估计，不能验证这种价值连接。用户不接受代理量时，应保留设计未定，不偷偷补默认天数。

方法背景仅用于备选 B/C：未修正 Kaplan–Meier 在真实终点处按风险集乘生存比例，删失不当终点；本文 A 是自行定义并以上下界单调性证明的集合规则，不借 KM 的统计性质为它背书。[NIST Kaplan–Meier](https://itl.nist.gov/div898/software/dataplot/refman1/auxillar/kaplan.htm)。同刻终点/删失、风险集和近似相等的时间会影响 KM 实现；因此比较时固定事件先于同刻删失、整数时长相等，不照搬容差。[Therneau 方法说明 §2](https://therneau.r-universe.dev/survival/doc/methods.pdf)。终结事件不能随意当独立删失，见原作者关于竞争终点的说明。[survival vignette](https://therneau.r-universe.dev/survival/doc/survival.pdf)。本稿不引入这些软件依赖。
