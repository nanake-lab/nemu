# ADR 0041：F 依据槽的生命周期与失效合并

## 0. 白话总览

槽不是一段记忆，而是“这件事现在已经占了多少感受”的账。记忆留在 H；如果把还没平复的账直接丢掉，下次想起时可能再加一次。建议先让槽能从常驻快照退出、需要时从已有历史精确恢复，把工程容量和“旧事还能否触动她”分开。若必须让旧事的作用在有限时间内真正终止，就要另选一条会改变她行为的规律，不能借精度或内存上限暗中决定。

失效合并另有明确缺口：建议保留已经发生的全部残量，但只允许仍有效的来源提供今后的目标。这样不会复活假消息的目标；代价是混合组下次重访时，仍可能收回旧失效残量，这与“失效残量永远只自然衰减”的强读法不同，须由用户选择。

## 1. 背景与容量结论

[增长估算](../../reports/DESIGN-SLOT-LIFE-01/GROWTH.md) 给出计数模型、CanonicalV1 字节推导、生成速率与半衰期敏感性。若每日留下 100 个不同非零槽、持续累积且 ID 各为 36 字节，8 个学得坐标约 5.86 日即到 1 MiB 的宽松界，32 个坐标约 1.70 日；真正固定开销使它更早。4096 项并非总是先触及的界。

G01 表明有限寿命不能由“向零收缩”推出。1074 个半衰期是理想指数尾的尺度，不是规范递推期限：频繁小步可永久停滞；足够长的单次间隔若 pull=1，又能提前清零。不能选择性只报长停机下的有利结果。

三个不同目标须先分清：

1. **退出热工作集/单个快照对象**：以后可精确恢复 h；不删除因果作用。
2. **删除残量数值且仍可重访**：必须能证明恢复同一 h，或接受行为变化。
3. **永久取消该目标的未来 F 作用**：可不再保留计算残量，但这是新的行为取舍。H、G/C 证据和消费身份仍在。

无限真实新依据、固定总资源、精确保留每个依据任意未来作用，这三项不能靠垃圾回收同时保证。有限 binary64 也不是许可证：状态位数有限不表示任意来源身份与未来治理信息能装进固定几个槽。分块解决消息边界，不能把无界总量说成有界。

## 2. 先发散，再收敛

本表只比较路线，不把互斥路线叠成默认配置。符号/人物/心情不参与淘汰优先级。

| 路线 | 有限时间能移除什么 | A1、重访与合并的影响 | 取舍 |
| --- | --- | --- | --- |
| L0 原精确零规则，扩大单消息上限 | 仅实际到零的槽，无一般期限 | 原样 | 只延迟耗尽；不推荐作为生命周期答案 |
| **L1 精确重建，把槽作为可逐出物化结果** | 每次提交后可逐出不在当前计算中的物理槽；逻辑 h 仍可还原 | 恢复后用原 h、原目标与规范次序；合并也先恢复各组残量 | **优先建议**；不增加心理参数，代价是查询/重放工作和新表示完整性合同；不承诺固定总资源 |
| L2 证明未来永不再读的槽删除 | 在有效性被永久封闭、无未来更新/恢复/合并读取的提交删除 | 不影响以后可观察输出；只在严格前提内 | 条件优化，不是所有槽的寿命规则；暂时失效不够 |
| L3 小残量直接丢弃，允许重入 | 在首次满足阈值的提交移除；频繁更新未必到阈值 | A1 再从零开始，会重复计入遗留残量；合并丢失部分和 | 仅作为明示有损候选；任意 epsilon 无依据，排除默认采用 |
| L4 固定期限或容量次序退役，关闭未来旧目标 | 到期提交或预算逐出时终止该目标代；不等浮点到零 | 不再纯重访旧目标；若同根真实更新从零开始，会再计旧残量，需接受或恢复原 h | 能真正给过去设有限作用期，但改变生活；不推荐未经用户选择采用 |
| L5 改槽 Φ，使尾部有限步归零 | 在足够恢复进度且无更新时移槽 | x 的 Φ 可不动，h 的新算术会改变以后 A1；不再逐位兼容原规律 | 包括截断次正规、向零舍入、有限支撑尾；不是编译优化。不能保证在持续更新下有限寿命 |
| L6 与 0038 联合的总误差预算移除 | 可证明未来作用误差受预算约束时移除；可能永不满足 | 近似 h 或取消重访，须分别记误差；有效新解释/合并会使局部界失效 | 研究候选；先有数值合同与整体误差界，不凭 r 很小宣布无损 |
| L7 不同依据合成总槽/摘要、丢来源身份 | 总槽数可小 | 单独重访无法知道应减哪份 h；饱和与舍入非结合 | 排除精确方案；只把总和改名 y 不能恢复来源分摊 |
| L8 限制外部新依据、降采样、把同 EV2 组都当同槽 | 可压低输入速率 | 改变真实刺激资格/份额；EV2 不是 F 身份 | 超出工程回收，违背已定角色；排除 |

永久无作用目标、无损压缩、分页可辅助 L1/L2；更高精度或直接闭式投影会改变规范轨迹且仍不保有界历史，不能冒充原 I16。随机淘汰与 LRU 都使资源/回想节奏影响她，且没有比明示 FIFO 更少的行为代价，不另加随机资源或“重要性”评分。保留 H，故以上没有“删除经历”的选项。

## 3. 三问与原则挂靠

下表覆盖拟议新增的机制；L0、L7、L8 等被排除路线不是新增提议。数学上的可能性不等于建议采用。

| 提议 | 能不能不加？ | 一个人会怎样？ | 加了以后什么改不掉？ |
| --- | --- | --- | --- |
| L1 物化逐出/重建 | 可以保留原单对象但会触界；先减掉“所有槽常驻同一消息”的要求，无需加心理期限 | 不必一直在脑中逐项算账；她能准确保存历史，不强迫模拟遗忘 | 表示可版本化迁回；延迟导致已经错过的交互无法事后补成原人生，必须测恢复时间 |
| L2 永不读取的死槽 | 可一直存，但没有用途；先要求封闭证据，不添失效时钟 | 已证伪的事不再当真，感受未必立刻消失 | 若以后纠错恢复资格，裸删残量便无法保持原轨迹；封闭不稳就只能 L1 |
| L3/L6 近似或误差预算 | 可选 L1；没有精确方案的性能证据前没必要加 | 人对极微小差异不必敏感，但不能据此推出模型不敏感 | 小差异也可能改变行动与后来经历；保留 H 可重放，不能撤销已经发生的行为；误差参数不是用户调心情旋钮 |
| L4 有限目标代/退役资格 | 可选 L1；若坚持逻辑有限寿命才需选择 | 人会逐渐不被旧事触动，也可能再次深受影响，没有天然统一截止日 | 退役期间没产生的反应与后续经历补不回来；之后改规律只能改变未来规则，不能补造过去 |
| L5 有限尾槽 Φ | 原 Φ 有停滞，但可用 L1 避免靠改数学省空间 | 平复没有一个人人相同的精确零时刻 | 数值路径一改，未来重访可能不同；旧版本必须保留，无法把过去 x 静默改写 |
| M1 有效来源选目标，全部残量保留 | G02 不能靠默认取最早项解决；只补资格组合，不加阈值或新的真假模型 | 知道最早消息是假的后，不应因为后来的真消息而重新相信它；当初的感受仍真实发生 | 下一次重访如何收回混合残量影响她，后续经历不可撤回；具体取舍交 U3 |

与 [ADR 0039](0039-echo-core-principles.md) 的关系：P1/P9 要求 H 不改、核心唯一权威、缓存不是另一个她；P2/P4 要求同史同规律同结果、不按符号或人物选槽；P3 要求 F 生命周期不成为 G/C 时间遗忘；P5 禁止新增不可改变的“负面更快”等偏置；P6 支持准确保留记忆而不伪造人类遗忘；P7 的机器预算不自动授权改变她是谁；P8 不以长期难过为回收触发；P10 只约束未决证据资格，不授权删除微小感受。L3–L6 都含原则不能唯一推出的行为选择，作为**显式例外/建模选择待用户决定**，不能宣称由原则强制得出。

## 4. L1：建议的最小生命周期

### 4.1 只有存放方式改变

“常驻”“已逐出”“精确零”“失效”是本设计的描述，不预留四个新枚举或一套并行权威。有效性、目标与身份仍从 H 的治理/作用记录取；物化位置由工程表示管理。

| 发生什么 | 生命周期与下一次作用 |
| --- | --- |
| 首次新依据 | 原 A1 从 +0 建槽；当次实际 h 全零可沿 B7 省略 |
| Φ / 已有依据更新 / 重访 | 恢复所需前态，严格按原次序计算；保留身份、来源与消费语义 |
| 提交完成，热预算要逐出 | 当前 x 不变；仅在重建来源已完整提交且可用时逐出物化 h；没有新的 F 作用 |
| 以后合法重访/目标更新/合并 | 从同一历史前缀恢复该槽实际 h，再作原运算；缺物化项不表示 +0 |
| 各坐标确切 +0 | 可标为数值缺省 +0，但依据目标、原前态、消费记录仍可检索；可重入 |
| 失效 | 不主动改 x/h，停用目标资格；可物化逐出，残量仍可精确恢复供治理使用 |

**精确恢复要求：**从保存的同版本状态与提交锚点，重演每个已提交的 Φ 间隔、原速度、A1、解释生效、维数对齐和合并步骤。不能把 N 次短间隔改为一个长间隔；不能只用旧 v 推算 h；饱和时实际份额需要当时 x，故保守恢复可以重放完整相关状态前缀，而非假设每槽总能 O(1) 求出。H 中若缺这些输入，不能称可重建；保留原槽/检查点，标为迁移前置。

这一方案改的是“可物化表示”，不是把非零槽从 V3 的 slots 里直接删掉：现行 V3 把缺项解释为 +0，**不能原地复用该含义**。后继须有新表示版本，以同一提交的完整可恢复状态引用绑定分块检查点/历史前缀；每块满足消息界，根引用也不能再塞无界成员列表。具体编码由后继契约卡定，不在本 ADR 预造字段。

在一个提交有可处理的有限输入、恢复可完成的条件下，每个槽完成使用后就能退出热工作集；一个涉及大量依据的事务可按规范顺序分块读取，不能改成按块大小截断语义输入。热集/单对象受字节与条数工程预算控制，不按 h 正负、大小、对象身份或回想次数决定作用资格。缓存命中与未命中必须同结果。

代价：逻辑槽和 H 总量不受此方案约束，最坏恢复可能线性扫历史；需要完整引用、原子发布、崩溃恢复与适当检查点。不能以“可重放”宣称用户等待时间合格。工程预算耗尽/输入缺失按原故障或未完成边界报告，不能静默从零重建、丢新事件或削弱正常生活。

### 4.2 L2 的充分条件与不能使用的捷径

全坐标 +0 是现行充分条件。对非零槽，只有**所有合法未来路径都不再读它**才允许永久删除计算分量：不重访、不目标更新、不用它做合并扣账、不恢复资格；x 的独立 Φ、其他槽、G/C、J 都不读它，原 H/消费身份仍保留。于是从删除时起可见输出相同，这是条件论证，不是 current active=false 的同义词。

现行规则没有普遍“永久不可恢复”的封闭证书。权限撤回可能恢复，失效可能被后续合法治理纠正；别名会读残量。因此不新增一个“永久失效”标志来硬凑删除条件，默认按 L1 保留恢复能力。若选 §6 的 M2 隔离残量政策，亦不能自动把未证明封闭的残量删掉。

## 5. 真正有限寿命与近似：可选，但须承认代价

### 5.1 L3 / L5：删 h、仍允许回来

例：x=1/4、h=1/4、v=1/2，未饱和。保留槽重访得到 x=1/2；删 h 而不改 x，下次从零得到 x=3/4。把门槛缩小只缩小这一次差额，不消除重复逐出/重建的累计影响。修改 Φ 为“足够小就 +0”、次正规 flush-to-zero 或改用乘法衰减，同样是新数值规律；仅截断次正规不能解决进入次正规以前已经撞容量的问题。

固定阈值 ε 的剩余时间只能在无更新、速率有下界等条件下由实数式 `ln(|h₀|/ε)/λ_min` 估算。ε 取大决定更早重复计入，取小未必及时回收；binary64 停滞还需要规范边界。ε 不从机器最小数或“看不出来”自动取得正当性。

### 5.2 L4：明确退役目标代

一个完整的有损候选是：使用目标来源后的可信存在年龄，在已批准有限期限到达后的第一个提交，将这一目标代退役；或按已批准容量规则、原首次作用次序在提交中逐出。保留 H 和已消费键，x 不变，纯旧目标重访不再发行作用，反思不重开此目标代，别名不把它包装成新代。不得把“退休根没有可用目标”自动降到内部支路再发一次 D；真正无外部根的内部支路仍沿原规则。

必须另选真实目标更新的含义：**L4a** 恢复旧 h 后按原 A1（保留新刺激体验，但仅物理删除，逻辑 h 未终结）；**L4b** 新目标代从零开始、旧残量不再参与合并/扣账（有损，可能重复计入）；**L4c** 连同根合法更新也拒绝（使持续接触结束/迟到首次补解释失格，与原 D11/角色合同冲突，不推荐）。不能同时声称永久删 h、允许任意原更新、又严格不重复。

期限不从“最后回想”重置；否则反刍可保活。沿 0038 的真实目标更新可以换来源/起点，但这意味着不断更新的依据永不必退役；若要求每个身份无条件有限寿命，就要接受 L4b/c 等更强改变。期限只在提交生效，不增加后台 F timer，不改 x 的 Φ，也不保证总心情按期回落。到达突发仍可能在期限以前溢出，容量强退另有行为代价；本稿不定期限、FIFO 配额或阈值。

### 5.3 ADR 0038 不提供一般的无损回收条件

其唯一入口是 `w=fl(r·v)`，`q=clamp(w,[min(h,v),max(h,v)])`，再对 q 作原 A1。

- `r→0` 不代表 h→精确零；慢尾在实数下无限期非零，S1 的 α/曲线/数值合同尚未完成。不能把当前 Φ 的半衰期当成旧事淡化半衰期。
- 即使 r=0，固定同号 0≤h≤v 时 q=h，原调用恒等，却没有把 h 清零。若直接删 h，下一次在 r>0 的新解释/真实更新/别名路径又可能不同。
- 反号/历史合并时甚至 r=0 也不意味着当前重访无作用：x=0、h=−1/2、v=1/2，w=q=0，原 A1 得 x=1/2；删 h 后得到 x=0。三个数都是精确 binary64 的设计见证，无需实验才能看出两式不同。
- 一次 `q=h`、一次 x 的加法舍入没变，或当前 `v=0`，都不是所有未来输入的不可区分证明；合法解释修订与治理可能改变目标/残量关系。

可用的无损条件仍是 B7 的精确零，或 L2 的所有未来路径不读。0038 可以使**受约束未来重访的误差界变小**，但不能独立保证 finite-time GC。

### 5.4 L6：先有误差合同，才谈近似无损

仅在固定输入/身份/目标来源路径下讨论：删除集合 D 但保持 x，初始扩展状态误差为 `E₀=max_i Σ_{c∈D}|h_ci|`。原实数 A1 的 d◇ 非扩张使其不增长，无输入段收缩；新增删除必须累计其当时误差，不能每个槽都拿一份完整 ε。binary64 必须再加逐操作外向舍入包络，ADR 0035 U2 未证明严格非扩张；0038 的 h 依赖 q 也必须重新验证，不能直接借旧结论。

若取消未来重访而非仅近似 h，还须计入每次被省略的作用，并给出整个未来序列的可求上界。r 的无穷小极限、单次 w 很小都不足以给任意多依据/任意次数保证。若存在合法目标更新、反号修订、合并等不能纳入界的输入，要先恢复准确 h；不能等错误行动发生后再补回。

因此一个可评审的近似版本至少先定：保证哪种输出、哪个时间域/输入域、总误差如何累计与收缩、超界前如何回到精确计算、符号对称性、可重放的决定及数值资源。若 J 是固定线性注入，x 界可推到系数误差；仍不能推出生成文本、离散行动或完整闭环等价，阈值附近任意小差异都可能改变之后的生活。

本卡不填一个任意误差数。**由用户选择是否接受这类差异，再经版本化数值定义与合成验证决定预算**；它不是可以在配置中按喜欢的心情调节的量。保证无法在移除前成立时，不移除或走 L1，不偷偷增加预算。

## 6. G02：有效性、别名与目标来源

### 6.1 三个选择

| 候选 | 残量怎么处理 | 今后目标 | 她的行为与成本 |
| --- | --- | --- | --- |
| **M1 全部残量保留，目标只由有效来源给出（建议）** | 合并仍求全部实际 h 之和，不因失效丢份额；合并本身不驱动 x | 有效来源中按原首次作用次序选最早；无有效来源则无重访目标 | 不复活失效目标；有效成员仍能触动她；下次重访可收回失效/重复残量，须接受这项扩展 |
| M2 失效残量隔离，只合有效份额 | 失效部分保持不可重访尾，独立 Φ；有效部分合并 | 最早有效来源 | 坚持失效尾只自然平复；部分失效发生在既有合并之后时无法从总 h 唯一分摊，需恢复历史分解或另定归属，复杂度与槽增长更大 |
| M3 任何成员失效则整个别名组不重访 | 全部残量保留淡去 | 无 | 简单但使真实有效 B 也失去作用；不由 P10 自动推出，须用户接受 |

“保留最早失效目标但把组标为 active”不作为合法候选。身份同一并不意味着一份失效记录能授权另一份目标；全事件被证伪与仅一个来源/权限失效的范围由既有 m=0 治理确定，本 ADR 不新增真实性判断员。

### 6.2 M1 的候选完整语义

1. **固定前缀。** 在本次提交的已确定 H 治理前缀下解析别名成员、来源有效性与获准目标记录。当前代表 ID 只用于寻址，不能替代目标来源、有效性或原首次作用次序。所有变更按历史提交顺序重放，不把最终有效性倒灌到旧前缀。
2. **残量连续。** 各现存组先按同一锚点推进一次 Φ；合并这些互不重叠的组时，每组残量只相加一次，按既有首次作用次序，binary64 逐项求和。已经合过的组不可因成员数再次乘算；重复治理提交不再次求和。若所列成员已经属于同一个组、没有新的并组关系，则合并步骤恒等，也不重新选择目标；不能借重复声明同一别名覆盖后来目标更新。全零省略为 +0，L1 逐出的非零项须恢复，不得当零。
3. **目标资格独立。** 合并时，从仍有效且确有合法目标来源的成员里按原首次作用位置选择最早成员的**现行目标来源**。不按目标更新时间、幅度或正负选。其 v、完整原前态、解释生效引用一起继承；若启用 0038，继承同一来源的年龄起点/速度，不用合并时刻重起。最早代表失效但后者有效，不妨碍后者被选。
4. **后继更新不能被覆盖。** 合并后的获准目标更新仍按 0035 §4.3 成为整个组的现行目标来源；不要在每次重访重新挑“最早”覆盖合法更新。为使备用选择确定，H 解析保留每个原成员自身最后一次合法目标来源：组目标更新须绑定实际授权成员，更新该成员的来源头并成为组目标，不抹掉其他成员的来源头；同一成员被更新取代的旧来源不可再用。当前组目标来源后来失效，才在其他仍有效的来源头中按原首次作用次序选备用。再次合法合并同样在并集的有效成员来源头中选，不把引用复制当作新来源头；可能换回更早成员的现行目标，这是 M1 选择规则的后果。有效性恢复仅在没有有效组目标时触发备用选择；已有有效组目标不因恢复更早成员自动切换，直到下一次合法目标更新或合并。所有解析从实际治理提交起生效，不清 h、不发新脉冲；目标资格恢复不是新依据。
5. **没有有效目标。** 组没有重访资格，h 继续原 Φ，目标可留审计引用但不可执行。来源闭包在治理前已指向该组的记录，不可因为过滤后为空就借“内部支路”恢复失效目标；若闭包还含其他有效组，原次序只重访有效组；只有原本真正无可追溯已作用根的纯内部支路沿旧规则。新外部观察仍按自身角色判定，不被旧根失效一并抹掉。
6. **治理不是刺激。** 合并、目标备用选择、来源失效/恢复自身零次 F；同提交若另有按既有资格获准的新观察/更正经历，按该记录原角色至多一次，不把维护当额外作用。固定时刻/维数的维护令 x/h（除合并表示）不变；下一条合法重访才用自己的 D11-A 消费键执行一次组 A1。恒等也消费；修订、恢复、别名不重开旧消费键。
7. **合并后再部分失效。** 已合并 h 不重新猜成员分摊，保留总 h，重新解析有效目标。重新取得一个目标不是重算历史 x。若以后要求拆开已经合并的组，须用可验证历史恢复或另写有损拆分决定；不能从总 h 均分。不同合并提交树的舍入可能不同，I16 只要求同一 H 同序重放，不承诺不同历史分组逐位等价。

第 4 项的来源资格/备用查询由 H 治理提供可信视图，内核只执行；需要的引用可由已有历史派生，不另立持久“有效性真相”。缺失来源、权限冲突或真假未决沿既有治理边界处理，不用 `any(active)` 加最早旧 target 拼成伪授权。

**精确见证与明确代价：**审计例中 x=1/2、h_A=3/4、v_A=3/4，h_B=−1/4、v_B=−1/4；A 失效、B 有效。M1 合并后 h=1/2、v=−1/4，x 仍 1/2；在 r=1 时下一次重访得 x=h=−1/4。旧歧义路径会升到 +3/4；M2 会保留 A 尾、B 已在目标上，所以当时 x 仍 +1/2；M3 也不重访。这是三种不同生活结果，不只是 `active` 检查的工程细节。若启用 B，则应使用 B 的 q，而不能把此 r=1 数值照抄为所有年龄的期望。

## 7. I23、结构重放与实施前置

**相同 H 与有效解释**下，L1/M1 的槽机制不得给 G/C 新的计数/权重/时间折扣；原来源更正引起的 G/C 重算照常，不把“F 不碰学习”误写成更正也不许改 R/θ。I23/AC2-08/18/19 验的是 G/C 规范增量与重算；x、槽、消费、有效目标与缓存重建另按 I16/18/21 验证。不同生命周期导致未来不同生活时，R/θ 可以合法不同，不声称闭环人生相同。

后继采用需要新表示/规律版本与明确 numerics_id 边界；旧快照/已发布版本按旧规则读。物化逐出的迁移必须证明历史输入足够、x 逐位不跳变、消费不重开；不足则保留旧状态，不猜 h。存储变化须有 SYS17 迁移/回退/失败保留旧系统。不能照 0035 §4.8 的旧版本有损空槽迁移来宣称本方案无损。

候选验证均 **not_run**，不新增正式验收编号，也不替代原验收：

| 要守的边界 | 后继正例、反例与观测 |
| --- | --- |

## 9. 限制与后果

所有速率、ID 长度与半衰期情景在增长附件标出，未读取用户历史、未作测量。没有实现、运行数值脚本、编译、测试或 GPU 工作；本次不签发性能、浮点包络或正式行为验收。L1 为候选表示方案，不表示现有 H/快照已足以支持高效恢复；M1 是明确的行为扩展，不把 G02 条件反例冒充已经发生的生产漏洞。
