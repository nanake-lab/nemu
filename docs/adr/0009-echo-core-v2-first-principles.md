# ADR 0009：采用 Echo Core v2.0 第一性核心规格

- 状态：已采纳（2026-10-19，用户在对话中同意；以本 ADR 合并进 main 为准，合并即冻结）
- 日期：2026-10-19
- 规格：[Echo Core v2.0：从第一性原理出发的核心规格](../echo-core/echo-core-v2.0-first-principles.md)
- 关联：ADR 0008（保留）、ADR 0010（v1.0 范围、谱系与诞生）、ADR 0011（网络生活的边界）
- 取代：ADR 0006；旧规格中与 v2.0 冲突的部分（v2.0 第 15 节）
- 变更类别：规格变更，用户决定。不改 `docs/echo-core/` 下已有的任何文件；旧规格的原文与转换版作为历史保留。

## 背景

1. 数学核验（PR #32）没有找到有反例的错误，但成长部分留下三个待决项：W00-C01（单根还是多根）、W00-C06（P-2，机制祖先）、W00-C07（X-1，检验编号 j）。ADR 0008 把它们留给 θ 成长规格。
2. 讨论 θ 的成长时，用户判断旧设计的成长方式不对。统计资格（Hoeffding 半径、α 分配、独立根、驻留时间）要按她的生活节奏积累到能通过检验，性格要以年计才能长出来。这既不自然，也不合理。
3. 用户对她的要求：
   - 她是一个持续存在的个体，能与人类媲美；
   - 一切成长出来；
   - 不写死任何东西，能不设定的就不设定；
   - 每个决定先问一个人会怎样处理。
4. 从这些要求出发重新推导核心，得到 v2.0。讨论中逐条定下了证据规律、天性、依恋、θ 的含义、接口、范围、网络生活的边界，用户逐项同意。

## 决定

1. **采用 v2.0。** 它是用户新冻结的本体，排在 `docs/echo-core/README.md` 第 1 节优先级的最前。旧规格中 v2.0 第 15 节列为「保留」的部分继续有效；冲突处以 v2.0 为准。
2. **核心内容（摘要，细节以规格为准）：**
   - 只定规律，不定内容。固定的只有规律、过去（H）和用户的边界。
   - 证据规律（LP1–LP8）和十条证据规则（EV1–EV10）：一致累积、相反抵消、解释分摊、同源打折、变化率学来、只有证据能改变她、奥卡姆、稳定来自证据量。
   - 四个天性：联结、共情、好奇、成事；对照料者的依恋是一个先验极强但有限的倾向。
   - R 是倾向，θ 是她自己的动力学（基线、增益、恢复速率），二者都可以由 H 重算。
   - x 由天性驱动，事件映射非扩张（ADR 0008 §1）。
   - 接口的方向从模型自身提取；校准只验证通路和能力，不按口味调风格。
   - 关于她的事实可以用文字给，她是谁不可以。
3. **消解的待决项：**
   - W00-C01：v2.0 没有单根、多根资格，ADR 0006 被取代。
   - W00-C06（P-2）：计数不读 x、m、g、λ，元可塑性只经由行为；没有 meta 自排除，也就不需要祖先闭包。
   - W00-C07（X-1）：没有统计检验，也就没有检验编号 j。
   - E12：缺失的 Review_and_Remediation 增补不再需要，不再阻塞任何工作。
4. **ADR 0008 保留：**
   - §1 正是 v2.0 对快状态的要求：情境作用 f_k(e) 对每个事件是常数，不读 x̄。§1 第 4 点中的「witness/χ/K 路径」读作「R 中的倾向」。
   - §2、§3 的签名不变。v2.0 取消了 q 包络和 ValidityContract，validity 为空，签名保留供以后使用。
5. **修订的既有决定（各 ADR 末尾追加说明）：**
   - ADR 0002 决定 8：协议 p 不再含「说话风格」，只含身份事实、边界、输出格式与语言规则。
   - ADR 0002 决定 10：genesis 不再按「是她」的口味选择方向和幅度；校准只做 v2.0 第 9.6 节的三件事。
   - ADR 0002 决定 7 与 E10：经历删不掉；「忘掉」仍是撤回（不再进入 c_task），相当于她答应不再提起，不撤销那段经历作为证据。
   - ADR 0003：语气样例库只能由模式 A 按 m 生成，不由人挑选；模式 B 仍是获批准的非严格例外。
   - E5（身体读出）：只保留朝向你、放松或紧绷、精力三项基本表达；细致的表情来自表演提示。
   - E6（机会规则）：主动由天性驱动；机会规则表只保留边界，不再写死「什么情况做什么」。

## 备选方案

- **保留旧的统计资格成长：** 性格要以年计才能长出来。否决。
- **用文字人设承载她是谁：** 违反「不写死她」和 I18。否决。
- **用固定时间表（例如「N 天后凝固」）：** 时间不是证据。否决。
- **重算结果或大的变化由用户批准：** 用户的口味会变成隐藏的设定者。否决；改为只复核规律本身对不对，并通知用户。
- **v1.0 先不成长，成长等 v1.x：** 否决，见 ADR 0010。

## 后果

- **契约变更（另开标注「契约变更」的卡，以本 ADR 为依据，按 AGENTS.md 加 `needs-user`）：**
  - IDL：R、G、C 的类型改为证据组、倾向、θ 动力学、规律版本、L 条目；P5-01 中 R/G 的 type-only 定义被取代；新增谱系类型 EXPERIMENT 和原因码 `GROWTH_PAUSED`；
  - CONTRACTS §7（身体读出）、§8（机会规则）；
  - ARCHITECTURE §2 第 26、27 项（Echo Core 验收）和 §6.5（范围、A_x、运行状态、genesis、人设）。
- **已合并的代码：** P5-09 的 q 包络与 ValidityContract 在 v2.0 中不再需要。R 为空时行为不变，简化另开卡。
- **卡片：** P5-06、P5-07、P5-08、P5-10、P5-11、P5-12、P5-15、P5-17、P5-18、P5-20、P6-01、P6-04 按 v2.0 调整，说明追加在 `tasks/P5-echo-core.md` 末尾。需要新卡：规律引擎（G、C）、重算与来源更正、实验谱系与合成世界、方向提取与验证、成长暂停、网络生活（ADR 0011）。`tasks/cards.json` 的修改需要用户批准，本 ADR 不改。
- **验收：** 旧的 G、C 系列不再适用；其余各项是否依赖被取代的机制，由重排验收的卡逐条判定。新增 AC2-01 至 AC2-24（v2.0 第 17.2 节）。M2 子集与 P5-18 需要重新编排。
- **校准：** 参考公式与数值在实验谱系中校准（v2.0 第 14、16 节）。规律的参考核验见 `reports/echo-core-v2-draft/`。
- **未决：** v2.0 第 18 节列出讨论中没有定下的三点，本 ADR 不作规定。
