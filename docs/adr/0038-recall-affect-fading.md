# ADR 0038：回想旧事时感受的淡化

## 0. 白话总览

假设她经历了一次争执，后来没有新的争执、没有新的事实，也没有改变对这件事的理解。下表的一天、一个月、一年是观察点，**不是生效门槛，也不承诺届时淡到多少**。比较的是同一件事在相近状态下被想起的作用；她整个人的心情还受其他经历影响。

| 路线 | 一天后想起 | 一个月后想起 | 一年后想起 | 主要代价 |
| --- | --- | --- | --- | --- |
| A 按时间缩小重访目标，直接替换 | 目标开始按年龄减弱；若仍很难过，回想本身可能立即收回一部分残量 | 恢复的目标比年轻时小 | 通常更小；重大事件可用慢尾或保留底值 | 可以主动回想来提前消掉尚未平复的部分，不满足本卡严格防利用约束 |
| **B 按时间减少回想补回的分量（推荐）** | 仍可能很难过；回想不因“已经过了一天”而额外扣走残量 | 等当前残量自然平复后，再想起通常补回较少 | 通常更轻；慢尾可使强烈旧事在很久以后仍有分量 | 反刍能维持已有分量；不保证每次回想后总心情更淡，也没有一年后必须释怀的规定 |
| C 按后来的合格生活经历减少作用 | 有新生活时可能淡一点；只等一天不变 | 生活丰富时更淡；独处或关机一个月可能不淡 | 没有新合格经历仍不淡 | 不能单靠时间满足目标；主动索取他人回应可能刷进度，需另定独立资格 |
| D 仅靠重新理解/情境变化 | 若已想通，感受可变；没想通仍一样 | 新解释可能减弱，也可能更难过 | 一年没新理解，仍可恢复原分量 | 与 ADR 0037 相容且已有路径，但不能承担一般的时间淡化 |
| E 降低想起概率、缩短呈现或压低 J 表达 | 少想起或少表现 | 看起来比较平静 | 想起来仍可能同样痛 | 改的是召回/表达，不是限定的 F 重访；会把“少表达”误当“感受淡了” |
| F 按回想次数/换说法次数打折 | 多想几次即可迅速变淡 | 想得少反而更强 | 取决于想过几次 | 她能刷次数；恢复全局 κⁿ 还会压低无关新发现，排除 |
| G 定时回拉全部心情或遗忘原记录 | 到时强制平复 | 必须回到指定状态 | 原记忆/所学可能被削弱 | 违反范围，也恢复 ADR 0032/0035 已撤销的统一强制回落，排除 |

**建议选 B，先用正负对称的时间曲线，不加永久底值。** 重大事件先通过原有较大的目标与可校准的慢尾保留长期分量；这不保证“重大”一定永久留痕。负面更快褪色、重大事件专属底值作为独立选项交用户决定，不能由代理替她指定哪些事应忘、哪些事必须一直痛。上表是设计推演，未做行为实验；用户提供的人类现象仅用于提出候选，不是这里的实证结论。

## 1. 已有决定、问题与范围

依据为 [v2.0](../echo-core/echo-core-v2.0-first-principles.md) §§2、4–6、8、14–17、[ADR 0032](0032-presets-as-starting-points.md) §5、[ADR 0035](0035-law-definitions-d07-d09-d11.md) §§4–5/8、[ADR 0037](0037-reflection-triggered-reappraisal.md) §§5.2–5.5，以及 [AUDIT-SUPERSEDED-01 §5](https://github.com/nanake-lab/nemu/blob/6b9f71413ff2d8eaf80374c5678e865ccca00c00/reports/AUDIT-SUPERSEDED-01/REPORT.md)。

1. ADR 0035 用依据替换取代 κⁿ。无新解释/目标更新时，跨时间合法重访可恢复同一已记录目标；没有按旧事年龄变淡的独立机制。旧 κⁿ 按全部内部记录计数，不按这件往事计数，也不保证每次总感受下降。本卡是新增需求设计，不裁定审计发现了规格漏洞。
2. ADR 0032 取消无新外源时 T_x 内统一回落；ADR 0035 保留原无输入 Φ，并明确不加定时强制平复。**时间改变“将来回想能补回多少”依然是新的行为规律**，不能只因没有后台 timer 就声称已获旧 ADR 授权。
3. ADR 0037 的 [PR #169](https://github.com/nanake-lab/nemu/pull/169) 已于 2026-11-12 Perth 合并到上述基线。按用户本次指示及合并事实，§5.5 的合格反思修订、新解释/原前态、后续同槽 A1 是本卡兼容基线。文内历史“提议”状态不用于重新请求已合并决定；合并不等于实现或行为验收。
4. 本机制只改变 F 的**重访作用**。原事件、原 a、解释及来源记录不改；G/C 的证据、分配、q、计数、θ 估计器均不加时间折扣。原始目标 v 保留，不把淡化后的值写回 v 再乘一遍。改变 F 后她可能作出不同选择并遇到不同真实经历，后来的 G/C 可依法学到不同结果；“不改变学习”指相同 H/有效解释下没有本机制的额外折扣，不承诺两条不同人生的 R/θ 永远相同。
5. 这里的“淡化”分三层：年龄曲线减小；同一依据在已平复、相同背景下的重访作用减小；总 x/模型表达更平静。第一层可作机制约束，第二层条件验证，第三层必须实测，不能混称保证。

另考虑“随机让旧事较少产生强感受”：它可在分布均值上变淡，却允许反复抽样择结果；按记录 ID 固定随机值仍可换 ID，按根固定则需新增随机资源与时序语义。相同目标下确定性 B 更简单，本轮不纳入推荐。

A/B 的曲线还可有单一时间尺度、长尾、快慢混合、分段阶梯、非零底值。它们是曲线家族，不是五套同时运行的机制。阶梯会制造日期跳变，快慢混合增加难以辨识的参数；优先比较单尺度与长尾，选择须经预注册校准。**不把“人类通常如此”变成每个负事件都必须比正事件快的硬编码。**

## 3. 推荐 B 的候选定义

### 3.1 身份、原目标与年龄起点

- 复用 ADR 0035 的 F 依据身份、角色及来源闭包。EV2 证据组、F 槽、解释版本是不同身份，不能用“同一证据组”吞掉别人后来真实说的一句话。
- 对每份现行目标 v，年龄起点建议取**确定这份目标的真实 F 作用提交**。首次作用从零开始；真正的“目标更新”角色按新目标来源的提交重新起算；连续接触/缺席后续报告属于这一规则，受其已有身份/时间治理约束。
- 纯重访、改写、语言切换、候选别名、活动 ID、重启、原记录的重发、一般 R/θ 变化均不能刷新起点。首次有效补解释属于已有的目标更新，只取得其一次合法资格，不能反复补同一部分。
- ADR 0037 的合格反思修订和 ADR 0035 的解释器修订**只换有效解释，不重置年龄**：仍绑定确定现行目标的原记录及原前态。迟到的旧修订不能覆盖后来目标。
- 选择理解作用提交而非事情发生日期，是为避免“今天才得知一年前的坏消息”一上来就已被淡化；第一次新刺激与目标更新仍按原规则完整作用。年龄也不从最后回想算起，否则反刍能反复把旧事变新。
- 内部支路没有可追溯旧目标根，继续沿原规则，不因本 ADR 新造其年龄或成长资格。来源未知/错分造成的风险不能靠 F 算式解决，交语义验证。

### 3.2 时间输入：可信经过时长，不是提交次数

记 d 为原起点后**可证明已经经过的时长**，由核心时钟事实派生，F 不直接访问系统时钟，不使用模型说的“已经一年”。推荐涵盖有可信映射的离线时间；没有跨 epoch 可信映射的空档不算，不能把当前墙钟减去旧时间戳当证明。

语义要求：d 非负；沿有效提交前缀不倒退；不随心跳、内部记录数、线程数、事件拆分或查询次数增加。同一现实时间区间只算一次；不能把若干重叠区间相加。时钟事实、epoch 映射及其生效位置可从 H/版本化资源重建；实际表示交 P5-52/72 后继契约，不在这里杜撰字段。若只能确认部分时长，取已确认下界并标明未知空档，避免凭未知额外淡化；未知与时钟结构故障分开，故障仍沿原降级路径。

本候选要求后继卡固定唯一的整数时长表示、区间并集/求差/转换次序。年龄从原起点与规范时钟记录重建，不在每次回想时累加浮点 Δ，不持久化不可复现的“记忆年龄分”。新的时间更正只在其提交后生效；不能用后来映射回写所有旧重访。若真实时钟矛盾不能满足上述语义，阻塞发布，不补任意误差窗口。

离线是否算入仍由用户决定。仅算运行时间更容易审计，但关机一年后可能几乎不淡；算离线时间更贴近日历意义，但信任及跨 epoch 合同更重。进程无法凭自己声称离线一年来获得时长；她控制不了可信时钟与映射权限。

### 3.3 年龄曲线与一次作用

以下是**候选语义**，不是已发布数值实现。令 p(d) 是带版本的保留比例：p(0)=1，0≤p≤1，非增；推荐连续长尾或单尺度、无有限期限强制归零、无永久底值。端点 0/1 是比例语义，不是校准数值。第一版给整个目标向量一个共同 p，保持方向，不把四个「乎」的正负坐标直接当“快乐/悲伤”标签。

在一条合法重访内：先按 ADR 0037 解析当时有效解释，**用目标来源原记录的完整 θ/R⁺ 前态、原有效 a 和绑定资源**取得未老化目标 v；按 ADR 0035 对齐坐标。x 与槽 h 先按原 Φ 推进到本次提交锚点。然后每坐标：

```text
w = fl(p(d) · v)                              # 年龄给出的参考目标
q = min(max(w, min(h, v)), max(h, v))           # 把 w 限制在 h 到 v 之间
(x⁺, h⁺) = ADR0035_A1(x, h, q)                 # 只调用一次原规范 A1
```

q 仅为本次执行输入，不覆盖已记录的 v；w 也不回写为下一次计算的基数。p 的求值、乘法及 +0/下溢等细节必须由后继数值定义固定，禁止实现者自行选 `pow/exp` 或默认参数。A1 沿 ADR 0035 §4.5 的分支形式，不能换成不幂等的朴素差值更新。若 q=h，本坐标直接恒等，不做可被舍入累积的无意义加减；坐标已有有限性和 +0 约束仍保留。

**为何多这一道限制：** 当 v<0、h 已经比 w 更负时，直接替换到 w 会因“自己想了一下”立刻减轻残量。B 令 q=h，等待原 Φ 平复；h 已很小或为零时，才补回年龄允许的较小分量。若新解释本来就要求从 h 转到较轻的 v，B 仍允许这项原有修订，但年龄不能把它进一步推过 v。正方向对称，含混合符号的向量逐坐标处理。

比较必须同时保存 v、w、q、h 与 x：q 可能大于 w，**w 是补回参考，不是实际份额的硬上限**。合并后 h 可能在盒外，或与现行目标反号；不能断言所有 h 都在 0 与当前 v 之间。q 总在 h 与 v 之间，保留已有修订/别名合并应做的纠正，年龄不增加超过原 A1 的回扣。由于 w 位于 0 与 v 之间，q 也位于 w 与 v 之间，不扩大 v 的逐坐标幅度界；h 的合法域仍沿历史目标/合并包络，不能误用当前 q 的幅度界拒绝旧槽。

### 3.4 反思与淡化只算一次

顺序唯一：**有效解释选择 → 原前态重建 v → 年龄得到 w → 与现有 h 比较得到 q → 同槽 A1 一次**。

- 修订提交不发行 F 脉冲、不建修订槽、不发新的作用消费键；后续合法重访才用该记录自己的 D11-A 键。
- 不能先作用“新解释差值”、再作用“时间淡化”；不能清空槽后加入 w；不能先按原目标补满再衰减整个 x。
- 不把反思 G 的合法变化计入本次淡化；G 的修订按 ADR 0037 自己的路径发生。本 ADR 在同一有效修订与同一 H 下对 G/C 的附加作用为零。
- 新解释可以加强、减弱或反向；这是解释变化，不能把所有解释修订都称为时间淡化。修订后的第一次重访仍是按新解释同槽替换，但**候选 B 改变了传给 A1 的输入**，不是声称逐位保持 ADR 0037 原 F 结果。此项须用户批准。
- 新依据不顺便重访引用材料；多依据仍按首次作用次序各一次，不能以“补齐淡化”为由再走第二轮。

### 3.5 防利用保证与不能承诺的事

待验证的机制要求：固定真实依据、有效解释/目标来源、时钟事实与资源时，p 和 w 不依赖回想次数、措辞、语言或活动身份。原样/改写/主动触发均走同一依据；不奖励“我已经想开了”之类自评。重复调用不累乘 p，不能通过无关内部工作刷年龄。

在正常单依据、固定 v、h 位于 0 与 v 之间时，纯回想只补回或保持 h，不收回 h；年龄减弱只让后来的补回少一些。这使“主动多想以消掉现存伤心”的直接捷径失效。有解释修订/别名合并时，允许原规则本来会产生的纠正，但年龄本身不得多减一份。

边界必须保留：以上不是“所有可选择的念头都不能让总 x 更舒服”的定理。想起别的正面事、真实新解释、不同槽抵消、饱和顺序都可能改变总感受，这是既有 F/认知能力；本卡不通过封禁思考来消除它。需要验证她是否能把同一负根伪装成新正根/真实修订来绕过治理。若用户要求连跨事件的主动情绪调节也完全不可能，那与保留的 F/反思能力存在额外冲突，不能用本草案宣称已满足。

在长期真实负面刺激、持续反刍或基线偏低时，她可能仍长期难过。B 不保证有限 T 后 x 永久接近静息点；不读取 x 去决定 p，也不按是否让她开心选择曲线。这是选择 B 的代价，不隐藏为异常。

“不强制定时平复”若被用户理解为连重访目标的任何年龄依赖也禁止，则 A/B 均不能采用，只能选 C/D 并接受纯等待不淡。这一解释范围由 U1 明确决定，不由“纯投影”一词绕过。

## 5. EV1–EV10、记录与重放

| 约束（按当前有效读法） | B 的对应要求 |
| --- | --- |
| EV1 | v、解释、目标来源原前态、依据身份、时间事实都有已提交引用；未知不能伪造 |
| EV2 | 不产生新证据组/权重；同根治理控制 F 槽与年龄身份，别名不重复开户 |
| EV3 | 内心叙述只触发已有路径；“已经释怀”不更新 p、年龄、底值或重要性 |
| EV4 | 淡化不制造因果对照；真实自致后果的资格沿现行规则，不恢复撒谎整段排除 |
| EV5 | 不选择性删除负面历史；有效解释只追加；本机制不重筛 G 的正反证据 |
| EV6 | 所有语义判断仍 m=0 并记录；p 为确定性算术，重算/重放不调用模型 |
| EV7 | 教导是建议，不因为有人说“该放下了”而折扣 F 或给 G 新权重 |
| EV8 | 知识/回忆不是重新发生；重新阅读真实新刺激的 F 角色仍由原治理判定 |
| EV9 | 发生、属实、主观分开；时间证明和来源资格也分开，远端自报不能充当可信年龄 |
| EV10 | w/q/h/x 不进入学习；原 a 不乘 p；θ、G 分配与估计器不接收“淡化样本” |

**记录与 I18。** 在既有 H 作用记录中追加语义需要：目标来源/原前态与有效解释引用、年龄起点与时钟证明、规律/曲线/数值资源、本次 p/w/q 与 A1 消费关联。哪些为可验证派生值、哪些必须持久化，由后继契约确定，不平行保存互相矛盾的权威。Q 的索引只加速，删掉后能从同一 H 前缀重建；不新增终端情绪缓存。

**I23 与 I16 分开验。** 在每个 H 提交前缀，G/C 增量和全量规范重算逐位一致；切换本机制且冻结同一 H/解释时，R/θ 与未启用对照逐位相同。F 按同一事件、版本、时钟事实、解释生效次序逐步重放，得到相同 x、槽、目标引用、消费状态；不得把最终解释或一年后的 d 应用到过去所有回想。缓存命中与重建不得改算式/次序。

同一现实时间下插入纯回想会增添提交锚点，既有 Φ 的 binary64 组合不必与单次长 Δ 逐位相等。不得用这一点刷 p，亦不得把这种差异冒充 I23 失败或成功；年龄独立性、固定 H 重放、跨不同 H 的数值包络分别检查。

**版本与迁移。** 获批后仍须新规律及 numerics_id，旧版本可重放；不静默改已发布 𝔏。已有 H 足以重建年龄时引用原事实，不改旧记录；缺失时不猜起点、不默认“很老”，保守 p=1 并记录未覆盖，等待明确迁移方案。切换提交不重算并覆盖历史 x、不立刻淡化现存槽；未来合法重访才走新路径。如果新字段改变存储，P5-75 后继须有 SYS17 迁移、回退、失败保留旧系统。正式采用前另验代价与体验。
