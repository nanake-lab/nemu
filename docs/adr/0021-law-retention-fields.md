# ADR 0021：分配的实际保留率与倾向的证据量

- 状态：提议，待用户合并批准；P5-34 草稿 PR 标 `needs-user`。
- 日期：2026-10-23。
- 依据：ADR 0007 §2、§11；ADR 0016；已合并的 ADR 0019 §3.2、§5、§6、§8；v2.0 §2.2、§5.2、§5.4；V2-50、V2-55–V2-60。
- 范围：仅契约、生成类型、语义检查与合成向量；不实现 G，不启用规律、不打开任何谱系存储。

## 1. 背景与不可反推的原因

ADR 0019 的 A 是有符号证据量 E−C，V 是绝对证据量 E+C，B 仍为 c+V，c=n₀+κ，P 为不衰减的依恋先验。π=(P+A)/((P+c)+V)。普通倾向 P=0。每个分配首次计入时的实际保留率 q 一经生成，普通分摊与内容修订不得追改；来源更正、新规律版本从有效 H 重新生成 q。

| 已有字段 | 为什么不足 |
| --- | --- |
| A/B | A 混合正反贡献，不能恢复 V。B 的 binary64 加法已舍入，例如 c=4、V=2⁻⁵³ 时 B=4，B−c=0；减法不能恢复 V，也不能恢复每组的 q |
| π | 是一次除法的舍入结果，多个 A/V/P/c 状态可有同一 π；不能由它逆推出 V 或 q |
| M/U、r | 是 μ·p 与 μ 的另一套统计，与 W·S、W·\|S\| 不同；r 还经过截断。即使同用 q，也不能从聚合的 M/U 分解出历史 q |
| ordinal/μ/p、S、强度、份额、可信、可核实 | ordinal 仅给次序；其余给当前因子。自适应 q 依赖首次计入时的 π、P/c、h 与 W/S；普通分摊会改变当前因子，按它们重新估计旧 q 违反撤回单调性（ADR 0019 §5） |

## 2. 决定：只增加两个权威字段

| 后继消息、冻结标签 | 字段表 |
| --- | --- |
| `EvidenceAllocationV3`，`echo.evidence-allocation-v3` | 1–8 与 V2 相同；9 `actual_retention`，必填有限 double，0<q≤1 |
| `TendencyV3`，`echo.tendency-v3` | 1–17 与 V2 相同；18 `evidence_absolute`，必填有限 double，V≥0 且 V≥\|A\| |
| `EvidenceGroupV3`，`echo.evidence-group-v3` | 继承 `reserved 7`；再保留 8；9 `allocations` 为 V3，按 tendency_id 成集合；其余字段相同 |
| `RSnapshotV3`，`echo.r-snapshot-v3` | 继承 `reserved 4`；再保留 5；6 `tendencies` 为 V3，按 tendency_id 成集合；其余字段相同 |

V2 消息标取代，定义和字节保留。字段号与标签不复用。`schema_version` 仍为 1，新含义由新类型标签区分。对象引用的 `object_type` 必须使用后继标签；引用消息本身不换代。现有 `baselines/p5-32/` 已由 P5-22 冻结，本卡核对后保留，不以当前 IDL 覆盖它。

q 是**该分配计入前对旧统计执行的乘数**，不是该分配自身的当前 ω；首次 ordinal=0 时也保存所算出的 q（旧统计为零不等于 q 必须为 1）。零有效信号首次 q=1；后续若修改 S 到零仍保留原 q，故不能根据当前 S 强制 q=1。q 不设人为正下限，次正规数允许由契约表达。

V 不含 c 或 P。A、B、π、M/U 继续各自含义，不把 B 改成 V。ADR 0019 §8 的规范次序是：先算 c，再 anchor=P+c、before=(P+A)/(anchor+V)；算 q；A/V/M/U 各先乘 q 再加新项；最终 π 用 (P+A)/(anchor+V) 计算。B 是兼容的派生量 `c+V`，不作为恢复 V 或计算依恋分母的输入；`P+(c+V)` 与 `(P+c)+V` 不保证同位。

## 3. 语义检查的关系与边界

结构编解码拒绝缺省、非有限值、V<0、q≤0 或 q>1、V<|A|。为让黄金向量和嵌套消息在三种语言均拒绝 q=0 与 V<|A|，IDL 新消息分别声明 `@rules {"positive":["actual_retention"]}`、`@rules {"at_least_abs":{"evidence_absolute":"evidence_a"}}`。生成器只允许规则指向必填的标量 double；Rust 通用校验、Python/TypeScript 模板与浏览器 Zod 根据同一描述符解释规则。旧消息不加规则、不改变编解码结果。Rust 语义层也独立检查这两条，供原生类型调用者使用；其他语义关系不由结构编解码代替，所有生产者仍需执行语义检查。

`check_tendency_v3` 保留单位方向、π∈(−1,1)、B>0、\|A\|≤B、计数和关系检查，显式拒绝所有标量的非有限值及负 U/r/P，并要求 V≥\|A\|、h∈[0,1)、N/F<2⁵³；第一组之前 M=U=0；U=0 时 r=0。保留 M=2⁻¹⁰⁷⁴、U=0 的合法边界，不额外约束 M/U 的比例。N=0 不强制 A/V 为零，因为关系倾向可有规律/genesis 给出的初值。

`check_tendency_v3_with_parameters` 在调用者提供所属规律的参数后核对：κ=κ₁×谓词条件数，c=n₀+κ 有限且正；B=`c+V`；π=`(P+A)/((P+c)+V)`；r 在 U=0 时为0，否则为 `clip(M/U,0,r_max)`。每一步有限并按指定括号计算，精确相等，不设容差。不能用 B−V 恢复 c，也不能用 P+B 代替分母。规律参数/对象引用的身份绑定、H 重算、q 的首次生成与不可追改由 P5-23/P5-26/P5-29 保证；本卡不伪称字段检查能证明历史真实性。

V3 分配序号检查同 P5-32：每个倾向恰好 0…N−1，各一次，并核对 q 的语义范围。一个字段值合法不代表它由完整规律生成。

## 4. 字段最小性与四种路径自查

| 路径 | 读取、生成与写入 | 是否需要额外权威字段 |
| --- | --- | --- |
| 普通新增与已存分配重放 | 新增按本组前态生成一次 q；A/V/M/U 先乘 q 后加因子。重放从规律/genesis 初值，按 ordinal 只折叠已存 q、S、强度、份额、可信、可核实、μ、p | q/V 足够表达递推；不存当前 ω、历史 π 或历史 b/σ |
| 回溯分摊、迟到成员 | 写好旧分配的当前因子；保留旧 q；按 ordinal 重放得到 cf，再处理旧组中首次加入的新候选分配并生成它的新 q | 全事件计划来自 H 和确定算法；不把审计 cf、before/after 变成新增持久状态 |
| 容量移出 | 独立计划修改受影响侧的旧份额，保留其 q，重放剩余倾向；证据仍在 H。移出后重新建立的倾向按完整规律处理 | 不用额外 ω 字段；容量选择、计划与边际审计待 P5-23 验证，本卡不签发 AC2-21 |
| 来源更正或新规律版本 | 从更正后的有效 H 开始完整 G，重新计算全部受影响首次 q/V；不删分配后直接沿用假证据产生的旧 q | H、解释记录、规律/genesis 已是输入；不需要在分配复制它们，本卡不签发 AC2-19 |

**仍需后续核对、仅列出而不加入的潜在字段：** P5-33 若选用新的变化检测器，其后验/裁剪状态和实现资源版本可能需要显式版本化字段或对象引用；现有标量 h/N/F 不一定足够。这不属于 ADR 0019 当前翻转频率版本的缺字段，本卡不设计或添加，由用户结合 P5-33 决定。关系的信任种子、容量后重建和计划的具体规范继续由 P5-23 的待确认清单界定，不借本卡增加字段或替用户裁决。

## 5. 备选与迁移/回退

- 从 B−c 得 V、从当前因子重新算旧 q：分别损失已舍入的信息、违反 ADR 0019 §5；不采纳。
- 每个分配存当前 ω：每来一组都要改全部旧分配，且仍缺 V；不采纳。
- 修改 V2 的字段或类型标签：改变已发布字节，违反 ADR 0007；不采纳。

本卡不访问或迁移现有存储，不假定用户存储中没有某种对象。旧消息保持原标签原解码器；后继消息绝不冒充 V2。未来接入前按 ADR 0007/0005 备份，由 P5-23/P5-26 从 H 和绑定的规律/genesis 构建 V3，禁止缺 q 默认1、V=B−c 的转换；失败保留旧对象。回退恢复旧程序与备份、停用 V3 生产者，保留 V3 原始对象，不向旧类型降格。生产迁移与 SYS17 不由纯契约往返测试替代。

## 8. 2026-10-24 验收发现：JSON 输入保留 binary64 位值

首次黄金冻结拒绝中止：JSON 的 `V=0.9999999999999999`（1 的前一 binary64 值）、`A=-1` 被 Rust 接受。复现确认，现有 serde_json 默认解析路径已把 V 变成1，导致后续 V≥|A| 检查面对的是错误输入。

core-types 为现有锁定的 serde_json 1.0.154 启用 `float_roundtrip`；不新增依赖、不改锁定版本或字段。JSON、原生类型、CanonicalV1 和 Protobuf 的回归测试核对相邻值及次正规数的位模式，并拒绝两种 A 符号下的 V<|A|。这落实第3节的 binary64 输入语义，不增加容差或重写旧黄金；旧向量继续按原期望逐项复核。原始失败及修复后的记录保留于 P5-34 报告。

## 9. 2026-10-24 审查修复：集合预算与概念重放输入

`max_items` 约束本次实际编码的集合，不是谱系历史证据组ID的终身上限。普通发布先校验事务本身的集合预算，再按待发布R中的倾向及最新关联索引核对序号；历史最新版本先于关联筛选，空后继继续遮蔽旧关联。完整重放逐行访问历史最新组，仍有分配的组必须给出重建结果或空后继；已经为空的组无须每次重复发布。本条澄清第7节“覆盖所有旧组”的边界，不截断历史、不增总量阈值。

逐事件重放输入保留原事务的`staged_concepts`，其引用及递归资源闭包与解释结果一样校验摘要后提供给可信核心，确保当次首次引入、旧Registry尚未收录的概念可读。历史概念按各自事件保留关联。该字段来自既有CoreTransactionV2，不是第三个新增权威字段；资源视图仍排除所有版本的R统计。回调失败或发布失败保持原head与概念可见性，真实G集成仍待其实现。
