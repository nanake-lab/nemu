# ADR 0047　本机授权、执行与成长管理

交付线 P5-40，提议，待用户批准。差异登记为 [V2-189](../traceability/diff-register.md#p5-40-权限与成长管理的契约承接)。权限服务、操作系统隔离与真实执行由 P5-41 联测。

## 背景与决定

P5-05 可核对载荷，P5-35 能证明安装实例持有配对会话。两者都不足以证明当前人是 u*，或某个执行器仍有权执行某次行动。认证方根据本机受信来源将当前 u* 与连接会话绑定。凭证仅由本地闸门签发，执行器凭服务端登记、绑定持有者及一次性消费核验。任何客户端发送的身份字段都不能自行产生身份。

1. [ADR 0043 §4.1](0043-two-lines.md) 允许用户选择不可挽回行动的档位。一律不做、先问用户同意后做、直接做均可选。用户已定默认“先问用户，同意后做”。能挽回的都可以做，包括关掉用户的游戏。每次桌面放行绑定动作、载荷、当时的档位资源版本及可挽回性判定资源引用。先问路径记录同意者、确认时间与行动绑定。可挽回性规则另行按版本发布。
2. 按 [ADR 0045 D9](0045-speak-think-wiring.md)，权限设置的默认值中，只有影响她的行为、表达或成长且尚无既定决定的，才标为“默认待用户定”。例如，未设定的钱包余额上限只影响依赖该上限的资金授权。不可挽回行动的默认档位按第 1 条执行。
   行动派发有两项纯工程设置。实现方依 [AGENTS §5](../../AGENTS.md#5-代码规范) 提供可直接使用的默认值，在代码定义旁写明取值理由，并允许用户调整。用户未设置时采用工程默认值，说话仍走正常的派发和逐块凭证检查。
   - `credential_lifetime_ns`（执行凭证有效期）需覆盖正常的最长一段发言，以便末块仍可核验，同时限制一次凭证可使用的时间。
   - `max_dispatching`（同时在途的行动数上限）为说话与身体动作并行留出容量，同时约束执行器的资源占用。
3. [ADR 0045 D1](0045-speak-think-wiring.md) 与 [ADR 0046 §2.1](0046-speak-think-contract-gaps.md) 把云端认知限于提供内部文字。权限入口复用 RemoteCognitiveReceipt.mode 和 local_pause_reason。其输入输出类型没有下一步关注、查询、行动选择、执行、对外投递或写 H/Q 的凭证。本地路径暂停时依赖它的能力随之暂停。
4. [P5-05 拆分说明](../../tasks/requests/P5-05-permission-integration.md) 要求撤权、会话、一次性和崩溃语义。发送前在同一个消费边界核对主体、权限与协议版本、动作、原样载荷 SHA-256、作用域、预算、有效期与撤销代际。消费及预算预留须持久化后才允许副作用；已可能发送但结果不明进入 UNKNOWN，重启不重发。
5. [差异登记](../traceability/diff-register.md) V2-89、V2-104 限定她以自己身份发消息、约定与小钱包支付，默认信任；涉及 u* 的事事后通知。仅 u* 可充值，有余额上限、不能透支、自动充值或绑定 u* 的卡。社交内容不得接触 u* 的账户、密码、秘密。T3 不可记忆；信任由外层事务写 Q 或已版本化资源。
6. 同一认证管理入口处理 pause、resume、review。面板仅可二次确认暂停或恢复，echoctl 可登记逐报警复核；绑定报警 ID、记录、规律版本与 H 前缀，结论只有规律无误、规律有错。报警只通知；合法命令的审计与 H 系统记录由外层事务同时发布。系统记录不经过 F、不作为 G/C 证据。（V2-87、97、101；v2.0 §5.4、§10、§11。）

## 备选与后果

| 结构 | 能否省略 | 一个人会怎样 | 什么不能事后改变 |
| --- | --- | --- | --- |
| 本机身份、作用域与一次性凭证 | 只传安装实例、摘要或通用 ObjectRef 无法区分授权者与被授权执行者 | 同意一件事只适用于当时同意的内容 | 已发生的外部副作用和历史不能靠切换档位撤回 |
| 档位与信任资源 | 固定默认会替用户决定；覆盖旧资源会丢失授权来路 | 会在行动前征询，并允许以后改变选择 | 旧行动仍按当时生效版本解释 |
| 逐报警的管理记录 | 单一“当前报警”无法在并发复核时配对 | 可以认为规律有错并修订规律 | 过去那次报警、复核与同意始终保留 |

沿用 [ADR 0007](0007-initial-idl-canonical-encoding.md) 和 ADR 0046 §4 的字段号与基线纪律。仍有生产者的前驱保留原标签。P5-41 在切换前完成临时存储迁移与回退测试，旧记录不得升级为有效执行权。

## 接线与发布

| 消费者 | 入口与拒绝语义 |
| --- | --- |
| P5-14 闸门和执行器 | 查自己持有的本机签发表，以认证执行连接的会话和签发记录调用 `check_dispatch_binding`。凭证时间为 issued_at_ns ≤ now < expires_at_ns，使用受信同一时钟域；恢复后时钟不可比则拒绝。按目录重新解析 connector_id、operation_id、resource_id，与原样字节核对。权限/协议/作用域切换、预算不足、同意或信任已撤回、并发消费、未知结果均不得重发。结果携带审计 ID 和对应派发记录 ID 或 PermissionDenial。 |
| P5-29 认证管理与提交 | P5-35 的配对证明与会话能力先通过。认证服务从操作系统与当前 u* 的受信绑定取得 LocalUserBinding，并从连接取得 ManagementEntry，两者均独立于请求。调用 `check_management_binding`。面板的 confirmation_id 指向服务签发、绑定会话、当前 u* 和完整命令规范摘要的一次性二次确认。失败记拒绝；成功须把审计和系统记录原子提交，再以同请求标识返回。 |
| P5-15 echoctl、恢复 | 与面板共用 TerminalRequestV2/TerminalResponseV2；确认返回的 request_id、session_id、protocol_version、reply_to、成功/拒绝分支和审计记录。review 逐报警读取相应 H 系统记录，核对触发与规律/H 前缀；“规律有错”绑定后继版本。只有新维护命令才能改变状态，恢复时重放历史结果。 |

权限设置及其版本由核心持有。授权以当前目录、信任资源和发行记录为准；入参中的 ID 都只是定位符。允许记忆的 T1/T2 经 u* 同意由外层事务写 Q 或版本资源，撤销后版本失配立即拒绝。通用连接器按原 §6 分层；桌面操作按 ADR 0043 的专门档位核对，可挽回或明确选“直接做”时无需桌面逐次同意。付款与充值必须使用发行方解析出的专属钱包，对当前余额、上限、金额、币种与充值人核验；声明某种 scope 不会改变实际操作分类。社交默认信任限于 V2-89 已确定的范围，设置变更按当前权限版本生效。

ActionRequest、GrowthCommand、TerminalRequest、TerminalResponse 保留原读写方，后继均标 `@retains`。P5-14 迁执行器、P5-29/P5-15 迁管理命令和网关收发；确认没有活跃前驱写方与嵌入后再申请退役。旧凭证引用没有签发事实，不能按新标签读，也不能据此恢复执行权。合成基线冻结于 #234 合并提交。各字段及联测要点见[规格对照](../traceability/P5-40.md)。
