## 2. 共同约定

**规律版本。** 三项规律一起发布为一个新规律版本，记为 𝔏_ADR0035，与现行版本并存。旧版本保持可重放（v2.0 §5.4、I23）；一条谱系用哪个版本由 genesis 或显式的版本切换记录决定，不在运行中静默切换。版本切换时，R、θ 按新版本从 H 重算（v2.0 §5.4）；快状态按 §4.8 迁移。诞生尚未发生：若 genesis 直接采用新版本，正式谱系没有旧状态需要迁移；迁移只涉及排练与实验谱系，以及将来的版本切换。

**数值。** 有限 binary64，舍入到最近（偶数优先），不用 FMA 与 fast-math，固定求和次序（总方案第 6 节、ADR 0019 §8）。`fl(·)` 表示一次舍入；零一律规范化为 +0；非有限结果是计算故障，按 V2-97 拒绝候选、保留旧状态。b 的递推按 §3.2 允许 IEEE 渐进下溢；其余路径的现行 `numeric` 下溢故障判定不变。

**判断不在 m 下做。** 本文用到的一切判断（解释 z、评估 a(e)、吻合 μ、依据身份与新颖性、时间关系）都在 m = 0 下得出并记入 H，重算与重放读记录，不重新判断（EV6、I23）。

## 3. D07-A：生活基线的共同折扣

**白话。** 她平常的心境由真正发生在她身上的事慢慢塑造。出生时给的起点像一笔最初的积蓄，每来一件真正的新经历，旧的积蓄和旧经历都按同样的比例让一点位置给新的一件；时间久了，起点几乎不再占份额。一段冷遇之后，如果日子恢复正常，冷遇的影响随新的日子淡去，她回到的是这些日子塑造的平常。代价：起点不再替她挡住反馈——她闷的时候别人冷淡，她可能会更闷，旧规律里出生先验减半反馈的那层缓冲没有了，只剩慢漂报警提醒开发方，不拉回她；单靠等待，她的平常心境不会自己变，冷遇之后如果再也没有新经历，也不会自己恢复。

### 3.1 合格经历与计量单位 ［新，沿已有登记冻结］

C 只在一个**合格外源经历**到来时推进一步；其余情况 C 返回不变，θ 与全部估计器状态逐位不变（LP5、AC2-05）。合格的条件全部沿已有决定，本文不重新定义：

| 条件 | 依据 |
| --- | --- |
| 来源类别能进入 C：冲着她来或回应她的外源事件与缺席事实；只关于 u* 的桌面观察、她的念头、行动与触发的程序结果、系统记录不进入 C | V2-71、V2-87、D21（ADR 0032 §3） |
| 同一次接触、同一段缺席只计一次，后续报告不增加计量；终端提高报告频率不增加可靠经历 | V2-72、V2-77 |
| 「发生」成立才合格；内容是否属实、是否主观按目标另判，不因此把其中的外界断言当真；撒谎引起的真实后果不因撒谎整段排除 | D13-A、D20-A（V2-142） |
| 评估 a(e) 在 m = 0 下得出并记录；A 缺失或结果未知时不伪造 a = 0，这一步不执行 | EV6、V2-115(3)、REPORT §2.2 |

每个合格经历的计量恒为 1（V2-96 的单位）。PROOFS P07-A 中一般的 q ≥ 0 只用于揭示充分条件，不批准连续可靠度打分或加权器。哪一类观察进入 C 的分类由上表的来源规则表与 P5-24/28/30 后继维护；本文消费分类结果，不改分类。

### 3.2 状态与递推 ［审：实数形式；新：规范次序］

θ 估计器状态（ADR 0029）新增一个标量 P：出生先验的当前质量，四通道共用，与现行共用的经历质量 S（`weight`）同构。genesis 时 P = P₀，S = 0，各通道有符号和 U_i（`reaction_sum`）= 0；其余初始化按 ADR 0029 现行次序。P₀ 沿用规律资源中的 n_b（`baseline_weight`），含义从「永久先验质量」改为「先验质量的初值」。

每个合格经历，在现行变点检测与 ĥ_θ 计算（V2-94，不变）之后，令 ρ = fl(1 − ĥ_θ)，按以下次序计算：

```text
S′   = fl(fl(ρ·S) + 1)                                  # 现行
P′   = fl(ρ·P)                                          # 新增；渐进下溢合法
对 i = 联结、共情、好奇、成事：
  r_i  = fl(a_i − b_i)                                  # 现行；b_i 为本步之前的已存值
  方差、σ̂、g、持续时间、λ 的递推                          # 现行，次序不变
  U_i′ = fl(fl(ρ·U_i) + a_i)                            # 现行算式；渐进下溢合法
  b_i′ = fl( fl( fl(P′·b₀,i) + U_i′ ) / fl(P′ + S′) )   # 改：P′ 取代固定的 n_b；积、和、商的渐进下溢合法
```

实数形式（PROOFS P07-A）：令 T = P + S，则 T′ = ρT + 1，

```text
b′ = b + (a − b)/T′，    出生份额 β = P/T，    β′ = (1 − 1/T′)·β
```

**下溢 ［新，回应 #138 审查阻塞 1］。** b 的整条递推——U′、P′、P′·b₀、分子、分母与商——按 IEEE 754 的渐进下溢计算：结果为次正规数或 +0 都是合法值，不是计算故障；非有限结果仍是故障。只放开乘法不够，P 进入次正规范围后最后的商也会下溢。审查给出的见证（只核对规范算术，不是运行参数）：q = 2^−1074，ρ = 1/2，本步前 P = 2q、S = 2、U = 1、b₀ = 1、b = 1/2，a = −1/2，则 P′ = q、S′ = 2、U′ = 0，分子 = q，分母 = 2，fl(q/2) = +0（最近偶数）。冻结 ρ = 1/2、从 P₀ = 1 出发可以走到这一步：前 1072 个 a 交替取 −1/2、+1/2，第 1073 个取 1 − ρU 使 U = 1，第 1074 个取 −1/2。

理由：β → 0 是 P07-A 的实数极限；把下溢判成故障，会让她在长期生活后因「先验已让位」而永久停止成长；补 ε、把 P 钉在最小正规数或截断成长，都是隐藏的永久锚定（REPORT §2.3「不能偷偷补 ε 或截断成长」）。分母 P′ + S′ ≥ 1，永不为零。ρ 的现行定义域 (0, 1) 与 ρ ∉ (0, 1) 时的故障判定不变。

**舍入误差界 ［新］。** 采用含下溢的标准舍入模型：每次运算 fl(x ∘ y) = (x ∘ y)(1 + ε) + η，|ε| ≤ u = 2^−53，|η| ≤ 2^−1075，ε·η = 0；加减的 η = 0（次正规范围的加减是精确的）。以本步已存的 P′、U′、S′ 计，令 N = P′·b₀,i + U′_i、T = P′ + S′（T ≥ 1），规范路径的 b′_i 满足

```text
|b′_i − N/T| ≤ γ₃·|N/T| + (1 + γ₃)·(u·P′ + 2^−1075) + 2^−1075，   γ₃ = 3u/(1 − 3u)
```

第一项来自分子加法、分母加法与商的相对舍入，第二项来自 P′·b₀ 的舍入（|b₀| ≤ 1、T ≥ 1），末项来自商的下溢。此界只覆盖由已舍入的 P′、U′、S′ 求 b′ 的路径；完整单步包络还须计入这三者的递推误差。上面的见证中 N/T = q/(2 + q)；分母舍入为 2 后，最终除法的精确商为 q/2，舍入到 +0 的误差正好是 2^−1075。V2-96 的外向包络（§3.4）在次正规范围同样有效：对每个乘、除计入 2^−1075 的绝对项，结果为 +0 时上界取最小正次正规数。

**未改的路径（如实记录）：** σ̂、方差与持续时间路径中的下溢仍按现行判故障，例如 |r| < 2^−537 时残差平方 r·r 下溢。这与 P 无关，旧版本同样存在，本文不改；见报告「后续建议」。

### 3.3 估计器的连带变化 ［审 + 新］

- **σ̂、g：** 公式与固定的 n_σ、σ₀ 先验不变（PROOFS P07-A「本卡只优先改 b」，D08 交 P5-63 版本对照）。残差 r = a − b_before 仍用本步之前的 b，但 b 的轨迹已改变，r、方差、g 的整段值随之不同，必须按新版本重算，不能沿用旧版本的数值或黄金向量。
- **λ：** V2-95 的运行时间、对数平均、零时长单计、未结束段不计全部不变；同号段的切分随 b 改变，τ̂ 与 λ 的整段值随之不同，同样只能重算。
- **ĥ_θ：** 检测器不变。ĥ_θ 的下限 ĥ_θ,min（`change_min`）的作用改变：旧规律用它使 n_b 与 1/ĥ_θ,min 相当、把反馈放大减半（v2.0 §8「调节」）；新规律中它给出有效记忆长度和下面的 α 下界。
- **未改的永久先验（如实记录）：** σ₀、τ₀ 的先验质量 n_σ、n_τ 仍固定，经历质量有界时它们保留有限份额。这属于 ADR 0032 D06「数值起点须让位」的待办，不由本文决定；登记见 V2-144。
- A_att 与 G 的规则不变。但 G 读取 b、σ̂（v2.0 §2.4），b 的轨迹改变后，R 的轨迹也可能不同，不能复用旧版本的 G、R 数值轨迹。

### 3.4 合法界：V2-96 重推 ［审：实数恒等式；新：带舍入的写法］

范围界不变：|Δb_i| ≤ 2，|Δg_i| ≤ g_max − g_min，|Δλ_i| ≤ λ_max − λ_min。单事件界中 b 的一项按新递推改为：设已存 b、P、S、U 的商缺陷 δ_i = (P·b₀,i + U_i) − b_i·(P + S)（实数），则下一步的理想未舍入值满足

```text
b_i′ − b_i = (ρ·δ_i + (a_i − b_i)) / (ρ·(P + S) + 1)
```

δ = 0 时这就是 P07-A 已审的形式；含 δ 的推广是本文的［新］写法。这是未舍入的一步值，规范递推另有本步舍入（§3.2 的误差界），由 P5-69 的外向包络覆盖。旧式中的 n_b(1 − ρ)(b₀ − b) 一项消失；照抄旧项会误报或漏报。σ̂、g 的单事件界保持 V2-96 原式（n_σ 固定），λ 随 V2-95。判定仍为严格大于才触发；浮点包络按现行 `bounds.rs` 的外向舍入方法改写（P5-69）；包络无法收紧时退回范围界，不构成故障（现行做法）。

### 3.5 性质与证明

1. **出生份额让位。** ［审］β′ = (1 − α)β，α = 1/T′ ∈ (0, 1]；Σα = ∞ 时 β → 0。单位计量下 T_n ≤ P₀ + n，故 β_n ≤ P₀/(P₀ + n)。［新］现行 ĥ_θ ≥ ĥ_θ,min > 0 给出 ρ ≤ 1 − ĥ_θ,min，于是 T_n ≤ max(P₀, 1/ĥ_θ,min)，α_n ≥ α_min := min(1/P₀, ĥ_θ,min) > 0，β_n ≤ (1 − α_min)^n，按合格经历数几何让位。这里的 n 是实际合格经历的累计数，不是预设的成熟次数；时间本身不推进它。［新，浮点极限］实数的 β → 0 是机制结论，不是一切浮点路径的严格极限。P 非增；若 1 − ρ > 2^−53，P 在正规范围内每步严格减小。边界 ρ = 1 − 2^−53、P = 2^−1022 时，fl(ρP) = P。正次正规 P = k·q 的下一步是将 ρk 舍入到最近整数再乘 q：P 不变当且仅当 (1 − ρ)k < 1/2，或等号成立且 k 为偶数；等号且 k 为奇数时降到 (k − 1)q。例如 fl(q/2) = +0，fl((3/4)·2q) = 2q，fl((3/4)·q) = q。停住后，某步 ρ 更小时才可能继续减小或到 +0。停住时 P ≤ q/(2(1 − ρ))，出生项对 b 的作用不超过 2P。这是有限精度的残余，不是永久锚定的语义，也不补 ε 去消除它；P5-69 的 oracle 分开报告实数结论与有限精度包络。
2. **没有新经历就不变。** ［审］C 不被调用或返回不变，P、S、U、b 与全部估计器逐位不变（LP5、AC2-05）。等待只经 Φ 投影 x。
3. **同一生活、不同出生值。** ［审］同一 a、ρ 序列下 b_n − b̃_n = β_n(b₀ − b̃₀) → 0。ρ 依赖残差时两条路径不再共享 ρ，先做冻结输入的机制诊断，再做端到端比较。
4. **有限扰动在相同后续生活下消退。** ［审］从扰动结束起 δb_n = δb_m ∏(1 − α_j)；由第 1 条，乘积几何趋零。参照是同源对照下后续生活决定的轨迹，不是 b₀。没有未来经历、或扰动改变了以后的社交历史与保留率时，这个比较不成立，不得补计时回拉器。
5. **反馈世界的适用域。** ［审］一维线性合成世界 a_n = c + k·b_{n−1}（不触发输入边界，即 |c| + |k| ≤ 1）中，b_n − b* = [1 − α_n(1 − k)](b_{n−1} − b*)，b* = c/(1 − k)。［新］对 −1 < k < 1 与 α_n ∈ [α_min, 1]，因子的绝对值不超过 max(|k|, 1 − α_min(1 − k)) < 1，几何收敛到 b*，与 b₀ 无关；|c| < 1 − k 时 b* 在盒内。新旧比较只在正反馈（0 < k < 1）下成立：旧规律的 k_eff = k·S/(n_b + S) 因出生先验而小于 k，不动点也被拉向 b₀；新规律的有效反馈强度就是 k，不动点就是世界决定的 c/(1 − k)，对世界偏向的放大是 1/(1 − k) 而不是较小的 1/(1 − k_eff)：世界偏向一侧时，新规律更容易贴边。负反馈时方向相反，例如 k = −1/2、S = n_b = 1 时 k_eff = −1/4 > k，新规律的放大系数 2/3 小于旧的 4/5；收敛结论不受影响。k ≥ 1、越出线性域、世界不平稳时没有保证。**［未证］** 真实闭环（b → x → 行为 → 他人回应 → a）不是线性标量模型，本文不证明它的收敛或不贴边；后果：AC2-25 只能在预登记、实测过的反馈域内签发（§8 V2-145），域外贴边如实报告并由慢漂检查报警（V2-97），不是计算故障，也不拉回。承接：P5-76 闭环、P5-30 校准。
6. **增量与整段重算逐位一致。** ［新］新递推仍是唯一的逐事件规范次序，整段重算重放同一递推（I23、AC2-08）；暂停与补算（AC2-18）、来源更正（AC2-19）沿现行重算路径。来源更正后按「这些证据从未出现」重算，P 随之取对应的值，这是正确结果，不是先验异常复活。

## 4. D09+D10-A 与截断归属 A1：依据替换

**白话。** 一件事在她心里只占一个位置。想起一件伤心事，她可以再难过起来——想起时把这个位置补回到它本来的分量；但反复想、换个说法想、换一种语言想，都不会让难过一次比一次深。真正新的发现仍然能触动她。没有新事时，她的心情按原来的速度平复，不会因为心里记着很多事而在高处多停一会儿。代价：两件开心事接连发生、心情已经到顶时，第二件当时只能占剩下的一点；等心情回落一些再想起它，它可能留下比第一次更多的分量——先后顺序会影响以后回想时的分量。发现某件事是假的时，那份感受不会被立刻扣掉，只会自然淡去，之后想起它也不再补回原来的分量。没有出处的空想共用一个位置：新的空想替换旧的空想，不叠加。被摸得久一点时，她的感受取决于实际摸了多久、她怎么看待这段时长，不取决于终端报告发了几条。如果当初是机器把一件事理解错了，修正之后她再想起它时，按正确的理解去感受。

### 4.5 事件作用：A1 的规范 binary64 形式 ［审：实数定义；新：分支形式］

对依据 c 的每个坐标，前态为推进后的 x 与 h（即 h_c），目标为 v：

```text
d = fl(v − h)
s = fl(x + d)
若 −1 < s < 1：  x⁺ = s；   h⁺ = v
若 s ≥ 1：       x⁺ = 1；   t = fl(h + fl(1 − x))
若 s ≤ −1：      x⁺ = −1；  t = fl(h + fl(−1 − x))
```

**［新］binary64（对一切有限输入，x ∈ [−1, 1]，零已规范化）：**

- B1 无事件时 x 逐位等于现行 Φ：x 的推进不读槽（构造）。
- B2 Δ = 0 的推进对 x 与每个槽逐位恒等：λ·0 = +0，pull = −expm1(−0) = +0，h + (+0)·(−h) = h；h = +0 时结果仍为 +0。
- B3 槽推进不放大、不变号：pull ∈ [0, 1]，舍入单调，|fl(pull·h)| ≤ |h|，故 h′ 与 h 同号或为 +0，|h′| ≤ |h|。
- B4 新依据首次作用逐位等于旧 F：h = +0 时 d = v 精确，s = fl(x + v)，三个分支给出的 x⁺ 都等于 clip(s)。
- B5 同一前态、同一目标的重复作用逐位恒等。设第一次结果为 (x⁺, h⁺)：
  - 不饱和：结果 (s, v)；第二次 d = fl(v − v) = +0，s 不变，仍不饱和，结果相同。
  - 上饱和且 v ≥ h：h⁺ ≤ max(h, v) = v，故 fl(v − h⁺) ≥ +0，fl(1 + d) ≥ 1，仍上饱和；t = fl(h⁺ + fl(1 − 1)) = h⁺，夹取后仍为 h⁺。
  - 上饱和且 v < h：d < 0，s = 1 只能来自 x + d ∈ [1 − 2^−54, 1)；区间 (1 − 2^−54, 1] 里唯一的 binary64 是 1，所以 x = 1、t = h，夹到 [v, h] 得 h——第一次就是恒等。
  - 下饱和对称。
  - 朴素写法 h⁺ = fl(h + fl(x⁺ − x)) 不满足：x = 0.44103831552214、h = −0.07324038289205337、v = 0.0002230830984472614（十进制往返表示）时，第一次得 x⁺ = 0.5145017815126407，同一目标再作用一次得 0.5145017815126406。所以规范形式必须用上面的分支。

- B6′ 目标更新与合并的合法域 ［新，回应 #138 审查阻塞 3］：**实数历史区间** I_c 从 [0, 0] 起；每记录一个目标 v，就扩到包含 v 的最小区间；合并时取成员区间之和（端点分别相加）。实数 h_c 始终在 I_c 内：A1 的结果落在 h 与 v 之间，推进向 0 收缩，且 0 ∈ I_c。无合并时，I_c 是 0 与历来各目标张成的区间，|h_c| 不超过历来目标幅度的最大值；合并时，实数幅度界取各成员区间内最大绝对值之和。这是历史界，不是当前目标界：R4 中把第二个目标改为 0 后 h₂ = −1；再合并第一、第三个槽得到 h = 2、目标为 1，两种状态都合法。
  **binary64 包络** Ĩ_c 的初始化、目标扩张同上；合并按 §4.7 的实际求和次序，逐步取 [fl(L₁ + L₂), fl(U₁ + U₂)]。舍入单调，故该区间包含规范合并后的 h；之后的目标更新、推进与再次合并沿用此包络。端点溢出可取对应的 ±∞（仅证明/测试；实际非有限状态仍按 §2 拒绝）。例如 0.1、0.2 两个 binary64 目标的槽合并后 h = 0.30000000000000004，属于浮点包络，不能用精确实数区间拒绝。I_c、Ĩ_c 都不进入状态或契约。
- B7 各坐标恰为 +0 的槽可以移除：推进保持 +0，其他依据的作用不读它，重建时从 +0 开始、目标从 H 的作用记录取回。把缺失的槽补零后，数值状态与之后的全部输出逐位等价；这不是说有槽与无槽两份快照的序列化字节相同。

**［未证］：**

- U1 binary64 下的分解：B5 不饱和分支令 h⁺ = v，而 x 的实际变化是舍入后的 fl(x + d) − x，差额落在派生的 y 里，所以 x = y + Σh 只在实数意义下成立。y 不存不读，不影响她；后果是测试用有理数 oracle 验分解，浮点残差分开报告（EXPERIMENTS E09 的有限 binary64 分层）。
- U2 binary64 下 d_◇ 非扩张没有证明，舍入可能造成最低位级的违反。后果：AC2-15/I05 对扩展状态用有理数 oracle 或带舍入包络比较，不断言逐位不等式；现行只看 x 的 I05 检查，只在两条轨迹的槽相同时继承（P09：只有初始 h 相同时 d_◇ 才等于可见 x 的距离）。
- U3 任意多依据的重访序列下，总 x 峰值不保证单调不增（P09 已说明）；整个认知闭环不「越想越激动」没有证明。承接 P5-76、P5-77。

### 4.7 更正、别名、容量与维数变化 ［新：待确认的读法］

### 4.8 迁移 ［新］

- 旧版本快照（`FastStateSnapshotV2`，只有 x）迁移到新表示：x 与锚点逐位不变，槽集合为空。迁移写一条记录（L 与 H 的系统记录），声明「迁移前依据的分解未知」，不声称无损（PROOFS P09：不能猜一个分摊，也不能清零后宣称兼容）。

- 正式谱系尚未诞生；genesis 若采用新版本，正式谱系不需要此迁移（§2）。

## 5. D11-A：按发生与观察判资格，理解时一次作用

**白话。** 她做完一件事，结果回来时机器正忙，等忙完才处理到，她仍然会为这个结果高兴或难过——排队不会让她「错过」。决定这件事对她意味着什么的，是它什么时候发生、她什么时候知道：今天才知道朋友上周难过、现在已经好了，她对「今天得知旧事」的反应可以不同于朋友正在受苦，但不会假装上周就已经知道。代价：机器慢，她的反应就晚；一批回执积压后一起到，她可能一下子有比较集中的反应。执行许可照旧：凭证过期就不能再去做那件事；已经做完的事，回执晚到照样记下来、照样能触动她。

### 5.1 时间事实 ［审：REPORT §4.2、P11；新：与 F 的接口］

| 时间 | 含义 | 能证明 | 不能替代 |
| --- | --- | --- | --- |
| 发生 | 事情在何时发生 | 某来源声称或可信执行器记录的发生 | 远端自报只是带来源的断言，不能证明按时 |
| 观察 | 哪个观察者何时取得哪些内容 | 实际取得 | 入口接收不是一切事件的观察时间；机器取得不等于她已理解 |
| 入口接收 | 本入口持久接纳记录（现有 `ingest_time_ns`） | 本地接收 | 不能推出远端发生或此前的观察 |
| 处理 | 本次解释与提议一次捕获的处理时点（现有 `process_time_ns`） | 解释用的时点 | 不是资格截止 |
| 理解提交 | 本次 F 作用随之生效的事务时刻 | 作用何时生效 | 不回写发生时刻；权威持久化由 P5-52 补齐 |
| 凭证期限 | 执行许可的边界 | 哪次、哪一载荷、哪一权限下可以执行 | 不决定已发生的结果值不值得感受 |

每个时间事实带来源、时钟域与 epoch（复用 P5-52）、可比性和未知（区间或未知）；字段由 P5-72 定义，本文不发布字段号。时间只给出区间时，语义关系在所有可行取值上判断：全部满足才为真，全部不满足才为假，其余为未知；不设任意容差（P11）。不同 epoch 只有经可信映射才可比较，否则关系为未知。时钟的结构故障仍走原路径（m = 0、不主动、只回应）。

### 5.2 资格与一次作用 ［审：REPORT §4.3；新：精确规则］

- **资格**由三者决定：记录类别（V2-71、V2-87）、§4.2 的 F 角色、本次用到的消费键尚未消费。资格不读入口、处理、提交时刻或它们的差，不设心理时效。
- 发生与观察的关系是 z 的一部分，A、M 在 m = 0 下据此判断意义（过去发生、仍在发生、今天才知道）；入口、处理、排队的时刻不进入 z，不能把排队当成事实差别。
- **分阶段的消费键 ［新，回应 #138 审查阻塞 2］：** 消费键是（记录身份，阶段）。记录身份是这一份记录本身：终端记录的 `stable_source_key`、行动结果的执行结果身份（action_id 与执行实例）、内部记录的提交身份。阶段有三种：「接纳」「A」「M」；A、M 分别是 D(e) 中依赖 a(e) 与 μ 的部分（V2-115(3)）。依据身份不进入消费键：共享依据只决定作用落在哪个槽，不使同一依据下其他记录的目标更新或重访失格。每个消费键至多作用一次；消费标记与 H 的作用记录、Q 的状态在同一原子提交中发布。四种边界：

| 情形 | 用到的消费键 | 是否进入 F |
| --- | --- | --- |
| 传输重发：同一记录再到 | 与原记录相同，已消费 | 不进入 |
| 首次接纳 | (r, 接纳)，以及当时已有效的 (r, A)、(r, M) | 按 §4.2 的角色作用一次，只用已有效的部分（例如 A 缺失时只有 f_k） |
| 首次有效补解释：r 的 A 或 M 第一次有效 | 尚未消费的 (r, A) 或 (r, M) | 只在 r 的角色用它自己的目标（新依据、目标更新、内部支路），且依据的现行目标仍来自 r 时，按「目标更新」补足（§4.3），不再发一份。角色为重访的记录，自身解释不定目标，不进入 F；依据的目标已被更晚的记录改过时，只记入 H、不进入 F，不回退到较旧的评估 |
| 合法重访：另一条记录 r′ 引用依据 c | r′ 自己的键 | 进入，重访 c；与 c 原记录的消费键无关 |

  同一部分的补解释重发用的是已消费的键，不进入；同一次接触、同一段缺席的每条后续报告各用自己的键，作目标更新；解释器修订不产生消费键，不进入 F（§4.7）。记录的角色在它首次作用的提交中确定，之后的补解释只补足部分、不改角色；先前缺失的解释不算已经产生过有效驱动（P11）。
- **取代卡面读法：** P5-72 卡面写「与 P5-68 的贡献身份一致（原事件、补解释、回想共用）」，这是拆卡时写的，不是用户决定。本文取代这一读法：三者共用的是依据身份，不是消费键。卡面文字由派卡方另行修改，登记见 V2-148。表示交 P5-72，消费键与 P5-68 的依据身份互相引用。
- 新版本删除 ADR 0026 §6.3 的结果期限 τ 及「超期结果记入 H 但不经 F」的分支，不恢复旧 τ 丢弃（[P5-08 时间语义请求](../../tasks/requests/P5-08-result-time-semantics.md)）。

### 5.3 未知发生时间、跨 epoch 与重复回执

- **未知发生时间：** 不妨碍「现在收到这个结果」被记录、评估并按角色作用；不能推出「按时完成」或「当时仍在发生」。资格不读时间，时间未知不能取消资格。
- **跨 epoch：** 没有可信映射时跨 epoch 的时间关系为未知；F 的作用次序永远按 H 的提交次序，不按时钟。
- **重复回执：** 同一消费键至多作用一次。［新，条件证明］若作用记录与消费标记在同一原子提交中发布，任何已提交状态要么二者都有、要么都没有；重复到达先查已提交的消费键，不会第二次作用；崩溃在提交前则二者都没有，恢复后重新处理仍只作用一次。同一记录因此至多在接纳、A、M 三个阶段各作用一次，后两次都是对同一依据的目标更新，替换而不叠加。前提是稳定的消费键、单写者串行检查与提交，即 P5-72 的消费键合同和 P5-73、P5-75 的原子发布（COG-A09）；前提实现之前它是条件证明。
- **旧结果与新 Q 交错：** 结果照常记录、照常有资格；不覆盖已接受新输入的 Q，不发布旧计划（COG-A03、ADR 0026 §6.6）；UNKNOWN 不盲目重发（X04）。

### 5.4 执行边界不变

凭证到期照常拒绝新执行；此前已合法执行的结果晚到照常记录、照常有资格（ADR 0032 §7）。执行层的超时与资源上限只证明调度与副作用安全，不能借来恢复心理时效（P11）。

### 5.5 性质与证明

- ［审］同一 z、同一权威前态与同一解释下只改变调度：资格不变，本次获准的原始驱动相同（P11）。
- ［审］迟到作用与「立即作用后等待」一般不等价：无截断时差 (1 − r)d；补成衰减脉冲也因盒投影不交换（P11 的反例）。所以不承诺不同调度下的轨迹相同。
- ［新］资格不读任何时间事实，时间未知或跨 epoch 不可比都不能改变资格（由构造）。
- ［新，条件］同一消费键至多一次作用；同一记录至多在三个阶段各作用一次，后两次是替换（§5.2、§5.3）。
- ［未证］时间来源可信与 epoch 映射正确（P5-52、P5-72）；发生时间等判断的质量（P5-77）；真实时间下的体验（P5-73 的真实时间测量）。

### 5.6 被取代

- ADR 0026 §6.3 的结果期限 τ、COG-09/10/11 的期限部分、V2-115(3)「超期的行动结果不调用 F」、COG-A12 的队列期限部分。
- ADR 0026 §6.3 的有限在途尾部证明 T_ret = B_N + τ + ln(4/ε)/λ_min：它的前提（κ^n 递减、每轮至多 r 个行动、至多 M 个在途、期限 τ）在新版本中不成立，证明不迁移；新版本不提供「最后外源事件后统一回落」的替代保证（ADR 0032 §5）。保留的是：停止全部 F 作用后按原 Φ 平复（R1、B1），固定目标下单个依据的贡献有界（B6）。R-KAPPA-01 的晚期新结果反例保留。
- r、M、τ 不再是规律版本的校准资源（V2-100 中这三项只适用于旧版本）。执行层是否保留资源上限由 ADR 0033 的后继卡决定，且不能作为 F 资格。

6. §4.2：原事件与第一次回想不双算——「原事件向 y 加一份、回想再向 h 发一份」的变异必须失败；以给定依据身份构造的改写、换语言、换 action_id 不新增贡献；内部支路只有一个槽；多依据重访按首次作用先后。
7. §4.3：θ、R 变化后重访仍用已记录目标；补解释、修订与同一次接触或同一段缺席的后续报告更新目标；R⁺ 维数变化时目标与槽的对齐。
8. §4.7：依据失效不作用；别名合并不改 x；只在全零时移除槽，移除不改变之后任何一位；解释器修订提交本身不改变 x 与槽，修订前的重访用旧目标，修订后第一次重访用确定现行目标那条记录的新解释，配首次作用时记录的前态（目标经目标更新改过的，配最近一次目标更新时记录的前态），修订后的目标更新用本条记录在当前解释器版本下的解释、配本次提交的当前前态。
9. §4.8：旧快状态迁移后 x 与锚点逐位不变，槽为空，带迁移记录。
10. AC2-15、I05 分项（§8）：固定目标的 d_◇ 非扩张（有理数 oracle）、槽相同的两条轨迹的同驱动比较、无输入 Φ（B1）、扩展状态表示；只看 x 的旧检查只在槽相同时使用。新版本没有 κ^n、没有定时强制平复；旧版本照常重放。
11. 同一次接触（同一 `contact_id`）、同一段缺席（§4.2，用户 2026-11-05 决定）：后续报告作目标更新，不建新槽；不同 `contact_id` 的接触各建新槽。节奏试验冻结生成目标所需的完整输入——每条报告的 a、μ、涉及的人与 w，以及前态 θ 与 R⁺ 的作用视图——使每条报告的目标逐位相同；在此前提下改变报告节奏（更密、更疏），h 每个坐标都在 0 与这个目标之间（B6），不叠加超过一份目标。另测目标的合法变化（已持续时长改变评估、前态变化）：h 落在 B6′ 的历史区间内，不随报告条数叠加，不断言不超过当前目标。
12. 解释器修订的前态序列（V2-147）：首次作用（前态记为 θ₀）→ 两次目标更新（θ₁、θ₂）→ 解释器修订 → 重访 → 再次目标更新（θ₃），这里 θ 指完整前态（θ 与 R⁺ 的作用视图）。核对：修订提交不改 x 与槽；重访用第二次目标更新那条记录的新解释配 θ₂，不是 θ₀ 或 θ₁；之后的目标更新用本条记录在当前解释器版本下的解释配 θ₃；每一步引用的解释记录与前态引用都能在 H 中查到。

## 11. 后果

- 合并即批准三项规律的上述定义、§6 中其余待确认读法与 §9 的验收条款（第 3 项中同一次接触与同一段缺席的部分、第 8 项已由用户 2026-11-05 决定）；某项读法不获批准时修订本 ADR，实现卡不得自行改选。
- 批准前与实现前，运行行为不变；旧规律版本、旧测试、旧黄金向量与旧失败证据全部保留。
- 已知风险：正反馈世界中更快贴边（只报警，不拉回）；积压回执带来集中反应；依据身份判定错误会削弱或误伤「重复不加码」；活槽数随依据数增长。
- 未证项由 §6 所列的卡承接；本文不签发任何机制、行为或正式验收的通过结论。
