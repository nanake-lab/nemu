## 2. 共同约定

**规律版本。** 三项规律一起发布为一个新规律版本，记为 𝔏_ADR0035，与现行版本并存。旧版本保持可重放（v2.0 §5.4、I23）；一条谱系用哪个版本由 genesis 或显式的版本切换记录决定，不在运行中静默切换。版本切换时，R、θ 按新版本从 H 重算（v2.0 §5.4）；快状态按 §4.8 迁移。诞生尚未发生：若 genesis 直接采用新版本，正式谱系没有旧状态需要迁移；迁移只涉及排练与实验谱系，以及将来的版本切换。

**数值。** 有限 binary64，舍入到最近（偶数优先），不用 FMA 与 fast-math，固定求和次序（总方案第 6 节、ADR 0019 §8）。`fl(·)` 表示一次舍入；零一律规范化为 +0；非有限结果是计算故障，按 V2-97 拒绝候选、保留旧状态。本文明确允许下溢的两处（§3.2）除外，现行 `numeric` 的下溢故障判定不变。

**判断不在 m 下做。** 本文用到的一切判断（解释 z、评估 a(e)、吻合 μ、依据身份与新颖性、时间关系）都在 m = 0 下得出并记入 H，重算与重放读记录，不重新判断（EV6、I23）。

## 3. D07-A：生活基线的共同折扣

**白话。** 她平常的心境由真正发生在她身上的事慢慢塑造。出生时给的起点像一笔最初的积蓄，每来一件真正的新经历，旧的积蓄和旧经历都按同样的比例让一点位置给新的一件；时间久了，起点几乎不再占份额。一段冷遇之后，如果日子恢复正常，冷遇的影响随新的日子淡去，她回到的是这些日子塑造的平常。代价：起点不再替她挡住反馈——她闷的时候别人冷淡，她可能会更闷，旧规律里出生先验减半反馈的那层缓冲没有了，只剩慢漂报警提醒开发方，不拉回她；单靠等待，她的平常心境不会自己变，冷遇之后如果再也没有新经历，也不会自己恢复。

### 3.1 合格经历与计量单位 ［新，沿已有登记冻结］

C 只在一个**合格外源经历**到来时推进一步；其余情况 C 返回不变，θ 与全部估计器状态逐位不变（LP5、AC2-05）。合格的条件全部沿已有决定，本文不重新定义：

| 条件 | 依据 |
| --- | --- |
| 来源类别能进入 C：冲着她来或回应她的外源事件与缺席事实；只关于 u* 的桌面观察、她的念头、行动与触发的程序结果、系统记录不进入 C | V2-71、V2-87、D21（ADR 0032 §3） |
| 同一次接触、同一段缺席只计一次，后续报告不增加计量；终端提高报告频率不增加可靠经历 | V2-72、V2-77 |
| 「发生」成立才合格；内容是否属实、是否主观按目标另判，不因此把其中的外界断言当真；撒谎引起的真实后果不因撒谎整段排除 | D13-A、D20-A（V2-142） |
| 评估 a(e) 在 m = 0 下得出并记录；A 缺失或结果未知时不伪造 a = 0，这一步不执行 | EV6、V2-115(3)、REPORT §2.2 |

每个合格经历的计量恒为 1（V2-96 的单位）。PROOFS P07-A 中一般的 q ≥ 0 只用于揭示充分条件，不批准连续可靠度打分或加权器。哪一类观察进入 C 的分类由上表的来源规则表与 P5-24/28/30 后继维护；本文消费分类结果，不改分类。

### 3.2 状态与递推 ［审：实数形式；新：规范次序］

θ 估计器状态（ADR 0029）新增一个标量 P：出生先验的当前质量，四通道共用，与现行共用的经历质量 S（`weight`）同构。genesis 时 P = P₀，S = 0，各通道有符号和 U_i（`reaction_sum`）= 0；其余初始化按 ADR 0029 现行次序。P₀ 沿用规律资源中的 n_b（`baseline_weight`），含义从「永久先验质量」改为「先验质量的初值」。

每个合格经历，在现行变点检测与 ĥ_θ 计算（V2-94，不变）之后，令 ρ = fl(1 − ĥ_θ)，按以下次序计算：

```text
S′   = fl(fl(ρ·S) + 1)                                  # 现行
P′   = fl(ρ·P)                                          # 新增；允许下溢
对 i = 联结、共情、好奇、成事：
  r_i  = fl(a_i − b_i)                                  # 现行；b_i 为本步之前的已存值
  方差、σ̂、g、持续时间、λ 的递推                          # 现行，次序不变
  U_i′ = fl(fl(ρ·U_i) + a_i)                            # 现行
  b_i′ = fl( fl( fl(P′·b₀,i) + U_i′ ) / fl(P′ + S′) )   # 改：P′ 取代固定的 n_b；乘积允许下溢
```

实数形式（PROOFS P07-A）：令 T = P + S，则 T′ = ρT + 1，

```text
b′ = b + (a − b)/T′，    出生份额 β = P/T，    β′ = (1 − 1/T′)·β
```

**下溢。** P′ 与 P′·b₀,i 两处乘法允许按 IEEE 渐进下溢得到次正规数或 +0，不是计算故障；P 到 +0 后保持 +0。理由：β → 0 是 P07-A 的实数极限；T′ ≥ 1，出生项对 b 的作用不超过 2P，P 进入次正规范围时这个上界小于 2^−1021；把它判成故障会让她在长期生活后因「先验已让位」而永久停止成长，补 ε 或把 P 钉在最小正规数则是隐藏的永久锚定（REPORT §2.3「不能偷偷补 ε 或截断成长」）。分母 T′ ≥ 1，永不为零。ρ 的现行定义域 (0, 1) 与 ρ ∉ (0, 1) 时的故障判定不变。

### 3.3 估计器的连带变化 ［审 + 新］

- **σ̂、g：** 公式与固定的 n_σ、σ₀ 先验不变（PROOFS P07-A「本卡只优先改 b」，D08 交 P5-63 版本对照）。残差 r = a − b_before 仍用本步之前的 b，但 b 的轨迹已改变，r、方差、g 的整段值随之不同，必须按新版本重算，不能沿用旧版本的数值或黄金向量。
- **λ：** V2-95 的运行时间、对数平均、零时长单计、未结束段不计全部不变；同号段的切分随 b 改变，τ̂ 与 λ 的整段值随之不同，同样只能重算。
- **ĥ_θ：** 检测器不变。ĥ_θ 的下限 ĥ_θ,min（`change_min`）的作用改变：旧规律用它使 n_b 与 1/ĥ_θ,min 相当、把反馈放大减半（v2.0 §8「调节」）；新规律中它给出有效记忆长度和下面的 α 下界。
- **未改的永久先验（如实记录）：** σ₀、τ₀ 的先验质量 n_σ、n_τ 仍固定，经历质量有界时它们保留有限份额。这属于 ADR 0032 D06「数值起点须让位」的待办，不由本文决定；登记见 V2-144。
- A_att、G 与 R 不受 D07-A 影响。

### 3.4 合法界：V2-96 重推 ［审：实数恒等式；新：带舍入的写法］

范围界不变：|Δb_i| ≤ 2，|Δg_i| ≤ g_max − g_min，|Δλ_i| ≤ λ_max − λ_min。单事件界中 b 的一项按新递推改为：设已存 b、P、S、U 的商缺陷 δ_i = (P·b₀,i + U_i) − b_i·(P + S)（实数），则

```text
b_i′ − b_i = (ρ·δ_i + (a_i − b_i)) / (ρ·(P + S) + 1)
```

旧式中的 n_b(1 − ρ)(b₀ − b) 一项消失；照抄旧项会误报或漏报。σ̂、g 的单事件界保持 V2-96 原式（n_σ 固定），λ 随 V2-95。判定仍为严格大于才触发；浮点包络按现行 `bounds.rs` 的外向舍入方法改写（P5-69）；包络无法收紧时退回范围界，不构成故障（现行做法）。

### 3.5 性质与证明

1. **出生份额让位。** ［审］β′ = (1 − α)β，α = 1/T′ ∈ (0, 1]；Σα = ∞ 时 β → 0。单位计量下 T_n ≤ P₀ + n，故 β_n ≤ P₀/(P₀ + n)。［新］现行 ĥ_θ ≥ ĥ_θ,min > 0 给出 ρ ≤ 1 − ĥ_θ,min，于是 T_n ≤ max(P₀, 1/ĥ_θ,min)，α_n ≥ α_min := min(1/P₀, ĥ_θ,min) > 0，β_n ≤ (1 − α_min)^n，按合格经历数几何让位。这里的 n 是实际合格经历的累计数，不是预设的成熟次数；时间本身不推进它。
2. **没有新经历就不变。** ［审］C 不被调用或返回不变，P、S、U、b 与全部估计器逐位不变（LP5、AC2-05）。等待只经 Φ 投影 x。
3. **同一生活、不同出生值。** ［审］同一 a、ρ 序列下 b_n − b̃_n = β_n(b₀ − b̃₀) → 0。ρ 依赖残差时两条路径不再共享 ρ，先做冻结输入的机制诊断，再做端到端比较。
4. **有限扰动在相同后续生活下消退。** ［审］从扰动结束起 δb_n = δb_m ∏(1 − α_j)；由第 1 条，乘积几何趋零。参照是同源对照下后续生活决定的轨迹，不是 b₀。没有未来经历、或扰动改变了以后的社交历史与保留率时，这个比较不成立，不得补计时回拉器。
5. **反馈世界的适用域。** ［审］一维线性合成世界 a_n = c + k·b_{n−1}（不触发输入边界，即 |c| + |k| ≤ 1）中，b_n − b* = [1 − α_n(1 − k)](b_{n−1} − b*)，b* = c/(1 − k)。［新］对 −1 < k < 1 与 α_n ∈ [α_min, 1]，因子的绝对值不超过 max(|k|, 1 − α_min(1 − k)) < 1，几何收敛到 b*，与 b₀ 无关；|c| < 1 − k 时 b* 在盒内。旧规律的 k_eff 因出生先验而小于 k，新规律的有效反馈强度就是 k：同一个世界里，新规律的不动点离中心更远，贴边更早。k ≥ 1、越出线性域、世界不平稳时没有保证。**［未证］** 真实闭环（b → x → 行为 → 他人回应 → a）不是线性标量模型，本文不证明它的收敛或不贴边；后果：AC2-25 只能在预登记、实测过的反馈域内签发（§8 V2-145），域外贴边如实报告并由慢漂检查报警（V2-97），不是计算故障，也不拉回。承接：P5-76 闭环、P5-30 校准。
6. **增量与整段重算逐位一致。** ［新］新递推仍是唯一的逐事件规范次序，整段重算重放同一递推（I23、AC2-08）；暂停与补算（AC2-18）、来源更正（AC2-19）沿现行重算路径。来源更正后按「这些证据从未出现」重算，P 随之取对应的值，这是正确结果，不是先验异常复活。

### 3.6 迁移

θ 是 H 在规律下的确定函数（v2.0 §2.2），换到新版本即从 H 按新版本重算 θ（v2.0 §5.4）；不能把旧快照的 S、U 接上一个猜出来的 P 继续算。旧版本快照（ADR 0029 的 `ThetaSnapshotV2`）只按旧版本读取与重放，不能直接恢复成新版本的可运行状态。切换造成的 θ 变化写入 L，按 V2-97 照常应用并报警。排练谱系 G、C 恒等，θ 就是 genesis，切换不产生变化。
