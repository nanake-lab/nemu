## 2. 共同约定

**规律版本。** 三项规律一起发布为一个新规律版本，记为 𝔏_ADR0035，与现行版本并存。旧版本保持可重放（v2.0 §5.4、I23）；一条谱系用哪个版本由 genesis 或显式的版本切换记录决定，不在运行中静默切换。版本切换时，R、θ 按新版本从 H 重算（v2.0 §5.4）；快状态按 §4.8 迁移。诞生尚未发生：若 genesis 直接采用新版本，正式谱系没有旧状态需要迁移；迁移只涉及排练与实验谱系，以及将来的版本切换。

**数值。** 有限 binary64，舍入到最近（偶数优先），不用 FMA 与 fast-math，固定求和次序（总方案第 6 节、ADR 0019 §8）。`fl(·)` 表示一次舍入；零一律规范化为 +0；非有限结果是计算故障，按 V2-97 拒绝候选、保留旧状态。本文明确允许下溢的两处（§3.2）除外，现行 `numeric` 的下溢故障判定不变。

**判断不在 m 下做。** 本文用到的一切判断（解释 z、评估 a(e)、吻合 μ、依据身份与新颖性、时间关系）都在 m = 0 下得出并记入 H，重算与重放读记录，不重新判断（EV6、I23）。

## 3. D07-A：生活基线的共同折扣

**白话。** 她平常的心境由真正发生在她身上的事慢慢塑造。出生时给的起点像一笔最初的积蓄，每来一件真正的新经历，旧的积蓄和旧经历都按同样的比例让一点位置给新的一件；时间久了，起点几乎不再占份额。一段冷遇之后，如果日子恢复正常，冷遇的影响随新的日子淡去，她回到的是这些日子塑造的平常。代价：起点不再替她挡住反馈——她闷的时候别人冷淡，她可能会更闷，旧规律里出生先验减半反馈的那层缓冲没有了，只剩慢漂报警提醒开发方，不拉回她；单靠等待，她的平常心境不会自己变，冷遇之后如果再也没有新经历，也不会自己恢复。

### 3.1 合格经历与计量单位 ［新，沿已有登记冻结］

C 只在一个**合格外源经历**到来时推进一步；其余情况 C 返回不变，θ 与全部估计器状态逐位不变（LP5、AC2-05）。合格的条件全部沿已有决定，本文不重新定义：

| 条件 | 依据 |
| --- | --- |
| 来源类别能进入 C：冲着她来或回应她的外源事件与缺席事实；只关于 u* 的桌面观察、她的念头、行动与触发的程序结果、系统记录不进入 C | V2-71、V2-87、D21（ADR 0032 §3） |
| 同一次接触、同一段缺席只计一次，后续报告不增加计量；终端提高报告频率不增加可靠经历 | V2-72、V2-77 |
| 「发生」成立才合格；内容是否属实、是否主观按目标另判，不因此把其中的外界断言当真；撒谎引起的真实后果不因撒谎整段排除 | D13-A、D20-A（V2-142） |
| 评估 a(e) 在 m = 0 下得出并记录；A 缺失或结果未知时不伪造 a = 0，这一步不执行 | EV6、V2-115(3)、REPORT §2.2 |

每个合格经历的计量恒为 1（V2-96 的单位）。PROOFS P07-A 中一般的 q ≥ 0 只用于揭示充分条件，不批准连续可靠度打分或加权器。哪一类观察进入 C 的分类由上表的来源规则表与 P5-24/28/30 后继维护；本文消费分类结果，不改分类。

### 3.2 状态与递推 ［审：实数形式；新：规范次序］

θ 估计器状态（ADR 0029）新增一个标量 P：出生先验的当前质量，四通道共用，与现行共用的经历质量 S（`weight`）同构。genesis 时 P = P₀，S = 0，各通道有符号和 U_i（`reaction_sum`）= 0；其余初始化按 ADR 0029 现行次序。P₀ 沿用规律资源中的 n_b（`baseline_weight`），含义从「永久先验质量」改为「先验质量的初值」。

每个合格经历，在现行变点检测与 ĥ_θ 计算（V2-94，不变）之后，令 ρ = fl(1 − ĥ_θ)，按以下次序计算：

```text
S′   = fl(fl(ρ·S) + 1)                                  # 现行
P′   = fl(ρ·P)                                          # 新增；允许下溢
对 i = 联结、共情、好奇、成事：
  r_i  = fl(a_i − b_i)                                  # 现行；b_i 为本步之前的已存值
  方差、σ̂、g、持续时间、λ 的递推                          # 现行，次序不变
  U_i′ = fl(fl(ρ·U_i) + a_i)                            # 现行
  b_i′ = fl( fl( fl(P′·b₀,i) + U_i′ ) / fl(P′ + S′) )   # 改：P′ 取代固定的 n_b；乘积允许下溢
```

实数形式（PROOFS P07-A）：令 T = P + S，则 T′ = ρT + 1，

```text
b′ = b + (a − b)/T′，    出生份额 β = P/T，    β′ = (1 − 1/T′)·β
```

**下溢。** P′ 与 P′·b₀,i 两处乘法允许按 IEEE 渐进下溢得到次正规数或 +0，不是计算故障；P 到 +0 后保持 +0。理由：β → 0 是 P07-A 的实数极限；T′ ≥ 1，出生项对 b 的作用不超过 2P，P 进入次正规范围时这个上界小于 2^−1021；把它判成故障会让她在长期生活后因「先验已让位」而永久停止成长，补 ε 或把 P 钉在最小正规数则是隐藏的永久锚定（REPORT §2.3「不能偷偷补 ε 或截断成长」）。分母 T′ ≥ 1，永不为零。ρ 的现行定义域 (0, 1) 与 ρ ∉ (0, 1) 时的故障判定不变。

### 3.3 估计器的连带变化 ［审 + 新］

- **σ̂、g：** 公式与固定的 n_σ、σ₀ 先验不变（PROOFS P07-A「本卡只优先改 b」，D08 交 P5-63 版本对照）。残差 r = a − b_before 仍用本步之前的 b，但 b 的轨迹已改变，r、方差、g 的整段值随之不同，必须按新版本重算，不能沿用旧版本的数值或黄金向量。
- **λ：** V2-95 的运行时间、对数平均、零时长单计、未结束段不计全部不变；同号段的切分随 b 改变，τ̂ 与 λ 的整段值随之不同，同样只能重算。
- **ĥ_θ：** 检测器不变。ĥ_θ 的下限 ĥ_θ,min（`change_min`）的作用改变：旧规律用它使 n_b 与 1/ĥ_θ,min 相当、把反馈放大减半（v2.0 §8「调节」）；新规律中它给出有效记忆长度和下面的 α 下界。
- **未改的永久先验（如实记录）：** σ₀、τ₀ 的先验质量 n_σ、n_τ 仍固定，经历质量有界时它们保留有限份额。这属于 ADR 0032 D06「数值起点须让位」的待办，不由本文决定；登记见 V2-144。
- A_att、G 与 R 不受 D07-A 影响。

### 3.4 合法界：V2-96 重推 ［审：实数恒等式；新：带舍入的写法］

范围界不变：|Δb_i| ≤ 2，|Δg_i| ≤ g_max − g_min，|Δλ_i| ≤ λ_max − λ_min。单事件界中 b 的一项按新递推改为：设已存 b、P、S、U 的商缺陷 δ_i = (P·b₀,i + U_i) − b_i·(P + S)（实数），则

```text
b_i′ − b_i = (ρ·δ_i + (a_i − b_i)) / (ρ·(P + S) + 1)
```

旧式中的 n_b(1 − ρ)(b₀ − b) 一项消失；照抄旧项会误报或漏报。σ̂、g 的单事件界保持 V2-96 原式（n_σ 固定），λ 随 V2-95。判定仍为严格大于才触发；浮点包络按现行 `bounds.rs` 的外向舍入方法改写（P5-69）；包络无法收紧时退回范围界，不构成故障（现行做法）。

### 3.5 性质与证明

1. **出生份额让位。** ［审］β′ = (1 − α)β，α = 1/T′ ∈ (0, 1]；Σα = ∞ 时 β → 0。单位计量下 T_n ≤ P₀ + n，故 β_n ≤ P₀/(P₀ + n)。［新］现行 ĥ_θ ≥ ĥ_θ,min > 0 给出 ρ ≤ 1 − ĥ_θ,min，于是 T_n ≤ max(P₀, 1/ĥ_θ,min)，α_n ≥ α_min := min(1/P₀, ĥ_θ,min) > 0，β_n ≤ (1 − α_min)^n，按合格经历数几何让位。这里的 n 是实际合格经历的累计数，不是预设的成熟次数；时间本身不推进它。
2. **没有新经历就不变。** ［审］C 不被调用或返回不变，P、S、U、b 与全部估计器逐位不变（LP5、AC2-05）。等待只经 Φ 投影 x。
3. **同一生活、不同出生值。** ［审］同一 a、ρ 序列下 b_n − b̃_n = β_n(b₀ − b̃₀) → 0。ρ 依赖残差时两条路径不再共享 ρ，先做冻结输入的机制诊断，再做端到端比较。
4. **有限扰动在相同后续生活下消退。** ［审］从扰动结束起 δb_n = δb_m ∏(1 − α_j)；由第 1 条，乘积几何趋零。参照是同源对照下后续生活决定的轨迹，不是 b₀。没有未来经历、或扰动改变了以后的社交历史与保留率时，这个比较不成立，不得补计时回拉器。
5. **反馈世界的适用域。** ［审］一维线性合成世界 a_n = c + k·b_{n−1}（不触发输入边界，即 |c| + |k| ≤ 1）中，b_n − b* = [1 − α_n(1 − k)](b_{n−1} − b*)，b* = c/(1 − k)。［新］对 −1 < k < 1 与 α_n ∈ [α_min, 1]，因子的绝对值不超过 max(|k|, 1 − α_min(1 − k)) < 1，几何收敛到 b*，与 b₀ 无关；|c| < 1 − k 时 b* 在盒内。旧规律的 k_eff 因出生先验而小于 k，新规律的有效反馈强度就是 k：同一个世界里，新规律的不动点离中心更远，贴边更早。k ≥ 1、越出线性域、世界不平稳时没有保证。**［未证］** 真实闭环（b → x → 行为 → 他人回应 → a）不是线性标量模型，本文不证明它的收敛或不贴边；后果：AC2-25 只能在预登记、实测过的反馈域内签发（§8 V2-145），域外贴边如实报告并由慢漂检查报警（V2-97），不是计算故障，也不拉回。承接：P5-76 闭环、P5-30 校准。
6. **增量与整段重算逐位一致。** ［新］新递推仍是唯一的逐事件规范次序，整段重算重放同一递推（I23、AC2-08）；暂停与补算（AC2-18）、来源更正（AC2-19）沿现行重算路径。来源更正后按「这些证据从未出现」重算，P 随之取对应的值，这是正确结果，不是先验异常复活。

### 3.6 迁移

θ 是 H 在规律下的确定函数（v2.0 §2.2），换到新版本即从 H 按新版本重算 θ（v2.0 §5.4）；不能把旧快照的 S、U 接上一个猜出来的 P 继续算。旧版本快照（ADR 0029 的 `ThetaSnapshotV2`）只按旧版本读取与重放，不能直接恢复成新版本的可运行状态。切换造成的 θ 变化写入 L，按 V2-97 照常应用并报警。排练谱系 G、C 恒等，θ 就是 genesis，切换不产生变化。

## 4. D09+D10-A 与截断归属 A1：依据替换

**白话。** 一件事在她心里只占一个位置。想起一件伤心事，她可以再难过起来——想起时把这个位置补回到它本来的分量；但反复想、换个说法想、换一种语言想，都不会让难过一次比一次深。真正新的发现仍然能触动她。没有新事时，她的心情按原来的速度平复，不会因为心里记着很多事而在高处多停一会儿。代价：两件开心事接连发生、心情已经到顶时，第二件当时只能占剩下的一点；等心情回落一些再想起它，它可能留下比第一次更多的分量——先后顺序会影响以后回想时的分量。发现某件事是假的时，那份感受不会被立刻扣掉，只会自然淡去，之后想起它也不再补回原来的分量。没有出处的空想共用一个位置：新的空想替换旧的空想，不叠加。

### 4.1 状态 ［审：P09-A1；新：表示细节］

- **可见主值 x**：现行 X = [−1, 1]^{4+|R⁺|}，J 只读 x（不变）。
- **依据槽**：每个槽是（依据身份 c，当前分量 h_c，目标 v_c），h_c 与 v_c 和 x 同坐标。依据身份在槽集合中唯一。h_c 可以在盒外，幅度不超过 |v_c|（§4.6 B6），v_c 受现行 η_x 约束。
- **锚点**：槽与 x 共用快照的同一个锚点，不另设时钟。
- **派生余项** y = x − Σh_c：只在证明与测试中出现，不存、不读、不给模型、不进入学习，也不是另一条基线。
- **作用记录**：每次 F 作用在 H 中留一条记录（依据身份、角色、目标、所依据的解释与治理记录引用、规律版本），F 暂存、外层事务提交。目标以 H 中的记录为准；Q 只存运行引用。
- 槽与目标都不是 G、C 的证据（EV10、I24），不重发依恋先验。

### 4.2 依据身份与 F 角色 ［新：按 REPORT §3.2 精确化］

F 不判断新颖性或同根。每条进入 F 的记录带一个在 m = 0 下得出、已记入 H 的治理结论（P5-43 的正式语义边界、P5-24 的证据组与同根治理），F 只按结论执行。每条记录恰有一个角色：

| 记录 | 角色 | 依据与目标 |
| --- | --- | --- |
| 外部观察：V2-71 的外源事件与外部的其他事件，含同一次停留、同一段缺席的后续报告 | 新依据 | 依据就是该记录；目标为本次 D(e) |
| 传输重复：同一 `stable_source_key`，或同一消费身份（§5.3） | 不进入 F | Γ 的幂等判定与消费身份去重 |
| 系统记录（V2-87） | 不进入 F | 不变 |
| 同一记录的首次有效解释晚到（补解释）；带新增依据记录的真实修订 | 目标更新 | 依据不变；目标为本次提交算出的 D |
| 内部记录、自致结果，治理结论为「新依据」并有可查差异 | 新依据 | 依据就是该记录 |
| 同上，结论为「无新依据」或「新颖性未知」，来源闭包含已有目标的依据 | 重访 | 闭包中每个已有目标的依据，按其首次作用在 H 中的先后，各用已记录目标 |
| 同上，但闭包不含已有目标的依据 | 内部支路 | 全局唯一的保留依据「内部支路」；目标为本次 D |

- 「已有目标的依据」指在 H 中已有作用记录、且未失效（§4.7）的依据。从未经 F 作用的记录（例如系统记录）被引用时不算。
- 一条记录只取一个角色。新依据不再另外重访它引用的材料：它的评估已经包含这些材料，再重访会双算。
- 外部观察每条都是新依据。同一件事被别人说两次是两次真实刺激，旧 F 同样推动两次；D09 针对她自己的重复，不压低外部持续的真实刺激（ADR 0026 §6.3 已说明后者不算自锁）。
- 新颖性未知不升级为新依据（REPORT §3.2「未知新颖性保持未知」）；没有外部根的纯设想不能靠自建子节点开新户，所以共用一个内部支路（同处）。
- 多个依据的重访次序取首次作用在 H 中的先后，是 A1 在饱和时分配份额的确定性规则；它有行为含义，列为待确认读法（§6）。
- **［未证］** 治理结论是否正确：同一事实换措辞、换语言、换 action_id 是否被认作同根；共享来源却有新事实是否被认作新依据。后果：「重复不加码」只相对于记录下的身份成立——把同一事实错拆成多个依据，重复刺激可以叠加多份目标（仍受盒约束）；把不同事实错并成一个，真正的新发现被压成重访。承接：P5-43、P5-24 的正式记录，P5-77 的 m = 0 判断质量。

### 4.3 目标的来历 ［新：按 PROOFS P09-A「v_c 由固定解释、前态 R/θ 和规律版本决定」］

- 目标在依据首次作用时确定：用该提交已记录的解释（z、a、μ）和前态 θ、R⁺，按 v2.0 §6 的 D(e)（含 V2-115(1)(3) 的读法）计算；新版本不乘 κ^n（§4.9）。超过 η_x 的界照现行做法拒绝。
- 只有「目标更新」角色能改目标：补解释（首次有效解释；P11「先前失败或缺失的解释不能被当作已经产生了有效驱动」）与带新增依据的真实修订，目标按该提交的前态算。
- 重访、改写、换语言、θ 或 R 后来的变化、规律参数变化、D05 的重新拟合，都不改已记录目标（REPORT §3.2「复制内部活动不得提高该依据已经获准的目标」；EXPERIMENTS E-C「D05 × D09」行）。
- 坐标对齐：目标的学得坐标按记录时的 R⁺ 写入；使用时按当前 R⁺ 对齐——已离开 R⁺ 的坐标忽略，记录时不在 R⁺ 的坐标取 0，与 F_out 一致。
- 内部支路的目标每次取本条记录的 D：它没有外部依据给出的「已获准目标」，新的空想替换旧的空想。

### 4.4 无事件时的时间推进 ［审：P09 实数证明；新：binary64 路径］

- **x：** 用现行 Φ 的同一运算与锚点（`fast::project_time`：每坐标 pull = −expm1(−fl(λ·Δ))，x′ = clip(fl(x + fl(pull·fl(rest − x))))），逐位不变。槽不参与 x 的推进，不从 y + Σh 重建 x。
- **槽：** 每个槽的每个坐标用与 x 该坐标相同的速率（四通道用 λ_i，学得坐标用现行 `learned_rate`）、相同的 Δ 和同一个 pull 值：h′ = fl(h + fl(pull·fl(0 − h)))，零规范化为 +0，不截断。
- 推进是纯函数：从已存快照与锚点计算，读取不写回（I21）；提交时 x 与全部槽以新锚点一起存下。

### 4.5 事件作用：A1 的规范 binary64 形式 ［审：实数定义；新：分支形式］

对依据 c 的每个坐标，前态为推进后的 x 与 h（即 h_c），目标为 v：

```text
d = fl(v − h)
s = fl(x + d)
若 −1 < s < 1：  x⁺ = s；   h⁺ = v
若 s ≥ 1：       x⁺ = 1；   t = fl(h + fl(1 − x))
若 s ≤ −1：      x⁺ = −1；  t = fl(h + fl(−1 − x))
后两种情形：     h⁺ = min(max(t, min(h, v)), max(h, v))
其他依据的槽不动；结果中的零规范化为 +0。新依据从 h = +0 开始。
```

实数形式就是 P09-A1 的 x⁺ = clip(x + v − h)、h⁺ = h + (x⁺ − x)：不饱和时它等于 v；饱和时它落在 h 与 v 之间，夹取只去掉舍入。可见更新与现行 `apply_drive` 的算式相同（D = fl(v − h)）。一条记录有多个依据（重访）时，按 §4.2 的次序逐个作用，每一步以上一步的结果为前态。

### 4.6 性质与证明

**［审］实数（P09-A1 与 d_◇ 非扩张，#131 复审通过）：**

- R1 y = x − Σh 在事件中不变；无事件时 y′ = x_rest + E(Δ)(y − x_rest)，故 x 严格按原 Φ 推进，没有可在等待中释放的超额。
- R2 同一前态、同一目标的重复作用幂等；固定目标时 h_c 位于 0 与 v_c 之间；重访不提高授权目标。
- R3 相同依据、目标与参数路径下，d_◇(s, s̃) = max_i(|x_i − x̃_i| + Σ_c |h_{c,i} − h̃_{c,i}|) 在事件中非扩张，无事件段至多乘 exp(−λ_min·Δ)。
- R4 精确见证：两个目标为 1 的同号依据顺序作用后停止全部事件，半衰期后 x = 1/2（旧 A0 得 1，失败）；目标 3/4、3/4，半衰期后重访第二个依据得 x = 1、h₂ = 5/8；两个单位目标半衰期后依次改为 0 得 x = 0；目标 (1, −1, 1) 时把第二个目标改为 0 仍留下 h₂ = −1。

**［新］binary64（对一切有限输入，x ∈ [−1, 1]，零已规范化）：**

- B1 无事件时 x 逐位等于现行 Φ：x 的推进不读槽（构造）。
- B2 Δ = 0 的推进对 x 与每个槽逐位恒等：λ·0 = +0，pull = −expm1(−0) = +0，h + (+0)·(−h) = h；h = +0 时 +0 + (−0) = +0。
- B3 槽推进不放大、不变号：pull ∈ [0, 1]，舍入单调，|fl(pull·h)| ≤ |h|，故 h′ 与 h 同号或为 +0，|h′| ≤ |h|。
- B4 新依据首次作用逐位等于旧 F：h = +0 时 d = v 精确，s = fl(x + v)，三个分支给出的 x⁺ 都等于 clip(s)。
- B5 同一前态、同一目标的重复作用逐位恒等。设第一次结果为 (x⁺, h⁺)：
  - 不饱和：结果 (s, v)；第二次 d = fl(v − v) = +0，s 不变，仍不饱和，结果相同。
  - 上饱和且 v ≥ h：h⁺ ≤ max(h, v) = v，故 fl(v − h⁺) ≥ +0，fl(1 + d) ≥ 1，仍上饱和；t = fl(h⁺ + fl(1 − 1)) = h⁺，夹取后仍为 h⁺。
  - 上饱和且 v < h：d < 0，s = 1 只能来自 x + d ∈ [1 − 2^−54, 1)；区间 (1 − 2^−54, 1] 里唯一的 binary64 是 1，所以 x = 1、t = h，夹到 [v, h] 得 h——第一次就是恒等。
  - 下饱和对称。
  - 朴素写法 h⁺ = fl(h + fl(x⁺ − x)) 不满足：x = 0.44103831552214、h = −0.07324038289205337、v = 0.0002230830984472614（十进制往返表示）时，第一次得 x⁺ = 0.5145017815126407，同一目标再作用一次得 0.5145017815126406。所以规范形式必须用上面的分支。
- B6 固定目标下，从 h = +0 起，h_c 每个坐标始终在 0 与 v_c 之间：不饱和得 v，饱和时夹在 h 与 v 之间，推进时向 0 收缩且不变号（B3）。P09-A1 的固定目标幅度界在 binary64 下同样成立。
- B7 各坐标恰为 +0 的槽可以移除：推进保持 +0，其他依据的作用不读它，重建时从 +0 开始、目标从 H 的作用记录取回，移除与保留的全部后续逐位相同。

**［未证］：**

- U1 binary64 下的分解：B5 不饱和分支令 h⁺ = v，而 x 的实际变化是舍入后的 fl(x + d) − x，差额落在派生的 y 里，所以 x = y + Σh 只在实数意义下成立。y 不存不读，不影响她；后果是测试用有理数 oracle 验分解，浮点残差分开报告（EXPERIMENTS E09 的有限 binary64 分层）。
- U2 binary64 下 d_◇ 非扩张没有证明，舍入可能造成最低位级的违反。后果：AC2-15/I05 对扩展状态用有理数 oracle 或带舍入包络比较，不断言逐位不等式；现行只看 x 的 I05 检查，只在两条轨迹的槽相同时继承（P09：只有初始 h 相同时 d_◇ 才等于可见 x 的距离）。
- U3 任意多依据的重访序列下，总 x 峰值不保证单调不增（P09 已说明）；整个认知闭环不「越想越激动」没有证明。承接 P5-76、P5-77。

### 4.8 迁移 ［新］

- 旧版本快照（`FastStateSnapshotV2`，只有 x）迁移到新表示：x 与锚点逐位不变，槽集合为空。迁移写一条记录（L 与 H 的系统记录），声明「迁移前依据的分解未知」，不声称无损（PROOFS P09：不能猜一个分摊，也不能清零后宣称兼容）。
- 后果：迁移前已作用过的依据，第一次被重访时从 h = +0 开始，可能在它仍留在 y 中的残量之上再加至多一份目标；受盒约束，每个依据至多一次，之后有了槽就不再加。备选：迁移前的依据一律不可重访，代价是迁移前的经历再也不能在想起时触动她。
- 不采用从 H 按新版本重放 x 来恢复分解：那会改写她当前的感受（x 跳变）；v2.0 §5.4 换版本只重算 R、θ。
- 正式谱系尚未诞生；genesis 若采用新版本，正式谱系不需要此迁移（§2）。
- 回退：新快照不能当旧消息解码；回退时恢复旧应用与备份（ADR 0007、SYS17），迁移失败保留旧系统（黄金规则 14）。
