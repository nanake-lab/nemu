# ADR 0013：基于可追溯结果与明确目标的学习机制（候选）

- 状态：**PROPOSED / needs-user**。提交PR是研究交付，不表示采纳。现行2.0规格仍有效。
- 日期：2026-10-21。
- 范围：评价、证据、学习与成长验收的候选修订；无运行时或契约实现变更。
- 完整条文与验收映射：[PROPOSAL.md](../../reports/echo-core-v2-revision/PROPOSAL.md)。

## 背景

现行2.0以四天性评估a(e)作为学习信号，再以倾向分数和θ改变反应。它没有充分区分结果观察、相对于目标的评价、因果归属和观测缺失。已有研究也发现熟悉/预测误差与偏好混淆、累积估计难适应真实变化等问题。用户要求不维护任何不必要的版本结构，提出具体替代并接受实验挑战。

## 候选决定（待审查、待用户批准）

1. 保留单权威、事务、可追溯历史、谱系隔离、行动权限、重放和迁移保护。
2. 从最小学习本体删除固定四天性、统一a(e)奖励、强制解释份额总和为1、π到R⁺的硬阈值，以及独立的b/g/λ人格成长要求；删除管理身份自动带来的强依恋/高信任先验，保留用户身份和权限。删除必要性主张不等于已关闭现有运行阶段。
3. 用带来源、主体、目标引用、实际行动、结果/缺失、观测机制和纠错关系的记录，支持可修正的结果预测；有依据的目标才允许形成评价。
4. 偏好先定义为有范围、可被反证的行为倾向，不强制增加独立人格状态。记录和必要不确定性要能重建未来学习，不能只保留一个分数。
5. 稳定与变化同时建模；变化先验公开、版本化。没有观测/因果识别依据时保留区间或不可识别状态，不制造确定好恶。
6. 对现有AC2逐项给出保留/替代/延后清单。新研究编号不替换当前验收，未运行项明确记为未验证。

实验后的算法选择：不将本轮自适应变点混合定为必选实现，它在部分世界输给更简单基线；保守排序区间也不能作为成长门槛。完整结果与反例见[报告](../../reports/echo-core-v2-revision/REPORT.md)。

## 备选方案

- 只修复2.0参考公式：不能解决评价信号的依据，暂不推荐作为完整修订。
- 直接采用既有v3候选：其预测表示没有自动解决价值来源；本PR不声称在完整实现对照中击败v3。
- 完全删除评价、只做预测：不能决定行动取舍。
- 立即重写全部核心：现有证据不支持；安全、存储和事务底座仍有用途。

## 后果和采纳边界

若用户采纳，需要另开实现卡修订核心状态/记录IDL、学习算子、IRL/评估接口、J读出和迁移测试；不能把本PR的Python研究代码直接接入正式人生。涉及P5-21、23–26、10–13、28–31、17–18的依赖需另行排定，当前任务卡不改。

本候选已明确承认：任务/关系中的条件性选择学习不等于完整人格，内在审美与终极价值形成仍没有验证闭环。合并研究材料、批准候选规范、批准生产启用是三个不同决定。本PR不启用后两者。
