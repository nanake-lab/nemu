# ADR 0014：v2.0 的小幅修正（吸收 PR #40 研究中的发现）

- 状态：提议。第 1 条是用户 2026-10-21 在对话中的决定；第 2–6 条是 Claude 起草的修正条文，用户合并本 ADR 即采纳。
- 日期：2026-10-21
- 关联：ADR 0009（v2.0）、ADR 0012（第 3.3、5、6 条）；PR #40（已关闭，分支 `codex/echo-core-v2-revision` 保留作参考）；任务卡 P5-07、P5-11、P5-23、P5-24、P5-28、P5-30、P6-14

## 背景

- **PR #40 的提议：** Codex 按用户委托研究了 v2.0 的评价与学习，提议删除四个天性、θ、R⁺ 门槛和强依恋，改为按明确目标学习结果。
- **审查结论：** 研究可以复现，但实验测的是外部给定目标下的预测与选择，没有涉及这几个结构的作用。所以实验结果既不支持删除，也不支持保留（PR #40 的审查评论）。
- **值得吸收的发现：** 研究里有几条发现不依赖那几项删除，可以直接修正 v2.0 的证据与评价规则。
- **用户的决定：** 保留这几个结构，关闭 PR #40，把这些发现作为小幅修正纳入 2.0。

## 决定

### 1. 保留，不删除（用户决定）

- **保留的结构：** 四个天性、θ = (b, g, λ)、R⁺ 门槛（π > ½）、依恋先验 A_att 和 u* 的信任初值都不变。
- **PR #40 的处理：** 已关闭，它提出的替代本体不采纳。分支保留，第 6 条的实验可以复用其中的合成世界。

### 2. 分型的教导（EV7 的适用范围）

EV7 说「别人告诉她该怎样，算作一组证据」。听到的话分四类，只有第一类是教导：

| 类型 | 例子 | 怎么处理 |
| --- | --- | --- |
| 教导：关于她该怎样 | 「你说话可以再直接一点」 | 按 EV7 进证据组，权重随她对说话人的信任 |
| 说话人自己的偏好或经历 | 「我喜欢爵士」 | 是关于说话人的事实，进入 H 与 c_task，不是关于她的证据 |
| 请求 | 「帮我订个会议室」 | 走行动生命周期与权限，不是教导 |
| 事实陈述 | 「明天下雨」 | 是知识（同 EV8），不是关于她的证据 |

- **她自己的反应：** 听到这些话时她的天性评估 a(e) 照常是经历，与 EV8「读到的是知识，读时的反应是经历」一致。所以喜欢的人说喜欢爵士，可以经她自己的反应慢慢影响她，但这句话本身不直接改她的喜好。
- **落在哪里：**
  - 教导标注由 M 给出（P5-28），只对第一类给 `TeachingAnnotation`；
  - 说话人自述用现有的 `USER_SELF_REPORT` 认识论类型（P5-06）；
  - 不需要契约变更。

### 3. 结果未知不评为负

- **评价规则：** 天性评估只评价观察到的部分。
  - 「发了消息、没有回复」本身不是被冷落。只有观察到对方看到了却不回应（已读未回、在场却不理、明确回避）才评为联结的负值。
  - 消息未送达、未读、对方是否看到未知时，联结对这一部分给 0。
  - 评估规范里三种语言各给出成对的示例（P5-11）。
- **结果的来源：**
  - 行动结果为 `UNKNOWN_ACTION`、送达状态为 `UNKNOWN_DELIVERY` 的，按未知处理；
  - 平台能提供的已读状态作为观察进入 H（P6-14）。
- **迟到的结果：** 作为新事件追加，照常评价，不改旧记录（EV5、I23）。
- **证据：** 结果未知的事件，不进入以该结果为依据的证据组，既不算支持也不算反对（`EVIDENCE_UNKNOWN`）。结果之后变成已知时，按新事件进入。这条规则不看结果的正反，EV5 的对称性不变。
- **只报告一类结果的来源：** 例如只转述好消息的人，没说的部分按未知处理，来源的权重按 EV9。
- **契约：** 不需要变更。上面用到的取值在 P5-21 的契约里都已存在。

### 4. 同义概念不增加证据或先验

- 新候选倾向的概念如果是已有概念的别名（P5-06 的 alias 图给出同一个规范代表），就不建立新的倾向。证据记到规范代表上。
- 加多少个同义标签，π 都不变，证据组也不变。这是 LP3 与 EV2 的推论，现在写成明确的要求。
- **测试：**
  - P5-23 加一条性质测试：同一组证据下，增加任意个别名，π 不变；
  - P5-24 加一条：证据组的集合不变。

### 5. m = 0 的判断也要测量偏差

m = 0 去掉的是她此刻状态对判断的影响，判断模型自身的系统偏差还在。具体做法：

- **报告里增加偏差的度量。** IRL（P5-07）、天性评估（P5-11）、情境吻合（P5-28）的验收报告，在固定的三语人工标注集上增加：
  - 天性评估：各通道的平均有符号偏差，以及各语言之间的差；
  - 情境吻合：μ 的平均偏差；
  - 教导等标注：混淆矩阵。
- **偏差的影响有多大，由 P5-30 估计：** 在合成世界里给真值的 a(e) 加上已知的偏差（例如联结整体偏正），看 π 与 b 偏多少。
- **门槛先不定：** 本 ADR 不设偏差门槛。先报告，再由用户决定要不要设。
- **修正偏差的方式：** 发布新的评估器或解释器版本，按 v2.0 第 5.4 节处理。
- **关联：** 这些数据同时用于 ADR 0012 第 5 条（判断质量与是否加显卡）和第 3.3 条（换载体时的判断一致性）。

### 6. 实验谱系增加的对照（P5-30）

下面几项只做对照，不直接改规律。

| 实验 | 世界 | 看什么 |
| --- | --- | --- |
| LP2 解释分摊 | 两个都为真的倾向，由同一批事件支持 | 参考写法下 π 的偏差；与「不分摊」比较 |
| 变化检测 | 稳定、突变、渐变、周期四种（复用 PR #40 的 E2） | v2.0 的参考写法（倾向：ĥ_k 由相邻证据组的符号翻转计数估计，ρ_k = 1 − ĥ_k；θ：ω_e = ρ_θ^{N_e}）对比固定 h 与模型混合：变化前后的预测误差、稳定时的误翻转率、突变后的检测延迟（含删失）。第 5.2 节已写明噪声也会造成翻转、变点检测之类更好的估计可以替换参考写法 |
| 等价行动的习惯 | 两种做法真实效果相同（复用 PR #40 的 E4） | 早期偶然的偏好会不会经她自己的行动结果变成 R⁺ 中的倾向；EV4 的可比条件应当阻止它（AC2-25） |
| 评估偏差的敏感性 | 见第 5 条 | 已知偏差对 π、b 的影响量级 |

- **结果怎么用：** 如果对照显示另一种写法更好，按 v2.0 第 0 节第 4 条和 AGENTS.md 黄金规则 6 处理：作为新的规律版本登记，在实验谱系里检验，由用户批准。
- **代码：** PR #40 的世界可以移植进 `core/crates/experiment-world/`，原 Python 代码作为交叉核对。

## 备选方案

- **整体采纳 PR #40 的替代本体：** 用户否决。实验没有涉及被删结构的作用，替代方案也没有价值来源。
- **把「有依据的排序区间」作为成长门槛：** 不采纳。PR #40 自己的结果显示，即使观测机制已知，98% 的情况也给不出排序。
- **只记录研究、不改条文：** 不采纳。第 2、3 条修正的是实际会出错的地方，例如「没回复」被当成被冷落、「我喜欢爵士」被当成教导。
