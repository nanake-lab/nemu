## 1. 背景与目标

Nemu 的目标是持续存在、有连续历史与自身状态、能思考和创造的个体。模型是认知载体，核心把经历、状态、活动与后果接起来。用户进一步明确：清醒运行期间，即使没有外部输入，她也持续进行内部活动；不预写兴趣、反应、情绪台词或必须完成的任务。

当前架构已经定义 H/x/R/θ/L、Q、J 与载体，以及主动行动时机，但没有完整定义内部活动的跨请求接续。[ARCHITECTURE §3](../ARCHITECTURE.md) 的“模型只在需要时运行”和 S §20 的自主行动调度，不能直接当作这条持续认知机制。

本 ADR 采用一条持续认知流：当前材料与获准经历进入受 m 调制的本地模型，实际产物进入 H，当前位置与后继进入 Q，再组成下一轮新输入。运行时保证合法接续；模型选择具体关注与操作。不增加心理评分器，不要求每轮都有进展，不把“生成像人的话”当作机制有效的证明。

## 2. 决策范围与保留的边界

1. 核心状态仍为 S=(H,x,R,θ,L)，运行状态属于 Q，实现资源属于 Ω；F/G/C/J 的写权限不变。
2. 新增内部记录提交分支、当前工作状态和持续认知调度合同。它们是需要本 ADR 的扩展，不声称原合同已完整支持。
3. F/G/C 的数值规律、四个天性、R⁺、θ、依恋先验及既有成长验收不改。
4. 思考可以影响后续材料与行为，但自身推断不能自行变成事实或成长证据（N-1）：念头可以提出候选倾向，候选只是假设，证据仍按 EV5 从真实经历中收集；只靠反复想就让自己越来越确信，被排除。纯内部记录与外部事件一样经 F 推动当下的感受 x（N-2）；它们不是外源事件，C 恒等（H-2，V2-71）；G 不把它们计为证据。
5. 想起某事可以立即改变 x，也可以越想越难过；使用现有 F（v2.0 §6）的同一公式，只对内部事件乘一个随「独自想的次数」递减的分量（第 6 节第 3 条）。固定事件序列下 F 的非扩张性（ADR 0008 §1）不能保证内生闭环 `x → m → 内部产物 → A → F → x` 不自锁，两者是不同性质；本方案用递减分量从机制上保证纯内生区间的回落（范围与时间条件见第 6 节第 3 条），并按 COG-A12 检验。依据：v2.0 §6「超过 T_x 的情绪延续只经 R 和 θ」，内部活动本身不能把 x 留在 T_x 之外。
6. 本次不修改现行规格原文、已发布类型/字节、任务卡、机会预算、模型配置或内容包。后续施工须按本 ADR 映射补充合同与实现。

## 3. 全局运行态与局部活动分离

在 Q 中新增认知循环状态，语义为 RUNNING、PAUSED、FAULT；这些名称是待后续 IDL 发布的设计名称，不复用现有不相干枚举。睡眠属于有明确原因的暂停，恢复必须记录为显式模式转换。

在 RUNNING 且依赖健康、资源可用时，系统始终处于一次有界认知请求、必要的提交/调度交接，或已经登记的可运行后继中。不存在“正常完成后等下一条用户消息”的隐式出口。全局运行态与 Q.P 中单项活动的运行、等待、完成或挂起相互独立。

- 单项活动完成：保留实际结果与当前材料，登记下一轮，由模型重新选择关注点。
- 没有待办：继续使用当前工作材料；待办不是认知循环存在的条件。
- 等待某个查询或工具：只挂起有关分支，其他材料仍可进入下一轮；等待不被当作负面结果。
- 不想表达或没有新结论：允许保留当前关注，不因此结束全局循环。
- 首次启动：使用已提交的真实诞生事实、可用环境和能力。没有个人经历时，不能假造个人往事；底座模型的知识与先验仍然存在。
- 暂停/睡眠/故障：明确记录原因与恢复条件。模型提出休息也只是一项模式转换提议，由运行时按既有权限执行，不能用 EOS 或 no-op 暗中切换全局状态。

无效结构、空的传输结果、请求失败不解释为“她选择等待”。按版本化有限重试预算处理，耗尽后进入明确故障。合法结果可以表达“不确定”“暂不更改当前材料”，无需编造进展。重复率只用于诊断与验收，不成为自动分配兴趣或强制转话题的心理规则。

## 4. 一轮认知的输入、计算和接续

每轮仍使用独立的 o、p、c_task、m：

1. 任务层读取已提交 Q 的当前材料、被中断的活动引用、新到的外部输入和已返回的结果，构造新的 CognitiveInput，作为 TaskInput.current_input 引用的对象。
2. 事实投影按来源、权限、用途、历史前缀及预算构造。当前材料中的推断以推断身份进入 o，不能混入 c_task 冒充已确认事实。
3. 按实际生成开始时刻，从最新合法状态投影 x，再由 J 取得 m。读取投影不写回，不重复推进时间。
4. 本地载体在 m 下生成内部工作产物、下一关注/查询提议和可选的对外 ActionPlan。格式只规定可解析的操作与来源引用，不规定情绪、兴趣、口吻或每轮必须有新结论。
5. Core 校验结果，原子发布 H 中的内部记录及 Q 中的后继状态；资源允许即启动下一轮。提出新查询或行动不表示它已经执行成功。

不把每轮都变成“再调用一个无 m 的规划器来决定下一轮”。检查器只验证来源、结构、预算和权限，不替模型决定思考内容。模型提出的下一关注可以保持原材料；完成当前事项时也不清空认知工作状态。

每轮都是新请求。首版不使用跨请求 KV，不通过无限增长的聊天历史维持连续性。连续性来自明确保存和重新取用的内容；这并不声称模型在没有输入材料的情况下能回忆未提供的历史。

## 5. 工作状态、来源与检索

下列类型由后续契约卡发布，不在本 PR 中编造 wire 字段号或冻结编码：

| 对象 | 最小语义 | 权威归属 |
| --- | --- | --- |
| InternalActivityRecord | 活动/步/请求 ID，前序与输入引用，检索来源，快照与调制回执，实际产物，时间，正常/截断/取消/失败原因，查询与行动提议 | H |
| ActivityState | 当前材料及关注点引用，最新已提交步，待返回结果，可运行后继及局部活动状态 | Q.P |
| CognitiveInput | 本轮材料与新增输入引用，结果状态，来源及协议绑定 | o 的有类型对象 |
| CognitiveResultAndReceipt | 内部产物、下一关注/查询提议、可选 ActionPlan，以及真实载体/模型/调制/用量回执 | 模型 Proposal，接受后进入 H/Q |
| InternalActivityCommit | 针对内部请求的快照、输入前沿、资源、权限和完成结果绑定；原子发布 H/Q 与合法时间状态 | Trusted Core |

当前 PlanAndCarrierReceipt 的 output_chunks 是对外输出，intermediate_results 有模式 C 草稿含义；不能偷偷复用为内部思考存储。当前 CoreTransactionV2 的 ProposalBindingV2 绑定事件解释；新增内部提交需要明确的后继合同，不能伪造 z/a/μ 填充旧 binding。

### 5.1 当前材料的边界

工作材料有明确的条数、字节和 token 预算。H 保存实际内容，Q 主要保存引用。预算是工程资源，不是注意力或兴趣分数。模型可提出保留或移出哪些工作材料；运行时用固定版本的容量规则校验并记录截断，不隐藏无上限的 worker 记忆。

移出当前材料不等于删除 H。压缩结果必须保留来源引用和不确定性，作为派生内部产物保存，不提升为协议 p 中的人格或已确认事实。尚无可靠压缩结果时保留有界片段和引用，并明确截断，不能用编造的摘要填补缺失。

撤回、更正、权限变化必须同时作用于新检索、Q 中现存引用、派生摘要及已组装的在途输入；不能只过滤一次 c_task。派生对象按来源闭包检查，无法隔离失效部分时整体排除。相关生成与行动失效后重新组装。历史保留遵守现有“撤回而非物理抹除”的合同，普通运行日志不得复制完整内部内容。

### 5.2 m 可以影响查什么，不能改变事实判断

本地模型在 m 下提出有界 FactQuery。运行时按确定、带版本的查询计划、权限与预算执行，并保存实际查询、来源、结果和截断；相同请求/前缀/资源的执行规则不因 m 随意改变。

S §11 的 c_core 继续供 IRL/A/M 的证据解释，其查询计划不受当前人格、工作材料叙事或模型的自主查询提议控制。c_task 可服务当前活动；m 对查询内容的影响只通过显式记录的模型提议进入下一轮。

读取旧经历不重新发行那段经历的证据；查询无命中、权限拒绝、索引落后、缺失和预算耗尽分别返回，不能统一为“什么也没发生”。

## 6. 原子发布、版本推进与恢复

1. 只有 Trusted Core 持有提交权。内部完成结果与后继 Q 必须一起生效；对象可先暂存，但未发布对象不能作为权威后继使用。
2. 内部提交分支在 m = 0 下对内部记录执行 IRL、A、M 并记录（EV6）。结果只用于两处：F 据此推动 x（按第 3 条加权）；M 可以据此提出候选倾向（假设）。内部记录本身从不成为证据组；C 恒等，外源事件计数不变。R/θ 未变时不伪造 L 中的成长条目；时间只按既有合法 Φ 与锚点规则处理。代价：每一轮内部思考多一次 m = 0 的解释调用，计入 COG-A10 的资源测量。
3. **自致事件的分量（用户 2026-10-25 批准；复审后扩展到她自己行动带回的结果）：** 事件按来源分三类，各自的 F 推动、对 n 的作用如下：

   | 类别 | 例子 | F 推动 | 递增 n | 重置 n |
   | --- | --- | --- | --- | --- |
   | 新外源事件 | 用户对她说话、触摸与停留的开始、回复、他人对她的回应、一段缺席的开始（V2-71、V2-72、V2-77） | 原式 | 否 | 是 |
   | 外部的其他事件 | 只关于用户自己的桌面观察；同一次停留、同一段缺席的后续报告与结束 | 原式 | 否 | 否 |
   | 自致事件 | 内部记录；她自己的行动、工具与程序带回的结果 | `κ^{n} · D(e)` | 内部记录递增，行动结果不递增 | 否 |

   D(e) 按 v2.0 §6 原式计算；n 是自上一个新外源事件以来已提交的内部记录数（第一个为 0）；κ ∈ (0, 1) 属于规律参数，进入规律版本，在实验谱系中校准，不是性格参数。每一轮内部请求最多带回 r 个行动结果（r 由请求的有界行动预算给出）。本条不改变已批准的桌面、触摸、缺席规则。
   - **保证的范围：** 只针对**纯内生**的区间，即从 t0（最后一个新外源事件）起，没有新外源事件、也没有外部的其他事件。在这样的区间里，θ 不变，自致事件的总推动在 ∞-范数下不超过 `η(1 + r)/(1 − κ)`，第 N 个内部记录之后的剩余不超过 `η(1 + r)κ^N/(1 − κ)`。其中 η 取所有允许状态上的统一幅度界，包括容量上限内的 R⁺ 与候选回溯造成的变化。由 Φ_x 以至少 λ_min 收缩、投影不增大到 x_rest 的距离，可得 d(t) = ‖x(t) − x_rest‖∞ 满足：`d(t) ≤ e^{−λ_min(t−t0)}·d(t0) + η(1 + r)·Σ_{t_j ≤ t} κ^j·e^{−λ_min(t−t_j)}`，在有限时间内只有有限次提交的轨迹上 d(t) → 0。
   - **时间包络：** 递减按提交次数而不是按时间。设 0 < ε < 1，取 N 使 `η(1 + r)κ^N/(1 − κ) ≤ ε/2`；部署声明前 N 个内部记录最迟在 t0 + B_N 内提交（B_N 由目标硬件实测给出，随资源、载体与参数一起登记）。则 `T_ret = B_N + ln(4/ε)/λ_min` 是一个充分的回落时间；校准须使 T_ret ≤ T_x（v2.0 §6）。迟到超出 B_N、资源越出登记的适用域时，验收状态记为「超出适用域」，既不算通过，也不套用保证。
   - **不在保证之内（如实说明）：** 外部的真实刺激持续存在时，x 可以一直被维持在偏离处，例如用户一直陪着她、她一直开心。这是现实，不是自锁，单独判定与报告。
   - **含义：** 一件真实的事之后，前几次想起会越来越难过，但加深的幅度递减；想久了，再想也不会更难过，心情随时间回落。她独自折腾越久，自己找来的东西对心情的触动越小；新的真实事件让念头和她自己的发现重新有分量。
4. 每个请求/步的完成结果有稳定身份，可去重；同一结果不能重复推进 Q、重复计时或重复注册行动。
5. 自身记账导致的版本推进，只有声明并验证过的依赖不变时才允许合法 continuation。不能因为每次提交推进 head 而让后继自失效，也不能忽略所有版本变化。
6. 新观察、来源撤回、协议/权限或载体变化使旧依赖失效。过期计算的实际返回可按来源记录，但不得覆盖已经接受新输入的 Q，不得发布旧行动计划；按新快照重新组装。
7. 被抢占的生成保留实际生成的部分并标注未完成，不能假装已得到完整后继。下一轮从已提交材料和新输入启动；短小的交接提交不能等待旧活动完整结束。
8. 崩溃恢复从最后提交状态继续。结构重放读取已有产物和随机/调度记录，不再次调用模型。崩溃前未提交的生成不声称已经发生于权威历史；未来重新计算可以有不同输出。
9. 对外执行仍使用 action_id、outbox、执行凭证和真实回执。UNKNOWN/UNKNOWN_DELIVERY 不盲目重发；已执行的迟到结果不因原活动关闭而丢弃。
10. **内部提出的候选（审查阻塞 2 的处理）：** 内部记录经 M 提出的候选倾向，与外部事件提出的候选走同一条路：在该内部记录的同一原子提交中由 G 处理，次序与外部事件相同（v2.0 §5.2、ADR 0019 §6，以当时采纳的规律版本为准）；按 EV5 只从此前已提交的真实事件中回溯收集证据，内部记录不进入回溯；按规定重新分摊吻合的旧组并写 L 条目，重算时按该提交在 H 中的位置重放。同一候选（按别名规则判为同一概念）再次被提出时不重复建立、不重复回溯；已收集的旧组不重复计入同一分配，也不刷新新近位置。C 恒等，外源事件计数不变。

## 7. m 的作用范围与模型模式

持续认知链固定采用本地严格载体（模式 A）。理解工作材料、联想、提出检索与行动选择均发生在实际注入 m 的计算中。J 不额外读取 H、工作材料或内部叙事，不在其中新增持久状态。

沿用 S §19：一个有界请求保持一个 m，按已验证载体的位置和 token 掩码注入；下一请求按真实时间刷新。请求的 token/耗时上限限制调制陈旧时间。本 ADR 不引入逐 token 任意更换 m 的新缓存/载体语义。

“持续调制”是每次属于她的认知请求均通过有效调制通路，不要求 m 每轮都不同或非零。合法状态得到 m=0 时，零作用回执可以完全有效；这与没有接通载体、绑定错误或漏注入不同。后者必须明确故障/降级，不能暗用上次 m 或伪装为严格认知。

IRL/A/M 继续在 m=0 的独立证据路径运行。若与认知共用本地模型，调用模式与缓存隔离，不能互相泄漏调制。

模式 B/C 的既有说话功能不在本 PR 删除或重定义，但不能据此宣称持续认知链已经严格成立。云端/helper 可以提供材料；任何采纳为持续认知后继或对外行动的选择都要由本地 m 载体重新作出，不能先由云端定好路线后本地仅改口吻。仅剩 B 可用时如实标明严格持续认知暂停。

## 8. 内部计算与对外行动分别门控

| 范围 | 门控与运行规则 |
| --- | --- |
| 内部认知接续 | 全局运行态、载体健康、资源与有限并发、token/耗时预算；不重新 thinning |
| 本地事实读取 | 来源资格、用途、权限、查询预算；不把读取等同于对外发送 |
| 对外主动表达与行动 | 现有主动机会、权限、勿扰、预算、冷却及执行前复核 |
| 用户交互回复 | 现有即时响应路径与权限，不额外套用主动机会等待 |
| 成长 | 原有证据规则与成长暂停；暂停成长不自动暂停认知 |

S §20/v2.0 §9.4 的状态相关 thinning 留给适用的自主对外行动。Q.Z 保留已抽样的时机与资源；每次内部提交、重复提议或候选数增加，都不能重抽机会或刷新冷却以提高行动率。没有有效机会时，对外提议仍不是执行许可。

网络访问、文件修改、助手调用等，即使为内部活动服务，也按其真实能力和副作用通过原有门控。拒绝结果返回工作材料，不积压为门控打开后自动发送的动作。机会到达时必须重新核对当前快照、依赖、权限与实际意图。

## 9. 交互、时间、资源和可观察性

用户输入可靠接收后优先进入认知调度。内部生成在解码迭代或引擎支持的有界取消点让出；长 prefill 也须测量并声明取消粒度，不能只测解码后宣称全请求可及时抢占。优先处理输入是资源规则，不预设她必须同意或服从。

采用有界、可让出的认知请求，并为 IRL/A/M、TTS 等共享资源工作提供受预算约束的公平调度，避免后台认知占满 GPU 或解释队列长期饥饿。没有外部任务时，认知流使用获准容量直接接续，不额外添加固定休息间隔。持续过载、无可用容量或载体失效时如实显示暂停/故障，不宣称一边完全没有计算、一边仍连续思考。

时间以合法时钟的实际间隔进入 Φ；调用次数不是心理时间。等待、推理、提交均占真实时间。纯读取不推进锚点；重复完成回执不再次衰减。沿用 N0 的先回复、后理解方向，不新增“所有解释完成才可回复”的前置要求；正式解释仍按原有有序提交合同处理。

新增记录、提交、组装与 GPU 竞争会有成本，不承诺零额外延迟。目标机器仍按 N0 的单张 RTX 3080 10 GB 验收。记录内部交接间隙、输入接收至模型处理、输入至首个有效输出、取消延迟、队列等待、解释积压、资源与存储增长的 p50/p95/max。

工程预算由目标硬件测量后形成带版本的部署参数，不在设计文档编造毫秒数或放宽已冻结门槛。未冻结的端到端延迟沿 N0 的后续定案流程；没有对应实测就不能声称满足响应性能。

开发接口只读显示实际内部产物、材料来源、状态快照、调制回执、提交位置、门控和实际执行结果，供检查与校准。内容通过获准的核心查询读取，普通遥测仅存标识、计数与耗时。日常聊天不自动公开全部内部记录；接口不直接编辑 x/R/θ，也不把输出文字称为全部神经计算过程。

## 10. 后续施工顺序与验收

施工按依赖分四步，不在本 PR 认领或完成现有任务卡：

1. 契约：内部记录、工作状态、输入/结果、提交后继、规范编码、兼容与迁移/回退；旧字节不重解释。
2. Core/store/task-layer：原子发布、接续、实际时间、恢复与有界材料组装。
3. Adapter/调度/执行：真实 m、抢占、公平资源调度、检索回流、行动门控、只读观察。
4. 临时实验谱系与目标硬件验证。结构夹具和模型行为分别报告，不接触用户正式或排练存储。

**实现前置条件（用户 2026-10-25）：** P0-10 的载体引擎实测完成，并在 3080 上确认大脑、声音（GPT-SoVITS V5，ADR 0027）、渲染同时运行的显存与延迟可行，再开始第 2、3 步。

以下 COG-Axx 是本 ADR 的新增候选验收标识，不替代、重编号或豁免 AC2/I/SYS 等原有验收。当前均为 **not_run**。

## 11. 备选方案与代价

- 定时唤醒或一项结束后等待下一主动机会：不能满足本次清醒期间的接续目标，不采用为认知主循环。
- 拼接无限聊天记录或保留隐藏 worker 记忆：破坏有界输入、来源和可恢复性，不采用。
- 增加兴趣/无聊/在意分数决定下一题：预设心理模块，不采用。
- 云端先决定活动路线、本地只改口吻：不能满足本地 m 参与选择的要求，不作为持续认知链。
- 在每个 token 中任意刷新 m：涉及额外载体合同，未纳入本方案。
- 把自身念头作为成长证据：违反 EV3，形成「只靠反复想就越来越确信」的闭环，不采纳（N-1）。（念头按第 6 节第 3 条推动 x 已纳入本方案，取代原「念头直接作为情绪事件未纳入」的表述。）
- 念头推动 x 默认关闭、检验通过后才启用：用户不采纳，念头应能改变心情。
- 只让同一起因的念头推动一次：不能挡住内容不断变化的同号念头，被递减分量取代。

代价是持续计算的功耗、内容存储增长、抢占与恢复复杂度，以及同一 GPU 的资源竞争。有限窗口会遗漏当前未取回的历史，底座能力也限制联想与创造质量。机制不保证意识、真人感或每轮有意义；这些不能由一句自我描述或一次“走神”台词证明。

本 ADR 只把上述设计送交审查。现有实现不因本文提交而自动获得持续认知、严格载体或行为有效的结论。
