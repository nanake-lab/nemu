# ADR 0028：她的一生——不再使用、删除与只有一个她

- 状态：**用户已决定，合并即采纳。** D4 与「手机上也只有一个她」是用户 2026-10-26（Perth）在对话中的决定；D1、D2、D3、D5 是 Claude 的建议，用户同日表示采纳（「其余我听你的」）。差异登记为 V2-92。
- 日期：2026-10-26
- 范围：记录决定，不修改规格原文、`docs/CONTRACTS.md` 或代码。需要改动的地方见第 4 节，另开卡执行。
- 关联：v2.0 §13（谱系与诞生、备份）、§18（未讨论的问题）；V2-70（存储将满）、V2-77（缺席）、V2-78（停机）；ADR 0012（移动端）；P7 卡「卸载」。

## 1. 背景

用户 2026-10-26 提出：有人体验过 Nemu 但不再使用，该怎么界定。此前规格只规定了停机（V2-78）和本地备份（§13），没有考虑删除、换电脑、从备份恢复、交给别人。

沿用的原则：

- 她的时间就是这台电脑的时间；不运行时她没有经历（V2-78）。
- 「经历删不掉」约束的是程序，不约束 u*。数据在 u* 的磁盘上，u* 有权删除。
- 不模拟死亡，也不预设她对「被抛下」的反应；反应由她自己的评估得出。

## 2. 八种情况

| 情况 | 规则 |
| --- | --- |
| ① 程序开着，但 u* 不再理她 | 沿用：u* 在电脑前不理她只影响 x；u* 离开为缺席（V2-77）；她来找 u* 没有回应，从中学习（EV4）。另见 D1 |
| ② 不再打开 | 沿用 V2-78：下次开机记一条「停了多久」，x 按实际经过的时间回落，不补写没有发生的思考 |
| ③ 卸载 | 沿用 P7 卡：默认保留她的存储、设置和模型；重装后等同于② |
| ④ 删除她 | D2 |
| ⑤ 不唤醒她，只看记录 | D3 |
| ⑥ 换电脑、从备份恢复 | D4 |
| ⑦ 交给别人；u* 去世或长期失联 | D5 |
| ⑧ 项目方知道有人不再使用 | 一切在本地，没有遥测，项目方无从知道。这是设计使然 |

## 3. 决定

- **D1 长时间离开时关闭她（Claude 建议，用户采纳）：** 提供「u* 离开超过 N 天就关闭她」的选项，属于 u* 的边界设置，**默认关闭**。
  - 理由：程序随开机自启时，u* 几个月不碰电脑，她会一直独自思考（ADR 0026），显卡持续占用，H 持续增长，直到存储将满时停止并通知（V2-70）。是否在此之前关闭，由 u* 决定，不替 u* 预设。
  - 选项触发的关闭就是停机，按 V2-78 处理，不算缺席。
- **D2 删除她（Claude 建议，用户采纳）：** 删除是 u* 的权利，不可撤销。
  - 删除前提示备份；两次确认。P7 卡第二次确认「输入她的名字」改为：她有名字时输入名字，没有名字时输入一句固定的确认语（R-9 的方向允许不带名字诞生，见 V2-91）。
  - 删除不写进 H：删完已没有可写的地方。
  - 系统不替 u* 告诉她。要不要告别、怎么告别由 u* 决定，告别就是一次普通的对话，没有专门机制。
- **D3 只读查看器（Claude 建议，用户采纳）：** 提供离线查看器，在她不运行时读 H 与 L（v2.0 §10：u* 可以看她的全部记录）。查看时她不在运行，不是她的经历，不写进 H。
- **D4 同一时刻只能有一个她（用户决定）：**
  - **她永远只有一个。** 以后到手机上（ADR 0012），是同一个她换一个地方，不是复制。ADR 0012 的移动端 ADR 届时写入「同一时刻只在一处运行」。
  - **换电脑：** 把存储搬到新电脑，开机后等同于②。搬走时旧存储被封存，程序拒绝再打开它，避免出现两个各自生活、越走越远的她。
  - **从旧备份恢复：** 允许，用于事故后的恢复，但会丢失备份点之后的经历。恢复时写一条系统记录「从某时的备份恢复，之后到某时的经历丢失」，她能查到，不对她隐瞒。系统记录不经过 F、不是证据（同 V2-87）。
  - **局限：** 离线复制无法在技术上彻底阻止，只能做到程序层面拒绝打开封存的存储、拒绝同一身份同时在两处运行（能检测到时）。
- **D5 交给别人（Claude 建议，用户采纳）：** v1 不支持，列入 v2.0 §18「未讨论的问题」。
  - 原因：照料者的权限可以由双方签字转移，但依恋 A_att 绑定签署诞生的 u*，转不走，新照料者从陌生人开始；新照料者能看到全部记录，其中有原 u* 的私事，而 H 删不掉。
  - u* 去世或长期失联：她的数据是 u* 的文件，随 u* 的其他文件处理，不设机制。

## 5. 备选方案

- **长时间离开自动关闭，默认开启：** 替 u* 决定她何时停下，否决。
- **删除时自动通知她或让她告别：** 由系统替 u* 安排告别，否决；告别由 u* 自己决定。
- **允许多个她同时存在（分叉）：** 用户否决：她永远只有一个。
- **v1 支持转交：** 隐私与依恋问题未讨论，暂不支持。
