## 2. 与 ADR 0042 的关系

**U5 的过渡范围只涉及谁写内部文字。** ADR 0042 U5 把独处思考、后继和行动选择交给本地 A；ADR 0043 据此安排首版，ADR 0026 要求本地载体在 m 下选择。D1 调整其中的文字生产者。云端不取得选择权，也不取得核心提交权。若本地选择暂停，界面和回执分别表示云端文字生成与严格持续认知的实际状态。现有演示中 DeepSeek off 较本地未训练 4B 少编事件，但两者都有错误；因此保留 D8 的采纳检查。训练完成后，待本地载体、调制、抢占与接线通过既有验收，经审查、批准和载体迁移切回；历史回执保留当时的真实生产者。[ADR 0042 L184–195](../../docs/adr/0042-cause-projection.md#L184-L195) [ADR 0043 L23–36](../../docs/adr/0043-two-lines.md#L23-L36) [ADR 0026 L116–126](../../docs/adr/0026-continuous-cognition.md#L116-L126) [P5-echo-core.md L1656–1669](../../tasks/P5-echo-core.md#L1656-L1669) [DEMO-THINK-03 L24–35](../../reports/DEMO-THINK-03/REPORT.md#L24-L35)

## 6. 后果与取舍

| 黄金规则 17 的问题 | 本设计的回答 |
| --- | --- |
| 能不能不加？ | 复用 H、Q、既有来源闭包、投递回执与内部事务。沿用单一本地严格模式最省契约工作，但当前 4B 的念头质量尚有缺口；让云端同时选后继会扩大权限。只补云端文字的真实回执以及不足的身份/关系语义，能同时兑现 D1 和本地选择边界。 |
| 一个人会怎样？ | 人可以在独处时猜测以后会怎样，也能记得自己曾有过一个念头。与人交谈时，谁说了什么、当时想的是什么、事情后来有没有发生，可以分别说清。D2、D6–D8 保留这三个区别。 |
| 加了以后，有什么从此改不掉？ | 载体、设置和计量规则可按版本迁移；已发给服务方的原文、真正投递的话和已进入后续历史的想法不能靠换模型收回。保守上界会少带材料，也可能结束一轮；一起交付让用户晚些见到说话功能，但可首次就检验独处后再开口的完整体验。 |
