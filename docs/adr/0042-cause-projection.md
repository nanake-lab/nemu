# ADR 0042：文字路线交来由，不交状态

## 0. 结论在前

建议让本地核心挑出此刻仍有影响的真实往事，把原话交给 API 模型。先保留对话，再在剩余空间里放完整来由。这样能告诉模型发生过什么，但不能完整传出感受的强弱和长期性情。如果首版只有 API 模型，按现行规则还不能持续独处思考；这一点和选材取舍一起交给你决定。

## 1. 怎么挑

### 1.1 先确定这一轮已经感受到了哪里

**槽**是核心给一份依据保存的位置；其中 **h** 是这份依据此刻还留着的实际分量。排序读取已有 h。**来源包**是本轮临时算出的原始记录集合，构造规则见 §1.3。

把“输入已经可靠接收”和“输入的有效解释、状态更新已经按序提交”分开。每次组装绑定一个状态前缀 H≤n、对应快照锚点，以及实际输入 o 的持久对象/原文引用、接收回执和材料事实前沿。事实前沿说明这次可见哪些已记录原文与治理结果；它不能被一句“查询计划版本”替代。

| U6 路线 | 准备回复的条件与快照 |
| --- | --- |
| 保留 N0：用准备回复时已有的前缀 | 输入可靠接收后，可取组装开始时最新合法状态前缀。o 单独提供；其解释尚未生效时，本轮来由不包含这次输入尚未产生的感受。后补解释用于后续请求 |
| **按用户倾向展开的候选：感受先于回话** | 先等 o 的有效解释及依法需要的前序提交完成，按现行顺序完成应有的 Φ、A1/F_out 等状态更新，再取组装开始时最新合法前缀；该前缀必须包含这次处理结果。合法判定为无作用也算处理完成，失败/缺失占位不算 |

等待路线只等待本轮输入及其有序依赖，不要求系统所有解释队列清空。它明确改变 [ADR 0026 §9](0026-continuous-cognition.md)与 [N0 决定第 5 项](../../reports/P0-09/DECISION.md)在本候选模式 B 回复路径上的“先回复、后理解”，登记为 **V2-170 / U6**。失败、积压和后补解释的处理见 §3.1；两条路线均未由本稿替用户选定。

一次请求使用绑定前缀中的实际解释、治理版本和作用记录；随后出现的新解释不能回填旧请求。排队使依赖失效时，按现有任务生命周期失效并重新组装。严格模式 J 在实际生成时刻取 m 的规则仍单独适用。

### 1.2 读取现有分量并排序

按当时生效的 genesis、规律/解释资源和已记录次序，从 H 恢复全部逻辑槽、快照与作用沿革；快照和索引只加速。旧迁移的分解未知与部分新槽并存时，采用 §3.2 的**整个来由投影不可得**结果。

对可用真实来源的非零槽 c，临时计算：

```text
s(c) = max_i abs(h_c,i)
排序：s 降序 → 首次 F 作用在 H 中的位置升序 → 依据身份规范字节序
```

这复用 [ADR 0035 §§4.1–4.8](0035-law-definitions-d07-d09-d11.md)的实际 h、坐标对齐与规范零。全部坐标恰为零才退出；h 可在盒外或与 v 反号，照值排序。max/abs 不添加权重，也不因学得坐标多而通过求和抬高分数。s 仅用于本次本地选择。

当前平复及已经发生的合法回想都已体现在 h 中。[ADR 0038](0038-recall-affect-fading.md)的回想淡化 r 控制未来合法回想的补回，不再乘到当前 h 上。该尺度是 U1 候选；“单件分量大”不等于“删掉这件事后总心情变化最大”。

### 1.3 来源包的唯一构造

**先固定依据沿革，再对原文依赖求闭包。** 下表是 r3 的完整遍历范围，对基础材料与可选来源包一致适用。关系类别按已记录语义及冻结版本的类型映射决定，不由投影器临时读句子猜测“是否必要”；无法区分的关系按未知处理。同一目标同时有接续和正文依赖时，正文依赖仍展开。后继契约须将语义关系映射到已有记录类型，缺少映射时按不可得处理。

| 阶段/关系 | 唯一展开规则 |
| --- | --- |
| 候选槽的成员 | 在 H≤n 中，按已生效治理取该槽及传递合并进来的全部成员依据。别名只解析身份，不另算一件；尚未定案的合并关系按未知处理 |
| 初始来源与目标沿革 | 对上述每个成员，收集首次“新依据”和截至 n 全部已生效“目标更新”所指的原始事件来源；有多个来源就全收。保留历次原文，不只取现行目标那一条。补解释/解释器修订若仍指同一原事件，只增加本地绑定，不复制原文 |
| 对话接续 | “回复上一条”或会话父消息等接续关系，仅保留本记录中已记的直接目标身份与引用；不把目标正文加入集合/工作队列，也不追它的接续祖先。对话保留范围由既有计划决定；目标恰好已在 D 时照 D 呈现 |
| 原文来源与正文引用 | 从已收录原记录，递归展开已明确记录为正文依赖的原文来源、引用/转述关系，所有端点都取。普通文字里的姓名、网址、相似主题，以及无这些语义的普通外键不展开；不新做语义检索 |
| 更正与撤回关系 | 对每条已收录记录，在绑定事实前沿内查全**指向它**的事实更正、证伪、撤回与权限关系；再对新增更正原记录执行相同引用/更正闭包。更正的更正也收录，保留原说法与修正的顺序 |
| 遍历边界 | 候选槽的目标沿革只在前两步展开一次。普通引用碰到另一个依据的原文，不自动展开那个依据的所有 F 作用或目标史；F/解释/前态/资源链接仅用于本地重放与来源定位。纯重访、内部改写和解释文本不是新增原始经历正文 |

具体算法是：把初始原记录身份入集合与工作队列；每次取队列中 H 位置最早者，同位置按原记录身份规范字节序；仅将表中应展开的正文依赖及更正端点加入集合/队列，直到队列为空。接续边只保留该直接引用，不读取目标记录来继续遍历；只因目标正文未被选中或未读取，不判依赖缺失。已访问身份不再展开，循环引用因此终止。绑定前沿包含有限记录；真实原文依赖不以深度、次数或 token 上限截断。查询完整性不能确认、正文依赖端点丢失或关系语义未知时，按 §3.2 处理。

更正闭包覆盖实际采用的原文及其正文依赖；仅作接续指针的目标不因此算已收录原文。若其事实通过明确来源、正文引用或必要任务材料被使用，则相应原文及必要更正必须进入闭包。接续引用本身继续遵守原有身份与使用权限规则。

去重使用不可变原记录身份与内容版本/对象引用；同一不可变对象身份对应不同内容是异常。别名依据合成一个包，但各成员真实发生的不同记录保留；两个人真的说了同一句话也保留两条。最终原文按 H 提交位置与规范身份排序。

包的**可见内容**只取 H 中原始事件/事实 payload 与原有说话人、时间、种类、来源/纠错关系。F 作用、目标与解释/治理记录是本地构造依据；含状态的记录不整条发出。治理只提供关系时，保留其既有事实关系及引用，不为它生成解释句。

可用性按完整包判定：必要来源确定不合格（无真实外根、已禁止使用等）时，候选包整体排除并记录缺口；若属于基础材料则本次请求失败。必要端点缺失或资格未决时，整个投影不可得；不删除包内失效成员后继续使用合并总 h 选材。原话内容被证伪、但“曾说过这句话”确实发生且仍可使用时，原话与全部已知更正一起入包。合并槽的包包含全部已知成员原文，不把总 h 分摊到单条；#183 尚未批准的政策不参与解析。

## 2. 怎么放

### 2.1 先保留对话，并补齐它自身的更正

最终顺序固定为：

**固定协议 P → 已保留的对话 D → 本轮来由 E → 最新输入 o。**

P 沿用事实、边界、格式、语言；D 由既有对话计划选定并保留角色与顺序，包含实际已投递内容；o 在末尾。本轮 E 同时容纳必要事实原文、基础材料所需的引用/更正，以及按 h 选中的经历。各原记录在 E 中按 H 次序排列，容器只标明历史身份与来源。

先锁定本次 P、D、o 和原任务必需的事实查询结果。对 D、o、必要事实以及 P 引用的事实原文，按 §1.3 的“原文来源/正文引用＋更正与撤回”规则求闭包，得到**基础材料**；这一步不展开它们所属槽的目标史，也不沿接续关系补回 D 已裁掉的前文。缺少更正的旧话尚不具备发送资格，不能先把它当作已保留内容豁免检查。

**优先级是：来源可用及更正完整 → 基础对话/任务材料 → 可选来由。** 按最终四段请求与输出预留预算计量基础材料。它们装不下，就结束本次组装，不发送；本次尝试内不删更正、不剪原话，也不挤掉已锁定的对话来塞可选经历。若另行按既有对话计划缩小范围，须新绑定并重新计算完整闭包；只有新的基础请求装得下才恢复。若固定 P、o、必需任务事实及其原文依赖本身已超窗，单独缩小 D 无效。

同一原记录的正文出现位置固定为 **o 优先于 D，D 优先于 E**；D 内保留所选对话中该身份首次出现的位置。原文包引用已有位置，不复制正文；各包所需关系仍保留。P 按完整协议资源使用，不能通过文字相同匹配删协议句子。实际投递片段与完整原记录不是同一个呈现对象：D 只保留已投递范围，只有完整所需原文已在 D/o 时才可扣除该原文的新增占用；不把未投递部分补成她已说过的话。

### 2.2 在剩余空间装入完整包

基础请求可用后，按 §1.2 的排序逐包试放。每次对**去重后的最终完整四段请求**重新序列化、计量，包含包装、来源、更正及输出预留；计量器和模型/包装资源固定。

整包放得下就接纳；首个放不下就停止，后面的包不再试放。实际件数 K 为接纳的包数，没有另设固定 k；一个包可有多条原文，也可因全部已在基础材料中而不新增正文。真实原文不截句、不翻译、不摘要；闭包的计算本身不受这个装包预算截断。

### 2.3 原文依赖四例与长对话例：唯一预期

例中的字母是记录身份，箭头是已记录关系，不是运行参数。除第四例明确超预算外，假定完整请求放得下；所有次序均取记录在 H 中的实际先后。

| 例子 | 已记录事实 | 唯一预期 |
| --- | --- | --- |
| 正文引用与接续分开 | 依据原文 r2 明确引用 r1 原文，r1 以 r0 为原文来源；r2 另有“回复 r9”的接续关系，正文提到网址，没有其他正文依赖 | 来源包正文为 {r0,r1,r2}，三条各一次；保留指向 r9 的直接身份/引用，不取 r9 正文，不访问网址。r0↔r1 若有正文循环引用，仍各一次 |
| 目标更新 | 同次接触有开始 t0、后续 t1、结束 t2；三者依法建立/更新同一槽。之后有纯回想 i 和对 t2 的解释器修订 j，j 未增加事实来源 | 包为 {t0,t1,t2}，不是只保留 t2；i/j 的派生解释不进正文，作用和版本引用留本地 |
| 别名合并 | c1 来源 a1、目标更新 a2；c2 来源 b1；a1/b1 都引用 q。生效合并记录 M 把两槽合并，H 次序 q<a1<b1<a2<M | 一个候选槽，包正文按 [q,a1,b1,a2]，q 仅一次；M 是本地成员关系绑定，不发送其中状态。总 h 不归到 a1 一条上 |
| 更正超预算 | 已锁定 D 中有旧话 d0，H 中另有更正 c；P,D,o 本身放得下，但完整 P,D,E={c},o 放不下 | **本次请求不发送**，不是丢掉 c 后发送 d0。若 d0 原本只在可选包、没有在基础材料出现，则完整 {d0,c} 包放不下时停止可选装包，仍可发送完整基础请求 |

**长对话例：回复链超窗，D 已裁短，o 固定。** H 中有连续接续链 `r0 ← r1 ← … ← rn (=o)`，每条只回复上一条，整链正文已超过固定窗口。本例既有对话计划选定 `D=[r(n−2),r(n−1)]`，不另设默认保留条数；o 仍为 rn。没有正文来源/引用、更正、额外必需事实或合格可选来源包；其余就绪条件满足，P 与这两条 D、o 的完整请求（含引用、包装和输出预留）能放下。

唯一结果是：基础原文集合为 `{r(n−2),r(n−1),rn}`，E 为空、K=0，发送 `P,D,E=空,o`。保留这三条各自的直接接续引用，包括 r(n−2) 指向未装入正文的 r(n−3)；不读取 r(n−3) 来追祖先，r0…r(n−3) 的正文不会自动回填 E。被省去的祖先可以由原有对话计划另行选入，但接续身份本身不保证其指代语境完整。

**恢复条件：** 从失败请求恢复须用 r3 规则和实际 D 范围建立新绑定，再计量完整必要材料。上例既定条件下可恢复；若 D/o 明确引用旧原文 q，或所用原文有必要更正 c，q/c 及其真实依赖仍须加入 E。若它们使完整基础请求超窗，本轮仍不发送；固定必要材料已超窗时，缩 D 不能恢复，须有已获准且足够的可用容量等实际条件改变，再新绑定重组。不能把正文依赖改称接续或删除更正来制造“恢复”。

| 事实查询 | 每次实际查询、参数、用途/权限、前沿、顺序/分页/截断及预算；保存可重放的确定查询输入和资源，或可取回的有序结果对象引用及状态。无命中、缺失、拒绝和预算耗尽分别记录 |
| 来源与装包 | 依据成员、接续/正文依赖的已记录类别及映射版本、保留的直接接续引用、原文/更正闭包引用、排除/未知原因、实际接纳集合、首个溢出包与停止原因、正文去重位置 |
| 发送请求 | P、投影/呈现/序列化/计量资源版本、完整实际请求及生成参数（或足以恢复它的不可变引用）、模型/tokenizer、输入容量及输出预留、实际模式/严格标记、发送前依赖核对 |

摘要哈希只作核验，不能代替上述内容或可取回对象。源内容仍保存在 H/其对象中，回执与 Q 复用现有引用机制，不新建心理账本；后继契约明确不足的字段。规则 r3 的重算目标是：同一绑定及完整资源得到相同的**本地请求字节**。

### 2.5 后置来由的缓存代价

采用每轮替换 E 的后置方案。两轮分别为 `P,D,E1,o1` 和 `P,D,o1,a1,E2,o2`，其中 a1 仅指实际投递部分。共同前缀通常只到 D；移除 E1 后，o1/a1 首次进入干净对话前缀的部分仍须处理。相较“P,E,D,o”，变化位置后移，但不保证整段 D 每轮都命中。

[OpenAI](https://developers.openai.com/api/docs/guides/prompt-caching)和 [Anthropic](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)的官方文档说明缓存依赖共同前缀。需要显式断点的接入资源在稳定部分末尾设置断点；命中仍受接口与缓存可用性限制。这里的两轮比较是据此前缀规则作出的设计推导，不是实测。

将旧 E 永久留在对话流会保留已经落选的来由；把 E 固定若干轮会引入陈旧材料及重建条件。两种都不在本次采用。缓存命中与否不参与选材；撤回、更正、窗口裁切或资源变化时重组，接受缓存损失。次序、角色、转义、去重位置和预算一起版本化；更换次序后重新计量完整请求。

## 3. 放不下或失败怎么办

### 3.1 U6 等待路线的候选行为

| 情况 | 本轮行为 |
| --- | --- |
| 解释与有序提交完成 | 按 §1.1 取满足条件的前缀；有效的“无作用”结果也可回复 |
| 解释仍在排队、前序尚未提交 | 保留本轮输入身份，等待其有序依赖；运行界面如实显示等待。其他获准任务按既有公平调度继续；不提前生成本轮角色回复 |
| 解释失败 | 只按已经绑定的有限重试资源重试；耗尽、不可重试或没有获批重试配置时，结束本轮为失败。运行状态通知不冒充她的回应，也不将失败占位算作感受已形成 |
| 积压、过载、用户取消 | 沿已有任务的取消、截止与资源过载判据终止/暂停并记录原因；不在本文编超时数字。该路径所需终止/有限重试资源尚未冻结时，不启用等待方案 |
| 失败后才补齐解释 | 按现行合同有序提交，影响后续状态；不自动复活已失败/取消的回复任务。重新请求或获准重试建立新绑定，旧输出不重复投递或产生作用 |
| 组装后解释/依赖改变 | 已发请求保留当时版本；尚在途且依赖失效的部分按 §3.2 取消、重组，不用新解释回填旧输入 |

这条候选不自动降级到 N0；要允许超时后先回复，属于另一个须显式选择的回复策略。本卡只列“保留 N0”与上述等待路线，不暗加第三条自动切换规则。

### 3.2 后继验收：失败结果必须唯一

以下均为**设计要求、not_run**。例中原文均为合成记录；后继卡才运行检查，不读取用户正式或排练存储。

| 情形 | 必须验证的结果 |
| --- | --- |
| 两次组装之间或发送前有撤回、更正、权限变化 | 旧前缀不冻结发送资格。按 ADR 0026 §5.1 检查来由、D、o、必要事实、P 引用事实及依赖的派生对象；使相关在途请求/待投递结果失效，重新绑定、重建闭包。已投递部分如实记录，无法撤回的内容不称已收回 |
| 本地估计能放下，API 拒绝或自动裁切 | 将该请求记为容量/完整性失败；可控制的接口禁用静默裁切。服务方保留范围无法核验时，不签发输入忠实成功。新预算/模型/范围必须新绑定并重组，不沿用原摘要、不删更正后续跑 |
| 两包共享原文及更正 | B1={s,a,c}、B2={s,b,c}，c 更正 s，H 次序 s<a<b<c，基础材料不含它们，且两包合后放得下：K=2，E=[s,a,b,c]，s/c 各一次 |
| 一个包部分已在对话 | D 已有完整 s，c 是其更正，B1={s,a,c} 且全请求能放下：基础 E 先含 c，接纳 B1 后 E=[a,c]，s 留 D、c 一次；按最终完整请求计量 |
| 最大包放不下但后面短包放得下 | 基础请求完整可用：停止在最大包，K=0，不尝试后包；E 只含基础必要材料 |
| 基础材料耗尽预算 | 完整基础请求恰好达到容量，首包还需新增原文 a：K=0，发送基础请求；若基础请求本身超容量，则不发送。已全在基础中的包可零新增占用接纳 |
| 长接续链、裁短 D、固定 o | 按 §2.3 的长对话例核对唯一原文集合、直接引用、E为空及可恢复结果；接续祖先不回填。再增加明确正文依赖/必要更正，验证真实闭包仍完整，超窗时失败，不能以缩D一概宣称恢复 |
| 请求取消或仅投递部分输出 | 下一轮 D 只把已记录实际投递范围当作已说的话；完整生成稿仍按原合同记录其真实身份。旧响应/重复回执/重试不重复投递，不重复推进作用与消费 |
| 旧迁移分解未知与新槽可恢复并存 | **整个来由投影不可得，本模式不发送该生成请求**；不只挑恢复出的那部分后宣称全局最重。冷槽只要能按原规律完整恢复不属未知；不按新规律倒造旧分解 |
| 包关系未知、原文丢失、查询完整性不能确认 | 整个投影不可得，结束本次组装；不把未知包当小分量跳过。与“已知不合格而排除”区分；基础材料本身不可用也不发送 |
| 同一绑定重复组装、回放与缓存命中变化 | 本地输入字节相同；H/x/R/θ/L/Q、槽、时钟、证据/消费状态不因取材改变。缓存只加速。需恢复的资源或对象缺失时明确不可复现 |
| U6 等待、失败、积压及后补解释 | 验证 §3.1 每一分支，本轮输入尚未有效处理时不冒充已经感受；测真实队列等待和首个有效输出时长，不在设计阶段预填通过 |
| 上下文位置与语义 | 验证四段次序、原说话人/时间、最新 o 身份、完整更正和实际投递范围；后置对指代、忠实性、自然表达与三语的影响后继实测 |

### 3.3 真正没有经历时

如果槽与来源都完整可知，却没有合格的非零真实经历，新增经历材料为空，仍可发送完整基础请求。刚出生时保留 H 中真实诞生事实、名字、能力/环境和当前对话；不存在的往事不补。

回执分别记录“无合格经历”“可选包超预算”“投影不可得”“基础请求失败”。前两者可有合法请求，后两者本轮不发送；空包不被写成她处于中性。

## 4. 用户选什么

所有建议均为候选。U1–U4 延续初稿；U5、U6 沿用 r2，编号不互换，本轮不新增 U 项。

| U 项 | 白话场景 | 候选建议与取舍 |
| --- | --- | --- |
| **U1：当前分量怎么量** | 旧大事已经平复，新小事还压着；多坐标的感受也可能不同 | 建议按当前 h 的最大绝对坐标及稳定次序，不按“再想起可能有多强”排序；这个尺度由用户决定 |
| **U2：完整来由与窗口** | 最重的一件很长；长对话已裁短，真正引用的旧原文及更正却仍可能很长 | 建议接续只保留直接身份/引用，原文依赖仍完整；无固定件数、首个可选包溢出即停。基础更正优先，固定必要材料超窗时缩D无效；缺少祖先正文的指代语境也不保证完整。接受这些代价，或另定规则 |
| **U3：已经淡了的原话** | 只剩一件很淡的旧事，它仍第一名，文字却和刚发生时一样 | 建议保留原话并接受强弱损失；若不能接受模型反应过重，先补表达设计再启用 |
| **U4：小事合力与长期底色** | 二十次小冷遇合起来超过一次好事；或多年经历已改变平常心境，当前槽都已平复 | 建议先接受当前可追溯残量的覆盖范围；若首版必须完整传达累计作用，先补原文集合/长期来源设计 |
| **U5：第一版独处思考** | 你不说话时，她是否仍能继续想，并由此决定主动开口或行动 | 下表三条路线，由用户选；本稿不推荐其中一条 |
| **U6：感受先于回话** | 你刚说了一句有分量的话，她应先被触动再回答，还是先回答再完成理解 | 按用户倾向提出 §1.1/§3.1 的等待候选；接受等待和失败时不生成本轮回复的代价，或保留 N0。用户倾向不记成已批准 |

### U5 的三条路线

| 路线 | 第一版具体会怎样 | 条件 |
| --- | --- | --- |
| API 说话，本地 A 思考 | 对话用 API；独处时由本地严格载体接续思考、决定后继和行动提议 | 现行规则允许这种分工，但需要可用 A 载体、接线及验收；API 不能先定路线，再让 A 只改口吻 |
| 第一版只有 B | 可继续已有用户交互回复、合法任务后续，以及核心按事件记账/成长；暂没有获批的持续独处思考路径，也不能由该循环产生新主动时机 | 由用户接受这个首版范围；不恢复 V2-117 已取代的旧强度函数/thinning |
| 第一版纯 API 也要独处思考 | 希望没有本地 A 时仍持续接续并产生自己的后继选择 | 另作非严格认知扩展，明确取代 ADR 0026/V2-117 的范围，覆盖接续、记录、重访、预算、故障、行动选择；本稿没有定义或批准该循环 |

### 5.2 淡化、合力与长期心境的覆盖

入选旧事仍交原文。h 平复后，旧事可能被挤出，或在确切归零后退出；若始终只剩同一件非零旧事，输入文字可能完全不变，API 无从精确恢复强弱。存在年龄只计算已证明的核心运行区间，与日历日期不同；仅给时间事实不能替代核心的淡化计算。0038 未冻结的曲线/数值不能由本稿补出。

许多小事各有 h 时，完整包能装多少就交多少，但单件排序可能漏掉合力：无饱和的一维例子中，二十份 −1/100 与一份 +3/20 合为 −1/20，单件排序却先取正的一份。这只是代数见证，不是运行参数或测量。相反残量的抵消也可能未完整呈现。

已经改变 b/R/θ 的经历不一定仍有活跃槽。派生余项 y 只用于证明/测试，不作为新增背景状态或模型输入；不能从长期状态倒编故事。以上损失交 U3/U4 决定，不以阈值、重复次数、隐藏标签或新主题摘要补偿。

### 5.3 API 发出内容与开放问题

| 发给 API 服务方 | 留在本地，不作为生成正文 |
| --- | --- |
| P 中的既有事实/边界/格式/语言；实际 o；保留对话与实际投递片段；必需事实和入选经历的原始内容，以及原有说话人、记录引用、种类、时间和纠错关系 | 整个 H/L/Q、槽全集、x/R/θ、m、h/v、a/μ、排序和存在年龄计算、未选原文、解释/人格摘要 |

原文里的姓名、对话与活动事实会随材料发出。按用户方向不新增敏感词、脱敏、匿名化或逐条审批；既有来源使用权限和在途失效仍适用。每轮请求从明确保存的内容重建，不依赖服务方未记录的聊天线程或隐藏材料。

**O1：助手、客服、心理咨询腔。** 这是用户提出的体验问题。本卡不加“别像助手”的人设、话术或后处理，也不宣称真实原文已经解决它。
