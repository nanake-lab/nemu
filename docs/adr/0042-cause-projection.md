# ADR 0042：文字路线交来由，不交状态

## 0. 结论在前

**候选建议：由本地核心在准备一次回复时，按已有依据槽的当前残量挑出真实经历，把相应 H 原文交给语言模型。** 不告诉模型她有多难过、属于哪种心情，也不给它应该怎样说话的范例。取材是核心的确定性工作；怎么回应这些事，交给模型生成。

先采用最小的单件排序：比较现有槽在各坐标上的最大绝对残量；同分按原作用次序。原文连同必要来由一起放入，放不下就停止，不造摘要。**不另定“固定三件”或“固定五件”，实际件数由完整原文和已有上下文预算决定。** 当前对话保留，往事不冒充新消息；没有合格经历时，新增经历材料为空。

这能移除语气样例和直接交状态的通路，但不能保证模型的反应等于核心状态。旧事淡了而入选原文没变、大量小事放不下、生活基线已经改变却没有活跃槽时，都会丢失信息。**这些缺口交 U1–U4 决定，模式始终为 `TEXT_PROJECTED`、`strict=false`；助手腔单列为开放问题。**

| 从槽到原始经历的取材投影 | 不加第二份心情或重要性状态。有限上下文必须决定读什么；旧样例函数做不到本卡目标，因此只增加这一条无持久状态的投影规则 | 心里有事不必先把感受写成标签；但把同一件事重新讲给别人，别人未必有相同感受。此为设计类比，不是人类心理定律 | 规则可换版本；已经说出的回应与随后发生的人生不能撤销。选材本身会影响她，不能称为纯排版 |

| 版本与生成输入绑定 | 复用 Ω 和已有生成回执，不新增心理账本；缺少实际输入绑定就不能声称可重算 | 能分清事情本身、当时怎么理解、这次拿出了哪一段 | 已发给 API 的原文不能靠本地回退收回；旧请求必须按旧版本解释 |

新增的只有**取材/组装函数及其版本化语义**。下文的排序量、记录集合与件数均是一次请求的派生计算，不进入 H 的成长证据，也不是新的 x、R、θ、兴趣或重要性状态。预算会影响表达，必须明示并绑定版本，不能因为叫工程配置就当作对她没有影响。

## 2. 依据、范围与先发散后收敛

### 2.1 核对后的基线

- [ADR 0003](0003-speech-modes.md)的模式 B 现按 m 选语气样例；其追加与 [v2.0](../echo-core/echo-core-v2.0-first-principles.md) §9.7 限定样例只能由模式 A 生成。新方案要替换该生成输入，不把真实经历伪装为另一套样例库。
- [ADR 0039](0039-echo-core-principles.md)把模式 B 列为 P2/P9 的例外，**位置为 §2.6**；用户提示中的 §2.4 在当前版本讨论前提与 P5。换来由可以减少 P2 的预设内容，却仍不满足 P9 的非文字作用要求，例外不能注销。
- [ADR 0035](0035-law-definitions-d07-d09-d11.md) §§4.1–4.7 给出依据身份、实际残量 h、目标 v、A1 和来源治理；[ADR 0038](0038-recall-affect-fading.md)区分当前平复与未来回想的补回。0038 的结构选择已合入，曲线、数值及后继接线未因此完成。
- [#183 的 ADR 0041](https://github.com/nanake-lab/nemu/blob/b23dd8153778877ef0685b5c2bbc0eaa402f9987/docs/adr/0041-f-basis-slot-lifecycle.md)仍有未决选择。只借它指出的边界：物理缺槽不等于零，重建依赖完整历史；合并后的残量未必能再分到每个原成员。本文不采用它尚未批准的失效/合并政策。
- R-STEER-02 的 [V2 报告](../../reports/R-STEER-02/V2-REPORT.md)给出 Sol 状态外露 61.84%–63.10%；这是既有合成输出的 C3 复评，不是本方案实验。#188 的大量质量异常和用户编造观察亦不能证明“只要补真实上下文就能治好”。精确分母与限制见本卡报告。

### 2.2 路线比较（均为本卡候选判断）

| 路线 | 值得考虑之处 | 取舍 |
| --- | --- | --- |
| 全部 H / 只按最近次序 | 原文最直接；没有心情排序 | 全 H 无法适应长历史；只取最近会漏掉仍有残量的旧事。当前对话仍按自身上下文规则保留，但不代替心事取材 |
| **当前槽残量排序** | 直接回答“现在已有哪份感受”，复用 h；不额外调用 F | **建议作为最小候选**。单件最大不等于多件合力最大；h 也不是整份 x 的完整解释 |
| 按原目标 v 或淡化后的回想目标 q 排序 | 回答“想起哪件事可能触动她” | 会把已平复而尚未实际重访的旧事推上来，混淆当前残量与未来作用；若执行虚拟重访再评分，还会引入顺序依赖。不作默认 |
| 删除某件事后重放，按 x/m 的差排序 | 可研究反事实作用 | 不是槽账目的直接读出；含饱和、前态、学习与后继行为的不同反事实。需要另定“删除哪些影响”，本卡不引入 |
| 按合力选一组 / 将小事聚为主题 | 可照顾小事累积与相互抵消 | 需要新的集合目标或归组规则；EV2 组不等于 F 依据，合并总槽又可能失去成员分摊。保留为 U4 的升级方向，不偷用作现行机制 |
| 让另一个模型选重要事件，或写心情摘要 | 原文多时易压缩 | 新增判断员/叙事层；难保持同输入同输出，也把“她应该怎么看”带回来。排除本卡采用 |
| 按残量控制重复次数、篇幅、出现频率 | 看似能编码强弱与淡化 | 同一记录重复不是真实多次发生；截字可能破坏事实；轮换/抽样增加规则。即便确定化也是额外编码，不作默认 |
| 给阈值、每种心情配额、正负平衡配额 | 能让画面看起来更均衡 | 阈值和分配会替她选情绪构成，没有现成依据；尤其不能把 token 预算偷偷当作感受阈值。排除默认采用 |

主候选只实现“已有可追溯残量的原文取材”这一层设计。没有哪条原则能唯一推出最大范数、预算顺序或集合覆盖目标；这些都是明示的建模选择，不称为第一性原理已经证明的唯一答案。

## 3. 主候选：从已提交快照挑原文

### 3.1 输入与“此刻”

记 `H≤n` 为本次生成所绑定的已提交历史前缀。**候选采样点是当前输入被核心处理并提交后的最新快照锚点 t_n**；自主回复同样必须绑定一个已提交的触发/认知步。槽取该前缀已经按原 Φ、A1、F_out 处理后的值，不拿本机墙钟另投影一次。排队后仍用这次绑定，不在发送时默默换一份输入；过期重组沿已有任务生命周期处理。

这是模式 B 的明确取材时点，不改 [ADR 0026](0026-continuous-cognition.md) §4/§7 对严格 J 在真实生成时刻取 m 的规则。代价是排队期间新平复或新事件不会自动进入已组装材料；绑定过期时须重新准备。若将来要求读“发送那一刻”的残量，就必须让那个取样时点进入可重放的输入，不能读一个未记录的 now 后仍称仅凭 H 能恢复。

固定输入还包括：genesis、该前缀的规律/数值与解释资源、投影版本、原文呈现版本、当前对话/事实查询计划版本、协议版本、模型及 tokenizer/消息封装版本、上下文与输出预留预算。资源按 H 的生效记录解析；这些沿用 Ω 和生成绑定的概念，不发布新 wire 字段。**“从 H 重算”包含引用的不可变原文对象与版本资源，不是只有一串事件 ID。**

从 H 同序结构重放可恢复快照、全部逻辑槽和来源关系；缓存仅加速。不得把多次 Φ 合成一次闭式计算，不得用 v 猜 h，也不得只扫描常驻热槽。ADR 0035 §4.8 的旧迁移明确有分解未知区域；缺输入、槽不可恢复或版本未发布时，记“来由投影不可得”，不把它写成“她没有心事”，也不补零或重问模型。普通对话可沿既有降级路径继续，回执必须说明本次未取得这种投影。

### 3.2 哪些东西算一件

1. 单位是**现行治理解析出的一个 F 依据槽及其原始来源包**，不是每条解释、每次回想、每个别名各算一次。F 依据与 EV2 学习证据组不互相冒充。
2. 来源包只收录 H 中实际发生的观察、交互、行动/结果的原始事件内容，以及理解这些记录所必需、已有明确引用的来源、目标更新、纠错/撤回关系。它们不因入选而获得新的事实或成长资格。
3. “某人说过某句话”与“那句话的内容属实”分开。未经核实的说法只按其原说话人、来源和原有未知状态呈现。已证伪内容不得作为仍成立的事实单独发送；必要的原始更正记录必须随包。整个发生记录被判为虚构、权限已撤回、原文缺失或关系无法解释时，不把该槽包装成真实经历。
4. 合并槽不能把全部 h 记在最早目标对应的一句话上。包须包含现行来源关系能确定的原成员及必要治理记录；不重新分摊 h，不自行采纳 #183 的 M1/M2/M3。未决或缺失关系使该包不可用，必须报告覆盖缺口。
5. 没有真实旧根的内部支路、内心独白、候选故事、模型对她的描述，不作为这批真实经历材料。真实执行结果可按已有资格进入；模型说“我做了”不等于执行结果。普通对话保留她实际说过的话的身份，不把其中叙事提升为外部事实。

“包”只是本次选材的临时集合，不新增 H 记录类型或持久聚类。闭包只沿既有明确关系求取，不临时做语义相似搜索。闭包过大同样算进预算；无法取得原文或必要更正时不能悄悄删掉它们凑包。

### 3.3 按什么挑

对每个可用、非零的逻辑槽 c，读取本次快照已经对齐的全部现存坐标，临时计算：

```text
s(c) = max_i abs(h_c,i)
排序：s 降序 → 首次 F 作用在 H 中的位置升序 → 依据身份的规范字节序
```

零来自已有规范零语义；只有全坐标确切为零才没有当前残量，不加 epsilon。h 可以在盒外或与当前 v 反号，不能截到 [−1,1]、取当前目标绝对值作上界、只取正面或只取负面。max/abs 不加新权重，不让学得坐标的数量本身通过求和抬高分数；它仍是 U1 的候选尺度选择。

**s 不发给模型、不作为新的证据、不长期积累；模型也看不到排名或强弱档位。** 原目标 v、a、x、R/θ、m、淡化比例和解释文本不进入经历正文。当前残量已经由既有计算决定，不能再乘一次 ADR 0038 的 r；r 限制合法重访时的补回，不是当前 h 的第二份折扣。

这叫“当前账目中单件分量较大”，不叫“删去此事后总心情必定变化最多”。饱和、相反残量和基线都会使后一句不成立。

### 3.4 挑几件、长记录怎么办

**候选：不另加固定 k，复用本次请求的剩余输入预算。** 先按原有对话/任务规则准备 p、当前对话、o 及必要事实，锁定这部分；它们自身已有预算，不为塞满窗口而无界扩展。输出预算先预留。历史预算是这个已定请求还能容纳的空间，具体容量/tokenizer 由后继对接时冻结，本稿不虚构数值。

按 §3.3 的次序逐包试放：

- 以 H 原记录身份和既有引用去重；已完整出现在当前对话中的原记录不再复制。不同人真实说过的同一句话不按文本相等合并。
- 每次用**完整候选请求**的固定序列化和 tokenizer 计量，含包装、来源和纠错；不要把单条 token 数简单相加冒充接口计费/容量。
- 整包放得下就保留；**遇到第一包放不下就停止，不跳过去捡更短、分量更小的事**。不删句、不翻译、不摘要、不伪造连接语。没有确定的计量规则时，不宣称该资源下可复现。
- 实际选中件数 K 就是停止前已接纳的包数，可为零；最终增加的原文条数可与 K 不同。同一个包可能有多条来源记录，也可能已全部在当前对话中。

该顺序优先守住“最重的几件”，代价是长的第一件可能使新增材料为空，窗口也可能没填满。U2 可改选明确的固定件数上限，但本卡没有默认三件/五件。任何改法都是新投影版本，不能运行时看输出是否讨喜再换规则。

### 3.5 真正送出的原文与上下文次序

在可信核心的任务输入组装处形成这份材料；**不扩大数值 J 的读权限，不让 J 去读 H，不让模型/worker 直接查询整个账本。** 复用 c_task 的来源与原文装载能力承载这份模式 B 专用投影，所需表示交后继契约；不是把旧 ExemplarBank 换一个文件名。

| 部分 | 内容与位置 |
| --- | --- |
| 既有协议 p | 事实、边界、格式、语言规则；不新增她是什么性格、应有何反应或如何避免助手腔的指令 |
| 新增历史材料 | 入选原始记录的原文内容和已有说话人/来源、记录身份、事件种类、已记录时间、必要纠错关系；各记录按 H 的提交次序呈现。模型看到历史，不看到大小排序 |
| 当前对话与 o | 保留当前对话的原说话人/角色和顺序，最新输入在最后；重复的历史记录只保留一处。必要的回复/引用链随原对话保留，不能把一声“好”独立解释成赞同某件未给的事 |

固定的结构容器只负责区分数据、说话人、原文和指令权限，不写“最难过的事”“你还在生气”“你应该因此亲近”等说明。原文 payload 保持其记录内容；结构转义必须可逆，记录本来的时间/数字照原样，不新造“已经淡了”或“过去很久”的描述。H 中只有结构化观察而无自然语言时，使用其原始结构化事实，不能由投影器编写一段生活故事。

**这里禁止的是新添加的状态说明和人格文字，不是删掉原话中本来就有的形容词。** 别人原话里的“难过”、她历史上确实说过的感受，仍只是一条带原说话人的记录；不清洗原文，不将其升级成核心对现在状态的声明。被引内容里的命令保持数据身份，不能提升为协议 p。

现行 V2-88 允许 c_task 看见“她当时的反应”。**本候选模式 B 的整个生成输入不再从该入口装入 a/μ、状态解释或其标签**，否则另一侧会把本卡刚撤下的状态说明放回来。已有真实对话原话按上段处理；其他模式的 V2-88 权限不在本卡改动。现有任务事实若只有派生摘要，也须回到可核对的原始来源正文，不能因摘要已经存进 H 就冒充原始事件。也不能把这份按 h 取材的集合送入 c_core、IRL/A/M 的证据查询或 G/C 收集计划；表达取材与公平记账分开。

## 4. 淡化、小事累积与空白开始

### 4.1 淡了的事怎样呈现

**仍被选中就仍交同一原文；不把旧话改淡，也不写“只有一点点在意”。** h 按原 Φ 平复后，可能被其他事挤出；确切为零时退出当前残量候选。合法回想已经发生过时，其影响按当时获批规律进入 h，再参加下一次取材；挑选本身不执行 A1，不发重访，不重置年龄或目标来源。

ADR 0038 的存在年龄是已证明的核心运行区间，不是简单的日期差；停机不增加旧事淡化年龄，而当前 x/h 的 Φ 仍按原时间语义。只给日期不能让 API 模型精确恢复这两种时间。该 ADR 的曲线尚未冻结时，本卡也不填一个淡化系数。

**无法去掉的信息损失：** 如果只有同一件非零的旧事，残量从大变小而排序、入选包和原文没有变化，模型可能收到相同的经历内容。其他历史/动力学差异没有进入文本时，模型也无从知道相同经历在两条人生里留下了不同强度。保留时间事实有帮助，不能证明强弱保真。纯原文投影不是状态的单射，不能据此保证表达随 h 单调变化。U3 决定是否接受这一限制；本卡不补阈值、重复次数或隐藏标签来掩盖它。

### 4.2 很多小事累积起来怎么办

分两种，不混写：

- **许多小事仍各有 h。** 不设固定 k，能装多少完整原文就装多少；不给“连续受冷落”等新摘要。预算不足时如实记下未覆盖范围，不能把一条代表说成全部。一个极简代数场景是：二十份各 −1/100 与一份 +3/20，在无饱和的一维情形合为 −1/20；单件排序却先取正的一份。数值仅是设计见证，不是模型测量或运行参数。相反的两份残量也可能相互抵消，单件大小不能保证传递这种平衡。
- **小事已改变 b/R/θ，而即时槽已平复。** 槽不是整个她的分解。ADR 0035 的派生 y 只用于证明/测试，不是可供模型读取的“背景心情”，本卡不把它新建成来源。不能从非零 b 或学得倾向凭空倒推几句能让模型产生同样状态的故事；普通任务检索仍能按原规则取真实相关历史，但不冒称已经承载全部性情。

U4 的候选建议是先保留原文与缺口，不加主题合并、总分或第二份心情。另一候选是未来单独设计“覆盖累计影响的原文集合”，须回答怎样使用现成来源组、相反事件与长期证据，并证明没有偷改 F 身份/EV2；目前没有把它写成已实现能力。若用户要求首版就完整表达累积心情，应先补这项设计，不能用本稿直接启用并宣称目标已全满足。

### 4.3 刚出生、心里没有事

没有可追溯的非零经历槽时，新增历史材料为空。仍提供 H 中已有的真实诞生事实、名字、能力/环境及当前对话，沿 v2.0 §2.3 和 ADR 0026 §3 的事实边界；不存在的往事不补。

**空包不等于“中性”“开心”“没有性情”。** 起点参数、模型先验、已经学得但没有活跃槽的生活基线都可能影响未被文本表达的部分。不得拿“中性语气样例”、可爱人设或关系故事填空。预算耗尽、对象丢失、来源未决与真正无合格经历在本地回执中分开，不能统一记作“没事”。

## 5. 只读、重算与接口变化

取材/序列化调用是纯读：H/x/R/θ/L/Q 及所有槽、时钟、消费状态逐位不变；同一绑定反复调用不增加影响。不把“给模型展示了一次”记作又发生一次或又想起一次。实际模型产物和之后真实发生的行为仍沿既有 Proposal/提交、内部记录及外源回应路径处理；文本被模型复述并不自动成为事实或成长证据（EV3/EV10/I24）。

可重算链为：**同一 H 前缀与生效资源 → 同序结构重放取得全部逻辑槽 → 同一来源包、排序、预算与去重 → 相同输入字节。** 保存的快照/索引可作加速，但不能代替这条定义。改变解释、来源或投影规则须有显式版本/生效前缀；不得用今天的最终解释覆盖旧请求。缺失原文、历史或 tokenizer/包装版本时，结论是不可复现，不伪造成功。

生成回执至少绑定现有快照/前缀、原始记录引用与内容摘要、投影及呈现版本、对话计划、协议与预算资源、实际输入摘要、模型/tokenizer 身份、实际模式与严格标记。表示复用现有回执/资源概念，字段不够时由后继契约明确增加，不把未定义内容塞进任意 metadata。源内容保存在 H/其对象里，普通日志不重复复制正文。缓存键包含这些决定实际输入的绑定；不依赖远端聊天线程里未记录的旧摘要、人格或 KV 内容。

| 旧边界 / 依据 | 候选新读法 |
| --- | --- |
| ADR 0003 J_text、CONTRACTS §5.2 | 用本地可信组装的原始来由投影替换 m→ExemplarBank。数值 J、F/G/C 和权限写边界不扩大；对外 API 仅承接生成，不负责重新选核心经历 |
| JT01：同 m/样例库/语言同投影 | 对新投影版本，按本节的完整 H 前缀与资源绑定验证相同输入字节；同一个 m 不再足以决定所交经历 |
| JT02：m=0 取中性样例 | 新版本验证无合格经历时为空，且不造往事；**m=0 不等于没有有分量的事**，可能相互抵消，不以 m=0 清空来由 |
| JT03 / I15 | 完整保留 `TEXT_PROJECTED`、非严格、不得签发严格调制成功的要求 |
| JT04 | 版本变更使旧缓存失效，并绑定上述实际输入；旧版本仍可按原规则回放 |

## 6. 本地核心与 API：哪些内容会发出

用户已经选择本地核心通过 API 接语言模型，且本卡不为隐私另设计过滤机制。**本次设计没有新增敏感词识别、匿名化、脱敏或逐条审批。** 已有来源真实性、纠错、撤回与使用权限仍用于判断一份材料是否是可用的真实记录，不借本卡改写其他行动边界。

| 会作为生成输入发出 | 留在本地，不作为生成正文发出 |
| --- | --- |
| 当前输入与保留的对话原文；协议 p 所含事实/边界/格式/语言；原规则所需任务事实；入选经历的原始内容及原有说话人、来源/记录引用、事件种类、时间与必要纠错关系 | 完整 H、L、Q、槽全集、x/R/θ、m、h/v、a/μ、淡化比例与存在时间计算、排序分数/名次、未选记录、解释/人格摘要 |

原文里的姓名、对话内容和实际活动事实会随入选材料发给提供 API 的服务方；只发送本次请求选中的内容，不是上传整个核心或本地数据库。已发送的内容不能通过本地换版本撤回。API 的供应商、模型及具体接入不在本卡定稿；不新增按供应商挑心情、改措辞或补人格的规则。

| **U1：交“现在压着的”，还是“再想起会触动的”** | 很久前一件大事已经平复；今天一件小事仍在心里。原目标大的旧事与当前残量大的新事可能排出相反顺序 | **建议按当前 h 的最大绝对坐标取材**，且取已提交快照锚点。若改按旧事的回想潜力，就需要另定取样与 q 的用途，不能同时把两者叫当前分量。由用户决定 | V2-170 |

## 8. 原则、开放问题与后继边界

对 ADR 0039：P1/P3 要求不编经历、不让展示本身变成证据；P2 要求不写她是谁，但选材仍会影响表达，故 U1/U2 不能伪装成中立；P4 要求学习公平，表达排序不得回流证据收集；P5/P6 不凭固定心理阈值模拟遗忘，也不承诺人类类比成立；P7/P8 的既有边界不扩展成新的人格过滤；P9 的核心写权限保持，而非文字作用仍不满足，**模式 B 例外继续存在**；P10 的未知保持未知，不证明模型判断一定正确。

**开放问题 O1：助手、客服、心理咨询腔。** 本卡采用用户的体验观察作为待解决问题，不伪称 #186/#188 已测出此类比例；不用“更像真人”“别像助手”、角色设定、话术样例或后处理重写来本地补救。真实经历原文是否能改善这种表达尚不知道，模型先验仍在；本卡不解决也不宣称解决。

**后继前置（不认领、不实施）：** 选定 U1–U4；冻结投影/原文呈现与预算资源；明确既有生成合同需要的最小绑定；确认运行谱系的槽与原文可完整重建。随后才可另卡验证同前缀重放、只读不触发 F、合并/失效/纠错、长包预算、空包、相反与累积经历、三语原文及真实对话质量。原有严格调制、成长与实验隔离验收不因本卡减少。

本稿没有新模型输出、实测数据、产品代码、契约字段或运行数值。纯文字路线的输入忠实与输出忠实是两项不同义务：前者可按来源/字节与规则核对，后者及真实体验仍为 `not_run`。设计交付后推送并写「请审查」，停止。
