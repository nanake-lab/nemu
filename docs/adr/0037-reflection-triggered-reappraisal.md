## 1. 问题、依据与术语

用户希望她能回想真实发生过的事，改变对它的理解，再改变以后的选择。这里的「重新评价」指一条可追溯的计算路径，不把心理学名称当机制，也不声称本设计复现了人类的心理过程。

已定约束来自 [v2.0](../echo-core/echo-core-v2.0-first-principles.md) §§2、4–8、14、17、[ADR 0026](0026-continuous-cognition.md) §§5–6、[ADR 0032](0032-presets-as-starting-points.md) §§1、3、5–6、[ADR 0035](0035-law-definitions-d07-d09-d11.md) §§3–5、8：

- H 的原事件与旧解释只追加不改；「当时发生了什么」「当时怎样理解」「现在怎样理解」可以不同，但不能互相覆盖。
- 念头可进入 H、提出假设和检索请求，不能因为有了 H 的记录身份就成为外部事实或成长证据（EV1/EV3）。
- m 可以影响关注什么；证据路径的 c_core 不由她当前的叙事或自主 FactQuery 决定。IRL/A/M 不读 x、m、θ、倾向强度；G 可读其原合同允许的证据统计量。
- EV7、EV9 及 EV4 中撒谎排除的旧读法须结合 ADR 0032 §6、[ADR 0033](0033-helper-fuses-cursor-evidence.md) §4：建议不直接作证据；发生、属实、主观分开；真实后果保留，可比性要求不取消。
- ADR 0035/P5-70 的同依据替换属于 **F 的快状态**。它不证明 G/C 已有本 ADR 的资格、解释版本选择或提交路径，也不证明语义判断正确。
- ADR 0026 §6.10 已允许内部候选按 EV5 回溯真实旧组并重新分摊；因此「没有新外部事件」不必然等于「R 绝不改变」。内部记录仍不是证据，C 仍恒等。

本设计区分三种身份：真实事件与 EV2 的证据组；解释修订记录；F 的依据槽。三者有引用关系，不假定三种 ID 相同，也不把 EV2 的分组规则套成「所有外部刺激只推动 F 一次」。

## 2. 发散：四种可行机制

下面均是可以继续设计与实现的路线，不是全部已获规格授权。成本是相对工程范围，未作工时测量；各路线的 EV 对照见 §3。

### A. 完整重释：G 与 C 都采用修订解释

- **触发：** 内部活动指出真实旧事件、出现可核对的理解差异；独立 m=0 路径重做 z、a、μ。可使用当时漏联的已有事实，或后来发生的真实事实。
- **记录：** 旧事件、旧解释保留；追加目标引用、材料前沿、z′/a′/μ′、替代关系、资源版本与生效位置；明确这是今天的新评价。
- **G/C：** G 修订原组贡献；对原本合格的外源经历，C 在原计量位置替换 a，并重算其后全部估计器。内部触发不另加外源计量，不把 a′ 当第二次经历。C 的残差、变点、持续时间、b/σ/g/λ 以及依赖它们的 G 都可能连带变化。
- **防循环：** 使用 §5 的材料去重和不可自举规则；同一输入只采纳一个重评结果，回放不用模型；不按新解释次数增加质量或刷新旧位置。
- **与过去的关系：** 不必虚构事件，但会改变「怎样计算当年感受对今天的影响」。不能把重算后的轨迹说成当时实际体验；改变历史折扣与时间段的范围必须另定完整规律，不能简单在今天追加一次 C。
- **成本与风险：高。** 需闭合 C 修订、全后缀重算、G/C 交互、版本迁移及新单步/重算界；单次错误 m=0 解释可改变很长的性情轨迹。EV6 保留，但 m=0 不代表无偏。

### B. 重新理解归因与情境，保留当时的「乎」评估（推荐）

- **触发：** 内部活动引用真实旧事件，请求重新理解；核心按独立计划取全体相关材料。既允许首次在相同材料上重新思考，也允许后来取回此前未进入解释的真实材料。
- **记录：** 追加 z′、相关概念的 μ′、支持/反对/未知的来源映射与旧解释引用；**a(e) 仍引用该经历原有的有效 m=0 评估**。新解释不伪装成发生在过去。
- **G/C：** G 改变旧经历归属于哪些情境/倾向及其份额，按原组修订，不增加组。当前反思的 C 恒等，θ 与全部估计器不变。改变后的 R 经 F/J 影响以后选择；以后遭遇的真实外源回应仍可正常进入 C。
- **防循环：** 材料绑定、对称检索、固定结果、旧组不刷新、ADR 0019 的历史 q 不追改；新解释不是下一次独立证据。相同材料不能通过改写念头反复重评。
- **与过去的关系：** 能从「他不在乎我」改成「这次沉默不足以证明不在乎」，保留当时失落的 a；不会凭想通了就制造当时的愉快。不能把未记录的善意、动机或行为填进 H。
- **成本与风险：中。** 需要语义修订记录、独立材料构造、G 修订与原子发布，以及后续重访的解释/原前态绑定；不新增 C 数值规律。代价是反思本身不能重写 θ，也不能把负 a 改为正；若成长所需变化必须依赖改写 a，本方案会不足，必须如实报告。

### C. 只提出竞争假设，按已有解释回溯分摊

- **触发：** 念头经 m=0 的 M 提出新候选，例如「忙碌时暂不回复」；原有 z/a 不重新解释。
- **记录：** 内部记录、规范化候选/别名、真实旧组检索与分摊计划、L 变化；沿 ADR 0026 §6.10。
- **G/C：** G 在新旧候选之间重新分摊既有证据；C 恒等。R 改变后影响 F/J，后来的外源经历另进 C。
- **防循环：** 候选只是待证假设；别名不能反复新建，EV5 回溯正反都取，组质量不随提议次数增加。仍需检查不同候选对有限证据的竞争，不能把候选数量当发现数量。
- **与过去的关系：** 不改旧事实，也不制造新事实；但若旧 z 把「不知道是否送达」错读成「明知而拒绝」，只换候选无法纠正根部误解。
- **成本与风险：低至中。** 主要补既有路径的接线/质量验证，不等于现已全链可用。适合原解释足够准确、缺的是新假设的场景；不能完整满足重新理解旧事件的需求。

### D. 反思产生预期，由未来经历检验

- **触发：** 回想后产生可检验预期，允许提出询问或选择另一种行动；不强制行动，不编排她必须遇到什么。
- **记录：** 预期、条件、关联旧事件、实际行动及真实后果；没有执行或结果未知就明确记录未知。
- **G/C：** 当下不因反思改变旧贡献；未来合格经历按 EV1–EV10 进入 G，真正的外源回应进入 C。她自己的工具返回不改标外源。
- **防循环：** 行动与反思不能自证；自致结果作因果证据仍需可比变化；不把反复询问取得的同源回答计作独立支持，不把模拟结果作真实经历。
- **与过去的关系：** 不编造过去；可长期悬而未决，过去无法重现时尤其如此。
- **成本与风险：中。** 复用行动边界和建议/预期路径，仍需完整结果归属与闭环验证；取得证据有真实时间与交互成本。无法单靠已有完整往事实现即时理解变化。

## 4. 收敛与后果

**代理建议：采用 B，C/D 作为既有互补路径，不启用 A。** B 直接实现「旧事 → 新理解 → R → 以后选择」，又保留「当时确实失落」的评估，不增加一个把自我叙事直接写进 θ 的入口。它是有边界的第一种实现，不是所有心理重新评价的总模型。

不选其余方案作本卡主方案的理由：A 对历史 a 的含义及整个 C 轨迹有更大影响，不能仅以“同源去重”证明安全；C 无法修正错误的旧解释；D 把已经具备全部材料的理解变化也推迟到下一次外部经历。单纯保留 F 重访则只改变当下感受，不足以证明成长。

**明确接受的限制（待用户决定）：** 同一事实和资源下的一次重新思考也可能判断错误；冻结第一次结果防止反复抽样，不保证第一次正确。若没有新的有效材料、来源更正或获准的解释器修订，不能不断换措辞重新抽答案。她仍可思考和提出假设，但不能不断重新发行同一重评的成长效果。用户若不接受这一取舍，需重设计，而非暗设次数阈值或置信度旋钮。

## 5. 推荐 B 的具体机制（全部为待批准建议）

### 5.1 触发与独立材料

1. 受 m 调制的内部活动可以提出「重新看看事件 e」；请求必须引用已提交真实事件。无引用、纯想象、引用仅指向自身日记时，不建立证据修订。内部活动照常记录，不因无新理解而被判为故障。
2. 可信核心解析原事件及来源闭包。独立、版本化 c_core 计划决定相关事件范围、顺序与预算，不能直接拿她选出的片段或结论作为证据包。针对同一事件的遗漏、支持、反对与未知按同一规则收集；预算按来源/提交次序等固定规则截断，不按评价正负截断。
3. 证据包记录命中与未完成状态。索引落后、权限拒绝、来源失效、对象缺失或预算截断不能冒充完整检索；本次不发布权威解释修订，保留原因。资源可用时可恢复同一任务，不用空包证明某事没有发生。完整只指已声明查询范围执行完毕，不声称发现了 H 中所有相关事实；遗漏率另测。长历史超过预算可能使重释迟迟不能完成，这是可用性代价，不暗中只取支持项。检索预算来自带版本工程资源，不用次数或时间决定成长。
4. 反思文本只作审计与触发，不传入独立解释的证据正文；解释器先基于真实材料形成 z′/μ′，再比较旧记录。概念定义按现有 M 权限读取，强度不可读；不得把“我已经更信任他”作为解释条件。

### 5.2 一份材料一次重评，不靠改写重新开奖

建议的语义工作身份为「目标真实事件/规范来源闭包、已完成的相关材料集合与来源治理版本、解释/检索规则版本、重评阶段」。这是设计语义，不是 wire 字段或哈希算法。初次实时解释和第一次反思重评是不同阶段；因此**没有新外部事件、同一材料，也允许一次实质重新理解**。

- 同一材料的后续重评复用已提交结果，包括维持原解释与不确定结果；不因为不喜欢结论就重试。合法不确定不是传输失败。
- 内部记录数、全局 H head、措辞、语言、情绪、活动 ID、候选名称、旧/新解释 ID 不给新资格。概念增补本身走 C 的候选回溯路线，不借改概念不断重新打开同一事件的重评。
- 新资格须有可追溯的**相关真实材料差异**、来源治理变化，或经批准的解释资源修订。无关新事件、同源复述、改写摘要不算材料增量。新材料可以早已存在 H、但此前确实未进入本事件完整解释包；记录其原发生/提交位置与此次取得位置，不伪装成刚发生。
- 记录版本化规则如何认定相关/同源；内容哈希不同不等于新证据。材料集合不能通过反复删去再加回旧来源刷新资格；保存已处理材料前沿与依赖引用，属于 H/Q 可重建状态。
- 同一任务的计算失败可按现有工程预算重试，仍绑定原输入与任务身份；所有实际返回保留，第一份完成治理并原子提交的有效结果获准。并发/迟到结果不能覆盖它；成功后不得以重新采样挑有利结果。

这是一项新提议，EV2 本身不蕴含「只准一次重评」。它允许反思触发第一次修订，并以明确幂等语义防止无限同材料试探；它没有保证语义相关性判断永不出错。

### 5.3 记录内容与接受边界

追加一份语义修订记录，至少表达下列含义（后继契约再定类型与编码）：

| 含义 | 必须能核对的内容 |
| --- | --- |
| 对象与时序 | 原事件、EV2 组、旧解释、触发内部记录；材料截止前缀；现在的提交位置与过去的事件位置分开 |
| 实际输入 | 正反材料及来源闭包、检索规则/预算/完整性、引用资格、与上次的真实差异 |
| 判断 | m=0 运行/资源绑定、z′ 与 μ′；每项事实、来源断言、推断、未知分开；原有效 a 引用不可省略 |
| 处置 | 替换/不变/不确定/拒绝及理由；替代的是哪一份 G 解释，旧记录保留；不新增事实事件 |
| 权威作用 | 本次 G 修订计划、前后 R、C 恒等、受影响证据/分摊与 L 引用、成长暂停状态；供未来重访解析的 F 依据、确定现行目标的原记录及其原前态、有效解释与修订生效位置（§5.5） |

来源引用存在只是必要条件，不证明推论成立。结构校验拒绝不存在或越权引用；语义治理必须检查推论与来源的关系、冲突及未知。结果无法判断时保留旧有效解释并记录不确定，不能给 a=0 或 μ=0 来假装完成。m=0 质量需独立金标准验证，不能由自身解释再给自身打分宣告正确。

### 5.4 G、C 与重算

**G 的输入和更新。** 只更新有真实根的既有事件的解释/情境适用性。保留该事件的原有效 a，按新 z/μ 和既有 G 规则计算原组的支持/反对与份额；没有另一份“反思证据”。同组在全部竞争倾向中按 EV5/LP2 对称重新分摊，不能只改触发念头支持的那个倾向。

沿 [ADR 0019](0019-law-lp1-reference.md) §§5–6：旧分配保留 ordinal 与首次计入的 actual_retention q，修改旧分配后按规范次序折叠；不能重估旧 q，把回想当新组刷新新近权重或世界变化率的样本数。既有 F/N/最后符号按修订后解释重放，不能把该记录另算一次翻转。合法新候选对旧组的首次分配仍走原来的 FirstAllocation/反事实审计与同组份额守恒；候选/别名归一不由本卡另造。

**C 的边界。** 这次反思、解释修订及其系统记录都不是合格新外源经历；C、θ、P/S/U、变点与持续时间估计器全部逐位不变。原外源事件当时的 a 与进入 C 的位置不改。真正新到的外源证据照常作为自己的事件处理，不借修订漏计或重复计入。

**重算。** 在 H 中到达该修订提交位置才执行对应 G 计划；较早历史前缀仍给出当时的结果。整段重算复现原始解释、候选与每次修订的先后，不能把最终 μ′ 铺到过去所有前缀再宣称当时已理解。保存的 q/分摊派生状态须能从同序 H 重建。每个提交前缀都要求增量与全段规范重算逐位一致，重算不调用模型。

**来源更正与解释器错误另走既有路径。** 它们不是普通反思：按 v2.0 §5.4/ADR 0019 §6 重算，必要时影响 C，生成相应版本与 L；不能把想换一个解释冒称解释器有错，也不能用本方案的 C 恒等阻止合法纠错。

### 5.5 F、事务与实际选择

- **U3 v2 候选：合法 B 修订沿用 ADR 0035 §4.7 的路径①。** 仅 U2 那一次冻结且通过治理的实质重评，或带新增相关真实材料的合法 B 修订，可使后续重访采用新的 z/μ；原 a 与全部旧记录保留。纯念头、同材料改写、候选别名、维持/不确定结果不改变重访目标。来源失效与真正解释器修订仍走各自既有路径；不是给普通反思套一个「解释器错误」标签，也不借检索规则版本变化或解释 ID 变化单独取得这项 F 资格。
- **修订只登记新解释，不发行作用。** B 修订提交本身不调用 F、不为修订发出接纳/A/M 的作用消费键、不重开旧记录已消费阶段；不在该提交把新目标作用到 x 或槽。触发反思的内部记录若按既有规则已重访旧目标，保留那次真实作用；不得在修订完成时再自动补发一次新目标重访。之后另一次合法重访才用自己的 D11-A 消费键，重发该重访仍由同一键去重。
- **目标与历史前态一起绑定。** 每次合法重访只解析当时已经生效的解释，取「确定现行目标的那条记录」的修订后解释，配它在 H 中保存的完整前态 θ 与 R⁺ 作用视图、目标计算资源；a 仍为该原记录的有效 a。目标从未更新过时用首次作用前态；更新过时用最近一次目标更新的前态，不能一律退回首次前态，更不能用反思后或重访时的 R/θ 重新抬高目标。修订必须确实覆盖这条目标来源记录；只修订同根的更早记录，不能覆盖后来目标。新的合法目标更新继续沿 ADR 0035 §4.3；迟到的旧修订不能把它回退。
- **A1 替换保留同一个槽。** 重访用修订后的目标 v′ 与按现行 Φ 推进后的该槽实际份额 h，执行 ADR 0035 §4.5 的规范 binary64 A1（实数示意为 `x⁺ = clip(x + v′ − h)`）。不新建修订槽，不清空旧 h 再加入 v′，也不把目标差 `v′ − v_old` 当成新脉冲。新解释可使目标变强、变弱或不变；原 a 不变时也可能没有可测目标差，不承诺一定舒缓。后续纯重访不再改变这个目标，但衰减后的合法重访可以补回实际份额；不能把「不发额外脉冲」误读成 x 永不再变。多依据与截断沿原规范次序，不额外重访修订引用的材料来凑第二份作用。
- **前缀与重放。** 修订前的重访仍用旧解释，修订提交只改变后续解释选择，此后的合法重访才用新解释配上述原前态。目标来源记录、解释版本、生效位置、前态及作用消费键必须可从 H/Q 重建；结构重放不调用模型、不重发作用，不能用最终解释回写所有过去重访。与 §5.4 的 R/θ 重算分开核对：同一 H 前缀的增量与全段规范重算须逐位一致，F 的 x/槽/目标/消费状态由同序结构重放逐位复现。
- G 修改 R 后，F_out 仍只按既有规则增删/对齐学得坐标；这不是修订产生的 F 脉冲。「修订提交不作用于 x」指不新增驱动，不取消合法 Φ 或必要的维数对齐；固定时刻且维数不变的修订检查才要求 x/槽逐位不变。目标按记录时坐标和原视图计算，再按 ADR 0035 §4.3 对齐；新进入 R⁺ 的坐标不能借重评改用当前强度。
- 新解释及其生效引用、G 暂存变化、F_out 必要对齐、L、重评任务消费状态由核心原子发布；worker 只提交 Proposal。重评任务去重与 D11-A 的 F 作用消费键分开：前者不创造后者。按绑定检查前缀/资源/资格，失效结果留作审计，不部分发布、不覆盖新输入。
- 用户暂停成长时可继续记录反思与解释，R/θ 不发布变化；恢复按同一 H 计划补算，不重新调用模型。用户暂停不变成同材料再次抽样的机会。
- 无效果、反向效果与强烈变化都如实记录；沿 V2-97 报警/故障分工，不新增「必须更开心、更信任用户」的通过条件，也不以正常改变为由自动暂停。

**兼容性评估（代理判断，非验收）：** EV3 不被放宽，修订仍解释真实旧根，内部内容不是新证据；P11 禁止的是对已消费结果再发行完整脉冲，此处修订零作用、之后同槽 A1 替换，符合其边界；D11-A 仍按重访记录自己的键一次作用，修订没有额外作用键。需要明确扩展的是 ADR 0035 路径①的适用资格，现行条文只写解释器修订，本 ADR 把合格 B 修订列为候选新入口，不能称现有实现已支持。U2 防止同材料反复抽样，不能保证第一次判断正确；固定历史前态与不新增槽共同防止 `R 改变 → 重算旧目标 → 再强化`，不据此证明完整闭环安全。

## 6. 防自我欺骗能保证什么

在同一真实材料、同一已提交重评结果、候选集合与资源固定时，重复内部叙述没有新增组、没有旧组再新增、没有 C 更新、没有新重评结果，故本机制不再改变 R/θ。这是依赖身份/治理/事务正确的条件性结论，待测试与后继实现验证。

它**不证明**：m=0 的推论一定正确；无限新候选的竞争一定无偏；真实社交反馈一定稳定；反思所选主题公平；x 的总峰值单调不增。ADR 0035 已区分同依据目标有界与完整内生闭环。多依据反复重访、同源误拆、选择性召回、观点伪装成事实均要做反例。持续的真实负面证据可使她更难过，不应为了“稳定”冻结 G/C 或定时清零 x。

不伪造过去也有两层：结构层能保证不能直接写入未发生的外源事件或覆盖旧记录；语义层仍可能错误地推断别人的动机。未经验证的动机只作推断/未知，不作“他确实这样想”的事实。前者通过不等于后者通过。

## 7. 验证与实施成本

完整候选矩阵见 [EXPERIMENTS](../../reports/DESIGN-REFLECT-01/EXPERIMENTS.md)。先用合成真值验证修订、幂等、撤回与重放，再测 m=0 判断质量，最后验证经 R/F/J 改变真实选择。所有阶段当前 **not_run**；本 ADR 仅设计，不授权实验执行、模型费用、GPU 窗口或生产接线。

后继工作按责任范围承接，不在此派卡：语义/同源/来源路径（P5-43/45/50 等的后继）、G/重算（P5-23/24/26/54 后继）、认知/存储/运行时（P5-37/38/75 后继）、判断与闭环（P5-51/77 及合成世界后继）。正式编号与目录冲突开工时重核。涉及已发布类型、存储时另做契约 ADR、兼容、SYS17 迁移/回退；旧记录不得补造 a、解释或材料前沿。

单次成本由独立检索、m=0 解释/匹配、受影响 G 分配折叠和 H/L 记录组成。没有新长期模型或后台情绪分数。全量保守重算的上界随 H 长度与受影响分配增长；不能承诺常数成本，也不因预算不足只取支持证据。先测 CPU/存储与实际端到端延迟，再定工程预算；不加运行时依赖。
