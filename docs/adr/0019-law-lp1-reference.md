## 1. 背景与不变的数学含义

原参考规律每来一组就让旧证据乘名义保留率 ρ。固定的弱先验与复杂度基数不一起缩小，因此衰减会把 π 拉向先验值；这一拉动可能大于新支持的增量。ADR 0018 已证明：相对“同样衰减后”的基线单调，不能证明没有撤回的一整个事件步满足 LP1。

以下记号将“基数”和“证据量”分开，避免复用原 B 的含义：

\[
c=n_0+\kappa>0,\quad P=A_{att}\ge0,\quad
A=E-C,\quad V=E+C,\quad D=P+c+V,\quad \pi=(P+A)/D.
\]

普通倾向 P=0；依恋 P 固定，永不衰减。E、C 是非负的旧证据分量，c 仍是弱先验与复杂度代价，不是可遗忘的证据。原规格的 B=c+V；本文的 Python `a=A,b=V`，不把 `b` 冒充既有 IDL 的 `B`。

新组有效强度 w=W|S|，非零符号 σ=sign(S)。W 的强度、可信、可核实、份额四因子，以及 S 的预言公式，沿用原定义。先讨论精确实数；第 8 节单列 binary64 的可表示性限制。

## 2. LP1 在解释分摊下的三条判定

用户 2026-10-22 明确以下读法；本文将它作为原文在解释分摊情形下的**补全，不是放宽**，仍列为待批准项：

1. **没有撤回、没有重新分摊：** 按完整已提交事件比较 π_before、π_after。新增支持必须严格增大，新增反对必须严格减小；事件内对同一倾向的数个同号新增组按规范次序合成后仍须如此。
2. **新增证据与回溯分摊同时发生：** 固定同一步的回溯分摊计划、因子和计算次序，只去掉新增证据，得到 π_cf。新增支持要求 π_after>π_cf；新增反对要求 π_after<π_cf。π_after 与 π_before 也照常报告，不把混合变化整体豁免。
3. **撤回本身：** 只执行该分摊计划、没有新增证据时，被撤回支持的倾向不得上升，被撤回反对的不得下降。存在多项支持、反对撤回时，还要逐项分解检查，不能用净变化掩盖反向的边际作用。

同一倾向同时新增支持和反对时没有一个共同的符号；按固定顺序逐项作上述边际检查，记录完整净变化。零有效强度不是“新增支持/反对”，不能要求严格不等式。来源更正的“从未出现”重算另见第 6 节，不把重新分摊和来源失效混为一类。

## 3. 两个候选与反例

### 3.1 候选 A：衰减只压缩旧证据，保持 π 不动

设压缩后的 V̄=ρV，要求 π̄=π，同时 P、c 固定，则唯一的有符号分量是

\[
\bar A=\pi(P+c+\rho V)-P.
\]

压缩后再加新组，确有

\[
\pi'-\pi=\sigma w(1-\sigma\pi)/(P+c+\rho V+w),
\]

所以在 |π|<1、w>0、非负分量可行时满足整步 LP1；压缩使分母减小，也更容易被后续证据改变。

但它不能普遍保住原分量的含义。P=0、只有支持 E>0 时，π=E/(c+E)，而 ρ<1 给出

\[
\bar A=E(c+\rho E)/(c+E)>\rho E=\bar V.
\]

于是 C̄=(V̄−Ā)/2<0。具体 c=4、E=10、ρ=1/2，Ā=45/7>5=V̄，出现负的反对证据。依恋也有相同问题：P=60、c=4、E=0、C=1、ρ=1/2 时 π=59/65，Ā≈−1.453846，绝对值大于 V̄=0.5。

一般可行条件是 |π(P+c+V̄)−P|≤V̄，等价于

\[
P+c+\bar V\ \ge\max\{c/(1-\pi),(2P+c)/(1+\pi)\}.
\]

纯单边证据已在边界，不能继续这样压缩。把总分子、总分母一起乘 ρ 可以保持 π，却会让 c、P 衰减；增加一个吸收差额的“先验”会改变 P/c 的含义。将 π 单独存作与 E/C 不再一致的权威量，也改变推论 1、3、7。因此不选此候选。

### 3.2 候选 B：按新信号限制共同衰减（选定）

对任意共同保留率 q，先 A←qA、V←qV，再加 σw、w，可得恒等式

\[
\pi'-\pi=\frac{(1-q)d+\sigma u}{P+c+qV+w},\quad
d=P-\pi(P+c),\quad u=w(1-\sigma\pi)>0.
\]

因此整步 LP1 的充要条件是 `u + σ(1−q)d > 0`。原 q=ρ=1−h 不总满足此条件，这正是 ADR 0018 的冲突。

保留原变化率估计，在新组加入**之前**计算

\[
h=\hat h=(h_0n_h+F)/(n_h+N),\quad \rho=1-h.
\]

若部署指定了 h 的下限，先按规律参数取下限；本文实验没有下限。要求 0≤h<1。定义实际折扣 δ=1−q：

\[
\delta=\begin{cases}
0,&w=0,\\
h,&\sigma d\ge0,\\
\displaystyle\frac{h u}{u+2h|d|},&\sigma d<0.
\end{cases}\qquad q=1-\delta.
\]

随后唯一的递推为

\[
A'=qA+WS,\quad V'=qV+W|S|,\quad
M'=qM+\mu p,\quad U'=qU+\mu.
\]

教导组不加 μp、μ，只让 M/U 乘 q。r=clip(M/U,0,r_max)，U=0 时 r=0，保留 ADR 0016 对 U=0、M≠0 的合法状态的处理。P 与 c 都不乘 q。

**LP1 证明。** 若衰减方向同新证据一致（σd≥0），有 σΔπ≥u/D'>0。若相反，代入 δ 得

\[
\sigma\Delta\pi=\frac{u(u+h|d|)}{(u+2h|d|)D'}\ \ge\frac{u}{2D'}>0.
\]

有限 P,c、|π|<1、w>0 即可；h=0 给出 q=1。w=0 定为 q=1，所以不会发生“无净信号也把 π 拉回先验”的变化。每个同号新增组都严格单调，故固定次序下合成的完整事件也严格单调。

**数值设计中淘汰的变体。** 初稿使用 δ=hu/(u+h|d|)，实数也严格单调，但逆向衰减时增量可小至 O(w²)。80,000 个计划事件中 299 条合成谱系在普通小权重处触发显式精度故障。选定的分母系数 2 保留至少一半新信号的方向增量，取代初稿；不是降低 LP1 阈值。初稿输出与源文件保留在 `attempt-01`，后续输出不覆盖它。

## 4. LP2–LP8、新近权重与含义

**LP2 / I25。** 保留正、反两边分别归一的份额规则；每个实际分量都保持非负。份额变小引起 W 变小，固定前态下新证据的方向增量随 w 严格增加。证明：逆向衰减时设 x=u、a=h|d|、r=1−σπ，方向增量为

\[
f(x)=\frac{x(x+a)}{x^2/r+(D+2a/r-hV)x+2aD}.
\]

令 α=1/r、β=D+2a/r−hV、γ=2aD；导数分子为 `(β−aα)x²+2γx+aγ`，其中 β−aα=P+c+(1−h)V+a/r>0。h=0 或 a=0 直接退化为通常的分式单调性。顺向衰减时 q 固定，同样成立。撤回旧份额还需要第 5 节的历史 q 规则。

**LP3。** 同源归组、首次位置、纯重复不刷新保持不变。一个组的重复不调用新增递推；不制造新 q、N 或 F。本文未重写 EV2 的组装器，原 LAW-9 的支持/强度计算原样使用。

**LP4。** h 仍是带弱先验的符号翻转频率估计；噪声也会提高 h，它不是已经校准的变点概率。ρ 现在表示**名义保留率**，实际 q∈[ρ,1]；逆向衰减时 ∂δ/∂h=u²/(u+2h|d|)²>0。因此匹配同一前态、同一新证据时，较大的 h 仍使旧证据让位更快，只是受 LP1 的信号预算限制。

新近权重改成 `ω_{c,k}=∏后续首次计入的实际 q`，不再是名义 ρ 的乘积。它随证据事件变化，不随墙钟变化；没有 q<1 的统一下界，也没有统一有限记忆长度的保证。M/U 使用同一 ω。h 的估计沿用参考脚本“跳过零符号、连接前后非零符号”的约定；PR #49 的 V2-45 已指出这与含零组的字面相邻读法有区别，本 ADR 不代替用户批准那一歧义。

旧证据确实能让位。例如 P=0、固定 h>0、恒定支持 w>0 时，E_{n+1}−E_n≥w/2，而 `δ_n=hw/(w+2hE_n)`；又 E_n≤E_0+nw，所以 Σδ_n 发散，任何固定旧组的权重积趋于 0。h=K/(n_h+n)、K>0 时有同样的调和下界。**单个旧组逐渐消失，与总证据量存在统一上界是两件不同的性质。** 对任意快速趋零的后续证据强度，不宣称统一察觉时间。

**LP5。** 没有证据事件时所有值逐位不变，不读时钟。零信号组的 A/V/M/U 不衰减；若它是经历组，仍可给 M/U 加入其幅度信息，N 与符号计数按记录更新。纯重复不是新组。零信号组不改变 π 是对原 D4/V2-45 的显式变更。

**LP6。** c、κ 的含义与一次成为性格的门槛不变。纯支持、P=0 时

\[
E'-E=w\frac{w+hE}{w+2hE}\in[w/2,w],
\]

与 c 无关；同样的纯支持序列产生相同 E，更大的 c 给出更小的 π、需要更多证据跨越 1/2。不同正反历史、不同先验间不额外宣称全序。

**LP7。** 固定 π、P、c、h 和新组，d、u、q 都不随 V 变化，而 D'=P+c+qV+w 随 V 增大，所以 |Δπ| 变小。这是控制组成与方向后比较证据量的性质；不把任意两个方向、变化率均不同的历史只按总量排序。全步可用的上界是

\[
|\Delta\pi|\le\frac{\delta|d|+2w}{P+c+qV+w}.
\]

推论 4 原本限定“不计新近权重”，不能把它的旧上界冒充全步上界。顺向衰减仍可在很小 w 下产生可见的先验回拉，这是保留的行为与局限；w=0 则不触发该回拉。

**LP8。** 新 q 只依赖证据统计、P/c、前态 π 与新 W/S，不读 x、m、g、λ、模型或时钟。I23 的计算次序与历史存储规则如下；θ 的原规律本次不改。

## 5. 撤回单调性要求：历史 q 不随份额重算

自适应 q 不能在旧份额变更后重新估计整条旧 q 序列。保留的 20 组反例（默认 c=4、P=0、h₀=0.1、n_h=10）将第 0 组反对证据权重乘 0.1：

| 方式 | 最终 π |
| --- | ---: |
| 撤回前 | −0.5752715543316654 |
| 错误：按减小后的权重重新计算后续 q | −0.5753015920389444 |
| 选定：份额改变，历史 q 保持首次计入值 | −0.5752208068511547 |

错误方案撤回反对后反而更反对，违反第 2 节第 3 条。完整输入见 [反例](../../reports/law-lp1-reference/withdrawal-recomputed-q-counterexample.json)，参数及复算见 `law_v2_properties.py` 和最终 extra 原始输出。

选定规则：每个 (组,倾向) 首次计入时，按该时刻的前态计算实际 q，与其 ordinal 一同保存。重新分摊只改份额；按 ordinal 从初值折叠已存 q 与因子，不重新估计旧 q。F/N/最后符号仍按当前解释重放，供未来首次新增时估计 h；改变 S 的解释更新也不能追改已发生的 q。

精确实数中，每个旧分量的系数 Ω 是已存后续 q 的非负乘积，与本次份额修改无关，且

\[
\frac{\partial\pi}{\partial E}=\frac{c+2C}{D^2}>0,\qquad
\frac{\partial\pi}{\partial C}=-\frac{2P+c+2E}{D^2}<0.
\]

所以撤回支持不升、撤回反对不降；多项同类撤回按固定次序合成同样成立。混合项仍拆开检查，不承诺净效应单向。binary64 下采用同样的方向后置检查；等值允许用于撤回，反向舍入是显式数值故障。

## 6. 一个事件的次序、反事实与 I23

建议取代 D2/D3 中可能交错“改旧分配”和“新加组”的部分，采用明确的两阶段参考步骤：

1. 规范化候选/别名与本步全部输入，使用本事件前的 b、σ̂；建立显式分摊计划。单次分摊中的所有份额使用同一前态快照，按规范 ID 排序。份额修改、旧组内容修改及其正反分量变化都保留来源。
2. 完成旧分配的修改，按固定组序、倾向序写好全部份额，然后对受影响倾向按 ordinal、已存 q 重放。得到本步修订后的状态。
3. 新分配按追加位置、group_id、tendency_id 的规范次序计入；本组份额使用该组前态，同组各倾向使用同一快照；新 q 计算一次并保存。记录 π_after。
4. 审计反事实复用第 1、2 步完全相同的计划与次序，省去第 3 步，得到 π_cf。先检查撤回，再检查新增边际作用。没有修订时直接比较 π_before/after。
5. L 记录全部实际变化与证据引用；外层事务原子发布。任一故障都不发布部分 R。无证据项时直接返回原 R。

这是与原 D2/D3、V2-40 的显式次序差异，不静默覆盖旧定义。新候选对旧组的首次分配属于新增证据，对原参与者的份额变化属于修订。容量移出造成的分摊也须记录独立计划并进行相同的分量/边际审计；本研究夹具未实现容量选择、别名与内容变化的完整 G，不将其报告成 AC2-21 通过。Claude 后续实现时须把容量后的实际分摊也纳入上述比较，不能只测递推函数。

**I23 的归纳依据：** 全 H 重算在每个事件重复同一个计划、同一个 q 首次生成、同一个份额量化、同一个修改与折叠次序。增量计算保存的是这些同位模式的显式 R 字段；不是无法从 H 重建的缓存。由共同初值和每步确定运算，两者每个前缀逐位相同。直接用闭式求和不是规范重放，即使实数公式相等也不替代递推。

**来源更正 / 新规律版本：** 遵守 v2.0 第 5.4 节。来源失效时从更正后的有效 H 重新执行完整规律，如同该证据从未出现，并重新生成受影响历史的 q；新规律版本也从 H 开头生成自己的 q。不能直接删一个旧分配却保留由假证据产生的其他历史 q，并声称 AC2-19 通过。这种重算可能同时改变多个正反分量，须完整记录差异；第 2 节的同分摊反事实不代替“从未出现”的标准。暂停/恢复仍复用同一完整事件序列，不修改暂停语义。本次未运行真实存储、暂停、来源更正或 θ 的验收。

## 7. 对推论 1–7 的逐条影响

| 推论 | 判定 | 草案中的具体含义 |
| --- | --- | --- |
| 1 成为性格 | 代数门槛不变，达到门槛的轨迹变化 | P=0、只有支持时 π>1/2 当且仅当 E>c。E 使用新的实际 q；不能复用旧轨迹的时刻 |
| 2 一次就够 | 门槛不变，普通序列的速度可能变化 | 无旧证据时 W>c、S=1 仍一次跨过；更大 c 的纯支持门槛仍更难。原 LAW-2 原样执行 |
| 3 改变倾向 | 代数关系不变 | P=0 时 C>(E−c)/3；含先验为 C>(P+E−c)/3。E/C 的数值轨迹变化 |
| 4 单组上界 | 原无衰减限定下不变；全步另列新上界 | q=1 时仍 ≤2w/(D+w)。全步使用第 4 节含 δd 的界，不能削弱 LP1 或修改旧 LAW-4 |
| 5 时间不改变 | 不受影响；零信号事件另有显式变化 | 无事件不变。原来的 S=0 组会衰减 A/V；新形式不衰减，详见第 4 节 |
| 6 记忆长度 | **受影响，用户已确认方案 A（2026-10-23）** | 固定名义 ρ<1 不再推出 E/C≤w_max/(1−ρ)。只在实际 q 有统一上界 q_max<1 时才有相应几何界；新规则不保证该条件。替代保证及证明边界见 §11.5 |
| 7 依恋 | 先验及代数不变；两类行为保留但条件须写明，数值速度变化 | P 固定不衰减；持续一致的反对最终可改变有限 P；交替证据的抵抗依赖 P/证据上限/变化率的校准，不能解读成任意 P 都绝不改变 |

**推论 6 的直接反例：** P=0、固定 h>0、恒定纯支持 w>0，由第 4 节 E_{n+1}−E_n≥w/2，所以 E 无界。原 LAW-6 保持原判据，3,000 个随机序列中报告 **3,064 个状态违例**、退出码 1；没有把 `fixed_rho` 偷换成实际 q，也没有把这个失败改成通过。用户已按第 11 节选择方案 A，接受当前候选与旧推论 6 的差异；原规格及原 LAW-6 文本不改，其余规律发布仍待批准。

**推论 7 的条件证明：** 从任一有限前态起，若持续加入恒定 w>0 的反对，则每步 π 严格下降，并有 `−Δπ≥w(1+π)/(2D')`、D'≤D_0+(n+1)w。若其极限大于 −1，则增量的下界为正的调和级数，矛盾，故实数极限为 −1，最终跨过 1/2。P 没有衰减；改变来自持续的证据。

若正反严格交替、各组 w≤w_max、h≥h_*>0，以 π_0=P/(P+c) 为界，每一对相反符号至少有一组衰减方向与新信号相同，使用完整名义折扣，所以每对旧证据的乘积≤1−h_*。于是相反证据在对末端有界为 max(C_0,w_max/h_*)，任意组后可保守界为 C_max=max(C_0,w_max/h_*)+w_max。P>c+3C_max 是保持 π>1/2 的充分条件。原“交替改变不了它”保留为在此类校准范围内的行为，不升级为无条件定理。原 LAW-10 的 5,000 组交替场景最低 π 为 0.824；200 组支持后翻到 1/2 以下所需反对组数从旧 29/51/421 改为 39/61/298（普通 / P=60 / P=600）。无限实数证明不保证有限 binary64 能无限推进，精度或计数耗尽按第 8 节故障。

## 8. 数值规范与未来契约需求

1. 权威数值为有限 binary64，圆整到最近、平局取偶；不启用 fast-math、不做 FMA 合并，不以闭式替代递推。每个乘、加、除均在 `law_v2_model.py` 的明确括号位置舍入并检查有限性，−0 存前转 +0。归一化权重可用确定的整数精确运算选择可表示份额，与 D9 的精确均值同属显式舍入算法，不保存有理数状态。
2. 顺序：先 `c=n0+kappa`、`anchor=P+c`、`before=(P+A)/(anchor+V)`，再 `h=1−rho`、`d=P−before*anchor`、`w=W*abs(S)`、`u=w*(1−σ*before)`；逆向分支按 `h*abs(d)`、`2*该值`、`u+该值`、`u/该值`、`h*该值`、`1−该值` 得 q。A/V/M/U 都先乘 q，再加新项；π 最后重算，所有字段检查后一次提交。
3. 正输入 w 下溢到 0、正输入不能使 π 的位模式沿正确方向变化、π 到达 ±1、无穷/NaN、计数无法准确转换均是显式故障。没有容差通行、最小权重、夹紧、nextafter 修补或静默跳过。N/F 在达到 2^53 前故障，避免 binary64 分母中的整数被无声丢失。数学上严格单调不能消除有限格式的最小可表示增量。
4. **I25 的精确舍入提议：** 对每一边，先计算 binary64 的 `(1+π)/2`，将其精确比例配额分到 2^52 个单位，取整后按余数从大到小分配余下单位，平局按规范 ID。每份是整数×2^-52；每份相对理想配额误差<2^-52，每边实数和、规范次序 binary64 和均严格为 1。任何正配额被分成 0 时显式 `PrecisionExhaustedShare`，不丢掉它。**这是对独立除法舍入的新增规范，须批准**，不是假称精确比例能在有限位中全部同时实现。
5. 持久化需要后继类型中的至少两项：每个分配的 `actual_retention q`；每个倾向显式的证据绝对量 V。后者用于避免从已舍入 B 减去 c 的二次精度损失。现有 A/B、π、M/U、ordinal/μ/p 等字段继续保留自身含义；不重新解释 ADR 0016 已发布的 `TendencyV2` 字段。按 ADR 0007 另立契约变更卡、后继类型、黄金向量和兼容检查，批准前不修改 IDL。
6. M/U 的次正规数测试保留 `M=2^-1074,U=0`；不补上已被 ADR 0016 审查撤回的错误约束。标量重放比较也包含非零 μ/p、教导的缺省 projection 与 JSON 往返，比较全部状态位。

## 11. 推论 6：失去的保证、行为影响与用户决定（2026-10-23）

### 11.1 失去了什么

旧参考形式在固定 ρ<1、每组不超过 w_max 时保证：无论积累多少组，折算后的一致证据 E 和反对证据 C 各自都不会超过 w_max/(1−ρ)。这是“现在还有多重的过去在拉着她”的上限，不是 H 中存多少历史的上限；H 一直保留，未要求删除。

当前候选还保留“固定的一条旧证据可以逐渐让位”，但失去上述**总量上限**。一直收到同样强的支持时，折扣被 LP1 限住，旧证据每步少掉的量小于新加入的量。E 每步至少增加 w/2，所以即使名义变化率一直不变，折算总量也会越积越大。单组权重变小、总量却变大，并不矛盾：后来不断有新的组进来。

### 11.2 对她的行为可能有什么实际影响

- 一段很长的稳定经历可能带来越来越大的惯性。后来世界改变，她仍能被反对证据改变，但没有一个仅凭固定名义 h 和单组上限就能给出的统一适应时间。旧倾向不会因为时间流逝自动松动。
- 这可能降低偶然事件造成的误翻转，也可能让真正的变化更晚被察觉。不能只选其中一个说成好处；四世界的512步对照不足以保证经历十万组后也有相同延迟。
- π 仍在 (−1,1)，性格门槛仍是 1/2，依恋先验 P 仍不衰减。有限上界失效不等于先验被遗忘，也不等于永远改不了；但“最终能改”没有给出可接受的速度。
- 总量持续增大还可能使弱先验或新证据相对它小到 binary64 分辨不出，此时必须显式精度故障。不能把机器最大有限数、计数耗尽或静默饱和当成恢复了推论 6。

### 11.3 能不能在保住 LP1 时恢复上界

**LP1 与有限上界本身没有被证明互斥。** 但不能给当前公式简单加一个硬截断或强制最小折扣就算解决：

1. 纯支持、P=0、E>0 时，整步 LP1 等价于 E'=qE+w>E。若强制 q≤q_max<1，取足够小的正 w<(1−q_max)E，就会失败。因此不能靠强制实际 q 永远低于某个常数恢复旧几何证明，也不能通过提高最低证据强度来回避。
2. 若纯支持已经恰好到达硬上限 E=L，仍使用固定 c 的 π=E/(c+E)，则继续加入支持却要求 E'≤L，不可能让 π 严格增大。`min(E',L)` 会违反 LP1。必须避免实数状态达到上限，或重新设计统计/读出含义；有限 binary64 的严格比较耗尽也仍须处理。
3. 以下“开放上界”构造说明：对**没有历史份额修改的新增步**，固定 P/c 与 LP1 可以兼容 V<L。取版本参数 L>w_max、前态 V<L；当原 q 会使 V'≥L 时，设 q_hi=(L−w)/V。若衰减逆向，设 v=|d|、r=1−σπ、q_lo=max(0,1−wr/v)；顺向设 q_lo=0。逆向时

   \[
   q_{hi}-(1-wr/v)=\frac{(L-V)v+w(V-\sigma A)}{Vv}>0,
   \]

   因为 L>V、V≥|A|。所以选择 q=(q_hi+q_lo)/2 可同时给出 q>0、V'<L 和严格 LP1。V=0 或尚无上界压力时不需要此分支。这只是实数新增步的可行性证明，**不是本 PR 的新实现，也不是完整规律的通过结论**。

该构造可能要求 q 比名义 ρ 更小，额外引入容量压力，改变 h 与遗忘的关系。更关键的是：历史 q 固定时，回溯份额增加可能把重放后的 V 推过 L；上述新增步证明没有解决它。若因此重新估计旧 q，又会遇到第 5 节的撤回单调性反例。要恢复完整事件上的统一上界，必须另外证明分摊、容量移出、来源更正及重放都守住上界和三条 LP1，不能只跑一条纯支持序列。

### 11.5 当前参考版本的替代保证及其边界

替代保证是：**任意固定旧组的权重最终趋于 0；在固定 h 下，变化后的适应时间随一致历史的长度增长，但不再有常数上界。** 前半句需要后续证据持续推动折扣，后半句指下面明确的单倾向、一致支持后持续反对、跌破 π=1/2 的实验与实数证明，不外推成所有世界的察觉时间定理。

**旧组让位的充分条件与证明。** 在当前标量参考形式中，固定任意一个旧组；不修改它的历史份额，此后每步加入固定有效权重 w>0 的非零证据（符号可以不同），P、c 固定，且名义 h 固定于 (0,1)，或采用当前自适应估计且 h₀n_h>0。这是可证明的一组充分条件，包含本节实验；不是新增最低证据强度规则，也不是任意未来序列都保证趋零。

设第 t 步前 D_t=P+c+V_t，d_t=P−π_t(P+c)，u_t=w(1−σ_tπ_t)。因为 V_t≤V₀+tw、|d_t|≤2P+c、u_t≥wc/D_t，实际折扣 δ_t=1−q_t（含直接取 h_t 的分支）满足

\[
\frac1{\delta_t}\le\frac1{h_t}+
\frac{2(2P+c)(D_0+tw)}{wc}.
\]

固定 h 时右侧至多线性增长；自适应时 h_t=(h₀n_h+F_t)/(n_h+N₀+t)，故 1/h_t≤(n_h+N₀+t)/(h₀n_h)，同样至多线性增长。因此 Σδ_t 发散，任意固定旧组的后续系数 Ω=∏(1−δ_t)≤exp(−Σδ_t)→0。若没有后续事件、之后全是零有效信号（q=1），结论不成立；h=0 或任意衰弱信号序列也不在上述保证内。一般地，是否趋零取决于后续 ∑−log q 是否发散，不能省去持续折扣的条件。普通份额修改与来源更正不属于这个固定旧组证明。

**固定 h 下的适应时间。** 对 P=0、c>0、每组 w>0、先 N 组纯支持，从 E₀=C₀=0 开始，当前形式满足

\[
E_{n+1}-E_n=\frac{w(w+hE_n)}{w+2hE_n}\in[w/2,w],
\qquad Nw/2\le E_N\le Nw.
\]

改为持续反对后，在首次跌破 π=1/2 之前 π>0，衰减顺着反对方向，所以每步实际 q=ρ=1−h。第 m 组反对后的值为

\[
\pi_m=\frac{\rho^m E_N-w(1-\rho^m)/h}
 {c+\rho^m E_N+w(1-\rho^m)/h},\qquad
\pi_m<\tfrac12\iff
\rho^m(E_N+3w/h)<c+3w/h.
\]

E_N 随 N 严格增长且无界，所以首次越线所需组数随 N 非递减（整数阶梯），并且没有独立于 N 的常数上界。固定 N 则有限；这不等于无论历史多长都能很快察觉。旧形式的 E_N≤w/h，因此该固定 h 场景有统一的越线时间上界。自适应 h 的比较见下表，未把有限数据外推成所有 N 的速度定理。

这些极限和上界是**实数递推**的结论。有限 binary64 执行只承诺在显式数值故障前依固定次序递推；不能声称机器能无限执行、最终一定将某组舍入到零，或把精度耗尽当成遗忘保证。实验只支持所列有限前缀。

## 12. 审查后实现修复与证据更正（2026-10-23）

[阻塞审查](https://github.com/nanake-lab/nemu/pull/61#issuecomment-6356460860) 指出：此前事件夹具把回溯中新候选的首次分配提前计入 cf，随机检查也遗漏该候选。故前文及早期报告的“零违例”只覆盖当时已检查的目标，不能用于证明这个漏测场景。失败见证和源快照保存在 `reports/law-lp1-reference/review-20261023/before/`，没有覆盖旧输出。

现在 `_revise` 只改已存在的分配，首次分配形成显式 `FirstAllocation` 计划，初始化候选后先捕获 cf，再计入这些新增，最后处理当前新组。反事实可以暂时缺少新候选的份额，是不可发布的审计视图；只在整个事件完成、I25守恒后原子发布。新增“只回溯”和“回溯+新组”随机检查，并以只折叠事件前分配身份的独立 oracle 检查 cf；不再用两个共用同一错误 `revise` 的路径互相证明。
