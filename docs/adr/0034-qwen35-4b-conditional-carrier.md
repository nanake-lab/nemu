# ADR 0034：载体换为 Qwen3.5-4B（有条件）

## 背景

她需要看图，包括照片、表情与屏幕。ADR 0031 的 Qwen3-4B-Instruct-2507 是纯文本载体。用户作出本次决定时，P5-13 与 P5-31 尚未开工，E2 默认 m = 0，现在更换几乎没有迁移成本。

[P0-10 报告](../../reports/P0-10/REPORT.md)、[注入实测](../../reports/P0-10/INJECTION-REPORT.md)与[速度实测](../../reports/P0-10/BENCHMARK-REPORT.md)只覆盖原配置，不能据此宣布新模型的注入、速度或状态清除通过。

## 决定

### 1. 目标载体与来源

载体有条件改为 **Qwen/Qwen3.5-4B**（Apache-2.0，原生支持图像输入），使用 **Q4_K_M、不思考模式**。从官方固定修订自行转换与量化，连同视觉编码器（mmproj）记录全部哈希，不使用第三方量化文件。具体官方修订和产物哈希由 P0-12 在实际准备时记录，本 ADR 不填未取得的值。

### 2. 生效条件与回退

- 新增实测卡 **P0-12**，依赖 P0-10，归入 E2；P5-13 增加对 P0-12 的依赖。
- **P0-12 对 Qwen3.5-4B 的实测通过后，目标载体才生效。**
- 不通过则退回 **Qwen3-VL-4B-Instruct**，在同一卡按相同测量项目复测；不能未经复测就切换。
- 两者都不通过，保留 ADR 0031 的 **Qwen3-4B-Instruct-2507**。

P0-12 只测量，不设新阈值、不选择注入位置、不提取方向；完成测量不等于模型通过。报告必须区分实测结果、未测项和能否支持条件切换。既有要求不足以判定的项目如实交回用户，不由执行者补判据。

### 3. 每次更新 m 时清除全部推理状态

Qwen3.5 为混合结构，含循环记忆层。ADR 0031 的「每次更新 m 前显式清 KV」扩展为：**显式清除 KV 与循环状态 → 安装本次向量 → 重新 prefill**。不得沿用旧 m 留下的 KV 或循环状态；清除是否完整、每次请求更新是否可复现，须由 P0-12 实测确认。

使用 server 时同时设置 **`--cache-ram 0`、`cache_prompt=false`**，或直接调用库；禁用缓存配置不能代替状态清除的实测证据。

## 备选方案

本次选择的顺序为 Qwen3.5-4B → Qwen3-VL-4B-Instruct → 保留 Qwen3-4B-Instruct-2507；前两者必须分别经过同一卡实测。不增加其他候选或重新选定注入位置。

## 后果与待办

- P0-12 测零注入逐位置 logits 字节一致性、每请求更新 m 的可复现性、注入位置可用性、中英日文字速度和首 token 时间、单张图片处理时间、载体加视觉编码器显存峰值、不思考模式输出稳定性。
- 需要用户安排 GPU 安静窗口，并单独批准下载约 **9 GB** 的官方原始权重；本次文档提交不执行下载或测量。
- P5-31 的方向提取与正式验证仍由原卡承担；旧向量不得复用，E2 默认 m = 0、开启非零 m 仍按 ADR 0031。此次条件切换不新增她的行为、性格、评价或语言设定，ADR 0032 的既定分工继续适用。
- 本 ADR 不另选引擎版本，不宣称 ADR 0031 固定版本已支持新模型。P0-12 记录实际引擎及兼容性；遇到需要更换工具或引擎的阻塞，按 AGENTS.md 处理，不静默改选。
