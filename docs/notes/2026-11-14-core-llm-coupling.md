# Echo Core × 冻结 LLM：经历驱动的耦合学习

> 2026-11-14 讨论备忘。**记录问题和研究候选，不是规格、ADR、实施授权或已验证结论。**“用户观点”仅指本次讨论中用户实际表达的想法；其余判断标为讨论推论或助手候选。

## 核心问题

**一个训练完成、参数冻结的 LLM，能否通过 Echo Core 和真实经历，持续改变未来的认知与行动，而不只是改变说话风格？**

这里的“改变自己”首先指 **NEMU 整个系统** 的变化：同样的基础模型，在不同经历之后，会关注不同的事、提出不同的方案，并能依据新证据修正。它不等同于 LLM 权重已更新。

## 观点及其边界

- **用户提出：** 从第一性原理研究，不维护错误前提；借鉴生物脑区功能分工，思考不同机制能否形成一个整体。意识可能分段出现是用户提及的研究线索，**不是本项目的设计前提**。
- **助手提出，用户认可继续思考：** **工程上解耦，因果上耦合。** 清晰的接口、权限和替换能力，与持续的双向反馈不矛盾。“不是主仆”描述的是双方都可能对系统未来产生因果贡献，**不是写入权限平等**：Echo Core 仍是状态的唯一提交者，LLM 只能提出解释、思考和行动候选。
- **共同聚焦：** 不急于预设“自我”只存在于核心或载体；把持续运行的整体过程作为研究对象。脑区分工只提供类比，不直接推出 NEMU 的正确架构。
- **关于规模法则：** 大模型扩展有可预测、通用且容易衡量的收益；记忆、反思、智能体与环境反馈也一直有人研究。二者优化目标部分不同，**不是规模法则与耦合路线二选一**，也不能据此声称 NEMU 优于头部路线。

## 当前 NEMU 的闭环

`真实事件 H → 状态 (x, R, θ) → J 编译 m → 冻结 LLM 的计算与提议 → 行动/外部反馈 → 新事件 H`

这是一条**设计中的因果链**，不是已经完成的能力证明：

- H 记录经历；F/G/C 更新快状态、倾向和动力学，J 只读状态编译调制；IRL/A/M 在 `m = 0` 下提出解释与评估，核心治理后提交。
- 按 [ADR 0026](../adr/0026-continuous-cognition.md)，内部思考可以接续、记录并影响 x 或后续行为，但念头本身不能直接作为 R/θ 成长证据；真实后果需要按现行证据规则处理。
- 当前 [README](../../README.md) 记载 E2 默认 `m = 0`，尚未证明非零调制可稳定影响语言表现。因此不能把预期中的认知反馈当成已运行结果。

## 真正的瓶颈

1. **表征瓶颈：** LLM 对一段经历形成的复杂理解，哪些能通过 H 的检索、R/θ 的长期变化和 J 的有限调制，实际影响未来？不应误把状态维数少，直接等同于系统记不住细节；要检验的是**未来行为所需的信息是否仍可用**。
2. **可塑性边界：** 保存经历、形成偏好、改进长期策略与学习新的底层能力，不是同一种变化。冻结权重的系统能做到前几项到什么程度、何时需要参数更新，仍待分辨。
3. **解释与现实的缝隙：** `m = 0` 不会消除 LLM 预训练形成的先验。错误解释若进入证据链，可能被长期保留；反复自述不能代替外部反馈。
4. **反馈是否真双向：** 仅有“状态→语气变化”不够；要看她的经历能否持续影响**关注、检索、计划和行动**。但不预先要求 m 直接操控某个具体决定；这些差异也可能经事实视图、活动接续及经历形成。

## 后续判断建议（候选，不派卡）

对同一冻结 LLM，在相近的历史检索、上下文和资源预算下比较：

- A：只提供可检索历史，无长期状态反馈；
- B：增加 Echo Core 状态读出，但切断行动后果回流；
- C：状态、内部活动、行动和可核实后果形成完整闭环。

给三组可比但有所分化的经历，再在**未见的新情境、重启之后、出现反证之后**观察：它们是否有稳定、可追溯且可修正的关注点、行动与策略差异；同时排除随机采样、更多上下文及额外计算带来的假增益。对照方案还须细化，不能直接当作验收设计。

**失败时先定位断点，不先加规则：** 是事实没被取回、解释失真、状态没记住、J 没有效果，还是模型无法利用已获得的信息？遵守“能不能不加、一个人会怎样、加后什么改不掉”的三问。

## 可继续追问

- 哪些关于经历的差异，若未保留就会让未来行为出现不可恢复的损失？这能否成为表示的最小性判据？
- 一次独立思考怎样形成可持续的行动和真实反馈，而不形成自我确认循环？
- 核心状态与模型认知之间，最小而充分的接口是什么？哪些能力必须留给模型学习？
