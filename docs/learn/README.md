# 学习区

这里放给用户读的讲解，一篇讲透一个问题，按编号顺序读。规格、ADR 和报告写给执行者看，讲究精确；这里写给人看，讲究读得懂。两边说法不一致时，以规格和 ADR 为准，并把这里改正。

## 怎么用

- **按顺序读。** 一篇读懂了，再读下一篇。后面的文章会用到前面讲过的概念。
- **不懂就问。** 读的时候哪里看不明白，直接在对话里问。答案会补进那一篇，注明日期，下一个读的人就不会卡在同一处。
- **用自测题检验。** 每篇末尾有几道题。不看正文答得出来，就算读懂了。告诉 Claude「01 读懂了」，下次提交时把下表的状态改掉。
- **分清「候选」和「决定」。** 文中标「候选」的是 Claude 的想法；「用户决定」只写你亲口定过的事。

## 下一篇写什么（候选，由你定）

- **她的状态怎么变：** x、R、θ 分别是什么，F、G、C 三条规律怎样让她有心情、长出倾向、改变性情。01 讲状态怎样进入模型，这篇讲状态本身从哪来。
- **她怎么理解一件事：** IRL、A、M 三个判断员各管什么，什么能算证据、什么不能（证据规则 EV）。
- **从你发消息到她开口：** 一条消息走过的每一段，各要多久，包括声音管线的实测数字。
- **怎么知道她真的在变：** 验收、合成世界、交叉审查各自管什么，又管不到什么。
