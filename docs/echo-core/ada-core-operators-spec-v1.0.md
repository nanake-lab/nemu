# Echo Core Ada 核心算子与整体动力学规格 v1.0

版本 1.0 冻结候选（数学闭合修订）　2026 年 9 月 23 日

本规格给出 F、G、C、J 的可施工定义，并把它们接成有唯一事件顺序、明确作用权限、可恢复事务和可证伪验收的整体机制。继续使用 H、x、R、θ、L 与运行时 Q，不增加核心状态或第五个成长算子。G 延续既有 χ/K、shadow、资格验证与责任交接设计。

结论：四算子的结构合同、参考算法和失败路径可以按本文进入实现。数值配置、基础模型、调制载体参数和真实实验仍须绑定并验收，不能把规格推演当作已验证的 Ada。本文选择现冻结边界内的严格 θ 失效模式；无合法补偿时停止核心作用并保留任务响应，不暗中启用局部撤权例外。

# 2 状态归属和数据权限

核心仍为 S=(H,x,R,θ,L)，运行时为 Q。五态按因果职责而非语义标签或单纯时间长短划分；本节给出母定义，后续 F/G/C/J 的载体、统计与事务规则不得改变这些边界。

## 2 1 五态母定义与状态完备性

H 是规范有效事件、观察、声明、行动结果、来源与纠错关系的只追加历史权威。H 保证“记录过什么以及其来源/纠错关系”，不保证记录中的命题天然为真。对一个被 Γ 接受的规范事件 r_k，正常路径满足 H\_{k+1}=H_k⊕r_k；纠错以新的 r 追加，不覆盖旧记录。z、SemanticGraph、索引与摘要是绑定到 H/r 的派生解释或资源，不形成第二套平行历史。

x 是近期历史对未来短时核心转移的有限维近似因果充分状态。对声明的时间窗 T_x、容差 ε_x，在固定 R、θ、合法事实视图 c、外部条件与版本化资源 Ω 后，若两段近期历史被压缩到同一 x，则其在该合同覆盖的短时未来核心端点上应不可区分到 ε_x 以内。x 可以有损遗忘历史，但不得因为 x 遗忘而删除 H 中以后仍可能用于验证的证据。

R 保存尚未凝固的最小历史因果区别 χ、其条件耦合 K、资格与作用控制。R 的自由度不是“历史不同”本身：只有在固定 x、θ、合法事实访问 c、已有获准作用及其他相关条件后，当前表示仍错误合并了对未来核心转移具有不可约条件差异的历史，R 才有必要最小细化。χ 是被保留的最小历史区别；K 是该区别对未来核心端点的非冗余条件因果耦合。只有经资格验证并正式获准的 K 才构成有效自由度；provisional/shadow 的历史区别本身不增加正式自由度。

θ 采用概念上的双视图 θ=(D_θ,G_θ)，不是增加新的核心状态。D_θ 是当前生效的长期动力学；G_θ 是为了寻址、门控、组合、接管、失效、隔离与修复这些动力学所必需的当前责任结构。形成证据、root 消费、审查历史与失效原因主要保留在 H/L，θ 只保存运行时必需的责任与来源指针。C 是 θ 的唯一成长写路径，G 对 θ 只读；θ 在两次合法 C 提交之间不自主漂移。

L 是只追加的凝固、贡献消费与不可逆审计账本。L 可以约束未来 C 的资格和预算，但不是事实库、人格向量或运行时作用触发器；F/J 不从 L 读取行为信号。

定义 Ω_k 为当前事务显式绑定的版本化实现资源集合，包括 Registry、IRL/解析器、scope 解释器、carrier、基础模型与配置。整体转移可写为 (S\_{k+1},Q\_{k+1},U\_{k+1})=T(S_k,Q_k,U_k,r_k,Δ_k;Ω_k)。在这些输入以及已记录的随机种子/实际 worker 结果固定后，不允许任何匿名持久变量改变未来核心转移；否则该变量必须归入 S、Q、U 或成为显式版本化 Ω。Registry 可以增加/迁移语义身份，但不得自行携带获准的 F/G/J 行为倾向或成长参数。

来源与 provenance 默认用于解释形成、预算、失效传播和审计，而不是运行时触发器。只有当来源类别本身被显式写入合法 scope、具备相应输入权限并通过资格验证时，才可参与端点求值；不得仅凭 source_trace_id 私下回读 H 来触发长期作用。

| **数据或决定**                           | **唯一逻辑归属**    | **允许的变更者**                     |
|------------------------------------------|---------------------|--------------------------------------|
| Γ 接受的规范事件、实际外部结果与纠错关系 | H（原始接收另在 D） | 入口及外层事务；只追加               |
| 快状态                                   | x                   | F；只由外层事务发布                  |
| χ/K、证据链接、资格、R 授权消费          | R                   | G；只由外层事务发布                  |
| module、已凝固责任和处置记录             | θ                   | C；只由外层事务发布                  |
| 凝固贡献及拒绝记录                       | L                   | C 暂存，外层追加                     |
| TrialPlan 执行、action、隔离模式         | Q                   | 确定性运行时                         |
| 解析器、作用解释器、模型载体             | 版本化实现资源      | 显式发布或迁移；不由成长过程静默改写 |

验证服务不拥有额外可变的成长状态。证书和足以解释其资格的摘要属于 R；原始观测属于 H；大型不可变试验产物由内容引用定位，必须可恢复。验证缓存、索引和历史 z 都不是可绕过 R 的长期作用来源。

权限按读路径落实。IRL 只读当前事件、受预算限制的 c_core 和解析资源，不读 x/R/θ 来“纠正事实”。G 可读 R_full，但其正式 metaplastic 输入必须单独经过授权投影。C 可读完整 R、θ、L 及有范围的 H 证据视图。F、J、人格性调度和 A_x 不得读取 shadow、证据叙述、trial 预测或审计文本。

基础权重 φ₀ 在运行中冻结。任何新增有持久作用的学习参数必须归入 R、θ 或显式版本化实现资源，不能藏在模型 worker、J 缓存、在线优化器、Registry alias 或解释器私有状态里。版本化资源只能按其公开合同影响转移；若某资源开始承载经验形成的行为倾向，它必须迁入 R/θ 或重新定义为受治理的核心状态，而不能以“实现资源”名义绕过 G/C。

# 3 统一作用合同与去重

## 3 1 作用身份和端点

沿用 responsibility_id 表示一项可寻址的因果责任，revision 表示其不可变实现版本。责任可以含多个经共同验证的子作用，但每个子作用必须声明端点和路由。本轮端点为 F_event、J_direct、G_meta；θ 已有 b、Λ 等自然动力学由 F_time 投影读取。端点是既有算子的字段，不是新算子或新核心状态。

同一来源可能合法支持不同作用，因此“同 root”不等于“必须只有一个输出”。真正的重复是：同一责任、同一 scope、同一端点已由一个 owner 承担，却又由另一路径实现一次。多通道作用必须在同一合同中显式列出并联合验证；不得把一项效果先编码入 x，再以未声明的 J_direct 副本相加。

参考作用记录包含：responsibility_id、causal_revision、owner、endpoint、scope、carrier、参数、幅度界、资格引用、机制祖先及解释依赖。未凝固责任由 R 管理；已有 θ 接管记录的责任，以 θ 记录为准。禁用或失效处置必须保留接管记录，不能被解释为“从未接管”。

作用记录中的来源绑定、ancestry 与解释依赖默认是形成/失效/审计元数据，不是端点触发条件。运行时只有 endpoint、scope 与其白名单 typed_context 可以决定是否命中作用；若需按来源类别触发，必须把该类别显式纳入 scope 合同并重新资格化。

## 3 2 两阶段纯函数

CompileAuthorizedEffects(R_snapshot, theta_snapshot, validity_snapshot, t, config)  
-\> AuthorizedEffectSet \| StructuralFault  
EvaluateEffects(effect_set, endpoint, typed_context)

Compile 检查 phase、eligibility、时间包络、证书/来源有效性、失效屏障、已提交授权、责任 owner 和依赖版本，输出当前时刻的最小有效运行描述。它不修改存储状态，也不返回候选文本、confidence 叙述或证据计数。R 可因时间投影得到不同有效幅度；θ 在严格模式下若存在未解决硬失效或超出合法有效合同，则 Compile 返回 StructuralFault 并触发全核心隔离语义，而不是 runtime 私自局部改写 module enabled。Evaluate 只求值，不扣额度、不写状态；receipt 记录命中的责任、端点、版本与实际幅度，用于审计而非新的记忆。

## 3 3 条件语言和组合

第一版 scope 使用有界、无任意代码的 predicate DSL：类型化枚举、Concept 身份、有限集合、数值闭区间、布尔组合及显式允许的状态坐标谓词。深度、节点数和数值精度有限。不同端点使用不同字段白名单；所有含义绑定解释器和 Registry 版本。

对于此有限语言，Core 可用规范化约束检查重叠。无法证明不重叠即按冲突处理；不调用 LLM 判定函数等价。作用以稳定责任顺序归约，数值归约算法固定。不同责任可相加，但新增候选必须连同既有作用通过总幅度、冲突和行为交互检查。不得靠数值相消掩盖两个相反的强作用。

# 4 单事件顺序与数学接口

以下 k 为已提交基线，t_k 为记录的处理时刻。取 t≥t_k，Δ=t−t_k。事件发生时间用于证据语义，不用于回拨动力学时钟。

F_in、G、C、F_out 是同一事件的阶段，不是四个可分别发布的事务。G 使用 θ_k；C 的 θ_next 最早影响本事件提交后的 J 以及后续事件的 F/G，不回流重算本事件 G。若待办需要等待，J 从同一提交快照投影到生成时刻后求值。

所有辅助入参分为三类：数学输入的有类型子视图、不可变实现配置、当前事务绑定。不能借 config 或 context 传入未声明的可变状态。Proposal、证书等数据要么已经属于上述快照，要么是本次 r/z 携带并经验证的结算结果。

z 及其 SemanticGraph/解析摘要是本次 r 的有版本派生解释，不被当成另一条可独立成长的历史。后续若需引用其语义结果，必须绑定原 r、解析资源版本与摘要；不能只保存一个脱离来源的 z 再把它当作新的事实根。

# 5 F 快速动力学

## 5 1 状态空间和自然时间

第一版参考实现使用固定维数的盒空间 X=\[−1,1\]^d；d、表示版本、序列化精度和度量在部署配置中给出。坐标不命名为信任、依恋等心理量。维数只由容量与因果消融验收支持；运行时 residual 不扩维。改 d 属于显式表示迁移。

这里的“快状态”由因果职责而不是单纯存活时长定义：在声明 T_x 和 ε_x 内，x 应尽量压缩当前未来转移所需的近期信息；若某历史区别在 x 已固定后仍对未来核心端点产生稳定、不可替代的条件差异，则该区别不应通过把 λ 调小而长期塞进 x，而应进入 R 的 witness/χ/K 路径。

从 θ 取得唯一的时间参数投影 b∈X、Λ=diag(λ₁,…,λ_d)，且 0\<λ_min≤λ_i≤λ_max。严格正下界是第一版快速性的要求，不能用 λ=0 偷存长期记忆。

Phi_x(Delta, x; theta)\_i  
= b_i + exp(-lambda_i \* Delta) \* (x_i - b_i)

该表达式是 x 与 b 的凸组合，因此 X 前向不变；固定 θ 时具半群性。同一 R/θ 和未来条件下，两个初始 x 的差满足 \|\|δx(t)\|\|∞≤exp(−λ_min t)\|\|δx(0)\|\|∞。T_x 和误差目标据此约束 λ_min；“频繁更新”不作为快速性的替代证明。

R 的已授权作用可以经 F_event 改变 x，θ 可以经 b/Λ 与事件敏感性 B 改变 x。第一版不开放 R 任意改写自然向量场。若未来要让 C 学到新的 b/Λ/B 责任，必须先提供能在 R 中验证同类功能的 slice 与稳定性/交互证明；没有可接管 R 功能来源的候选返回 UnsupportedSlice。这是对未获资格通道的封闭，不限制 θ genesis 中已经合法冻结的 b/Λ/B 投影。

## 5 2 事件驱动

第一版把 A_x 限定为基础事件 drive 的提议者，仅接收已验证 z、x_bar 与固定版本的编码器。它不直接读取 R/θ 作用参数；后者由 Core 在唯一一次事件作用装配中施加，从而避免 worker 已考虑一次、Core 再乘一次同一敏感性。

一个可施工的 A_x 实现为 u=tanh(W_z f(z)+W_x x_bar+a)，其中 f 为固定容量的类型化语义特征编码，所有矩阵均为版本化、运行中不训练的提议模型参数。规则或其他学习模型可替换它，但不能扩大输入权限。此式不是预设正确人格；是否产生必要快状态作用由独立实验决定。不可用的 A_x 不以该式临时猜测替补。

u = ValidateDrive(A_x_proposal, z, x_bar, binding)  
delta = g(z, x_bar) ⊙ (B(theta_k) u  
+ Sum(F_event residuals from unique owners))  
x_tilde = Project_X(x_bar + delta)

第一版 u∈\[−1,1\]^d、B∈ℝ^(d×d)、g∈\[0,1\]^d，F_event residual 输出 d 维向量。g 是固定规则给出的事件门，B 是 θ 正式敏感性投影；新增 module 不得再次施加已经包含在 B 中的同一责任。责任清单必须区分基础敏感性槽与附加局部作用槽。第一版 residual 使用有界矩阵和向量、白名单 scope，不执行自由代码。

B(theta) = B_0 + Sum\_{j in O_B(theta)} Delta_B_j

其中 B_0 是 genesis/载体版本中冻结的基础事件敏感性；O_B(θ) 是当前由 θ 合法承担的 B 类 F_event responsibility 集合。每个 Δ_B_j 必须有稳定 responsibility_id、scope、owner、幅度界和资格来源，并只能由 C 从已合格 R slice 接管安装。worker、A_x 或 C 都不得在没有对应责任的情况下直接训练/改写 B。所有 B 项与 residual 一样按绝对幅度和组合交互验收，禁止靠数值相消绕过界。

Core 在实例加载与候选准入时检查 \|\|delta\|\|∞≤η_x 的保守界，使用各项幅度绝对值之和而非抵消后的值。非法数值、NaN、超界 drive、错误来源或绑定不符均拒绝；不通过任意缩放非法 Proposal 使其“勉强合法”。Project_X 是已冻结快状态边界，不是给新 K 重分配旧作用额度的办法。边界饱和区域也要进入功能探针。

一个事件无论重试多少次，只形成一个已提交脉冲。已提交事件不因 A_x 新版本或迟到 Proposal 再次处理；后续纠正须成为新事件。相同 root 的真实新事件可以影响 x，但不因此给 R/θ 增发独立支持。

## 5 3 F_out 的必要职责

本版不采用额外 post-event 脉冲。正常路径 F_out(x_tilde)=x_tilde；它核验 x 表示、所有候选依赖、θ_next 的时间参数合法性和该快状态对下一次投影的可用性，形成最终 receipt。C 更新后不得把 x 瞬间重置到新 b，也不得再调用 A_x 或自然衰减来“对齐”新 θ。

因此 F_out 是必要的提交阶段，但不宣称它是不可约的第二种动力学；代码可与最终 validator 合并。验收要求 F_in 和完整 F 有可测作用，不要求 F_out 为了通过测试故意非恒等。若未来引入真实 post-event 机制，必须给出独立输入依据、与 F_in 不重算的证明及版本变更。

硬失效可能留下已经进入 x 的短时影响。一般非线性情况下不能从当前 x 减去某个历史来源。遇到这种污染，本版进入核心隔离；恢复时仅允许有显式记录的 FastState reset 到固定 x_init，或在已证明安全的 θ 下等待至少满足误差界的 washout。两者都记录近期因果连续性中断，不能声称恢复了原本应有的反事实 x。固定 reset 是故障恢复规则，不是日常学习机制。

## 5 4 F 失败

A_x 失败只取消本次语义脉冲，保留合法 Φ 结果并记录 AX_DEGRADED；若 z 完全失败，F/G/C 不使用失败语义。F 的确定性计算出错或 x 表示损坏时不能发布伪造状态：保留原事务未提交并进入故障处理；可独立提供任务响应，但不得冒充核心提交成功。C 候选导致最终兼容性失败时，拒绝 C，保留合法的 G/F_in 结果；所有重新装配仍使用同一事件绑定，不重复脉冲。

# 6 G 的验证入口与候选语言

## 6 1 witness 不再是未实现的神谕

R 的本体判据与资格证据分离。给定 ReferenceContract E，在固定当前 x、θ、合法事实视图 c、已有获准 R_base、策略/实验条件及版本化资源 Ω 后，候选 χ/K 本身必须从比较基线中禁用。对两段历史 h_a、h_b，定义其在该合同中的条件等价为：

h_a ~\_E h_b  
iff  
sup\_{u+ in U_E} d_E(  
T_E^+(h_a \| x,theta,c,R_base,u+),  
T_E^+(h_b \| x,theta,c,R_base,u+)  
) \<= epsilon_E

其中 U_E 是预声明的允许未来探针/条件集合，T_E^+ 是合同声明的未来核心端点或外部可辨识结果签名；R_base 不含正在被检验的新候选。若当前 R 把 h_a、h_b 合并而实际出现 h_a≁\_E h_b 的可辨识证据，G 才有理由做最小必要细化。χ 只保留覆盖该非等价所需的最小历史判别；K 则给出 χ 到声明端点的非冗余条件耦合。有限候选语言找不到合格细化只说明当前实现未找到，不等于证明不存在。

ReferenceContract、scorer、统计检验与 trial 是“允许相信该非等价”的资格证据，不是 R 本体本身。更换 scorer、命名或模型不能单独制造新的有效自由度。任何机制不得仅凭由自身作用因果产生的后果获得自身资格信用；candidate-created difference 只能证明通路有作用，不能证明 candidate 在安装前就是必要的。

ReferenceContract 在候选资格检验前固定目标变量、外部结果来源、允许信息、事实检索与计算预算、比较基线、作用范围、数据划分、评分规则和统计假设。参照对象可以是经授权的预测或控制任务，不是 LLM 生成的“正确人格轨迹”。没有参照、可用结果或必要辨识条件时，结论是 non_identifiable。

验证计算可以在独立 worker 中进行，但只产出带完整输入绑定和实际结果的 Proposal。其结果作为有来源的 trial-result 或 maintenance 事件，经确定性 adapter 入 z，再由 G 校验证书并纳入 R。它不是第五个成长算子，也没有直接激活 K 的权限。

历史比较需要的数据由 H 提供受预算限制、可复现的研究视图，不允许 G 在正式转移时扫描无界 H。见证至少满足：在 candidate-free baseline 下，当前表示合并的历史样本对预声明未来端点或外部结果存在可重复的条件差异；差异不是已声明 x、θ、既有 R、合法事实取证、共同上游原因或行动策略足以解释的；比较使用候选之外的参照。安装 K 后才出现的核心差异，只能证明通路有作用，不能证明旧表示不足。

事实替代基线至少包括当前检索器及预注册的同预算可行替代。若相关区别能以合法事实投影在同等资源内解决，不授予新 R 自由度。这里的必要性是相对于明确的信息和计算合同，不能宣称对所有可能检索算法都不可替代。

## 6 2 可执行统计规则

第一版采用前瞻冻结的候选与 bounded-loss 对照。每个因果独立 root block 形成一个配对评分差 d_i∈\[−1,1\]，正值表示候选或历史分组对外部参照的预注册改进。block 内重复观察不能当作独立 n。不同 root ID 也不自动代表独立：若多个记录由同一上游行动、exposure 选择、模型生成副本、复制来源或共同未控制原因产生，在资格计数中仍按同一或相关 root 处理，除非预注册设计能够识别所需独立外生变异。若检验依赖真实干预，必须有预先登记的随机分配或足以支持目标因果量的辨识条件。

root independence 是因果/实验设计属性而不是 ID 属性。系统自己的机制 K、θ、调度或行动若影响了后续观测，该后果必须保留相应 ancestry/exposure 链；没有合法对照或可识别反事实时，它可以成为经历记录或故障信号，但不能被拆成新的独立 root 为原机制增发长期资格信用。

为处理重复查看和不断提出候选，分配全局错误预算 α。第 j 个测试机会分得 α_j=6α/(π²j²)，在累计 n 个独立 block 后查看，分得 α_jn=α_j/\[n(n+1)\]；同一 n 不能重复结算。j 由 R 的版本化验证记录单调分配，换名称、split、重试或更换 scorer 不重置它。每个独立对照或验收指标也必须取得自己的测试机会，不能共享一个 α_j 而不做校正。

在预声明的独立同分布 block 条件下，使用：

radius(j,n) = sqrt(2 \* log(2/alpha_jn) / n)  
CI(j,n) = \[mean(d)-radius, mean(d)+radius\] intersect \[-1,1\]  
pass improvement iff lower(CI) \> required_margin  
pass equivalence iff CI is wholly inside \[-epsilon, +epsilon\]

这是 bounded block 的 Hoeffding 界加可求和的多重检验分配；并非声称所有现实时间序列都满足独立假设。相关性未知、干预有未建模的跨 block 干扰、结果选择性缺失或权重不明时不使用该公式给出资格，返回 non_identifiable 或等待合法数据。需要更强序贯方法时可替换统计 profile，必须记录其假设与版本。\[R3\]

“没有显著差异”不能作为等价证书。连续性以差异上界低于容差判断；改进以下界超过预先门槛判断。用于选择 K、scorer、scope 或 stopping rule 的数据属于 discovery，不能再被标为正式未见验证。结果未知不记为零损失或成功；第一版遇到选择性缺失使检验假设失效时停止结算，不自行补标签。

## 6 3 表示分区和最小候选

ε 距离只是 compatibility，不作为可传递的等价关系。χ 使用固定编码的有限分区描述；新增 split 分割已有叶域，merge 必须验证整个合并域的误差界。不能对 A≈B、B≈C 做传递闭包后宣称 A≈C。

第一版候选语言包含：已有 scope 的细化、固定维数的有界稀疏 K 参数修订、有限 predicate 的 χ split、带等价证书的 merge、新的来源锚定 trace。参数采用配置规定的有限精度，描述长度有上限；一次搜索最多处理 N_candidate 个按规范顺序枚举或由 worker 提出的合法候选。有限搜索未找到解不等于不存在更优机制。

候选选择先满足硬约束与当前 witness 覆盖，再按固定表示码长度、未覆盖风险、作用扰动和规范 ID 排序。若没有能在容量和预算内覆盖当前要求的候选，返回 DEFERRED_NO_FEASIBLE_REPAIR，保留覆盖缺口。允许分批处理互不依赖的 witness，但每批必须明示范围，不能把遗漏伪装成全部已解决。

K 的参考载体为有界稀疏条件作用：scope 命中时，对已声明端点输出受界的向量、矩阵修正或候选搜索配额偏置。学习器可在 discovery 数据上优化其参数；只有通过资格后的不可变 revision 才具有正式作用。允许局部数值 residual，但 residual 的大小不产生新的 χ、维数或来源。

# 7 G 输入输出与完整状态机

G(θ_readonly,R_bar,x_tilde,r,z;config_G) 返回 StagedRResult。其内部 validation view 来源于输入 R 的绑定快照；θ 的正式影响经 G_meta view 进入。G 不访问全局“最新”validation_store，不重解释原文，不推进自然衰减，也不改 θ。

χ 生命周期为 provisional、qualified、superseded、retired；K phase 为 zero、shadow、qualified_shadow、active、suspended、superseded。validation outcome 单独记录 qualified、rejected、non_identifiable、continue_shadow；eligibility 单独记录 valid、needs_review、invalid。这样 rejected 不再是缺少定义的 phase，needs_review 也不再只是可忽略的备注。

| **转移**                   | **所需依据**                               | **作用结果**                   |
|----------------------------|--------------------------------------------|--------------------------------|
| 新建零作用观察项           | 合法来源与容量                             | 不增加有效自由度               |
| 新增 χ 或 split            | 已验证不足见证                             | 新分区和 K 先进入 shadow       |
| revision 或 scope 扩大     | 变化依据、当前基线和新试验计划             | 旧有效 revision 保留到正式切换 |
| shadow 到 qualified_shadow | 当前有效 χ 与 K 资格证书                   | 仍无正式作用                   |
| qualified_shadow 到 active | 预算、责任、连续性、交互及回退预案全部通过 | 原子 head switch；进入 canary  |
| merge                      | 整域等价证书与责任重映射                   | 不复制来源或信用               |
| active 到 suspended        | 验证失效、证据否定或 canary 故障           | 撤去 R 作用；记录故障路径      |
| needs_review               | 上游依赖失效或证书条件不再成立             | 默认隔离受影响 scope           |
| retire 或归档              | 无作用或已有合法移交与资源政策             | 不删除来源和责任处置           |
| rehydrate                  | 明确引用和候选恢复                         | 只恢复候选，不恢复旧资格       |

active 参数不原地训练。evidence-only revision 不改变责任、active carrier 或 θ suppression。split 的子作用只能在不重叠 scope 内分配原责任；重叠必须声明 composite 并整体验证。merge 不取“两个余额各完整保留”，而保留同一祖先使用流水。主动删除仍有效的作用不是无成本的资源清理，须走声明的退休/连续性合同；硬失效另记故障变化。

## 7 1 θ 到 G 的正式只读接口

ReadPlasticityView(theta_k, R_bar)  
-\> immutable approved metaplastic effects  
ApplyMeta(view, target, event_features, x_tilde)  
-\> bounded proposal-search controls + mechanism_context

第一版 metaplastic influence 只改变候选召回优先级、已授权搜索容量的分配和候选参数提议的局部门控；可以影响“先提出什么”，不能改变事实语义、统计阈值、root 独立性、测试机会分配、资格、激活门或贡献预算。影响搜寻不到某候选的可能性属于可测 plasticity effect，要进入 C 的 plasticity continuity 和覆盖率测试。

候选 target 在调用前先有责任来源和 lineage 声明。若 target 是调制机制本身、其机制祖先或同 authority lineage，关闭该项 meta influence。新生 K 和本事件刚接管的 θ module 不进入本事件 meta view。每项受影响修订记录实际使用的机制集合和版本，不能只记录“可能可用”的全部模块。

跨 lineage 情况中，A 调制生成 B 后，B 的 ancestry 包含 A，因此 B 不能再通过 G_meta 调制 A 的修订。由 A/B 诱发或筛选的证据保留 action 与机制因果链，不能改名为独立证据。独立随机化产生的真实新外部信息可以按原检验合同支持更新；不把“受过行为影响”一律解释成永远不能学习。

# 8 真实验证与后代复核

观察模式只能验证可由已发生输入/结果辨识的目标；内部路径探针只验证代码作用、消融和连续性；action-mediated K 必须另有受授权的真实干预。资格前的 shadow 不通过正式 J 改变行为。

TrialPlan 在结果可得前固定 candidate、baseline、数据分配、干预、scorer、停止条件、预算和解释依赖。运行时接受计划后将执行任务放入 Q；执行走普通 action-request、权限核对、结果记录。试验 worker 可在隔离实验实例中测试候选，包括非文本调制，但其候选状态不得写回正式分支。试验事件标明 experimental，不能把实验授权误当成核心主动倾向。

每个 block/settlement ID 只使用一次。候选、基线作用、解析器或模型改变且影响证书域时，未完成 trial 暂停或作废；不混合不同基线的数据。长期证书绑定的是其测试域和实际语义依赖，不要求每个无关的 x 数值更新都作废；当前提交 Proposal 则必须绑定本次精确快照。此区分同时防止 stale 资格和“所有资格永远来不及使用”。

后代依赖图是 R/θ 记录的派生索引，记录资格依赖、生成机制依赖和数据/action 来源依赖。上游失效先计算受影响责任闭包；在一个原子事务里安装隔离集合或一个可判定的祖先失效屏障。大图可随后分批详细复核，但屏障生效前不得恢复正式作用，不能以队列尚未扫描完为由继续使用污染后代。

R 后代以 G 暂存 needs_review；θ 后代在严格模式下不能靠 runtime 直接修改 enabled。只要不能由现有合法 C 原子修复，本实例进入全核心隔离。此时自动停止 θ/R 对 F/G/J 与人格性调度的正式作用，继续事实记录和确定性证据结算；不运行被失效 metaplastic 机制影响的候选搜索。没有独立有效支持时允许长期等待。

复核若证明证书无需被否定的依赖即可成立，记录替代证书并解除对应屏障；否则保持失效。所有真实行动和结果仍在 H 中。源模块关闭不自动恢复源 R，后代还要包括已经再次凝固的 θ 模块。

# 9 C 凝固资格和 slice

C(θ,R_next,H_next,L;config_C) 返回待提交 (θ_next,L_next)。只读 H 通过本次候选声明的证据查询计划：支持集合、同假设反证索引和来源有效性视图。查不到或索引版本不足时返回 EVIDENCE_INCOMPLETE；不得把“未检索到”视为“不存在反证”。C 不据此新建 χ。

可以进入 C 的内容必须是：χ 和 K 在声明 scope 合格；至少在先前提交中 active；作用责任可寻址；没有未解决硬反证；实际 canary 和要求的驻留完成；支持来源有效且相关；载体能够导出可复制或转换的功能 slice；满足 n_min\>1 的因果独立 root 资格；root/lineage、单步、窗口和交互预算都允许。

第一版所有普通非零 θ 凝固均要求 \|Roots_independent\|≥n_min 且 n_min\>1，并要求事件跨度 Δ_min\>0。重复观察、换时间点、换 ID、split、merge、摘要重写或由同一上游行动/来源产生的多个结果都不能把一个因果 root 变成多个独立 root。单一 root 可以维持/修订 R、延长 shadow/active 观察、触发 probe、故障告警或隔离，但不能单独授权新的非零 θ 长期更新。内容或支持关系实质改变重新计时；摘要、换 ID 或拆簇不刷新年龄和额度。单靠经历“很久以前”或反复回想不能获得资格。

ConsolidationSlice 是既有 R 作用的有类型视图，包含精确来源 revision、稳定责任、作用端点、scope 子域、函数合同、当前时间包络、候选长期包络、支持根、资格、ancestry、解释依赖与预算申领。slice 不创建新 root，也不能只凭相似参数认定两个职责相同。

默认 slice 为一个完整责任在一个可判定子域的接管。子域与剩余 R 的域必须不重叠；若不能证明，保持整个责任未接管，不能执行含糊的“吸收一部分”。未覆盖的责任仍由 R 承担。

slice 必须通过依赖闭包检查：χ 中为作用必需的判别函数及其参数随功能合同一起转移；接管后的 module 只能使用其端点允许的显式输入。不能复制 K 后仍按 source_trace_id 私下读取原 R 的 χ 状态、证据或历史。若机制依赖一个继续由 G 更新的源 R 私有变量，而当前 θ carrier 无法按现合同承载该依赖，则该 slice 不可凝固，保持在 R；不以隐藏读取完成“接管”。

## 9 1 C_propose 的确定职责

第一版优先使用可复制的稀疏有界载体：把已合格的条件和端点函数编译为 θ 的 source-addressable module；参数保持语义，新增来源、组合次序、owner 与长期作用合同。若需要换载体，学习器仅提出映射参数；Core 必须对映射进行独立 transfer 和回归检验。编译不代表自动通过。

本版不在 C 内发现全新的机制，不顺便修改无关 b/Λ/B、基础模型权重或 J 映射。没有 R 功能来源的 θ 改变返回 UNSUPPORTED_SLICE。对 B 的任何新长期敏感性修正也必须由对应 F_event responsibility 的 R slice 接管而来。θ 的存储优化或共享参数压缩只有在所有相关责任仍可单独寻址、隔离、解释和重放时才允许；否则不是合法迁移。

# 10 C 交接和连续性

## 10 1 原子责任交接

交接前的比较系统为旧 θ 加仍由 R 承担的源 slice；交接后的比较系统为候选 θ 加已被接管记录抑制的 R。禁止固定 R_effective 不变、只替换 θ 来测 handoff，那会把本来不应存在的双重作用带入探针。

theta_candidate = compile_or_map(slice)  
candidate_view = CompileAuthorizedEffects(R_next, theta_candidate)  
validate whole old view versus whole candidate view  
stage theta module + responsibility disposition + L entries  
outer commit publishes them together with R_next and x_next

C 不需要另一个 R 输出：θ 是已凝固责任登记的权威，R_effective 从 R 与 θ 联合导出。R 中 binding 若保留，只是引用或可重建缓存。C 拒绝则 θ 不变且不消费凝固贡献；可以追加拒绝记录。交接后 evidence-only revision 继续指向同一责任，不能重新泄露 R 作用。

## 10 2 即时等价与长期保持分开验证

即时 transfer 检验固定同一 x、当前输入、事实、模型与调度条件，比较交接两侧的端点输出、J 调制、行为和 G 候选过程。对复制编译的参考载体，参数与条件相同可给出端点级精确相等；浮点实现仍有明确误差。

长期凝固通常会改变保持时间，不能要求与旧 R 的衰减轨迹永久相等。本版候选必须另外声明未来保持合同和测试时域 T_promote；长期维持须由对应资格支持，并计入 θ 变化预算。T_promote 只表示至少被直接验证的 transfer/保持时域，不自动等价于“永久授权”。每个 θ module 还必须携带显式 ValidityContract，声明其作用域、依赖假设以及有限 valid_until 或可验证的续期/持续有效条件。只证明 t=0 相等不能证明长期提升合法，也不能把所有未来差异都当作交接失败。

第一版在接管时复制 R 当前实际幅度 q(t_h)K，θ module 在合法 ValidityContract 内、两次 C 之间保持该幅度，不自动回升到历史峰值。于是即时无跳变；未来相对于 R 的衰减差异属于被申报的长期保持。若该时点作用已为零，不能以接管名义重建非零 θ。需要更强幅度的候选必须另有当前资格和预算。若有限 valid_until 到期或持续有效条件失效而没有合法 C 续期/补偿，严格模式不允许 runtime 局部改 enabled；授权编译返回失效并进入 CORE_QUARANTINED，直到 C 合法处置。

| **检验**              | **具体比较对象**                                          | **拒绝条件**                       |
|-----------------------|-----------------------------------------------------------|------------------------------------|
| Modulation continuity | 完整有效视图在 F/J/调度端点的数值输出                     | 超过预注册界或遗漏端点             |
| Behavior continuity   | 固定上下文下的输出分布或预注册样本统计、行动时机          | 上置信界超阈值或能力回归           |
| Plasticity continuity | 固定事件集、搜索种子和 Proposal 集下 G 的候选、排序、覆盖 | 无关大范围改变或治理规则被改变     |
| Time transfer         | 交接瞬间与 T_promote 内的参考轨迹                         | 未申报的持续性变化或时间尺度越界   |
| Interaction           | 新模块与所有潜在重叠责任的组合                            | 合计越界、冲突、不可解释的次序依赖 |

单模块通过不代表组合通过。第一版固定组合次序，并对所有 scope 可能相交的模块进行整组检验。只做两两 probe 无法排除三元协同；因此至少检查实际整组输出，并用保守幅度上界覆盖未枚举组合。不能证明的组合保持候选。

## 10 3 θ 距离和作用预算

继续使用 θ 基线的度量空间合同 d_Θ。它必须是对实际长期状态或其规范表示定义的度量，不能把有限 probe 差异冒充全域度量，也不能因为传输即时等价就认定非零 module 安装距离为零。若 carrier 的参数有 gauge 等价，可对规范化参数或已定义商空间计量；该规范化必须确定。

本轮有限稀疏载体给出可执行参考度量：θ 采用有界 module slot 的规范序列，未用参数补零；数值部分 p 包含全部 carrier 参数，离散部分 c 包含有效开关、owner、端点、规范 scope、来源绑定和组合次序。取 d_Θ=w_p\|\|p−p′\|\|₁+w_c·Hamming(c,c′)，w_p,w_c\>0，离散字段使用规范原值比较而非把哈希碰撞当相等。slot 的分配与保留处置规则固定。该式在规范表示上是度量，且无须运行模型就可计算；审计叙述仍放 L，不混入参数距离。其他 θ carrier 可提供保留同样预算义务的已验证度量适配器。

C 同时检查 d_Θ≤κΣw(e)、单步界、窗口路径界和行为/作用界。若 carrier 无法提供计算 d_Θ 的实现或保守上界，直接拒绝载入；不会用“探针没变化”代替距离。本版 C 算法可参数化于合法 d_Θ，具体单位、κ 与阈值属于必填部署配置。

# 11 C 预算 失效与伪代码

来源预算分开计算 R 授权增长和 θ 更新，但不能给同一来源复制两份可自由互换的全额信用。第一版为每个获准 root 预分配有限 b_R(e)、b_Θ(e)，其和不超过固定总配额；两份配额不互借、不随时间补满。R 消费归 R，θ 消费归 L，因而 G 不需要偷偷读取 L。固定分配比例是部署配置，不是两个独立发行者。

R 的每次授权增长/一般补偿满足 cost_R≤κ_RΣcharge_R，θ 的普通更新满足 d_Θ≤κ_ΘΣw；各 root 累计消费分别不超过初始配额。split、merge、revision、handoff 继承同一账本索引，不复制余额。贡献资格不等于支持数量；同一 root 在 C 中仍只算一个，R 已验证它不等于获得一个新根。

root 分组被正式纠正时保留旧消费记录，并以新的保守分组停止超额授权、复核受影响资格；不重写过去为“从未超额”，也不退款再发信用。拒绝与未提交预留释放；已经提交的普通更新、补偿和 canary 回退成本保留。纯读、J、Φ 与重放不扣授权额度，外部执行成本另由 Q 按 action_id 结算。

R 硬失效的撤作用可能越过通常连续性界，作为故障路径单独计量，不能用普通成长路径定理声称其也小步。恢复安全旧 revision 仍须当前有效并保留责任约束；为 canary 恢复预留的预算只是未消费余额保留，成功恢复时正常消费。没有合法恢复条件则维持零作用或隔离，不无限退款重试。

θ 失效遵守严格模式：runtime 不能写 enabled；没有合法 C 补偿时进入 CORE_QUARANTINED，J 不产生有效核心调制，F/G 的正式成长关闭，任务层可显式以 m=0 响应。事实、失效通知、试验原始结果和合法独立维护仍可记录；固定治理的资格结算不受失效 metaplastic 作用影响。重新开放须合法 C 处置受影响 θ，完成 R/θ 后代复核和 x 污染恢复。此路径保证封闭性，不保证一定存在恢复证据。

C.REVOKE 没有被本版悄悄采纳。若产品以后要求“证据额度耗尽仍即时局部关闭 θ，并保留其余核心运行”，必须修改上位第 7 至 9、11、14 节及预算定理。现有冻结条件下不能同时承诺该性质。

C(theta, R_next, H_next, L, cfg):  
sources = bounded_evidence_view(H_next, R_next, cfg)  
if unresolved_hard_invalidation_of_theta:  
request_core_quarantine()  
slices = select_previously_active_slices_in_fixed_order(R_next, theta)  
for slice in bounded(slices):  
if not current_eligibility(slice, sources, L): record_reject(); continue  
proposal = recorded_C_propose(theta, slice)  
if not valid_module_and_owner_map(proposal): record_reject(); continue  
if not valid_credit_metric_and_window(proposal): record_defer(); continue  
old_view, new_view = bind_whole_views(theta, proposal, R_next)  
if not all_transfer_behavior_plasticity_time_interaction_checks:  
record_reject(); continue  
stage_one_canonical_candidate_and_L(proposal)  
return staged_theta_and_L()  
return unchanged_theta_and_rejection_audit()

第一版每事件至多接受一组预先共同验证的 C 候选。不能按循环次序连续安装多个只相对同一旧 θ 测过的模块；下一次更新必须基于已提交新 θ。外部 probe 太慢时在 Q 中建立显式 trial，先提交合法无 C 更新结果；结果后来作为新事件进入 C，重新检查其实际语义依赖。不会在后台完成后越过既有提交顺序直接写 θ。

伪代码中的 request_core_quarantine 只产生本次 C 决定记录，不是对 Q 的即时写入。外层运行时据该已暂存决定构造 Q 变更并一同提交。G 的 requested_trial_jobs 同样只是 R 中试验决定的执行请求。隔离期间 C 优先处理受影响责任的合法补偿，不因安装了一个无关模块就解除隔离；必须检查全部屏障和污染后代已获得合法处置。

# 12 J 的数学职责与输入

J 把同一提交快照的因果状态变成基础模型可直接消费的非文本调制 m。它不是叙事生成器，不解释事实，不决定价值真相，也不承担额外记忆。

J(theta, x, R; carrier_config) -\> ModulationEnvelope \| JFault  
effects = CompileAuthorizedEffects(R, theta, validity_snapshot, t, config)  
m = (a_l for l in declared_hook_layers)  
a_l = W_l x + Sum(J_direct effects from effects with unique owners)

W_l 为固定版本的快状态读出映射。可减去固定初始化参考点，但不得在每次 C 后临时改参考点并抵消真实 x；第一版取固定原点。R/θ 的 J_direct 作用为 scope 内的有界稀疏向量或 x 的有界函数。θ 通过 b/Λ/B 影响 x 所形成的效应已经包含在 W_l x 中，不能以“θ 总结”再复制一次。θ 的直接调制只包含独立登记的 J_direct 责任。

本版不使用一个黑箱 J_joint(x,R_full,θ_full) 同时猜测各状态的重要性。首先按责任路由排除未授权项，再用确定性组合形成 m。多源对不同端点或不同功能的交互可以存在，但必须有联合合同；来源相同并不自动要求线性相减。

同一责任仅有唯一 owner 是可检查的不变量；“两个不同责任语义上完全不冗余”只能在声明 scope 下通过条件消融验证。资格试验至少包含：保留 x 撤去直接项、钳制 x 保留直接项、二者同时撤去、完整系统。若直接项只是复制经 x 已充分实现的作用且没有独立必要性，不给予第二项资格。

## 12 1 scope 强度与竞争

J scope 只使用 x 与 R/θ 授权的状态字段。不接受任意当前文本触发器。某个模块要求“仅当用户提及某概念”但 J 无该输入时，必须改走 F_event 合法路径并验证短时余量，不能给 J 偷加参数。

每个载体层 l 预留快状态最大额度 β_x,l，其他 J_direct 项按责任分配 β_r,l，要求 \|\|W_l\|\|∞→2≤β_x,l 以及 Σβ_r,l+β_x,l≤β_l。实施时可用 W_l 各列二范数之和作为容易计算的保守上界，不要求求解难以计算的精确诱导范数。使用保守的绝对幅度预算，冲突项不能凭符号相消过关。新候选若超额，保持既有作用，候选延期；不自动缩小全部旧模块。

参考组合允许加法，但统计上已验证的互斥或冲突责任必须由资格过程选择唯一作用，或编译为单一 composite 后重新验收。运行时只执行已经明确的规则，不由 LLM 临时仲裁。相加后仍需行为探针；线性载体不使基础模型成为线性系统。

J 无自身持久状态，因为时序依赖已分别归 x/R/θ，行动和缓存归 Q。若某实现需要跨请求累计隐藏 m、迟滞门或内部记忆，必须先证明现有状态不能表达；本版不允许以 J 私有变量实现。相同合法输入和载体版本必得相同 m。

# 13 第一版真实模型载体

## 13 1 低秩激活加法

采用可访问内部激活的冻结 decoder 模型。在配置指定的一个残差流 hook 上，按每个参与生成分布计算的位置注入：

h_l,p' = h_l,p + U_l a_l  
U_l has fixed dimensions d_model by r, r \<= d_model  
operator_norm(U_l) \<= 1  
norm_2(a_l) \<= beta_l

第一版从一个 hook、有限 rank、固定位置掩码开始。hook 明确到层号、残差相加后的张量以及与下一归一化层的相对位置；prefill 最后位置和后续生成位置的规则必须相同且可测试。位置规则是固定载体合同，不由请求文本临时选择。m 在一次有界生成请求中保持不变；新事件需要重新生成计划。

U_l 与 W_l 的参数、精度、注入位置和掩码属于载体版本，运行中冻结。它们可以通过独立校准任务拟合，但必须报告来源和先验，不能从“信任”等心理词直接宣称状态坐标真值。R/θ 的作用参数经既有资格与提交机制变化；不得在 carrier 内运行持久优化器。

选择激活加法的理由是作用路径简单、可以实际测到注入差值、易于消融且不必更改基础权重。公开 activation engineering 工作提供了内部激活调制可影响输出的实验先例；本规格的路由、预算与验收是针对 Echo Core 的设计，不由该文献自动保证。\[R1\] LoRA 也可冻结基础权重并引入低秩参数，但第一版不同时混入另一套在线适配状态；其替换必须经过下述迁移合同。\[R2\]

## 13 2 模型接收和缓存合同

ModulationEnvelope 至少含 snapshot_id、投影时刻、x/R/θ 摘要、carrier/model 版本、hook 描述、a_l 数组、总界和 effect receipt digest。推理适配器验证 shape、dtype、范围与完整性，加载正确 U 后执行注入，并返回实际使用的调制摘要和探针位置统计。只接受但未应用 m 是功能失败。

基础模型的普通输入仍为 o、p、c_task；这些不反向成为 J 入参。m=0 必须产生未调制基准路径。只有文本 API 的模型不能完成此严格接口，应返回 CARRIER_UNAVAILABLE，系统进入明确任务响应模式；不能把 m 翻译成人格提示后继续报告严格调制成功。

KV cache 会承载之前调制过的激活。缓存键因此必须包括基础模型、tokenizer、prompt 前缀、carrier、m 摘要、掩码和数值配置。m 改变后不得复用旧调制 prefill；第一版直接失效并重算相关缓存。跨请求复用也遵守同一规则。缓存属于推理运行时，不是 J 新状态。

一个生成请求绑定单一快照、最大 token 数和最长处理时长。输出中的执行建议仍只是 plan。若流式内容已经对外发布，那些实际发布部分是已发生输出，不能在新事件后假装撤回；其记录按行动生命周期保留。状态、协议或权限变化使尚未发出的计划过期，执行前必须复核。

## 13 3 替换载体

换 U、W、hook、基础模型或 tokenizer 都可能改变状态作用语义，不只是文件格式升级。迁移必须保持责任与来源身份，给出旧作用到新作用的映射，并验证零作用、各责任消融、组合、时间轨迹、scope 泄漏、能力回归和 G 的受影响 probe。映射失败保留原核心并拒绝新 carrier，不清空状态或静默退回文本提示。

迁移不是新经历，不增加 root 或信用。x/R/θ 参数若需要变换，必须由显式迁移事务记录前后映射、状态摘要和误差；该记录不能与普通 C 成长混为一谈。保持存储不代表已经保持行为。

# 14 J 验收与失败

第一层是通路验收：在指定 hook 实测 h'−h=Ua，误差低于数值容差；m=0 与基准相等；更换 m 必须让缓存失效；所有运行记录能指向实际 carrier。第二层是功能验收：在独立冻结的测试集上比较完整系统、m=0、匹配范数的随机方向、状态打乱和各责任消融。事实输入、协议、模型、采样方案和生成预算保持固定。

预注册的主要指标必须反映被声明的行为或控制目标，并有足够重复采样、误差区间和负对照。要求有方向、有最小效果量的可重复变化，同时通过离域与能力回归限制。“文本提到了更多人格词”“LLM 说自己感觉不同”不算证据。内部激活变化也不能单独替代行为效果。

若某项调制只改变即时词频，但被声明为行动策略或长期状态效应，验收失败。长期 θ 验收需统一 x、控制剩余 R，在新独立场景与合法条件下检查作用；否则不能区分凝固与尚未衰减的短期效应。

J 编译失败、数值非法、carrier 不兼容或实际未应用 m 时，不复用旧 m。Q 标记 CORE_UNMODULATED 或 CORE_QUARANTINED，暂停依赖核心倾向的自主行动；任务层可以 m=0 响应并记录该模式。J 失败不反向修改 θ 或返还预算。对失败原因进行修复、通过固定探针和版本核对后才恢复。

# 15 自然时间和尺度分离

当前冻结边界中的完整时间链为：

Phi_full(Delta; x,R,theta) = (x_bar, R_bar, theta)  
x_bar = Phi_x(Delta; x, theta)  
R_bar = Phi_R(Delta; R)  
theta(t) = last theta committed by C  
E_eff(t) = CompileAuthorizedEffects(R_bar, theta, validity(t), t, config)

这里必须区分存储状态与有效作用视图。Phi_R 只从最后提交锚点计算当前 R 的时间投影视图 R_bar，不把衰减读操作写回 stored R；重复读取不累计衰减。θ stored state 在两次合法 C 之间恒定，纯时间不写 θ；但 E_eff(t) 会根据 q 包络、scope、owner/suppression、证书/来源有效性、ValidityContract 与失效屏障决定当前允许执行的作用。采用 θ 自身连续演化会改变写权限和预算定理，不属于本版扩展。

第一版 R 作用保持采用明确的标量包络 q∈\[0,1\]，位于现有 effect_control：q(t+Δ)=q(t)exp(−γΔ)，γ 在合法激活时固定。它只乘已经验证支持缩放的稀疏载体，不能借包络改变 scope 或产生新参数。归档、资格与证据记录不因时间自动变成另一事实。无事件维护从同一锚点确定投影，重复读取不积累误差或消费额度。

q 的资格域必须覆盖将使用的 \[0,q₀\]；如果中间幅度行为非线性超界，即使端点通过也不能启用连续缩放。R 证书到期时，过期作用不再进入 E_eff；正常退出尽可能使用已验证的衰减/退休合同。θ 的长期 module 则按其 ValidityContract 判定，不允许把有限 T_promote 证据静默扩展成无限时间授权；严格模式下无法合法续期/补偿时进入全核心隔离，而不是局部 runtime disable。没有安全连续退出时按故障处置并记录突变，不为保持平滑继续使用过期资格。

第一版 λ_min 与 R 衰减率满足预声明的尺度分离区间，例如 λ_min/γ_max≥ρ，ρ\>1；目标比率由实验配置冻结，不把示例数值当本体。θ 的时间尺度通过长期变化达到固定 d_Θ 或行为量所需的真实时间测量，并由 θ 的窗口路径上限约束。

为防止窗口边界的短时突发，θ profile 必须同时给出单步 ε_Θ、实际滚动窗口，以及对任意区间的累计界 path_Θ(\[s,t\])≤v_Θ(t−s)+ε_Θ。Core 用持久化提交时刻和路径前缀校验，不按“调用次数”限速。若希望声称 τ_θ 至少为某值，必须对预注册变化量 D\>ε_Θ 验证 (D−ε_Θ)/v_Θ 达标。R 的一般授权变更也采用自己的速率界；故障撤作用单独统计。

固定有限根下，普通成长累计路径由贡献预算给出上界；不断到来的新根可以支持更长变化，但仍受真实时间限速。稳定机制的重复执行不是成长路径长度。x 的快速记忆在控制慢状态时收缩；若不同 R/θ 持续驱动了不同 x，不应把该差异误认成 x 偷存长期状态。

F_in、G、C、F_out 均不再推进本区间 Δ。同一 θ、无实质事件时 Φ 分段投影应一致；有 C 更新时必须按记录的事务生效处理时刻分段，不能用新 θ 倒算此前经过的时间。维护可触发对已有合格证据的 C 检查，但 C 更新是独立显式事件效果，不是 Φ 的隐藏副作用。

# 16 Proposal 事务 崩溃与重放

## 16 1 完整输入绑定

ProposalBinding  
branch_id, event_id, raw_log_position, base_commit  
process_time, anchor_time, projected_state_digest  
accepted_z_digest, c_core_digest  
x/R/theta revisions, validation_snapshot, source_validity_version  
registry/scope/carrier/model/config versions  
relevant_effect_set_digest, proposal_payload_digest

base_commit 相同不代表 x 输入相同：不同处理时刻会产生不同投影。Core 必须核对实际 read set 和投影摘要。工作线程产生的 Proposal 记录实际输出及其输入，不只存 prompt、种子或摘要；大对象引用必须可完整恢复。

配置和外部资源采用不可变版本。发布新 Registry alias、scope 解释器或模型版本不能直接重解释 active 条件；显式兼容迁移或新资格完成前使用旧解释资源。缺少旧资源时停止对应作用或报告不可重放，不能调用新服务猜旧结果。

## 16 2 原子边界

接收先追加 D。外层事务按唯一 branch 顺序读取下一记录，在锁外完成可重放的 Proposal 计算，提交时核对 head 与全部绑定。原子发布集合至少为 H、x、R、θ、L、Q 的必要变化、入口 U、处理位置、时间锚点、当前 staged Concept 与审计引用。任何一项缺失都不是完整提交。

持久化采用单个具原子事务能力的权威存储或等价日志协议。大型实际返回先写不可变对象并确认可恢复，再在事务中引用；未提交孤儿对象可以回收，已提交引用不能提前丢失。事务日志中的 accepted result 足够恢复，不要求再次运行不确定 worker。

一次事实事件的 G/C 非关键 Proposal 可以因超时延期，提交合法的证据和快状态；但检测到硬失效时，隔离模式或失效屏障必须与相关记录同时提交。不能让“后台复核中”成为继续使用已知无效作用的理由。

## 16 3 行动与外部副作用

模型只生成 plan。运行时将带 action_id 的请求和 outbox 原子登记，随后执行外部副作用；记录执行成功、失败或未知，并把结果作为新事件输入。没有外部幂等键时不承诺一般性的 exactly-once；崩溃后执行状态未知则核对或停在 UNKNOWN，不盲目重发。

请求登记本身不形成新的独立支持，也不自动递归生成同类请求。仅由登记引起、没有改变计划语义的版本推进可使用明确的合法延续规则。真正新观察、调制变化或协议变化使未执行计划过期。即使计划已取消，已发送行动的结果仍按原 action_id 接收。

## 16 4 恢复与补偿

提交前崩溃：所有 staged 变更和未提交预留失效，从最后提交继续。提交后崩溃：按已保存 accepted result 恢复同一版本和账本，不重复发布。θ handoff、责任处置、R stage、L 消费及处理位置不得存在可见中间态。

rollback 指向前追加的补偿事务。不能回拨 H/L、trial 使用记录或来源消费；不能恢复一个当前已失效或已被 θ 接管的 R 版本。加载旧检查点另行发展必须按基线登记恢复或分叉，不能冒充当前 branch 的无损继续。

结构重放重建提交状态、资格、owner、预算和行动状态，不执行真实行动，也不重新询问模型。行为重放只有在模型、采样与数值环境满足确定性条件时要求逐次一致；否则检验预注册统计一致性。结构一致不等于已证明人格或主观自我连续。

# 17 整体闭环的执行细则

## 17 1 因果顺序

完整链为 H/current event → IRL → F_in → G → C → F_out → 原子提交 → 授权作用编译 E_eff → J → model plan → runtime execution → 新 event。读依赖始终来自前一提交、本事件已有暂存阶段或版本化只读资源。没有阶段可以读取自己的未来提交结果，也没有“继续迭代直到人格自洽”的隐式固定点求解。

θ_k → G_k → R_next → C_k → θ_next 不是同事件循环，因为 G_k 不读取 θ_next。F_in 采用旧 θ，J 采用新 θ 是显式阶段语义，不允许实施者自行交换。若 C 拒绝，F_out 用旧 θ；若 C 接受，新的 J_direct 可立即用于提交后的计划，新的 F_event 只作用于后续事件。不同端点的生效时点必须写进 slice。

G 在当前事件发现硬失效时，F_in 可能已经使用了旧机制。外层事务必须将本次 x 视为可能受污染，不能在撤去 R 或隔离 θ 后直接发布“已清洁”m。若无法证明本次和既往快状态未受影响，F_out 标记快状态隔离，Q 禁止核心输出；按第 5 节的显式恢复处理。此规则同时覆盖 R 和 θ 的失效。

## 17 2 墙钟 处理时刻与队列

事务在开始处理 head 记录时捕获单调的 process_time，后续 worker 都绑定该时刻的投影；最终提交不重新读取时钟悄悄改变 x。该时刻是本次数学转移的生效处理时刻，实际持久化完成时刻另记为 commit_wall_time。两者不混用于重复推进时间。

同一 branch 在该事务未完成时不从其 staged 状态发行动。提交后生成计划时按生成的实际时刻从记录锚点投影一次，包含计算等待时间。C 对 θ 的分段点使用已记录的生效处理时刻；不能每次 replay 用当天的机器速度决定分段。相同有效事件序列但不同真实处理时间本来可以有不同动力学，不宣称只凭事件 ID 可实现时间无关重放。时间预算也使用这组实际捕获、单调且不回填的处理时刻，不能通过更改 commit_wall_time 刷新窗口。

部署必须限制处理延迟并报告 process_time 与 commit_wall_time 的差。若时延超过 profile 的可接受范围，本次 C/复杂候选延期或进入降级；不能让一个耗时数小时的推理仍宣称是未经误差限制的实时反应。J 生成和外部执行前还要核对已接收日志 frontier；有应优先处理的新输入时旧计划延期或失效。

## 17 3 行动时机和自证边界

人格性调度只读已获准 x/R/θ 作用与 m，运行时权限及资源门另外相乘。第一版配置有有限强度上界 λ_sched,max 和最小实际行动间隔，使有限时段内行动次数有界；维护和计划重算另设资源限额。调度不能读取 shadow 数量来改变人格时机。

模型输出“我变得更信任你”不会直接成为 x/R/θ 真值；自身输出进入 H 时继承自生成标记。行动结果也不天然独立：若 Ada 先诱导一个结果，再用它证明原判断，必须检查行为策略、暴露选择、共同上游原因和外部反馈来源。任何机制不得仅凭由自身作用因果下游产生的后果获得自身资格信用；只有合法随机干预、独立外生新信息或其他足以识别目标反事实的设计，才能把受影响结果用于相应 K 的资格。缺少此条件时最多记录经历，不能据此通过相应因果 K。

有界性：Φ_x 是 X 内的凸组合，F_in 在接受有界 drive 后投影回 X，F_out 不额外施加动力，因此每个正常提交 x∈X。有限字节、数值精度和 d 也是容量合同的一部分；只声明实数盒有界仍不足以证明信息容量有限。

无同事件环：按第 4 节顺序给阶段编号，所有可变读边都指向较小编号或 k 快照；G_meta 限于旧已提交集合，因此不存在从 θ_next/K_new 反向进入当前 G 的边。不同事件间的反馈保留，这是学习所需；其证据资格另由来源与干预规则治理。

不双算：对每项责任先按 θ 的接管登记选择唯一 owner，再求值一次。由责任创建和每次原子替换的归纳可保持 I07。它不等于证明所有不同责任都语义独立，后者须通过条件消融与组合证书。

有限根路径：对普通更新 j，有 path_j≤κΣ_e charge_j(e)，而每根累计 charge 不超过有限 b(e)，故固定根集合的普通累计路径≤κΣ_e b(e)。故障撤作用、模型迁移及自然演化须单独报告，不能将这个证明扩大到全部行为变化。

恢复：只发布完整提交记录，且所有不确定输入的实际结果可恢复，则重放可以按同样阶段与顺序重建同样结构状态。没有记录完整性和资源版本，不成立该结论；散列本身不补回丢失内容。

状态完备性：若在固定 S/Q/U、当前记录、处理时刻、版本化 Ω 与已记录实际结果后，两次执行仍可因某个未声明的持久变量而产生不同核心转移，则该实现违反 I18。缓存命中与性能差异可以不同，但不得改变权威语义结果。

| 运行时     | 时钟、事务编码、实际结果保存、action 幂等、隔离恢复                                           | 不发布核心状态或行动     |

维数、阈值和模型选择没有被宣称为本体真理，但必须在一个具体实例部署前取确定值。不得为通过某一测试临时换 profile；每次语义相关修改保留版本并重验。

最小 IDL 可沿用已有 EventEnvelope、SemanticGraph、ProposalBinding、FastStateSnapshot、CoreTransaction，并补齐现有对象的字段：EffectContract、QualificationCertificate、ConsolidationSlice、ThetaModule/ResponsibilityBinding、TrialResult 和 ModulationEnvelope。它们是数据消息，不是新增核心状态。

所有数值包括坐标边界、层数、矩阵 shape、单位和容差须显式。source/Concept/责任 ID 不允许由 worker 自行制造为有效身份。未知 schema、枚举、溢出和非有限数值返回错误；任何有界计数器达到上限时停止相应增长，不得回绕为零重新发放资格。

施工顺序为：先做 IDL 与权威事务骨架，再做纯 Φ/F、作用投影和责任解析，再接 G 的零作用候选与试验结算，再接准入和 C，最后接实际 J carrier 及整体验收。可用确定性模拟器验证事务与数学性质，但模拟器通过不能代替模型行为与真实外部辨识实验。

G04 的正向夹具可使用外部生成、预注册的慢转移核任务：当前观察相同，近期 x 已洗脱，历史校准导致未来结果条件分布不同，事实基线受相同已声明预算限制。只有在合法同预算事实替代仍不足、独立结果支持区别时才允许形成 χ/K；如果事实检索可完全解决，这个夹具应转为 G03，而不是人为排除成功基线。它验证有范围的机制能力，不证明所有真实经历都应成为人格。

四算子的非退化验收分别针对：F 的事件和时间响应，G 的合法必要修订，C 的实际责任转移与长期保持，J 的模型内作用与行为后果。不能用“从来不更新所以从不出错”的系统通过整体验收，也不能因为 F_out 正常恒等而人为添加心理学变量。

# 22 尚未由规格实验性解决的事项

第一，具体实例的 x 维数、编码参数、λ/γ、贡献与速率预算、probe 容差、统计样本量以及 θ ValidityContract 的有限有效期/续期参数须通过校准冻结。本文已规定选择与拒绝接口，但没有用任意数字假装证明最佳参数。

第二，基础模型、hook、rank 和 U/W 的具体参数尚待选定并实测。激活接口可以施工，实际承载目标行为的能力仍须 J01 至 J07 验证。某 carrier 失败可替换，但不得改变状态本体或用人格文本伪装成功。

第三，ReferenceContract 的外部目标、root 因果独立性和可辨识实验依实际任务提供。观察数据无法一般性识别所有因果作用或共同上游来源；没有合法干预/独立外生信息条件的 K 或 root independence 可以永久 non_identifiable。有限 R 容量也不保证保留所有未来相关区别。这些限制不是再增加几个状态对象就能消除的。

第四，严格 θ 失效模式在无合法新证据或额度时可能长期隔离。即时局部撤权与“所有 θ 更新均满足原凝固资格和正贡献约束”不能在该情形同时成立。本版已选择保持冻结边界，不把自动恢复的活性保证伪装成已经实现。

第五，第一版 C 不安装缺少 R 时间作用来源的全新 b/Λ 功能，也不支持 θ 自主自然演化、G 自改治理或跨分支自动合并。若后续需要这些能力，必须按上位扩展处理，不从 carrier 可替换性推出新权限。

因此本版的可冻结范围是算子职责、路由、数学与数据接口、参考控制算法、状态机、事务与验收合同。部署配置和经验效果在完成对应验证前仍标记未验收。规格允许实施失败被识别出来，而不是保证任何模型和参数都能产生合格的 Ada。
