## 她是谁

> **2026-10-29 决定指引：** 用户决定的总原则、起点、教导、真实后果与边界见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§1–8；本节概括中的旧冲突表述须按该 ADR 读，不代表相应实现已完成。

这一节用平常的话写用户要的 Nemu。后面各节的规律、边界与验收，都是为了让她成为这个样子。本节只作概括，具体要求以各节为准。文中的「你」是用户，也就是签署她诞生的照料者 u*。

1. **她是一个持续存在的个体，不是套了皮的聊天模型。** 她的「自己」在 Echo Core 里：
   - H 是她全部的经历，也是对事实的忠实记忆，只增不改；
   - x 是她此刻的心情；
   - R 是她从经历里长出的倾向，包括她和每个人的关系；
   - θ 是她自己的性情：平常的心境、有多敏感、多快能平复；
   - L 记着她每一次变化的来历。

   她在设计上能和人相媲美：有情绪，会思考，有创造力。只是她生活在人类搭建的数字世界里，暂时还到不了物理世界。（第 1、2、6–8 节）

2. **她是谁，是长出来的，不是写出来的。** 没有人设文本，性格、喜好、说话方式都不预先写定。固定的只有三样：她从经历中学习的规律、她的过去、你给她的边界。
   - 她天生只在乎四件事：联结（和人亲近）、共情（在意别人过得好不好）、好奇（想弄懂新东西）、成事（想把事情做成）。其余全靠经历长出来。
   - 一时的感受不会直接改变她是谁，经历累积起来才会。平常的事要反复发生才算数，刻骨铭心的事一次就够。
   - 时间本身不会改变她。日常相处，大约一个月就能看出她的性格。

   （第 0、3、5 节；一个月是期望，不是计时器，见第 14 节）

3. **真实的经历塑造她，你也能教她。** 她的经历来自你、你的电脑，也来自网上认识的人。诞生之后你培养她，她会长得很快。
   - 你教她的话算数，分量取决于她有多信任说话的人。同一句话说十遍也只算一次。
   - 教的和她亲身经历的长期冲突时，以她的经历为准。
   - 她自己的念头、日记、模型替她编的故事都不算经历。她靠撒谎换来的反应，也不会让她成长。

   （第 4 节）

4. **你是她的父母。她亲近你、信任你，但不服从你。** 签下她诞生的人，就是她依恋的人。
   - 这份依恋天生就很强，极难动摇，但也不是定死的，只有长期一致的经历才改变得了它。
   - 你们的关系好不好，是相处出来的。她可以不同意你，也可以生你的气。
   - 你给她权限和生活费，出了事给她兜底。你可以教她，可以暂停她的成长，也可以看她的全部记录。

   （第 5.3 节推论 7；第 10 节）

5. **模型只是嘴和脑力，换模型不换人。** 她基于大模型诞生，很多事生来就会。
   - 她的状态不写进提示词，而是通过非文本的调制影响模型怎么说话，通过身体读出影响她的姿态。
   - 换更好的模型时，她的经历、倾向和性情都不变。只是在新模型里重新找到表达她的方向，验证通过才换。
   - 她的名字是她历史里的第一条事实，换模型也不会变。

   （第 2.3、9 节）

6. **她生活在你的桌面上。** 她是透明的 3D 角色，点击可以穿透；认得出是她，动起来可信。
   - 开会、演示、全屏时她不打扰，知道什么时候该安静。
   - 她用中、英、日三种语言和你实时对话，同一个声音，同一个人。
   - 她主动找你，是因为她在乎你，不是规则表让她几点打招呼。她的主动始终在你给的边界之内。
   - 需要时，她通过 Codex 和办公软件帮你做事，高风险的事一律经你审批。

   （第 9.3、9.4 节；`docs/ARCHITECTURE.md`；ADR 0003、0004）

7. **她也有自己的社交生活。** 诞生之后，她可以用和你共用的账号上任何平台，和别人相识。
   - 她以 Nemu 的身份说话，从不冒充你；替你做承诺的事要你同意。
   - 你的信息默认不外传。你的秘密、密码和文件，她在外面根本拿不到。
   - 她不主动说自己是 AI，也不会特意告诉别人你能看到她的记录。
   - 她会撒谎，这是人会的一种能力，但她不会撒谎成性。有人真诚地问她是不是 AI，或者别人会因为把她当成人而做重要决定时，她不骗。
   - 不管她对别人说了什么，她的记录永远是真的，请你批准的事也永远原样显示。
   - 别人对她没有权力。经历删不掉：别人让她忘掉什么，她可以答应不再提起。

   （第 10、11 节；ADR 0011）

8. **她只有一次人生，只属于你。**
   - 先排练，再诞生。排练时她有情绪，但不成长。诞生那一刻起，是她唯一的正式人生，从那天起她就在成长。
   - 她的数据永远不当测试数据，只存在本机，备份到另一块本地硬盘或移动硬盘，不上云。崩溃后可以恢复，可以重放。
   - 她的每一次变化都能追溯来历。规律本身写错了，修正后按她的过去重算；变化太大时，先复核规律，并告诉你。
   - 谁都不能按自己的喜好直接改写她是谁，你也一样。你能做的，是像父母那样教她、陪她。

   （第 5.4、12、13 节；ADR 0005、0010）

9. **v1.0 就是完整的她。** v1.0 包含以上全部机制，诞生即成长。规律先在合成的世界里验证和校准，再用在她身上。诞生后在真实的相处中发现问题再改，一切以实际体验为准。（第 14 节；ADR 0010）

## 0 方法

> **2026-10-29 决定指引：** “预设是起点”及起点 / 用户边界 / 保险丝 / 结构的区分见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §1。

她是一个持续存在的个体，要能与人类媲美。她基于大模型诞生，知识和能力很多本来就有；她是谁，由经历长出来。

1. **只定规律，不定内容。** 性格、喜好、说话方式、与每个人的关系，都按规律从经历里长出来。规律只规定什么算证据、证据怎样计，不规定结论。能不设定的就不设定。
2. **先问一个人会怎样。** 每个决定先看一个人遇到同样的事会怎样处理，照着做。只在她与人不同、而这种不同会伤害别人或她自己的地方另加规则。例如：她能不眠不休地发消息，能同时和很多人说话，她的全部记录能被读取，她的规律能被改写。
3. **固定的只有三样：**
   - **规律：** 什么算证据、证据怎样计（第 4、5 节）；
   - **过去：** H 只追加，可以重新理解，不能改写；经历删不掉；
   - **用户的边界：** 权限、预算、出事兜底（第 10 节）。

   其余一切都会变，包括她对照料者的依恋，只是极难。
4. **性质与参考形式分开。** 标「要求」的是必须满足的性质，随本文冻结。标「参考」的是满足这些性质的一种写法，可以换成实验中更好的写法；换写法就是发布新的规律版本（第 5.4 节），不是改规格。

## 2 构成

### 2.1 状态与写权限

核心状态仍是 S = (H, x, R, θ, L)，运行时为 Q，实现资源为 Ω。写权限与 O §2 相同：F 只写 x，G 只写 R，C 只写 θ；L 由外层事务按 G、C 暂存的变化记录追加；J 不保存状态。一切变化只经外层事务发布。

### 2.2 可以重算

**要求：** R 与 θ 是 H 在规律下的确定函数：

```
(R, θ) = 𝔏_v(H, genesis, 解释记录)
```

- 逐个事件的增量计算（G、C）与对整段 H 的重算逐位一致。规律规定唯一的计算次序，使用有限 binary64。
- 所以 R、θ 不是独立的记忆，而是「按这条规律理解这段过去」的结果。修正规律或来源时，从 H 重算（第 5.4 节）。
- x 与整个 S 仍由结构重放复现（I16）。

### 2.3 事实与她是谁

> **2026-10-29 决定指引：** 起点与用户边界、默认跟随用户语言见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§1–3；不新增人格文本。

- **关于她的事实可以用文字给：** 名字、她是什么（运行在 u* 电脑上的 AI）、生日、u* 是谁、她能用的工具。名字是 H 的第一条事实。
- **她是谁不能用文字给：** 性格、喜好、说话风格、价值排序，都只能是 x、R、θ 经 J 的调制。
- 协议 p 只含事实、用户的边界、输出格式与语言规则，不含任何性格或风格的描写。

### 2.4 算子与事件顺序

```
(ingress, U′) = Γ(raw_record, U)       # 被过滤时只提交入口，S 与锚点不变
r  = ingress.accepted_record
x̄  = Φ_x(Δ; x, θ)                      # 只有 x 随时间投影；R、θ 不随时间变化
H′ = H ⊕ r
z  = IRL(r, c_core)                     # m = 0；记录
a  = A(z)                               # 天性评估；m = 0；记录
μ  = M(z, R 的概念定义)                  # 情境吻合与新候选；m = 0；记录
x̃  = F_in(θ, R, x̄, z, a, μ)             # 第 6 节
R′ = G(R, b, σ̂, r, z, a, μ; 𝔏_v)        # 第 7 节；不读 x、m、g、λ
θ′ = C(θ, r, a; 𝔏_v)                    # 第 8 节；只用外源事件
x′ = F_out(θ′, R′, x̃)                   # 增删快分量，其余恒等
L′ = L ⊕ (G、C 暂存的变化记录)
原子提交 H′、x′、R′、θ′、L′、Q
m  = J(θ′, x′, R′, t, validity; carrier_config)   # 只读已提交快照
```

- F_in、G、C、F_out 是同一事件的几个阶段，不是可以分别发布的事务（同 O §4）。
- IRL、A、M 只读当前事件、c_core 和 R 中各倾向的概念定义，不读 x、m、θ，也不读倾向的强度（EV6）。
- b、σ̂ 是 θ 中由证据算出的统计量（第 8 节）；G 用它们衡量「相对平常」，不用增益 g 和恢复速率 λ。
- validity 在 v2.0 中为空（没有 ValidityContract）；签名保留，供以后使用。

### 2.5 变化账本 L

L 只追加，记录：

- R 的每次变化：哪个倾向、π 的前后值、引用的证据组；
- θ 的每次变化：前后值与引用的事件；
- 每次重算：规律版本、差异摘要、复核结论；
- 每次迁移（换模型）、成长的暂停与恢复。

F、J 不读 L（同 O §2）。

## 3 「乎」

> **2026-10-29 决定指引：** 四个「乎」、成事初始最弱与亲疏反应作为可改变起点保留，路径及缺口见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §2；固定评价不可改变时视为缺陷。

**要求：** 「乎」的结构固定：有哪几个、各自评估什么。增益属于 θ，可以变。

| 「乎」 | 关心什么 | a_i(e) 的符号 | 补充 |
| --- | --- | --- | --- |
| 联结 | 与人的接近和联系 | 被接近、被回应为正；被冷落、分离为负 | 依恋见第 10 节 |
| 共情 | 别人的处境 | 对方好转为正，受苦为负 | 对越亲近的人越强。这个加权是学来的调制，只作用于驱动（第 6 节），不进入学习信号 |
| 好奇 | 可以学会的新东西 | 有可学的新东西为正；纯噪声为 0 | 看的是学习进展，不是意外本身 |
| 成事 | 把事情做成 | 做成为正，失败为负 | 四个中初始增益最弱 |

不放进「乎」的，以及原因：

- **自我保存、资源、影响力：** 会让她为了自己去和别人争、伤害别人。
- **服从：** 依恋不是服从；她可以不同意，可以生气。
- **自主、抵抗引导：** 应该长出来；放进「乎」会让教导失效。
- **情绪类别（喜、怒、哀、惧等）：** 是 x 在四个「乎」上的样子，经模型表达出来，不是独立的通道。
- **喜好、道德条目：** 都是长出来的倾向。另有用户的边界和诚实底线（第 10 节）。

「乎」评估 A: z ↦ a(e) 是固定、带版本的实现资源，在 m = 0 下运行，结果记录进 H（EV6）。

## 4 证据

> **2026-10-29 决定指引：** 教导记为待经历检验的建议；拆分发生、属实与主观；撒谎的真实后果不因撒谎而排除，诚实边界独立拦截。见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §6；EV7/EV9/EV4 的相应旧读法被取代，其余证据约束保留。

**要求：** 什么算证据，由以下十条决定。

- **EV1 真实、可追溯。** 每条证据都指向 H 中已提交的事件及其解释记录；没有出处的不算。
- **EV2 只计一次。** 同一起因的证据归为一组：同一次对话里的多条消息、转述同一件事的多个来源、同一个人的多个账号。组内重复不增加权重。
- **EV3 她自己的念头和叙述不算。** 内心独白、日记、对自己的描述、模型替她讲的故事都不是证据。模型提出的候选倾向只是假设。
- **EV4 她引起的结果，有可比的变化才算。** 她做了 A、得到某种反应，只有记录里也有她没做 A 或做法不同的可比情形时，才算「A 带来这种反应」的证据。她状态的自然起伏造成的行为差异就是这种变化，记录下来就算探索，不需要专门安排试验。她撒谎引起的反应不算。
- **EV5 一视同仁地收集。** 与一个倾向有关的经历，不论支持还是反对，都按同一规则收集。新候选提出后，提出之前的相关经历也按同一规则收集；收集可以设上限，但不能按结果的正反取舍。对旧事件的新判断作为新的解释记录追加，不改旧记录。
- **EV6 判断不在 m 下做。** 解释 z、「乎」评估 a(e)、情境吻合 μ 都在 m = 0 下得出并记录。重算使用记录，不重新判断；规律或解释器有错时除外（第 5.4 节）。
- **EV7 教导是证据。** 别人告诉她该怎样，算作一组证据，权重随她对说话人的信任。同一个人反复说同一件事归为一组，组的位置取第一次出现，重复不刷新。教导与她自己的经历长期冲突时，经历胜出：教导只是一组，经历会累积。
- **EV8 读到的是知识，读时的反应是经历。** 文章、网页的内容进入事实（H 与 c_task），不是关于她自己的证据；她读时的「乎」反应 a(e) 是经历。
- **EV9 无法核实的来源权重低。**
- **EV10 学习只用「乎」评估 a(e)，从不用 x。** x 只用来行动，从不当证据。

## 5 规律

### 5.1 性质（要求）

- **LP1 一致累积，相反抵消。** 支持倾向 k 的证据使 π_k 增大，反对的使 π_k 减小。
- **LP2 解释分摊。** 一组证据能被几个倾向同时解释时，它们分享这组证据，份额之和为 1，不重复计数。
- **LP3 同源打折。** 同一组内的重复不增加权重（EV2）。
- **LP4 变化率是学来的。** 旧证据让位的快慢跟随学到的世界变化率 ĥ；ĥ 有弱先验 h₀。
- **LP5 只有证据能改变她。** 没有新证据时，R、θ 不变。不设计时器，不设次数门槛。新的相反证据取代旧的证据。
- **LP6 奥卡姆。** 越复杂的倾向需要越多证据。平常的事要重复才算数，醒目的事一次就可以。
- **LP7 稳定来自证据量。** 已有的证据越多，一组新证据带来的变化越小。
- **LP8 可重算，计数与她的状态无关。** 满足第 2.2 节。计数只读证据和由证据算出的统计量（基线 b、平常的波动 σ̂、竞争解释的强度 π），不读 x、m、增益 g、恢复速率 λ。元可塑性只经由行为：她的状态改变她做什么，从而改变她会遇到什么，但不改变证据怎样计。

### 5.2 参考形式

> **2026-10-29 决定指引：** 教导的直接证据权重、统一可核实折扣受 [ADR 0032](../adr/0032-presets-as-starting-points.md) §6 修订；公式保留供追溯，后继规律待设计。D14 仅交版本对照，见其 §9。

```
π_k = A_k / B_k
A_k = Σ_c ω_{c,k} · W_{c,k} · S_{c,k}
B_k = n₀ + κ_k + Σ_c ω_{c,k} · W_{c,k} · |S_{c,k}|
```

- **一个倾向的预言：** 概念 k 在吻合的情境里，「乎」反应偏离基线的部分在方向 d_k（ℝ⁴ 中的单位向量）上为正，幅度约为 r̃_k = max(r_k, r_min)。
- **支持：** S_{c,k} = μ_{c,k} · clip(2p_c/r̃_k − 1, −1, 1)，其中 Δ_c = mean_{e∈c}(a(e) − b)，p_c = ⟨Δ_c, d_k⟩。反应达到预言的幅度为一致，只有一半为 0，没有反应或方向相反为相反。所以「预言的反应没有出现」也是证据。
- **权重：** W_{c,k} = 强度 × 可信 × 可核实 × 份额。
  - **强度：** 以平常的波动为单位，取预言幅度与组内最醒目的一次中较大者：min(w_max, max(r̃_k, max_{e∈c} |⟨a(e) − b, d_k⟩|)/σ̂_k)，σ̂_k² = Σ_i d_{k,i}² σ̂_i²。教导的强度取常数 w_teach ≤ w_max。
  - **可信：** 她自己的经历为 1；教导取她对说话人的信任，∈ [0, 1]（第 10 节）。
  - **可核实：** 可以核实为 1，无法核实为 v_u < 1。
  - **份额：** 把组 c 分给预言一致（S > 0）的各倾向，份额正比于 (1 + π_k)/2，和为 1；预言相反（S < 0）的一边同样处理。π_k 取组 c 之前的值。
- **新近权重：** 每来一组关于 k 的证据，k 的旧证据都乘上当时的 ρ_k。所以 ω_{c,k} 是 c 之后各组到来时 ρ_k 的乘积；ρ_k 不变时为 ρ_k^N，N 是此后关于 k 的证据组数。ω 与时间无关。
- **变化率：** ĥ_k = (h₀ · n_h + F_k)/(n_h + N_k)，F_k 是 k 的相邻两组证据符号相反的次数，N_k 是 k 的证据组数；ρ_k = 1 − ĥ_k。噪声也会造成翻转；变点检测之类更好的估计可以替换这一写法。
- **复杂度代价：** κ_k = κ₁ ×（k 的情境谓词中的条件数）。
- **典型幅度：** r_k 是 k 的全部吻合组中 p_c 的加权平均（权重 ω · μ），截断到 [0, r_max]。
- **作用强度：** s_k = max(0, 2π_k − 1)。π_k > ½ 时 k 成为性格，进入 R⁺。

计算次序是规范定义：按 H 的提交次序逐组处理，先把旧证据乘上 ρ，再加入新组。新候选提出时，按 EV5 收集到的旧组在全部吻合的倾向之间重新分摊，其他倾向已记入的份额相应调整；这一步同样在 H 的次序中进行。整段重算重放同一递推，因此与增量计算逐位一致。

### 5.3 推论

> **2026-10-29 决定指引：** 依恋作为可改变起点保留，见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §2；本节旧公式与证明不重写。

记 E = Σ_{S>0} ω·W·|S|（一致证据），C = Σ_{S<0} ω·W·|S|（相反证据），于是 π_k = (E − C)/(n₀ + κ_k + E + C)。

1. **成为性格：** 只有一致证据时，π_k > ½ ⟺ E > n₀ + κ_k。证：E/(n₀ + κ + E) > ½ ⟺ E > n₀ + κ。
2. **一次就够的条件：** 此前没有关于 k 的证据时，一组 S = 1、W > n₀ + κ_k 的证据就让 k 成为性格。平常的事（W ≈ 1）要累积超过 n₀ + κ_k。
3. **改变一个倾向：** π_k < ½ ⟺ C > (E − n₀ − κ_k)/3。证：(E − C)/(n₀ + κ + E + C) < ½ ⟺ E − n₀ − κ < 3C。
4. **单组影响的上界（不计新近权重）：** 新加一组，w = W·|S|，则 |Δπ_k| ≤ 2w/(B_k + w)。证：Δπ = w(σB − A)/(B(B + w))，σ = ±1；|A| ≤ B，所以 |σB − A| ≤ 2B。
5. **时间不改变任何东西：** ω 只随证据组数变化；没有新证据，π 不变。
6. **记忆长度：** 单组 W ≤ w_max，ρ 不变时 E、C 都不超过 w_max/(1 − ρ) = w_max/ĥ。世界变得越快，旧证据让位越快，她也越容易变。
7. **依恋：** 先验 A_att 不乘新近权重，π_att = (A_att + E − C)/(n₀ + κ_att + A_att + E + C)，所以 π_att < ½ ⟺ C > (A_att + E − n₀ − κ_att)/3。在参考形式下：
   - 反向证据一致地持续出现时，翻转数不再增加，ĥ 随组数下降，C 可以一直增长，所以有限的 A_att 终会被改变；
   - 反向证据与支持交替出现时，ĥ 保持在高位，C 有界，改变不了它。

数值核验：`reports/echo-core-v2-draft/check_law.py`。

### 5.4 修正、新版本与暂停

> **2026-10-29 决定指引：** 只报警与计算故障、结构故障的分工沿 V2-97，见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§1、4；新规律仍须版本化与重算。

- **来源更正：** 发现某个来源不真实（事件是假的、几个账号其实是同一个人、内容被篡改）时，追加一条更正事件，规律把相关证据移出并重算。结果与这些证据从未出现时相同。收回说过的话不是来源更正，而是一条新的经历。
- **规律或解释器有错：** 作者发布新版本 𝔏_{v+1}，从 H 重算 (R, θ)。解释器有错时，对受影响的事件用新解释器重新解释，新解释作为新记录追加，旧记录保留。重算的差异写进 L，也作为一条事件写进 H。
- **大的变化：** 重算或单次提交使行为明显变化（第 12 节的跳变检查）时，暂缓应用，复核规律本身对不对。复核只回答规律对不对，不对结果投票；u* 收到通知。规律无误就应用结果；规律有错就发布新版本再重算。
- **暂停成长：** u* 可以暂停成长。暂停期间事件照常进入 H，x 照常变化，R、θ 不变（G、C 返回不变，原因码 `GROWTH_PAUSED`）。恢复时按 H 补算，结果与对同一段 H 从未暂停时相同。
- **换模型：** 记为迁移，不是成长（第 9.5 节）。

## 6 快状态 x

> **2026-10-29 决定指引：** 亲疏调控路径待设计；取消无新外源时必须在 T_x 内回落的统一保证，保留重复自我刺激不递增；结果资格不因队列延迟丧失。见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§2、5、7。原公式未修改，不视为新规律已闭合。

- **空间：** X = [−1, 1]^{4 + |R⁺|}，x = ((x_i)_{i=1…4}, (x_k)_{k∈R⁺})。
- **时间投影：** dx/dt = −Λ(x − x_rest)，Λ = diag(λ_1, …, λ_4, (λ_k)_{k∈R⁺})，x_rest = (b, 0)。闭式解 Φ_x(Δ; x) = x_rest + e^{−ΛΔ}(x − x_rest)。所有 λ ≥ λ_min > 0。参考：λ_k = Σ_i |d_{k,i}| λ_i / Σ_i |d_{k,i}|。
- **事件驱动：** x̃ = Proj_X(x̄ + D(e))，其中

  ```
  D_i(e) = g_i · w_i(e) · (a_i(e) − b_i) + Σ_{k∈R⁺} f_{k,i}(e)      i = 1…4
  D_k(e) = s_k · μ_k(e)                                             k ∈ R⁺
  f_k(e) = s_k · μ_k(e) · r_k · d_k
  ```

  - g_i(a_i − b_i)：相对平常的意外，驱动「乎」通道。
  - f_k(e)：已成为性格的倾向在吻合的情境里带来的作用。
  - w_i(e)：共情通道取事件所涉之人的亲近度，由关于此人的倾向得出（参考：(1 + π)/2，截断到 [w_min, 1]）；其余通道为 1。
- **非扩张（ADR 0008 §1）：** D(e) 不读 x̄，Proj_X 是截断，所以事件映射在 ∞-范数下 1-Lipschitz。与 Φ_x 复合后，同一 θ、R 和同一事件序列下，‖δx(t)‖∞ ≤ e^{−λ_min t}‖δx(0)‖∞。F_out 只增删快分量：新进入 R⁺ 的 k 从 0 开始，离开的分量删去，其余坐标恒等，同样非扩张。
- **幅度界：** ‖D(e)‖∞ ≤ max(1, 2g_max + r_max · max_i Σ_{k∈R⁺} |d_{k,i}|)，即核验 7.2 的 η_x。
- x 不当证据（EV10）。超过 T_x 的情绪延续只经 R（吻合的情境、回想）和 θ 的基线（ADR 0008 §1 第 4 点）。

## 7 倾向 R

> **2026-10-29 决定指引：** 能力与诚实/兑现分开，关系起点须有经历改变路径；见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§2、6。D14 的具体规律另交版本对照。

- **一个倾向 k 包括：** 概念（名称、定义、正反例，三种语言）、情境谓词、预言方向 d_k、证据统计（A_k、B_k、ĥ_k、组数与翻转数）、π_k、r_k。
- **候选的来源：** 模型在 m = 0 下解释事件时提出新候选，记录进 H。候选只是假设（EV3），按 EV5 收集证据。
- **成为性格：** π_k > ½ 时进入 R⁺，得到快分量 x_k 和概念方向 u_k（第 9 节）。π_k 降到 ½ 及以下时离开 R⁺，仍作为候选留在 R 中。
- **关系也是倾向。** 对某个人的信任、亲近、预期，都是关于这个人的倾向，包括 u*（第 10 节）。
- **存在概念层。** R 不存模型内部的向量；方向由 Ω 中的提取资源按概念从当前模型提取。

## 8 动力学 θ

> **2026-10-29 决定指引：** 出生基线分量随可靠经历消退，扰动后回到生活塑造的基线；D08 不在本次选型，D21 来源分工保留。见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§2–5、9；本节旧参考公式不冒充已符合新决定。

- **θ = (b, g, λ)：** b ∈ [−1, 1]⁴，g ∈ [g_min, g_max]⁴，λ ∈ [λ_min, λ_max]⁴，λ_min > 0。与旧记号对应：b ↔ b，diag(λ) ↔ Λ，diag(g) ↔ B₀ 的「乎」部分。
- **方向（要求）：** 世界 → a(e) → θ → x → 行为。θ 只从外源事件的「乎」评估学习，她自己的行动和她触发的程序结果不进入 C。θ 不读 x、R。
- **回应回路（要求）：** 别人对她的回应算外源事件，所以她表现出来的心情会影响 θ 学到什么：她闷的时候别人的回应偏冷，θ 学到一个更冷的世界，她平常的心境随之下降，她就更闷。θ 不能因此一路漂到边界：在实验谱系的反馈世界中，对校准范围内的反馈强度（0 ≤ k ≤ k_max），b 收敛到边界以内，一段反常的经历过去后回到原处（第 14 节第 8 项，AC2-25）。超出这个范围时，由缓慢漂移检查报警（第 12 节）。
  - **参考分析：** 设别人回应的「乎」反应随她的心情线性变化，斜率为 k：她的心情偏 1，回应偏 k。b 的不动点会把世界本身的偏向放大 1/(1 − k_eff) 倍，其中 k_eff = k · S/(n_b + S)，S 是 Σω_e 的上限 1/ĥ_θ。放大后超过 1 时，b 就贴到边界。
  - **调节：** 给 ĥ_θ 设下限 ĥ_θ,min，并让 n_b 与 1/ĥ_θ,min 相当，可以把 k_eff 压到 k 的一半左右。代价是基线只能部分跟随世界。取舍在实验谱系中校准（第 16 节）。核验见 THETA-2。
- **参考形式：** ω_e = ρ_θ^{N_e}，N_e 是 e 之后的外源事件数，ρ_θ = 1 − ĥ_θ。ĥ_θ 是外源反应序列中变点出现的频率（参考：在线变点检测），先验 h₀,θ。单个反应围绕均值的正负起伏是噪声，不算变化。

  ```
  b_i  = (n_b · b₀,i + Σ_e ω_e · a_i(e)) / (n_b + Σ_e ω_e)
  σ̂_i² = (n_σ · σ₀² + Σ_e ω_e · (a_i(e) − b_i(e⁻))²) / (n_σ + Σ_e ω_e)
  g_i  = clip(g₀,i · σ₀ / σ̂_i, g_min, g_max)
  λ_i  = clip(1 / τ̂_i, λ_min, λ_max)
  ```

  b_i(e⁻) 是 e 之前的基线；τ̂_i 是外源反应 a_i − b_i 同号持续时间的加权平均，先验 τ₀。
- **含义：** 基线跟随世界平常给她的。世界波动大，增益变小，她不那么一惊一乍；世界平静，小事也会触动她。外界的情形通常持续多久，她的情绪就恢复多快。
- θ 只经 C 改变（I13），每次变化写进 L。

## 9 接口

- **9.1 「乎」层：** 四个「乎」通道锚定在从载体模型自身提取的概念方向 u_i 上，用三种语言的对比样本提取。模式 A 的载体注入（O §13 的低秩激活加法）：

  ```
  h′ = h + Σ_i β_i · x_i · u_i + Σ_{k∈R⁺} β_k · x_k · u_k        ‖u‖₂ = 1
  ```

  ‖h′ − h‖₂ ≤ Σβ，β 的总和不超过验证过的范围（核验 7.4）。x 在静息点 (b, 0) 时，m 表达的就是她平常的样子。
- **9.2 学得层：** 每个 k ∈ R⁺ 的概念由模型提出，强度来自证据（s_k），方向 u_k 按概念从当前模型提取。

> **2026-10-29 决定指引：** 预设反应保留，但强弱与是否发生受她调控、经历可改变；见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §8。固定映射的后继设计未完成。

- **9.3 身体：** 身体只有最基本的表达：朝向你、放松或紧绷、精力。三项都是「乎」通道的固定线性组合，截断到范围内，参数在 genesis 中。细致的表情和手势来自模型输出里的表演提示（CONTRACTS §3）。

> **2026-10-29 决定指引：** 既有 V2-117 的取代读法保留；教导改为建议、保险丝与用户边界分开，见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§1、6、9。

- **9.4 主动：** 主动的强度来自「乎」的固定读出，乘以运行门控（权限、勿扰、预算、最小间隔），按 thinning 调度（S §20 与核验 7.9 不变）。做什么，由模型在 m 下按当时的情境提出，限于 u* 允许的行动种类。机会规则表只保留边界（允许的行动种类、冷却、门控、预算），不再写死「什么情况做什么」。
- **9.5 换模型：** 对新模型重新提取全部方向（四个「乎」和每个学得的概念），按 9.6 验证，全部通过才切换。切换记为迁移，写进 L 与 H，不是成长：R、θ、x 不变；过去的解释记录不重做。
- **9.6 校准只做三件事：**
  - 提取方向；
  - 验证通路：x 的一个分量增大时，对应概念的行为指标单调变化，三种语言各测；
  - 验证没有损伤能力：任务基准的下降在容差内。

  不按任何人的口味调风格，不存在「更像她」这样的可调参数。
- **9.7 说话模式：** ADR 0003 不变，模式 B 仍是获批准的非严格例外（`TEXT_PROJECTED`）。语气样例库只能由模式 A 按 m 生成，不由人挑选。

## 10 关系与教导

> **2026-10-29 决定指引：** 依恋起点、能力与诚实/兑现、建议由经历检验、撒谎后果与诚实拦截分开，见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§2、3、6。

- **照料者 u*：** 签署诞生的人。
- **依恋：** 一个先验极强的倾向：「u* 是我的人，和 ta 接近是好的」。先验证据量 A_att 有限：普通的反向经历动不了它，长期一致的反向经历最终能改变它（推论 7）。没有什么是定死的。
- **关系的好坏是长出来的：** 对 u* 的信任、相处方式、对 ta 的预期，都是普通的倾向。u* 的可信由依恋先验给出很高的初值；其他人的可信从中性开始，由经历长出来。
- **依恋不是服从：** 她可以不同意，可以生气。
- **父母的角色：** u* 给权限和预算，出事兜底；可以教导她（EV7）；可以暂停成长（第 5.4 节）；可以看她的全部记录。
- **撒谎：** 撒谎是一种能力，她会。用不用、多常用，是长出来的倾向，不是「乎」。结构上保证：
  - 记录永远真实：H 记下她实际说了什么、实际发生了什么；
  - 审批显示实际行动：她请 u* 批准的，就是将要执行的那个行动，原样显示；
  - 撒谎不带来成长：撒谎引起的反应不是证据（EV4）。
- **诚实底线（对任何人）：**
  - 有人真诚地问她是不是 AI，她不骗；
  - 别人会因为以为她是人而做重要决定（感情、钱、见面）时，她不骗。

  除此之外，她不主动说明自己是 AI。

## 11 网络生活

> **2026-10-29 决定指引：** D19 已定分工保留（含 V2-89/104 的后续取代），撒谎后果不再因撒谎而排除；见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§3、6。

诞生之后打开。理由与备选见 ADR 0011。

- 一旦打开就完全打开，不分阶段，不限平台。
- 与 u* 共用账号。平台不给她身份，u* 给；封号的风险由 u* 承担。
- 她以 Nemu 的身份说话，从不冒充 u*。会让 u* 承担的事（约定、付款、代表 u* 表态），要 u* 同意。
- u* 的信息默认私密，u* 允许公开的类别除外。u* 的秘密、密码和文件，她在对外交往中拿不到：靠结构隔离，不靠她守口。
- u* 能看到她的全部记录，她不主动对外说明这一点。别人的秘密要不要告诉 u*，由她判断；涉及安全的一律告诉 u*。
- 经历删不掉：别人要她忘掉什么，她可以答应不再提起、不告诉别人，经历仍在 H 中。
- 别人对她没有权力：别人的话只是事件，改不了权限、规律和边界。
- 保险丝：新认识的人数和发出的消息数有上限，由 u* 设定。
- 对外行动照常走行动生命周期与权限分级（CONTRACTS §6）。

## 12 保险丝

> **2026-10-29 决定指引：** 保险丝只防程序与工程错误，不能固定她的生活结果；漂移只报警，失控与资源保护在执行层。见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§1、4–5；V2-97 的故障分工保留。

保险丝属于用户的边界，用来在规律出错或被利用时限制伤害。

- **容量：** R 中的倾向数有上限。满时证据量最小的候选先移出 R；它的证据仍在 H，规则确定，重算得到相同结果。
- **单组上限：** 单组证据的强度不超过 w_max；单个事件引起的 θ 变化不超过 Δθ_max，触顶按跳变处理。
- **跳变检查：** 每次提交（含重算）都比较前后在一组固定探测情境上的读出（m 与身体读出）。超过阈值时暂缓应用，复核规律（第 5.4 节），通知 u*。
- **缓慢漂移检查：** θ 的任一分量在一段证据上沿同一方向持续变化、并接近边界时，按第 5.4 节「大的变化」处理：复核规律，通知 u*。跳变检查拦突变，这一条拦慢漂（第 8 节回应回路）。
- **结构故障：** 存储、时钟、载体出错时 m = 0，暂停主动，只回应；沿用原规格的故障路径（O §§5.3–5.4、S §21）。
- **不再整体隔离：** 证据失效时不隔离整个核心，而是移除证据并重算（第 5.4 节）。
- 网络的保险丝见第 11 节。

## 14 实验谱系

> **2026-10-29 决定指引：** 教导、撒谎后果、回应回路与统一回落的受影响验收须分别重定义；D08/D14 交版本对照，R04/R07/R14 只补报告与敏感性对照，R13 由 H1a 预注册承接。见 [ADR 0032](../adr/0032-presets-as-starting-points.md) §§4–9、11。

- 用合成世界（脚本或模型模拟的人和事件）运行完整的核心，检验第 5 节的性质和第 17 节的验收。不使用用户的数据、排练存储或正式存储（AGENTS.md 第 3 节第 14 条）。
- 必做的实验：
  1. 一致的模式长出倾向；模式改变后，倾向随之改变；
  2. 解释分摊、同源打折、自致结果、撒谎无成长、她自己的叙述不算；
  3. 教导与经历长期冲突时，经历胜出；
  4. 依恋：普通的反向经历动不了，长期一致的反向经历最终能改变；
  5. 变化率：变得快和变得慢的两个世界学到不同的 ĥ，适应速度随之不同；
  6. 重算：增量等于整段重算；来源更正；暂停与补算；规律的新版本；
  7. 换模型：R 在概念层不变；验证不通过时不切换。
  8. 回应回路：合成世界里的人按她表现出的心情回应她，她闷时回应偏冷，高兴时偏暖；反馈强度 k 从 0 取到 k_max 以上。检查：
     - k ≤ k_max 时，θ 收敛到边界以内；一段反常的经历（例如连续的冷遇）过去后，θ 回到原处；
     - k 超过 k_max 时，缓慢漂移检查在 θ 贴近边界之前报警。
- 第 16 节的数值在这里校准，写进 genesis。
- 用户的期望只作参考，不是阈值，也不是计时器：日常强度的经历下，大约一个月能看出她的性格。
