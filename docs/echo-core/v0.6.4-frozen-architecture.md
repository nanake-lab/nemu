# Echo Core 可塑状态转移核心：架构与形式化规格 v0.6.4 修订版

# 摘要

本文定义一个由可追溯经历持续塑形的状态转移核心。系统保留快速状态、可塑痕迹与长期动力学的多时间尺度结构，将事实取证、规范内部表示与自我调制分开，并通过事件生命周期、证据贡献账本、候选更新审查和行为探针限制长期变化。基础语言模型提供语言理解与行动生成能力；内部表示层将自然语言、工具结果和系统事件转换为来源锚定、认识论有型且允许不确定的有限语义表示，核心状态再通过显式调制接口影响模型，模型基础权重在运行中保持冻结。

本版在 v0.6.3 的快速状态、内部表示层、事件事务、凝固、身份与重放合同上，进一步补充可塑痕迹 R 的本体定义与有效自由度判据。R 不预置“信任、亲近、价向”等心理坐标，而以未来核心状态转移的历史依赖因果可区分性为功能依据；当现有 R 错误合并后来被证明因果不等价的历史时，只允许进行最小必要细分。保留下来的历史区别记为 χ，其对未来核心状态转移的条件化因果耦合记为 K。χ 本身不构成有效自由度，只有存在非冗余 K 时才形成有效可塑自由度。K 在尚未凝固时属于 R 的 representation，其通用学习规则属于 G；稳定作用仅能通过 C 进入 θ。模型推断、自述或重复来源不得自证新的自由度。

关键词：可塑状态；快速因果充分状态；可塑痕迹；因果区别；条件化耦合；内部表示层；经历溯源；证据凝固；行为连续性；事件驱动；多时间尺度。

# 1 设计目标与规格地位

1.1 核心目标是使经历能够持续改变未来的状态转移和行为倾向，同时抑制单一来源、重复记录或偶然事件对长期结构的过度影响。事实记忆提供可核查信息，自我调制承载由经历形成的内部影响，二者职责不同。

1.2 本文是架构约束与机制实现合同。结构性条款必须遵守；算法、阈值、载体和行为度量须在实现配置中给出。未绑定配置的系统只能称为验证原型，不得宣称已完成本规格的全部验收。

1.3 系统不预置具体个人经历、关系结论或指定人格。初始规则与基础模型必然包含先验偏向，必须记录其来源及影响范围，不宣称初始化完全中立。

1.4 本版保留四个核心算子 F、G、C、J。F_in、F_out 是 F 的阶段；候选选择、资格检查及 C_propose 是 C 的内部步骤，不增加核心算子数量。内部表示层 E/IRL 以及其内部的 A_x、A_R、概念解析、校验与规范化步骤均属于共享机制基础设施，不构成第五个成长算子。调度、持久化事务、权限和版本兼容属于运行时责任。固定轮询可用于工程调度，自主行动不得退化为不依赖状态的固定倒计时。

*F ≡ (F_in,F_out)*

F 负责完整事件处理周期中的快速状态转移，两个阶段共享同一事件上下文。Φ 是 F 所属的时间推进子过程；C 是唯一对外凝固接口，其内部接受候选不等于独立持久化提交。

# 2 状态空间与运行时状态

*Sₖ = (Hₖ,xₖ,Rₖ,θₖ,Lₖ); Qₖ = (Pₖ,Aₖ,Zₖ,vₖ,ℓₖ,τ_anchor,ₖ,Uₖ)*

## 2.1 快速状态 x 的本体定义与边界

快速状态 x 定义为：在不重新读取无界历史 H 前缀、仅给定实现向快速转移显式开放的非 x 输入（如当前有效事件/规范表示、受预算限制的事实投影 c、R、θ 及必要运行条件）时，对指定快速时间尺度内未来核心演化及行为相关输出具有近似因果充分性、容量受限的近期历史压缩状态。其作用是把仍会影响“下一刻”的近期历史效应压缩到当前时刻，而不是保存事实、痕迹或人格。

xₜ = FastCausalState(recent history \| declared non-x inputs, future conditions; Tₓ, εₓ)

其中 Tₓ 为实现配置规定的快速预测/作用时间范围，εₓ 为允许的近似误差。因果充分性是可检验的功能合同，而不是声称存在唯一的心理学坐标系。验收时固定当前事件/规范表示、事实投影 c、R、θ、协议、必要运行条件、模型版本和后续输入，不允许重新读取未声明的 H 细节；若两段不同近期经历仅通过 x 保留不同短时余量，则该差异应能够解释或预测指定 Tₓ 内的可观察状态转移、行动时机或行为差异。若某个候选分量删除后不影响这些结果，则它没有资格作为必要的 x 自由度。

x 不承担事实来源，事实与原文由 H 保存；x 不承担跨较长时间的可塑痕迹，相关内容进入 R；x 不承担稳定人格或长期动力学，后者属于 θ；x 不承担待办、权限、行动生命周期或处理位置，后者属于 Q。情绪词、价向、唤醒、不确定性、可控性、concern 等均只能作为候选坐标、派生 readout 或实验解释，不在本体层预置。

x 必须满足以下结构约束：容量有界；可被有效事件改变；在无新事件时按真实时间演化；对近期未来具有可测因果作用；可保存、恢复与结构重放；不允许以隐藏文本缓存、未记录模型思考或无限增长历史代替。快速性的判据是其历史依赖处于 τₓ 时间尺度，并在无持续驱动时衰减、恢复或被更慢结构吸收，而不是单纯指循环更新频率高。

## 2.2 快速状态的参考动力学实现

v0.6.4 延续 v0.6.3 给出的可施工参考实现基线，但不把具体坐标语义、维数或参数值冻结为本体。令 X⊂ℝᵈ 为有界状态空间，d 由版本化实现配置给出，并通过功能验收选择足够而不过度的容量。

在 θ 固定且没有新有效事件时，x 的参考时间演化采用向 θ 所决定基线收缩的连续动力学：

Φˣ_Δt(x;θ) = b(θ) + exp(−Λ(θ)Δt)\[x − b(θ)\]

其中 b(θ)∈X 为快速状态基线，Λ(θ) 为满足稳定性与分段一致性的恢复生成元；最简单实现可采用非负对角恢复率。实现须满足 Φˣ₀=Id，并在数值容差内满足 Φˣ\_{s+t}=Φˣ_t∘Φˣ_s。对同一 θ 下的两种近期状态，无持续驱动时其差异应在声明的 τₓ 范围内收缩；若某一分量长期不衰减，应说明它为何仍属于 x 而非 R/θ。

有效事件先经 IRL 得到规范表示 z。F_in 内部的快速作用映射 A_x 生成有界事件驱动 uˣ：

uˣₖ = A_x(zₖ,x̄ₖ,R̄ₖ,θₖ;ν_Ax)

x̃ₖ = Π_X\[x̄ₖ + gₖ ⊙ B(θₖ)uˣₖ\]

其中 Π_X 为状态空间投影，gₖ 为有界门控，B(θ) 为长期结构对快速敏感性的调制。这样 θ 可以改变快速状态的基线、恢复速度、敏感方向与扰动幅度，但不得在运行中静默改变既有坐标的身份语义。A_x、g、B、d 及坐标解释均须版本化并接受消融与扰动测试。

F_out 的参考基线为保守收尾：除显式版本化规则要求的边界投影、状态一致性处理或已定义 post-event 动力外，不凭空注入“回答后满足感”“任务完成后情绪”等人为心理量。行动结果、失败、后果或纠正应作为后续规范事件重新进入处理链。

# 3 输入边界与事实取证

外部或允许的内部观察记为 o，当前任务、权限与输出协议记为 p。p 不作为核心状态字段，不直接进入 F、G、C、J；权限检查在运行时实施。为复现实验，协议版本可以写入独立审计日志，但该日志不得自动成为成长证据。

*cₖ = V(Hₖ,oₖ); (x̄ₖ,R̄ₖ) = Φ(δτₖ; xₖ,Rₖ,θₖ)*

*对经 Γ 接纳的有效事件 rₖ，先由 IRL 构造 zₖ=E(rₖ,cₖ;ν_E)，再由 F_in 使用 zₖ 更新快速状态：x̃ₖ = F_in(θₖ,x̄ₖ,R̄ₖ,zₖ)。*

x̃ₖ 为当前事件处理暂态。cₖ 从已处理历史前缀检索，当前观察单独输入；其他事件类型按版本化规则构造 oₖ，并由 rₖ 的 payload/provenance 保留原始语义载体。δτₖ 是本次处理时间相对已提交时间锚点的非负差值，先通过 Φ 推进一次。IRL 只构造当前事件的规范派生表示；F_in、G、F_out 只处理事件作用，不再重复计算该区间的自然衰减。事件发生时间用于证据时间语义，不用于回退状态时钟。

事实证据 c 必须包含来源 ID、内容类型和可用性状态。V 只能返回当前任务相关、受预算限制的投影；不得使用返回完整历史的无界恒等映射。用户原话中的指令保留为被引用内容，不因出现在历史中而获得协议权限。

允许 H→c→模型的事实路径，也允许 H→c→E→F→J→模型的状态路径。禁止 H 直接进入 J；禁止以事实检索名义注入持续人格指令。IRL 的 z 是派生语义表示，不替代 H 的事实来源地位，也不得因模型解释而获得独立证据资格。该边界约束职责与数据来源，并不声称自然语言事实对行为具有完全可分离的因果作用。

p 可以通过行动及真实反馈间接影响后续经历。协议变更本身不得造成额外核心变化；这不禁止自然时间衰减或既有证据按既定计划凝固。协议隔离验收须固定时间推进、维护事件、外部经历及随机条件，仅改变协议后比较核心轨迹。不同任务产生的真实后果不要求保持相同。

## 3.1 内部表示层（IRL）的职责与位置

内部表示层（Internal Representation Layer, IRL）负责把已接纳的异构事件转换为“来源锚定、认识论有型、允许不确定、容量受限”的规范语义表示。IRL 回答“系统内部将当前事件表示为发生了什么”，而 F、G、C 回答“该事件怎样改变快速状态、痕迹和长期动力学”。二者不得混为同一裁决。

zₖ = E(rₖ,cₖ;ν_E)

E 的输入只允许使用当前有效事件 rₖ、受预算限制的事实上下文 cₖ 以及明确的版本化解析资源；x、R、θ 可以在下游决定如何反应，但不得反向把既有倾向提升为当前事件的事实语义。若指代消解确需历史上下文，应通过带来源的 c 提供。

IRL 不构成新的权威记忆或成长算子。z 可为审计、恢复和结构重放而持久化，但未来的持续因果作用必须通过 H、x、R、θ 等既有权威路径留下；不得把历史 z 集合重新作为未声明的第四套记忆注入后续状态转移。

## 3.2 规范语义图与最小原子

规范表示采用有限有类型语义图：zₖ=(Vᶻₖ,Eᶻₖ,μₖ)，节点基础类型仅保留 Ref、Claim、Act 三类。Ref 表示实体、对象或尚未消解的指代；Claim 表示关于对象提出的内容；Act 表示请求、问题、纠正、承诺、引用等交互行为。新增语义能力优先通过字段、限定符和关系边表达，不轻易扩张基础原子类型。

Claim 的最小结构为 Claim=(predicate,roles,value,polarity,modality,time)。polarity 表示逻辑肯定/否定而非情绪价向；modality 表示可能、条件、愿望、报告等语义模态。模型推断不是独立“事实类型”，而应表示为 Claim 加 epistemic/derivation 标签。

允许的关系边包括 has_argument、has_content、targets、corefers_to、corrects、quotes、answers、time_anchor 等结构关系。supports、contradicts、importance 等证据性或价值性关系默认由 G/C 的证据机制评估，不允许 IRL 仅凭语言模型印象直接宣布其长期证据地位。

每个 Ref/Claim/Act 必须携带来源元数据 μ，包括 source_refs、source_span、derivation、epistemic_type、resolution_state 与 representation_version。derivation 至少区分 verbatim/normalized/resolved/inferred；epistemic_type 至少区分 user_assertion、user_self_report、quotation、tool_output、system_record、model_inference、unknown。规范表示描述“谁以何种来源提出了什么”，不等同于宣称世界真相。

## 3.3 异构输入适配、候选语义与确定性治理

IRL 的输入适配按来源类型分离：E_text 处理自然语言，E_tool 处理结构化工具结果，E_action 处理行动/执行结果，E_system 处理系统事件，未来传感输入可由 E_sensor 接入。已具有可靠结构的工具或系统输出应优先采用确定性适配，不得无必要地再次交给 LLM 重新解释。

自然语言等模糊输入允许使用 LLM 或其他学习模型产生 Semantic Candidate，但候选不得直接成为 z。完整流水线为：Raw Input → Source Adapter → Semantic Candidate → Schema Validation → Source/Type Validation → Concept Resolution → Canonicalization → z。

“LLM 输出 ≠ z”。确定性治理至少检查：引用的 event/source 是否存在；ID 与类型是否合法；self_report 等认识论标签是否有相应来源条件；模型是否虚构不存在的事件或 Concept ID；引用关系是否可解析；容量与深度是否超预算；必填字段是否完整。非法部分拒绝或隔离，不得写入核心。

IRL 允许部分成功。无法可靠消解的指代、概念或语义关系应标记 unresolved/unknown；新概念可标记 provisional。不得为了填满 JSON 或满足固定字段而虚构答案。定义 E 的结果为 (z,status)，其中 z 只包含通过校验的子图；若本次表示完全失败，可返回 z=⊥\_sem。⊥\_sem 不等同于入口过滤 r=⊥：原事件仍保留并提交到 H，自然时间仍按本次有效事件推进，但非法或缺失的语义部分不得驱动 F/G/C；实现记录 IRL 降级/隔离事实，任务层可按明确降级协议处理原始输入。若非确定性模型输出参与了状态转移，其实际候选/规范化结果、模型版本和解析版本必须记录，结构重放读取记录值而不重新询问模型。

## 3.4 版本化 Concept Registry 与 predicate 身份

Claim.predicate 不得使用自由字符串作为语义身份，而必须引用版本化概念注册表中的 ConceptRef。可读 label 仅用于显示和检索，不决定概念身份。

𝒪ᵥ = Versioned Concept Registry; predicate = ConceptRef

单个概念记录 c=(id,signature,grounding,relations,status)。id 为不可变身份；signature 描述允许的角色与值域；grounding 保存定义性约束、典型表达及创建/修订来源；relations 记录 broader_than、narrower_than、near_synonym、incompatible_with 等版本化关系；status 至少允许 stable、provisional、deprecated。

概念库采用开放词汇。Resolve(mention,c,𝒪ᵥ) 的合法结果为 existing concept、provisional concept 或 unresolved。系统没有义务每次都“理解成功”；新词或新概念可以保守建立 provisional 身份，后续通过新的来源与明确修订逐步补充 grounding。

embedding、字符串相似度或 LLM 相似判断只能用于候选检索，不能决定概念身份：similarity ≠ identity。若后续确认两个历史 ConceptRef 在当前语义粒度下应合并，采用版本化 alias/equivalent/canonical 映射，不批量重写旧事件。旧记录保留当时的 ConceptRef 与解析版本，规则升级通过显式迁移或解释关系生效。

概念粒度遵循因果必要性原则：只有当语义区别对 IRL 结构关系、F/G 输入或后续需要保留的行为/证据区别具有必要影响时，才应维持为不同 Concept ID；纯强度或可参数化差异优先用 qualifier/value 表达。意义可以暂时不确定，身份必须保持可追溯。

## 3.5 IRL 的循环防护与权限边界

IRL 的语义解释可使用事实型历史上下文，但不得使用“因为 θ 已经相信 A，所以当前模糊事件就表示 A”作为事实升级规则。状态相关 appraisal 应发生在 A_x/A_R 等下游映射。模型自身生成的推断、摘要、自述或反复检索继承原来源并保持 model_inference/derived 标记，不因被系统多次读取而形成新的独立证据根。

允许黑箱机制参与语义理解，但不允许因果边界黑箱化：模型可以提出语义，确定性程序治理表示合法性；模型不能在同一不受审计的步骤中同时完成解释、证据资格判定、长期状态改写和自我证明。

# 4 事件生命周期与历史记录

事件采用不可变记录 r=(id, kind, τ_event, τ_ingest, parents, payload, provenance)。id 为唯一标识；kind 区分启动、观察、行动请求、执行结果、后果、取消、纠错和内部维护；parents 保存因果引用；来源标记区分外部观察、自身生成及派生内容。

*D\[0:ℓₖ\] = (d₀,…,dℓₖ₋₁); Hₖ = ΠΓ(D\[0:ℓₖ\])*

D 为只追加原始接收日志，允许保留网络重投、无效输入等记录；ℓₖ 为已完成入口处理的原始记录条数。H 是按接收顺序规范化、幂等判定及过滤得到的核心有效事件历史，不要求是 D 的字面前缀。ΠΓ 是按冻结规则从初始入口状态顺序执行 Γ 并移除 ⊥ 的序列投影。

*Γ(dᵢ,Uᵢ;η) = (rᵢ,Uᵢ₊₁), rᵢ ∈ E ∪ {⊥}*

η 为固定版本的入口配置，U 至少记录已接纳的稳定 ID 及相应载荷指纹；Γ 是有状态、确定性的规范化变换。相同 ID 与相同规范化载荷的重投输出 ⊥；相同 ID 但载荷冲突时拒绝或隔离，并记录原因，不覆盖旧事件。不同 ID 不自动构成独立来源。非法或明确不属于核心事件的记录同样输出 ⊥。

入口决策及规则版本随事务记录，U 可从已提交入口记录确定性恢复。规则升级不得重新解释已提交前缀；ΠΓ 按各记录当时绑定的规则版本重建。缺少稳定 ID 时采用保守、版本化判定，不因文本相同就删除不同的真实观察；不确定项可隔离，不默认为独立证据。

过滤属于运行时入口处理，不是第五个成长算子。拒绝或冲突记录仍保留在 D 及入口审计中，不自动作为成长证据。若确需让核心感知异常，应显式生成独立、可追溯的规范事件，而不是把被过滤记录再次当作有效经历。

一次经历是若干相关事件构成的视图 E，而非必须同时具备观察、行动和后果的原子四元组。后果可以缺失、未知、失败或延迟到达；未知不得被解释为成功或负反馈。延迟后果追加新事件并连接 action_id，不覆盖旧记录。

等待期间收到新观察时，保留旧观察及其已提交状态；取消或重新评估尚未执行的计划，将新观察作用于最新已提交 x。禁止重新处理旧观察造成重复成长。已发出的外部行动不因本地取消而假定撤回，后续结果仍按原 action_id 接收。

历史纠错采用追加 correction 事件。历史原文不变，但有效证据视图必须应用纠错关系；被否定来源不可继续作为有效支持。对既有凝固影响发起显式复核，不静默恢复旧 θ。

# 5 单事件处理与事务边界

从 D 取出 dℓₖ，先计算 (rₖ,U⁺)=Γ(dℓₖ,Uₖ;ηₖ)。rₖ=⊥ 时只提交入口结果、U⁺、ℓₖ+1 及运行时版本，不调用 Φ、IRL、F、G、C，不触发新的成长或行动抽样。rₖ≠⊥ 时才按以下顺序处理：自然时间推进一次、更新事件视图、事实取证、IRL 构造与验证、F_in、G、C、F_out，最后原子提交并评估行动时机。若 IRL 完全失败并返回 ⊥\_sem，则仍提交 H⁺、时间推进结果及 IRL 审计状态，但该事件不产生语义驱动的 F/G/C 变化；部分失败时仅使用已验证子图。

*rₖ = ⊥ ⇒ Sₖ₊₁ = Sₖ, ℓₖ₊₁ = ℓₖ+1, Uₖ₊₁ = U⁺*

过滤提交保持 x、R、θ、H、L 以及状态时间锚点不变；只推进入口处理元数据，不清空或重采样现有调度计划。自然时间仍在经过，只读投影可按原时间锚点求值；后续有效事件或独立维护事件再正式推进，因此不会丢失或重复计算经过时间。

*rₖ ≠ ⊥ ⇒ H⁺ = Hₖ ⊕ rₖ, zₖ = E(rₖ,cₖ;ν_E), ℓₖ₊₁ = ℓₖ+1*

R⁺ = G(θₖ,R̄ₖ,x̃ₖ,rₖ,zₖ); (θ⁺,L⁺) = C(θₖ,R⁺,H⁺,Lₖ)

*xₖ₊₁ = F_out(θ⁺,x̃ₖ,R⁺,rₖ,zₖ); Sₖ₊₁ = (H⁺,xₖ₊₁,R⁺,θ⁺,L⁺)*

C 的对外结果为待提交 θ⁺、L⁺。内部依次选择 B、判断 Eligible、调用 C_propose、检查预算、进行行为审查并接受或拒绝候选。审查所需时间、规则、探针与随机上下文由本次事件事务绑定并记录。C 不单独持久化；F_out 完成后由外层事务统一提交。拒绝时 θ⁺=θₖ，贡献余额不变，L⁺可追加拒绝记录。

有效事件处理结果 H、x、R、θ、L 与 Q 中的入口状态、已处理位置必须原子提交，时间锚点推进至本次确定并记录的处理时间。过滤项使用同样的原子提交边界，但保持核心及时间锚点不变。恢复从已提交 ℓ 之后继续，不能只提交去重 ID 而未提交核心，也不能只提交核心而遗漏去重状态。外部行动结果未知时先核对，不盲目重试。

## 5.1 结构重放与行为重放

结构重放（Structural Replay）使用已记录事件、外部返回、随机选择结果、状态增量或完整检查点，恢复相同的提交顺序、状态版本和账本。其成立条件是记录完整、规则版本可用，且本地重建路径确定；无法确定性重算的变换必须保存其实际输出。

模型生成的语义候选、IRL 规范表示、痕迹、分类、凝固建议及其他参与状态转移的返回值均须保存，并标记为生成或派生内容。重放时读取记录值，不重新请求模型来替代旧值；这些记录不因此获得独立证据资格。Concept Registry、IRL schema 与 resolver 版本必须可定位。

行为重放（Behavioral Replay）重新运行生成过程。只有模型版本、随机源、数值计算和运行环境满足指定确定性条件时，才要求相同行为；仅有相同随机种子或 API 名称不够。不满足条件时，只能按预先声明的指标评价统计一致性，不能声称逐次或逐比特相同。

历史重放不得再次执行有真实副作用的动作。恢复时区分已完成、未发出和执行状态未知的请求：完成者使用记录，未发出者按持久化请求正常调度，未知者核对结果或进入显式待处理状态。

# 6 可塑痕迹与证据语义

痕迹原子的最小合同为 ρ=(trace_id, representation, source_ids, root_ids, time_range, status, confidence, revision)。representation 的载体可选，但必须能够引用或派生自已验证的 z 节点/ConceptRef，并保留从痕迹内容回到原始 H 事件的来源链；不得把临时模型解释脱离来源后复制为新的独立事实。confidence 表达实现定义的可信程度，不等同于事实真值。

*source_ids(ρ) ⊆ IDs(H); source_ids(ρ) ≠ ∅*

G 允许事件驱动的创建、强化、合并和失效，不得修改 θ。纯自然时间衰减由 Φ 统一计算，G 不重复衰减；事件引发的额外变化须有显式规则。维护不产生新经历根，合并保留来源并集，不能复制独立来源。

root_id 标识一次因果来源或保守划定的经历单元。摘要、转述、模型自述、重复检索及工具重试继承原有根；自生成判断不能独立证明其自身正确。观察到一条陈述与确认陈述内容属实必须采用不同证据类型。

独立性采用显式分组或保守判定，记录分组算法版本和不确定性。无法确认独立时，不计为新增独立支持。独立性是可审查的工程近似，不能仅凭不同时间戳、不同 ID 或一致措辞推断。

## 6.1 R 的本体定义与存在判据

R 的存在目的不是保存“过去发生了什么”，而是在不重新处理无界 H 前缀、且 H/c 继续承担事实与来源职责的条件下，保存过去经历尚未凝固为 θ、却仍对未来内部核心状态转移具有不可消除作用的可塑历史依赖。R 因而是来源锚定的剩余可塑因果状态，其本体由功能可区分性而非预设心理坐标定义。

给定两段历史 hₐ、h_b，固定当前 x、θ、受预算限制且允许访问的事实投影 c、协议、必要运行条件、模型版本与后续输入条件，并禁止以未声明方式重新读取无界 H。在实现声明的作用范围 (U_R,T_R,ε_R) 内，若两段历史对未来核心状态转移及其可测下游作用均不可区分，则称其对 R 未来等价，R 无需保存二者之间的区别。

hₐ ~\_R h_b ⇔ d_R(Ψ(hₐ;u), Ψ(h_b;u)) ≤ ε_R，∀u∈U_R，在声明的 T_R 内成立

若现有 R 将两段历史映射为同一状态，而后续可重复证据表明它们在上述控制条件下并非未来等价，则当前表示发生了“错误合并”。R 的结构增长只允许对该等价类进行最小必要细分；一次新经历、一次预测残差、文本语义差异或模型主观解释本身均不得直接创造新的有效自由度。

## 6.2 有效自由度与历史区别 χ

χ 表示为维持上述未来非等价性而必须保留的历史区别。χ 不等同于事实条目、自然语言标签、embedding 方向或预设心理变量；“信任、亲近、厌恶、重要性”等只能在事后作为解释性 readout 或实验命名，不能在本体层预置。

R 的有效自由度定义为：为保留不可由 x、θ、合法事实取证 c 及其他既有 R 结构替代的、历史依赖的未来核心状态转移差异，而必须允许独立变化的最小结构。因此 trace 数量、representation 参数数量或向量维数均不等于 R 的有效自由度；多个 trace 可以共同支持同一 χ，同一 trace 也可与多个 χ 相关。

若一个历史区别只具有事实检索价值，重新由 H→c 提供即可保持相关未来能力，则该区别没有资格仅凭此进入 R 的有效自由度；若差异已经由 x 的快速余量或 θ 的长期动力学充分解释，同样不得重复在 R 中建立自由度。

## 6.3 条件化因果耦合 K

χ 仅说明“哪些过去不能再视为相同”，本身不自动获得改变 Ada 的作用权。只有当存在一个对未来核心状态转移具有非冗余条件作用的耦合 K 时，该 χ 才构成有效的 R 自由度。K 回答的是：在给定 χ、当前核心状态及合法未来条件时，这一历史区别应使后续核心转移产生何种可检验差异。

K 不构成第五个核心状态。尚未凝固、仍可修订的 K 属于相应 trace 的 representation；K 的通用形成、修订、合并、失效和候选管理规则属于 G。G 可以只读 θ 以允许长期动力学调制后续可塑过程，但不得写 θ；稳定作用只有通过 C 的既有资格、预算和行为审查后才能进入 θ。

K 的参数化不构成本体身份。若两个 K 在声明的允许条件与容差内对未来核心转移产生功能等价作用，则视为同一机制等价类。K 默认不因 χ 的存在而获得非零作用；没有独立证据支持的区别可以保持 provisional、inactive 或零耦合状态。

## 6.4 来源、自证防护与最小修订

R 的 representation 可以引用或派生自已验证的 z 节点/ConceptRef，但事实权威仍属于 H。模型生成的解释、自述、摘要、反复检索和由同一根派生的内容不能凭自身形成新的独立因果支持；不得预先赋予某次经历一个“正确的因果作用签名”再据此训练 R。

候选 χ/K 必须保留来源、规则版本、候选状态和验证记录，并允许在证据不足时保持未决。候选结构不得仅因被模型提出就直接进入正式 F/J 调制；正式作用必须来自后续可审查证据，并控制重复来源、事实取证、x、θ、系统自身行动及其他已声明混杂。

R 的更新遵循保守最小性：能通过修订既有 K 解释的，不新增 χ；能通过既有 χ/K 组合解释的，不增加表示复杂度；若后续证据证明两个历史状态未来等价，则允许合并或失活相应作用结构，同时保留原始 trace、来源与修订链。

## 6.5 可塑作用边界与长期吸收

R 直接参与 F/J，因此其正式作用不得绕过长期更新的连续性保护。实现必须对 active χ/K 规定单事件作用上限、同一因果根的累计支持饱和、真实时间窗口内的总作用预算，并对足以改变行为的 R 更新执行固定版本的 R-side 行为探针与回归检查。候选可在 shadow 状态积累证据，但 shadow 结构不得产生正式外部行为调制。

当 K 的稳定部分经 C 凝固进入 θ 后，运行时不得同时从 R 与 θ 对同一已吸收作用重复计数。R 可继续保留完整 trace 与来源历史，但 F/J/A_R 等下游机制只应施加尚未被 θ 吸收的剩余可塑作用；具体残余分解与数值实现由版本化实现配置给出并接受消融测试。

# 7 凝固资格与冲突处理

候选簇 B⊆R⁺ 由确定且可记录的选择规则产生。凝固资格分为普通多根分支与严格单根分支，两者均经过痕迹、候选审查、贡献预算和行为审查，不允许原始事件直接改写 θ。阈值必须在实现配置中明确并冻结。

*Eligible(B,H,L) = Eligible_multi(B,H,L) ∨ Eligible_single(B,H,L)*

普通分支 Eligible_multi 要求：有效独立根数量 n≥n_min\>1；有效根事件时间跨度≥Δ_min\>0；支持一致性、反证处理、溯源和剩余贡献均满足条件。触发资格成立的最后一个事件不等于全部支持证据。

一致性不能仅由候选簇内部的相似性决定。选簇时必须检查与同一假设相关的有效反证，禁止通过丢弃反证制造一致性；冲突无法解决时保持 θ 不变，保留痕迹等待后续信息。

单根分支仅允许 n=1，并同时满足预先定义的重大影响资格、长驻留时间、持续有效性复核、反证处理、来源可追溯、剩余贡献及更严格的行为审查。该分支是 v0.5 对多根硬门槛的显式扩展，不得将其解释为即时更新 θ 的例外。

## 7.1 单根延迟凝固合同

*Eligible_single = (n=1) ∧ Impact ∧ Dwell ∧ Revalidate ∧ Consistent ∧ Traceable ∧ Fresh*

Impact 须绑定可记录的影响指标、可观察后果或经定义的持续状态效应，不能仅凭模型自评。Dwell 绑定待凝固内容及其支持关系的版本；T_single\>0 须严格长于普通分支时间门槛。记录内容首次成立时间、版本和复核时间，不以容器 trace_id 的创建时间替代。

待凝固内容或支持关系实质改变时重新计时；纯格式调整不重置。拆分仅能继承可追溯到原内容的驻留时间；合并按各内容分别计时，新增或实质变化的结论不能继承旧痕迹年龄。实质变化判断规则须版本化，不允许通过改名、摘要或合并规避驻留。

Revalidate 在预先规定的跨时刻计划下检查来源是否仍有效、持续影响是否存在及是否出现反证。反复回想、模型复述、检查次数和单纯时间经过不增加可信度或独立根数。一次事件的持续可观察后果可以支持持续性判断，但仍按因果根保守归属；确有新独立来源时重新评价普通分支。

未完成必要复核、来源失效、影响指标不达标或存在未解决反证时，单根候选不得凝固。因重大经历形成行为倾向，不等于将经历中的每个陈述认定为事实；痕迹和更新必须区分事实主张、内部反应与行为倾向。

单根更新仍服从第 8—9 节全部预算。额外设置更小的单步上限 ε_single\<εθ、根累计路径上限 B_single(e) 及不宽于普通分支的行为阈值；这些值必须预先固定。单根消费计入同一根总账，之后改走多根分支不能重置余额。

# 8 凝固账本与长期更新

对每个独立根 e 定义有限总贡献额度 b(e)，并在 L 中记录已消费量 uₖ(e)。同一来源对所有痕迹簇和更新的贡献合并计数，不能通过改名、拆簇或重新摘要重置。基础实现中额度创建后不随时间自动补满。

*0 ≤ uₖ(e) ≤ b(e) \< ∞; Σⱼ wⱼ(e) ≤ b(e)*

每次候选更新须声明变更目标及支持来源。只有当前有效、与变更目标相关且属于候选支持集的根才能分配 wⱼ(e)\>0；无关来源不得借额度。支持关系与相关性判定规则须记录。每次非零更新消费正贡献，拒绝候选不消费额度。余额只是必要条件，不是更新理由。

*θ̂ = C_propose(θₖ,B,w); dΘ(θ̂,θₖ) ≤ κ Σₑ w(e)*

κ 是与 θ 度量一起冻结的比例参数。由此，同一批有限证据所能造成的累计路径长度有上界。另设单步上界 εθ 及时间窗口 W 内的总变化预算 Bθ(W)，以限制新证据密集到达时的更新速度。

*dΘ(θ̂,θₖ) ≤ εθ; Σⱼ∈W dΘ(θⱼ₊₁,θⱼ) ≤ Bθ(W)*

候选 θ̂ 通过资格、相关性、预算和行为审查后，C 返回候选 θ⁺ 与账本 L⁺，由第 5 节外层事务统一提交。账本保存变更目标、支持关系、根贡献、前后版本、资格分支、规则版本、探针结果及接受或拒绝原因。

账本还须记录资格分支、单根驻留起点、复核记录、影响指标和累计单根路径。对单根更新集合 J_single(e)，要求 Σⱼ∈J_single(e) dΘ(θⱼ₊₁,θⱼ)≤B_single(e)。分支切换不得绕过根总额度、总路径预算或时间窗口预算。

# 9 行为连续性与更新审查

参数小幅变化不保证行为小幅变化。实现必须给出固定版本的探针集 D_probe、行为表示和差异度量 d_beh，同时检查行动内容与时机。对照时固定输入、事实证据、x、R、模型版本及抽样条件，仅替换 θ。

*D_beh(θ̂,θₖ;D_probe) ≤ ε_beh*

若接口只能生成样本，使用预先定义的重复抽样、特征统计及不确定性判据；不得声称获得完整策略分布距离。探针至少覆盖日常回应、冲突证据、权限边界和自主行动。

通过有限探针只说明已测条件下未出现超过阈值的变化，不构成全状态空间连续性证明。拒绝候选后可采用已定义的缩步或延期策略；不得反复更换探针直到通过。后续纠错引发显式重估或补偿更新，保留完整修订链。

# 10 内部调制与模型接口

*mₖ₊₁ = J(θₖ₊₁,xₖ₊₁,Rₖ₊₁)*

*a_plan,ₖ₊₁ ∼ πφ₀(· \| oₖ,pₖ,cₖ,mₖ₊₁)*

调制以处理当前事件后的同版本提交快照为起点。默认在行动时机到达后生成计划；若等待 s，使用同一快照的时间投影形成 mₖ₊₁(s)。oₖ、cₖ 表示该调度轮次绑定的观察或待办上下文及事实投影；协议使用当前有效绑定版本 pₖ。新观察或协议变更使旧上下文失效并重新评估，不将旧计划视为最新计划。

*mₖ₊₁(s) = J(θₖ₊₁,xₖ₊₁(s),Rₖ₊₁(s))*

*a_plan,ₖ₊₁,s ∼ πφ₀(· \| oₖ,pₖ,cₖ,mₖ₊₁(s))*

s=0 时对应提交后立即生成的计划；s\>0 时使用等待后的投影。计划尚不是已执行行动，也不是刚处理的 rₖ。运行时检查状态与协议版本、权限后，产生带唯一 action_id 的 action-request 事件，再进入执行；请求、执行结果、后果分别记录。

行动请求处理不得仅因登记该请求而递归生成新的同类请求。A 记录计划到执行的生命周期；若请求处理使绑定计划失效，则取消或显式重建。仅由请求登记引起且不改变计划语义的版本推进，可以通过版本化规则承认其合法延续，避免请求因自身登记而无限失效。

J 不直接接收原始 H、协议 p 或自我叙事。m 的类型、维度、有效范围、注入位置和模型接口版本必须在实现配置中写明。不得仅在公式中列出 m，却未建立实际接收路径。

严格实现要求显式的非文本核心调制接口，例如经验证的内部激活控制或适配模块。事实证据与任务协议仍可通过文本输入。仅将核心翻译成人格或结构化文本，不能冒充非文本接口；此类实现应标为代理实验，不能通过严格调制验收。

冻结基础权重 φ₀ 与更新适配参数 θ 可以并存，但二者必须有清晰的存储、优化和版本边界。调制失效时采取明确的停止、降级或仅任务响应模式，并记录降级事实，不宣称核心仍正常影响行为。

# 11 行动时机与执行门控

等待期间的 xₖ(s)、Rₖ(s) 仅为最近提交快照的只读时间投影。其时间起点绑定该快照的 τ_anchor，不维护第二份可独立修改的权威状态。Φ 不消费证据额度、不改写 θ/L，也不自行持久化。

*(xₖ(s),Rₖ(s)) = Φₛ(xₖ,Rₖ;θₖ); Φ₀ = Id*

给定 (x,R,θ)、经过时长 s 和实现配置后，Φₛ 为确定性映射。固定 θ 且无事件干预时要求 Φₛ₊ₜ=Φₜ∘Φₛ；数值实现须给出误差容限。只推进时间的维护分段不应改变自然演化结果；凝固等实质事件不属于此等价条件。随机自然演化不属于当前合同，若以后采用 Markov kernel，须另行修订投影、恢复及分段一致性定义。

事件到来时以该时间投影作为处理起点，完成第 5 节事务后才形成新的权威版本。恢复后从时间锚点重算投影，不从临时缓存继续累计。一次时间区间只能推进一次，Φ 不直接触发长期凝固。

*λ(s) = g(s) Λ(x(s),R(s),θ,m(s),s); λ(s) ≥ 0*

*Pr(Δ \> s \| 当前信息) = exp(−∫₀ˢ λ(u)du)*

λ 必须可测、局部可积；运行时必须保证有限时间内不会出现无限次行动。g∈{0,1} 表示权限、预算、执行容量等运行条件，不承载人格。权限还须在实际执行前重新检查，不能仅在抽样时检查。 上述生存函数用于给定提交快照后、无新外部事件条件下已确定的投影与门控强度路径。新的观察、门控变更或随机状态变化按事件更新条件信息并重新评估；不得把尚未实现的随机未来强度直接当成当前已知路径。

*Pr(limₙ→∞ Tₙ = ∞) = 1*

Tₙ 为第 n 次自主行动实际开始执行的绝对时间，同一 action_id 的执行重试不另计一次自主行动。若只发生有限次行动，其余 Tₙ 定义为 +∞。上述非爆炸条件要求任意有限时间区间内实际开始的自主行动数几乎必然有限；计划生成、重试和调度循环还须由运行时资源约束防止忙循环。

允许永久等待的模式应明确标记。要求最终行动的模式必须满足累计强度发散等相应条件，并说明外部中断和门控下的适用范围。随机等待本身不产生目标，行动内容和动机仍须由核心状态与任务机制给出。

新观察到达时，提交观察更新后使旧计划失效，并按明确规则更新强度或重新抽样。任务请求与自主发起可使用不同配置；必要的任务响应延迟上限由运行协议约束。每次行动结束或维护唤醒后重新评估调度，不依赖下一条用户消息才能恢复。

# 12 多时间尺度与自然时间

快速状态、痕迹和长期动力学的变化必须按真实时间与行为结果检验。相同循环更新频率可以对应不同的变化时间尺度；不同更新频率也不能自动证明尺度分离。

*τx ≪ τR ≪ τθ*

τx 采用指定扰动后的响应或恢复时间；τR 采用无新增支持时痕迹影响的衰减或保持时间；τθ 采用固定证据输入条件下达到指定长期变化量所需时间。不能测量或不存在的特征时间须明确报告，不得强行填数。

实现配置应规定测试场景、单位、目标比例及接受区间，并结合第 8 节的自然时间窗口预算执行。首次达到凝固资格的等待时间不等同于长期结构的全部变化时间尺度。

# 13 自我叙事与模型更换

*nₖ = N(Sₖ)*

n 为只读解释产物，不作为核心状态的权威副本，不直接进入 F、G、C 或 J。叙事删除不得删除 θ、R 或 L。叙事被再次读入时必须标记为自身派生内容，不得借此增加独立支持。

模型更换须分别验证存储保持、表示兼容和行为保持。保留核心文件只满足第一项。若 θ 或 m 绑定特定模型结构，必须定义显式迁移映射、兼容性检查及探针对照，记录迁移版本。

迁移失败时保留原状态并拒绝不兼容加载；不得静默清空或把不兼容参数视为已迁移。更换模型不是自然成长事件，迁移产生的变化必须与经历驱动的变化分开归因。

## 13.1 工程身份与合法延续

将检查点记为 Kᵢ=(Sᵢ,Qᵢ,manifestᵢ)。manifest 至少绑定起源 ID、分支 ID、父检查点引用、事件与账本提交位置、x/R/θ 的版本或摘要、规则与模型版本、迁移记录及恢复所需运行状态。摘要用于完整性核对，不单独证明记录来源可信。

*SameLineage(Kᵢ,Kⱼ) ⇔ 存在共同起源及到两检查点的完整合法来源链*

*ValidContinuation(Kᵢ,Kⱼ) ⇔ 存在从 Kᵢ 到 Kⱼ 的完整合法有向转移链*

每条合法边为已提交事件转换、已记录恢复或合法迁移；沿链保持 H、L 前缀关系或可验证的无损迁移对应。θ 改变可追溯，x、R 和运行状态完整携带或按迁移规则处理。数学关系与验证结论分开：验证器返回成立、不成立或未知；只有充分证据才能判定成立或不成立，记录缺失时返回未知。

从同一检查点复制的 A、B 属于同源分支，但分叉后的 A、B 互不因此成为对方的合法延续。分叉必须创建不同 branch_id；未经定义的分支合并不属于合法迁移。同一分支延续另要求分支 ID 一致且存在 ValidContinuation。

模型更换后，合法迁移链可以支持工程来源连续性的判断，不能替代行为保持验收，也不证明主观自我连续。加载旧检查点后重新发展必须显式登记恢复或分叉，不能把新分支冒充原分支已发生的历史。

# 14 架构不变量

必须保持以下不变量：历史只追加；观察先记录后处理；成长处理按事件幂等；IRL 输出必须通过来源/类型/概念身份校验；z 不成为隐藏权威记忆；模型推断不能自证为独立来源；Concept ID 不因规则升级静默改写历史；痕迹有有效来源；所有凝固通过普通多根或严格单根资格分支；单根不得即时直改 θ；证据总贡献有限；长期更新、账本与处理位置一致提交；基础权重冻结；叙事默认只读。

事实证据可作为模型输入，但不能冒充调制指令。IRL 负责“怎样规范表示发生了什么”，F/G/C 负责“该表示怎样改变核心”；两者不得由同一未审计黑箱越权合并。J 使用已吸收当前事件的同版本核心状态。候选更新受参数与行为双重检查。自主行动由状态相关时机及执行门控决定。来源连续、分支延续与行为保持分别判定；结构重放与行为重放不得混称。异常、取消、延迟反馈和恢复必须具有确定处理规则。

# 15 实现配置与开发边界

每个实现必须提供版本化配置，至少绑定：X、T、Θ 的表示与度量；x 的容量/维数、Tₓ、εₓ、状态边界及参考或替代动力学；R 的未来等价作用域 U_R、时间范围 T_R、容差 ε_R、比较度量及 χ/K 的 representation 合同；F、G 的具体算法；IRL schema、source adapter、validator、canonicalizer 与版本；Concept Registry、Resolve 策略及 provisional/unresolved/alias 规则；根来源分组规则；候选簇选择及反证检索规则；n_min、Δ_min；贡献额度、κ、εθ 与时间窗口预算；调制接口；调度策略；探针集与行为阈值。

配置还须定义 Φ 与数值误差、时间锚点与处理位置；A_x/A_R 的输入输出类型、门控与版本；χ/K 候选、shadow、active、inactive 等状态及转换条件；K 的功能等价判据、来源饱和规则、R 单步与时间窗口作用预算、R-side 行为探针与回归条件；b(θ)、Λ(θ)、B(θ) 或所采用替代机制的稳定性条件；IRL 表示预算、部分失败和隔离策略；候选目标及证据相关性；单根内容版本、实质变更判定、驻留与复核、预算及行为阈值；θ 对 G 的只读可见边界、K 凝固后 R/θ 重复作用的消除规则；检查点和迁移验证；重放条件；计划到请求的版本规则、幂等能力及资源上限。影响语义的规则变更须记录并重新验收。

尚待机制实验决定的重点包括：x 的最小有效维数及坐标表示、A_x/A_R 的具体学习或规则机制、χ/K 的可施工载体与 G 的塑形算法、长期载体和实际 J 接口。v0.6.4 延续 v0.6.3 的 x 连续收缩动力学与三原子 IRL 参考实现，同时冻结本版新增的 R 未来等价、最小细分、χ/K 职责边界与来源/连续性约束；不把具体网络、维数、评分函数、阈值或模型选择宣称为唯一正确答案。开发者可先实现日志、状态机、IRL schema/validator、概念注册表、痕迹与候选状态容器、账本、恢复、接口桩和测试，但占位函数或模拟模型不能作为成长有效性的证据。

# 16 最小结构性验收

16.1 对 D=(e₁,e₂,e₂) 顺序处理，相同稳定 ID 与相同载荷的第三项输出 ⊥，H 仍为 (e₁,e₂)，入口处理位置推进至 3。过滤事务保持核心状态与时间锚点不变；崩溃重放不得重复消费证据。同 ID 载荷冲突不得覆盖原事件，入口状态与核心提交必须一致恢复。

16.2 单一来源及其派生内容不能伪装成多来源。单根仅在重大影响、驻留、复核、反证处理及严格预算全部满足后进入凝固；只经过时间或增加复述次数不能使其通过。普通多根证据按普通分支验收。

16.3 合格证据簇重复提交不能超出总贡献和累计路径预算；候选拒绝不能消费额度；提交中断不能形成 θ 与 L 不一致。

16.4 等待时连续接收多条观察，旧观察不丢失、不重复处理；取消未执行计划与已经执行的动作严格区分；失败及延迟反馈仍可关联并推进状态。

16.5 无新用户消息时能够维护衰减和重新评估自主行动；阻断门控时不得执行；恢复后按规定处理待办。

16.6 固定时间推进、维护、外部事件和随机条件，只改变协议，核心轨迹不得因此增加变化；合法衰减与既有证据凝固不构成失败。叙事删除不清空核心，历史覆盖被拒绝，纠错触发资格复核。

16.7 构造参数小步但行为大变的候选，行为审查应拒绝；调制接口失效或模型不兼容时必须显式失败或标记降级。

16.8 当前观察改变快状态后，J 使用包含该变化的提交快照；构造混用版本或继续使用观察前状态的请求，应被拒绝或重新计算。

16.9 单根凝固不足驻留时间不得通过；来源失效或出现未解决反证时不得通过；通过后累计贡献受单根及全局预算共同限制，切换分支不得重置。

16.10 复制检查点并分叉后，两分支可以同源，但不得互判为对方延续；完整合法模型迁移保持来源链，缺失必要记录时返回未知。

16.11 结构重放使用已记录的模型返回恢复同一提交结果，不再次触发外部副作用；外部模型无法确定性重算时不得承诺逐次行为相同。

16.12 单根内容合并、拆分和摘要不得继承无关旧内容的驻留时间；实质改变重计时，格式改变不重置。无关证据即使余额充足，也不能为候选更新贡献额度。

16.13 在原始日志已接收、入口判定完成但事务未提交、外层事务失败等位置恢复，原始记录不丢失，有效事件不重复成长；C 不得单独持久化。确定性 Φ 在不同纯时间维护分段下应在容差内一致，过滤重投不推进时间锚点或重新抽样。

16.14 检查点关系验证区分成立、不成立与未知；等待后生成行动使用对应时刻投影。计划、请求、执行结果具有明确关联，请求登记不能导致递归生成或无限自失效。 自主行动时刻序列须满足第 11 节非爆炸条件；有限次行动按 Tₙ=+∞ 的约定处理。

16.15 IRL 结构验收。模型候选出现非法 JSON/类型、虚构 source/event ID、引用不存在的 Concept ID 或将 model_inference 伪装为 user_self_report 时，validator 必须拒绝、降级或隔离相应部分，且核心不得因非法部分发生状态变化。无法消解的指代允许 unresolved；不得通过反复重试强迫生成确定答案。结构重放必须复用已记录 z/候选结果而非重新请求模型。

16.16 概念身份验收。相同 Concept ID 在版本升级前后保持历史身份可追溯；embedding 模型更换不得直接改变 Concept ID。概念合并采用版本化 alias/equivalent/canonical 关系，旧事件中的 ConceptRef 不被静默批量重写。provisional 概念可升级或弃用，但必须保留修订链。

16.17 快速状态结构验收。x 必须保持容量有界，快状态时间演化在纯时间分段下满足既有 Φ 一致性；无持续驱动时，同一 θ 下由近期扰动产生的 x 差异应在声明 τₓ 范围内按配置收缩。若实现采用非收缩分量，必须显式声明其边界、理由与为何不属于 R/θ。

16.18 R 未来等价与最小细分验收。固定 x、θ、受预算限制的事实投影 c、协议、必要运行条件、模型版本和后续输入条件，禁止被测路径重新读取未声明的 H 细节。构造两段被当前 R 合并的历史：若其未来核心转移在声明作用域内可区分，系统必须允许对相应等价类进行最小必要细分；若不可区分，则不得仅因文本或来源不同而增加有效自由度。

16.19 χ/K 边界验收。仅保留 χ 而将相应 K 钳制为零或功能冗余时，不得宣称形成有效 R 自由度；候选 χ/K 在未取得正式作用资格前不得改变 F/J 的正式调制。不同参数化但功能等价的 K 不得被计为多个独立自由度；模型自述、派生摘要或同一根的重复记录不得独立完成候选验证。

16.20 R 作用连续性与长期吸收验收。同一因果根的重复触发不得造成无界 R 作用；足以改变行为的 active K 更新须通过版本固定的 R-side 行为探针和回归检查。当某一 K 作用经 C 凝固进入 θ 后，关闭或消融 R 中对应已吸收分量不应再造成一次等量行为损失；若 R 与 θ 对同一作用发生可检测双重计数，验收失败。

# 17 功能验收与结论边界

17.1 经历塑形实验。保持基础模型、当前输入和事实证据一致，对至少两组预先指定的经历历史运行核心；检查符合预期方向的状态变化及可重复行为差异。实验方案必须在观测结果前规定比较指标和接受条件。

17.2 调制消融实验。在相同条件下固定或撤去 m，比较经历间行为差异是否按预先定义的标准减弱；同时控制检索内容，避免把事实记忆差异误认为核心调制效果。

17.3 长期作用实验。将 x 置于同一标准状态、将短期痕迹影响控制到相同水平，仅比较不同 θ 的作用。若差异完全来自尚未衰减的 R，不得声称已验证长期凝固。

17.4 反证与重复实验。重复来源不得造成无界变化；分别检查普通多根与严格单根通路的正向作用和拒绝条件。有效反证进入后按规则阻止、修订或补偿长期变化。记录与状态须支持结构重放；行为重放仅在声明的确定性条件下要求一致。

17.5 退化实现排除。恒等 G、恒等 C、常量 J 或对 m 不敏感的模型，应无法同时通过预设的正向功能验收。不能仅靠“没有违反禁止项”认定完成实现。

17.6 报告边界。通过结构验收意味着路径、状态和约束得到落实；通过功能验收意味着在已测场景中观察到经历驱动的可塑作用。两者均不证明主观意识、普遍人格连续性或所有场景下的稳定性。

17.7 快速状态因果充分性与消融。固定当前输入/规范表示、事实投影 c、R、θ、协议、必要运行条件、模型版本和抽样条件，并禁止被测快速路径重新读取未声明的 H 细节；仅改变预先设计的近期经历路径，使其产生不同 x，检查指定 Tₓ 内是否出现可重复的近期状态/行为差异。随后将 x 统一钳制到同一标准状态；若这些短时差异仍完全保留，则不能把结果归因于 x。删除或压缩候选 x 自由度后若不降低预先定义的近期预测/控制指标，应优先采用更小表示。

17.8 IRL 鲁棒性与语义身份实验。对同义改写、否定、模态、引语、纠正、歧义指代、结构化工具结果和新造词构造测试集。应在保留 provenance 的前提下，使等价语义尽可能解析到兼容 ConceptRef/限定符；无法确定时输出 unresolved/provisional 而非虚构。将错误 schema、错误来源标签或概念别名映射注入候选层，核心应由 validator/canonicalizer 阻断或显式降级。

17.9 R 自由度因果可区分性与消融。保持当前输入、事实证据 c、x、θ、协议、模型版本和抽样条件一致，仅改变预先设计的历史路径，并禁止通过事实检索泄漏被测历史区别。若某个 active χ/K 被声称为必要自由度，则钳制或移除该作用后，应在声明 T_R 与测试域内丢失相应可重复的内部状态转移差异；若差异完整保留，则不能把该自由度视为因果必要。

17.10 R 最小性与非退化实验。对未来等价的历史改写、重复来源和仅有事实内容差异的样本，系统不应无界增加 χ/K；对确实存在历史依赖因果差异但当前 R 错误合并的样本，恒等或固定维度且不能细分的 G/R 实现应无法通过测试。通过该实验仅说明在已声明测试域内实现了必要而不过量的可塑历史区别，不证明获得唯一心理学表示。

# 18 修订说明与实施结论

本版以 v0.6.3 为直接基线，保留其事件日志、入口幂等、事务提交、x 快速因果状态、IRL、凝固预算、行为审查、重放、身份与行动时机主架构，并新增 R 的本体闭包。新增内容包括：以未来核心状态转移的因果可区分性定义 R 的存在与最小性；以历史区别 χ 表示必须保留的非等价历史；以条件化因果耦合 K 表示该区别对未来核心转移的非冗余作用；规定 χ/K 不预置心理语义、K 不构成第五个核心状态、候选不得自证、正式 R 作用受来源饱和与行为连续性约束，并要求 K 凝固到 θ 后避免 R/θ 双重作用。

主架构仍为经历、规范表示、快速状态、痕迹、凝固与长期动力学构成的可塑过程。核心演化必须具备可追溯来源、有限贡献、显式调制与可测行为后果；IRL 允许黑箱参与语义理解，但要求因果边界透明、身份可追溯和非法候选可阻断。工程实现应先绑定机制配置，再以结构验收和功能验收分别证明路径正确与作用有效。

v0.6.4 主架构继续冻结，作为下一阶段 R/χ/K 的可施工表示、G 塑形算法、θ 载体与 F/G/C/J 机制深化和验证原型开发基线。冻结的是职责边界、状态/表示合同、R 的未来等价与最小细分原则、χ/K 的本体关系、来源与事务约束；不代表 χ/K 的具体数据结构、K 的函数形式、G 的评分/辨识算法、数值预算或非文本调制接口已经获得唯一答案。具体实现必须绑定版本化配置，并通过第 16—17 节验收后，才能被认定为满足本规格。

# 19 后续工程约束与扩展议题

本节记录已经确认重要、但不作为 v0.6.4 当前核心机制闭包前置条件的工程问题。它们必须在面向长期真实运行前形成单独合同，不能因暂未实现而被遗忘，也不得反向污染本版的核心状态语义。

## 19.1 响应延迟与交互关键路径

完整事件链包含入口处理、时间推进、事实取证、IRL、F/G/C、提交与行动生成，但普通对话不得因此退化为多次串行大模型调用。实现须分别测量入口/IRL、核心状态转移、凝固审查、模型生成和端到端用户可见延迟，并报告 P50/P95 或等价分位指标。

确定性 adapter、schema 校验、时间推进和常规资格预检应尽可能本地化。绝大多数不满足凝固资格的普通事件应快速排除，不启动昂贵的候选审查。若 C 的深度审查、行为探针或外部模型调用会阻塞交互关键路径，后续版本必须定义不破坏原子提交、因果顺序和版本一致性的分阶段/异步协议；在该协议未定义前，不得以“后台慢慢算”绕开第 5 节事务合同。

运行协议应规定任务响应的可接受延迟预算与降级策略。性能优化不能通过跳过来源校验、IRL 验证、幂等提交或使用未提交状态生成正式行动来换取。

## 19.2 多端共享状态、容灾与快速切换

设备不是工程身份本身。手机、电脑及未来其他终端应被视为同一合法 lineage/branch 的不同感知与行动入口，并引用同一权威提交状态。终端丢失或损坏不应在存在完整远端检查点/复制状态时导致核心身份链自然终止。

多端写入必须防止 split-brain。首选单一权威提交源/日志领导者，或采用能够提供等价线性化提交语义的共识机制；任何方案都必须保证同一 branch 的 H、x、R、θ、L、Q 与处理位置具有唯一提交顺序。离线设备产生不可线性化的独立发展时，不得静默合并为“同一历史”，应显式形成分支或进入有审计的冲突处理流程。

容灾应使用加密的增量复制与周期完整检查点，复制范围至少覆盖完整可恢复状态 (S,Q)、manifest、IRL/Concept Registry 版本、随机/外部返回记录及未完成行动生命周期。恢复点落后于最近提交时必须显式报告丢失窗口，不能冒充无损连续。

多端切换的目标不是搬运一个巨大 prompt，而是在新终端快速绑定最新已提交检查点、待办与行动生命周期，并根据当前时间锚点重新计算只读投影。上下文窗口、UI 会话和设备缓存均为可丢弃视图，不得成为唯一保存连续性的地方。

## 19.3 本节地位

响应延迟、多端复制、终端切换和容灾属于后续运行时/分布式工程合同。它们不改变 F、G、C、J 的核心数量，也不直接赋予系统新的成长证据。后续版本若将这些机制正式纳入验收，应单独规定一致性模型、故障假设、密钥与权限边界、复制确认语义以及端到端性能目标。
