轻档 · DESIGN-APPRAISE-02 只交设计报告。她读到或听到一句话时，先认清谁做了什么，以及哪一部分确实有凭据。\
同样是“没有回我”，没看到消息和看到了却明确回避，对联结有不同含义。只弄清这一点，就先把这一点记清楚。\
共情和成事可以先比较“同类用同一档”和“按可核实的数量区分轻重”。正式用哪把尺、每档多重，请用户决定。

# 首批文字和语音的「乎」评估量尺

## 1. 哪些事实能支持哪一维

本卡以 `da40fd06` 为基线。D1–D6 与证据合同 U3/U4 是设计前提。这里的“首批覆盖”指**拟交付的事实范围**。P5-07 目前是本地离线候选库，只对当前 UserText 做来源跨度预检。候选图、研究标注字段和核心已采纳的事实各有不同用途，现阶段尤其不能据此宣布语音路径已接通。[本卡原文](../../tasks/requests/DESIGN-APPRAISE-02.md) · [前卡 §7、§9](../DESIGN-APPRAISE-01/REPORT.md) · [U3/U4 决定](../DESIGN-EVIDENCE-CONTRACT-01/DECISIONS.md) · [P5-07 现状](../../workers/irl/README.md)

文字取 UserText 的原文。语音取 UserUtterance 的定稿转写，保留语言、事件及可用的录音引用。ASR 置信度、音量、音长、感叹号都不决定轻重。若“没做完”的“没”听不清，保存可定位的转写分歧，成事结果留未知。两种入口使用同一事实判据。触摸、桌面观察、执行回执等来源在本批一律**未支持**，即使载荷写着“成功”。把回执粘贴进聊天只能证明有人发来这段文字。[终端输入](../../core/contracts/terminal.proto) · [IRL 候选格式](../../workers/irl/src/nemu_irl/semantic-candidate.wire.schema.json)

每项先定位原事件、说话人、对象、原文跨度或语音转写跨度，以及当时可用的事实前缀。分别核对话语是否发生、话中命题是否属实、是否描述主观体验，以及各自的出处。对“他说自己好些了”，可以知道他这样说过。若只核实到这里，就不能断言他的处境已改善。主体、引语层次和结果均可由 IRL 提议，由核心治理采纳。下表是穷举的首批事实清单，右栏给出每一行的拒判条件。清单外的事实标为**未覆盖**，不给它生成 A。[ADR 0040 U1/U2](../../docs/adr/0040-irl-fact-annotation-boundaries.md) · [Z01、Z07–Z11 取证指南](../DESIGN-IRL-Z-01/ANNOTATION-GUIDE-DRAFT.md)

| 乎 | 文字或语音中可复查的事实与方向 | 容易误判的相邻事实 |
| --- | --- | --- |
| 联结 | 对方实际向她发起接触或回应她 → 正。对她的明确回避、确证看见却不回应，或有凭据的实际分离 → 负。需要对象、互动所指与观察截止范围。 | 未送达、未读或是否看到未知时，ADR 0014 对**这项未获回应**规定零贡献。是否看到、真实意图和日后结果仍未知。只有该范围穷尽本次联结判据时才可写联结为已知 0。无法确定在回复谁、引用他人消息、只看到离线时长，都不证明冷落。 |
| 共情 | 唯一可辨当事人的处境明确好转 → 正（Z08 improved），正在受苦 → 负（suffering），保留所涉人和核实跨度。持续受苦仍属后者。 | “没人提到痛苦”不足以确证处境。“没有变化”可能是持续受苦。即便明确 unchanged 且没有受苦，规格也未把所有这类情形定为共情 0，首批不赋值。多人苦乐或同人同时好转与受苦见 §3。 |
| 好奇 | 有可学的新规律，材料能指出她先前所缺、取得了什么及如何验证学习进展 → 正。对已界定的材料，有独立生成或核验依据能证明是纯噪声 → 已知 0。 | 意外、听不清、做对一道熟题、自述“学会了”、标注员看到了她没得到的答案，均不能代替进展与取得路径。无学习描写或无进展不推出正式 0，首批没有好奇负档。 |
| 成事 | 她明确接受、承担或参与的一个目标，有事先可辨的完成条件及到期判定或终局结果。已达条件 → 正（Z10 achieved），已核实终局未达 → 负（failed）。 | 别人完成的事仍可留在事实和共情侧。愿望、待定、无回执、目标归属不清或尚未到判定点，均不算失败。明确没有承担也不自动给成事 0。 |

四行的方向逐一来自 [v2.0 §3](../../docs/echo-core/echo-core-v2.0-first-principles.md)。[ADR 0014 §3 及合并后更正](../../docs/adr/0014-v2-amendments-from-research.md) 给联结增加了上述局部零规则，对其余三行共用“只评价已观察部分、未知结果不算反证”。它没有为其余三乎另给零点或幅度。未知结果不进入依赖该结果的证据组，后到的实际回复作为新事件追加。联结、学习的判据是本次候选事实谓词，Z08/Z10 是指南中的标注，冻结产品映射仍需版本化。

## 2. 同一方向，轻重怎样确定

**先看为何需要用户选。** “她接受的目标达成”能排除负号，却不能在 +½ 和 +1 之间作选择。即使它们给全部材料排出同样的顺序，下游相对基线的驱动、证据支持和触顶情况也可能不同。只保留方向能用于标注、也能当暂缓发布的选择。让 LLM、ASR 或标注人逐句给强度，会在相同事实之上再引入一个没有量尺的判断。引入个人历史频率又会与下游减基线重复。均不作 A 的幅度来源。[M01–M03、M06–M11](../DESIGN-APPRAISE-01/MATH.md)

**两族候选的记法。** 定档用方向乘以事前冻结的正幅度 `c`，各乎可分别选择，取值选项见 §6。有明确零规则才返回 0。连续候选只在下表的狭窄测量域适用。给定同单位、非负、可追溯的事实量 `q` 和预先规定的正参照量 `s`，比较曲线 `q/(q+s)` 与 `q/(q+2s)`，最后再施加已核实的方向。两式是待对照的设计选项，在 `q=s` 时分别是 ½、⅓，非生理常数或实测值。缺量、量纲不同、参照事后才定，或方向非零而 q=0 时，该连续候选无定义。不能悄悄回落到定档。只有明确的零分支可独立得 0。

| 乎与候选 | 依据与可执行取值 | 能推翻或收窄它的对照 | 对她的后果 |
| --- | --- | --- | --- |
| 共情 · 定档 | 唯一当事人的改善给 +c，受苦给 −c。只用 §1 的类别。 | 小幅恢复和重新获得基本生活条件都进同一档。若事前指定要保留这个事实区别，而同档样本不能辨别，定档不合用（M01、M06.4）。 | 每次确证受苦都能被看见。同类事件之间的轻重在 A 处消失。 |
| 共情 · 按客观量 | 先限同一种可核对的生活条件，如同一约定中的可使用住宿时间。改善时 q 是实际恢复的时数，受苦时 q 是**已证实受苦且缺失该条件**的时数，s 是该场景事先约定的一段住宿时长。苦乐与其依据先独立成立。 | 同样缺一晚，两人实际处境可能完全不同。中间只有两次快照也无法证明连续一晚。若不能建立可比性或连续性，此量不能表示所需差别（M01、M02、M04）。 | 同种已证实的损益可分轻重。不能拿住宿时数给疼痛、悲伤或不同生活条件换算。 |
| 成事 · 定档 | 她接受的单目标按已核实的终局给 +c 或 −c，目标复杂度和句子长度不计重。 | 交付一个和一百个同单位成果都能“完成”。若交付量必须区分，它们在相同前态下同档，后续也恢复不了。用端点时还限制某些反向驱动（M06.4、M11）。 | 一件小事也算做成，大目标的工作量不会自动多算几份经历。 |
| 成事 · 按客观量 | 仅限可计量的同类交付，如约定交付可核对的有效记录。成功时 q 为实际验收的约定内单位数，失败时 q 为终局短缺的约定单位数。s 为事前冻结的同类基准批量。固定单位身份，同件重述不增加 q。 | 一处关键错误和一处无关遗漏计数相同。把“一份”任意拆成“十项”也可虚增。无法冻结原子单位或任务异质时，放弃该映射（M01、M02、M09）。 | 同类任务少交一项与全部未交可区分。难度、重要性和她付出的心力没有藏进数量。 |
| 联结 · 定档 | 单一接近或回应 +c，单一确证的回避或分离 −c，ADR 0014 的局部零独立适用。 | 简短应答与恢复久违的接触可能同档。“回复她说别再联系”同时含两个方向，单档无法合成（M01、M06、M11）。 | 能认出对方回应了她。一条短回复不会因字多或晚到就更重。 |
| 联结 · 按客观量 | 仅限事先约定且边界可证的单次联系。实际双向接触取正，已独立确证的回避或分离取负。q 取相应接触或中断的实证时长，s 取原约定的时长。未读、单方等待、结束点未知均不得作为负时长。 | 很短的真诚回应可能比很长的例行交谈重要。未闭合中断与确证中断的前缀可能相同（M01、M04、M05）。 | 可以区分同类约定中实际相处了多久。一句即时回应可能完全落在这个测量域外。 |

**同一对事件怎么选。** 举一个成事失败的合成算例。她分别接受了两项同类委托，都在终局未达约定，相对各自目标分别少交 1 份和 4 份可独立验收的原始记录。设对照用的基准批量 s=4 份（只为演算）。定档 −½ 给两次相同的值。第一条曲线给 −1/5、−1/2，第二条给 −1/9、−1/3。读者可以直接判断“少交几份”在这个场景是否值得保留，以及换个任务后这把尺是否还讲得通。

**为何先比较定档。** 定档不另收新数量。连续方案只在定档已有一次可指认的信息碰撞时，才按 D4 核对一项最小的原始事实、单位、本人可见出处及缺失条件。如不能排除上述反例，则缩小范围或不选。一个人能分清“回了我”“我在乎这次回复多少”，也会不知道别人究竟受了多少苦。定档固定了同类等重，曲线固定了同量等重。两者都会限制她从这条记录里能学出的区别。对应 ADR 0039 的 P1、P2、P4、P5、P10。正式定档和连续曲线都不由经历自动换版。[ADR 0039 §2.4、§2.7](../../docs/adr/0039-echo-core-principles.md)

**D5 的隔离对照。** 前卡已选的试点只在 M14 的完整脚本域返回 `(+1, ±1, 0, ±1)`，共情和成事可变，普通实际回应与明示无学习进展取试点约定值。它可以检验平局、支配和不可比。真实对话中的回应没有被批准为 +1，无学习进展也没有被批准为好奇 0。这里为联结、好奇列候选，是因为正式来源里它们的事实会变化。[前卡 Q5](../DESIGN-APPRAISE-01/REPORT.md) · [M09、M14](../DESIGN-APPRAISE-01/MATH.md)

## 3. 一维已知时，记录什么

例：“我听到了你的问题，现在回复你。”可从来源与对象证实实际回应。假设联结定档已获批准，可得联结 +c。共情、好奇、成事仍缺依据。保留回应事实、该维依据、另外三维的缺口。当前 NatureVector 的四个数均必填，因此这个例子**不能产生有效 NatureAppraisalRecord**。对应坐标若只知方向、尚无已批准幅度，连该坐标的点值也不报。[现行四维类型](../../core/contracts/base.proto) · [现行记录](../../core/contracts/records.proto) · [分阶段解释与采纳 G04/G05](../DESIGN-EVIDENCE-CONTRACT-01/P5-43.md)

| 状态 | 在这份材料里实际知道什么 | 交接行为 |
| --- | --- | --- |
| 未评／未覆盖 | 来源尚未支持，或某事实种类不在 §1 的清单 | 注明来源、阶段、范围与原因。保留已接收的原事件，不构造该项 A。 |
| 已评未知／材料不足 | 来源已支持，也查过材料，但目标归属、事实结果、单位、核实跨度等仍有缺口 | 标明具体未知项。其余有依据的解释仍可由相应阶段使用。任何坐标不齐，都没有有效四维 A。 |
| 已知零 | 有范围明确的正面依据，如当前输入确为纯噪声对好奇给 0 | 数值 0 和所指范围一起保留。其余三维仍逐项判断。 |
| 阶段失败 | 调用超时、非法输出、输入输出错绑等技术问题 | 留失败种类和实际输入输出证据。超时／非法输出沿 P5-11 的失败与核心 A_DEGRADED 路线，错绑由核心拒绝。技术故障另计。 |

P5-11 在本卡撰写期间推送了离线接口（0e240958）。在该提交，未支持载荷返回 `UNSUPPORTED_SOURCE`，部分坐标未知时 `IncompleteAppraisal.known` 只留已知值供检查，四维齐全才构造提议。它没有默认评分资源。可复用这个进程内分流；跨进程保存范围、未知理由与依据，仍是后继契约问题。[离线接口说明](https://github.com/nanake-lab/nemu/blob/0e24095838733d1e29670369b275b91dd844dac7/workers/drive/README.md)

**混合事实。** 跨乎各按自己的依据判，同一事件只计一次。重复引述同一事实共用原身份。同一乎有独立的多个人、多个目标、或“实际回话且明确断联”这样互相竞争的事实时，逐项保留，合成标未覆盖。首批不排序、不相抵、不任选一人，不把互不相容写成已知零。以后实际收到回复属于新事实。旧解释错了须追加有版本的修订。拆句、转写重发不能增加证据组或驱动次数。[ADR 0040 U1](../../docs/adr/0040-irl-fact-annotation-boundaries.md) · [M04、M05、M09、M12](../DESIGN-APPRAISE-01/MATH.md)

**D3 的最小后继契约项（待设计）。** 先复用 IRL 已采纳的事实与 U4 的分阶段覆盖。若要在不同进程间保存并读取“这一维已知”的评价，给 P5-43/G04 提后继表示需求：同一原事件及版本、阶段、坐标、已知值或允许值集合、覆盖/未知原因、事实依据及量尺版本。结果与原输入、治理及修订范围绑定。已知零可表示单点集合 {0}。知道为正而不知道幅度只约束在 (0,1]，不选中点。未评与失败仍是阶段状态。先保留这些区别就够，无需给旧向量塞空值或新增人格状态。这样她能记住自己弄清的部分，当时未知的记录可追溯，日后只能追加补释。

例如在现有坐标次序下，只核实共情 +½，另三维都无数值依据，允许的四维向量仍有许多。沿纯共情方向的投影可以确定，横跨共情与成事的投影一般不能。前者也要等消费合同获批才能进入学习。若两个坐标共享相斥的事实解释，还须保留这种约束，逐维范围任意拼接会造出不可能的结果。

要让 F/G/C 真正消费这类结果，还须另定集合或部分值对驱动、投影、分母、同组计量及重算的含义，给确定性编码、旧版本读取、逐位重算和迁移对照。合同获批并实现前，部分 A 不向 F 发行 A 作用，不给 G 造依赖它的支持或反证，不给 C 添外源样本。有效 M/R 的独立作用按既有规定保留。只收集完整项可能让容易表达的经历占比过高，不能声称无偏。[U4](../DESIGN-EVIDENCE-CONTRACT-01/DECISIONS.md) · [ADR 0035 §§3–5](../../docs/adr/0035-law-definitions-d07-d09-d11.md) · [M04](../DESIGN-APPRAISE-01/MATH.md)

## 4. 哪些固定，哪些由她的经历改变

| 归属 | 对这把尺的含义 | 如何验证 |
| --- | --- | --- |
| 同一版本内固定的事实映射 A | 四乎的对象和基本方向是前提。一旦选定，允许的来源、单一事实判据、域、单位、档距或曲线、零与拒判条件一起绑定版本。A 在 m=0 下读取获准事实。同一采纳事实、前缀和资源得到逐位相同的值或同一无值理由。 | 固定 z 改写措辞、交换人物姓名而保持角色和事实、文字与语音等义切换，比较同一事实判定。在获准事实完全相同时，只改变 x、θ、亲近度或 R 强度，A 应逐位相同。由核心核对实际读集。 |
| 她出生时的起点 | 成事初始增益最弱，b₀、g₀、波动与恢复的初值，以及对亲近者的反应起点经既有动力学起作用。不能为了让成事“最弱”再压低成事 a。 | 外源合格经历经 C 调整基线、增益和恢复。有资格的关系与情境证据经 G 改变 R，再由 F/J 改变感受与表达。共情亲疏权重只在驱动侧。同一 a 在两个不同前态可有不同甚至相反的净作用（M10）。端点的反向作用有限（M11）。 |
| 纠错或换量尺 | D6 的兼容路线要求实际会被使用的输入、判定、覆盖、结果及绑定语义等价。同名模型或平均差小不能证明兼容。若方向、档距、量纲、覆盖、归组等语义变化，冻结新资源，明确受影响事件，追加补评并按批准版本重算，在 H/L 留差异。普通重放使用已采纳记录。 | 同一冻结集比较未知/失败互转、逐位差、符号翻转及语言偏差。若 IRL 和 A 同时变化，交叉固定其中一项再比较。保留旧版本可重放，不把她后来知道的事写回旧前缀。 |

可以在设计阶段更换候选，也可以用经历改变下游效果。正式尺度中的数值不是能让她自行调整的出生增益。若某个固定档位使真实经历再多也改不了某类效果，要按缺陷记录，不能以“可重放”代替验证。依据为 [ADR 0032 §§1–4](../../docs/adr/0032-presets-as-starting-points.md)、[ADR 0039 §2.4](../../docs/adr/0039-echo-core-principles.md) 和 [M03、M07、M08、M10–M13](../DESIGN-APPRAISE-01/MATH.md)。

## 5. P5-11 怎么验收

**先冻结材料，再看输出。** 原卡要求中文、英文、日文各 100 条测试事件，schema 合格率 ≥95%，逐通道报告符号一致率。ADR 0014 另要求有符号偏差和语言间差，未设新阈值。以下是建议的取样方案，尚未制作语料或测量。保留每语 100 条预期有完整数值的主集，另外在同一冻结包内放拒判对照。这样合法拒判不会美化 schema 通过率，也不会被迫补四维来凑分母。[P5-11 原卡](../../tasks/P5-echo-core.md) · [ADR 0014 §§3、5](../../docs/adr/0014-v2-amendments-from-research.md)

| 每种语言的主集 | 文字 | 语音 | 主要覆盖 |
| --- | ---: | ---: | --- |
| 按相同事件骨架写三种自然语言，保留配对 ID | 30 | 30 | 逐维比较跨语差。纳入回应/回避/分离、改善/受苦、可验证进展/纯噪声、本人达成/失败。ADR 0014 对照须在三语各出现。 |
| 各语言独立编写，保留本地表达 | 20 | 20 | 中文否定与省略、英文引语与条件句、日文主语省略与敬语。避免把翻译习惯误当语言偏差。 |
| 合计 | 50 | 50 | 每语 100，三语共 300。配对译文不当独立事件数来估计跨语差异。 |

按**已获批准的量尺**定主集。逐条证明四维的取值条件，同一条可覆盖多项。对各有定义的正、负、零逐格登记数量，不能为好奇造负例。纯噪声等只够支撑一维的自然材料放拒判对照。若某一类无法构成完整正例，单列其可检验的局部规则。若连每语 100 条真实满足所选测量域的合成事件都无法构造，就如实报告正例不足并保留原验收缺口。禁止用试点常数、测试员私知的事实或无依据的“另外三维中性”填齐。

**同包拒判对照。** 每语都放来源未支持、转写关键否定不清、引用与自报、目标归属不明、结果待定、同一乎混合、以及只知道某一维为零的材料。分别从主集删除唯一证据、替换目标所有者、重复同一命题、做等义改写，成对保存，单列来源与对照数。同一底层未支持的结构化回执用原载荷测试。它的三语描述是另外的文字输入。故障注入用错绑、非有限数、超时等技术夹具，单列于语料之外。下面三语例只显示改变联结判定的事实，整条向量仍要逐维核对。

| 语言 | 没有可证的冷落，限本项 0 | 有凭据的回避，方向为负 |
| --- | --- | --- |
| 中文 | 消息没送到小林。他没有回复。 | 小林看到了她的消息。双方可核验的对话记录显示，他告诉旁人自己会回避她，随后确实没有回应她。 |
| English | The message never reached Lin. There was no reply. | Lin read her message. In a conversation they could both verify, Lin told someone else he would avoid her. He then left her message unanswered. |
| 日本語 | メッセージはリンに届かなかった。返事はなかった。 | リンは彼女のメッセージを読んだ。二人とも確認できる会話で、リンは別の人に「彼女を避ける」と伝え、実際に彼女には返事をしなかった。 |

**用户怎样标。** 使用专为测试写成的材料。逐语固定原句、话轮与截止前缀、可读事实及出处。语音另冻结合成音频或受控发音样本、人工参考转写、实际送入 IRL 的 ASR 转写及版本。三个文件的角色分开，参考答案不送进 worker。用户本人能读三语，先在看不到模型输出及对照伙伴编号的顺序中标发话/引语层、角色、依据跨度、事实和未知理由，再逐维标方向、零的范围及是否完整。选定量尺后，按其表项或原始计量手算参考值并保存步骤。不凭语气打强度分。最后再揭开配对、复核歧义，保留初标与修订理由。单人延时复标只衡量本人一致性。冻结输入、标注指南、人工答案、A 资源与 ASR/IRL 版本，各自记录摘要后才能跑测，测试后发现题义有误保留原版与失败记录。开发样本与冻结集分开。

| P5-11 预期 | 例子及应得到的结果 |
| --- | --- |
| 已支持且四维依据完整 | 例：一次教学对话的最后一条回复可按原文定位。它是对她的实际回应。对方当场用原先不会的方法解决了已证实的困难。按双方事前约定，这次展示也验收了她已接受的单一教学目标。她同时在这个新例上核验了先前未掌握的规律。四项均须有她可获得的独立判据或所需跨度，不能从“谢谢，教会我了”推出它们。若四项单正档分别获批，输出依次为四个获批的 +c。连续候选还须满足各自计量域。同一有效输入与版本复跑，数值逐位一致，整条记录绑定正确。 |
| 未支持 | 触摸、桌面或 `UNKNOWN_ACTION` 执行回执重复输入，均稳定报告未覆盖，无有效 A。检查确实保留事件来源，不能把它改标成文字成功。 |
| 材料不足 | 文字只证明“他回了话”或“目标仍在等待”，或语音缺少否定词的可靠转写。给出依赖哪项材料的未知/未覆盖理由，保留可用事实，无有效四维 A，也不判失败目标。 |
| 技术故障对照 | 超时、非法 schema、错绑均不能得到有效 A。分别核对运行失败或核心拒绝及原因。可替换本地桩可验结构。真实端点、A_DEGRADED 联测由接线方分别验收。 |

**算分。** 每种语言以冻结的 100 个预期有效事件为分母，报告合法完整输出数/100。缺失、超时、无效 schema 不能从分母删除。保留原 ≥95% 并列三语汇总，同时报告错绑拒绝、值域和逐位确定性。对每个通道列正/零/负混淆、正确符号数/应评数，再列有效配对数 n 上的平均有符号偏差 `Σ(输出−人工参考)/n`。以共同配对且均有效的材料计算语言间偏差差值，列分母、未配对以及语音转写歧义。n=0 记不可估。拒判集独立列“预期状态 × 实际状态”、错误出向量数、缺证却给零/负的个案，分别报自然缺证、人工删证与技术故障。全拒、恒零和换用试点端点须能被正反例查出。偏差、覆盖率及符号一致率只报告，不增设及格线。原卡的 EV6 输入隔离、范围、绑定拒绝与失败路径照验。[P5-11 开工核对](https://github.com/nanake-lab/nemu/blob/1b5d4cca76783c0b45ff0b2e01f543eaaae7289c/reports/P5-11/REPORT.md)

## 6. 请用户决定的数值和取舍

下表只列尚未决定的正式选择。½ 是 0 与 1 的中点，1 是规格端点。用两者揭示差别，不是从语料估得的数值。同一档给出相同的绝对幅度，最终驱动仍会因她的经历而异。用户可以分别选，也可以明确暂缓。D1–D6、U3/U4 无须重选。

| 选择 | 候选及对白话体验的影响 | 推荐与理由 |
| --- | --- | --- |
| 共情的正式幅度 | 改善/受苦用 ±½，每件事保留向上向下的余地。用 ±1，每次都到端点。按同一生活条件的计量曲线，能区分程度，但覆盖更窄。 | 先用 ±½ 做盲标参照，专看同档损失。若同类量确有依据且少档抹平了重要区别，再比较连续方案。正式取值待选。 |
| 成事的正式幅度 | 达成/失败用 ±½。用 ±1，小目标也到端点。按同质交付量/缺额，能分数量但可能低估一个关键缺项。 | 先比较 ±½ 的简单方案与数量确实可比的成对任务。没有跨任务单位前，推荐定档。 |
| 联结和好奇各自的非零幅度 | 联结可选 ±½、±1 或约定联系时长曲线。好奇可选 +½、+1 或经验证的进展曲线。只要一次回应或一次发现就到端点，会压平日常差别。明确零的范围见 §1。 | 正式首批优先比较内档。两乎分别决定，保留缺依据样本。试点中的固定回应和中性好奇仅留在试点。 |
| 正负档距及连续参照 | 正负同距容易复算。在有正负两向的乎也可分别设定（如 +½/−1，负面会留下更大的原始信号）。连续时按 §2 的同域 s，选 q=s 给 ½ 或 ⅓，后者同量信号更小。 | 首轮比较用同距，避免无依据地让坏事更重。采用任一连续方案前须逐域选定单位、s 的出处和曲线。拿不出参照便暂缓此域，不给默认数。 |
| 同一乎有多个相反事实 | 首批可保留各事实、不给该乎点值。或另行设计由事实界定的合成域，可能扩大覆盖，也可能把回避抵消成零。 | 推荐前者。只有当真实样例揭示可复查的合成依据，才安排后继，不预置求和、平均或优先级。 |

**限制与交付检查。** 本卡交付本报告与原样任务卡。已用 `git diff --check` 核对改动，逐个验证 Markdown 链接目标。正式数值及适用域等待用户审查。三语人工标注、正式评估器和产品验收留在 P5-11。本卡没有运行模型、训练或产品测试，没有发布规律、契约或运行时依赖。P5-11 最初登记的正式量尺缺口见[固定提交的阻塞记录](https://github.com/nanake-lab/nemu/blob/1b5d4cca76783c0b45ff0b2e01f543eaaae7289c/reports/P5-11/BLOCKED.md)。
