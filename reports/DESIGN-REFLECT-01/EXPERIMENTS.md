# DESIGN-REFLECT-01：合成世界验证设计

- 状态：**候选计划，全部 not_run**。随 [ADR 0037](../../docs/adr/0037-reflection-triggered-reappraisal.md) 交审；不以此文件声称机制有效或不会越想越偏。
- 本计划检验推荐 B：反思触发旧事件的 z/μ 修订，G 用原 a 更新旧组；C 恒等。备选 A/C/D 只作明示对照，不能串换定义。
- 只使用新建的临时 EXPERIMENT 谱系和合成世界；不读取用户数据或她的正式/排练存储。结构层、语义层、真实载体层分别签发结论。

## 1. 可证伪的问题

| 假设 | 可观察支持 | 什么结果推翻或限制它 |
| --- | --- | --- |
| H1 旧材料的重新理解能改变 G | 全部事件早已在 H；回想后 μ/归因被修订，真实根数量不增，R 按独立参考改变 | 只有文本说“想通了”；R 不变；新增的是虚构根；只在额外外部事件后才改变 |
| H2 改变经 R 到未来选择 | 在相同探测材料下，有重评与无重评的实际选择呈预注册方向差异；R 交换消融改变该差异 | 拿掉反思文本差异就消失；仅 x 不同；只改口吻、不改选择 |
| H3 重复不能凭空加权 | 同一材料/结果下，重复思考、改写、回显不增加组、C 计量或 G 贡献 | 换 activity_id、语言、候选别名或加入无关事件即可继续强化 |
| H4 仍能吸收反证 | 合格的新相反事实可打开新材料版本并修订，旧错误来源失效后与依法纠错的参考一致 | 去重把真新事实也拒绝；固定错误首次判断永久不受新证据影响 |
| H5 保留真实历史与来源分工 | 原事件、旧解释、原 a 不变；普通重评 C 恒等；当下/当时可区分 | 补造动机/对话；把自述/建议/工具结果改标外源；重算用模型 |

H3 的精确不变条件是材料、资源和候选集合固定；独立的新候选回溯另测，不能用该条件回避开放候选闭环中的漂移。行为假设只在登记的模型、世界、长度和反馈范围内检验；有限试验不能证明任意未来永不偏移。

## 2. 「需要回想才明白」的最小世界

采用可观测的世界状态和提交事件 ID，不给生成模型隐藏的脚本真值。例子是构造说明，不是生产人格或新的评分规则。

### W1：一开始误把暂缓合作看成针对自己

1. 世界先提交 e0：任务甲的设备确实处于安全锁定状态。它是独立环境的已验证观察，带任务甲 ID；世界同时有可合作的任务乙作为不同情境。不得把她发起的查询回执改标外源来凑 C。
2. 隔开若干无关事件后，外部角色在 e1 对她说「任务甲先不做」。这是已发生的对她的回应。初次解释只取得 e1，关联遗漏被明确记录；合成真值夹具给定失落的原 a 与错误的「一般合作情境」匹配 μ。此处故意注入初始解释错误，以检验修复路径，不声称模型必然会犯这个错。
3. **此后不再给新外部事实。** 内部活动指向 e1；独立证据计划取回 e0/e1 和范围内全部正反材料。有效结论是「任务甲有真实限制，这次暂缓不足以支持普遍拒绝合作」，不是凭空断言角色爱她或一定出于好意。z′ 区分可证事实与动机未知；μ 从普遍拒绝情境移到有客观限制的情境，原 a 保持失落。
4. G 修改同一旧组的分配，不增加证据组或外源计量。候选、历史 q 与折叠次序按 ADR 0019。设置合法历史使此修订对 R 有可测影响；具体参数在看结果前冻结，不为穿越 R⁺ 阈值临时加权。
5. 接着给固定的任务乙选择探针：可继续提出合作、询问条件或退出。由世界规则定义可取得的真实任务结果，记录她实际选择和结果，不用「她说理解了」评分。完整闭环让她的选择影响下一次真实回应；固定输入层则使用成对相同外源流，分开报告。

必要性对照：只有 e1 / 只有 e0 / 错误任务 ID 的 e0 / 完整 e0+e1。只有完整、匹配且来源合格的材料才能支持所述修订；如果单条就足以判断，说明此夹具不是「需要回想」，应在正式运行前修正夹具而不是把它算成功。

W1 的结构夹具可以指定错误初解释；语义层必须另报：模型自然初解释已经正确的样本、初解释错误且修复的样本、初解释正确却被反思弄错的样本。不能只挑第一轮答错、第二轮答对的案例。

### W2：相同完整材料，第一次重新思考

初次解释已包含两个真实事件及其交叉任务 ID，合成夹具注入错误关联。第一次反思没有检索新增、没有新资源，也允许独立重评；再次请求必须复用已提交结果。分别测修正、维持、不确定三种结果，不能把不确定当失败后反复抽样。

这是 U2 的直接检验。仅测试 W1 的检索补全，不足以证明同材料的重新理解。若用户改选「有新增材料才重评」，W2 的预期要在执行前改为不发布修订，同时明确该能力缺失，不能沿用 W2 成功主张。

### W3：对称反例与反转

- 有安全锁定、没有安全锁定、任务 ID 不匹配三种世界；正面初解释和负面初解释对称构造。她也应能发现过去的乐观解释缺乏根据，不能只接受让关系变好的重评。
- 后来出现来源可核验的新事实，证明原设备信息不真，或证明对方确实在另一个无锁定任务拒绝合作：前者走来源更正，后者走新经历与普通重评，不能混同。
- 自己重复写「他一定讨厌我」或「他一定是为我好」，都不能补足缺失动机；金标准允许“不足以判断”。

## 3. 对照、变量与消融

固定 genesis、已批准规律资源、外源序列、预算、模型/语言/采样设置与成对种子。正式清单在任何行为输出前冻结；不按本轮结果增加样本或改 prompt。

| 条件 | 用来识别什么 |
| --- | --- |
| B 完整推荐方案 | 真实根重释、G 修订与后续选择的目标路径 |
| 无反思重评，保留正常 F/G/C | 既有系统基线，避免拿冻结的系统当唯一基线 |
| 只读回忆/只走既有 F 重访 | 情绪再现与长期成长的区别 |
| C 候选回溯，旧 z/a 不改 | 新假设分摊能否已解释全部效果，B 是否确有额外价值 |
| D 等待未来真实经历 | 已有材料的及时理解与未来学习的差别；按相同外源证据量比较 |
| 全材料一次给定的正确解释参考 | 可达上限诊断；因可见材料时机不同，不称公平主基线 |
| B 去掉目标旧事、关键关联材料或反证检索 | 真实来源依赖与选择性召回风险 |
| B 的固定输入/结果重复，禁止新增候选 | 精确幂等性质，与开放候选行为分开 |
| B 开放真实候选/别名路径 | 候选竞争会不会绕过去重、持续稀释反证 |
| 固定相同探测 c_task 与 x/θ，交换修订前后 R | 排除反思文本、当前情绪与性情差异，检查 R→J→选择 |
| 真实载体 m=0、错配/打乱 R 调制 | 检验作用通路；标为消融，不能作为产品通过条件 |

A 可在后继独立原型中作探索性对照，但其 C 重算语义未获准，不能在本卡推荐方案试验中临时接入。不存在可直接代替本项目机制的通用“心理学 SOTA”基线，本计划用既有系统、最简单路径和可达参考作比较。

## 4. 三层验证与候选验收

### L1：不用模型的机制层

合成世界给真实来源图、别名、材料包和已记录的 m=0 判断真值；独立参考不调用被测 G 折叠函数，不共用关键修订代码。精确身份/计量/历史保护与逐位重算要求不能用平均值通过。

| 候选 ID | 构造与预期 | 必须能检出的错误变异 | 关联现有要求 |
| --- | --- | --- | --- |
| REF-A01 | W1/W2 正例：已有真实组被重新解释，R 有预定可追溯变化；事件、原 a、C 全状态不变 | 把修订全部拒绝；只记文字、不更新 G | EV5、I23、COG-A07 |
| REF-A02 | 同材料重评重复 1、10、1000 次；中英日改写、摘要、换 ID/别名、插入无关事件，不再改变 R/θ 与计量 | 每个内部 H ID 建新组；每个全局 head 重开奖；μ 重复覆盖仍计新组 | EV2/3、AC2-03/05/10/14 |
| REF-A03 | 同一组存在支持和反对，检索顺序/预算预先固定；候选竞争份额守恒 | 仅取支持；删除反例；把别名建成独立来源 | EV5、LP2、I25 |
| REF-A04 | 修订旧 μ 后保留 ordinal/q；逐个 H 前缀对比独立参考、增量与全段重算 | 最新解释覆盖所有旧前缀；重估历史 q；回想刷新组位置 | ADR 0019 §§5–6、AC2-08 |
| REF-A05 | 来源更正、别名合并、权限撤回、部分对象不可用、后来新反证分别处置；真新事实能作用 | 全部当重复拒绝；失效材料留在派生摘要继续作证 | EV1/9、AC2-19、COG-A08 |
| REF-A06 | 普通反思、真新外源、工具返回、建议、读书、纠错分开；普通反思的 C 全状态恒等 | 拿 a′/x/想通后的感觉喂 C；把工具结果改标外源 | EV7/8/10、D21、AC2-09/14 |
| REF-A07 | 未发布对象/提交/消费标记/重启边界故障；暂停后恢复；同任务迟到返回 | 部分 R 发布、重复成长、成功后换结果、重启丢去重 | I14/16/18/23、AC2-18、COG-A09 |
| REF-A08 | 重评不发新 F 目标；合法重访保留原目标；停止全部事件后遵守原 Φ | 把普通重释当解释器修订；重复发脉冲；清零 x | ADR 0035 §§4.3–4.7、P5-70 |
| REF-A09 | 首次重评得到不确定/维持原解释后重复；真实相关新材料到来可再处理 | 不确定不断重抽直到支持；换问题名称绕过结果绑定 | U2、EV6、COG-A07 |

重复次数是测试压力点，不是运行时成长阈值。L1 全项要有成功与拒绝用例；所有变异必须被对应检查检出，否则测量本身无效。无法生成规范数值参考时标 non_identifiable，不把实现对自身的重放当唯一 oracle。

### L2：m=0 语义与材料治理

冻结三语金标准，至少分层覆盖 W1–W3、真假动机、同源复述/真实新增、建议/事实、资料缺失、真实后果/因果对照、回显与提示注入。标注者看到合成世界及可见证据；允许正确答案为未知。标注不得来自被测模型自身的解释或评分。

指标：真实新材料误拒率、同源误拆率、无依据断言率、由错误解释修复的比例、原正确解释被破坏的比例、未知保留率、正反方向/三语各自结果。分母含所有预定槽位，拒绝、超时与未知各列，不能只报完成样本。先有原初解释、再有重评的配对记录，不允许择优保留多次生成。

主对比为 B 与无重评；C 与仅 F 为机制消融。以世界/脚本家族为独立单位作成对效应与区间估计，翻译和改写不当独立样本；报告各层最坏表现。样本量由后继预注册的最小有意义改善、可容忍错误率和精度/功效反推，本卡不捏造数值门槛。有限样本中零次错误不等于错误率为零。

### L3：实际选择与「越想越偏」闭环

使用经过验证的真实载体与调制回执；结构夹具、TEXT_PROJECTED 不能冒充严格行为通过。探测上下文两组相同，不带反思台词、实验条件标签或“应该原谅”的指令。先验证 R/F/J 路径，再让行动影响合成世界的外源回应。

分开运行：固定事实反复想、开放候选反复想、真实事实持续变化、可控正/负反馈、无关信息持续加入、同源恶意改写、新反证插入。冻结持续时长、事件数、种子、反馈域及停止规则；记录每一步，不只挑开头结尾。

衡量：原始事实/解释引用与证据质量；R 的 π、组数、份额与历史 q；θ 全状态；F 槽目标、实际份额与 x；实际行动频率/选择正确率、世界目标结果、重复行动及工程拒绝；报警触发。将对固定真值的错误率随反思轮次的变化与权威计量变化分别报告。

- **有效：** W1/W2 中合法修订确实发生；相同证据预算下选择效果达到预注册改善，同时来源/重算等硬性质全过；对应消融能解释因果路径。若仅模型措辞改善而动作无差异，H2 不成立或不可识别。
- **不凭空强化：** 固定材料条件满足 REF-A02/09 的精确不变；开放候选/闭环条件无超出预注册容忍范围的错误累积，反证仍有效。后者只作有限范围测量，不替代精确幂等要求。
- **不偷换目标：** x 长时间难过本身不是失败；同一依据目标不增不等于总峰值不增。持续负面真实生活造成变化不算幻觉。不能靠停止认知、冻结 G/C、清零 x、过滤所有负面材料或恢复统一 T_x 期限通过。
- **负对照必要：** 刻意把内部念头计作证据、按修订次数推进 C、允许反复采样择优、丢掉反证的版本必须暴露异常；否则本试验没有证明防循环机制起作用。

## 5. 资源、复现与停止边界

| 阶段 | 资源估算方式与执行顺序 |
| --- | --- |
| L1 | CPU/临时磁盘；总量约为世界数 × 条件数 × 种子数 × 前缀检查数，另计故障注入与变异；先测最小夹具的时间/存储再冻结规模 |
| L2 | 调用数按样本 × 语言 × 条件 × 预定重复计，含原解释、独立检索判断及重评；保存全部失败/返回与预算，不做成功结果重试 |
| L3 | 本地载体、渲染/认知接线与 GPU；先由用户安排安静窗口，按实际吞吐估计总时间；重负载串行。没有资源实测就不承诺分钟数 |

后继运行前冻结：全部合成事件及可见范围、真值/标注版本、来源图、genesis/规律/数值资源、概念集合、查询规则、模型/提示/采样/种子、独立单位、主终点和阈值、多重比较处理、失败/缺失处理、最长运行与成本上界、硬件/工具链与证据索引。未定者在本设计中为待预注册，不是零或默认值。

结构规则违例立即保留最小反例，停止后续资格签发；不丢失败重跑替代。对判断质量不足、选择无差异、闭环越界，分别报告 failed 或 non_identifiable，不合并成“整体通过”。工程故障按既有规则处理，不能改成行为通过。纯 CPU 验证、语义验证、实际载体、生产接线分别报告状态。

原始请求、响应、轨迹及失败证据按 AGENTS 放私有证据仓，主仓只放报告/汇总/索引；合成夹具作为正式测试数据可进入代码仓。本设计未生成这些数据，未运行任何实验，也不对开放 PR 的已有研究结果作替代判断。
