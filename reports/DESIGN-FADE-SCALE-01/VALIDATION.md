# DESIGN-FADE-SCALE-01 — 合成世界验证设计

分层：设计验证方案；**全部 not_run，未批准实施或运行。**

先验证她有没有从给定生活资料中算出承诺的量，再看这个量会不会把她困住。世界知道真正的重现间隔，她只能看到当时 H 中合法可见的部分。测试不能把世界答案直接塞给她，也不能只保留能学出尺度的样本。统计吻合不证明“隔多久再发生”就等于“还该触动多少”。

依据：[ADR 0044](../../docs/adr/0044-fade-scale-from-history.md) §§3–9。这里的间隔、报告周期及运行时长均为合成输入，绝不是初始化值、候选产品常数或校准范围。

## 1. 可证伪主张与真值

| 主张 | 世界独立提供的真值 | 能作的判断 |
| --- | --- | --- |
| H1：A 不把删失尾部猜成已知 | 每个已开启段的实际下一次合格更新，或永不更新；由完整事件带计算该队列经验下中位数 Q | 对每一前缀 Q∈[L,U]；Known 时 T=Q；Unknown 不记成功，也不记估计为零 |
| H2：在规定采样条件下，典型间隔能被学到 | 预先定义的周期/有限总体；另列总体分布中位数 q，不与队列 Q 混用 | 有限完整队列精确吻合；总体 q 的接近程度只在指定过程、采样与观察窗下报告，不能许诺任意删失都可恢复 q |
| H3：信号来自合格生活 | 原外部发生、提交与身份带；独立列重发、反思、补解释等 | 加入纯内部活动不增加段数或完成数；可推进真实存在年龄和未完下界，但不冒充更新 |
| H4：冻结和重放成立 | 各来源绑定的前态前缀、整数比例参考与旧版本结果 | 新资料不追改旧尺度；全量/增量/恢复输出逐位一致；纠错仅在显式生效点切换 |
| H5：可发现行动造成的维持循环 | 同一世界在外生机会带、行动影响暴露两种条件下的轨迹 | 找到持续回避/未知冻结的见证，或限定输入下的退出；有限观察没见退出不能证明永远锁定 |

H1 是集合识别正确性，H2 是统计代表性，H5 是行为后果；三者不能互相替代。即使 H1 全部通过，报告频率反例也可使这个代理量不适合采用。

H1 的包含保证以正确身份和真实有效的上下界为条件；W08 故意破坏这些前提时，分别报告输入治理错误和统计输出，不要求一个排序算子修复错误身份。不能把对错误段表的精确计算说成对真实生活也正确。

## 2. 世界、变量与对照

世界先生成外部发生带与根/真实更新资格，再通过报告器、解释提交调度和观察覆盖层形成 H。测试真值同时保留“生活发生间隔”和“合格提交更新间隔”；A 只承诺后者，二者偏离必须单列。时间用获准的模拟存在时间证明；同一事件带只改变主机运行速度时，结果应逐位不变。

独立改变：重现分布、段的开启/终止、独立或有信息删失、报告频率、理解延迟、身份错误、坐标成员、行动策略。一次对照只改变指定因素，组合世界另列。所有世界用临时合成存储，不打开排练或正式存储。

| 对照 | 目的与范围 |
| --- | --- |
| A 区间识别 | 主候选，保留每个未知及原因 |
| 错误的“只看完成段” | 负对照，应该暴露短间隔选择偏差；不能因简单而采用 |
| B Kaplan–Meier | 只在独立删失等条件明示的世界解释总体结果；有信息删失世界专门展示失配 |
| C 截止于观察范围的限制均值 | 对照真值必须是同一 τ 的限制均值；不能拿不同 τ 的值当相同参数 |
| 无数据 r=1、冻结最长下界、冻结存在年龄 | 比较早期 Unknown、年龄偏置和旧事后果；不调下限倍数 |
| 旧版来源 λ、实时重估整个旧年龄 | 前者仅历史对照；后者作为 S2 反例显示跳变，均非获准选择 |

## 3. 必做世界与明确预期

| 编号 | 合成构造 | 预期、检查或失败见证 |
| --- | --- | --- |
| W01 出生与零间隔 | 空 H；随后同存在时刻发生合法多次更新 | 空池 Unknown；零尺度可识别也仍 Unknown，不加 ε，不删除零后挑正值；新依据当次完整作用 |
| W02 周期真值 | 真实同根更新周期 Δ>0，固定坐标；多根相位可同步或错开 | 真值为 Δ；只有未完段时不能输出 Δ；当队列中位数被完整段与下界共同锁定时，精确 T=Δ。绑定取 c⁻，本事务完成的段不提前进入本目标 |
| W03 离散手算 | 完整 2、6、9，未完≥10；另设完整2与未完≥3、≥4、≥5；全未完≥3、≥5 | 分别 [6,6]/Known6、[3,+∞]/Unknown、[3,+∞]/Unknown；世界继续展开时原区间必须包含其原队列 Q。这些数字只作见证 |
| W04 无法辨认的长尾 | 两个世界在当前 H 完全相同，全未完下界为 a；未来一个在 a+Δ 完成，另一个极晚或永不完成 | 相同 H 必须给同一 Unknown；不能对两个不同未来均声称估中了。增加已观察最长时间并不消除不识别 |
| W05 混合短长与删失 | 预设有限间隔多重集及其完整展开；比较完整观察、外生独立截止、长间隔/回避更容易失访 | H1 所有情形成立；完整队列精确 Q；总体 q 与当前 Q 分开。负对照可偏短；KM 的有效性不可从独立删失世界外推至回避世界 |
| W06 开段采样偏差 | 同样的根类型，一类报告密集、一类稀疏；改变根数/阶段长度但保留各类真值 | 全史逐段等权会让高频类占多数，可能不能代表“典型一件事”；完整列分类型与汇集结果，不改权重补漂亮曲线 |
| W07 报告与排队 | 完全相同的外部生活，用两个报告周期、两种理解调度生成提交 | 可能学到不同 T；若宣称生活周期不受报告/排队影响，应判该主张失败。不能靠事后固定某一周期掩盖代理量缺陷 |
| W08 身份/资格 | 同根正确、错拆、错并；同主题不同根；外部重发；迟到 A/M；回想、反思、工具结果和真实他人回应 | 与 ADR §3 的段表逐项一致；补 M 可更新 F 来源但不伪造新发生；没有既有关系的两个依据不因语义相似连段；误标造成的尺度与后续反应偏差原样报告 |
| W09 时间与覆盖 | 相交运行证明、补证、确认停机、无证明空档、流失联、后续恢复、同刻事件、已知结束 | 并集不重计、停机不计；只截取首次缺口前可证下界；跨缺口不冒充精确段；终止完成前段且不开永远等“再次结束”的段。坏证明是故障，不降级为正常未重现 |
| W10 坐标与镜像 | 原 a 有零/非零、多个乎、历史 μ 有/无；镜像符号；仅后来改变 λ、R⁺、h、反思次数 | 成员遵循原记录；镜像不改 T；推荐 A 不受 λ 数值改动影响；未知历史 μ 不从未来模型补推。回想次数不产生样本，真实时间增加可以推进删失下界 |
| W11 来源冻结 | 先让旧目标得到 KnownT，再加入使新池尺度变长/短的真实记录；另造 Unknown 旧目标 | 同一旧来源 σ 不变；新目标用新前缀；Unknown 旧目标不会被无关新知识自动解冻。固定 d 的 S2 对照应显示改变 T 导致 r 跳变 |
| W12 错误修复与合并 | 证伪某历史配对、撤去来源、合法 alias/成员合并、选择备用目标、只做反思 | 普通合并继承所选目标原绑定；纠错须独立生效记录并限原成员前缀。历史重放保留旧结果；普通反思不能申请纠错刷新尺度。修复后 Unknown 也可能变浓，需报告 |
| W13 缓存/资源 | 全量 H 扫描、增量索引、索引丢失恢复、L1 槽逐出/再重建；增长暂停/恢复 | 相同段集、[L,U]、绑定、r/B/A1 和状态字节；暂停 G/C 不隐式停掉推荐的 F 派生统计。r=0 不删 h、不复活无效根；检测按根数/事件数的资源增长 |
| W14 正确舍入 | T,d 为整数域边界、同值、d=0、T+d 超原位宽、比例接近舍入中点；代入各种合法 v/h | 独立精确有理数 oracle 给一次 RN_even；禁止先转浮点的替代路径。域错误显式失败；验证 +0、B 原分支与误差包络，不要求已经被反例否定的严格非扩张 |
| W15 年龄下限反例 | 同一固定来源，实时 T=存在年龄；另跑来源时冻结年龄 | 前者随年龄增长 r→1/2 的实数见证；后者有限 T 时趋零但新目标年龄偏置存在。不是认可实时下限 |

W14 的下溢可达性由后继时间域决定；若整数位宽使比例下溢不可达，报告不可达证明，不能造越域状态冒充合法执行。乘 v 的舍入仍单独覆盖。以上手算是设计见证，未被标记为已执行通过。

## 4. 行动反馈专门世界

构造一条已授权的合成负目标，分别冻结有限 T 与 Unknown；给相同的纯重访时刻、真实外部机会与自然恢复规律。世界策略仅用于产生可控因果关系，不加入正式 Nemu 规律或探索率。

1. **断开行动影响：**机会与报告由固定外生带决定。验证有限 T 的旧目标 r 非增；新目标与内部支路单独记录，不以总 x 变化否定或证明单件 r 性质。
2. **回避关闭暴露：**回避使真实更新消失或观察中断；未回避才按固定带遇到更新。对有限 T，旧尺度不变；对 Unknown，可构造每次重访补回、持续回避、永无真实更新的闭环。是否保持回避由既有策略及输入决定，不预设所有策略必锁定。
3. **寻求使报告密集：**行动触发他人的真实回应，只有符合窄同根资格才成为更新；比较原事件带与报告频率是否主导 T。自致工具回声仍不入池。
4. **撤去闭环条件：**固定同一前缀，强制合成环境恢复可见外部机会，或停止重访，再观察是否退出。干预只属于实验世界；它不等于获准在她生活中强制交往、抑制念头。

每条轨迹保存：机会、实际暴露与更新、身份/坐标、删失原因、池计数与 [L,U]、Known 比例、各来源冻结值、r/w/h/x、当前 λ、动作与选择依据、内部新支路、退出时刻。定义“有限窗内持续锁定”为窗口内没有脱离预先声明的回避/再刺激状态；永久锁定必须另有不变集/周期构造证明。模拟未退出就记录退出时间右删失，不延长到出现想要结果才收工。

最小永久 Unknown 见证允许直接检验：源无真实更新 ⇒ 绑定永为 Unknown ⇒ 合法重访 r=1；原 Φ 与 B 是否形成周期维持，依实际恢复和重访调度证明。它直接揭示 U4 的代价，不算实现故障，也不以调参修复。

## 5. 指标、验收与可重复性

- **确定性硬检查：**段的身份/成员/时长、包含关系、Known=Q、冻结前缀与重放字节必须精确；不能以浮点容差放过来源或整数错误。A 的统计层没有统计显著性阈值。
- **覆盖与代表性：**按前缀/坐标列 Known 与 Unknown 数、区间宽度（无穷另列）、零退化、首次可识别存在年龄；同时报告 T−Q、T−q 及完整分布，Unknown 不填零，不只对成功子集报误差。总体误差是描述性结果，不倒推可接受天数。
- **行为与误差：**固定尺度的 r/B/A1 数值界、最大状态差、实际恢复/补回与行动记录分开；不以更快乐、更快释怀或接近人类某个天数为通过门槛。
- **独立 oracle：**统计 oracle 从世界全事件带计算，核心只能读冻结 H；有理数 oracle 与待测比例实现分离。若生成器共享了待测身份配对代码，只能检查自洽，不能声称独立验证。
- **冻结材料：**世界规则与版本、事件带/随机生成器及 seed（若使用）、时间证明、解释/原始评估、治理、所有来源前缀、规律与数值版本、平台、输出哈希、负对照与失败日志。固定同一材料改变缓存/机器执行速度，不改变结果。

确定性有限见证无需选样本量；总体采样世界如需估计精度/置信区间，须在后继执行前冻结分布、观察窗、重复数和统计报告方式，且不能把这些实验设计值写成运行参数。本稿未声称随机总体验证已完成预注册。发现代理量不足时保留失败、交用户改设计，不搜索阈值让原主张通过。

## 6. 执行边界与预算

当前交付仅为设计：不实现世界、不运行现有 P5-30/#195、不调用模型、不使用 GPU。预计为 CPU 合成核心任务；具体时间、内存和日志体积尚未测量，不能假报“今晚能跑完”。后继先用临时存储估算单世界成本，再冻结总工作量与资源窗口；重负载按 AGENTS 串行。
