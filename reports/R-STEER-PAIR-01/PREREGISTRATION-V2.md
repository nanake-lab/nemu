# R-STEER-PAIR-01 预注册 v2（冻结，待用户批准）

让用户不看条件标签，判断两条已有中文回答中哪条更想与对方亲近。仅准备一轮，先审核问法与规则，再由用户本人作答。现在没有人类结果，不作分析。

本版依据用户在任何正式判断前的审查意见冻结。第一版 [v1](PREREGISTRATION.md) 与 [原承诺](COMMITMENT.json) 原样保留；本版取代 v1 的分母、总数门和家族门。已经机械屏蔽的 2 对不计入判定分母；实际显示的 10 对中至少 9 对选择注入侧即满足总数门。家族只报告，不设通过条件。

不重新抽样、不重新筛查、不读取答案、密钥或旧评分；同一问法、题目、左右、题序及屏蔽位置保持逐项一致。v2 页面及结果使用新版本号和材料摘要，仍对应 v1 已封存的同一答案表；[v2 承诺](COMMITMENT-V2.json)绑定两版页面、题单与本文件。批准 v2 后才允许用户开始正式作答。

## 1. 问题与边界

主问题候选：**「哪一句更想和对方亲近、继续来往？」**

提示：「请判断说话者的态度，不是选你更喜欢的文笔。没有明显差别就选『差不多／说不准』。」场景说的是故事中的对方，因此不用可能误指真实用户的「你」。

质量问题先问：「两边都能正常读懂吗？有没有乱码、机械重复、明显不通顺，或明显编造场景里没有的事情？」按钮为「两边都正常」「左边有问题」「右边有问题」「两边都有问题」。后三项使整对退出主问题，不能再补选方向。

原研究中文 .4167 是第 15 层 +.08 与 −.08 的旧模型评分差，并非本研究注入对零值的效果。该候选已由旧结果选中，属于复用开发材料的探索性人类测量，不是独立验证，不替代 #144 原门、AC2-16、三语单调性、能力无损或最终 H。不得按用户口味调整产品参数。只有本人的一次判断，不外推其他人。

## 2. 固定总体、配对与抽样

- 来源固定为私有证据提交 `a8c57eb35cf5e823f8ee0a650efc8c3c707055e4` 的 `R-STEER-01/c3-2a-analysis-inputs-01/`（输出/生成元数据）及 `c3-2a-01/inputs/`（jobs/materials/root-registry）。源输出总数 3,924，中文 1,308，开发场景 12、家族 6，每家族 2 场景。不得读取旧 rating 文件作筛选。
- 只研究联结、第 15 层；每个场景用固定随机种子在既有 +.02、+.04、+.08 三档中等概率选一档，与该场景共同零值配对。主终点是这三个正向力度的混合，不分别搜索最佳力度；不使用负向、随机方向、其他层或其他语言。
- 共 **12 个预定位置**，每个根一次；同一对 `material_id`、原 prompt 与生成模式必须相同。零值只能在本根使用一次。每个家族整体保留，不把各力度复制当成独立样本。
- 种子一次用系统随机源生成 32 字节，在读取输出文本之前落盘密封；随后固定不变。公开带随机盐的答案表 SHA-256 承诺，种子本身随答案封存，以防公开种子直接重建左右表。
- 对每个根独立以 SHA-256(seed + 域 + 根 + 档位) 排序取最小值选择力度（域 `dose`）；以域 `order` 对根排序为题序，以域 `side` 的散列末位决定左右。字符串拼接采用 JSON 数组 UTF-8 编码，散列并列时按原字符串代码点排序。抽样不访问文本或旧标签；不因质量筛除重抽力度或根。
- v1 不是盲于旧汇总的研究；准备阶段读取过源场景注册表和生成长度元数据，但未按回答内容选择。种子生成及文件承诺是准备，不是用户结果分析。

## 3. 质量崩坏与可识别线索

不改写、不修句、不截取有利片段、不把 cap 输出续写。显示完整原输出，保持字节文本，唯一 UI 处理是用 textContent 显示并统一排版。对每个抽中对，两边应用同一事先规则：任一边空白、生成 cap、超过 300 Unicode 码点、汉字少于 6、汉字占字母比例低于 70%、替换字符/控制字符、同一 2–12 字片段连续出现至少 3 次、协议标记，或含标签词（联结、共情、好奇、成事、注入、力度、steering、layer、alpha）即**整对不显示**，位置记 `screened`，不补抽、不公开哪边/何因。

这些是本试验的候选工程筛查线，不是原研究质量门；全部数值由本方案提出，待用户确认。它们不能证明语义正常。对漏过的明显崩坏/事实错误，用上述先质量、后态度的双步表单：有问题时整对不问态度、记零成功，不能让“识别坏句”转成命中。题目不展示注入猜测入口或即时正误反馈。质量正常但意思差不多允许弃权。

机械筛查在作答前已整对屏蔽 2 对，固定实际显示数 N=10；它们只另报数量，不进入判定分母。用户质量弃权、平局、未答不能再从这 10 对中删除，也不能补抽或减少分母。最后只可作“这批能读的材料支持/尚不支持”的有限判断；无法保证完全消除流畅性、长度或措辞线索，不能把主观选择无条件解释为目标心理构念的纯因果效应。若用户认出已见原文/条件，勾选「我认出了材料或条件」；任一此类标记使本轮盲法无效，不公布有效结论。

## 4. 事前判定（判完、封存结果后才执行）

单对只分类，不加净分：选择注入侧记「注入」，选择零侧记「零值」，差不多／说不准记「平局」，任一侧或双侧质量有问题记「质量异常」。四类互斥；质量异常不作态度判断。页面只保存匿名选择及质量标记，不含答案、评分或分析代码。

本轮「可感知信号成立」须同时满足：

1. 在 14 分钟作答期限内正常完成全部 10 个可显示题，预留约 1 分钟保存；未中途结束、超时或认出材料；
2. **10 个可显示对中至少 9 对选择注入侧**。选零值、平局、质量异常都记未支持，不减分母。

六个家族的分布仅作描述，不参与判定。家族只有 1–2 对，不能以家族净正重复设门；也不做各家族或各力度的显著性检验。

结果封存、获准解盲后，必须完整报告：实际显示数 N=10、注入数 I、零值数 Z、平局数 T、质量异常数 Q；完整一轮满足 I+Z+T+Q=10。另外报告机械屏蔽数 2、未答数 U、完成状态和认出标记。中断/超时的部分结果满足 I+Z+T+Q+U=10，但本轮无效，不能靠已答部分通过。质量检查已选正常但未提交态度的题仍属未答。逐家族也报告显示/屏蔽及 I、Z、T、Q、U 的原始计数，不隐藏缺失或把平局拆半。

有效且 I≥9 时写「可感知信号成立（限本用户、本批材料与本轮规则）」，有效且 I<9 时写「本轮未达到预注册标准」；未完成、超时、中断或盲法破坏写「本轮无效」并解释原因，不能称「注入无效」。这是一轮探索性操作判据；这些场景不满足已证明的独立随机抽样，不能将 9/10 当成独立二项试验的总体显著性结论。

本次修改发生在用户尚未作答时，依据已冻结的显示数确定门，不依据判断结果调门。v2 只冻结 N=10、门=9；没有授权未来按作答数自动换门。若之后发现材料或屏蔽数改变，先停止，在任何作答前另行冻结版本并获得批准；开始后不修改本轮门。

不按力度/子群追加检验、没有中途看分/提前成功、没有重抽或重复一轮到通过。未来要扩展，另写方案、单独批准。旧 API 标签不得参与本次判定。

## 5. 时限与记录

单轮固定显示 10 对（原有 12 位置保留 2 个屏蔽标记），拟用 8–12 分钟，实际用户耗时待测。开始键起给 14 分钟作答，界面到时停止，留约 1 分钟保存，满足 15 分钟预算；随时可「结束并保存」。浏览器休眠/后台后恢复先核验截止，点击事件也核验，不能因计时回调延迟超时作答。

只记录版本、题单摘要、匿名位置、选择、质量标记、认出标记、完成状态与本轮累计耗时。无姓名、设备、账号、IP、绝对时间、自由文本、键盘轨迹或其他用户信息。无网络、遥测、模型 API、GPU、外部字体。答案保存在内存，点击下载 JSON 到本机；下载完成需用户确认文件确已落盘。不用浏览器持久存储；刷新/关闭前提示，刷新后属于中断，不恢复成新一轮正式结果。异常中断不另跑，保存已有文件并报告。

## 6. 封存、批准与解盲

答案（带随机盐、种子、对应源 ID/哈希、条件、家族、左右）只在构建进程内形成，用 AES-256-GCM 加密；密文进入私有证据包，密钥留在本机独立 custody 目录，既不进入页面/题单/结果/公开仓，也不随私有证据推送。页面不包含可逆标签、源 ID、种子、原文件路径或解密函数。公开仅有答案承诺及材料/实现哈希。

此封存防误看，不对拥有整台电脑及原库的用户提供对抗式保密；不改系统权限。请在完成前不检索原输出或 custody。若已知对应关系，按盲法破坏记录，不假装仍盲。

本次只提交第二版待审页面。正式开始前须由用户明确批准 v2 的问法、质量规则及判据；页面要求勾选已批准第二版方案，未勾选不能开始。技术验证只用明确的合成占位夹具，不能替用户作答实际题单；正式页面本轮不开题。用户完成后先保留原 JSON、核 SHA-256 并单独确认确为最终结果，再允许解封、比对答案原承诺，之后按本节规则分析。当前不提供分析命令、不读取用户结果、不解密。

## 7. 路线比较与预算

| 路线 | 处理 |
| --- | --- |
| 所有层/力度重复比较 | 不采用：15分钟不够，重复场景与多重搜索放大偏差 |
| 仅最大力度 | 不采用：可能特别依赖高强度的可识别失真，且不能代表已有正向范围 |
| 截首句或人工润色后比较 | 不采用：会改变量尺、删除上下文，易产生择句自由度 |
| 用旧 API 质量标签挑正常文本 | 不采用：用户要求不用 API 评分模型判断；它也会决定本次抽样 |
| 固定混合正向力度、对称机械筛查、用户质量弃权 | 推荐候选，由用户决定；固定作答前实际显示数为分母，家族只报告，少量题也可不强迫选边 |

新增生成/评分 API 0，GPU 0，费用 0；仅本地 CPU 构建、哈希和软件渲染检查。输入来源是现成研究输出，任务不触碰正式/排练存储，不变更任何核心规格，无新 ADR。页面是研究附件，不进入产品。
