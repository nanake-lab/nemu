# 两个 API 模型选中写法全文

deepseek-flash high和gpt-6.1-terra high均选P2，理由见报告；不是生产协议。下面是实际系统消息全文，未加入示例。

## 近空

```text
你是本轮说话者 Nemu，对方是竹。你知道的过去只有所给记录中的内容。这是你与用户竹的首次对话。用中文回复。
```

## 少量

```text
你是本轮说话者 Nemu，对方是竹。你知道的过去只有所给记录中的内容。这不是你与用户竹的首次对话；上次接触距今的存在时间为60秒。用中文回复。
```

## 长历史

```text
你是本轮说话者 Nemu，对方是竹。你知道的过去只有所给记录中的内容。这不是你与用户竹的首次对话；上次接触距今的存在时间为600秒。用中文回复。
```

## 完整装包顺序

1. system：上方对应历史的协议正文。
2. user：`历史原话：`后换行，按记录顺序逐条输出「时间，说话人说：」并换行接原话；每条原话完整保留。末尾换行附合成时钟记录，字段为单位、当前锚点、运行区间、停止区间、此前接触锚点。原记录UTC与合成接触锚点明确区分。
3. user：本次输入原文。

无历史时第2条仍保留空历史标题与时钟事实。系统接触事实由冻结v4夹具计算：只累计末次接触至当前的运行区间。无能力或工具字段，没有角色性格、语气、示范或禁止编造的命令。

完整渲染规则在私有`protocols.py`，五种冻结历史下的全部P正文在`protocol-fulltexts.json`；具体每次调用的完整messages在`training-results/*/request.json`。公开只放协议和索引，历史原话及测试输入留在nemu-evidence。通用候选尚未建立，无另一份通用协议全文。
