## #235 合并后的 SYS21

本节为设计。已执行的用例数、各消息分母及结果见[覆盖表](VECTOR-COVERAGE.md)和[报告](REPORT.md)。

同步 main、重跑生成器、冻结**当时 main** 的契约基线，再按消息追加向量。现有黄金字节逐条保留。每个新消息至少三个正向及三个反向样例，三端分别走 encode、CanonicalV1 和 Protobuf；错误输入通过正式边界进入。使用独立的预期字节，校验未知版本、字段、枚举、重复、截断、集合规范顺序和整数边界。三端的语义检查和针对每种消息的覆盖计数属于这一阶段。

| 消息组 | 正向取样 | 主要反例 |
| --- | --- | --- |
| SourceField、SourceLocation、SourceTransform、SourceMetadataV2 | 整对象、嵌套字段、多处定位及按序多输入转换 | 索引错位、不同产物冒名、派生链断裂、引语来源错绑 |
| ConceptRole、ConceptRevision、ConceptLink、ConceptRegistry | 初版、修订、带别名/非等价概念关系 | 重复角色、同一 ID 重用、跨版本悬空、同义关系冒充治理合并 |
| RefV2、ClaimV2、ActV2、SemanticGraphV2 | 中日英原文、多个节点、角色表命中 | 旧字段号、未注册节点或种类、报告型 operand 引用错误原件 |
| TextAdapterEntry、TextAdapterTable | 文字和语音合法条目，不同注册表修订及多字节文本 | 缺某个首批条目、错误字段、载荷 schema 或谓词版本错配 |
| StageCoverage、StageAdoption | 完整、部分、失败；M 的零与未知 | 丢实际读集、A/M 冒名、回执前沿不符、伪造空清单 |
| AttributeRule、AttributeRuleTable、ScopedVerification、VerificationRequirement、TargetPremise、EventAttributesRecordV2 | 真实表达且内容未核实、不同判断范围、已证伪内容保留表达发生 | 旧 verifiable 偷换三项、未知冒充已知、自致结果冒充外源、漏依据或接触单位 |
