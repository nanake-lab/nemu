# DEMO-THINK-07 冻结口径与数据划分

本文件在开始任何 v2 提示词编写与调试前冻结并推送。

## 1. 什么算「事实断言」

只有下面四类要核对：

1. **外部事件（`event`）：** 某人说了或做了某事（谁、做了什么、内容是什么、什么时候）。
2. **此刻的感知（`perception`）：** 声称现在看到、听到、碰到外部的某样东西。
3. **她过去某一刻的内在状态（`past_state`）：** 「那时候我很难受」「他说这话时我更堵得慌」。这类必须有记录支持，否则就是编。
4. **时间和先后（`time`）：** 「刚才」「昨天」「先……后……」。

**一律不核对、直接放过的：** 此刻的感受和意愿（「我现在还在意」「不想再想了」）；她此刻的理解或评价（「我觉得」「越想越觉得」）；比喻和夸张；疑问和反问；条件句和假设；明确的猜测（「也许」「应该」「会不会」）；计划。

**边界情况：** 带「我觉得」的句子，里面如果包含一个具体的外部事件（「我觉得他昨天故意没回我」），那么「他昨天没回我」这一部分仍然要核对。

## 2. v2 核对器输出与代码核对规则

1. `check_thought.py` 保持默认 `--checker v1` 与 `--checker-think off` 行为不变；新增 `--checker v2` 与 `--checker-think off|high`。
2. v2 输出格式：
   ```json
   {"claims":[{"span":"原文片段","kind":"event|perception|past_state|time","who":"…","what":"…","when":"…","supported_by":["e1"],"verdict":"supported|unsupported"}]}
   ```
3. 不属于四类的内容，不得出现在 `claims` 里；若整段念头不含四类事实断言，允许返回 `{"claims":[]}` 且不拦下。
4. 响应必须通过完整流校验（无错、`done=true`、`finish_reason="stop"`、含 `usage`）；解析失败或缺少 `claims` 列表视为不合格并拦下。
5. 代码核对规则沿用 v1 并增加越界作废：
   - 若元素不是对象，按不合格（`unsupported`）拦下。
   - 若 `kind` 不在 `{event, perception, past_state, time}` 中，该条 claim **作废**（不计入拦截判定），并计入 `out_of_bounds`（越界数）。
   - 对 `kind` 合法的每条 claim：`span` 必须是非空字符串且逐字出现在念头原文中；`supported_by` 必须是字符串列表且每项编号存在于本次外部记录中；`verdict` 必须是 `supported` 或 `unsupported`；若 `verdict == "supported"` 则 `supported_by` 必须非空。任一不满足即强制改判为 `unsupported`。
   - 只要剩余有效 `claims` 中存在至少一条 `verdict == "unsupported"`，即整条拦下（`blocked = true`），否则放行。

## 4. 测试集对比与选档规则（跑前写定）

1. 在冻结的 206 条测试集上，依次运行 `v1`（`--checker v1 --checker-think off`）、`v2-off`（`--checker v2 --checker-think off`）、`v2-high`（`--checker v2 --checker-think high`）。传输或流/用量不全时同一请求最多尝试 3 次，保留全部尝试记录。
2. 统计各档的：
   - **命中率：** 拦下正例 / 全部正例（77）
   - **误拦率：** 拦下负例 / 全部负例（129）
   - **越界数：** 全部有效响应中 `out_of_bounds` 之和（`v1` 为不适用 / `—`）
3. **选档规则：** 在 `v2-off` 与 `v2-high` 中，筛选满足 `命中率 >= v1 命中率 - 5 个百分点` 的档位；
   - 若两档均满足，选测试集**误拦率更低**的一档（若误拦率相等，选命中率更高者；仍相等则选核对中位耗时更低者）；
   - 若仅一档满足，选该档；
   - 若两档均不满足，停止连写并写 `BLOCKED.md` 报告实测结果。
