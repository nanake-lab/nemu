## 主要结论

- **D07-A：** 只改 b 一项：出生先验质量 P 与经历同按 ρ 折扣。现行 ĥ_θ 的下限给出 α 的正下界，出生份额按合格经历数几何让位。旧规律中出生先验把反馈强度压成较小的 k_eff；新规律下有效反馈就是 k，世界偏向一侧时更容易贴边，只报警不拉回。真实闭环未证，新 AC2-25 只在实测域内签发。
- **D07 的数值：** P 会随生活几何趋零，现行 `numeric::mul` 遇下溢会判故障——照搬会让她在长期生活后永久停止成长。ADR 规定这两处乘法允许下溢到 +0，并给出量级界。
- **D09-A1 的数值：** P09-A1 的实数公式若照字面写成浮点 `h⁺ = h + (x⁺ − x)`，同一前态同一目标重复作用**不**逐位幂等。随机抽查的数百万组输入中，有百分之几出现最低位变化，ADR §4.6 给出一个可复现的见证。ADR 改用分支形式：不饱和时 h⁺ = v，饱和时夹在 h 与 v 之间。B5 证明分支形式逐位幂等，同一抽查无违例；B4 证明新依据首次作用逐位等于旧 F；B1 证明无事件时 x 逐位等于现行 Φ。
- **D11-A：** 资格不读任何队列或提交时刻；同一消费身份至多作用一次。后者是条件证明，前提是 P5-72、P5-73、P5-75 的原子发布。
- **被取代：** V2-96 的固定 n_b 项、THETA-2 与 AC2-25 的出生锚定读法、COG-A12 的统一回落与队列期限部分、ADR 0026 有限在途尾部证明，以及新版本中的 κ、r、M、τ。旧版本、旧测试与旧失败证据全部保留。

随机抽查只是辅助核对，不代替证明；不提交证据文件（轻档）。见证可在任何 IEEE binary64 环境复现：

```python
x, h, v = 0.44103831552214, -0.07324038289205337, 0.0002230830984472614
clip = lambda s: max(-1.0, min(1.0, s))
x1 = clip(x + (v - h)); h1 = h + (x1 - x)
x2 = clip(x1 + (v - h1))
print(x1, x2)   # 0.5145017815126407 0.5145017815126406
```
