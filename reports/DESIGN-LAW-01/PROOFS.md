# DESIGN-LAW-01 证明边界与重推路线

状态：设计中的实数条件推导；没有运行原型、证明检查器或数值/行为验收。正文的“成立”只指明列前提下的代数结论。规范 binary64 递推、误差界、权限/事务与所有未来闭环的保证另列义务，不拿有限实验代替证明。

依据是 [v2.0 §§6/8/17](../../docs/echo-core/echo-core-v2.0-first-principles.md)、[ADR 0008](../../docs/adr/0008-echo-core-math-clarifications.md)、[ADR 0026](../../docs/adr/0026-continuous-cognition.md)、[ADR 0032](../../docs/adr/0032-presets-as-starting-points.md)、[V2-95–97/115/118–143](../../docs/traceability/diff-register.md)。只使用这些既有命题与下列直接推导；不援引未经核验的外部稳定性结论。

## P00：先分清四种命题

## P07-A：先验与经历共同折扣

### 命题、递推与来源

研究标量通道；四通道逐坐标同理。令出生值 b₀∈[-1,1]，有限先验质量 P₀>0；合格第 n 组的反应 a_n∈[-1,1]、质量 q_n≥0、本步 ρ_n∈[0,1]。P₀、q 的具体资格/单位及 ρ 的估计方法须另行定稿，无默认值。q 不是 R 强度或当前心情；没有新合格观察不执行此步。

设 P 是出生质量，S 是经历质量，U 是经历的有符号和；初始 S₀=U₀=0。提案的唯一顺序为：

$$P'=\rho P,\qquad S'=\rho S+q,\qquad U'=\rho U+qa,$$
$$T=P+S,\qquad b=(Pb_0+U)/T,\qquad T'=\rho T+q>0.$$

先验质量与旧经历一起缩小，区别于 V2-96 的固定 n_b 分子项。证明用实数比值不是许可用闭式取代未来的逐步浮点规范。

### 新界与出生份额

令 α=q/T'，则 0≤α≤1，且

$$b'=(1-\alpha)b+\alpha a,\qquad b'-b=\alpha(a-b).$$

因此 b' 仍在合法区间，`|Δb|≤α(1+|b|)≤2α≤2`。这里的 2 是区间直径。没有旧界的 `n_b(1−ρ)(b₀−b)` 项；照抄它会误报或漏报新规律错误。

出生系数 β=P/T 满足

$$\beta'=(1-\alpha)\beta,\qquad \beta_n=\prod_{j=1}^{n}(1-\alpha_j).$$

若某 α=1，则出生份额归零；否则 `Σα_n=∞` 是 β→0 的充分条件，因为 `log(1−α)≤−α`。**持续发生很多事件不等于持续获得足够质量**：如果全部是假来源、重复、未知，或有效 α 总量有限，就不能宣称先验必定消失。没有新合格经历时 β/b/估计器逐位保持，符合 LP5。

同一 q/ρ/a 序列、同一 P₀、只换 b₀ 时，实数条件差异为 `b_n−b̃_n=β_n(b₀−b̃₀)`。若 ρ 的估计也依赖不同 b 所产生的残差，实际两条路径不再共享 ρ；必须先做冻结输入的机制诊断，再做端到端比较，不能把这个等式误当完整因果效果。

### 生活参照与有限扰动

对相同未来反应和相同 α 路径，从扰动结束的提交 m 开始，`δb_n=δb_m∏_{j=m+1}^n(1−α_j)`。乘积趋零时忘却有限扰动，回到共享后续生活决定的轨迹，而不是 b₀。若没有未来证据、α 总量有限，或扰动改变了未来的社交历史/保留率，则这个比较不成立；不得补一个计时回拉器。

### 对 σ/g/λ 的连带影响

本卡只优先改 b；不顺手选择 D08 的增益规律或 D14 的 G 规律。如果残差方差仍采用固定 n_σ 的旧形式，令 v=σ̂²、v₀=σ₀²、旧经历质量 S_σ，新残差 r=a−b_before，则

$$v'-v=\frac{n_\sigma(1-\rho)(v_0-v)+q(r^2-v)}{n_\sigma+\rho S_\sigma+q}.$$

这是该特定保留形式的恒等式；若方差先验也共同折扣，式子又要变。b 的改变会改变以后的 r，即使未改 g 公式也必须重验。对 `g=clip(K/√v,g_min,g_max)`，v,v'>0 时沿代数恒等式得

$$|\Delta g|\le\min\left(g_{max}-g_{min},\frac{K|v'-v|}{\sqrt{v'}\sqrt v(\sqrt{v'}+\sqrt v)}\right).$$

旧 v 正下界若依赖已改的先验/质量上界，不能直接继承；无该前提时只能先保留参数范围界，并另证数值合法性。

V2-95 的运行时间、正完成段的对数平均、零段只审计、未完成段不计仍是当前版本。b 改变会影响残差符号与分段，故 τ̂/λ 的整段重算也受影响。λ 的范围界在范围未改时保留；紧单步界须按实际完成段及运算路径重新推导，不能拿无限长未完成段当完成观测，也不能用当前 λ 外推尾部来造证据。

## P07-B：终生均值及其惯性

令 `T_n=P₀+Σ_{j≤n}q_j`、`b_n=(P₀b₀+Σq_ja_j)/T_n`。新增步仍是凸组合，α=q/(T+q)，所以同样有 `|Δb|≤2α`。出生份额 β=P₀/T_n；累计可靠质量趋于无穷时 β→0，任何固定有限扰动的分子贡献/T_n 也趋零。

条件很重要：没有新证据不能变；有限总质量不能保证趋零。很长旧人生 T 使下一组 α 很小，没有独立于历史的适应期限。若真实生活变成另一个稳定均值且持续提供无界质量，最终可跟随；有限观察中的慢跟随仍可能不合适。采用稳定在线均值也不能自动解决精度耗尽、全部旧组更正和规范重放，必须锁定唯一计算顺序。

## P07-F：反馈世界里还能保住什么

为分析而设一维合成世界 `a_n=c+k b_{n−1}`，假定此区间不触发输入边界，c/k 是世界参数而非产品默认值。均值递推给出

$$b_n-b_*=[1-\alpha_n(1-k)](b_{n-1}-b_*),\qquad b_*=c/(1-k).$$

对 0≤k<1、0<α_n≤1，因子在 [k,1)；若 Σα_n=∞，误差趋零。严格内部不动点另需 `|c|<1−k`。该条件不需要 b₀ 永久锚定；也明确说明：**“k 小于某数”本身不能保证任意世界偏向下不贴边。** k≥1、越出合法线性域、α 总量有限或世界永久改变，都没有这个保证。不能用 `clip` 把不动点推到边缘后仍报 AC2-25 通过。

真实反馈经过 `b → x → 行为 → 他人回应 → a`，不能把上述 b 代数当真实闭环证明。后继可在声明域内分别界定响应/学习的 Lipschitz 系数，得到非负比较矩阵 K；若能给正权重 v 和 r<1 使 `Kv≤rv`，则加权最大误差每步至多乘 r（由逐分量界直接推出）。这只是可用的证明路线：各系数、域、变动 α 及加入 D05 后的额外状态都尚未界定。无法建立时报告域内实测与反例，不能编造 k_max。

**AC2-25 重写提案：** 在预登记的生活/反馈域检验先验让位、稳定生活的跟踪、同一后续生活下有限扰动遗忘、真实永久变化的可跟随性、超域报警；原“回到原处”明确为生活参照。域外无稳定证明不等于程序故障。V2-97 报警不拦合法成长；新范围/单步界只能抓违约，界内错误仍可能漏检。

## P09-A：替换贡献能证明什么

### 一个可分析的最小状态模型

令扩展快状态为 `(y,{h_c})`，可见 `x=Proj_X(y+Σ_c h_c)`。y 是外部事件驱动的部分，h_c 是已治理依据 c 的内部反应部分；全部由 F 暂存、外层事务提交。H 保存出处与更新，Q 不保存心理强度。每个 h_c 的目标 v_c 只由被记录的评价、固定前态 R/θ 与规律版本确定，不读取当前 x；纯重复执行 `h_c←v_c`，不会执行 `x←x+D_c`。同一依据第一次重访的作用是候选规律允许的内部作用，不给 G/C 新证据；外部事件原始 F 消费与内部重访身份须分别明列，不能靠模糊“首次”重复发放。

这是一种可能的后继状态定义，不是声明现有 FastStateSnapshot 已能表示它。维数、根集合、拆分和相加顺序、投影位置、版本切换须先冻结；以下证明限定在同一已治理支持集合，不处理尚未批准的无限心理槽位。

### 重复不加码与局部非扩张

替换算子 U_c 满足 `U_c(U_c(s))=U_c(s)`：同一个值再次赋到同一位置，数值不增加。若两次重访之间 h 按 Φ 衰减，重访可恢复同一个目标，因此能保持偏离，但不能扩大该依据获准的峰值。**这是贡献不重复发行，不是承诺每个时刻总 x 的绝对值单调下降。** 其他分量的衰减、相反贡献消失以及真实新依据都会改变总 x；检验须分解这些来源，不能以净值抵消掩盖重复发行。

在同一根集合上用度量

$$d_*(s,\tilde s)=\|y-\tilde y\|_\infty+\sum_c\|h_c-\tilde h_c\|_\infty.$$

若两轨迹对同一 c 赋相同 v_c，该项差变为零，其余不变，故 U_c 非扩张。固定事件 D 的 y 平移加盒投影也非扩张。可见投影满足 `‖δx‖∞≤d_*`，由三角不等式与逐坐标截断直接得到。若 y 向 b、各 h 向零以同一允许 Λ 松弛，每一项至多乘 `exp(−λ_min Δ)`，从而 d_* 有对应的同驱动差异界。

**不能沿用旧结论的地方：** 两个扩展状态可能具有相同可见 x 而有不同 y/h。取一维合法端点 `(y,h)=(0,1)` 与 `(1,0)`，可见 x 都是 1；同一次将 h 替换为 0 后，可见值成为 0 与 1。初始可见差为零，后来非零。这里 0/1 只是状态域中的代数反例，不是推荐参数。因此原“只比较可见 x 初值”的 I05/AC2-15 不自动成立，必须选择扩展状态度量或规定相同内部分解的比较前提。若从共同 h=0、y=x 的初始化开始并共享全部后续目标，才可恢复对应旧形式的界。

没有共同根身份/更新序列、v_c 受当前 x 反馈选择、R 回溯改变目标或发生不同模型输出时，上述局部证明不覆盖。更正、别名合并和容量变化需要嵌入共同规范坐标再证明其映射；不允许删一个槽位再换名创建相同根来逃过峰值约束。

### 共享依据与总量，仍需闭合的义务

同一事实的派生结论、摘要和工具回显不能各有满额 h。后继需把已治理根的重叠按一个确定的归属/组合规则处理，旧根的纯重组不能扩大可用贡献集合；若发现此前引用错误，则以明确更正记录修订，不把它称为普通重复。该规则的正确性不能从“有哈希”推出：语义同根、独立新结论和真实条件改变需要可测的识别依据。

对固定有限根、固定 v_c 的重复序列，`Σ‖v_c‖∞` 是不随重复次数增长的贡献上界；它并不是预设心理预算，也不能用新增虚假根任意扩大。若多个真正不同的旧经历陆续首次进入当前认知，可有更强的总感受；这是不同材料的首次作用，须与同一件事反复加码区分。用户若要求更强的“任意内部内容序列的总峰值永不增加”，本候选不证明它，不能用含糊的“不自锁”替代。

## P09-B：一次消费的脉冲

令 C 为已消费的规范依据/修订身份集；对新合格身份 D 按原 F 作用并原子加入 C，旧身份不再产生内部脉冲。固定同一 C/H 与事件输入时，D 不读 x，故 P00 局部证明保留。重放只读取原资格与消费，不能重新判断或清空 C；来源索引缓存可删，权威身份不可丢。首次内部重访与真实新结果的资格合同必须明确，不以无限新 action_id 扩充 C。

若时刻 t* 后再没有合格新脉冲，R/θ 和维数固定，则

$$\|x(t)-x_{rest}\|_\infty\le e^{-\lambda_{min}(t-t_*)}\|x(t_*)-x_{rest}\|_\infty.$$

这是**停止有效驱动后的条件松弛**，不是最后外源输入之后的统一保证；t* 可以任意晚。若未来改成 λ≥0 而无固定正下界，差异界须用积分，积分有限时甚至不能保证趋零。此分支未被本卡自动采纳。

### 为什么不直接采用差分脉冲

设第一次给 +d，经过实际时间后只剩 r·d（0<r<1），再将目标改成零，简单发 −d 会得到 `(r−1)d`，并非零。存在盒截断、多个交错贡献时还可能丢失先前溢出部分，随后逆向差分不能恢复。因而“目标差分相加会自动望远镜消去”的说法缺条件。使用显式贡献状态重新计算可以避免这种错误，但它已经是 A 类的状态改变，不能冒称无状态小修。

## P09-C：COG-A12 的后继命题与保留反例

[R-KAPPA-01](../R-KAPPA-01/DEVLOG.md) 的最小反例保留：任意晚的 t>T_ret，若从静息点允许一个大小超过 ε 的合法新脉冲，就反驳“所有 t≥T_ret 永远留在 ε 内”。这些 ε、T_ret 取该研究定义，不为新规律另造数值。新方案接受晚期新知时，旧命题仍失败；不能将旧失败删除或标成原项 passed。

建议将 COG-A12 受影响部分分成以下子义务，编号由后继正式卡决定：

1. 同一真实依据的重复、改写、回显与换 ID 不重新发行或扩大贡献；A 测替换幂等/峰值不扩张，B 测一次消费。
2. 新的真实结果、真实反证有正例作用；不能靠全拒绝达到第一项。无新长期证据时 R/θ 不增长；内部候选的有效回溯按 COG-A07(b) 单列。
3. 晚期有效结果不因全局 n 或处理队列失格；同样保留权限拒执、旧 Q 保护与 UNKNOWN 不重发。
4. x→m→内生输入闭环在合成世界和真实载体上分别观察：长期饱和、重复、反证后的状态与实际选择。有限轨迹只支持有限域结论，不证明一般认知永不自锁。
5. 执行层对程序重复、资源耗尽和错误派发的保护独立检查；正常长时间在意不触发心理重置或成长暂停。

AC2-15/I05 分为事件局部、含事件的同驱动差异、无输入松弛与扩展状态表示四部分。A 要重写状态度量，B 保留现有状态与 λ 时保住前三项。没有一项被简单地随 T_x 一起删除。COG-A07/08/09/10 和 AC2-10/14 的来源、恢复、资源要求仍保留。

## 数值与证据义务（所有候选共用）

实数等式先给含义，再冻结有限 binary64 的乘加、求和、舍入、log/exp 和下溢/溢出处理。增量与整段重算必须走同一规范递推；另有独立来源/公式核对，避免两个路径共用一个错误互证。浮点容差来自运算误差分析和测试前登记，不能见到失败后加 ε。V2-96 的判定仍是严格越界才触发，等于数学合法界不应被拒绝；舍入包络尚未完成，不能把实数边界直接当实现断言。

普通新反证、来源失效、解释器修正、规律切换分别处理。H 原记录不改；解释器改版才追加新解释，通常重放不调用模型；旧版本仍可重放。新状态需要后继 IDL/CanonicalV1、迁移回退及 SYS17；本卡没有执行这些工作。
