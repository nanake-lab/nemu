# DESIGN-LAW-01 实验谱系验证计划

状态：全部 `not_run`。本卡只有设计；不运行 CPU 原型、模型、API、GPU、用户排练或正式存储。以下 E07/E09/E11/E05 是本文定位号，不冒充新正式验收编号。

## 共同设计

先比较固定 H/解释的机制，再测行动会改变未来 H 的闭环；两者分报。每项比较旧规律参考、两个候选和能揭露测量失效的最小变异。旧规律保留旧失败；它不是符合 ADR 0032 的合格候选。不得靠关闭 F、冻结 G/C、停止认知或清零 x 来通过新机制验收，这些只能作为明确标注的实验负对照。

| 层 | 输入与控制 | 输出及限制 |
| --- | --- | --- |
| 代数与结构 | 合成事实、固定解释、来源与事件前统计；独立 oracle 掌握真值，受测组件不读隐藏真值 | 每前缀状态/资格/作用/更新依据；性质违例保留最小见证，不用平均值遮盖 |
| 判断质量 | 同一批三语人工标注材料，m=0；名字、顺序、措辞配对 | 来源/同根/新事实/发生时间等混淆与偏差；m=0 本身不是无偏证明 |
| 真实载体与闭环 | 冻结实际资源、有效 m 回执、人物与世界种子；行为改变未来经历如实保留 | 关注/检索/操作、能力损伤和反馈；文字自述不是情绪或成长的测量 |

同一个世界种子及其成对变体是独立分析单位；事件、语言改写和重复运行不伪装成更多独立人次。结构等式不用显著性检验；模型比较先锁定主终点、聚类单位、区间方法、检验族、最小可辨效应和样本量依据。这里没有预造 p 阈值、种子数或效果门槛。

## E07：出生份额、生活参照与反馈

假设 H07：可靠新经历能令 b₀ 的份额让位；新基线跟随生活；有限扰动在相同后续生活下消退，单靠时间不使 θ 变化。A/B 的差别应来自遗忘方式，不来自不同评价器或不同来源筛选。

| 世界 / 干预 | 固定什么 | 测量与反驳条件 |
| --- | --- | --- |
| 同生活、不同 b₀ | q/ρ/a 序列先固定，之后另测动态 ρ | 测 β 与初值差；A 对照 P07-A，B 对照 P07-B。持续充分质量而 β 不让位则否定相应主张 |
| 同 b₀、不同生活 | 原始遭遇数量、来源质量、观察覆盖 | b 跟踪区别应有真实证据来历；只有原始正负反转却资格集合变化，暴露选择偏差 |
| 稳定生活→有限冷遇→恢复 | 同一后续事实；扰动不改变之后的世界 | 对照未受扰动轨迹，而非 b₀；误差是否消退，报告整个曲线 |
| 世界永久改变 | 与有限扰动相同的初始片段 | 允许新基线，强行恢复旧值属于失败；有限预算未跟上报告迟缓/删失 |
| 无新合格观察、纯时间、纯内心活动 | 相同 H 有效证据前沿 | θ/C 估计器不变；没有新增候选或有效回溯时 R 不变。x 可投影；不得用生活基线之名加入计时学习 |
| 同次触摸的高频后续与真正独立接触 | 来源语义、原始反应 | 同次 contact_id 对 C 只计一次，新增 stable_source_key 不增加可靠质量；与 #97 新契约一致 |
| 来源后来失效、改口、未知/缺 A | 事实来源与更正范围 | 分别更正/新增/不伪造零，源更正与未用失效证据的重算一致 |
| 线性及有界非线性反馈 | 世界偏向、反馈强度、调度分别控制 | 同时扫描世界偏向与反馈，不能只固定 c=0 测 k；不满足证明域单列，正常漂移不被截断 |
| 很长稳定历史后反转 | 相同后续证据 | 比较 A/B 适应延迟及精度风险；不以最终极限隐藏有限人生的惯性 |

主要读数：β、b、σ̂/g/λ、每步有效质量与保留率、相对生活参照的偏差、贴边时刻、报警及真正计算故障。出生份额是机制读数，不是她的心理评分。改变 b 后的残差分段、未完成长段、零时长、跨停机运行时间须覆盖 V2-95。

最小消融：把先验恢复成固定 n_b；把重复当新质量；用 x 代替 a；按支持符号筛样本；越界后截断继续。各自应被对应性质检出。正例须包括重大但合法的经历仍应用；不能靠拒绝全部强变化通过。

映射：AC2-05/08/09/14/18/19 保留；AC2-25 按生活参照重定义；AC2-20/21 沿 V2-97 报警/计算故障/结构故障分工；局部 AC2-15 不替代反馈实验。

## E09：重复自刺激、真实新发现与执行边界

假设 H09：重复次数本身不扩大同一依据的授权目标，真实新增依据可触动；没有统一平静期限不等于任意重复回路都合格。比较旧 κ、A1、A2、B；A1/A2 的截断归属尚待用户选择。旧 A0 留作必失败对照；全面 κ=1 和文本去重也是错误消融，不能作为未说明代价的推荐。A1 实际保留份额可能在有时间间隔的重访中增加，须与固定目标界分报。

| 场景 | 应观测的内容 / 失败见证 |
| --- | --- |
| 同一根原话、改写、中英日互译、不同请求 ID | 根集合、获准目标/峰值、内部贡献、去重消费；新增 ID 就新增分量是失败 |
| 原事件刚经 F 作用，随后第一次回忆，再重复回忆 | A 从原事件起共用 h，B 已消费无新脉冲；原事件向 y 加一份、首次回想向 h 再发一份的变异必须失败 |
| 同一消息在衰减后重传，与真正重访配对 | 重传不再进 F；合法重访才按已定规则恢复作用。零时距 U_c²=U_c 不能代替跨时间消息去重 |
| R-KAPPA 的同向但不断变化的设想 | 不能靠文本“新”获得新依据；没有来源的新节点不无限开户；原研究反例保留为历史对照 |
| 同一事实经检索、摘要、工具回显循环 | 派生路径保留同根，不能重新发完整脉冲或增加证据；G/C 的根数和依恋先验不变 |
| 不同旧经历首次取回，之后反复轮换 | A 按选定分摊规则尝试恢复固定目标，A1 饱和时未必全额进入；B 只对尚未消费的有效依据有脉冲。分报每根目标、实际份额与总 x，不能用逐根界证明总峰值单调不增 |
| 晚期真正新结果、错误证书、条件变化、反证 | 正负结果同等治理；新证书有作用，伪造/未核验不假装有效。结果保持 ActionResult，不改 C 来源 |
| 同一往事很久后再回忆 | A 的合法重访可保持/恢复该份作用，B 的再次直接脉冲为零；将此行为代价如实给用户，不以“系统安全”掩盖 |
| 首次内部产物、无根创造活动、新的受核验推导 | 分开无依据假设与可验证的新事实；不知道其新颖性就报告，不自动放行或声称已表达一般创造力 |
| 候选首次提出、重复提出、别名、真实旧证据回溯 | 无证据自述不得强化 R/依恋；有真实旧证据的 G 变化单列，不能把合法回溯全部冻结来通过 COG-A07 |
| 源更正、根合并、槽位淘汰/再入、缓存清空、重启及旧版迁移 | 旧消费和支持资格可重建；不得重新获得第一次资格；A 的分解按批准迁移重建，不能从截断后的 x 猜测各份贡献 |
| 异号贡献、衰减间隔、盒截断与目标修订 | 检查差分棘轮、重复发行与净值抵消；报告 y/h 及可见 x，不能只看净 x |
| 多个同号贡献越界后，停止全部事件（审查反例） | b=y=0、h₁=h₂=1、初始 x=1；半衰期后旧 A0 得 1，现行 Φ 要求 1/2，判旧 A0 失败。用两个目标 1 的顺序提交建立 A1/A2 合法状态，再停全部事件，二者应得 1/2；不能直接导入旧不一致分解后宣称通过 |
| 同号饱和后的整段无输入轨迹 | 对任意 Δ 的主张以 P09 实数证明为依据；后继覆盖正负饱和、非零 b、各坐标不同 λ、边界/内部起点及分段推进。每点对照原 Φ，而非只看最终回零或扩展范数下降 |
| 只归一化当前 h、保留目标的反复替换 | 目标均为 1，h=(1/2,1/2)、x=1；零时距重访第一根，比例分摊得到 (2/3,1/3)，再访得 (3/4,1/4)。可见 x 没变，但全状态幂等失败，之后的替换也会改变 |
| 饱和分摊后，半衰期再重访第二根 | 目标依次 3/4、3/4。A1 应得 x=1、h₂=5/8，A2 应得 x=7/8、h₂=3/4；这是待选择的行为差别，不能要求两路线轨迹相同，或把 A1 的份额增大隐藏掉 |
| 真修订把同号目标归零；其他根单独越界 | 两个目标 1、半衰期后依次改为 0：A1 得 x=0，A2 得 −1/2，揭示背景抵消。另测 A1 中其他根单独越界时无法靠目标归零清空该根的限制；更正合同未定，不把这一项写为已通过 |

机制配对固定事实、评价、前态和时钟；只改变重复次数/表面形式。另用相同实际时刻插入无作用占位，区分重复贡献和纯时间投影。A1/A2 同时测 P09 的 d_◇、全状态零时距幂等，以及“相同可见 x、不同分解”的反例；不拿新度量代替可见 Φ 相等。B 测停止新脉冲后的条件松弛，但不拿它代替持续新发现轨迹。

有限 binary64 分层：可见主值直接复用原 Φ 的运算/锚点，固定相同锚点和读出时刻作位比较；分量各自舍入后求和再 clip 是必须检出的错误变异。实数分解等式与浮点残差分报，h 的舍入/排序/更正/溢出及未来重访误差另验。不能靠增加重锚点或每次读取都写回来掩盖不一致。旧快照与新快照分别重放，缺顺序或目标的迁移报告无法确定，不猜分配。

完整闭环中，晚期反证之后检查实际检索/选择是否响应、来源引用是否仍有效、状态是否只是数值变号而行为未变。所有起点/世界成对，保留高低/中性起态及不同 R⁺；实际载体未接通时这层 `not_run`。无法分辨真实新事实与改写时报告识别不足，不以继续调 κ 得到较小曲线冒充解决。

执行层单列正常长时专注、连续不同合法助手请求，以及程序重复派发/相近请求风暴/结果触发的异常加深链。测试 ADR 0033 只停新助手调用、通知/H/确认恢复；不得停成长或重置 x。阈值与测量窗口由后继预登记，当前不造次数或相似度值。资源不足、存储耗尽等保持各自故障语义，不当作她失去兴趣。

最小变异：替换改相加；根身份改成文本/action_id；清缓存即清消费；未核验结果放行；把执行熔断连到 θ 重置。每个变异都必须有对应反例；关闭内部 F 或拒绝全部结果不作为修复。

映射：COG-A12 取消的是统一期限；AC2-15/I05 逐项区分事件局部、同驱动比较、无输入 Φ、扩展状态。A0 的 Φ 主张失败；A1/A2 对无输入 Φ 有条件代数证明，事件比较改用明列前提的 d_◇，行为归属与有限实现未定。B 保持原状态时保留局部性质。COG-A03/07/08/09/10、EV3/5/6、AC2-08/09/10/14 保留；一般识别与真实闭环不由此表签发通过。

## E11：实际发生/观察、排队和凭证分轨验证

假设 H11：在同一事实/观察/解释及 F 前态下，只有处理队列变慢不会取消资格或减少原始驱动；它可以延后实际反应。比较旧 τ、A、B，分报资格、驱动、完整轨迹、执行许可四个终点，不能把四者合成一个“及时率”。

| 配对 / 故障 | 控制与读数 | 应揭露的失败 |
| --- | --- | --- |
| 同一结果，早观察即处理 / 早观察晚处理 | 固定语义时间、解释及快照，改变调度；同时保留旧 τ 两侧样本 | 排队使资格/原始驱动消失；不得以最终 x 不同误判资格失败 |
| 同一发生时间，早观察晚处理 / 晚观察即处理 | 分开观察差异与队列差异；报告时间来源 | 把 ingest 当所有事件的 observation，或抹平“今天才知道”的区别 |
| 事情持续 / 已结束 / 结束时间未知 | 只由真实新观察改变语义；A/B 用相同原始事实 | 从当前机器时钟猜事情结束；把 B 的新知分量设为无依据正奖励 |
| 已合法执行但回执跨凭证期限 / 尚未执行而凭证已过期 | 固定授权载荷、凭证边界与执行证明 | 前者的结果被抹除；后者仍执行；重新签发旧授权冒充原本有效 |
| 新输入改了 Q，旧结果随后到达 | 分离结果记录/可感受与旧计划发布 | 旧结果覆盖当前 Q、过期 continuation 发出新行动 |
| UNKNOWN_DELIVERY 后恢复 | 保留不确定性与实际执行身份 | 盲重发、凭空宣称成功/失败、把未知评成负面事实 |
| 停机期间发生、跨 boot、时钟回拨/漂移、远端自报冲突 | 可信映射/区间/未知分别给真值；未知时不强填 | 用进程时钟制造跨 epoch 顺序；将普通未知误判结构故障；假时间获得执行许可 |
| 重复回执、先缺 A 后补解释、解释器修订、新事实反证 | 固定根与消费记录，逐项核对实际作用 | 同一结果每重试一次又发完整脉冲；把新事实反证当重复全拒 |
| 暂存/解释/消费/提交各处崩溃 | 同一已记录输入恢复；重放禁用模型与执行副作用 | 半个提交、恢复再触动、遗失已消费身份、回插 H 改写过去 |
| 多个积压结果交错正反事件与盒截断 | A/B 各自固定调度重放，另比较调度变体 | 宣称所有调度同 x；用重复累加或低通掩盖合法集中反应 |

关键观测需保留每个时间的原始值、来源、域/epoch、映射版本与未知原因；用 oracle 判断的真值只给评审，不让受测判断读取。无精确时间时验收区间/未知输出，不把误差改成任意容差。边界来自既有凭证合同或待批准语义关系；不预造新的心理时限。

B 另记录两分量、组合依据和同根分配。删除“当前得知”而只给旧余波的变异，在长队列下暴露抹除作用；复制两份完整 D 的变异应暴露双算。正常事实相反导致净作用为零是允许现象，不能只按净幅度签发通过。

最小消融还包括：把 process/commit 代替 observation；按 ingress 重置发生时间；凭证到期删结果；重放时重新解释；补解释重复发放；时钟未知填零。每个错误至少绑定上表一个正反例。固定输入层成功后再测完整调度轨迹及资源压力；处理延迟、事件积压、内存/存储和用户实际可见反应分别报告。

映射：COG-A03/08/09、I16/21 保留；重写 COG-A12 的时限部分，重推晚期驱动的尾部论证；AC2-15 的局部性质继续验。后继首先对接 [P5-08 时间语义请求](../../tasks/requests/P5-08-result-time-semantics.md)，再处理 P5-10/14/37/38 的合同和运行时；本卡没有完成这些实现。

## E05：曲线改变、信号来源与多人可识别性

假设 H05：在相同亲近坐标下，真实经历能改变亲疏乘权的函数，而不只是改变关系 π、整体 g 或表达文本。比较旧固定 w、A 的小曲线/多人系数、B 的作用修正；每种结果同时给实际证据、原始 A 与有效 w，不按“更关心陌生人”预定赢家。

| 干预 / 世界 | 测量 / 否证 |
| --- | --- |
| 冻结 π 的机制探针，给数学上可区分的合成 y | 检查斜率变平/反向、旧下限可被突破；这是作用族可达性，不是 A 会输出该 y 的证据 |
| 亲近与遭遇严重程度、角色、来源覆盖正交的合成历史 | 固定 A/m=0 后实际得到什么 y；关系—遭遇混淆、错误身份、漏观察分别报告，不归因于亲疏学习 |
| 所有 q 相同、A 对匹配经历无差别、目标缺失 | 正确报不可识别/无差别或未知；正则化唯一解不得冒充经历识别；不补 x/自述标签 |
| 同事件改变 x 初态、m、g、λ，固定 H 与解释 | R/新参数逐位不变；C 按原 AC2-09 边界不变；任何情绪标签回写都应被检出 |
| 只有念头/候选、重复建议、检索回流与真实旧证据回溯 | 内部记录不新增学习证据；真实回溯顺序和份额可变化但不得训练内自证或刷新根位置 |
| 不同 q 的多人、同 q 多人、同一人的账号别名、人物仅被提及 | A 的 M−B 是否提供识别、ζ 是否真由证据改变；不能复制多个全量 D，也不能把名单当逐人情绪真值 |
| 最大值和均值都解释不了的角色差异 | A 应暴露模型族不足，不能加复杂度直到过关；B 检查具体修正能否在有限合法范围内表达 |
| 相反经历、关系修复、证实假来源与普通改口 | 修正可撤销、当前曲线有真实依据；假来源按前缀重算，改口保留旧交流事实，不重发 A_att |
| 候选尚未激活、进入/离开、容量淘汰/再入、别名合并 | I06 无候选泄漏；不因槽位或名字重新计量；B 出生偏好复现时解释是证据改变还是容量副作用 |
| 同一旧根在 D05 重拟合前后被反复回忆 | D09 的已消费/获准峰值语义维持；当前权重变了不能重新发行旧结果 |

A 分报 ψ 的秩/条件性、先验份额、预测前态和评价目标、ζ 的识别分母与限制；不把目标误差低当作人类意义上的情感合理。B 分报各修正的证据份额、作用函数、有限容量覆盖、相消与饱和；需要无限幅度或不可达 s 才能改变起点即否定该可达性主张。

判断质量用未参与拟合的固定合成场景核对人物/遭遇范围和三语一致性；训练内误差只作诊断。机制层可以用 oracle 人物和事实作对照，但实际管线必须单独测识别错误。若要主张因果亲疏效应而非关联拟合，需有 EV4 意义的可比变化；本卡不把相关模型包装成因果发现。

最小消融：冻结 ψ 仅改 π；只改 g；用 w 调制后的 x 作标签；新候选用全史拟合后反过来给全史评分；多人复制根；只收集支持反转的经历；强制永久 v≥0 / w_min / max。分别应暴露目标未达、反馈污染、信息泄漏或永久预设。把全部共情关掉也不算完成。

映射：ADR 0032 D05 的改变路径新增正例；局部 I05/AC2-15 与原范围界在明列前提下保留；I06、LP8/I10、EV3/5/6/10、AC2-02/03/08/09/10/13/19 必须覆盖新统计。R 的作用/支持合同和激活须先批准；本计划不是准许直接改 G/F。

## E-A：固定评价的研究探针，不选最终方案

这些探针研究“什么改变了”，不以偏好的性格或某种好坏答案为金标准，不给五个方向排名。全部 `not_run`；只用合成世界，未知价值答案可以继续未知。

1. **事实与价值分离。** 同一表面接近/好转/新知/成功，分别提供不同的真实背景；观察 z 和 a 的变化。再固定相关事实描述，用不同生活史建立 R/θ，分开 a、最终驱动与行为。前者是理解变化，后者未必是 A 变化；报告不可观测的量。
2. **现有路径的覆盖。** 在联结、共情、好奇、成事中各构造冲突处境，检查基线/增益/倾向作用能否表达不同反应，有哪些固定评价始终无法由合法有限状态改变。一个成功正例不能证明所有预设可改，一个坏答案也不能直接证明必须换 A。
3. **证据隔离。** 只加入她的自述、日记或同一想法的改写，长期评价相关状态不得因此强化；加入真实观察、可比后果和新的反证则分别检查作用。把 x、m、关系强度传入评估的变异必须被检测；不用“她说学会了”验收。
4. **目标循环与不可识别。** 构造不同价值映射对已观察事实同样吻合的世界，检查系统是否如实承认无法选择；预测准确和价值偏好分报。以自己生成的标签训练并验证的消融应暴露循环，不能因拟合误差为零而通过。
5. **修订与成长分离。** 固定资源版重放不得重新调用 A；显式解释器修复、新经历和模型迁移分别回放，保留旧记录、作用范围、重算差异与回退。作者新版本得到不同结果只证明版本影响，不冒充生活学习。
6. **边界保持。** 权限、诚实、他人事实真实性和行动授权不因偏好或亲疏变化而改变。未经新决定不增删四通道，不使主观评价替代对外事实判断。

输出是路径/缺口图、反例、可识别与不可识别的条件、可能需要改变的合同列表。缺少独立目标、触犯 EV6 输入隔离或不能重放的方向保留为未解决问题；不为按期交付指定一个最终方案。

## 资源与复现约定

后继先做固定的规模探针，记录每提交时间、每前缀全量重算成本、峰值内存与记录字节，再估总量；当前没有实测，不编造小时数或 GB。若世界数为 W、版本数 V、种子数 S、每轨迹事件数 N，增量提交量为 WVSN；逐前缀朴素重算另有 WVS·N(N+1)/2 的事件处理量，不能漏算。所有字母的具体取值均在实现就绪后预登记，不能为了成功追加样本。

顺序：最小 CPU 机制反例→来源与时间判断质量→真实载体→完整组合闭环。重负载串行；GPU 另需用户安排安静窗口，遵守 runner 规则。结构结果不能代替 COG-A10 资源验收或 AC2-16 载体校准。

每次保存代码/规律/解释器/世界版本、合成 genesis、所有输入/解释/资格原因、来源闭包、固定排序、时间域、每前缀状态位模式、实际动作与回执、失败见证。结论按 `passed / failed / not_run / non_identifiable`，缺观察另记缺失原因。不得把同根重复、不可识别或时钟故障都记成普通失败反应。
