# DESIGN-LAW-01 实验谱系验证计划

状态：全部 `not_run`。本卡只有设计；不运行 CPU 原型、模型、API、GPU、用户排练或正式存储。以下 E07/E09/E11/E05 是本文定位号，不冒充新正式验收编号。

## 共同设计

先比较固定 H/解释的机制，再测行动会改变未来 H 的闭环；两者分报。每项比较旧规律参考、两个候选和能揭露测量失效的最小变异。旧规律保留旧失败；它不是符合 ADR 0032 的合格候选。不得靠关闭 F、冻结 G/C、停止认知或清零 x 来通过新机制验收，这些只能作为明确标注的实验负对照。

| 层 | 输入与控制 | 输出及限制 |
| --- | --- | --- |
| 代数与结构 | 合成事实、固定解释、来源与事件前统计；独立 oracle 掌握真值，受测组件不读隐藏真值 | 每前缀状态/资格/作用/更新依据；性质违例保留最小见证，不用平均值遮盖 |
| 判断质量 | 同一批三语人工标注材料，m=0；名字、顺序、措辞配对 | 来源/同根/新事实/发生时间等混淆与偏差；m=0 本身不是无偏证明 |
| 真实载体与闭环 | 冻结实际资源、有效 m 回执、人物与世界种子；行为改变未来经历如实保留 | 关注/检索/操作、能力损伤和反馈；文字自述不是情绪或成长的测量 |

同一个世界种子及其成对变体是独立分析单位；事件、语言改写和重复运行不伪装成更多独立人次。结构等式不用显著性检验；模型比较先锁定主终点、聚类单位、区间方法、检验族、最小可辨效应和样本量依据。这里没有预造 p 阈值、种子数或效果门槛。

## E07：出生份额、生活参照与反馈

假设 H07：可靠新经历能令 b₀ 的份额让位；新基线跟随生活；有限扰动在相同后续生活下消退，单靠时间不使 θ 变化。A/B 的差别应来自遗忘方式，不来自不同评价器或不同来源筛选。

| 世界 / 干预 | 固定什么 | 测量与反驳条件 |
| --- | --- | --- |
| 同生活、不同 b₀ | q/ρ/a 序列先固定，之后另测动态 ρ | 测 β 与初值差；A 对照 P07-A，B 对照 P07-B。持续充分质量而 β 不让位则否定相应主张 |
| 同 b₀、不同生活 | 原始遭遇数量、来源质量、观察覆盖 | b 跟踪区别应有真实证据来历；只有原始正负反转却资格集合变化，暴露选择偏差 |
| 稳定生活→有限冷遇→恢复 | 同一后续事实；扰动不改变之后的世界 | 对照未受扰动轨迹，而非 b₀；误差是否消退，报告整个曲线 |
| 世界永久改变 | 与有限扰动相同的初始片段 | 允许新基线，强行恢复旧值属于失败；有限预算未跟上报告迟缓/删失 |
| 无新合格观察、纯时间、纯内心活动 | 相同 H 有效证据前沿 | R/θ 和所有估计器不变，x 可投影；不得用生活基线之名加入计时学习 |
| 同次触摸的高频后续与真正独立接触 | 来源语义、原始反应 | 同次 contact_id 对 C 只计一次，新增 stable_source_key 不增加可靠质量；与 #97 新契约一致 |
| 来源后来失效、改口、未知/缺 A | 事实来源与更正范围 | 分别更正/新增/不伪造零，源更正与未用失效证据的重算一致 |
| 线性及有界非线性反馈 | 世界偏向、反馈强度、调度分别控制 | 同时扫描世界偏向与反馈，不能只固定 c=0 测 k；不满足证明域单列，正常漂移不被截断 |
| 很长稳定历史后反转 | 相同后续证据 | 比较 A/B 适应延迟及精度风险；不以最终极限隐藏有限人生的惯性 |

主要读数：β、b、σ̂/g/λ、每步有效质量与保留率、相对生活参照的偏差、贴边时刻、报警及真正计算故障。出生份额是机制读数，不是她的心理评分。改变 b 后的残差分段、未完成长段、零时长、跨停机运行时间须覆盖 V2-95。

最小消融：把先验恢复成固定 n_b；把重复当新质量；用 x 代替 a；按支持符号筛样本；越界后截断继续。各自应被对应性质检出。正例须包括重大但合法的经历仍应用；不能靠拒绝全部强变化通过。

映射：AC2-05/08/09/14/18/19 保留；AC2-25 按生活参照重定义；AC2-20/21 沿 V2-97 报警/计算故障/结构故障分工；局部 AC2-15 不替代反馈实验。

## 资源与复现约定

后继先做固定的规模探针，记录每提交时间、每前缀全量重算成本、峰值内存与记录字节，再估总量；当前没有实测，不编造小时数或 GB。若世界数为 W、版本数 V、种子数 S、每轨迹事件数 N，增量提交量为 WVSN；逐前缀朴素重算另有 WVS·N(N+1)/2 的事件处理量，不能漏算。所有字母的具体取值均在实现就绪后预登记，不能为了成功追加样本。

顺序：最小 CPU 机制反例→来源与时间判断质量→真实载体→完整组合闭环。重负载串行；GPU 另需用户安排安静窗口，遵守 runner 规则。结构结果不能代替 COG-A10 资源验收或 AC2-16 载体校准。

每次保存代码/规律/解释器/世界版本、合成 genesis、所有输入/解释/资格原因、来源闭包、固定排序、时间域、每前缀状态位模式、实际动作与回执、失败见证。结论按 `passed / failed / not_run / non_identifiable`，缺观察另记缺失原因。不得把同根重复、不可识别或时钟故障都记成普通失败反应。
