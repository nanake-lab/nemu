## 2. D07：生活塑造基线

### 2.1 先发散

| 形式 | 值得考虑的原因 | 去留及原因 |
| --- | --- | --- |
| 旧式：固定 n_b·b₀，旧经历持续折扣 | 简单，能压低反馈放大 | 排除为新方案：经历有效量有上界时，出生分量永久占比，不符合目标 |
| A：先验与经历共同折扣的归一均值 | 一条递推；先验不会在旧经历消退时重新占上风 | 入围；必须证明持续可靠经历下出生份额趋零 |
| B：不遗忘的终生加权均值 | 不需额外恢复锚点；出生份额有直接解释 | 入围；长期经历会带来越来越大的惯性 |
| 中位数、分位数或稳健损失中心 | 对少数异常值不敏感 | 不优先：重大但真实的一次经历可能被制度性压低；“异常”不能等于不喜欢的生活 |
| 多情境/多生活阶段的基线混合 | 可表达“独处、和朋友在一起不同” | 暂不入围：改变单一 b 的语义，需情境识别、切换与新状态，先没有必要 |
| 变点后整段重新开始 | 对长期环境变化反应快 | 暂不入围：误报会突然丢掉旧经历影响；隐藏的重置不是自然遗忘 |
| 扣掉“她自己引起的回应”的因果残差 | 理论上可分辨外部环境与反馈 | 暂不入围：单条自选行为轨迹通常不能识别反事实；不能把世界真实回应剥除，或让 C 偷读 x/R |
| b 由可回查的典型生活片段直接检索重建 | 不必固定均值几何，较非常规 | 暂不入围：检索预算、相似度、摘要选择会成为新先验，难于简单且逐位一致 |
| 潜在状态模型/贝叶斯生活阶段后验 | 可显式表达不确定性 | 暂不入围：模型/先验/推断误差多，尚无证据需要这层复杂性 |

### 2.2 共同语义：什么叫可靠，回到哪里

可靠经历指来源和适用资格已满足、可追溯且未重复计量的**合格外源观察**，不是“正面且符合预测的事件”。D13-A 的发生/属实/主观按目标分开：真实听到主观表达可以是交流经历，不能因此把其中外界断言当真。无依据、A 缺失及未知结果不伪造 a=0。真实反证仍收集。资格及分组只看受治理记录，不读 b 的喜恶、x/m 或亲近度；C 不取 G 按倾向分摊后的份额。

下述 a_c 是候选 C 输入的合格反应，q_c≥0 是其计量质量；q_c 不是新“可信分”。精确沿用哪些独立观察单位、同次接触怎样归约、混合观察如何合一，须由后继合同冻结；不能把相同 H 的采样频率增加当作更多可靠经历。第一轮比较固定输入单位，另测归组敏感性，不擅自改 D21 或 D13-A 的资格。

“扰动后回到生活基线”至少有两种情形：世界恢复相同稳定规律时，与未受扰动的同源对照在后续相同经历下逐渐接近；世界真的变了时，允许形成新的基线。不能要求回到扰动前某个瞬时数值，更不能要求回到 b₀。**若没有新的合格外源经历，θ 保持不变；单靠等待只能投影 x。** 这同时保住 LP5/AC2-05。

### 2.3 D07-A：共同折扣，出生经验不再永久豁免（推荐）

形式：把出生先验质量 P、其有符号贡献及真实经历的分子/质量用同一个本步保留率 ρ 缩小，再加入 q_c·a_c 与 q_c。只在合格新经历到来时推进；P 起点来自待冻结的 n_b，不另设“几天后成人”。出生份额为 P/(P+S)，基线是同一总分子/总质量。其均值形式、出生份额递推及界见证明 P07-A。

**她会怎样变化：** 稳定、可靠的温暖相处逐渐主导 b。后来持续冷遇能够改变它；恢复正常相处后，冷遇的影响随新经历让位。不会因为过去权重被折扣，反而露出更大的出生锚点。长期无新经历时，出生份额也不凭时间减少。

**风险与防护：** 可能更快跟随冷暖反馈，甚至贴边；这不是计算错误的充分证据。真实极端经历照常进入，报警不拉回。假来源和重复样本在入口治理；统计量非有限、分母丢失、状态与来源不一致才按计算违约处理。共同折扣中 ρ=0、质量下溢、极小新权重的精确数值处理须另定，不能用偷偷补 ε 或截断成长处理。

**证明与验收：** 固定 b/R/θ 的 ADR 0008 局部 F 性质仍可沿用；移动 b 的完整系统不能套同一静息点。V2-96 的出生先验回拉项消失，须重推 Δb、残差方差/g 及 λ 的连带影响。AC2-25 改为生活参照、持续新经历、明确反馈域的跟踪与扰动遗忘；旧 THETA-2 的永久出生锚定证明不能沿用。AC2-08/14/18/19 继续约束全部估计器。

**实验：** E07 对比同一生活/不同 b₀、不同生活/同一 b₀、长期冷暖转换及反馈强度。记录出生份额、跟踪误差、饱和与报警，不以“她最后开心”判优。若可靠经历持续但出生份额无法让位，或旧来源更正后先验异常复活，方案失败。

### 2.4 D07-B：终生证据均值

形式：P 保持有限；真实经历质量和分子只累积，不按新近性折扣。b=(P·b₀+Σq_c a_c)/(P+Σq_c)。没有第二个“长期基线”，这个均值本身就是生活基线；与 A 的区别在于不主动忘却旧经历。

**她会怎样变化：** 很长时间被善待，会有厚实的平常安心；短期冷遇的影响较小。环境真的变坏时也能改变，但越长的人生越可能需要较长的新经历。不是永久出生锚定，却可能成为对过去生活的强惯性。

**风险与防护：** 不应把慢变化解释为成熟或稳定优越。质量增长、binary64 中微小增量不可表示须显式报告，不能暗设证据容量恢复适应速度。更正需重算；不按正反删掉旧样本。此选项改变 θ 的新近适应假设，不能误称完全保留旧 C。

**证明与验收：** 出生份额在累计可靠质量无界时趋零，有限扰动在相同后续无限质量下的占比趋零；没有历史长度无关的速度保证。Δb 是归一新增权重乘 a−b。AC2-25 的新定义仍需反馈域；变环境适应速度须与 A 单列，不能用最终极限掩盖有限人生中的迟钝。AC2-08/14/18/19、局部 AC2-15 同 A；C 的新近性相关验收需改，G 的 ADR 0019 不随之改变。

**实验：** E07 增加稳定历史长度与同一后续反证的配对，观察适应延迟及删失，不为它规定几组必须改变。B 作为最简单的参照很有价值；不推荐作默认候选，原因是对变化生活的迟缓风险。

### 3.2 防循环的准确对象

分三种：传输重复必须幂等；无新依据的复述、换语言、查询回流及自己的总结不得新增感受贡献；真正新观察或可独立核验的新结果可以触动。第三种**不是**成长资格：工具结果不进入 C，G 仍核对 EV4。

“同一依据”沿可追溯来源闭包和已核验事实身份，不能用文本、候选名或 action_id 代替。纯设想没有外部根时属于同一个未新增依据的内部支路，不能靠自建子节点不断开户。新的旧记忆第一次被取回、对既有材料得到可核验的新结论、真实条件改变，可能有新增依据，但必须有可查差异；未知新颖性保持未知，不能由模型自评“我想通了”升级。

两候选都提出比“盒内有界”更具体的检验：固定合格依据、评价和版本，复制内部活动不得扩张该依据已经获准的贡献；它的**重复次数**不能使同一贡献的峰值不断上升。总 x 可以因时间投影、其他真实经历、第一次取回不同历史或反证改变；不能把这些全归为重复刺激。该判据是新 COG-A12 的设计提案，需用户确认，不把旧统一回落测试改名为通过。

### 3.3 D09+D10-A：同依据占同一份贡献，重访替换（推荐）

形式：将显示给 J 的快状态表示为外部响应部分 y 与内部重访贡献的确定投影。每份规范依据 c 的内部贡献 h_c 有已记录的评价目标、来源、版本和时间锚点；**相同依据重访只替换同一 h_c，不向总 x 再加一份 D**。固定依据与评价时，重访不得提高该贡献的获准峰值；换一种说法、反复经工具取回不更新资格或峰值。可在重访时恢复同一强度，因此可持续在意，不要求统一回落。

新依据才可注册或依法修订贡献。相反的新结果不是把旧难过的文字改成开心，而是另有真实依据的修订。内部 h 是 F 管理的显式快状态，**不塞进 R、θ 或 Q 伪装长期信念**；Q 只保管请求和引用，H 记录依据及获准更新。贡献生命周期、共用根的重叠分配、合并/别名/更正和有界存储必须在后继合同闭合；淘汰缓存不能恢复“第一次”资格。

**她会怎样变化：** 想起朋友的冷话时仍会难过，继续想可以维持那份难过；同一句话被改写成许多内心句子不把它堆得更重。朋友后来解释，或她找到确实不同的新材料，可以改变感受。没有新证据时 R/θ 仍不强化。

**风险与防护：** 误分为多个依据会重复加码；把不同真实经历误合并则会麻木。只能用受治理的来源关系防前者，用正反和新事实正例查后者，不能把所有内部活动禁掉来“通过”。内部产物首次评价仍可能有模型偏差；固定一次贡献不是证明该感受正确。对无根的不同创造活动不能保证语义上全部区分成功，这是明确的识别限制。

**证明与验收：** 重复替换在 h 上幂等，平移加投影在固定 h 下仍非扩张；但这是扩大后的状态空间，不能直接声称旧 x 的 AC2-15 全部原样成立。P09-A 给出何时能恢复旧差异界和何时只能得到扩展范数界。保留现行无输入指数 Φ 及 V2-95 的估计规则作为第一版模型假设；取消全局 T_ret/T_x 保证不要求先改 λ。持续重访可保持偏离，所以 COG-A12 改验重复不加码、反证可进入和执行层隔离。完整 x→m→产物闭环仍须独立实测。

**实验：** E09-A 比较固定根重复、多个旧根交错、同根多语言改写、纯设想不断改内容、来源更正和真实新结果。独立关闭“替换”而改“相加”的变异必须被检出。只看到有限窗没有饱和，不是证明无限未来无自锁。

### 3.4 D09+D10-B：新依据一次脉冲，保留原快状态形状

形式：首次合格依据或有真实新增部分的修订可经 F 发一次脉冲；消费身份和来源闭包在 H/Q 原子记录。重复取回同一依据没有新脉冲，仍可以进入认知材料和表达。区别于 ADR 0026 被排除的“每条念头一次”：按真实依据而非不断变化的念头身份去重；无新依据的设想不能靠换主题制造无限脉冲。新结果不继承全局 n 折扣。

**她会怎样变化：** 第一次想起一件事有触动，再反复想不继续加码；第一次解出一个新问题仍有作用。代价很直接：同一段重要往事过很久再想起也不再次产生直接脉冲，可能过于淡薄。不能把这一代价藏成纯工程去重。

**风险与防护：** 与 A 相同的身份/新颖性问题；还可能因为去重太强，把不同事实的真实认识当成重复。资格不足须报告，不能退回“每个新字符串一次”。旧消费记录不能因过期、缓存淘汰或重启消失。模型自述不能解除消费标记。

**平复形式与证明：** 最小版本保留旧指数 Φ 和 λ 的现行正下界；此时停止合格新脉冲后仍有**从最后有效脉冲算起**的条件回落，但从最后外源事件起的统一保证没有了。另一个可研究分支是让 λ 的恢复尺度完全由合格外源持续时间学习，取消固定正下界；这需另批，会失去统一严格收缩甚至无条件趋向静息的保证，不作为 B 的默认附带改动。V2-95 未完成段不计入的盲点必须报告，不能偷偷换成右删失模型。

**验收与实验：** B 的同历史消费状态下，D 仍不读当前 x，原 F 局部证明保留；异步结果很晚首次合格仍可推动 x，COG-A12 的统一期限仍须重写。E09-B 加“很久后再回忆同一事实”的代价探针；新事实、反证和无来源假设必须分开。推荐 A 是为了保留反复在意的能力；B 是结构更小、行为代价更大的可选方案。

### 3.5 执行层的保护

资源耗尽、重复派发、错误 continuation、失效依赖、无限重试按执行事实处理，既不按情绪强弱触发，也不设置“想同一件事多久就换话题”。沿 ADR 0033：助手循环/异常高总量触发时只暂停新助手调用，记 H、通知、用户确认恢复；不扩大成暂停她、G/C 或持续认知。阈值尚待测量批准，不挪用旧 30 次或旧 κ/r/M/τ 作为新默认。

正常长时间专注和资源 bug 要有正反对照。执行保险丝只证明被声明的资源/副作用边界，不能签发心理稳定证明。

## 4. D11：结果的时间与执行许可分开

### 4.1 先发散

| 形式 | 价值 | 去留及原因 |
| --- | --- | --- |
| 从 outbox 登记到 F 提交统一 τ | 易于尾部预算证明 | 排除：机器队列决定感受资格，已被 ADR 0032 取代 |
| 只将截止点改成网络返回时刻 | 小改动 | 不足：没有发生/观察区别、可信来源和离线语义；不能让终端自报时间自动可信 |
| A：发生/观察定语义，理解提交时作用 | 最少新心理结构 | 入围；承认处理慢导致反应晚，不伪造当时已理解 |
| 按发生时间回插 H、倒回重演并重发行为 | 理想化的事件时间轨迹 | 排除：改写已生活的过去，重发副作用违反记录和行动边界 |
| 迟到脉冲从观察时刻纯衰减到现在 | 对无截断线性系统容易分析 | 不单独入围：长队列会使作用接近零；只保留资格却抹掉触动，不足以满足本卡目标 |
| B：情境余波与现在得知分开 | 可区别旧事和新知，避免只剩衰减尾巴 | 入围；增加评价与状态语义，需防双算 |
| 完全忽略一切时间 | 不受队列影响 | 排除：不能分辨事情仍在发生、早已结束和今天才被观察到 |
| 各来源自定 TTL/可靠度折扣 | 可适应工具差异 | 不优先：容易把来源实现细节变成感受偏见，新增阈值无依据 |

### 4.2 两选项共用的最小时间事实

至少区分事情发生、可信观察取得、入口持久接收、解释/处理提交、凭证允许执行的期限；并记录各时间的来源、时钟域/epoch、可比较性和未知。这里是语义需求，不发布字段号。远端自报发生时间只是一项带来源的断言，不能自动拿来证明准时；本机首次持久观察可作为其自身接收时间的依据，不能补造远端发生时刻。

资格函数可以读发生与观察之间的语义关系、内容和来源；**不能把处理队列耗时作为失去 F 资格的条件**。是否“仍在发生”、结果是否首次得知、观察覆盖和过时信息的含义来自记录与 m=0 判断，不另设一个无依据的心理 TTL。未知发生时间可以支持“现在收到这个结果”，但不能证明某行动按时完成；确有结构时钟故障仍走旧故障路径。

执行前另核对凭证、载荷、权限和当前意图。凭证到期不能执行；此前已合法执行的回执晚到可以记录与触动。旧计算的结果不得覆盖新 Q，不得发布旧计划；UNKNOWN 不能盲目重发。去重与 F 一次消费须和 H/Q 提交绑定；崩溃恢复不能额外触动一次。

### 4.3 D11-A：理解时的一次新事件（推荐）

形式：保留发生/观察信息，按其语义生成被记录的 a、μ；在实际理解提交时，以该事件依法可用的当前 F 输入产生一次感受。队列延迟不删除资格、不把结果塞回过去，也不按等待时间给本次新知加折扣。若消息所述事情早已结束，A/M 可据真实时间关系区分“过去发生”和“仍在发生”，但不能把排队误当成这个事实差别。

**她会怎样变化：** 任务成功早已被观察，只是忙到现在才理解，现在仍能开心。若今天才知道朋友上周难过、现已恢复，她对“今天得知旧事”的反应可以不同于正在受苦。不能假称她上周已经感受过。

**风险与防护：** 一批积压回执集中到达可能产生集中反应；不能为降低峰值把合法回执伪造为过期。实际拒收/截断、处理能力不足要可见；去重防同一结果多发脉冲，资源保护在调度边界。内容真实与发生时间可信分别处理。

**证明与验收：** 资格对于仅改变处理延迟的输入不变；不承诺最终 x 或行为完全一样，因为 Φ、交错事件、R/θ 和理解时点可能不同。固定 F 快照、解释和语义时间的配对中，原始驱动不随排队变；再单测不同提交轨迹。ADR 0008 局部非扩张可保留，ADR 0026 的有限在途尾部时间证明失效。COG-A03/09、I16/21 与凭证拒执不变；COG-A12 队列期限部分重写。

**实验：** E11 的成对调度、边界时刻、睡眠/重启、远端时钟未知、旧结果/新 Q 交错与重复回执。推荐 A，因为它直接满足已定目标而不要求猜测“当时本应有什么感受”。

### 4.4 D11-B：情境余波与现在得知各有出处

形式：把结果的解释区分为“那件事对当前情境还有什么意义”和“现在得知了什么”。前者可以使用发生/观察的真实间隔建模，后者在理解提交时产生新知感受，不能按队列时长抹去。两部分共享同一真实根和一次分配预算，不能各领一份完整 D 或成长证据；组合权重、所需评价和版本语义尚待设计校准。

**她会怎样变化：** 知道朋友曾难过但已经恢复，可以同时有对过去的难过和现在的释然；迟到成功回执仍有现在得知的开心，却不假装旧任务仍在进行。比 A 更能表达阶段差异，代价是更难确定每部分的评价依据。

**风险与防护：** 如果“现在得知”被人为设为固定正奖励，就在发明情绪；如果两路都用同一 a 全量相加，就双算。两部分须有 m=0 的明确解释、来源和归约；没有可分辨信号时报告未知，不能由模型补出旧情绪。ADR 0033 对分句/因果升级的测试前提照常，不能借本选项绕开。

**证明与验收：** 若 D 是固定记录的两部分的凸组合且不读当前 x，局部事件非扩张保留；幅度界按实际组合重推。时间投影/截断与迟到注入一般不交换，不能证明“等于当时立即处理”。新增快状态分量时还需重定义 AC2-15 的状态范数和投影组合律。COG-A12、I16/21 及 COG-A03/09 同 A，新增同根无双算检查。

**实验：** E11-B 交叉“旧事仍持续/已结束”和“早观察晚处理/晚观察即处理”，比较两部分记录与总驱动；将新知部分删除的变异必须暴露队列长到完全无作用的问题。B 可选，但当前不推荐增加这层结构。

## 5. D05：改变亲疏加权这条关系本身

### 5.1 先发散

| 形式 | 价值 | 去留及原因 |
| --- | --- | --- |
| 只学习谁更亲近，固定 w=clip((1+π)/2,w_min,1) | 现有结构、可解释 | 排除为完成答案：斜率、最低影响和多人最大值仍永久固定 |
| 取消亲疏，一律同权 | 最简单、少偏见 | 排除：把另一种终身价值替换进去，也没有经历改变路径 |
| A：小型可学习曲线，允许平坦与反向 | 最直接展示关系本身能变 | 入围；必须先证明原始经历中存在可识别学习信号 |
| B：出生曲线加普通倾向的可追溯修正 | 情境解释清楚，可复用 G 的证据纪律 | 入围；需新作用形式，普通 f 的相加并不自动完成乘权改变 |
| 最大值改成固定均值、最小值或 softmax | 解掉“最亲者支配”一种情况 | 不能单独成案：只是换一个固定聚合偏好；温度等也不是纯工程量 |
| 让模型在 m 下每次直接给 w | 表现灵活 | 排除：绕过 EV6/可重算，模型自述和当前情绪可自证 |
| 让 x/行为强度当训练标签 | 信号容易取得 | 排除：把自身反应写回长期权重，违反 EV10、LP8/I24 |
| 以互动奖励做策略梯度/逆强化学习 | 可研究处境与回应的因果作用 | 暂不入围：奖励“什么算好”仍落在 A；EV4 可比性、探索和归因成本高，不能奖励讨好 |
| 任意神经函数/动态程序合成 | 形式表达力大，较非常规 | 暂不入围：先验隐藏、解释与验证困难，当前无需这层复杂性 |

### 5.2 共同难点：不能从她自己的情绪训练“应该怎样感受”

允许的标签来自合格真实观察及其 m=0 的 a(e)，不能来自 x、m、被 w 放大后的感受、她说“我更关心这个人了”或助手的评价。关系强度可以在 F 读出；如果拟合阶段需要事件前的亲近度作为解释变量，必须在确定的 G 侧重建并记录，**不传给 IRL/A/M**。这是对原 G 作用表示/输入的扩展请求，不能借 LP8 中“竞争解释的 π”偷渡任意关系强度来决定证据资格或权重。

两选项都必须能在**冻结亲近 π 的诊断探针**中改变有效曲线，展示斜率变平或反向、原下限不再是终身强制；还要在真实 H 对照中说明变化由什么经历支持。只换了最亲近的人、只加一段安慰台词、只降低全部 g 都不算完成。

多人的问题要先有“谁遇到什么”的可追溯观察范围。一个共情标量加人物名单不能唯一分解每个人的贡献。没有足够分辨的记录时报告不可识别，不能用最大值或平均值猜；不自动把 ADR 0033 尚未批准的细分 B 当作已有能力。出生时的多人最大值只能是待改的起点，后继必须让它被反例改变。

### 5.3 D05-A：小型、证据拟合的亲疏曲线（优先验证）

形式提案：在一个有观察支持的情境中，以事件前的亲近坐标 q_p=(1+π_p)/2 为自变量，用 `wψ(q_p)=clip(u+v·q_p,0,1)` 表达有效权重。u/v 是有真实证据来历的 R 中学得作用参数，只有合格激活状态才经 F 作用；出生参数体现“越亲近越能触动”，具体值另由已批准起点资源给出。**v 不被永远约束为正，固定 w_min 不作为终身下限。** 0/1 是现有乘权域端点，是否保留此域本身须在后继 ADR 明列，不伪称它无行为含义。

一种最小拟合候选是带有限出生先验、正反对称样本权重的约束最小二乘：预测真实外源反应相对当时基线的幅度，目标可取 `|a_emp−b_emp(e⁻)|/2`（除数来自 [-1,1] 两端最大距离，不是新调参值）。样本先按相同遭遇/观察条件匹配，拟合只在确定 G 侧读取冻结的事件前统计；同一根只算一次，先验随可靠经历让位。这个目标选择**本身是待用户批准的行为假设**：把原始相对反应幅度解释为未来亲疏乘权，可能导致重复缩放，不能称为从数学唯一推出。

多人情形不能继续固定取 max。提案是对可分辨的各人遭遇保留单独作用项，以同一受约束拟合学习角色/情境贡献，再作有界组合；出生时可初始化为旧“最亲者主导”，数据允许其他人主导或共同贡献。后继必须给出最小有限维组合式、同根总量和可识别条件，未闭合前不发布通用可学习聚合器。信息不足时不得默认沿用 max 并宣称 D05 完成。

**她会怎样变化：** 如果生活中某些熟人的反复小波动并不对应强烈原始反应，而陌生人的真实困境更显著，同类情境中曲线可以变平或反向；朋友仍然亲近，牵动程度却不再由亲近度单独决定。这里是条件性例子，不保证固定 A 会产生这种数据。

**风险与防护：** 相关不等于亲近度的因果作用；亲近者/陌生者遇到的事不同会形成混淆。控制遭遇与观察覆盖，保留未知，依据 EV5 回溯正反历史。不能用人为标签“应该更关心陌生人”替代 a。样本无区分、矩阵秩不足或先验主导时报告不可识别；不自动加复杂模型补结果。

**证明与验收：** 固定 ψ/R/θ 和记录时 D 不读 x，ADR 0008 局部非扩张保留，幅度界以实际权重域重推。I06 需要后继明确新参数的激活路径，不能让未成倾向的候选直接生效。LP8 的拟合输入扩展、EV10 的目标、出生先验让位、AC2-08/09/10/13/15 均须单列验证；λ、C 的来源范围不改。COG-A12 的贡献身份还须绑定权重版本，不因重新拟合重复发行旧根。

**实验与推荐边界：** E05 冻结 q 诊断、关系与遭遇正交、多人反例、反转/修复和信号不足负对照。推荐优先验证 A，是因参数少、斜率可见；**不是推荐现在采纳上述幅度标签或未闭合的多人式**。在拟合目标、激活和多人输入尚未获用户选择前，只能交付设计。

### 5.4 D05-B：普通倾向对出生曲线作有证据的修正

形式提案：`w(q,c)=clip(w_birth(q,c)+Σ_k s_k μ_k(c) h_k(q),0,1)`。h_k 是某个真实经历支持的情境中对乘权的修正，允许改变斜率与截距；例如一个简单仿射修正可抵消原斜率。它是**新作用形式**，不是现有 `f_k=s_k μ_k r_k d_k` 已经会做的事。h_k 的目标/幅度须从未经 w 调制的合格观察拟合，候选只提出形式，不提供证据；G 沿 ADR 0019 的实际 q、分摊和更正规则学习其支持。没有固定“成熟”“疏远”候选清单。

多人规则也作为可反驳的作用假设：例如某情境是否只由最亲近者代表，与逐人观察相矛盾时可以被新倾向替代；所有作用共享根和分配，不能给每人复制满额。后继须冻结冲突假设的确定组合及无合格假设时的起点读法，不能临场让模型选赢家。出生函数保留只是起点；若允许的修正族或容量使其下限/斜率永远无法抵消，这个选项就不符合 ADR 0032。

**她会怎样变化：** 她可能长出“在这种情况，不因为已经很熟就格外受影响”的特定反应，同时在其他场合仍更容易被亲近者触动。相反经历能削弱、撤销或改写该修正，不能把一次创伤永久固化成全局规则。

**风险与防护：** 候选之间互相抵消、反复命名、容量淘汰后恢复出生偏好，都是实际风险。必须使用共享分摊、别名与全历史再入，不复制依恋先验；量化最小反例说明修正族能改变原关系，而非只给结果叠一点其他情绪。仍可能没有学习信号，不能给某候选预造负方向或奖励来“帮她学会”。

**证明与验收：** 固定作用视图下的非扩张可保留；随新候选/份额变化的完整闭环不在旧证明内。要重推有限容量内的驱动界、修正组合与投影、无候选作用 I06，以及来源更正/再入后的 AC2-08/19。AC2-03/09/10/13/15、EV5/6 保留；COG-A12 不因新候选回溯而放宽重复根规则。

**实验：** E05-B 必须有既存亲近不变但曲线改变、修正互相冲突、合格新证据推翻修正、容量移出/再入的例子。若只能让谁亲近发生变化而曲线不变，即失败。B 可选，当前推荐 A 的优先级更高，因为 B 的解释性收益可能被更复杂的作用组合抵消。

## 6. 附带研究：固定 A 是否固定了好坏

本节只分析，不选最终方案、不授权换 A 或新增通道。

**已有路径的边界。** A 是 Ω 中固定版本的 m=0 评估。C 改变 b/g/λ，G 改变 R，F/J 改变感受和表达；b 移动可改变 a−b 的符号，R 也可产生反向作用，但原记录 a 本身没有因她的经历改变。因此“她不再喜欢这样被接近”可能只是补偿原 A，而非 A 已学会“这种接近不是好事”。不应把这两种结果写成同一结论。

| 研究方向 | 能改变什么 | 关键风险 / 要回答的问题 |
| --- | --- | --- |
| 保持 A 为事实化的反应坐标，偏好全部经 R/θ 表达 | 可改变最终反应，证据标尺较稳定 | 是否仍存在所有 R/θ 都无法翻转的固定评价？若只能补偿、不能表达某种改变，须承认缺口 |
| A 分成不带价值的描述与显式学得评价映射 | 可分开“发生什么”和“对她意味着什么” | 价值映射若参与 G/C 标签，可能自证；若只作用 F，又未改变学习评价。须给出新状态归属、冻结前态、独立证据与反事实不变性 |
| 多种 m=0 评价并存，经历改变使用的组合 | 可表达矛盾与不同情境，而非一条硬正负线 | 组合权重由谁学习、用什么不循环的目标？固定评价集合仍可能是隐藏价值菜单，不能按用户喜欢挑 |
| 有来源的结果/预测误差学习 A 的一部分 | 让后续事实纠正早先的好坏预测 | “事实预测更准”并不决定“什么值得追求”；自选行为的因果混淆和奖励投机不能靠优化器名称消除 |
| 作者发布修正 A 的新 Ω 版本 | 可以修正评估器理解或标注错误，追加新解释并重算 | 这是外部修订，不等于她自主从经历改变；不能为得到喜欢的性格重评过去，模型迁移也不能自动重做旧解释 |

若要研究“经历学习 A”，至少先证明：自身叙述不能训练长期标签；事实判定不受当前 m/关系偏好影响；相同 H 在固定版本下可逐位重算；旧评价与新解释可区分；AC2-09 的反事实不变性究竟保留哪部分。没有独立信号时必须允许“不足以选择”，不以她的自述为真值。四个「乎」作为起点、用户边界、诚实与权限不会因此被暗中删改。
