## 4. 状态、版本、重放与更正

| 设计对象 | 权威归属 / 需要冻结的合同 |
| --- | --- |
| D07 出生质量、经历质量/分子、残差/持续时间估计器 | θ 的显式快照统计，由 C 更新；全部进入规范重算和存储后继，不藏在缓存 |
| D09-A1 的可见主值、当前 h、目标、时间锚点与支持关系 | 都属显式快状态/记录，F 暂存、外层提交；y=x−Σh 为派生记账量，不另存心理基线。J 读主值，Q 只管运行引用。按已选 A1 接续数值运算/更正合同；迁移不得从截断后 x 猜分解 |
| D09-B 的消费身份；D11 的一次作用 | H/Q 和外层事务绑定；原事件、补解释、回想共用规范身份；索引可重建，删缓存不恢复资格 |
| D11 各时间、来源/域、未知及冲突 | H 的后继记录；执行时权限/凭证走行动边界，不能用观察时间代替授权时钟 |
| D05 ψ/ζ 或函数修正、激活与拟合前态 | R 的新概念作用/证据统计，由 G 更新；没有候选作用旁路。出生函数与数值规则在已批准资源版本 |
| 规律、解释器、支持/归组算法、截断分摊、数值运算 | Ω/规律版本绑定 genesis 与每段适用历史；旧 A0 不变名复用；不是允许在线隐藏修改 Ω |

A1 的截断更新定义已选；参数、IDL、部署以及完整更正/迁移合同未同时获准。后继按此选择冻结采样/同根资格、评价与 G/C 输入、F 状态表示、一次消费、更正范围、排序及有限 binary64 运算，再发布新的规律版本。新数值均待校准；本卡的 0/1/2、区间与维数来自定义/既有域或所列公式，不是运行阈值。旧 κ/r/M/τ、每日 30 次仅用于取代说明/对照，不复用作默认。

普通重放只读取固定解释和版本；同一新版本的增量与整段重算走同一规范递推，独立核对器另从来源与公式验算。通常不可重新运行模型；解释器错误的修订才追加新解释，保留旧版。普通新反证、来源本身虚假、权限撤回、人的改口、参数重算和版本切换分别记录，不能统称“删除旧事”。

来源更正应按 AC2-19 重建未使用失效证据的 R/θ 与依赖统计，不抹掉真实说过的话。D09 的快状态更正另定：A1 目标归零未必清空该根，A2 撤去正向作用可能露出负余项；不能把任一路线说成“自动撤销全部影响”。重建、别名合并、容量/迁移须补证明，不把残留快状态作为新证据；已经发生的行动与外界回应留在 H。处理慢不回写“早已理解”，版本切换也不保证状态相同。

后继类型按兼容规则新增，不改旧消息字节；缺观察时间、消费身份或拟合材料时不能默认“已知/未消费/合格”。必要时显式保持未知或受治理地补解释。新快状态与 θ/R 统计需要 CanonicalV1、黄金向量、往返、检查点/恢复、迁移/回退和 SYS17；新旧版本分别可重放，失败保留旧系统。本卡未创建这些类型或迁移产物。
