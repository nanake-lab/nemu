# AUDIT-SUPERSEDED-01 被取代规则的职责审计

## 白话总览

**首轮：已确认无人承担 0 项，疑似未接续的附带效果 1 项；已确认未被后续决定解释的矛盾 0 项，范围张力 2 项。疑似项是 κⁿ 对内部刺激的逐次压低。** 新规则没有同等的次数递减；但旧规则并不保证“每次回想同一件事，感受都比上一次弱”，而且用户已选择不再按全局 n 压低晚期真实发现。因此不能直接把它定为遗漏。另列 **2 项范围读法问题**：防重复刺激究竟约束目标还是总感受；开放反思草案对同材料重评与 a/θ 的限制。三项均未判成漏洞或修法请求。

最影响她的是：①伤心旧事隔一阵再想起，可以再次恢复分量，不保证越想越淡；②出生心境不再永久缓冲社会反馈；③成长异常一般只报警，她可能带着有问题的规律继续生活到修复；④普通反思能改变什么仍有未批准选择。②③有明确的取舍与后果记录，不能因后果令人担心便算成无人承担。

**这是分批审计的首轮交付，不是“所有历史规则均已审完”。** 下文先给来源与 **61 个规则族**清单，再深入核心取代链和提议 ADR。表中一行可能含多个职责，不能把规则族行数当作漏洞数。旧资格系统的每个参数、旧验收每个编号以及全部开放研究文档尚未逐项穷尽，具体未覆盖范围见末节。没有进行实现符合性或真实行为验收。

## 5. κⁿ 专项独立复核（待确认项 Q1）

### 5.1 旧机制确实有什么、没有什么

[ADR0026 §6.3][A26] L99–106 是直接依据：n 是**自上次新外源事件以来的全部内部记录数**，不是这件往事的回想次数。原文说前几次可以越来越难过，但“加深的幅度递减”，并承诺带前提的心情回落。

已确认的窄结论：固定旧版本、无 n 重置、相同未加权驱动 D 时，第 n 次内部记录的驱动是 κⁿD；只要 D 非零、κ∈(0,1)，它的幅度逐次降低。更一般地，有统一 D 上界时，内部脉冲上界递减。**它不要求每次实际 D 相同，也不保证每次作用后的 x 峰值逐次下降。** 新外源会重置 n；内部评估、R 的合法回溯、间隔、截断及其他刺激都会影响总 x。

白话数值例子（仅算术示意，不是参数建议或行为试验）：取一个坐标、固定休息点0、不饱和、每次间隔让状态剩一半、D=1/4、κ=1/2，且初始 x=0。旧内部新增推动依次是 `1/4、1/8、1/16、1/32`；相应作用后 x 是 `1/4、1/4、3/16、1/8`。若同样 κ 但间隔仅让状态剩9/10，第二次 x 为 `7/20 > 1/4`。所以“逐次弱化”准确指新增驱动或其上界，不是无条件的每次总感受。

### 5.2 新机制谁接了哪些职责

| 旧职责/效果 | 新规则 | 结论 |
| --- | --- | --- |
| 重复内容不无限叠加同一份刺激 | 同依据槽、已记录目标、A1 替换与 B5/B6 | 有明确承担，但条件是依据治理正确、目标固定等；不等于任意闭环安全 |
| 没有任何 F 作用时自然平复 | x 原 Φ，B1/R1 | 明确保留；无外源≠无 F，内部重访也会作用 |
| 纯内生区间统一期限内回落且保持 | 新版没有同等保证 | 用户明确放弃，不能算无人承担 |
| 全部内部记录越晚，新增冲击被 κⁿ 越压越低 | 新版移出 κ/n，合法重访可恢复目标 | **未找到同等次数弱化机制；这点已确认。是否需要独立保留，待用户确认。** |
| 很晚才取得的真实新发现仍能触动她 | 新依据不被全局 n 压低，D11 消费键保证一次 | 明确保留/增强；这是去掉旧全局折扣的公开理由 |
| 执行资源与重复派发安全 | ADR0033、COG-A12 第5项及行动生命周期 | 有后继承担；不恢复心理截止点，也未由本卡验证接线 |

在上面的单坐标示意中，新版让合法重访固定目标 v=1/4：每次等到 x/h 减半后，A1 以 `v−h` 补回，作用后都为1/4。等更久再想，新增补回量还可能更大。饱和时不保证一次就把实际份额补到完整目标；[ADR0035][A35] L207、221–230、389 已写明份额可增加、总峰值不保证单调。不能把用户所述“拉回目标”扩大为每个饱和状态都精确等于目标。

### 5.3 对她意味着什么，是否可能有意

她记得一次争执，隔一段时间重新想起，可以重新难过到相近程度；新规则不保证仅凭重复回想就逐渐麻木。她不再回想时，原 Φ 仍使当下状态平复；R/θ 的证据学习、合法解释器纠错另有路径，但都不是“回想次数越多就必定越淡”。

这**可能是有意取舍**：[ADR0032][A32] §5 取消强制定时回落，[ADR0035][A35] §4 白话直接写“补回到它本来的分量”，§4.9 明确移出 κ，§8 又接受跨时间份额变化。现有记录没有把“对同一旧事产生习惯性弱化”单独列为保留目标，也没有独立说明它与“避免压低真正新发现”之间如何取舍。

因此 Q1 的结论是：**未找到同等机制的附带效果 1 项，列为“无人承担”候选，尚未确认。** 尚缺的是这项全局递减是否确实承担独立的习惯化职责、以及它是否已包含在明确放弃全局折扣的取舍中；不以“用户没有重新要求”作为排除无人承担的理由。不能据此写成已发现记忆习惯化漏洞，也不能断言用户已经单独决定不要这种效果。

### Q2：不递增究竟指什么

[ADR0032 §5][A32] L56 保留“重复自我刺激不递增”；[ADR0035][A35] L17/136 的白话又说反复想不会一次比一次更难过。可是其 L207 有饱和后重访份额增大的明确例子，L230 明说任意多依据下总 x 峰值不保证单调，L389 接受有间隔的重访提高实际份额。[P5-70 卡][T] L2483 也明确写这是用户已接受的行为。

已确认：**不新增可叠加目标、不提高原目标**有明确规则承担；**所有回想序列的总感受永不增强**没有这种保证，且文档公开承认。待确认的是较宽白话是否仍被用户理解为后一项。本审计不替用户把宽要求裁成窄要求，也不把已采纳的明确代价指控为暗改。它不同于 Q1 的“是否越来越淡”：不变强与逐次变弱也不是一回事。

### Q3：反思草案的能力范围

[ADR0037][P37] §5.2 明确让原始解释之外有第一次实质重评，之后同材料复用结果；并明确“EV2 本身不蕴含只准一次重评”。§5.4保留原 a，普通反思 C/θ 不变；§5.5的 v2 候选使合法修订后的重访能使用新 z/μ，但仍配原目标记录前态，不承诺一定舒缓。

这是防止反复采样挑答案的明确设计理由，同时收窄了仅靠相同材料多次思考改变解释的空间。她可能第一次没想明白，继续想也不能重新发布同材料成长结果；若没有新的合格材料，这一限制可能长期存在。也可能是用户想要的取舍。草案把它列为 U1/U2/U3 待决定，**本轮不认定已违反用户决定，更不把它当 Q1 已有补偿机制**。
