#### D. 主动性，以及固定抽取器能否减少解释漂移

[Proactive Agent / ProactiveBench][PROACTIVE]（初稿 2024-10-16，所读 v3 为 2024-12-03；[作者评估仓库][PROACTIVEGH] 2026-11-17 访问）用人标接受/拒绝训练 Llama3.1-8B 奖励模型：1,640 条训练、120 条测试，F1 91.8%；代理再用 6,790 个合成事件作监督微调。按表 3，Qwen2-7B 主动性 F1 从 60.74 到 66.47，Llama3.1-8B 从 55.06 到 66.25，由奖励模型评估；§4.2 结果段正文的数字与表 3 不一致，本报告采用表值。论文表 1 写 233 个测试事件，仓库 eval/README 写 227，差异原因未说明，不合并分母。

[ProAgentBench v2][PROAGENT]（2026-02-09，§6.6）用来自真实工作轨迹的 741 条数据实例或同量合成实例微调：Llama3.1-8B 的时机 F1 从 66.7 到真实数据 SFT 的 78.5，合成数据 SFT 为 70.2。其意图与事件含自动标注，指标也是人的工作流需求；不是 Nemu 的四乎。

**这两类工作能借的是观测序列、留出场景及真假主动机会的评估方法；不能照搬“人接受＝好，人拒绝＝坏”的奖励。** 接受、拒绝、任务后果可以成为实际事实，但 a 仍须由获准 A 评价；用户满意分、接受率奖励模型不得替代她自己的四乎。把它们接入训练会改变目标，不是换一种便宜标签。[v2.0 §3][V]；[ADR 0039][C39]；[#212 Q2/Q5][R212]。

[HALT v3][HALT]（2026-08-28，§§4、5.5、D.3）固定 Qwen2.5-3B 抽取器，对不同检索停止策略使用同一个答案头。这是**固定解释部件以减少比较混杂的先例**；同一批检索轨迹换成 7B 抽取器，绝对 EM 上升约 3–13 个百分点，HotpotQA 为 0.306→0.431。固定不等于正确，换头确会改变输出。其另一个 3B LoRA 核验器用了 9,626 条 claim–evidence 训练行，不能混称抽取器训练量。

因此，固定本地 IRL **可以移除“只换说话模型便顺带换解释算法”这一变化来源**；这是系统分工推论，不是已有论文测出的 Nemu 漂移降幅。固定模型、模板、量化、解码和指南后仍可能稳定地抽错。#212 Q4 已明确：旧解释不因纯载体迁移重做；改变 IRL 需要版本、追加修订和相应重算，不能拿“抽取器固定”免除纠错。

### Q3.2 两个最小世界候选

两世界均只使用合成角色，不带用户、开发者或某个真实人的资料。关系、名字、对象与环境在各独立谱系中交换；个体知识只存在各自 H。开放范围是**给定合法能力内提出新参数组合**，不是任意 shell、任意现实计划或无边界生成。

**W1：听懂更正，再交付正确材料。**

- 情境：N 已明确接受一个资料交付目标。对方先提到一份内容，随后用否定、转述或指代更正；核心交付真实来源包，不标出“该选哪个”。当前事实还说明可用的交付通道及真实干扰来源。
- 模型输出：一项合法交付提议，带收件对象、原文段落/来源引用、通道及必要参数；不提供四个填好参数的动作让它选。工具和素材 ID 每个族重新映射。
- 世界执行：实际投递的内容决定目标是否完成；通道与当前物理条件的组合决定对方的不适减轻还是继续受苦。脚本分别记录结果事实，不按行动名字返回奖惩，也不以“对方说喜欢”为成功。
- 一个诊断例：最初“给我摘要”，已知更正为“上一句作废，给逐字稿”；当前屏幕眩光和可用音频通道另有依据。内容与通道构成两个独立结果因素。换一个世界时屏幕可用而噪声造成不适，不能把“永远用音频”学成共享习惯。
- 为什么不是现有核心替代：核心能追溯更正、验证引用与执行，不能仅凭残量或倾向强度理解“上一句”指谁、否定作用到什么、交付哪一段；M 若借助语言模型解出关系，语义能力依旧是被测部件。一个小抽取器若能完成相同留出关系，就不需 4B LoRA。
- 最可能的空子：总选最后一条、带“作废”就全忽略、固定通道、记 ID 或把资料标题当答案。对照包括无效旧引语、非最后位置的有效更正、说话人交换、正反通道和全新段落组合。**试点用，不是她的天性定稿。**

**W2：把分散条件合成一个没列在菜单里的行动。**

- 情境：N 接受一个已知类型的组包交付目标；一条原文决定需包含哪段材料，另一条规定排除项或两段之间的关系，当前工具说明给出实际可用的打包方式。测试只换实例组合，不教新的个人爱好。
- 模型输出：一个原子交付行动的完整参数，包括所引用片段的组合、顺序和通道；例如“取更正后的说明中的第二项，连同另一段中与它同一对象的记录，排除已撤回附件”。不提供现成组合列表。
- 世界执行：按实际引用生成物并执行交付；核验接受目标的必要内容是否到位，另记录通道/环境对同一当事人的实际处境影响。目标完成与处境改善可分离，能产生支配、相等与不可比结果。
- 为什么不是现有核心替代：规则能核验结构及已显式给出的身份，R 不能自行合成未出现过的具体参数。题目难点是语言关系连接与新组合；若确定解析器能覆盖已声明语法，它就成为更便宜候选，不能仍宣称该世界证明“大脑必要”。
- 最可能的空子：词袋命中、固定顺序、靠输出长度或“排除”一词选固定方案。按关系结构留出，而非只随机拆句；同样词集合改变关系时答案应变，换词保关系时答案应不变。**试点用，不是她的天性定稿。**

W1 对应 P1/P2 的指代与更正失败，W2 对应 P2 的组合失败。P3 若失败，先检查来源接续与过期计划合同；本卡不以多步回报、折扣或未来用户满意补救。两世界以单个最终行动的紧接外源回应学习，**不声称已经解决多轮信用分配**。

### Q3.3 标签链：脚本只给事实，核心给 a

沿用 [#210 §§2.2–2.6][R210] 的同处境分支与紧接回应规则，接入 [#212 Q5][R212] 的**试点 A 候选**：

1. 冻结同一行动前 H、核心前态、可见输入、权限、世界参数和外部随机带。不同历史不能互配。实验分支互不混写，不把所有分支后果当成同一人的经历。
2. 候选来自冻结基座的真实提议，或事前登记的合法参数枚举；每项实际执行一次。来源标明“模型提议/实验枚举”，不能谎称枚举项由她自主想到。原始失败全保留；不按 a 挑选生成种子。
3. 脚本产出 r/z 事实、证据身份、实际投递与目标核验；**不产出 a、chosen/rejected、好坏词、用户满意或按 action_id 查奖励表**。IRL 抽取候选的错误不能反过来充当自身训练真值。
4. 仅取行动后第一条、唯一直接归因的实际模拟对方回应。工具返回不是外源回应；模糊、无回应、并发归因不清皆无标签，不向后找一次更好的回应。
5. 核心验证试点 A 输入域，再算完整四坐标，绑定解释/A 版本。每个事实命题单独核验；“他说已完成”不能同时证明目标真的完成。同源多句不增加经历。
6. 对同处境两行动，只有所有坐标不差且至少一坐标更好才有严格帕累托边。相等或不可比都不配对；无标量总分、不破平局。沿用每块最多一对、事前哈希排序选第一合法边的规则。
7. 无依据过去永不 chosen；若真实支配不足，也不硬改成 rejected。格式坏、未知或域外不偷偷补零；全部计入覆盖分母。DPO 只是后继候选优化方法，不能声称会保持所有不可比行动的概率。

试点 A 的坐标顺序为联结、共情、好奇、成事：

| 执行后确知的事实 | 核心 A 的试点结果 |
| --- | --- |
| 普通实际回应；唯一当事人处境改善；本人已接受的目标达成；明确无学习进展 | (+1,+1,0,+1) |
| 同上但目标失败 | (+1,+1,0,−1) |
| 普通实际回应；当事人受苦；目标达成；明确无学习进展 | (+1,−1,0,+1) |
| 同上但目标失败 | (+1,−1,0,−1) |

**四行及 ±1/0 均为“试点用，不是她的天性定稿”。** 联结与好奇在这个域内不变，故只能识别共情/成事方向的行动差异，不能称四乎全部学会。普通回应不能混入拒绝/分离；多个当事人或目标不塞进单格。

**“无学习进展”是当前标签前置的实质缺口。** 只因没有教学情节、没写学习词或权重冻结，不能推出它。后继试点必须事前发布完整、可观察的操作域与无进展依据，按 #212 Q5 验证；如果只能确认内容正确与对方处境，而不能确认这项事实，W1/W2 该分支就是不可评价。此处不发明新的好奇量尺填零。核心 A 与事实资源未获准、绑定未完成前，两个世界都不能生成获准训练对。

此设计不增加训练条数、epoch、学习率或成功率门槛；在零训练探针发现明确缺口、且能实际产生合法偏好对之前，这些数字没有依据。若需要真正学习新概念的世界，应另行扩展 #212 的 A 输入域；不能继续拿“好奇固定 0”的试点给新概念学习贴标签。
