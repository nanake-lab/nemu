# 后继实测清单（全部 not_run）

本文件只列项目，不是执行计划授权；本卡不运行 GPU、不加载模型、不新增下载或依赖。每项的配置、样本数、尺寸、时长、预算和未冻结的判据，须在后继卡及 GPU 窗口前明确并获准；不能看结果后选阈值。既有验收不因本清单被放宽。

## 要确认的项目

| 项目 | 控制什么、测什么 | 能解决哪个问题 / 失败如何表述 |
| --- | --- | --- |
| G01 原配置复现与分配归因 | 固定 P0-12 模型/引擎、context 8192、batch/ubatch 512、F16 mmproj、FA off；分别测主脑单独、加入视觉加载/预热、实际编码、decoder 图像 prefill、完成后空闲。对照 4628.88 MiB、1472² 预热和默认最大面积；新增配置均单列 | 区分加载预留与请求峰值、主脑与视觉、CPU/RAM与GPU；不能把空 PID 匹配当零占用 |
| G02 token 上限与块尺寸 | 使用同一份含小字的原图，分别检查最大图像 token、实际 resize、预热形状、已分配缓冲以及释放；必要时逐次重建视觉 context。候选块尺寸、重叠和长宽比待预先确定；256²/512²/1024² 仅是 P0-12 已有对照尺寸 | 改输入/上限是否真能省预留；是否丢字、缺边或只把峰值延后；不按面积比例预造节省量 |
| G03 视觉计算优化 E | 保持同像素/预处理，核验固定版本的视觉 Flash Attention 等路径及实际 GPU/CPU 算子；测分配、输出与取消粒度。新实现或引擎若不可避免，先作为单独候选获批 | 工作区能否在不缩图的情况下下降；不把主干开关或源码存在当执行成功，不隐去 CPU 回退 |
| G04 CPU 视觉 C | 同模型/图像/预处理下，完整 CPU 编码与 GPU 编码配对；测 RAM、CPU线程、传输、decoder prefill 及与 ASR/认知争用。检查同配置零调制基线及跨配置数值/能力差异 | 不要求跨内核天然逐位一致；差异与质量单列，不能因看似更省就认定无损或免迁移验证 |
| G05 视觉生命周期 V08 | 主脑保持加载时，单独初始化/释放视觉 context；测权重、工作区、驱动驻留、冷/热编码、重复装卸与取消后分配。核验固定库接口/打包是否支持；不能默认 server 有热装卸端点 | 证明是否真释放，而不只是没有任务；若只能重启主脑，报告不满足此路线的常驻主脑条件 |
| G06 声音基础与生命周期 | 使用 ADR 0027 已定过渡声音，在后继批准部署后测加载、首句整句合成、RAM/GPU、取消、释放/重新加载、待播放音频与实际播放回执。声音 CPU 路线另列，参考身份与文本保持 | 把约 3.5 GB 从估算变成本机测量；不能拿旧 Qwen3-TTS 或不同声音的数据替代，也不沿用未经适用性核对的旧首包目标 |
| G07 真正的全系统同驻 | 分别对 A/C/E 候选测主脑持续认知、m=0 IRL/A/M、视觉、TTS、ASR、舞台共同运行；包含加载、预热、长输入、切换与空闲。WDDM 按全部拥有进程树观测并记录采样缺口；设备/桌面预算另列 | 判定单卡是否实际可用；保留 ARCHITECTURE §2 #21 与 ADR 0012 适用的验收口径，不把显卡标签容量当合格线 |
| G08 分时 D | 视觉与 TTS 互斥阶段核验释放；测试已在播放时近看、合成中请求近看、近看中请求说话、打断与取消。测装卸、排队及各阶段延迟，主脑保持加载，报告认知实际交接间隙 | “能分时计算”“能边播放边看”“能同时合成并编码”分别结论；不能相互代替 |
| G09 清晰度与照片理解 | 预先冻结合成小字、合法授权照片、照片内招牌/屏幕、截图密集字、跨块表格/公式、不同方向/压缩/对比度与长图。冻结人工真值和来源，比较整图、全覆盖分块、概览近看、CPU与OCR；字号/字高、语言与样本数待定 | 报逐字错误/遗漏、区域定位、跨块关系、视觉问答及不确定性；不能只看图像描述、格式或精选成功图；源图不可读另列，不伪造恢复 |
| G10 IRL 与关注隔离 | 原图的独立 m=0 解释、m 下选区、选区结果的 m=0 解释分别配对；核验同源绑定、漏读、来源跨度、三语 schema 和人工语义。保留 P0-12 原 wire 来源不足作为风险 | 不能用“她选了这块”证明全图都已客观解释；不能只报 schema。此项不代替 P0-12 条件切换与 P5-31 |
| G11 抢占、公平与持续认知 | 测解码、长 prefill、视觉编码及预处理的取消点；用户输入优先、解释积压、TTS等待、无外部任务时接续。各阶段记录等待、运行、交接的分位数和最大值，工程片长/预算待测后登记 | 不能让视觉或后台认知使其他分支饥饿；依赖失效返回不能覆盖新 Q；真暂停如实报告，不设心理休息规则 |
| G12 来源、时间与成长不受工程规则改写 | 在临时合成谱系固定原图、派生链和解释记录，核对整图/裁切/OCR不重复发行证据；自身近看结果不进 C，维护诊断不伪造情绪。固定同一合法记录/时间输入，对照工程队列与缓存安排的重放 | 不要求真实延迟下 x 完全相同；要证明设施不改证据、权威写权限、J 或规律。发生/观察/处理时间按 ADR 0032 分开，不因排队删真实后果 |
| G13 故障与恢复 | OOM、无容量、CPU不足、装卸失败、来源撤回、权限变化、新旧截图不一致、崩溃及重复回执；核验 H/Q 的请求/结果、部分覆盖、状态和恢复。新契约若涉及存储变更，补 SYS17 迁移回退 | 不假看到、不默降、不盲重发、不重演截图；局部不可用不自动变成全局成长暂停或载体结构故障 |
| G14 舞台与桌面压力 | 与实际舞台和声音共同测帧时间、口型/播放、输入响应、其他应用显存争用；显示配置沿现有架构验收档，图片坐标另核原图/DPI。核显路线仅在另获准盘点与适配后测 | 不能只看模型进程，或通过临时关身体使同驻“通过”；不自行更换视觉基准 |

## 测量口径要保留的区别

- **显存：** 文件大小、引擎模型/KV/循环/compute buffer、WDDM 专用与共享、OS 可用预算分别记录。引擎值不是完整进程峰值；采样峰值不是连续峰值；所有失败和采样缺口保留。
- **延迟：** 原图读入、解码/方向处理、裁切/resize、编码、图像 embedding prefill、文本 prefill、生成、IRL、排队、装卸、音频可播放与实际播放分开计时，保留包含关系，不能重复相加。冷与热、单图与完整任务均单列。
- **清晰度：** 原图尺寸、实际送入编码器尺寸、裁切坐标、图像 token、模型/预处理版本及覆盖范围都可追溯；分块和整图的完整任务对比，不能只比单块。
- **她的体验：** 能力成立、认知接续成立、表达与行为效果成立分别报告；少输出/少近看不是自动的性能成功，模型自述不是验收证据。

## 后继执行条件

先由用户选择测哪些路线，明确所需组件及后继范围；按 AGENTS §9 另约 GPU 安静窗口，执行前确认 Runner.Listener / Runner.Worker 均未运行。新组件先做最小可行性测量，失败依黄金规则 13 保留原始记录并交回选项，不自行更换模型、工具或阈值。

本卡不能据旧窗口时长推算上述项目总耗时；后继要在准备完成后说明估计时长及依据。测试只用临时存储与合成/许可测试素材，不能使用她的排练、正式存储或用户私人图像作为测试数据。测完退出自己启动的进程，再通知用户恢复 runner。

这些项目不构成新的正式验收编号。COG-A03/04/07/08/09/10、SYS05、SYS17、I18/I23/I25/I26/I29、AC2-14/16/17 等仍按各自有效规格与后继卡负责，本卡不签发其中任何通过结论。
