# P5-44：混合证据的成员、份额、排序和更正提案

同一场相处可能让她知道某人很会修电脑，却不足以证明那人每句话都可信。方案要保留这份区别，同时不把一件事复制成几份成长。下面给出三条可推进路线；推荐R2，但没有替用户选择，也没有批准DESIGN-EV-01的全B算法。

## 1. 先固定成员边界，再讨论怎样归约

### 1.1 四类身份分别传递

| 身份 | 用途与已定依据 | 不可代替的另一身份 |
| --- | --- | --- |
| 输入记录身份 | Γ以stable_source_key及载荷指纹去重；行动结果用action_id及执行实例等正式身份 | 字符串相同不证明同一观察，不同消息ID不证明独立根 |
| G同源组与组内证据观察身份 | EV2的一起因一组；完整事件及其受治理解释才是成员，多命题不增成员；纯转述/重复保留引用，不增有效观测量 | 不能当作C计数键或F消费键；同一个人不是他一生只有一个G组 |
| C合格外源经历身份 | ADR0035§3.1单位计量1；同次接触、同段缺席一次，有效A必要 | 不按G目标数/组数/命题数推进；G某目标不合格不能删除独立合法C输入 |
| F依据身份与记录阶段键 | ADR0035§§4–5：依据确定槽，消费键为记录＋阶段；外部真实刺激与内部重复分别处理 | 同源G组内可有不同F新依据；不能用同根取消合法目标更新或重访；具体表示仍交72 |

**共同根的拟议治理顺序（U5/U6）。**

1. 在同一可信H前缀上解析来源、撤回、人与账号、实际对话及是否属于同一件事的关系；先排除没有真实观察来路的叙述、候选和纯解释节点作为证据成员/连接桥。真实观察即使尚无某个目标的资格，仍可保留来源身份；身份与资格不是一回事。
2. 从直接可查的共同起因及有治理依据的对话、转述关系确定 G 根。确切记录间的关系复用 RecordRelation。SAME_EVENT_HINT、CONTACT、EVIDENCE_MEMBER 分别提供同事件提示、接触与成员事实；只有具备生效治理的 GOVERNED_MERGE 才证明相应合并。共享账号、相同键或一次回复本身都不能证明独立性或合并。若合组唯一依据是已失效或纯自述的中间节点，不合组；若仍有独立、有效的共同来源证明，保留合组。目标k不能拿另一目标合格的内容当自己的唯一连接证明。
3. 关系未知时不擅自拆成独立根，也不把所有未知记录合成一大组；只暂不分配独立性未能确定的相关输入，其余已知独立组继续处理，H、C、F按各自条件保留。未来新依据到来后重做相应投影，不设超时自动认定。
4. 在共同根内，为每个规范目标k建立**完整事件成员**集合E(c,k)，列出纳入/未纳入及其规则依据。只问发生、目标所需的事实、主观表达范围、EV4比较、有效A与解释资源；选择不读a正负、π、x/m/g/λ，不按后来结果好坏筛成员。
5. 同一证据观察身份至多取一份有效A；原事件的多个Claim/别名/语言解释只引用它。传输重发、同内容转述、同次接触后续报告不新添G独立组或重复证据观察；持续时长等真实新信息可以修订对应观察视图/原组内容，不制造独立根。同身份却出现互相冲突的有效解释，须先由G04明确有效版本，不能为求平均而保留两份。

这是拟议的根与投影接口，不宣称程序已能正确识别现实起因；未知同源关系仍需治理。G根的等价关系、每个目标的适用成员、来源是否真实须分别可审计；一次复述不能串起两个本来独立的组。

例如，她听见甲引用乙的原话。G01 用 QuoteLayer、SpeakerAttribution 核实各层作者和可见区间，G 用这次真实听闻判断「甲这样表达过」。要判断乙的原话或话中事情，仍须分别核对原记录与外部事实。表达侧按残量挑选的包、自引档位或语气样例均不构成 G 的成员选择依据。ADR 0045 D1 只在过渡期让云端写内部文字，后续关注和行动选择仍走本地获准路径；任一路的内部文字都不新增独立根。[ADR 0045 §§1–4](../../docs/adr/0045-speak-think-wiring.md)

### 1.2 D13-A 的目标资格矩阵

| 要判断什么 | 最少需要什么 | 不足时保留什么 |
| --- | --- | --- |
| 「她确实听到某人求助」 | 收到表达的真实事件、来源、有效A；人/受话对象有依据 | 求助内容的外界原因可未知；不自动证明「真的没睡」 |
| 「外部事实P成立」 | 对P本身的发生/真值依据，不只是说P的记录 | 陈述事件可保留；不能把unknown填false，或把true直接写成S=+1 |
| 「此人说自己难受」 | 自报确实发生、归属/范围明确 | 不要求直接测到内心；也不能证明其客观归因 |
| 「做法A导致某种结果」 | 真实做法/已知结果、版本化可比情境、不同做法或未做的比较记录 | 缺比较时该因果目标无资格；人的真实回应仍可进C；不能换名普通候选绕开EV4 |
| 「建议有效」 | 预先记录的可检验预期＋后续真实观察；因果目标仍需EV4 | 建议保持建议；听到建议的a不能证明建议内容或说话人诚实 |
| 「依靠此人办事有用」与诚实/兑现普通倾向 | 各自所需的真实事件及普通M匹配 | 能力不担保真话；D04-A不增加诚实/兑现枚举、扣分器或先验 |

矩阵是ADR0033所选语义的接口展开；**资格不等于支持方向**。支持只从批准规律对a、b、d、幅度等的计算产生。A未知与有效a=0不同，μ未知与μ=0不同；主观性不作乘数。

D20-A/D13-A只接事件级、明确无歧义的结果/观察范围。G01–G03能指到Claim并不授权按句分配不同a或因果影响。若一个事件不同片段需要不同反应而只记录了一份整体a，该目标明确暂不能表示；不能自动分句、猜份额或用一份整体a冒充各片段反应。ADR0040已经要求保留其它有独立依据的主张，但没有批准新分句器；表示不了的具体范围要报告。

## 3. 归约路线

先发散再取舍。以下都不重选B/A/A/A，只比较**已合格完整事件**如何成为每个(root,target)的一份输入；均需新版本及验收。新反应、匹配或来源更正能改变结论，但不能直接修改归约规则。

| 路线 | 如何计算 | 后果 | 经历能改变什么 | 经历改不掉什么 |
| --- | --- | --- | --- | --- |
| **R1：只处理可直接对齐的组** | 同根各有效目标须有同一合格成员列表；每目标成员μ须已知且相等，直接用共同值；沿既有均值/峰值支持计算；不满足时相关混合组不产G分配，明确报告 | 新结构/判断最少，易对照旧函数；真实混合经历可能长期少学，不能称为完整混合覆盖 | 新观察/补解释可能消除歧义，从而首次获分配；普通合格证据照常改变R | 本版对齐限制、等值门槛不会自行松动；等待不会使未知变已知 |
| **R2：目标事件视图＋明确的集合μ（推荐）** | 每目标取E(c,k)，以记录的集合μ进入现行支持计算；均值/峰值只读该集合；同根全部目标共享分侧份额 | 能表达同组不同目标的资格而少改支持算式；需一次受治理集合M，未知可能增多；新增判断误差和延迟必须测 | 新证据可改变成员、集合μ、a及份额，反例可削弱/推翻倾向，修复也可改变关系 | 选材条件、均值/峰值结构、μ量尺及m=0边界不能由生活自动修改 |
| **R3：逐事件算支持，再在根内平均** | 逐成员已有μ与a形成信号，确定性平均；每根每目标只出一份合成S/强度，再共享份额，详见下文 | 不需集合M；可利用不一致的已知μ；但非线性先后不同，是更大的数学改变，等权本身是固定假设 | 真实新成员、反证与解释更正改变合成结果；来源失效后重算 | 事件等权、先clip后平均、峰值强度及有效成员计数定义不随经历改变 |

R1是可实施的保守阶段路线，不满足「所有合法混合输入都能利用」的覆盖目标；若用户选择它，必须明确接受哪些混合输入仍未支持，不能用全拒绝测试宣称P5-44/45混合验收完成。R2/R3是待验证的完整事件级候选，不是已证明的生产算法；若不能守LP1/LP2、去重或重放，则必须报告失败，不能自动换路线。

### R2 的具体规则与边界

1. E(c,k)按照§1构造，纳入的每项有同一前缀上有效的A及所需资格。未知只阻断依赖它的主张；不会把未知当反应零，也不能只删不利成员使μ变高。已知的部分与未知部分无法在事件级分开时，该目标保持不能安全表示。
2. M读取目标定义、成员的受治理事实/来源与规定上下文，不读a正负、x/m/θ/π/s；为**整个集合**记录μ。逻辑目标须按既定定义给1/0/未知；部分吻合没有预先固定量尺则未知；不能取成员μ的mean/max/比例充数。集合适用范围必须在概念定义中事先明确；没有集合定义时，仅允许单成员或全部成员同一已知判断的无损提升，混合成员μ不能靠模型临场选择「任一/全部/多数」归约，必须留未知。多成员连续值须有明确的集合量尺，否则同样未知；这项限制意味着R2并不能自动消除所有混合μ缺口。已有成员μ保留其原判断来历，不冒充对另一集合的判断。
3. 空集合不分配；μ未知暂不分配；μ=0是不适用，不是负S。μ>0才调用支持函数。记录「未支持/未知」供解释与后继补齐，但不新建一个可增长的未知证据组。
4. 使用本事件前的b、σ̂，依现行数值路径先逐成员计算fl(a−b)，按现有`exact_mean`得各坐标均值，再作d的点积得到p；S=μ·clip(2p/r̃−1,−1,1)。强度沿现行max(r̃,成员绝对投影峰值)/σ̂并受w_max限制。r̃、d与所有运算版本来自绑定的规律/候选资源；不新设数值。`exact_mean`不换成普通浮点sum/n。
5. G只产生(root,target)一份分配；同根新增内容/集合μ正常修订不再发一份q/N。首次新目标分配及来源失效按§4/5区分。新G后继以资格选择替代旧统一verifiable折扣；这是新语义，不是把旧v_u设1。

**为什么推荐。** D13-A已经需要按目标判断资格，事件视图是把这一区别传到G的最少表达。R2保留已有支持/强度计算，只补明确的集合判断；比R3少引入一种新的信号压缩规律，比R1少整组丢掉混合相处。代价是集合M可能失败、没有量尺的部分吻合仍未知，判断耗时和质量尚未测量；不保证她一定学出能力与诚实的区别。

上轮审查讨论过一个可单选的简化办法：每目标仍取完整的 E(c,k)，只在非空、全体在同一有效定义和量尺下有完全相同的已知 μ、且目标语义允许同值无损提升时取共同值；其余未知。连续值仍须有集合量尺。不按容差比值，不因某成员不利或未知而删掉它；次数、次序或组合敏感的目标不能仅凭数值相等放行。例如目标是「恰有一次 P」，两件都满足 P 的单项各可取 1，合在一起却不满足。简化办法省去单独的集合 M 判断及其采纳记录，仍要保留成员 M、视图、未知原因和归约版本。已有分配转为未知时须修订有效分配及同侧份额，重新可用时沿首次、普通修订或来源失效的实际路径计算。覆盖、份额再分配、最终状态与调用成本均待测，不能推算固定的少学比例。这是 U5 的备选，原 R2 的推荐仍在。

**与未批准全B的分界。** 这里只借用了「目标视图＋明确集合μ」这一候选形状，并重新提交U5；没有采用D04-B的专门对照片段体系、D20-B的逐说法因果链、D13-B的自动分项依赖图，也没有批准它们的实验/数值。数据不足时明确未支持，不能借R2补上分句或因果归属能力。

### R3 的可审查计算骨架

这是独立候选，不是给R2的隐式fallback。对已完成§1资格处理、去重的n个成员，要求各成员μ为已知0或正数；任一必须使用的μ未知则该目标不归约。记p_e为成员(a_e−b)在d上的投影，r̃及b/σ̂与R2相同：

- 先逐成员算 s_e=fl(μ_e·clip(fl(fl(2p_e)/r̃)−1,−1,1))，再S=exact_mean(s_e)；每个证据观察等权，不按句数加权。
- μ̄=exact_mean(μ_e)。若μ̄=0则无分配；否则p̄=fl(exact_mean(fl(μ_e·p_e))/μ̄)，作为典型幅度M/U路径的投影输入。非有限、正信息被舍掉等按现行数值故障规则处理，不补ε。
- 强度仍取μ_e>0成员的绝对投影峰值与r̃的较大者，除σ̂后截到现有w_max；S的符号决定该目标所在份额侧，root只计一次。正反成员可能抵消，抵消为0沿已批准零信号路径，不把它变未知。
- 新增结构只有归约资源；**三问的答案**是：可以不用本路线而选R2；人可能先衡量每次经历再形成整体印象；采纳后等权和先clip的结构不会被经历自行改变。μ̄只作数值归约，不冒充新的语义吻合量尺；是否允许它作为G的M/U输入也属于U5的整体取舍。

它与R2不是等价写法。例如两个完整观察的投影为1和0、成员μ及已记录集合μ均1、r̃=0.5、b=0时，R2先平均再clip得到S=1，R3先clip得到1与−1，再平均为S=0。这里的数值只是手算区分算法的例子，不是参数建议、测量或验收通过。R3保留「一次很强的支持不能在clip后完全盖过一次反对」的效应，也可能更容易抵消；需独立核对整组输入的LP性质与M/U含义。

## 4. 共享份额和排序

**ADR 0019 已定分侧和次序，U6 只选新视图怎样携带或还原实际分配依据。** 对每个共同根c，在本次计划中的所有合格规范目标里，按S>0、S<0分别归一份额；S=0不参加任何一侧。非空一侧之和精确为1，空侧为0。不同E(c,k)不另领预算，同一根可同时有正侧和反侧，这是既有I25的分侧规则，不改成两侧合起来1。

每侧以同一规定前态的(1+π_k)/2形成配额，按ADR0019§8的2^52单位、最大余数及规范ID平局次序量化；正配额落为0时报精度故障，不静默丢弃。此处的2^52来自已批准数值规范，不是新参数。份额总和受约束，不等于不同方向各自强度之和必为1；每侧各目标W在单组强度上限及份额下受限。

| 层次 | 必须保存/恢复的顺序 | 禁止替代 |
| --- | --- | --- |
| 事件与解释 | H实际提交次序；同提交按明确记录的局部序位 | 发生时间、到达时钟、文件名或模型返回顺序 |
| 根的首次位置 | 最早有效来源位置；合组保留来历，纯重复不刷新 | 新视图摘要/新建议版本当新组 |
| 成员计算 | 真实成员次序和固定四乎坐标次序；均值仍按规定exact_mean | 普通sum/n或按反应大小排序 |
| 候选提出/结构关系再入 | genesis与H明确提出顺序；同提交有完整、唯一的同时提出次序；规范别名不刷新它 | 按ID猜谁先提出；从旧Assembly猜当前入场意图 |
| 旧分配修订 | 先建完整计划，再按固定组/目标序修订，按原ordinal与已存q折叠，记录π_cf | 重新估旧q；先插新目标后让它改变其它目标的同次前态 |
| 首次分配 | ADR0019§6/12的追加位置、group_id、tendency_id确定顺序；同组共享前态；q只生成一次并保存 | 把后来采纳的新候选第一次分配塞进π_cf，或伪装它从原根出现时就已采纳 |

根的历史位置与某目标的首次分配位置分开：EV5要回溯之前的正反经历，但回溯导致的首次分配发生在当前实际采纳事务。原参与者份额变化是修订，新候选第一次分到该旧根是新增；分别做撤回单调性和新增相对π_cf的边际检查。容量移出/再入也恢复真实尝试次序并回溯完整历史，不创建持久候选等待队列。

例：同一根含e1、e2，k1只合法使用e1，k2合法使用两项；二者同侧时共享该侧的一份额度，不能各得一份满额。若之后发现k1所依赖的事实失效，按§5处理其资格；e2真实存在不受牵连。若k3只是k2的别名，规范化后不能成为第三个竞争者。

## 5. 更正

对已提交的原记录，用 RecordVersion 固定两端、用途和分支，以生效提交及其后同分支前沿判定有效性。CORRECTION / RETRACTION / ACCEPTED_FALSIFICATION / USE_REVOKED 分别记录更正、撤回、获准证伪和指定用途撤权；单有矛盾标注或权限快照不能推出后两项。要断言已查全，应从被用原件反查含更正的更正在内的相关边，按端点、用途和前沿取 RelationSet 与 RelationQueryReceipt，核对独立可信清单，空集同样核对。投影器遇必要端点/查全证明缺失，按 ADR 0042 §§1.3、3.2 处理。本节表格处理学习侧的目标依赖及重算，查全凭据本身不给出受影响的目标或 q。[ADR 0045 §3](../../docs/adr/0045-speak-think-wiring.md) · [ADR 0046 §2.2](../../docs/adr/0046-speak-think-contract-gaps.md)

第三行是**U8待批的事件级最小范围规则**：比如「确实收到他说P」与「P为真」有分别明确的目标依据时可只撤回后者；无法确定依赖范围时相关目标暂不分配并报告缺口，不能任意选最小/最大删除范围。无需启用自动分句图；未来升级B后才能按批准的新细粒度依赖重算。
