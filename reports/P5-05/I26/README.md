# I26 原样载荷绑定：P5-05 的局部证据

2026-10-26 用户批准拆卡后，本卡只验收进程内的字节绑定。完整 I26（包含已认证审批、
执行凭证、防重放和 P5-14 的实际发送路径）**未运行，移交新卡 P5-40**，任务定义见
[PR #102](https://github.com/nanake-lab/nemu/pull/102)。本目录不声明完整 I26 通过。

实现：`core/crates/action-gate/src/permissions/approval.rs`；测试在同目录的
`approval/tests.rs`。复用现有生成的 `ApprovalRequestV2` / `ApprovalDecisionV2`，不修改 IDL。

| 局部检查 | 正向及拒绝用例 |
| --- | --- |
| 原样 SHA256 | 空串、abc、长消息已知答案；CRLF/LF、组合字符、NUL 不归一化 |
| gate 自行生成审批元数据 | 确定性标题、字节数与摘要；修改标题/说明拒绝，原始二进制载荷保留 |
| 请求/决策/实际字节绑定 | 一致时通过；请求字节、摘要、决策摘要、实际字节变化拒绝；重算请求摘要不能匹配旧决策 |
| 行动及审批 ID | 对应时通过；任一 ID 不匹配拒绝 |
| 确认选择 | ALLOW_ONCE 可通过；DENY、T3 的 ALLOW_ALWAYS 拒绝 |
| 过期 | 到期前可消费；验证和消费两处均在到期边界拒绝，不调用回调 |
| 持有已核验字节 | 后续修改原请求/决策/数组不能改变快照；回调只取得快照中的不可变字节和绑定 |
| 消费与错误 | 按值消费，无 Clone/序列化/公开构造；重复消费编译失败；回调失败仍消费，错误原样返回 |
| 生成契约和大小限制 | 合法输入通过；错误版本、空 ID、错误摘要长度及超限拒绝 |

9 项绑定测试、6 项权限/成长测试及 1 项 compile-fail doctest 的原始输出，见
[W22/rust-20261026-1926/workspace.log](../W22/rust-20261026-1926/workspace.log)。
这是合并 main `86779b1` 后的复验；首轮原件亦保留，见 [REPORT.md](../REPORT.md)。

限制：散列不是签名；身份、来源、tier、expiry 必须由未来的已认证服务建立。再次验证同一组
wire 消息仍能创建新的局部快照，因此单个 Rust 值的消费语义不等于全局或跨重启防重放。
