# P5-38 尚未通过的验收

## 内部解释、F 和行动结果

临时库的核心事务能把已给出的解释、x、内部记录、下一轮输入及在途行动一起发布。夹具提供解释和 x。正式入口需要从 m=0 来源治理和 F 得到这些结果，运行时目前只有外部事件的已分阶段计算入口。核心存储会拒绝在持久谱系上用这个夹具级入口提交内部状态。

- ADR 0026 §6.10 要求 M 的内部候选通过 G 回溯已提交的真实事件，分摊旧证据并写 L。当前事务只允许原有 R、L、θ、U 原样接续。这里缺少候选产生、G 处理到重放的同一笔提交。
- ADR 0032、0035 采用按依据的重复刺激限制，以及按发生、观察和理解提交判定的作用。还缺纯内生重复、经真实证据修订、同源去重、按接纳/A/M 分阶段消费的组合轨迹。排队跨期限、过期执行凭证、UNKNOWN 不重发也没有在本卡的完整内部循环中验证。产品级 COG-A12 与 D11 保持未验。
- 本地路径验证每轮与在途上限会拒收多余计划。界限由调用者传入，正式部署仍需把 r、M 与实际版本资源绑定。D8 接口已用合成审查回执验证，实际 D8 服务和载体未接入。

可以先交叉审查本 PR 中的格式、读写与恢复改动，再由负责后继规律的卡提供可信结果接线。若要求同一次交付完整验收，需要先提供该接口及允许修改的实现范围。COG-A10 已按派卡决定移到 P5-39。

## W19 产品接线

运行时入口调用注入的查询函数并核验前缀和来源，再把 W19 的材料和标记交给 task-layer。当前工作区只有 fact-view 自身编译 W19，实现中没有同时持有 fact-view 与 core-runtime 的产品调用方。直接从运行时链接 fact-view 会在 Cargo.lock 增加第三条依赖边，超出用户最后确认的范围。

可以由 P5-39 的产品调度入口提供实际 W19 查询函数。如果要求本卡直接链接并创建该入口，需要另行确定依赖与目录范围。本 PR 的材料回归只覆盖显式组装的临时库调用。
