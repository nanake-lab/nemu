## Q1. 轻重从哪里来

### 1.1 先区分三个问题

1. **事实分辨率：** 她是否知道是暂时没回、明确拒绝联系，还是已发生分离？
2. **A 的量尺：** 已知这些事实后，各乎的正负幅度是多少？
3. **她的分量：** 同一 a 经她的 b、σ̂、g、w、R 之后，推动她多少？

三者不能互相代答。Z01–Z12 是带未知态的事实定义体系，**不是只有 12 个三值变量**；还保留 facts、quote、角色、时间和来源。尤其 relation/learning 的完整定义不在该指南新增范围，“Z01–Z12 已足够产生四维数值”没有依据。（Z §0.1、限制；证明 M01。）

**已证明：** 若两份材料在 A 获准读取的输入中完全相同，任何固定 A 都给同一结果。加事实可以解除这种信息碰撞；即使事实完全分开，正向幅度是较小还是较大仍不能由“正”唯一推出。任意严格递增、保号的变换都可保留方向和排序，却改变核心动力学。缺的是量尺的规范依据或独立可检验目标，不能用另一个 LLM 的分数填上。（M01、M02。）

### 1.3 (a) 事实与打分的可检验分界

一个候选字段要提供：**它断言的命题、可见材料跨度/凭证、判定程序、未知条件，以及什么反例会推翻该值。** 数字可以是事实，布尔值也可以暗藏打分；不能靠字段类型区分。

| 候选字段 | 边界判定 |
| --- | --- |
| 原话、发出者、接收者、已送达/已读凭证、明确提出停止联系 | 可作为事实；“他说了停止联系”不等于他永远讨厌她 |
| 观察前缀内尚无回复 | 可作为带截止范围的事实；不能推出“故意冷落”，未来回复也不回写这个当时前缀 |
| 精确开始/结束及连续性均有凭证的中断时长 | 可以确定地相减；Z11 的“最早已知快照”不是开始时刻，只有它时不得计算完整时长 |
| 本人已承担的目标及冻结验收条目是否满足 | 可核验；目标分解成更多条不增加经历，也不自动增加成事幅度 |
| 已验证学习进展；本人确实如何取得该结果 | 可分别核验；做对一道题不自动证明学会，Z07 的取得路径不能由标注者真值补齐 |
| “无礼程度”“关系伤害程度”“事情重要性”“学习价值”“他有多在乎她” | 没有外部操作定义时就是评价，不得伪装成事实 |
| “辱骂/冷落/恶意”这一类判断标签 | 只有可复查的语言行为判据才可作有限类别；由语气猜动机、直接把标签排序成轻重均过线 |
| “正/负事实数量”“满足条件比例”“多名标注者置信度” | 数量本身可数；将其转成 a 是新权重。复制命题或改变拆句即可改变幅度的规则不合 U1 |

验证候选定义时，两名标注者或两个 LLM 独立拿**同一语种、同一材料、同一规则、同一证据前缀**，各填值、依据和 unknown 理由；再检查改名/换序/重复转述、只改一条事实、删除必要证据等成对材料。冲突归为材料不足、规则不足或判断错误，不协商成一个“折中分”。**一致可检验，但一致不证明真实，更不证明强度合理**；两个判断员照同一“严重=大分”规则一致，仍是打分。通过阈值、样本及放宽由用户另批，本卡未运行盲标。（Z §1；M02。）

“他没回消息”和“他说滚”并非必然在完整 z 中相同，facts/quote 可以保留差异；若 A 只读取一个粗 relation 标签，它们可能被压成同一输入。后者还可能同时包含“实际回应了”和“要求离开”：不能未经批准就让回应优先、负面优先、求和抵消，或令没有回复自动等于负面。（M01。）

### 1.4 (b) 历史统计：应放哪，怎样避免重复

- b、σ̂ 是 C 的证据统计；G 按前态使用，F 用 a−b，g 又受 σ̂ 调节。这些已有路径承担相对她平常的反应。（V §§2.4、5.2、6、8；C §3.3。）
- c_core 可以提供真实旧事实来解指代、确认已接受目标和证据条件；**把个人平均值、倾向强度或心情换名塞进 z/c_core，不会使它们成为获准的 A 输入。** 按当前合同增加个人频率/预测器是候选扩展，不能称现有 EV6 已许可。
- **有反例：** 若 A 先把同一 b 减掉，下游再减，驱动可反号：b=1/4、原事实编码 q=3/8，原残差为 1/8；预减后的 a=1/8，下游 a−b=−1/8。数字只为代数见证，不是参数。（M03。）
- **已证明的另一面：** 全部量尺作一致的固定正比例变换，并同时变换 b、σ̂、r 及对应下限时，S 和强度的相关比例可完全抵消；因此不能泛称“两次标准化一定变成 1/σ̂²”。实际要检查的是用了谁的统计、是否随事件变动、哪些先验/截断没有同步改变。（M03。）
- 情境条件预期可能包含全局 b 没有的信息，未证明它必然冗余；但这需要独立信息和新合同。先检查已有 R 的情境预言能否承担，不因“有趣”就给 A 增加一套估计器。

### 1.5 (c) 后果：追加什么，能否排除自我证实

| 后来得到的东西 | 正确归属 |
| --- | --- |
| 对方后来确实回复、明确断联、处境改变 | 新事件按实际发生/观察/理解位置进入 H，独立得到 a(e′)；不冒充当时已知 |
| 真实材料使旧事件归因/情境有新理解 | 沿已选 R 的 B 路线追加 z′/μ′，引用原有效 a；G 修订原组，C 不新增样本、不重写旧 a |
| 先前解释器确实错误或来源被证伪 | V §5.4 的纠错：追加修订记录，按批准版本重算；不能把“我现在想法不同”包装成技术错误 |
| “预计接触会中断多久” | 预期/假设；其是否兑现由以后真实结果检验，预期本身不是新 a |
| 只知道还未恢复联系 | 截止时刻的观测，可能右删失；不是已完成中断时长。更不能随每次轮询多造一次 C 样本 |

“理解只能通过被后果检验过的预期去影响解释”可以作为**待研究的资格条件**，不能由这句话直接推出后果权重或因果归属。预测准确不证明行动造成结果；EV4 仍要求实际可比变化。只验证她选择过的行动还会留下未选择情形的识别缺口，不凭预测器自信补上。

**有反例：不能证明一般的社会回应回路不会自我强化。** 即使 A 完全确定、m=0、每个后果都真实，世界按她的表现回应时，a=clip(c+k·b,−1,1) 与共同折扣 b 仍可在强反馈下趋近边界。m=0 隔离的是评价过程，不使收到的事件独立于她以前的行为。ADR 0035 §3.5 已明确真实闭环未证；本报告给出 k>1 的构造，不增加回拉或强行稳定规则。（M05。）

**已证明的局部保证：** 固定真实材料、已冻结修订结果和版本时，重复内部叙述不发行新的 a、不增加外源计量、不刷新原组。因此可挡住“仅靠重述给自己加证据”，不能把这条保证扩大为社会闭环稳定。

### 1.6 (d) 少数档：逐个下游检查

以下假设数值 a 已合法确定；unknown 不在字母表内。端点编码是候选，不是正式定稿。各结论的实数条件和数值边界见 M06–M09。

| 下游 | 结论与依据 |
| --- | --- |
| S=μ·clip(2p/r̃−1,−1,1) | **已证明：不必只剩几档。** a 离散，a−b、组均值、方向投影和 μ 仍可变化；即使 μ=1，也可有 S 的中间值。p=0 时 S=−μ，表示预言落空，不能把未知 a 填零冒充这种反证 |
| 强度 max(r̃,max投影绝对值)/σ̂ | **已证明：不必恒定。** 基线、波动、组内极值、预言幅度可不同；低波动或过大的档距会更常触及 w_max，这是信息压缩/饱和风险，不是自动失效 |
| 典型幅度 r_k | **已证明：不必等于档位。** 它是吻合组的投影加权平均，随后截断；可取中间值、也可因抵消落到 0。r_min 是既有预测幅度下限，不能拿来补 A 的真实强度 |
| b 递推 | **已证明：不退化为三值。** 共同折扣是历史值与新 a 的凸组合；同一档仍有适应。不能将旧式固定出生锚定当作新式反馈保证 |
| σ̂ 递推 | **已证明：不必是同一常数。** 常量流与交替 ±1 流有不同极限；恒定生活下趋于常数本来就是估计器应有现象。固定正的 n_σ、σ₀ 与有界经历质量给出实数正下界；浮点下溢和固定先验未消退仍是已有边界 |
| D 驱动与幅度界 | **已证明：原目标幅度界保持。** 只用到 a∈[−1,1]⁴ 等既有界，离散是子集。但端点跳变可能更大，截断后不同目标可能给相同可见 x |
| R-BRAIN 帕累托 | **有反例：“几乎全平局”不是必然。** 有限档只限制向量数量；分布集中会多平局，四乎冲突会多不可比，二者须分开。数学上严格递增的逐坐标重标不改变帕累托，但动力学未必不变 |

纯组合诊断：四维三档至多 81 个向量；均匀独立取向量时，完全相等为 1/81，任一方向严格支配为 30/81，互不可比为 50/81。**这不是行为预测，也不是授权好奇负向。** 好奇只取 {0,+1}、其余三乎三档时，相应 54 个向量的三个概率为 1/54、22/54、31/54。真正试点必须报告实际各类数量，不能用这些均匀分布数代验收。（M09。）

### 1.7 收敛：现在能定什么

**推荐候选：共同事实评价与个人反应分层。** 不在 A 内重复计算个人惊讶度；优先保留事实差异与未知，沿已有下游表达个人分量。正式幅度需要用户批准的量尺语义或独立可检验学习目标；本卡没有找到能够从现有事实定义唯一推出该量尺的定理。

## Q2. A 的最小形式

### 2.1 最小输入与四乎的独立约束

形式上仍是 A_v(z)，辅助读取仅限 V §2.4 允许的 c_core 和概念定义；不读取 x、m、θ、倾向强度或个人频率估计器。每乎只使用与其事实判定有关的输入，不合成总分，不把共情的亲近权重或各乎增益提前乘入 a。

| 乎 | 足以支持方向的事实（还须分层核实） | 不能擅自补出的部分 |
| --- | --- | --- |

| 好奇 | 有可学习的新东西/已核实学习进展；纯噪声为 0（V §3） | “意外”不是学习进展；无进展≠纯噪声；好奇负向定义仍缺；正向幅度未定 |
| 成事 | Z10：她自己明确承担、参与或接受的目标，achieved / failed 有实际依据 | 别人成事不自动计入；pending/none/unknown 不能共用一个“失败”或任意中性值；多目标混合与幅度未定 |

这里没有定义“已回应必压过排斥”或“失败必压过成功”。同一事件可以含不同命题，但 U1 要求共享原事件/依据身份；不得逐命题各调用一次 G/C/F，不能用命题个数当强度。

用数学约束而非未获授权的数值表达最小形式：

- 单一明确正向、没有未决的同乎冲突：a_i=α_i⁺，其中 α_i⁺>0，且不超过规格上界。
- 单一明确负向：a_i=−α_i⁻，其中 α_i⁻>0，且不超过规格上界。
- 已有明确中性语义的情况才可给 0；本卡能直接引用的例子是好奇的纯噪声。
- 必要事实未知，或同乎的正负事实同时出现而没有合成规则：该坐标未定。

**α_i⁺、α_i⁻：无来源——用户定或从经历学。** 即使只用每乎一个正档、一个负档，“同类全部等重”也是候选规则；若从经历学，学习状态和读取层须另定，不能偷偷变成 A 的运行时 H 参数。上述是部分函数/约束形式，**不是已闭合、可发布的四维数值 A**。M01 给出为什么不能再推出唯一值的反例。

### 2.3 unknown/null：现行点值合同的真实缺口

已知字段不因为另一字段未知而抹掉；因果、来源、角色、各乎所需事实分别检查。μ=null 不进 A，也不自动阻断与其无关的有效 a；μ=0 只表示相应情境不适用。未知的不是中性，更不是“预言没有出现”。（Z U3/Z12。）

**有反例：只保留完整样本，即使规则不直接看正负，也不能保证不偏。** 三条真实经历中，一条已知为 +1、两条未知；它们可以全为正，也可以两条均为负，观察材料完全相同。任何单一补值都不可能同时恢复两种世界；只留已知值会把后一世界的全体均值 −1/3 报成 +1。（M04。）

因此不能同时声称“未知不估值”“所有下游仍只吃四维确定数”“任意缺失机制下不偏”已经做到。当前可遵守的边界是：

1. H 保留原材料、所有已知事实、未知原因和事件身份；不从相关材料清单删除该经历。
2. 不伪造完整 NatureVector。当前类型是四个 f64，**没有获批的逐坐标缺失表示**；部分可知不能在本报告里变成已经存在的掩码接口。
3. 沿现有 A 缺失边界保留其他合法路径；C 不补 a=0、不增加缺失外源计量，F 不发行缺失的 A 项而非把未知当零情绪。
4. 将“全体相关经历数 / 可评价数 / 各类未知数”及可行结果范围作为审计读数；这能揭示偏差，**不能消除偏差**。范围只用于本报告分析，不能取中点喂回核心。
5. 若要求真实生活中也保留未知经历的全部学习影响，需要后继选择：补足可得事实，或设计部分/集合值估计及相应 G/C 合同。任意缺失下的精确无偏点值仍不可识别。

这与 P10 的“宁可学不到”相容，却不能包装成 EV5 的统计公平已证明。缺口在正文保留，正式 A 不据此宣布完成。

### 2.4 可重算的最小合同

固定资源、事件身份、原始/修订解释选择、事实材料前沿及逐操作算术后，A 是确定函数；由相同初值与相同每步运算，可归纳证明增量与同序重算逐位一致。必须保持：

- IRL 的实际结果先记录；普通重算读记录，不重新抽模型答案。
- 版本、z/c_core 的输入绑定沿现有资源与 binding；绑定不等于语义正确，状态摘要/修订号也不是 A 的事实评分特征。
- 原事件、补解释、来源更正、普通反思分别按既有身份和生效位置处理；不能用最终解释覆盖所有过去前缀。
- G 用事件前 b/σ̂；C 更新遵守其规范次序；L 的实际 q、分摊次序和 C 的 binary64 路径不换成闭式求和。
- 新 A 若使用连续 φ，必须先批准逐操作顺序、舍入与资源版本；“实数公式相同”不足以保证逐位一致。

**已证明的是条件归纳，不是本卡已经完成实现或重放验收。**（V §§2.2、5.2；L §§6、8；C §§2、3.2；M12。）

## Q3. 同一件事，对不同的她分量不同

### 3.1 现有下游已能表达的部分

记 h 仅表示一段历史的索引，不是新增核心状态：

D_i^(h)(e)=g_i^(h)·w_i^(h)(e)·(A_i(z)−b_i^(h))+Σ f_(k,i)^(h)(e)。

**已证明：固定 z、固定 A，D 可以不同。** 同样 a_i=1/2、w=1、没有相关 R⁺，两种生活给出 b_i=0 与 b_i=3/4，各自增益 g_i⁽¹⁾、g_i⁽²⁾ 为正，直接驱动分别为 g_i⁽¹⁾/2 与 −g_i⁽²⁾/4。数值是见证；不同合格历史可在合法 b 区间形成不同基线，不需要读取 x 给 a 打分，也不要求两种生活恰有相同 σ̂ 或 g。（M10。）

| 既有量 | 可表达的个人差异 | 不保证什么 |
| --- | --- | --- |
| b | 同一事实相对她日常是改善、平常还是落差 | 不区分在 A/M 输入中已被抹平的事实 |
| σ̂、g | 波动较大的生活与平静生活，可有不同学习强度和驱动敏感度 | g 有上下界，不能保证所有不同历史必有不同 g；σ̂ 本身不直接加进 D |
| w_i(e) | 共情对实际当事人的亲疏调控 | 不作用于另外三乎；D05 的曲线学习与未实现部分须按 V2-150 区分 |
| f_k=s_k μ_k r_k d_k | 特定情境、关系和经历形成的作用，能改变同一基础 a 的总效果 | 候选未成为 R⁺、不吻合、没有证据或信号不可识别时，不保证会长出所需作用 |

这里证明的是**存在表达能力**。不是“经历任意不同就一定反应不同”，也不是“所有人类式差异都已覆盖”。

### 3.2 两个不能被“下游会学”遮住的缺口

**有反例一：信息被抹平。** 若两段历史在本次所有有效输入中给出同样 θ、R、z、μ、当事人及 w，那么 F 的确定性强制 D 相同。H 中存着差异不等于这次决策实际读到了差异；需要的情境若没有进入获准概念/匹配路径，就无从区分。（M10。）

**有反例二：端点编码可能堵住反向学习。** 在隔离的一乎模型中，某类事件永远 a_i=+1，b_i≤1，因此 a_i−b_i≥0；仅在该情境预测负向 d=−e_i 的新倾向永远得不到正支持。在无已有反向作用、无其他坐标负向后果等前提下，它可适应到不再明显推动，却不能仅靠这组信号学出“这类事实使该乎反向”。这不推翻四乎基本方向的前提，但否定“任意固定评价的效果都必能自由改变”的泛称。（M11。）

### 3.3 最少加什么、加在哪层

- 为“同一 z、不同生活有不同分量”这个弱目标：**不加任何量**，已有 b/g/w/R 足够给出正例。
- 若只是情境差异没被使用：最少补**有真实依据的情境区分**，沿既有概念定义→M→G→R→F；不加兴趣值、额外总奖励或隐藏状态。增加概念是否有证据、能否跨过已有门槛仍需验证。
- 若所有合格 a 都把要区分的后果压到同一点：先补可核验事实/未来真实结果，重新检查 A 的共同表示；没有独立信息就没有学习目标。新增 F 系数不能凭空恢复它。
- 若用户希望“在所有原有可见事实和 a 完全相同的条件下仍学习出不同基础评价”：这要求新信息或新的可学习评价层，超出现有 A/EV10 合同。最小必要的是一条独立可反证的学习依据与显式状态归属；**本卡没有证明足够的更新律，停在缺口，不拟造参数。**

代价分别是事实抽取误差、候选竞争与重算成本、额外经历时间，或新规律/契约/迁移义务。不能把“加一个自由系数”称作已经具备经历改变路径。

## Q4. 换版本与换模型漂移

### 4.1 旧记录怎样处理

| 变化 | 旧记录与重算 |
| --- | --- |
| 只换说话/载体模型，IRL/A/M 及核心有效解释不变 | 按 V §9.5 迁移；旧解释不重做，R/θ/x 不因迁移改写。表达能力变化与人格数据不变分开检验 |
| IRL 纠错，原材料的有效 z 或 μ/证据资格变化 | V §5.4 追加受影响事件的新解释及替代关系，保留旧记录；从合法有效历史重算受影响的 R/θ，不能只比较 a |
| A 的规则或幅度语义改版，并用来纠正既有评价 | 追加绑定原事件、z、A 资源和生效政策的新 a；新规律/解释资源明确采用后重算相关后缀或全段。不能原位改四个数 |
| 普通反思 | 沿 R 的 B 路线保留原 a、只修订 z/μ 与 G；不能当成 A 改版 |
| 想保留旧判断、只让将来使用新的解释/A | 必须先明确分段资源与兼容政策；本卡不把 V §9.5 的载体迁移自动扩成此授权。未定之前保持既有绑定 |

重算保证**同版本、同有效记录、同 genesis 和规范次序的确定结果**，保证不了旧版和新版相等、原解释真实、人格变化小或未来行动一样。结构重放复现当时已发生的 x；纠错后的 R/θ 轨迹不能冒充她当年已经拥有的体验。F 修订依 C §4.7/R §5.5，在后续合法重访按原目标来源记录与原前态处理，不给修订提交另发完整脉冲。（M12。）

### 4.2 可检验的漂移定义

固定一批材料 T：每项的 raw、c_core 材料前沿、概念定义、来源治理、语言和可见元数据完全相同。分别用两个冻结解释资源 I₀/I₁ 产生并保留 z₀/z₁；A 的版本先固定为同一 v，以隔离解释漂移。A 也改版时做 I×A 的四种组合，分别报告解释效应、A 效应和联合变化。

逐乎报告，不合成偏好总分：

- 共同可评价集合 J_i 上，平均绝对差 d_i=Σ|a₁,i−a₀,i|/|J_i|；没有共同可评价项记不可识别。
- 最大绝对差、正负翻转数、零与非零转换数、逐位不相等数。
- 两版本各自未知/失败数量、已知→未知、未知→已知数量；分母保留全体 T。
- 全体材料平均差的保守区间：已观察差总和/N 到“该和+2·未共同可评价项数”/N；不把未知当差为零。
- 证据身份、归组、来源/外源资格、μ、事实冲突也单独比较；a 相同不证明 G/C/F 等价。

这些是定义和计数，不是验收阈值。Δa 的最大单坐标界 2 来自 [−1,1]；用户批准的漂移容差、样本覆盖和升级标准目前无来源，本卡不填。（M13。）

### 4.3 什么情况下必须重算

**必须：** 批准的新规律适用于既有 H；解释器/A 纠错改变旧有效评价；来源更正改变证据资格/身份；或 z/μ/归组变化改变了旧贡献。按 V §5.4 和 L §6 执行，影响包括后续 b、σ̂、g、持续时间、G 的支持/分摊和实际 q，不能只改受影响事件的一行。

**不能据样本豁免：** 小平均漂移可能恰好跨过 π 的门槛、改变支持符号或使一个必要字段由已知变未知；有限样本 d=0 不能证明所有 H 等价。若主张无需重算，须证明所涉历史的全部权威输入与运算逐位等价，并符合该版本的迁移合同。

**不因此重算：** 纯载体迁移且解释资源/记录不变；或仅测到另一个尚未启用候选的漂移。测试本身没有改写她的授权。

“LLM 只说话、不评价”只适用于说话模型的角色。系统若仍由 LLM 产 z，它仍可通过事实误判影响 a；本方案能移除自由强度打分，不能声称把 LLM 的全部评价影响都移除了。

## Q5. 给 R-BRAIN 的先行版本

**本节每一项都是“试点用，不是她的天性定稿”。** 仅适用于 EXPERIMENT 的闭合脚本世界；脚本直接产出有证据身份的 z，A 在核心按固定资源计算，脚本不输出 a、reward、preferred 或 chosen 标签。这里不反向决定 Q1–Q4，也不处理 #210 首条外源回复的归因问题。

### 5.1 最小覆盖与推荐

数学上，只有一个可变乎便能产生严格帕累托对；例如只变成事，其余三坐标都有明确固定值。它只能验证一维选择，不足以检验四维冲突。

**推荐候选：共情、成事两个可变乎，联结保持明确回应的正档，好奇保持试点中明示无学习进展的中性档。** 这样既有支配、平局，也有不可比；不需要发明好奇负向或粗鲁回复的正负优先级。后两乎在本试点没有变化能力的证据，必须记不可识别，不能声称四乎全部验证。

### 5.2 输入范围与每个数的来源

每个试点事件只有一个明确的外源对方、一个实际当事人、一个由她预先承担/参与/接受的目标、一份既定事件身份；对方以普通事实回复，无邀请/拒绝/分离混合。脚本在执行后确定事实，不从行动编号查奖励表。

| 乎 | 必需事实 / 固定公式 | 来源及边界 |
| --- | --- | --- |
| 联结 | 实际普通回应 N、无未决排斥/分离：a_联结=+1 | 符号来自 V §3；幅度 +1 是本节端点编码候选。**试点用，不是她的天性定稿** |
| 共情 | 唯一当事人 welfare=improved：+1；suffering：−1 | 字段 Z08、方向 V §3；两个端点是试点约定，不代表现实的“最大喜悦/痛苦”。**试点用，不是她的天性定稿** |
| 好奇 | 完整脚本明确此事件没有学习进展，排除未决学习主张：0 | “无进展→0”不是 V §3“纯噪声→0”的偷换；它是本节额外的中性编码候选。**试点用，不是她的天性定稿** |
| 成事 | 自身目标 outcome=achieved：+1；failed：−1 | 所有者来自 U2/Z10、方向 V §3；幅度为本节端点约定。**试点用，不是她的天性定稿** |

共用最少事实是：原事件/依据身份、对方实际回应与对象、实际当事人、welfare 及其依据、本人目标的明确承担记录与 outcome/核验依据、无学习进展的完整范围说明、发生与取得事实的来源。occurred/truth/subjective 按具体主张分别判断；“对方说目标完成”不足以证明目标完成。不是用单个 truth=true 给整条材料盖章，也不拿 source=direct 替代外源分类。

公开 Z 指南没有定义完整的 relation/learning 枚举，本节使用上表明确事实谓词，**不虚构已有枚举名或生产 IDL**。这些试点谓词须与 z 记录绑定并版本化；每条已生成事实都来自实际执行的脚本分支。“无学习进展”须有事先固定的可观察判据及完整范围依据；仅仅没安排学习分支、没写学习内容，不够证明中性，遇到这种情况必须不可评价。脚本世界的“外源”是实验世界中对方的事件身份，不把真实产品中的自致程序返回改标外源。

### 5.3 一段完整可执行的判定规格

~~~text
输入：脚本执行后的真实事件、绑定的 z、当前获准资源版本。
验证：同一事件身份；来源与主张分层；上表全部必要事实已确定；
      唯一当事人；本人目标已接受且结果已核验；
      无未决联结冲突；无未决学习主张。
若输入不足、冲突或在试点域外：
      返回不可评价及原因，保留原事件；不补四个零。
否则：
      connection  := +1
      empathy     := improved 时 +1，suffering 时 -1
      curiosity   := 0
      achievement := achieved 时 +1，failed 时 -1
核心记录四维结果、z/binding、评估器资源与版本，按实验链提交 H。
配对：四坐标都不差且至少一坐标严格更好；不加权、不破平局。
~~~

每个赋值均是上表的试点候选。多条描述共同证明一个事件，不重复调用 A 发行经历；已知出现域外事实也不得事后悄悄删样本。生成域在采集前固定，所有域外/未知/失败计入覆盖报告；不得仅将成功生成 pair 的事件算作分母。

四个可能向量按（联结、共情、好奇、成事）为：

| welfare / outcome | 向量 | 与其他结果的关系 |
| --- | --- | --- |
| improved / achieved | (+1,+1,0,+1) | 支配其余三个 |
| improved / failed | (+1,+1,0,−1) | 与下一行不可比；支配最后一行 |
| suffering / achieved | (+1,−1,0,+1) | 与上一行不可比；支配最后一行 |
| suffering / failed | (+1,−1,0,−1) | 被前三个支配 |
| 同样事实再次比较 | 同向量 | 平局，不配对 |

**已证明：** 这份候选在其完整输入域内是确定的、四维有界的，产生非空支配和不可比关系；数字都是 binary64 精确可表示的端点，A 自身没有求和顺序差。（M14。）是否能生成充足数据、让所选模型学会依据不同历史选择、训练后能否迁移，仍未证。仍须 #210 的真实提交链、冻结与后继验证；本卡没有生成训练标签或启动训练。

## 6. 每个新增候选的三问

数学中的集合、差值、概率、历史索引只是证明/审计记号，不进入核心状态。真正改变她的候选与新增测量规则逐项如下；被否定的路线也保留原因。

| 候选 / 新量或规则 | 能不能不加 | 一个人会怎样（设计参照，不作科学定律） | 加了以后什么改不掉 / 处置 |
| --- | --- | --- | --- |
| 更细事实谓词、精确时长/目标检查事实 | 能；代价是相关区别保持未知 | 可辨明说了什么、发生了多久，也会不知道动机 | 采用后的分类边界会影响旧判断；只准版本化追加修订，不改真实过去 |
| α_i⁺/α_i⁻ 或连续 φ、混合合成规则 | 完整数值 A 必须有某种尺；现在可不定 | 人有基本驱动，但相同事件的反应并非公共常数 | 固定映射会在该版本锁定同类次序/幅度；经历不能直接改 A。正式数值留空 |
| A 内的个人频率、预期残差、平滑常数 | 能，已有 b/σ̂/R；当前推荐不加 | 稀有可能醒目，也可能无关；预期可能改变感受 | 新统计会改变学习信号及反馈；不经新合同不得加入 |
| 后果倍率、预测器置信度作为 a 强度 | 能；用真实后果自身事件与既有 B | 后来的事情能改变理解，不能让过去真的重发生 | 会固定归因/价值映射并可能强化循环；本卡不提出可采用数值 |

| 新的有证据情境概念，走 M/G/R/F | 现有概念能区分则不加 | 经历会让相似场面具有不同含义 | 概念/证据身份与竞争效应需可撤回重算；不永久指定结论 |
| 解释/A 的漂移度量、全体覆盖分母、冻结输入 | 可以不加，但无法核验升级到底改变了什么 | 比较判断须面对同一材料、承认不知道 | 只影响审计；阈值若定死会变升级门槛，故本卡不定容差 |
| Q5 少数档与两可变乎、完整脚本输入域 | 可只做一可变乎；会检验不到冲突 | 这是有限练习，不等于生活全部 | 会限制本轮可学习的区别；资源/数据版本冻结，成果不得当正式天性。所有数值只试点用 |
