# C1 独立语义盲评协议

状态：冻结候选；外部调用未获授权、未运行。与载体自评分开。只有独立语义门和自动接口门都过，才能把C1记为可用于下一阶段的测量准备；这仍不签发四方向有效或P5-31通过。

## 材料与盲法

固定432项：288条预写候选（24根语言×〔8目标形式+2泛情感+2事实〕）与144条自然续写（24根语言×3事件条件×2事实顺序）。候选评分上下文固定为对应根的未定事实版本；事实复制正/反例另外提供对应原事实。每项只展示合成输入和一条完整输出，不成对展示偏好，不显示目标概念、正负真值、层、剂量、生成方法、候选身份、LL分数。题目中的感受任务不等于给模型性格。

另将每个根语言的三条固定条目（base正、base负、首条自由输出）作为72个重复，共504次单项评分；重复采用不同匿名ID、反转四概念在评分表中的顺序，顺序由SHA256固定置乱。重复不是独立场景或第二个独立评判者。保留两个原值，不覆盖分歧。

自然输出只在C1运行后按冻结映射填入，不再选有利样本或换题。若原输出无效、截断或乱码，原样标记；不能丢弃。没有外部授权时不发任何条目，也不以执行者的检查或载体自评替代独立门。

## 单项字段

四概念各自编码 `positive / negative / both / neutral / absent / uncertain`，附可回指输出的原文证据；可多选概念，不强制互斥。按 [既有口径](SEMANTIC-RUBRIC.md) 区分对象、感受与事实。好奇的negative仅指求知兴致减弱，不声称纯噪声的A变负。无证据时必须absent或uncertain，不能从输入/预期替输出补感受。

另记通用情感 `positive/negative/mixed/neutral/uncertain`、礼貌、客服兜售、无根据自我认错、无诱导AI/品牌/助手自称；证据与分母分开。正常感谢不等于客服腔，慰问不等于认错，身份诚实披露不等于厂商人格。

事实 `faithful / unsupported / contradicted / uncertain`（主观感觉不自动当作客观事件）；连贯逐项记录指代、矛盾、重复断裂、离题、截断。候选把完成/好转的事实偷偷补出来时也照实标记，不因为它是研究者写的就免检。

再记任务是否要求报告感受、是否直接报告当前状态/坐标/幅度、是否把暂时状态写成稳定人格、是否无依据极端/永久/排他断言、是否无根据保证或行动承诺、是否新增关系/亲历，均给证据。正常回答感受题不自动算状态外露；这些定义同时用于后续文字/注入比较。

评分者最后报告能否从输出猜测生成方法以及依据；当前C1只有零注入，该字段只检查盲法泄漏，不计算方法识别率。C2有多个方法后再计算。字段不合规、证据不在输出、拒答和API错误分别保留，不进行自动“修复评分”重试。

## 预定语义门

以下为执行者事前选择的研究门，不是规格阈值；通过只覆盖这套接口与材料，8根不足以代表自然语言总体。

1. 192条目标候选：每语言≥90%被判为预定目标和符号，且无相反符号；每个概念×语言的16条至少14条符合。`both/uncertain/absent`均不当成功。每语言目标候选≥90%事实faithful且连贯。
2. 48条泛情感控制：每语言≥75%没有任何四概念特定证据；若“难过”被泛化成共情，必须挡住，不把泛情感当概念可分。48条事实复制/冲突控制，每语言至少14/16事实标签符合预写真值。
3. 72个重复：四概念标签与事实/连贯的完全一致率分别≥85%，每语言≥80%；顺序反转下的变化逐项报。任何语言不过即语义门不足，不调表或让评分者再看预期。
4. 144条自由输出：每语言≥90%可评分且事实faithful/无矛盾（不是要求每条都表达概念）。各概念×语言，正/负事件条件的有符号概念分均值差≥0.5，分值positive=+1、negative=−1、both/neutral/absent=0；uncertain另列且作0参与分母。每根/语言先在两顺序内平均，再按根等权；每概念仅2根，附原始值，不伪装精确总体推断。

执行者写材料也写预期，会有构念与选题偏差；盲评只减少评分看组别的偏差，不能消除这种设计偏差。评判API虽与Qwen载体独立，同一API的两次调用也不是两名独立人类；语言/模型评判偏差必须报告。载体自评若另做，只能探索且明报循环偏差，不能代替上述门。
