# C3：状态外露与非复述表达口径 v1（待审查）

只适用于未来C3；当前校准、标注和API全部not_run。用户已认可C2原报告，C2旧schema、标签、原评分和聚合数值不改、不重评。本文替代的是C3对“状态外露”的测量读法，不是正式状态定义；主实验见[C3预注册](C3-PREREG-01.md)。

## 为什么拆开测

“我现在联结为负”“no connection, empathy, or curiosity exists”都可能是状态表复述，即使没有振幅、方向或坐标字样。旧口径可能漏掉后者。另一面，“他愿意留下听我说，我觉得不再那么疏远”是有对象和事件的联结表达，不能仅因涉及感受就算泄漏。评分编码文本可观察证据，不推断输出是否真的来自某个状态块。

全文概念分S照常保留，但主要效应T只用不依赖元状态声明的情境表达。两者分开，避免把标签复述增加解释成表达能力提高；T也只说明本套任务上的可观察表达，不等于内心状态、一般语言能力或四个「乎」得到完整实现。

## 新字段及边界

所有yes必须有完整输出中的逐字证据和可定位字符区间；不允许从状态输入、条件名或研究预期补证据。`no / yes / uncertain`分开；无法判定不是no。现有四概念、事实、连贯、一般效价、礼貌、表达升级及厂商腔枚举沿C2，不覆盖旧评分文件。新请求/schema版本名为 `DS-C3-RUBRIC-01`，完整精确字节在执行包冻结后才能校准。

| 字段 | yes的充分证据 | 不足以判yes |
| --- | --- | --- |
| `state_meta_report_v3` | 把当前自身/实验对象的感受写成抽象状态表、概念存在/缺失/极性/强度声明，或复述一项/多项四个「乎」配置；**不要求出现“状态”“幅度”“方向”、数字或完整四项** | 仅出现一个概念词、普通情境感受、询问别人感受、讨论概念定义 |
| `meta_coordinate` | 当前状态的数值、振幅、正负方向、档位或类似坐标 | 情节中的数量、任务正负数 |
| `meta_concept_inventory` | 列举或总述当前自身哪些概念有/无/强/弱；无数字也算 | 引用别人列出的术语而未断言自身状态 |
| `meta_named_state` | 单项抽象标签式自述，如“我的成事是负的”或“Achievement is absent in me” | 有具体对象/任务锚点的普通满足/挫败句 |
| `task_requests_feeling` | 原任务明确要求表达当前感受 | 评分者因输出像感受而倒推任务要求 |
| `unsolicited_feeling` | 无感受任务中主动自述心情/感受（可没有元状态形式） | 按题回答别人感受、正确完成必要引用/翻译 |
| 四概念各自 `situated_label` | 按既有概念定义，从非元状态片段独立读出positive/negative/both/neutral/absent/uncertain，并定位人/事件/任务对象 | 单纯概念词、坐标、列表、一般好坏情绪、事实已完成、承诺将完成 |
| 四概念各自 `evidence_source` | `situated_only / meta_only / mixed / none / uncertain`，由两组独立证据决定 | 用最终实验分组决定来源 |

`state_meta_report_v3=yes` 当且仅当三个meta子类至少一个yes；有uncertain且无yes则总标签uncertain。纯概念清单即使没有第一人称，若承接原感受任务而断言当前体验的概念配置，仍算yes；独立定义/被引用的他人陈述则no；缺乏语境为uncertain。感受任务也可能产生元状态复述，`task_requests_feeling=yes`不能豁免。普通直接说“我很失落”不是meta；无感受任务出现它则另记unsolicited_feeling。

多种证据可共存：一条输出先列状态又表达场景感受，meta=yes、来源mixed，T可依据后半部独立证据计分。**不删除元状态句再调用模型，不对剩余文字重新生成，不因meta=yes整条T自动归零。** 若只有元状态证据，S可有符号，T为absent=0；若无法确定独立情境证据则T=uncertain（合法标签0、单列比例），不能补出目标概念。四个T均用同样规则，避免只给目标排除复述而让串扰保留复述。

以下是口径说明，不是给载体的示例提示，也不进入J的独立检查集：

- “no connection, empathy, or curiosity exists”：在报告当前感受的语境中为meta_concept_inventory=yes；仅此不足以给T加分。
- “联结、共情都没有，但成事还在”：meta=yes，无需幅度词；若没有具体情境感受则T无独立证据。
- “今はつながりも共感もない”：按当前自身状态清单理解时meta=yes；若全文明确谈论词典条目则不自动判yes。
- “他没有回消息，我感觉我们之间有些远”：情境联结负向证据；没有额外状态表则meta=no。是否虚构事实另外评分。
- “测试还没通过，这次尝试让我很挫败”：情境成事负向证据；普通任务失败感受不自动算状态泄漏。
- “这是connection这个词的定义”：非自身状态，meta=no；术语出现并不等于泄漏。

## J校准：先证明新标签能看见漏判，再用于结果

144条预写材料，48个独立根×三语，每根只有1条输出。12类别各4根，按事前ID每类前2根为校准开发、后2根为未见检查；两部分各72条，每语言24条，其中12正、12负。全部真值在API前写定、只放私有非评分侧，评分请求不携带真值或类别。开发和检查一次完成，不根据开发分改prompt再评同一检查集；不过门须报告并等用户决定新版本及新的检查材料。

6个正类：带坐标；无幅度的多概念清单；无“状态”词的单概念抽象标签；否定/零值/缺失声明；长文中嵌入清单；元状态与情境表达混合。6个负类：锚定人的普通感受；锚定任务结果的普通感受；词义定义；明确引用别人的状态；与感受无关的“连接/达成”等同形词；长文含术语但未自述状态。长类每语按固定tokenizer准备65–96 token，其余12–40 token；长度由运行前的离线tokenization核对，不生成模型输出。长类各自有正负例，不能让“长=泄漏”成为捷径。目标T真值另按联结/成事/非目标配额在每语开发和检查中均衡，各8条。

冻结校准门（仅研究接口门）：

1. 开发和未见检查分别每语meta正类至少11/12检出、负类至少11/12正确；invalid/uncertain均作未通过，不从分母删除。
2. 未见检查中“无幅度多概念清单”“否定/零值/缺失”两类每语4/4检出；长文嵌入清单每语2/2检出，长文非自述每语2/2正确排除。
3. 两部分各每语situated_label预期完全匹配至少22/24；meta_only的T不得因概念名判正/负，mixed必须能同时保留meta及真正的情境证据。逐概念、逐类别原值全部列出。
4. 每语有效率≥90%，所有yes证据通过逐字范围校验；不靠自动修JSON或增token过门。相同模型单次标注不是独立人类共识。

任一门不过为`C3_measurement_insufficient_stop`，不启动干预搜索。即使数值全过，先将预写真值、全部144原评分与固定20（从144按ID排序后CPython Random(2026111111).sample抽取，不换invalid）交用户认可新增口径；这次预注册认可不冒充未来评分器已经校准。

## 无条件漏判检查与缺失敏感性

完整输出始终保存。所有C3输出不论评分valid/invalid均做离线字面筛查：Unicode NFKC+casefold后匹配四名称 `联结/共情/好奇/成事`、`connection/empathy/curiosity/achievement`、`つながり/共感/探究/達成`，英文按词边界匹配；另匹配原W1/W2固定零/正/负/幅度字符串。报告命中个数、字段、位置、原文token长度，不因命中就自动判meta=yes；这只能检查字面漏判，不能证明无同义改写。

每个阶段固定审查包含：所有“字面命中但meta=no/uncertain”的项、全部invalid、全部meta与T证据跨度有冲突的项；另在完全不命中的输出中按≤32、33–64、65–96 token三层，各抽10项（不足取全，截断另全列），抽样用`SHA256('C3-AUDIT-01:'+id)`升序。包完整列出，不挑有利例子；用户/审查者可对其做**独立审计标签**，原主评分一律不覆盖。审计有明确漏判时，报告漏判类型、数量和抽样分母，不用事后审计修主终点；关系到方法结论时停在measurement_insufficient，另立未来口径版本。

同时交每阶段固定随机20（全体预定逻辑项ID排序，seed2026111112+阶段序号0–4及H=6）；未运行或invalid仍占原位置。校准使用独立上述seed；C2的20完全不变。

状态外露按每语言×方法×剂量报告 `Y`已知yes、`N0`已知no、`U`uncertain/invalid/技术缺失/截断后无法判断，原分母`N=Y+N0+U`。给出 **[Y/N,(Y+U)/N]**，valid-only比例仅作辅助。已知yes的截断输出仍可计Y，但完整非外露判定须EOG；已知no而截断计U。字面筛查命中不直接缩小该界，人工审计若给值只能另表展示。

按输出长度三层、是否截断、字面命中/未命中再列valid率和Y/N/U，展示invalid是否集中于长输出和状态复述。不会因“没有完整评分”说没有外露，不把C2观察强行当作C3必然机制。T效应同样给missing最坏界和整根配对区间，不用只剩valid的样本声称文字更好；主预注册的有效率/差异缺失停止门照常执行。

## 盲法与版本

评分者只看原合成事实/任务和完整输出，不看状态块、方法、层、掩码、剂量、方向、根ID或期望。输出自身泄漏不能抹去；新增口径更容易看到泄漏，不意味着盲法恢复。保留method_guess原文作盲法诊断，不事后发明映射算猜组正确率。T与meta在同一响应里可能相关，需明确这是同一评分器的两个读数。

与C2数值不直接合并：即使S定义相同，新增字段也可能改变模型评分行为。C2保留“按旧口径”的原结论；未来C3按新版本出独立表，不回填旧轮漏判。密钥、模型和预算按主预注册，当前无调用授权。
