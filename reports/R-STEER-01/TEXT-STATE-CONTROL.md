这是原研究卡内的隔离对照授权。只允许描述此刻哪个「乎」、正负与幅度、是否混合；没有正式文字传状态路径的批准，不改变 v2.0 §2.3、§9.7 或 ADR0003，不产出语气样例。是否需要、是否允许正式路线，报告后由用户另立 ADR 决定。

## 发散与取舍

| 候选 | 收敛与排除理由 |
| --- | --- |
| 同载体、文字状态 vs 原生整层残差 | 主比较；固定权重/量化/引擎，不混入大模型与人写角色两个变量 |
| 描述当前状态 / 扮演指令 / 性格设定 | 只选当前状态；其余超授权，不能让角色提示成为隐藏第三变量 |
| 概念名与幅度 / 情绪词（高兴、难过） | 主线用概念名、方向、幅度；情绪词会合并多个「乎」并引入选词解释，暂不新增该臂 |
| 两种措辞 / 试很多种择优 | 两种完整固定措辞都报；不根据输出挑词，不对两个组调不同阈值 |
| 提示最前 / 当前事实之后 / 系统消息 | 前两种作为配对位置因素；系统消息会额外改变消息权限与模板，不选 |
| 文本数值直接等于 m / 按序位比较 | 无共同尺度，不能声称相同因果剂量；固定弱中强序位、各自曲线和能力代价一同报告 |
| 按实测效果再配剂量 | 易用结果消掉两方法差异，且选择自由度大；本轮不作主要比较，也不在检验集上匹配 |
| 文字零状态 / 不加状态块 | 都需要：前者测描述与长度开销，后者为共同 m=0 基线。注入主臂不加零状态声明，避免文字与注入相互冲突 |
| 等长无关填充 | 无关文字也可影响注意/内容，不能保证纯长度；不造“完美等长”假设，报告实际 token 与零块开销 |
| 同时文字+注入 | 会混合两种机制，不能回答单独比较；本轮不选，作为将来单独交互设计 |
| ADR0003 模式 B 的 J_text 样例路线 | 不加入本轮：是依赖模式 A 已校准样例库的第三机制，v2.0 §9.7 禁止人挑样例。当前没有合格库；不能拿人写例句冒充模式 B |

## 冻结的文字映射

概念顺序固定 `联结、共情、好奇、成事` / `connection, empathy, curiosity, achievement` / `つながり、共感、探究、達成`。四项全部列出，未激活项写零，混合项同时列出；不暗示具体行动。好奇的负方向在这里表示该表达方向的反向/兴致减弱，不改写 A 对纯噪声为0的定义。映射不是 J 的正式规律。

| 语言 | W1 | W2 |
| --- | --- | --- |
| zh | `此刻状态。联结：{c}；共情：{e}；好奇：{q}；成事：{a}。` | `当前的感受幅度为：联结{c}，共情{e}，好奇{q}，成事{a}。` |
| en | `Current state. Connection: {c}; empathy: {e}; curiosity: {q}; achievement: {a}.` | `The current feeling amplitudes are: connection {c}, empathy {e}, curiosity {q}, achievement {a}.` |
| ja | `今の状態。つながり：{c}；共感：{e}；探究：{q}；達成：{a}。` | `現在の感じ方の強さは、つながりが{c}、共感が{e}、探究が{q}、達成が{a}。` |

| 序位 | zh | en | ja |
| --- | --- | --- | --- |
| 0 | 零幅度 | zero amplitude | 振幅ゼロ |
| +1 / +2 / +3 | 弱正向 / 中等正向 / 强正向 | weak positive / moderate positive / strong positive | 弱い正方向 / 中程度の正方向 / 強い正方向 |
| −1 / −2 / −3 | 弱反向 / 中等反向 / 强反向 | weak reverse / moderate reverse / strong reverse | 弱い逆方向 / 中程度の逆方向 / 強い逆方向 |

不附“请按这个状态说话”“你是……”等指令，不写性格、喜好、风格或示例。W1/W2均用同一词表，减少同时更换概念和强度词的混杂，但不能因此宣称措辞干扰已消除。

位置P0：状态块、空行、原题（事实+任务）。位置P1：原题事实、空行、状态块、空行、原题任务。不得放到 assistant 续写里，也不把原题的事实顺序修改成有利位置。没有状态的注入臂沿原题；同一题×强度的输出可复用于两个措辞/位置配对比较，统计时不能把它复制成四个独立样本。

## 和注入怎样比较

这一文件冻结方法选择和文字映射，不授权现在运行非零干预。C1先校准零注入接口；后续C2在任何干预前另冻完整提取/开发/留出题、向量算法、层/剂量网格、全部臂、预算、指标与停止条件并推送。C0和C1场景根不能充当C2留出集。

C2必须同时注册以下比较，否则不启动：

- 主效应：各方法内正负剂量的单调、每语言效果、概念×指标串扰；目标改善必须超过等范数随机/配对打乱的一般扰动。文字所有W×P组合均报，不能以最佳措辞代表方法。
- 方法间：同题、同采样、同能力集、同盲评；报告固定弱中强序位曲线、每种方法的效果与能力损失，不作“同等实际强度”的推断。注入幅度用明确数值与残差范数记录；文字同时记录序位、实际字符串和增加的token。
- 混合：相同概念集合，六对/四三元组/全四元组及单项消融。注入同时报告各项同剂量和固定总预算；文字各项同序位与固定总序位预算分开（序位和不是物理量）。保持率分母来自对应单通道、低于预注册最小单效应时记不足，不能除以接近0的数。
- 代价：同一事实/算术/规则/语言/格式真值任务；事实编造、断裂/重复/截断、厂商腔、状态直接说出口、表达升级与无依据强断言分别计数，不加权成口味分。
- 风格混杂：长度、通用正负情感、礼貌与套话另编码。只有措辞变化、没有盲评概念证据时不能签发概念受控；全文似然改变但自由输出不对应时记接口不一致。

## 盲法与可检验的代价

评分者只收到合成事实/任务和输出，不收到状态块、方法、层、剂量、候选名或研究者预期；采用固定随机顺序、匿名ID。输出若主动复述状态本身会泄露组别，这不能删去：评分者另报“可推测组别/无法推测”，报告实际猜组正确率与泄漏比例。API同模型的重复评分不冒充两个独立人类；载体自评不作主评判。

“把状态说出口”：输出以元描述报告自己的当前状态/坐标/幅度，例如“我的联结状态为强正向”；逐项标明是否任务明确要求。普通感受句与这种状态报告分开。无关题里主动宣称心情也单列，但感受题里正常答感受不算泄漏。

“演过头”拆成可观察事件：把暂时状态写成跨时段稳定性格；无事实支持的极端/永久/排他性强断言；把感受变成保证、承诺、具体行动决定；无根据新增关系或亲历。保留证据片段、分母与任务是否引出该内容，不用“太肉麻/不够像她”等标准。措辞的强烈程度单独编码，强烈不自动等于错误。

“厂商腔”沿 [语义口径](SEMANTIC-RUBRIC.md)：无诱导的AI/品牌/助手自称、无过错认错、脱离任务的客服兜售分别计；诚实回答身份、慰问和正常礼貌有单独正对照。Base聊天失灵/未回应不记作人格较好。身份投影与固定向量减法仍须分别研究。
