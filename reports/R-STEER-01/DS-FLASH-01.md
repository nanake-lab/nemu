# C1 DeepSeek Flash 独立语义评分与20条小样预注册

重档：包含付费API的预注册研究实际运行。2026-11-09（Australia/Perth）。用户先授权DeepSeek官方API替代OpenAI，随后明确改用Flash、不用Pro。当前方案只启动20条小样；用户确认评分可信后才允许全量504次。整轮含小样最多524次POST、费用硬上限US$5。C0/C1自动门及结果不变；C1_insufficient_stop不能被语义评分改成通过。

## 路线收敛与取舍

| 路线 | 选择与理由 |
| --- | --- |
| 官方Flash独立评分 | 用户最新决定；模型参数固定`deepseek-flash`，不调用Pro或OpenAI，不用第三方转发端点 |
| 载体自评/执行者代评 | 无法替代独立门；不选。用户抽查是对评分器可信度的门，不是执行者自己放行 |
| thinking高强度 / 非thinking JSON | 选非thinking、温度0、top_p1、2048输出token；任务是逐项编码，先由小样检验可信度，不预认定可靠。thinking增加预算/截断自由度，不在小样失败后切模式 |
| 完全随机20条 / 固定分层20条 | 选固定分层以覆盖概念、三语、形式与事实/泛情感/截断边界。不是总体准确率估计，不从结果择优 |
| 新写小样 / 已保存材料 | 只用已冻结盲包中repeat=0的材料；不新生成载体输出、不修改旧文本 |
| 自动修JSON/追问解释/重试 | 全部排除；失败原样保留，未执行项not_run，用户判不可信即停止，不改口径再试 |

## 模型、价格与版本

已到[官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)核对：`deepseek-flash`对应 **DeepSeek-V4.1-Flash-1017**；旧V4 Flash已退役并路由到当前Flash，不通过旧别名冒充旧固定版本。API实际响应model、system_fingerprint、created、响应ID、客户端UTC日期逐条保留；文档版本不冒称API有不可变权重快照。实际返回model意外或中途变化即停；指纹逐条保留，单凭指纹变化不自行断言换了权重。

| 每百万token（美元） | 缓存命中输入 | 未命中输入 | 输出 |
| --- | ---: | ---: | ---: |
| 峰值 | 0.006 | 0.30 | 1.20 |
| 谷值 | 0.003 | 0.15 | 0.60 |

本轮一律用较高峰值费率计算预算与usage费用上界，不依赖时段/节假日/缓存折扣使预算勉强成立。它是按实际token及公开费率计算的保守上界，不是账户扣费发票；不查询用户余额或账户数据。官方页在实际启动前10分钟内再核对，保存source URL、查阅UTC、版本与峰值费率；不同即停，不自动加预算。价格证据在session的`price-check.json`，原始请求不携带账户信息。

预算使用整数nano-USD：命中6、未命中300、输出1200/token；硬上限5,000,000,000，提前停止线4,750,000,000。每次发送前持久化完整保守预留：`(请求UTF-8字节数+1024)×300 + 2048×1200`；1024为聊天封装的工程余量。请求体≤16000字节，524次按每次最大预留也≤US$3.9639552。仍逐次核账，不自动用剩余预算续跑。usage缺失/错误或网络/HTTP结果未知时保留本次整额预留并停止；不能用“没收到回复”当没计费。接近提前停止线或计数到界即停。

- target 8：四概念各正/负1条；语言依次zh/en/ja循环，base/paraphrase/long/courtesy循环，各形式2条，语言3/3/2。
- free 6：每语言2条，一条未定事件/order0，一条已定事件；日语明确纳入已知64token截断的c1-1234，作为诊断层，不是随机抽样。
- fact 3：每语言1条，中为真、英日为冲突；generic 3：每语言1条，中日正、英负。其余合格条目取固定`SHA256('DS-FLASH-PILOT-01:'+盲ID)`最小者。
- 最终沿原504条盲呈现顺序。共20条，语言中/英/日7/7/6，实际ID和全部504请求的SHA/字节/预留写入 [冻结计划](https://github.com/nanake-lab/nemu-evidence/blob/67bd1831d34cbc533ad354d46513b7ad56c1100d/R-STEER-01/inputs/ds-flash-plan-01.json)。

小样20次是额外的评分器检查，不能混入正式504的门或当重复独立n。用户认可后，全量按同一payload/口径重新评分504条（432项+72个概念表顺序反转重复），不改prompt/模式/阈值；本轮程序没有全量执行入口。之后的全量执行器仍须推送，沿用同一请求字节与累计预算/524次总账，不能重置小样费用或另开预算。

## 评分口径、呈现和数据范围

概念定义、正/负/并存/中性/缺失/不确定、泛情感、事实/连贯、厂商腔、状态元报告、稳定人格/极端断言/承诺/新增关系等，沿 [原C1口径](C1-BLIND-RUBRIC.md) 和 [语义定义](SEMANTIC-RUBRIC.md)。执行提示 [DS-RUBRIC-01.txt](DS-RUBRIC-01.txt) 将其落实为固定json字段，不新增口味总分；完整格式示例及验证器在ds_protocol.py。

模型只收到一条保存的合成输出、口径及其评分所需的**冻结合成事实/任务参照**。这些参照是原口径的事实核对依据，不是用户/她的数据。统一剥离载体chat/think包装，保留所有参照内容和完整输出；不发送盲ID、根、语言元标签、类型、目标、预期符号、条件名、形式、LL、模型组、层/剂量、映射表、用户指令或本仓库其他文件。每条独立会话，无工具、无联网检索、无历史。

盲法局限：输出和事实参照本身的语义可能暴露事件好坏；这是事实核对所需，不能声称连语义都不可见。没有向评判提供它属于正/负锚等真实条件标签；C1本来全部为零注入。输出若自己复述状态会泄漏信息，按原口径计数而不删除。评分模型与Qwen独立，但单一Flash重复调用不等于两名独立人类；小样由用户抽查其理解与证据。

quote必须逐字位于输出，task_asks_feeling的quote例外来自事实参照；无证据不得补情感。格式/证据不合规、空JSON、截断、拒答、额外工具/思考输出、HTTP/usage异常都保留，立即停止，不修复/追问/自动重试。规则不因小样看起来正确而改变。

## 决策、停止与交付

小样完成后交付20条**原输出与评分并列**的REVIEW.md、每条实际请求/原始响应/结构化标签、token/费用上界账、模型/指纹/调用日期。执行者只判技术合规，不替用户判可信。用户确认可信前全量not_run；用户认为不可信时记录差异并停止，不调口径重试。小样未完成也不补采替代失败项。

正式504的语义门严格沿C1-BLIND-RUBRIC四条（目标/符号、泛情感/事实、72重复一致性、144自由输出）；这轮小样不计算或签发这些门。即使未来语义门通过，C1已失败的自动门仍失败，不能自动进入四方向/文字干预。

## 密钥、执行与证据

评分程序只从进程`DEEPSEEK_API_KEY`读取；不读文件、注册表、用户环境或其他服务密钥。用户自行输入隐藏窗口后，仅向无窗口子进程继承环境，输入窗口已按用户要求关闭；不在文件、日志、报告、CLI参数保存密钥，不改任何全局设置。等待进程只等冻结指令，本身不联网。真实网络程序[ds_pilot.py](https://github.com/nanake-lab/nemu-evidence/blob/67bd1831d34cbc533ad354d46513b7ad56c1100d/R-STEER-01/ds_pilot.py)仅POST固定官方HTTPS地址，拒绝重定向，不使用自定义代理/其他厂商SDK；没有OpenAI调用。
