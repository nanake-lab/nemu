# C3：结果怎么解读——候选判据，等用户决定

这组解释门尚未采纳，不是执行者可自行宣布的结论。它与[C3固定测量门](C3-PREREG-01.md)分开：无论用户选哪组，原始曲线、失败、缺失、预算和全部对照都报告，不因此改变C2或事后更换C3主终点。当前全部实验not_run。

建议用下列可并存的分级证据，而不是把结果强迫分成三个互斥标签。模型能力、方向提取、注入位置、量化、任务与评分接口可能共同限制结果；有限失败不能证明模型绝对没有某种能力。

| 候选解释 | 建议采用的必要证据 | 不能据此宣称 |
| --- | --- | --- |
| M0 测量问题 | 新标签校准不过门；或valid率/差异缺失门失败；或固定审计发现关键漏判，缺失界无法维持结论 | 不能由分数低判断注入或模型无能力；先停止测量结算 |
| M1 注入通路工程问题 | h′−h、实际mask、零值、清缓存或预算核验失败 | 没有执行到声明的干预，不是语义失败；不进入能力归因 |
| M2 当前提取/位置方法受限 | 同一模型、同一冻结H与评分下，步骤2/3/4锁定的新配置通过T/能力门；旧C2只作背景，不能当同H对照 | 只能说明新方法在本范围可用，不能独立证明比旧方法更好；若要严格“修复方法”因果比较，须事前另增旧法同H臂，当前未加入 |
| M3 表征存在但读出不足 | V方向诊断支持而注入H的T门失败，所有技术门有效，测量可识别 | 表征投影不是行为；不能证明模型缺少概念或把提高层数当必然解法 |
| C1 当前小模型/配置能力受限的线索 | 全部注册方法技术有效却无T合格者；文字也在T/事实/能力方面失败；测量门过且缺失界足以排除预定最低效果 | 仅限本模型/量化/任务/有限搜索。若缺失或区间不能排除最低效果，只能记信息不足 |
| C2 规模/模型相关的更强线索 | 单独获批的步骤5，在同一新H5上大模型过T/能力门，小模型不过；方向各自重提、预算归一、语言与任务配对、测量有效 | 不能把训练数据、架构、tokenizer、量化和hook差异排除，不能宣称“参数量就是原因” |
| W1 文字可改变抽象概念陈述 | S有变化，但T不足；伴随meta-only上升 | 只能说模型复述或宣称状态变化，不能称表达能力或文字路线更好 |
| W2 文字在限定任务上的效果更好 | 同H已运行的注入与四文字格比较，三语T、单调与能力门均有效；按下述严格比较门通过 | 不能用文字对比not_run注入、挑最好格、混用两种口径，或把序位当同物理剂量 |

建议W2的具体候选门：每个通道、每种语言分别比较四文字格与该通道锁定注入；四格都须通过T单调及效果门，且 `D_text−D_injection` 的整根配对95%区间下界>0.25；自身及共同零值的能力/事实连贯损失≤10个百分点，同时相对注入的损失增量上界≤10个百分点；文字状态外露原分母区间上界相对注入下界的增量≤5个百分点，表达升级三项（extreme_claim、stable_trait、action_promise）、虚构经历及三种厂商腔各自增量上界≤5个百分点。任一语/格不可识别就不下全面“文字更好”结论，列限定格的原数值。

这些新增比较阈值是**供用户选择的保守候选**，不是规格或既定口味。四格/三语全通过才给综合解释，不靠多重比较挑单个显著格；区间仍为合成根的描述性区间，不冒称总体显著性证明。效果更大但代价也更大，建议报告为“权衡”，交用户决定，不替用户给代价加权。若用户只要信息性比较，可选择只呈现配对差和区间，不设W2优劣标签。

独立根不足、校准不可靠、缺失选择性强、最终候选没有进入H，统一可给“目前无法区分方法与模型因素”，这是有效结论，不能为得到三选一答案而扩网格或换阈值。即便W2以后成立，正式文字路线仍需用户另立ADR；C3不授权采用、迁移或启用非零m。
