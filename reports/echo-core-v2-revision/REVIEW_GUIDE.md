## 复现

Python 3.12，运行时只用标准库。作者验证工具：mypy 1.20.2、ruff 0.15.6，均仅为开发检查工具。

在本目录的 `reference/` 下运行（`<new-output-directory>` 必须不存在，产物只写该目录）：

```text
python -B -m unittest -v test_reference
python -m ruff check .
python -m mypy --strict --cache-dir <temporary-cache-directory> .
python -B run.py --out <new-output-directory>
```

最后一项是CPU合成实验。单元测试无需重负载。所有随机种子、模型配置和判断规则在协议中固定；不要为得到好看结果改阈值。报告保存第一次mypy失败记录及修复说明。

`results/`保存本次实验；`verification/`保存原始命令输出与失败；`sha256.json`供已提交文件核验。重跑时解析CSV/JSON后比较结果/轨迹/摘要，单列数值差异；Windows与Linux的换行字节可能不同，不把换行差异当成数值差异。provenance中的时间、操作系统、Python补丁版本不要求相同。生产工程测试没有因这个研究PR被重新声明通过。
