# Echo Core 2.0 的具体修订候选

**状态：PROPOSED。用于Claude审查与用户决定，未取代现行规格，不是生产实现指令。**

## 1. 建议的决定

保留2.0的工程基线，重新定义评价与学习。不保留“四天性→a(e)→R/θ→人格”作为必须成立的本体。候选的最小功能链为：

**记录真实经历及依据 → 学习情境与结果的关系 → 依据当前有效目标比较行为 → 行动产生新的实际结果。**

“2.0修订”表示从现有项目出发处理差异，不保证保留其符号或算子。没有必要为了延续版本而保留四个通道、分开的G/C、独立θ或人格资格门槛。本PR只新增候选材料，当前生产行为不变。

## 3. 状态与算子的最小边界

本候选只要求三类功能信息：经历账本H；可用H及版本资源重建的预测/解释B；现有运行状态Q与审计L。B可以包含结果分布、模型不确定性和适用情境，**不是新增一份与R、θ并行的人格状态**。未来实现应替换或合并旧容器，而非简单叠加。

“最小”是本轮可检验任务中的工作假设，不是对所有伙伴能力的不可约性证明。H/Q/L是工程与追溯职责，不能把容器数量当成人格理论复杂度。对每项新增要求的删除后果如下：

| 要求 | 删除后的可检验损失 | 本轮依据 |
| --- | --- | --- |
| 来源与修订身份 | 重发和纠错变成新经历，已有贡献无法撤回 | R01/R02 |
| 主体、主张类型与目标适用范围 | 用户偏好或自述被当作她的实际结果 | R03；自然语言抽取未测 |
| 情境相关预测 | 相反情境被平均，无法选对行动 | E3 |
| 结果可重评价 | 目标改变后仍沿用旧标量排序 | R05/E3 |
| 缺失/不确定性信息 | 选择性报告产生错误的确定排序 | E1/E4；当前保守界也有严重拒绝排序代价 |
| 改变当前规律的能力 | 旧经验长期压住已改变的环境 | E2；不证明某一变点算法必需 |
| 可重建与版本记录 | 同一经历无法复核、纠错及继续学习 | R06/R09只覆盖参照；完整迁移未测 |

四通道、独立θ、R⁺门槛未用于这些任务仍能完成上述功能，因此不应作为未经证明的强制结构。此结果不证明删去这些结构就已实现完整情感或内在价值。

有效目标C由H中的授权、采纳、完成和撤销记录投影得到；它不是一个暗藏的恒定奖励向量。候选解释和模型资源由显式版本Ω管理。预算、权限、低风险探索策略等已有运行规则继续有版本与审计。

一个计算接口足以表达学习部分：

```text
Learn(committed_history_view, law_version) -> derived_belief_and_receipt
Compare(belief, effective_criterion, current_context, allowed_actions)
    -> predictions, uncertainty, applicability, proposed_choice
```

这是职责接口，不是将所有问题藏进两个算子：下节明确输入资格、更新、缺失和纠错规则。物理存储格式、IDL及单写能力仍需另开契约卡；本PR不把研究DTO定义复制到进程边界。

若短期状态x将影响未来行为，它也必须在核心权威状态内、可重放，不能因为本候选暂未定义情绪坐标就把它转移到模型KV缓存或界面。参考学习模型不需要额外快状态，并不证明整个伙伴系统不需要短期响应。

## 4. 经历与目标的资格

### 4.1 经历记录的语义

每项学习主张需要：原始事件/来源根；事件次序；主体；适用情境；实际行动与选择条件；结果字段及观察状态；目标引用；解释/测量版本；修订、依赖和撤销关系。

这些是能追问的字段，不要求每项都有独立标量。未知必须显式表示。一次重发、一次新解释或一次模型复述不能创造新的独立经历。多条结果来自同一次事件时保留共同来源依赖，不能通过换root_id宣称独立。

同一人的两个不同真实事件不应无条件压成一个样本；同一事件的多账号转述也不能算多个独立样本。归组困难时保留来源假设或相关性，不用一个小权重掩盖未知真实性。参考代码把root标签当作给定，**没有实现开放世界归组**。

### 4.2 有效目标与评价来源

目标最初可以来自明确授权并被采纳的任务/共同约定；目标包含适用范围、可观察结果判据、来源和撤销条件。事实告知、他人的偏好、自我陈述、行动请求必须分型。用户说“我喜欢爵士”是关于用户的证据，不直接修改Nemu的审美。

建议不能仅因说话者被信任就变成她的喜好。授权改变权限，任务采纳形成当前承诺，观察改变对事实的理解；这三条路径不同。用户的管理权限继续保留，不作为先验好感。

在一个已有目标c下，评价写作u_c(o)。实验采用“任务成功”或“成功−指定成本权重”。这些目标是实验显式给定的条件，不宣称由事实自动发现。多目标没有获准的可比规则时保留偏序/不可比，不擅自合成加权分数。

目标修订需有授权/采纳/纠错事件和理由，不能为了取得更高自评分而悄悄改写评价器。选择目标的机制同样须有依据；目前尚未得到能从无价值前提中自动产生内在审美的方案。因此本候选是**有依据的条件性成长机制，不是完整人格理论**。

### 4.3 未经观察的结果与自述

收到赞同只直接支持“对方作出了这次表达”；不自动证明任务成功、对方真实感受、她的价值或行动因果效果。消息送达不等于被读到；未回复不等于拒绝。模型说“我很开心”及它自己对该句的打分不形成两份独立证据。

程序或身体的真实测量可作为能力/结果证据；它来自内部进程不构成自动排除理由。反之，人类回复来自外部也不自动满足因果独立。自致结果应记录进H，但“发生过”和“某行为造成了好结果”是不同主张。

### 4.4 因果主张的条件

预测可使用P(o|c,a)；只有在已记录的识别条件成立时才能称为P(o|do(a),c)。至少明确：可比情境、行为覆盖、已测混杂、观测选择与稳定性。无法排除的混杂必须缩小或撤销因果主张。不得以自主探索之名越过权限。

本轮参考只验证随机合成环境下的预测/选择。真实因果识别不是一个布尔字段自动能保证的，仍需设计与证据；不能把本轮区间称为普遍因果保证。

## 5. 明确可执行的数值参照

### 5.1 稳定、二元结果的最小估计

对某一已声明的情境/行动/目标单元，去重纠错后已观察n次，其中s次成功；Beta(1,1)只作为标签对称的公开研究先验：

```text
p = (s + 1)/(n + 2)
观察新的结果y后：p' − p = (y − p)/(n + 3)
```

因此第一次有效经历已能改变p；固定单元、规则和观测资格时，成功使p增大，失败使p减小，单次变化≤1/(n+3)。这才是适用范围明确的累积性质。来源纠错、情境拆分、目标改变、世界变点时不能强求旧分数单调。

若有测得成本，可另保存足够结果信息或重放原始记录后计算u。**不要求独立结果向量；要求保留未来重评价所需信息。**对完整经历做重评价不重复增加样本数。

### 5.2 缺失：预测与有根据的断言分开

总试验N中有s次观察成功，m次结果未知。未知观测机制下，真实成功率的识别范围至少是[s/N,(s+m)/N]，再加采样不确定性。仅在给定行动/情境内缺失与结果独立等声明成立时，才允许按已观察子样本估计总体结果。

本研究用保守的并集Hoeffding界：K个预先固定查询单元、0<δ<1，

```text
ε(N)=sqrt(log(π² K N²/(3δ))/(2N))
I=[max(0,s/N−ε), min(1,(s+m)/N+ε)]
```

对每单元每N的两侧失败概率≤6δ/(π² K N²)，对K单元和N≥1求和≤δ。证明依赖有界独立试验或适用的固定条件均值，不适用于任意非平稳过程/数据依赖的无限概念搜索。K动态扩展需要重新分配风险，不能沿用原证书。本轮把K固定，不实现该扩展。

区间是研究诊断和断言依据，**不是成长激活门槛**。p及低风险行动建议从第一条证据即可变化；相近行动可以依权限采用可审计的探索策略。不能重建“等够样本才允许有个性”的旧制度。未知机制下的p只是已观察样本预测，不得隐称已校准的总体偏好。未排序比例必须和错误率一起报告。

### 5.3 变化模型

为候选模型m维护权重w_m；收到一个新、合格结果y时，先用更新前预测p_m计算：

```text
w'_m ∝ w_m · p_m^y · (1−p_m)^(1−y)
随后每个模型用y更新；下一步预测为Σw'_m p'_m。
```

参考模型族包含稳定Beta模型与每新事件可发生变点的Beta重置模型，h∈{0,.002,.01,.05}，初权重均匀。每个变点模型精确保留运行段长度的后验；原经历留在H，当前规则可以让较早经历主要解释过去。h网格/先验仍是版本化选择，不是“零设计”。

这里的混合允许世界变化的证据调节适应速度，不能由墙钟、重复解释、相同消息重发来推进。缺失、迟到结果和多单元变化需要按观测模型处理；本轮只在完整、独立二元序列验证此模型，**不能把变化模型的后验套进上一节的稳定过程频率保证**。

精确变点模型计算/存储随历史增长；本PR保留它作为可检查参照，不宣称已解决长期有界预算。裁剪/近似必须量测误差及纠错等价性后才能进入正式核心。

**执行后的选择：不将该混合模型定为2.0必选算法。**E2中它改善永久累积在变化环境下的误差，却输给稳定环境的累计模型、渐变的64事件窗口，以及突变/周期的固定h模型。保留“能够依据经历适应变化”的要求，具体算法继续作为可替换参照。完整数字见[报告](REPORT.md)，不因候选由本研究提出就维持它。

### 5.4 解释与假设别名

一个来源可以同时支持多个不同事实；不存在普遍“证据总份额必须为1”。若模型是互斥的解释，其后验权重可归一化；这是模型比较，不是把同一事实在所有人格词之间分薄。

语义等价的模型必须共享一份总先验质量，或使用一个规范代表；加入同义标签不能增加证据或总先验。新概念需要控制模型选择偏差，不能先挑最能解释旧经历的标签，再把同一数据当成独立确认。本轮不实现自动新概念发现；R07只证明复制自述不能成为新证据。

## 6. 纠错、暂停、迁移与连续性

1. H只追加。原事件内容为假时，修订的是相关真值/资格，不删除真实发生的说话、行动和后果。当前有效证据视图按根及修订确定；同一修订冲突拒绝；旧修订迟到不覆盖新修订；修订不刷新原经历次序。
2. 同源合并或拆分需显式来源修订，并重算所有依赖结果。原始消息投递幂等仍由Γ处理；学习证据归组是另一个语义问题，不能混淆。
3. 暂停时记H但冻结派生学习快照；恢复后对**同一个H**与未暂停重放结果一致。不承诺暂停期间行为改变后仍获得相同人生。
4. 兼容迁移保持有关未来预测、选择、纠错和继续学习的性质，不只检查当前数字。版本变化若改变了语义，需要新评估与回退；不能以坐标相同冒充身份连续。
5. 结构重放使用记录的解释版本和随机选择凭据；规律更正另记版本及差异。参考代码每次从canonical H计算，证明的是参照重放一致性，未实现高效增量缓存或数据库事务。

参考DTO只支持结果值或资格的修订，固定主体/情境/行动等身份字段。若这些字段本身解释错误，完整实现必须追加显式关联的主张替换并保留共同来源、删除旧贡献；不能靠换一个root_id给同一事件加权。本轮未实现这类语义重解释，不能宣称通用纠错已经完成。
