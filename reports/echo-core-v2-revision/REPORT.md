# Echo Core 2.0 评价与学习修订研究 — 报告

## 结论

**保留2.0的工程底座，重做评价与学习的语义；不原样推进2.0，也不把本轮参考算法宣布为定稿核心。**候选条文、可运行参照与实验已完成。完整人格、真实载体和生产升级仍未验证。本PR仅供Claude独立审查，由用户决定是否合并及是否采纳。

## 最小机制以及尚未解决的问题

最低限度的可检验链路是：**保留有来源的经历 → 学习情境与实际结果的关系 → 相对于有效目标比较行动 → 接收实际后果并允许纠错。**不额外设置“人格已成熟”资格：第一条合格经历就能更新预测，低风险选择也可随之改变。变化速度应按有效经历衡量，不能把模拟事件数换算成现实相处天数。

例如，她在真实互动中逐渐发现“工作时打断”和“闲暇时聊天”的结果不同，就可以改变什么时候开口；用户一句“我喜欢爵士”只能先更新关于用户的认识。前一种情境差异已在合成任务验证，后者的主体分型只验证了结构化字段。真实语言中是否正确理解“工作时”、结果是否归因正确，仍需验证。

事实本身不能唯一指定什么值得追求。本轮任务成功、成本权重均显式给定，未将其冒充自然长出的审美。任务/承诺带来的条件性偏好与终极价值形成是不同问题。行为推断中的奖励与规划器分解也需要额外假设，不能仅靠“偏好是最简单解释”消除不确定性。[Mindermann与Armstrong，2018](https://proceedings.neurips.cc/paper_files/paper/2018/file/d89a66c7c80a29b1bdbab0f2a1a94af8-Paper.pdf)

**因此：这次得到的是应如何修订评价与学习的具体方案，并没有证明一个完整的“自然人格生成核心”已经成立。**关系、内在审美、开放概念、真实F/J和迁移仍是生产启用阻塞项，不能用现有模拟结果替代。

## 实验结果

运行前固定[协议](PROTOCOL.md)和5个Python源文件，全部为合成数据，未接触用户正式或排练存储。E1/E3/E4各256个种子，E2每环境128个种子，共6656条逐种子/方法结果。基线不是完整2.0实现；本研究不能声称在端到端对照中击败整个2.0或v3。以下只覆盖明确列出的失效机制。

### E1：没有回复，不能直接算坏；只看回复，也可能被骗

每行动400次试验。MAR场景A成功率0.9、只有30%结果被观察，B成功率0.6且全观察；MNAR场景A成功率0.4但只显示成功，B仍为0.6且全观察。

| 方法 | MAR：正确 / 错误 / 未排序 | MNAR：正确 / 错误 / 未排序 |
| --- | --- | --- |
| 未知结果填零 | 0 / 256 / 0 | 256 / 0 / 0 |
| 只按已观察结果点估计 | 256 / 0 / 0 | 0 / 256 / 0 |
| 宣称MAR并用保守区间 | 4 / 0 / 252 | 0 / 235 / 21 |
| 观测机制未知时给部分识别区间 | 0 / 0 / 256 | 0 / 0 / 256 |

MNAR中的“宣称MAR”是有意违反前提的负对照：**公式再严谨也不能补救错误的观测假设。**未知机制方法没有错误排序，但也一次都没得出排序；已知MAR保守界也有98.44%的未排序率。不能把“零错误”包装成快速有效学习。故本区间仅作为可追问的断言诊断，不能成为成长或所有行动的前置门槛；更有效的可靠判断尚未在本轮解决。

### E2：要能改变，但不应为了自适应而强装一个复杂算法

每序列512次，先预测再更新。表中为事件64起相对于已知真实成功率的平均预测MSE（越低越好）。这不是从真实用户生活得到的成功率。

| 方法 | 稳定 | 突变 | 渐变 | 周期 |
| --- | ---: | ---: | ---: | ---: |
| 永久累计 | **0.000812** | 0.043735 | 0.034854 | 0.046699 |
| 最近16次窗口 | 0.011026 | 0.013149 | 0.011948 | 0.016845 |
| 最近64次窗口 | 0.003025 | 0.010541 | **0.005286** | 0.026229 |
| 固定h=0.01变点模型 | 0.004080 | **0.007500** | 0.007029 | **0.014247** |
| 候选自适应混合 | 0.001796 | 0.007836 | 0.007736 | 0.015572 |

混合模型在突变后平均24.08个事件达到连续五次预测低于0.5；固定h模型17.85次，窗口16为15.78次、窗口64为38.84次。永久累计在全部128条序列的192次后续观察内仍未达标，193仅为预先指定的删失编码，不能称真实平均延迟193次。稳定环境下混合模型0.509%的预测翻到错误一侧，永久累计为0%。

配对“混合−比较方法”的MSE差及95%蒙特卡洛区间：

| 比较 | 差值 | 95% MC区间 |
| --- | ---: | --- |
| 稳定：对永久累计 | +0.000984 | [0.000762, 0.001207] |
| 突变：对永久累计 | −0.035899 | [−0.036974, −0.034824] |
| 突变：对固定h | +0.000336 | [0.000106, 0.000566] |
| 渐变：对窗口64 | +0.002450 | [0.002154, 0.002746] |
| 周期：对固定h | +0.001324 | [0.001187, 0.001462] |

混合能按证据改变模型权重，却不是本实验中的通用最优方法。**否决把这次提出的混合算法定为必选实现。**保留“世界变化时能够改变”的要求；取消永久累积和固定人格层不可替代的假定。不同方法的优势受本轮世界、参数、时长与MSE指标限制，不能拿本轮胜者直接替换生产核心。

参考使用运行段长度后验的变点模型；这个既有统计方法的价值是可核对的变化推断，不是它能自行赋予经历价值。[Adams与MacKay，2007](https://arxiv.org/abs/0710.3742) 本轮完整运行段枚举保留为参照，计算量随历史增长，没有长期资源保证。

### E3：理解与目标改变必须能传到选择

两个给定情境需要相反行动，每单元200条经历：不分情境的选择正确率50%，冻结基线50%，分情境100%（256个种子）。目标从“成功−0.1成本”变成“成功−0.8成本”后，沿用旧目标排序正确0/256，保留结果后重评价正确256/256；没有新增经历。

这支持保留情境和可重评价结果信息，**不要求独立的结果向量容器**：原始结果重放或充分统计均可。情境、两个行动、目标权重与正确答案由实验设计给定；100%不是自然语言理解、目标自发形成或真实人格成长的证据。标签置换前后预测误差为0，只是同构迁移检查。

### E4：已经形成行为差异，不等于已经形成有根据的偏好

两个行动真实成功率都为0.7，240次闭环、前8次交替、之后10%探索。平均绝对选择偏向为0.7685（定义为两行动次数差的绝对值/240），预测成功率差为0.09919。独立审计每行动400次后，预测差降到0.02555。闭环与审计均未被保守区间判为有依据的优劣排序（各0/256）。

早期随机经验会制造明显习惯；这种路径差异可以是真实历史的一部分，但不能拿其偏向本身证明某行动更好，也不能把偏向作为额外成功证据。该实验没有证明无差异必须抹平，更没有评估人与她的真实关系。独立审计只用于揭露偏差，不是建议让用户强迫训练她。
