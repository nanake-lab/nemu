## 计数差异与独立核验

主代理最初新增的离线 v01 错误假定 SSE token 数必须等于原生 `predicted_n`，断言失败。它不是原测量入口判据；原计时、计数、输出和判据未修改。v01 脚本、失败日志和差异清单均保留在 `benchmark-run-03/analysis/attempt-01/`。

固定 [server-context.cpp:1976–2020](https://github.com/ggml-org/llama.cpp/blob/620d2225cc436ab0b001e3200e590e3b286ef9ab/tools/server/server-context.cpp#L1976-L2020) 对未闭合 UTF-8 分片不发 partial；[2200–2246](https://github.com/ggml-org/llama.cpp/blob/620d2225cc436ab0b001e3200e590e3b286ef9ab/tools/server/server-context.cpp#L2200-L2246) 每个已发 partial 只返回当前 token ID，streaming 最终数组为空。原始 `tokens_predicted` 跳号与计数差逐条吻合，例如“雰”“囲”跨分片。

每量化 **16 条响应少 32 个 SSE token ID**，合计 32 条、64 个 ID；原生最终计数保留，所有已发内容拼接与 response 相同。v02 分别核对事件、计数和跳号并列差异，分析成功；不补造缺失 ID/时间，这 32 条不能用于完整逐 token 到达序列分析。输出 token/TPS 使用原生字段，948 条首 partial 原生计数均为 1。

机械 reporter 独立重验两量化各 450 条正式 IRL，schema/source 布尔与行记录不一致为 0；948 请求/响应、事件重组、显存和两种分位数亦独立核验。其首版含 3 条 IRL 预热（453 条）未覆盖，另存 formal-only 450 条投影。合并最新 main 后，14 Python 文件 Ruff/strict mypy、6 项 unittest 均通过，无 GPU 重跑。

全部原始 3775 文件、138,579,801 bytes，以 SHA-256 去重成 3152 个 gzip 对象、14,077,348 bytes，逐文件哈希与无损回查通过。见 [文件映射](benchmark-run-03/raw-filemap.json)、[完整统计](benchmark-run-03/analysis/summary.json)、[运行与并发](benchmark-run-03/context/) 和 `benchmark-run-03/audit/`；缓存原文件未删改。前两次 server 失败及参数失误的前后提交见 [BENCHMARK-RERUN.md](BENCHMARK-RERUN.md)。
