## 自审结论与收紧项

| 检查 | 结论 / 处理 |
| --- | --- |
| 无输入时接续 | 全局 RUNNING 与局部完成/等待分离；不退回等待用户或重新 thinning。有限请求和公平资源调度保证可让出，不以空转冒充能力 |
| m 与脑力路径 | 自主选择实际在本地 m 载体发生；一请求一 m，下一请求按真实时间刷新；IRL/A/M 保留 m=0 |
| 合法零值与失效 | m=0 可以是合法计算结果；验证的是载体通路和回执，不能把零值一律当成故障或强迫每轮非零 |
| 过期计算与抢占 | 旧实际产物可以按来源记录，但不能覆盖新输入后的 Q、发布旧行动或假装完整结束；自身记账仅在依赖验证后合法接续 |
| 撤回与摘要 | 撤回/权限变化传播到 Q 引用、摘要来源闭包及在途输入；不能只过滤新检索而由当前材料泄漏回来 |
| 主动机会 | 内部提交/提议次数不得重抽机会、提高行动强度或绕过冷却；对外执行仍重验凭证 |
| 成长与短时状态 | ~~纯内部记录只允许既有 Φ 时间作用，不伪造 IRL/A/M 或新 F 内容驱动~~（已被取代，见文末「用户决定后的修订」）。自身推断仍不造证据 |
| 数据与恢复 | Core 独占原子发布，去重完成回执；重放不调用模型/重复发送；缺失资源、结构失败和暂停如实展示 |
| 能力与时延 | 循环存在不等于有创造力；效果需消融与场景测试。无零延迟/低功耗保证，不放宽原门槛 |
