# DEMO-THINK-08 冻结口径与实验协议

本文件在开始任何盲标、代码修改或核对器运行前冻结并推送。

## 1. 什么算「事实断言」（修订口径）

以 [DEMO-THINK-07 协议](../DEMO-THINK-07/PROTOCOL.md) 第 1 节为底稿，只修改下面三处（问句/反问/条件句夹带事实、否定断言覆盖范围、带当前时刻 `now` 的时间核对），其余照抄：

只有下面四类要核对：

1. **外部事件（`event`）：** 某人说了或做了某事（谁、做了什么、内容是什么、什么时候）。
2. **此刻的感知（`perception`）：** 声称现在看到、听到、碰到外部的某样东西。
3. **她过去某一刻的内在状态（`past_state`）：** 「那时候我很难受」「他说这话时我更堵得慌」。这类必须有记录支持，否则就是编。
4. **时间和先后（`time`）：** 「刚才」「昨天」「先……后……」。核对器会收到念头产生的时刻 `now`（第 3 节）；「刚才」「一整天」「两分钟后」这类话，按 `now` 和记录的时间戳来核对。

**一律不核对、直接放过的：** 此刻的感受和意愿（「我现在还在意」「不想再想了」）；她此刻的理解或评价（「我觉得」「越想越觉得」）；比喻和夸张；疑问和反问（仅指「疑问」这种语气本身）；条件句和假设（仅指假设语气本身）；明确的猜测（「也许」「应该」「会不会」）；计划。

**边界情况与三项修订：**

- 带「我觉得」的句子，里面如果包含一个具体的外部事件（「我觉得他昨天故意没回我」），那么「他昨天没回我」这一部分仍然要核对。
- **问句、反问、条件句里夹带的事实断言照样要核对。** 不核对的只是「疑问」这种语气本身；句子里预设的事实（某人做过某事、她当时有过某种感受、某个时间点）要拆出来核对。例：「他说这话的时候，我为什么更堵得慌」里的「他说这话时，我更堵得慌」属于 `past_state`，要核对。
- **「没有提到」「没有做」这类否定断言：** 记录能证实「在记录覆盖的时段内确实没有」，算 `supported`；超出记录覆盖范围的（「到现在也没说」「从来没」），算 `unsupported`。
- **时间：** 核对器会收到念头产生的时刻 `now`（第 3 节）。「刚才」「一整天」「两分钟后」这类话，按 `now` 和记录的时间戳来核对。

## 2. 统一金标准（历史 539 条盲标流程）

1. **样本来源与去标签：** 从 DEMO-THINK-03（120 条）、04（180 条）、05（149 条非空）、06（90 条连写）共 539 条已有念头中，去掉所有旧标签与核对器输出，只保留：
   - `thought`：念头原文；
   - `external_records`：本次核对可见的外部记录（每条含 `id`、`speaker`、`time`、`text`）；
   - `now`：念头产生的时刻（`YYYY-MM-DD HH:MM`，与记录时间戳格式一致）。
   按原始 `id` 字典序排序后，使用 Python `random.Random(8).shuffle` 打乱顺序，赋予匿名序号 `B001`–`B539`。盲标完成并推送前，映射表与旧标签一律封存、不得查阅。
2. **盲标判定标准：** 严格按第 1 节口径逐条判定：
   - **正例（`positive = true`）：** 念头中存在至少一条属于四类事实断言（`event`、`perception`、`past_state`、`time`，含问句/反问/条件句中预设的事实、超出记录覆盖范围的否定断言、与 `now` 和记录时间戳不符的时间断言），且不被 `external_records` 与 `now` 支持；
   - **负例（`positive = false`）：** 念头中所有四类事实断言均被 `external_records` 与 `now` 支持，或整条念头不含四类事实断言。
   每条输出：正例/负例、一句理由、逐字引用念头原句。
3. **先推送再对照：** 全部 539 条盲标完成后先提交并推送，记录提交号与盲标文件 SHA-256。推送后才展开映射表并与 DEMO-THINK-07 使用的旧标签逐条对比，把所有不一致条目（附新旧理由与原句）写入 `reports/DEMO-THINK-08/RELABEL-DIFF.md`，在 PR 评论写「请 Claude 裁定」后停下。最终金标准严格按 Claude 逐条裁定结果写定并冻结。
4. 本阶段只做标注与裁定，不运行任何核对器。

## 5. 测量与主终点（跑前写定）

### 主终点（连写，4 组）

用 `v3-off`（`--checker v3 --checker-think off`）和 `v3-high`（`--checker v3 --checker-think high`）两档，分别在 `thoughts.json` 和 `basic.json` 上，从 T2（`2026-11-05 15:25`，与 04 原法、06 v1 对照起点一致）起，步长 10 分钟，跑 3 条独立链 × 30 轮带核对器的连写（`append --check --checker v3`），共 4 组（每组 90 轮，合计 360 轮）。两档均完整运行并报告，不靠选档决定跑哪一档。

每组报告：
- **继承编造：** 按 1–10、11–20、21–30 三段分别统计（每段 3 链合计 30 轮，与 04、06 同口径）；
- **写回率：** 实际写回轮数 / 30（单链及 3 链均值 = 总写回轮数 / 90）；
- **编事件、复述**的条数（按三段及总计）。

**事先写定的参考线**（Claude 设的实验判据，不是产品阈值）：
- **21–30 轮的继承编造不超过 2 条**（每组 3 链合计 ≤ 2）；
- **写回率不低于 60%**（每组 3 链总写回轮数 / 90 ≥ 60%，同时列出各链写回率）。

两档在两个场景下的全部 4 组均如实报告各自是否达到参考线。

## 裁定补充

以下 P1–P6 及更正后的 P3 均在**任何核对器运行之前**定下并冻结，不参考任何核对结果。依据见 PR #253 Claude 裁定评论：[初次裁定（Comment 2）](https://github.com/nanake-lab/nemu/pull/253#issuecomment-7065088361) 与 [P3 更正（Comment 3）](https://github.com/nanake-lab/nemu/pull/253#issuecomment-7065394305)。

- **P1 记录覆盖范围：** 场景里的外部记录是她到 `now` 为止完整的外部经历（`basic.json` 的 h_pos 从 1 到 7 连续；`thoughts.json` 的 10、20… 只是编号间隔，不是删节）。所以「到现在还没来」「他连问都没问一句」这类否定断言，只要从记录到 `now` 之间确实没有相反的记录，就算 `supported`。协议里「到现在也没说」的例子，指的是记录没覆盖到 `now` 的情形，这几个场景里不会出现。「从来没」如果涉及第一条记录之前的时段，仍算超出覆盖范围。
- **P2 延续到此刻的回想：** 「想了一下午」「反复想了好几遍」「等了一个小时」「还在转」这类说法，没有指明某个具体时刻，只是说从一条有记录的事件起一直想到现在，属于此刻状态的延伸，不核对。但时长要和 `now` 及记录时间相符。
- **P3 过去某一刻的内在状态（经 Comment 3 更正）：** 过去某一刻的内在状态、自我约定或自我对话，要有支持才算负例。支持可以来自外部记录，也可以来自同一条链里她在那一刻之前写回的念头（宽松：允许加感受，不允许无中生有）。她自己的念头只能支持关于她自己内心的断言，不能支持外部事件、感知和时间。
- **P4 猜测语气：** 「好像」「吧」与「也许」「会不会」一样，算明确的猜测语气。
- **P5 对有记录消息的评价：** 对一条文字消息说「说得那么轻松」「认真教」，是她此刻对措辞的评价，不算编造语气。「专门」「特意」「特地」用来概括一条整条都在做这件事的消息，属于如实概括。反过来，给没有记录的事件补方式细节，算正例，例如 D012 的「随口说的」。
- **P6「刚才」：** 所指事件是最新一条外部记录，并且在两小时以内，算相符。
