# DESIGN-CAUSE-PROJ-01 — 交来由，不交状态

**设计草案已完成：建议把模式 B 的语气样例，换成本地核心按现有槽挑出的真实经历原文。** 模型拿到的是发生了什么，不是心情数值、标签或应该模仿的说话方式。最小候选按当前残量排序，不另设固定件数，用完整原文和既有上下文预算决定能装几件。原文无法无损传递旧事淡化、很多小事的合力和长期心境，这些取舍已写成 U1–U4，全部由用户决定。去不掉的助手腔单列为开放问题，本卡没有用人设或话术补救。

## 1. 当前状态与三问

设计交付完成，等待 U1–U4 与交叉审查；PR 保持 draft / `needs-user`。不代表新模式已启用或效果验证通过。最终推送并写「请审查」后停止。

按 AGENTS 黄金规则 17，提出取材机制前已在[任务请求](../../tasks/requests/DESIGN-CAUSE-PROJ-01.md)首先回答：

- **能不能不加？** 不加新的心情/重要性状态；复用 H、槽、现行淡化与上下文预算。仍必须新增“选哪几段原文”的确定性投影，不能称为完全零机制。
- **一个人会怎样？** 会记得原话，但今天未必仍有当时那么强的感受；把来由告诉另一个人也不能保证对方反应一致。这是类比，不是人类心理实证。
- **有什么改不掉？** 规则可换版本，H 不改；已经发给 API 的原文、已经说出的回应和由此发生的后续经历无法靠本地回退撤回。

逐项新增的三问、先发散后收敛、被排除路线与理由在 [ADR 0042 §§1–2](../../docs/adr/0042-cause-projection.md)。
