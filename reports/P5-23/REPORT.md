# P5-23 规律引擎 G：倾向的证据计数 — 报告

## 结果

部分完成（见 BLOCKED.md）。计数的递推、支持与强度、份额、关于人的倾向、保险丝的选择规则和 G 的入口都已实现并测试，LAW-1 至 LAW-10 的移植 0 违例，状态数与 `results.txt` 逐项一致。

有两块被契约缺口挡住（V2-48）：典型幅度 r_k 的递推，以及改旧分配时的重放。IDL 缺少 r_k 的两个累加量，也缺少分配的序号、μ 与 p_c。在补齐之前，G 遇到证据组时返回显式故障 `ContractGap`，不做近似。已于 2026-10-21 报告用户，等待决定。

## 交付物

- `core/crates/core-kernel/src/law/`（新）：
  - `mod.rs`：模块说明与导出；`core-kernel/src/lib.rs` 只追加一行 `pub mod law;`；
  - `engine.rs`：G 的入口 `g(RState, &ThetaView, &Step, &LawContext) -> LawResult<Output>`，按 D2 的阶段执行：建立候选并做别名归并（D10），建立第一次涉及的人的关系倾向（D6），处理证据组（显式报缺），执行容量保险丝（D7），生成 L 条目（D11）；
  - `input.rs`：进程内的输入。`ThetaView` 只有 b 与 σ̂；另有 `LawContext`、`RState`、`Step`、`Candidate`、`GroupItem`；
  - `recurrence.rs`：单倾向的递推 D4（A、B、N、F、上一组符号、ĥ、ρ、π），以及初值、存储一致性检查、s_k 与 R⁺；
  - `support.rs`：支持 S、强度、权重 W，教导组；
  - `shares.rs`：两边各自按 (1 + π)/2 分配的份额；
  - `relation.rs`：亲近与信任的 ID、方向、谓词，u* 的依恋与信任初值（R₀），亲近度与信任的读出；
  - `fuse.rs`：容量的移出选择，单组上限；
  - `num.rs`：精确的组内均值（精确求和、一次正确舍入）、固定次序的内积、有限性检查与 −0 归一；
  - `params.rs`：规律参数的校验，κ、c₀、ĥ；
  - `error.rs`：显式故障；
  - `tests/`：性质测试与验收测试（见下）。`pyrandom.rs` 实现 CPython 的 MT19937，使移植的测试与 `check_law.py` 抽到完全相同的样本；`mean_vectors.rs` 是用 Python `Fraction` 生成的 283 组均值参照。
- `docs/traceability/P5-23.md`（新）：规范定义 D1–D11、规格对照表、验收编号。
- `docs/traceability/diff-register.md`：追加 V2-38 至 V2-49。
- `tasks/requests/P5-23-law-state-idl.md`（新）：契约接口请求。
- `reports/P5-23/`：本报告、`BLOCKED.md`、`gen_mean_vectors.py`（均值参照的生成脚本）、`verification/`（日志）。
