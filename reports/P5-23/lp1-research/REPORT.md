# P5-23 LP1 参考形式研究报告

## 结果

**一轮研究完成，两个候选均不满足全部要求；P5-23 仍阻塞。** 新公式没有批准。详见 [ADR 0019](../../../docs/adr/0019-law-lp1-candidates.md)。没有改 Rust、IDL、黄金向量、原 `check_law.py` 或冻结原文。

用户选择 ADR 0018 的 A，仅授权设计和验证。O 为原式，M 为均值保持的置信量衰减，B 为单调预算衰减。计划先于候选运行写入，运行 manifest 含计划/源码 SHA256。没有搜索或调参；运行后只新增了明确标记的数值反例/察觉指标诊断。

## 数学与性质

完整条件见 ADR 0019 与数学依据。M 在实数下满足三条 LP1（固定 S、序号、组存在性，ρ 不随 W 变），也给出固定其他条件的 LP7 证明。B 满足单步/末尾新组边际 LP1，但固定 h 持续正证据时 E 无界，且回溯撤回有实数反例。两者都没有成为“满足全部条件”的选定公式。

| 检查 | O | M | B |
| --- | --- | --- | --- |
| 原 LAW-1…10 | 10/10 通过 | LAW-1（1,320）、LAW-3（2,215）、LAW-10 失败 | LAW-6（4,055）失败 |
| LP1-1，20,000 | 7,445 违例 | 0 违例、0 故障 | 0 违例、0 故障 |
| LP1-2，20,000 | 7,350 违例 | 0 违例、0 故障 | 0 违例、0 故障 |
| LP1-3，20,000 | 39 违例 | 0 违例、0 故障 | 52 违例 |
| LP7 固定 p/h/c/v 增大 b，20,000 | 0 违例 | 0 违例 | 0 违例 |
| I23，500×40 个 H 前缀 | 0 位差 | 0 位差 | 0 位差 |
| I25 分边检查 | 41,627 次，0 违例 | 41,625 次，0 违例 | 41,662 次，0 违例 |

三模型使用相同随机输入。I25 次数略不同来自候选 π 影响移出对象/剩余支持边；每一条 H 仍相同。I23 比较 a、b、p、ρ、N、F、上一符号的完整位模式，含 checkpoint 往返及从 H 重做分配；覆盖回溯、后来成员内容改变、容量移出重分摊。**这是投影输入层的研究模型，不是完整 Rust G**；没有重写 θ 投影器、分组器、持久化或正式成长。LAW-7 原来只检查 a/b，所以另查 p，不能拿原 LAW-7 单独支持 M 的 I23。

精度边界：两候选对不可表示的次正规弱证据方向、非有限输入和溢出均显式 `PrecisionExhausted`，不修改旧状态、不静默忽略；这里是研究原型的统一数值异常，生产中仍应区分 NonFinite / Overflow / PrecisionExhausted。容量保护有独立 `CapacityExhausted` 正例测试；随机世界未遇到容量故障。没有提高任何权重下限。上述边界抽样不是覆盖全部 binary64 输入的证明。

O 的 39 个撤回违例全部经 Fraction 证明只发生于浮点计算；最大的错误方向差 2.22e-16，仍列失败。B 的最大违例被缩短为四组，精确有理数仍违例；缩短阈值仅用于选择容易说明的反例，不影响原 52 个违例计数。`failures.jsonl.gz` 保留全部 14,886 个新检查违例记录（O=14,834，B=52），没有删掉微小违例。

## 四种世界

30 个配对种子，每世界 2,000 步。固定 W 分布 {0.01,0.1,1,3}，固定 c=4、h₀=0.1、n_h=10、P=0；本节衡量普通倾向，依恋另由原 LAW-10 检查。全部 240,000 个世界输入及各模型预测/后值保存在压缩 JSONL。预测概率为 (1+p)/2。

表内为均值 ± 样本标准差；均方误差越小越好。Brier 对实际二元结果，latent MSE 对生成器概率，均在看到当前组之前计算。

| 世界 | O Brier | M Brier | B Brier | O / M / B latent MSE 均值 |
| --- | --- | --- | --- | --- |
| 稳定 | 0.202980 ± 0.005208 | 0.186257 ± 0.006656 | 0.181855 ± 0.006571 | 0.043006 / 0.025166 / 0.021126 |
| 突变 | 0.201246 ± 0.004451 | 0.183783 ± 0.005543 | 0.179426 ± 0.005645 | 0.042021 / 0.025212 / 0.020476 |
| 渐变 | 0.224298 ± 0.004326 | 0.219552 ± 0.006183 | 0.210916 ± 0.005545 | 0.034860 / 0.030460 / 0.021659 |
| 周期 | 0.204195 ± 0.005465 | 0.191296 ± 0.006942 | 0.185292 ± 0.006533 | 0.044713 / 0.031399 / 0.025527 |

| 指标 | O | M | B |
| --- | --- | --- | --- |
| 稳定期误翻转 / 1,000 步 | 52.28 ± 4.90 | 17.70 ± 3.72 | 20.93 ± 5.13 |
| 稳定期错误方向占比 | 14.61% ± 1.60% | 5.64% ± 1.26% | 5.91% ± 1.41% |
| 突变后首次越零延迟（组） | 2.77 ± 1.91 | 5.80 ± 3.88 | 4.37 ± 2.65 |
| 突变后连续 5 步确认延迟（组） | 9.53 ± 4.27 | 11.03 ± 4.16 | 10.63 ± 3.82 |

无删失。M/B 相对 O 的首次延迟配对差分别为 +3.03 ± 3.25、+1.60 ± 2.62 组；确认延迟 +1.50 ± 2.08、+1.10 ± 1.86 组。全部 30 种子、配对差及周期每段延迟在 JSON，不只给均值。没有根据结果新增可接受劣化阈值，也没有用平均误差改善抵消适应延迟代价。

事后检查：O/M/B 在突变前已错向的种子数为 5/1/1。三个模型均方向正确的 25 个共同种子中，首次延迟为 3.12/6.36/4.64，确认延迟为 10.16/11.84/11.36。这个诊断排除了“原式只是更常提前出错”这一部分混淆，仍观察到候选延迟增加；它不证明所有合成或真实世界都如此。
