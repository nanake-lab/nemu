## CPU 口径与判据

每次记录 `process.cpuUsage()` 的 user/system 微秒差、单调墙钟毫秒差、逻辑 CPU 数、采样次数。主口径是**单核百分比**：

`raw_one_core_percent = 100 * (user_us + system_us) / (wall_ms * 1000)`。

同时列出整机总容量口径 `raw_total_capacity_percent = raw_one_core_percent / logical_cpu_count`，避免混淆。空载对照用同一公式。每对另列 `sense_raw - control_raw`（可以为负，不裁到 0）。

**原始感知占用的 3 次单核百分比均须 ≤ 1% 才通过**；不以扣除对照后的差值代替 1% 判据。逐次列原始值、对照值、差值及描述性中位数/最大值。缺数据、失败或中断不能算通过。
