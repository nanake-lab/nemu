## 2. 作者与 API 代理标注，用户只裁决分歧

固定 **gpt-6.1-terra/high** 为本段代理标注员，deepseek-flash/high为对照系统，不在看见分歧后换裁判。Terra在R-JUDGE-01中是限定范围已校准的判断员；**既有认可没有覆盖本任务的a(e)、z、μ**。本次采用它是用户选择的低人工成本代理方案，不是新校准证明。所有非人工结果必须写：**“代理判断，不是人工金标准”**。

流程分两次冻结，解决标签要由API产生而又须先于4B评估确定的顺序：

1. **调用前冻结A包：** 作者先完成36视图的事实图、原子z字段、a方向、μ端点/未定、三语对应和理由；冻结prompt/schema、调用清单、比较规则及本版预算。作者标签此后不得按代理意见暗改。
2. **代理盲标：** Terra每视图一次，共最多36次。只见合成原文、必要合成事实上下文、概念定义与研究说明；不见作者答案、4B/DeepSeek输出、目标格/方向/根号。一次输出用于数据标注的原子z、四方向、三个概念匹配及证据跨度。此联合表仅为研究数据审核，不是把生产IRL/A/M并成一次调用，也不生成可提交的Proposal。
3. **机械比对：** 按冻结的字段/枚举/指代/时间/来源与方向比较；允许的同义表须事前列明。纯文风差异不算语义分歧，无法机械确定等价记未定，不由作者临时放行。D08的好奇负向标签强制U_spec，不因API给了符号而发起裁决或计分。
4. **只交分歧：** 作者与Terra有效结论不同（包括一方确定、一方语义uncertain）的字段交用户，按独立根合并成一份卡，带受影响三语、两方原标签/依据和可见材料。用户可选作者/API/另一结论/仍未定；未裁决保持U。双方同为未定则保留U，不要求用户补齐。纯API技术invalid/missing不转为额外人工标注任务，记代理标签缺失。
5. **冻结B包：** 一致字段取Terra标签，来源`proxy_agreed`；分歧裁决字段记`user_adjudicated`；其余`unresolved`，保留两套原标签及裁决。生成固定z_ref/a_ref/μ_ref和计分掩码，冻结后才开始三系统D评估。用户裁决不能看4B输出挑答案。

**用户负担上限：** 不要求全量人工标注；裁决队列为0–12份根卡，最坏覆盖36个语言视图，卡中合并所有冲突字段，同根不反复提交。无a(e)既往分歧率可用于可靠预测，所以以**最多12份/36视图**规划，不承诺只有2–3条。API技术失败、双方未定和U_spec不强行转交用户；用户不裁决的字段继续U，允许完成部分D报告，不靠追加人工/模型填满。

一致项存在作者与代理共同出错的风险。Terra参与标签建立，再测Terra只能报告**同模型复判一致性/技术稳定性**，不能称独立准确率或与4B公平金标排名。DeepSeek与4B对代理标签的吻合也不是人工准确率。按proxy_agreed/user_adjudicated/unresolved分层，另给作者标签与API标签的原始分歧；不把只含难例的人工裁决子集外推为无偏准确率。DeepSeek和4B之间的分歧只作结果，不自动增加用户裁决队列。
