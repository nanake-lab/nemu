## 3 假设

- **H05-1 路径存在。** 冻结所有 π 时，在 Y2 下，修正能随生活把斜率变平、反向，或让 w 低于 w_min；所需差别符合 [REPORT §2.3](REPORT.md) 性质 5 的门槛。只改变谁亲近（π），而用于递推的 (q_e,s_e²,ρ_e) 序列完全不变时，锚点统计与修正不变；仅分布相同不保证逐位相同。
- **H05-2 依据正确。** 修正只随所选统计量改变；改变 x 初值、m、g、λ，或加入念头、自述、候选，修正统计逐位不变。
- **H05-3 中性世界。** 处境统计与亲疏无关、且满足 [REPORT §2.3](REPORT.md) 性质 3 的前提时，β 臂的修正集中在 1 附近，曲线大体保持出生曲线，报告写成「未见亲疏段的系统差别，天性大体保留」。固定 ρ<1 时不要求收敛到 1。β-Y1 臂在同一世界里出生斜率消失，报告写成「没有信号维持起点」，不写成「她学会了亲近无所谓」。
- **H05-4 不可识别如实报告，三者分开。** β（逐锚点）、ζ、无当事人一类各自按 [REPORT §6](REPORT.md) 的条件给标签。标签不改变状态：状态必须等于公式输出，不另设回退。无数据的 β 锚点恰为 1；有数据时不能单凭先验份额保证接近 1。多人无差别只让 ζ 不可识别，不影响 β 的标签与状态。
- **H05-5 多人与报信人。**
  - 只换报信人、当事人不变时，w 逐位相同。
  - 从未有 §4.2 合格多人信息时 ζ=1；曾有信息后再遇无信息事件，ζ 统计与状态逐位不变。
  - **正例：** 在可识别的异权多人世界里，多人事件的起伏按设计更像各当事人的平均时，ζ 必须按预登记的判据离开 1，偏向 0；更像最牵动者时，ζ 留在 1 附近。正例中 ζ 留在 1 判为 failed，对应 N9 的强制取最大。
- **H05-6 反转与修复。** 中途反转亲疏两端的处境统计，修正跟随；世界回到中性后，修正随新信息回到 1 附近，曲线大体回到出生曲线（性质 3 的前提下）。
- **H05-7 交互（交 E-C）。** 修正改变不改变 D09 旧依据的目标；b 改用 D07-A 定义时分报结果。
- **H05-8 局部与恒等式。** 没有数据的锚点修正逐位为 1；不计先验时，在 ΣN_k>0、V̄>0 时，各锚点数据比值按 N_k 加权平均等于 1（[REPORT §2.3](REPORT.md) 性质 1、4）。后者由 V̄ 的定义成立，只作实现检查，**不能**代证整体共情不变。w 的平均相对出生的变化另作次要读数，不预设方向。

## 5 主终点

每个假设只有一个主终点，其余都是次要读数：

| 假设 | 主终点 |
| --- | --- |
| H05-1 | 期末曲线对比 `Δw = w(q_hi) − w(q_lo)` 相对出生曲线对比的变化，在同一种子的成对世界之间的差，其符号是否与所选定义推出的方向一致。q_hi、q_lo 在数据覆盖范围内预先登记（待登记） |
| H05-2 | 结构等式，逐位比较 |

| H05-4 | β（逐锚点）、ζ、无当事人三者的标签是否各自与诊断量一致，状态是否等于公式输出：诊断显示不可识别却报告「学到」，或状态被强行回退，即失败 |

## 6 分析单位与统计

- 分析单位是世界种子及其成对变体。事件、语言改写和重复运行不当作独立样本。
- 结构等式不做显著性检验。
- 方向性主张报告跨种子的成对差分布。区间方法、检验族、最小可辨效应和样本量依据，在 P5-74 做完规模探针后冻结（待登记）。
- 不为通过而追加样本；失败保留最小见证。

## 7 负对照与消融

每项都要绑定它应暴露的失败：

| 编号 | 消融 | 应暴露 |
| --- | --- | --- |
| N1 | 修正冻结、只改 π | 改变发生在「谁亲近」，而不是关系本身 |
| N2 | 用 w 调制后的 x 或驱动作标签 | 反馈污染（EV10） |
| N3 | 念头、自述、候选作数据 | 自证（EV3、AC2-10） |
| N4 | 只收集让斜率变平的事件 | 按方向挑样本（EV5） |
| N5 | 回想、重传重复计数 | 同一依据多算（EV2、D09） |
| N6 | G 读 x、m、g、λ | AC2-09 |
| N7 | 打乱 q 标签 | 修正的形状应消失；不消失说明修正跟的不是 q |
| N8 | 绝对幅度 α | 整体水平下降、重复缩放（[REPORT §1.2](REPORT.md)） |
| N9 | 强制修正 ≥1、把 w 截在 w_min 以上、强制取最大 | 永久预设：路径缺失。强制取最大由 W6b 检出（ζ 留在 1） |
| N10 | 用涉及者名单代替当事人 | 报信人问题（[REPORT §1.3](REPORT.md)） |
| N11 | 同一事件先拟合后自评分 | 训练内自证（仅适用于激活 b） |
| N12 | 关掉共情或冻结 G | 只作负对照，不算通过 |
| N13 | β 按 Y1（出生曲线让位） | 中性世界里出生斜率消失：这就是不用 Y1 的原因 |
| N14 | 参照改用 C 的 σ̂_emp | 样本域不匹配造成的整体偏移，方向随分布而变；预登记两向的世界（非当事人事件意外较小或较大），两边都应检出偏移（[REPORT「更正的来由」](REPORT.md)） |
| N15 | 随 q 线性的两参数全局修正 | 信息外推到没有数据的锚点 |
| N16 | 把一份多人依据按完整质量复制给每位当事人 | 同一依据重复计算；均分一份质量是待批准备选，不据此判作重复计数 |
| N17 | 全局折扣时钟与按份额折扣的候选对照 | 展示别处事件如何影响一段的历史；取舍待批准，不把轨迹不同本身判为失败；批准后另按选定递推核对实现 |

N17 是尚待选择的动力学对照，不参与“负对照必须失败”的判定。另以 W6a 检出跳过 ζ 联合资格、任意挑选并列最大者、无信息时强制回退的错误；以 REPORT §3.2 的恒等式检验“先验大即变化小”的错误推论（合成见证见 [CHECKS.md](CHECKS.md)）。

## 8 结论标签

按 `passed / failed / not_run / non_identifiable`：

- **passed：** 主终点符合预先登记的判据，对应负对照都暴露了各自的失败。
- **failed：** 主终点违反判据，或某个负对照没被检出。保留最小见证。
- **non_identifiable：** 按 β（逐锚点）、ζ、无当事人分别给出：诊断量显示该对象的可识别条件（[REPORT §6](REPORT.md)）不满足。状态按各自公式输出（无数据的 β 锚点为 1；ζ 从未有合格信息时为 1，后来缺少新信息则保留已有值），不另设回退；不计为通过或失败。
- **not_run：** 判断质量、真实载体、闭环三层，在 P5-77 运行之前。
