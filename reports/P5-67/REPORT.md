# P5-67 设计卡：D05-A 亲疏曲线定稿 — 报告

## 白话总览

（本节在全部内容写完后定稿；下面是目前已经成立的结论。）

**最重要的发现：** 按现有规则，给她打「这件事好不好」分数的评估器 A 看不到她和谁亲近（EV6、LP8）。所以单看一件事她当时的原始反应，永远学不出「亲近本身该让她多动容」。这是规则决定的，不是数据不够。曲线能学到的，只是生活里不同亲疏的人通常遇到什么样的事。学这个，就要先选曲线代表什么意思；这是性情上的选择，由用户决定。

**原提案的问题：** DESIGN-LAW-01 提的拟合目标是「这件事的原始反应有多大」。这个目标把「事情多大」和「她让多少感受通过」混在一起。长期下来，不论生活怎样，她对所有人的共情都会整体下降，降多少看世界里的事通常多大，与关系无关。这个目标的方向还与她现有的「世界波动大，增益就变小」相反。

**现有读法里的两个缺口，与选哪条路线无关：** 多人取最大时把报信人也算进去了，你转告陌生人出事，她按「是你说的」来动容；没有具体当事人的事按 1 算，点出名字的陌生人只按一半算。

## 1 先讲清的事实

### 1.1 评估器看不到亲近度：同一事件的反应学不出「亲近本身该多牵动她」

**前提。** A 在 m=0 下由解释 z 得出 a(e)。按 EV6、LP8 及 DESIGN-LAW-01 §5.2，关系强度 π 不传给 IRL/A/M。记 s 为 z 中除关系强度以外的处境描述（发生了什么、对谁、多严重、观察覆盖）。于是 a_emp 只依赖 s：在 s 与事件前前缀给定时，它与当事人的亲近坐标 q=(1+π)/2 无关。

**命题 P1。** 任取只由本事件原始评估和事件前世界统计算出的目标 `y_e=h(a_emp(e), b_emp(e⁻), σ̂_emp(e⁻))`，都有 `E[y | q, s, 前缀] = E[y | s, 前缀]`。所以 y 对 q 的回归只能反映「不同亲疏的人遇到的处境在分布上有什么不同」，即 Cov(q, E[y|s])；处境分布与 q 无关时，总体斜率为 0。

**证明。** h 的三个输入里，a_emp 在给定 s 与前缀时与 q 条件独立；b_emp(e⁻)、σ̂_emp(e⁻) 是前缀的函数。故 y 在给定 (s, 前缀) 时与 q 条件独立，条件期望不含 q。对 q 求最小二乘的总体斜率等于 `Cov(q, y)/Var(q) = Cov(q, E[y|s,前缀])/Var(q)`，s 与 q 独立时为 0。∎

**含义。**

- 「亲近这件事本身应该让她多动容」不是 a 的分布里的量。数据再多也学不出来；这是构造决定的不可识别，不是样本不足。
- 用这类目标拟合的曲线，长期形状只由两件事决定：她生活里各种亲疏的人遇到的处境有什么不同（包括接触与报道的选择偏差），以及目标本身的含义。如果两者无关，曲线变平。
- 卡的约束要求出生先验随可靠经历让位，所以在亲疏者处境差不多的生活里，起点的斜率会消失。这不是她「学会了亲近无所谓」，而是没有任何信号在维持它。

**前提的边界。** 这个结论成立的程度，取决于 z 是否真的不含关系强度。如果 z 写进「这是她的照料者」之类的角色事实，模型可能凭常识给出不同的 a，这时 A 本身已带亲疏差别，w 再乘一次就是重复。这一点属于判断质量层，交 P5-77 测，不在机制层假定已经成立。

### 1.2 原提案目标的量纲：事情多大，与让多少感受通过，被混在一起

w∈[0,1] 是乘在 (a−b) 上的通过比例：1 表示完全通过。原提案的目标 y=|a−b|/2 是一件事的反应幅度。拿后者去拟合前者有三个后果：

1. **整体水平被拉向世界的典型事件大小。** 出生先验让位后，在处境与亲疏无关的世界里，最小二乘得到 v→0、u→E[y]。曲线最高处现在接近 1（照料者）；要保住这个值，亲近者的事必须几乎每次都是 [-1,1] 两端之间可能的最大意外（|a−b|=2）。任何正常生活都不是这样，所以她对所有人、包括照料者的共情驱动都会整体下降。降多少由世界上的事通常多大决定，与关系无关。
2. **重复缩放。** 驱动变成「这类人的事通常多大 × 这件事多大」，大事的人被放大两次，小事的人被压低两次。DESIGN-LAW-01 P05-A 已提到这个风险，这里给出它的长期形式。
3. **与已有的 g 方向相反。** C 学到的增益 `g = g₀σ₀/σ̂` 在世界波动变大时变小（v2.0 §8「世界波动大，增益变小，她不那么一惊一乍」）。原目标在事情变大时让 w 变大。两个学习器对同一统计量反向响应，相互抵消多少取决于参数，她的总体反应难以预料。

只学形状、不学整体高度可以修掉第 1 点，但需要另定「多高算 1」的约定；第 2、3 点和命题 P1 仍在。见 §2。

### 1.3 名单里的报信人

亲近倾向的谓词是「此人说话、被说到或被提到」（[relation.rs](../../core/crates/core-kernel/src/law/relation.rs)），评估记录的 `persons` 是「事件涉及的人」（[records.proto](../../core/contracts/records.proto)），现行 w 对所有涉及者取最大。所以：

- 照料者告诉她「某个陌生人出了车祸」：w 取照料者的亲近度，接近 1；
- 陌生人告诉她同一件事：w=1/2。

同一个陌生人的同一件事，她动容多少取决于谁来报信。任何多人组合式（包括 ζ）在这份名单上学习，都会把报信人当成当事人。要分开，必须在 m=0 下标出「这是谁的处境」，这是 IRL 记录的新输入（§4、§5）。

### 1.4 没有具体当事人时的断点

现行读法：没有人涉及时 w=1；第一次涉及某个具体的人时 π=0、w=1/2（V2-115 (1)、V2-13）。所以「有个孩子在受苦」让她完全动容，「一个叫某某的孩子在受苦」只让她动容一半。点出名字的陌生人并不比匿名的人更疏远，这个断点与起点本身的方向不一致，任何路线都要给它一个读法（§4.3）。

### 1.5 对选择意味着什么

- 「拟合目标」不是技术细节，而是定义曲线代表什么。由命题 P1，任何只看同一事件原始反应的目标，学到的都是「生活里各类人遇到的事有什么统计差别」，具体是哪种差别、往哪个方向调，要由用户选。
- 学不出来有两种：一种是构造上的（命题 P1：亲近本身的作用），先说清，不必等实验；另一种是数据上的（曲线要识别的统计差别在她的生活里不出现或太少），由 E05 检验并按 `non_identifiable` 报告。
- 报信人与无当事人断点是现有读法的缺口，不论选哪条路线都需要处理。

### 2.2 收敛：α′、β、δ 三条深入比较

三条都只用原始 a(e)、b、σ̂、π，不读 x、m、g、λ，不用自述。下面的式子只到概念层，精确代数、数值运算和保留率来源交 ADR 修订。

#### α′：「通常是大事」的那类人更牵动她

形式：按亲疏 q 拟合 E[|a_emp−b_emp(e⁻)| | q]，除以总体典型幅度后截到 [0,1]，作为 w(q) 的形状。

**她会怎样变化：** 如果她听到的陌生人的事多是新闻里的大事，而照料者的事多是日常小事，她会变得对陌生人的新闻比对照料者更动容。这个权重作用在照料者的所有事上，所以照料者真出大事时，她也不如出生时动容。谁决定她听到什么，谁就在决定她在意谁。

**代价：** 重复缩放仍在：通常有大事的那类人的大事被放大两次。与 g 反向的问题仍在。由命题 P1，曲线形状完全由接触与报道的选择决定。

#### β：「那类人的处境通常起伏多大」，起伏越大越淡定（推荐，由用户决定）

形式：按亲疏 q 拟合当事人处境意外的典型尺度 `σ̂_emp(q)²≈E[(a_emp−b_emp(e⁻))² | q]`，令 `w(q)=clip(σ̂_emp/σ̂_emp(q), 0, 1)`，σ̂_emp 是 C 已有的共情通道平常波动。于是共情驱动的增益部分 `g_emp·w = g₀σ₀/σ̂_emp(q)`：把 θ「世界波动大，增益变小」细化到「那类人的处境波动大，增益变小」。

**她会怎样变化：**

- 你平时平稳、偶尔有事：她对你的事保持敏感，最多回到完全通过。
- 你常有大起大落：她对你的起伏会比出生时淡定；你真有大事时，按「相对你平常有多大」来动容。
- 传到她这里的陌生人的事多是大事：她对陌生人的事更淡定。普通生活里出生的斜率大致保持，但理由变了：不是因为不亲，而是因为这类事在她这里通常就大。
- 亲疏者的处境起伏差不多：曲线变平并停在 1，她对陌生人也会和对亲近的人一样动容。整体有多动容仍由 g 管。
- 长期处境艰难的那类人：起伏大，她会渐渐不那么动容。这是同情疲劳，与 v2.0 §8 在世界层面已经写下的「波动大，增益小」是同一代价，只是落到了具体的一类人身上。

**推荐理由：**

1. 不新造价值：沿用 v2.0 §8 对 g 已经写下的含义，只把「世界」细化为「那类人」。
2. 与 g 同向，没有两个学习器互相抵消；也不重复缩放，驱动变成「相对那类人平常尺度的意外」。
3. 不需要另定「多高算 1」：与世界平常尺度相同的那类人取 1，由同一个归一化给出。
4. 平方意外对正负对称，自然满足 EV5；只读 LP8 允许的 b、σ̂、π。
5. 仍是 D05-A 框内的一条小曲线，斜率可以变平或反向，下限不再是终身的。

**代价：**

- 由命题 P1，亲近本身不是永久理由。只有亲疏者的处境在她经历里确实不同，曲线才保持倾斜。
- 中性生活的终点是 1，不是出生时的 1/2：在亲疏无差别的生活里，她对陌生人的动容会升到与亲近者一样。
- 陌生人那端主要由报道选择决定。
- 截到 1 意味着比世界更平稳的那类人不会更高。
- 两参数的曲线表达不了「只有照料者特别」这类非线性。要表达它，需要换成个人版或更大的曲线族，那是新的复杂度，须另批。
- 估计二阶矩比估计均值要更多数据（§6）。

#### δ：不学斜率（退路）

形式：斜率保持出生形状；去掉 w_min 下限，使已有的 π 路径能把关系变差的人降到下限以下；按 §4 修报信人与无当事人；对某类处境的特别在意继续经已有 R 的情境倾向「加一份」。斜率作为 ADR 0032 的未闭合缺口写进差异登记。

**她会怎样变化：** 和现在差不多。对某人的处境有多动容，仍跟着她和这个人的关系走。和某人相处一直不愉快，这个人的事会更难触动她。某类处境被反复证实对她重要时，她会多一份在意，但不改变比例。

**代价：** 「越亲近越能触动」的比例本身仍是她改不了的预设，ADR 0032 意义上的缺陷保留，要用户知情接受。

### 2.3 出生曲线怎样让位

| 方式 | 含义 | 去留 |
| --- | --- | --- |
| **Y1 共同折扣**（同 D07-A）：出生曲线是有限先验，与经历一起按保留率缩小，只在合格新事件到来时推进 | 先验份额随可靠经历趋零；没有新事件时不变（LP5） | 推荐；符合卡的约束和 D07-A 的选择 |
| Y2 出生曲线作永久底子，经历只乘一个修正 | 中性生活里永远保持出生斜率 | 排除：出生份额永久存在，违反卡的约束，与用户在 D07 去掉永久出生锚定的选择相反 |
| Y3 依恋式不衰减先验（像 A_att） | 经历有新近折扣时，先验份额永久保留 | 排除：理由同 Y2 |

Y1 的后果已写在 β 的代价里：在亲疏无差别的生活里，出生斜率会消失。保留率用 G 自己 ĥ 的写法还是 D07-A 的写法，交 ADR 定；无论哪种都不读 g、λ。

### 2.4 本项推荐（由用户决定）

- **推荐 β** 作为 E05 的主候选，α′ 作为对照臂，δ 作为预先约定的退路：E05 若显示 β 学不出来，或主要由用户不接受的选择偏差决定，就采用 δ，并把斜率登记为未闭合缺口。
- 原提案 α（绝对幅度）不推荐，只在 E05 里作负对照，展示 §1.2 的整体下降。
- β 的个人版和 γ「亲身经历过」是框外选项，不推荐现在做；β 在分段层面可识别后，可以另开设计卡。

## 3 激活与支持：什么时候开始起作用

### 3.1 发散与筛选

| 方式 | 去留及原因 |
| --- | --- |
| **a 不设门槛**：曲线是规律给定形式的结构统计，出生曲线作有限先验，按 §2.3 的 Y1 连续让位；F 每个事件读当前曲线 | 推荐 |
| b 原提案：作为候选概念，以「先预测、后更新」的损失差 S_e 作支持，经 G 的 π>1/2 进入 R⁺（I06） | 对照：要新的支持合同、π 递推与份额；而曲线形式由规律给定，没有模型提出的候选可言，「候选」框架在这里不必要 |
| c 可识别门槛：设计矩阵满秩或先验份额低于某值才替换出生曲线 | 排除：阈值是新的预设；有限先验在数据少时本来就保留出生曲线 |
| d 次数门槛：累计若干事件后启用 | 排除：LP5 不设次数门槛 |
| e 时间门槛：几天、几周后启用 | 排除：LP5、AC2-05 |
| f 用户批准后启用 | 排除：用户批准的是规律版本，不是她每次的变化；否则不是经历在改变她 |
| g 只在某些情境启用学到的曲线 | 排除于 A：这是 D05-B 的修正族，用户没有选为优先 |

**先例：** 结构关系倾向本来就不经 R⁺ 门槛起作用。第一次涉及某人时 π=0，w=1/2 立即生效（V2-115 (1)）。I06 约束的是候选倾向；规律给定形式的结构统计不是候选。这是一处新读法，须登记（§5.4）。DESIGN-LAW-01 说「I06 不能跳过」，前提是把 ψ 当作候选概念的 R 统计；本推荐换了表示，所以要用户批准这处读法。

### 3.2 本项推荐（由用户决定）：a 不设门槛

**她会怎样变化：** 没有「学会了」的那一刻。每个合格事件只把曲线挪动一点，挪多少由先验还占多大份额决定。不会突然换性情；没有新的合格事件时，曲线一动不动。

**代价：** 早期少量、偶然的事件也会让曲线有小幅移动，幅度受先验份额约束。没有「这已经成为她的性格」的单独记录点，曲线的每次变化照常写进 L。是否「已经学到」靠 §6 的诊断量（先验份额、满秩条件）报告，不靠门槛宣布。

## 4 多人情境怎样组合

### 4.1 先分清当事人（前提）

| 方式 | 去留及原因 |
| --- | --- |
| 现状：所有涉及者（说话、被说到、被提到） | 排除：§1.3 的报信人问题 |
| **m=0 标出「这是谁的处境」**：当事人集合；她自己不算共情当事人 | 推荐：IRL 记录要新增输入（契约变更），判断质量交 P5-77 |
| 固定规则：说话者一律不算当事人 | 排除：说话者讲自己的事时就是当事人 |
| 只取被提及者 | 排除：理由同上 |

标不出当事人时记「未知」，按 §4.3 的「无具体当事人」处理，不猜，也不作学习数据（规则统一，不违反 EV5）。

**她会怎样变化：** 你转告她一个陌生人出了事，她按那位陌生人来动容，不再因为是你说的就完全动容；你说自己的事时，你就是当事人。**代价：** 当事人判断错，会直接影响她对谁动容；这一层的准确率要单独测量，不能由机制实验代替。

### 4.2 几个当事人如何合成

| 方式 | 去留及原因 |
| --- | --- |
| 取最大（现状） | 作出生起点 |
| 固定均值、最小、softmax | 排除：换一个固定偏好，没有改变路径；softmax 的温度也是预设 |
| **ζ 介于最大与均值**（原提案），在当事人集合上，`W=B+ζ(M−B)`，M、B 是当事人权重的最大与均值，出生 ζ=1 | 入围，推荐保留：一维、可查；改在当事人集合上；用与单人曲线同一个目标学习 |
| 在统计层合并（按 β，多人事件的尺度由各当事人分段尺度合并，不设 ζ） | 对照：少一个参数，但合并规则本身固定；ADR 0032 要求多人规则可改变，这里没有路径，只是各人的权重在变 |
| 把 a 拆给每个人，各发一份 D | 排除：虚构逐人情绪，也是复制情绪 |
| 先算有效亲疏 `q_eff=均值+ζ(最大−均值)` 再查曲线 | 不优先：曲线反向后，「最亲」不再是「最牵动」，出生起点的含义被悄悄改了 |
| 按角色（受害者、旁观者、施害者）区分 | 框外，暂不入围：要角色分类体系、新判断与新参数 |

**本项推荐（由用户决定）：** 在当事人集合上用 ζ，出生 ζ=1，即「最能牵动她的当事人为主」；用 §2 选定的目标从多人事件学习。

**她会怎样变化：** 几个人一起出事时，起点是按最让她牵挂的那位来动容。如果她经历的多人事件显示「不只看那一位」更贴合，会慢慢偏向平均。

**代价：** 当事人权重不同的多人事件在桌面伙伴的生活里很少；ζ 多半学不出来，会一直停在出生值，必须报告为 `non_identifiable`，不能说成「她学会了以最亲者为主」。只在最大与均值之间，表达不了角色差别；遇到这种反例要报告模型族不足，不加复杂度凑结果。

### 4.3 没有具体当事人

| 方式 | 她会怎样 | 去留 |
| --- | --- | --- |
| 保持 w=1（现状） | 断点保留，且不可改变 | 排除：没有路径 |
| 当作亲疏中性，取曲线在 π=0 处的值 | 去掉断点；但匿名的事从完全通过变为与陌生人相同 | 入围：最简单，不加统计；改变出生行为 |
| **单独一类，出生值沿用 1，用同一目标学习** | 出生行为不变，并有改变路径 | 推荐 |

**本项推荐（由用户决定）：** 单独一类。**她会怎样变化：** 「有个孩子在受苦」一开始仍让她完全动容。如果这类没名没姓的事在她这里通常起伏很大（多是新闻大事），按 β 她会对它们渐渐淡定。**代价：** 出生时的断点（匿名 1、点名陌生人 1/2）仍在，只能随经历改变；多一组统计。要不要出生时就去掉断点（选中性那一行），由用户决定。

## 5 G 的输入与 R 的表示

### 5.1 状态放在哪里

| 位置 | 去留及原因 |
| --- | --- |
| **R 中一条结构统计**：规律给定形式，不是候选；由 G 在合格事件上更新，F 读其作用视图 | 推荐 |
| R 中候选概念（原提案） | 对照：要 I06 门槛与新支持合同（§3） |
| θ，由 C 更新 | 排除：C 不读 R（v2.0 §8），而曲线的自变量来自 π |
| Ω 资源，由作者发版改变 | 排除：不是经历。出生曲线本身作为已批准资源放在 genesis |
| 挂在每个人的亲近倾向上（个人版） | 框外，见 §2.1 |
| H 的派生索引或缓存 | 排除：会影响未来行为的持久信息必须显式归属（I18） |

统计的内容只到概念层：出生先验质量，带折扣的按 q 的数据矩，ζ 的统计，无当事人一类的统计，保留率所需的统计，以及规律版本绑定。全部进入规范重算（I23），变化写进 L；新状态需要后继 IDL、CanonicalV1、迁移与回退（SYS17）。

### 5.2 G 新增的输入（逐处列明，须用户批准）

1. **m=0 的当事人标注：** IRL/A 记录的新字段，属于契约变更。
2. **事件前每位当事人的亲近 π：** G 在自己这边按前缀重建，不传给 IRL/A/M。这是对 LP8「竞争解释的强度 π」读法的扩展，须明列批准，不能借其名义带入。
3. **事件前的 b_emp(e⁻)、σ̂_emp(e⁻)：** LP8 允许。D07-A 生效后用它的定义（D05×D07 交互交 E-C）。
4. **原始 a_emp 与 EV2 归组：** 同一起因只计一次。D09 的回想与原事件共用依据，回想不是新数据；她的念头、日记、候选不是数据（EV3）。

G 不读：x、m、g、λ，以及任何被 w 调制过的量。

### 5.3 F 的输入与 D09 的交互

F 读曲线的作用视图、事件前当事人的 q 与当事人标注。按 D09-A1，每份依据的目标 v_c 绑定产生时的曲线版本；曲线变了，不更新旧依据的目标，换参数不是换依据（DESIGN-LAW-01 E-C）。白话：曲线变了以后，旧事重想不会因此更痛或更淡；新发生的事按新曲线。
