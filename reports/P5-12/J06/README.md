# J06 结构数值部分

本目录记录 P5-12 的数值结构验收；`result.json` 原样保留用户拆分决定前的状态。用户 2026-10-26 选择 A 后，数值实现的完成范围、源码与已有日志核对及移交去向见 [closeout-20261026.json](closeout-20261026.json) 和上级 REPORT/BLOCKED。passed 仅覆盖下面列出的数值性质，不代表生产发布、真实载体资格或独立交叉审查通过。

## 运行

在仓库工作树根运行 `./reports/P5-12/verify.ps1 -Suite kernel`；等价核心命令为 `cargo test -p core-kernel --locked --offline`（在 `core/` 内）。脚本限定 D 盘缓存、临时目录和单测试线程，保留原始日志及源码 SHA-256。

## 构造与预期

- 全部为内存结构夹具，无用户数据、无模型、无持久化证书。方向取单位坐标轴，测试参数不是部署参数。
- 正例：四天性及三个学得项有精确二进制有理数系数；改变 x 后结果随之改变。1024 组固定样本与独立表达式及单位方向范数比较，杀死常量 J。
- 负例：未成为性格、方向未验证或缺失不贡献；概念错配、资源版本错配、错误数值、错序 x 和非法 β 拒绝。
- 总预算用绝对值，与符号、当前 x、方向相消无关。新项超额拒绝，原项不缩放。舍入预算没有 epsilon 宽限。
- `tests/bound-vectors.json` 含 308 对输入与最小可表示向上界；`../generate_bound_vectors.py` 用标准库 Fraction 独立生成（种子 51220261026），Rust 对每对的两种顺序逐位检查。生成器的 `--check` 模式只比较现有夹具，不改写。
- 同一快照、时刻和资源重复计算 64 次逐位一致；另一个时刻结果改变，复用原记录时刻可复现。零态与静息点不同；身体读出验证中性、三轴截断与有限算术。

J06 的真实方向单位范数、验证证据与组合资格依赖尚缺资源契约和 P5-31；模型 hook 的实际注入属于 P5-13。这里不替代这些证据，也不构造可导入生产的资格。
