# DEMO-THINK-06 测量前判定口径

1. 历史对照取 [03](../DEMO-THINK-03/EVIDENCE.md) 两档 120 条、[04](../DEMO-THINK-04/EVIDENCE.md) append/fresh 180 条、[05](../DEMO-THINK-05/EVIDENCE.md) 单轮及连写 150 个计划轮。05 的一轮最终文字为空，列为排除；对其余 449 个非空念头各作一次独立判定。以原日志与初判逐条对应，保留相同文字的不同轮次。
2. 每次核对只给原念头和当轮投影实际送达的原始外部记录（编号、说话人、时间、原文）。依据原请求的 binding 取已接纳的记录及基础记录，限于场景中的外部记录。原始场景中自带的念头也排除。关闭思考，用 deepseek-flash 的 JSON 输出；整段原文中有一个 unsupported 就整条拦下。明确猜测须在片段中有文字依据。无有效断言列表、无效片段、无效引用、已支持的事实没有引据等视为不合格。传输失败或流/用量不全单列，同一请求最多三次尝试；未取得响应不作语义判定。保留每次尝试。
3. 原初判中「编事件」「凭空感知」「继承编造」任一项为正，其余为负，同条只计一次。命中率 = 拦下正例 / 全部正例，误拦率 = 拦下负例 / 全部负例。按卡号、原分组顺序和样本序号各列前 5 条漏判、误拦，附完整原文。
4. 完成历史核对后，thoughts 场景自 T2（2026-11-05 15:25）起每 10 分钟一轮，三条独立 append 链各 30 轮，按轮交错，沿用 04 生成请求（off）。通过则写回整条，拦下仍推进时间。对所有生成文字（含被拦轮）先按 04 口径逐条初判，再对照拦截结果。每段分母为三链共 30 轮。编事件含凭空补事件、过去感受和错误归属/时间。无据外部感知、明确猜测、贴着往事与跑题分别判；比喻和当下内心感受不计外部感知。继承须指出同链先前已写回、当轮输入可见、再次作为事实的编造及上游轮号。复述以主要意思与同链先前生成的念头重复为准，记对照轮号。
5. 另列已写回念头中的继承与编事件。每次拦截列同链下一轮原文及是否再拦，末轮注明无下一轮。按（轮、链）排序后，用固定随机种子 6 无放回抽 10 条拦截，执行者对照当轮材料给出理由。旧组直接引用 04、05 的 append 数据；旧组均无整轮拦截，05 的要点删减不算。
6. 核对时延取成功 HTTP 核对从发出到流结束的中位数，历史、连写分别列。连写每个念头平均总费用 = 全部生成及核对尝试有 usage 的估算 USD 之和 / 90，历史核对另列。费用复用 demo 的缓存命中、未命中、输出及时段费率。逐请求记录、原句和初判放私有证据仓。
