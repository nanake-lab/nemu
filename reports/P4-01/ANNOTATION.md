# 本机盲标操作

用 Chrome 或 Edge 打开：

`D:\NemuData\asr-evaluation\manual-labels\annotation.html`

这是自包含本地文件，无服务器、外部资源或上传。音频、频谱与标注 JSON 都留在本机 D 盘仓库外。页面只显示录音和你自己的点位，不含自动参考或系统检测点。共26条，顺序已固定。

1. 先听全段。起点取第一个能听到的语音音，包括清辅音；终点取最后一个能听到的语音音。重读不要裁掉，取最后一次读音的末音。排除无关点击、环境声和单独呼吸。
2. 选“起点”或“终点”，点击波形或频谱；可用放大、平移和0.75/0.5/0.25倍播放。点图后用方向键微调光标，用 S/E 落点；必要时填写备注。
3. 播放光标前后300 ms、可见范围或已标区间，反复确认。可撤销上次修改，不要按波形亮度阈值猜点。
4. 页面内切换录音会保留已标点位；关闭页面前必须点“导出JSON”。未标完导出的是草稿，重新打开后“导入已保存JSON”继续。页面不在后台自动保存。
5. 导出时明确选择 `D:\NemuData\asr-evaluation\manual-labels\`，保留每份草稿/最终文件。不会用浏览器默认下载目录。26条全部完成后导出状态为 final 的JSON，再通知 Codex 文件名。

仅在所有26条有效时才导出 final。若不能确定边界，先保存草稿并保留备注，不用为了凑完整而猜点。

重建页面（不改已有标注文件）：`pnpm asr:annotate`。

最终文件导入/抽检命令（不启动测量）：

```powershell
pnpm asr:annotations D:\NemuData\asr-evaluation\manual-labels\annotations-final-<时间>.json
```

导入核对计划、26个唯一任务、录音哈希、样本长度与起止范围，然后生成仓库外的60条混合参考候选与五条抽检比较。任何端点绝对偏差>80 ms都会报告；不自动挪动点位，不覆盖旧参考，不自动启动正式测量。

验证范围：26份嵌入WAV的SHA/格式/长度与频谱PNG结构已检查；六项合成媒体下的页面状态与导入导出逻辑测试通过。浏览器自动化工具拒绝 file:// 协议，只允许HTTP/HTTPS；没有绕过该限制或启动服务器，所以尚未做真实浏览器画面、声音播放和文件选择器操作验证。如打开后有显示或保存问题，保留现有文件并告知具体表现。
