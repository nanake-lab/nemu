# P4-01 独立固定上下文时标预登记 v3 — 2026-10-21

本版本在任何被测 VAD/打断延迟结果之前提交；v1/v2 raw、参考及诊断全部保留。60 个 ID、用户已确认实际文字、全部重读、250/300 ms 判据与实时重放规则不变。没有按延迟结果选样本、工具或边界。

## 原因与固定方法
v2 已数值有效，但 18 条首点为 0，部分与同源长上下文定位不一致。不能把数字合法等同于真实语音边界准确。为避免孤立短句的第一个单位偏置，独立对齐统一使用固定、非被测的上下文，不按单条试验换上下文。

固定锚点为已下载的 Google FLEURS public-zh-001（CC-BY-4.0），SHA-256 a72c0b59fdba80850552af7991de07f9f4940846d2d70f0890eeb153c40f164b；音频和来源已登记于 public-data.lock.json。选择规则固定为第一条中文公开样本；不与 60 条用户输入重复。锚点文本用该数据集人工转录，不调用任何识别器。工具、固定修订和软件环境仍为 qwen-asr 0.0.6 / Qwen3-ForcedAligner-0.6B、Apache-2.0、CPU float32/eager/2 线程/seed 0，无新依赖或模型下载。

每条目标规范 PCM = 1 秒数字静音 + 原始用户 WAV 规范 PCM + 1 秒数字静音。原始样本一字节不改，不裁切、不改增益；保留全部重读。目标在 alignment-input-v3/，冻结 alignment-inputs-v3.json。

对齐输入 = 锚点原 PCM + 800 ms 数字静音 + 目标规范 PCM；文本 = 锚点人工转录 + 不发音的句号与换行分句符 + 用户已确认文字；分句符只用于确定文本单位边界，不增加音素或参考词。全部 60 条使用相同锚点及间隔。用官方空白／CJK 字切分路径处理混语（English 参数只选分词路径，不设定音频语言），同句上下文分词允许内部单位边界改变，但字符串和两句边界必须严格一致；跨句单位或改字即失败。

只取目标单位的原始时间点，减去精确 (锚点帧数 + 12800) / 16000 秒，不使用估计偏移、不平移至达标方向。首点取第一个目标单位 start，末点取最后一个目标单位 end；保留所有词元和零时长警告。V2 的有限／非负／单调／不越界／完整区间正时长及全部 60 条覆盖规则不变；任何无效不发布参考，不夹紧。

被测系统只重放目标规范 PCM，不包含锚点；对齐器目标部分与被测输入逐样本完全相同，偏移按已知样本数换算。统一首尾静音同时进入参考目标与被测输入，时差相减抵消固定时间平移，不降低 250/300 ms 门槛；实时重放原有额外 1 秒收尾等待保留。

所有 context WAV、raw span、目标和锚点哈希、精确 prefixFrames、用户文字哈希均放仓库外。旧参考以 v2 名称保存后才生成新的 timing-references.json。meta 的 method=P4-01-context-alignment-v3，annotation=qwen3-context-alignment-v3。原始用户音频、字稿及 150 条识别评测输入均不修改；该规范输入只服务延迟测量。

80 ms 只是输出网格，不是经校准的误差保证；报告临界案例与全部数值，不声称物理边界已人工验证。VAD 中位 ≤300 ms，打断每条 ≤250 ms，任何缺失或提前事件失败；20 ms 实时 PCM 迟到 >20 ms 判无效。先退出对齐进程，确认无 Blender、Electron/Playwright、GPU 测量、Runner.Worker 后才测，空闲 Runner.Listener 可以在线。

纯文本预检补充：Nagisa 在个别上下文跨句合并单位，已在模型运行前拒绝并保留失败日志。因此固定使用官方空白切分＋CJK 字拆分路径；两句由空白分隔，所有 60 条必须在字符与句界上完全一致才运行。没有根据音频边界或延迟成绩切换分词规则。

锚点格式预检补充：公开 WAV 是 IEEE float，第一次 v3 在任何模型推理前因标准库 wave 不支持格式 3 而停止。保存该失败日志。锚点固定经 ffmpeg 转成 16 kHz 单声道 PCM16，不裁切或改增益；源与规范锚点 SHA-256、确切帧数同时冻结。前缀偏移始终按规范锚点实际帧数计算，不按文件容器字节或估计时长计算。
