# MADE IN HEAVEN：合成一生的设计

**结论：先做一个只喂合成事实、调用现有核心算子的实验运行器。** 用同一起点走过不同的生活，记录倾向、性情以及同一新事件引起的反应。本轮交付设计，运行器未实现，实验未运行。它是交付线的规律层检查，不等待模型研究，也不替代真实相处验收。

设计基线：`ce115abe6ced3ec8cc301bea2a290f47ace4807a`（2026-11-14 fetch 的 origin/main）。本轮范围为用户指定的 MADE IN HEAVEN，不宣称完成 [P5-30 全卡](../../tasks/P5-echo-core.md)。候选时窗、事件节奏、观察定义在 [预注册](PREREGISTRATION.md)；取舍见 [U 项](BLOCKED.md)。

## 1. 新增之前的三问

| 对象 | 能不能不加？ | 一个人会怎样？ | 加了以后有什么从此改不掉？ |
| --- | --- | --- | --- |
| 合成世界与运行器 | 可以手工调用算子，但多年、配对和重放很容易错位；只需事件表、顺序驱动和只读汇总，不做通用模拟引擎 | 同一个人反复生活会积累经历；实验需要多份合成起点才能比较不同人生 | 不写 LIFE/REHEARSAL；工具可删换，冻结的输入、失败和旧版本必须留存 |
| 主终点与观察窗口 | 可以只画曲线，但回答不了“多久”和“有没有停住”；增加的是观察定义，不是她的门槛 | 一时心情不同不等于性格不同；要在多次同类处境中仍有区别 | 观察定义一旦冻结不能看结果后改；换定义要新版本、旧结果保留 |
| 关系结构与后续学习观察 | 能直接检验现有 R/θ/估计器，无须加关系矩阵、元学习器或新状态 | 对同一个人的不同方面可能判断不同；看似相近的人也可能因历史不同而学得不同 | 不预先决定她必须分化；未分化也不能补机制使这一轮“成功” |
| 后继反思、淡化观察 | 本轮不加实现，保留问题和未运行状态 | 想通、遗忘、现在心情平复不是同一件事 | 未实现的机制不能由实验代码偷偷定义；采用后另绑定规律版本 |

## 2. 路线比较

| 路线 | 值得考虑的原因 | 本轮取舍 |
| --- | --- | --- |
| 静态读代码与数学分析 | 能发现权限错误、结构性不可区分，不需要运行 | 作为设计依据；不能回答具体生活中的首次时间 |
| 复用 Python 研究脚本直接模拟 | P5-33 与 v2 草案已有世界和对照 | 复用世界含义与独立 oracle，不把 Python 替身当当前 Rust 实现 |
| **顺序调用现有 Rust 纯算子** | 确定、可重放、无模型；允许生产接线前检查规律 | **推荐**，只在 EXPERIMENT 内组合已有定义，缺接口就标 not_run |
| 全部生产运行时加速运行 | 能覆盖事务、恢复与接线 | 后续由 P5-29/P5-18 等承接；当前适配不完整，不假装已就绪 |
| 模型扮演人物、生成想法与判断 | 可研究开放互动与表达 | 本轮排除；违反合成真值、无模型约束；R-LIFE-01 自有授权 |
| 跳过中间经历、乘大学习率或把一天折成一个大事件 | 运行会快 | 排除；改变证据量、折扣、θ 的时长估计或浮点路径 |

选择纯算子驱动，不引入新心理机制、通用插件层或可在线调参的控制台。推荐及其代价由用户审阅；本轮不实施。

### 版本按完整组合绑定

- **L0：当前已实现的旧规律组合对照。** 固定 G、旧 C/F、证据规则、完整参数与数值路径。已被 ADR 0032 取代但尚未接线的部分逐项标明，不能称为现行生产语义或诞生结果。
- **L35：现有 ADR 0035 纯函数的实验组合。** 只有适配明确覆盖目标来源、前态、角色、同源、消费资格与顺序后才可用；函数存在不等于组合就绪。不实施缺失的 D11/来源机制。未接通项保留 not_run。
- **Lbirth：诞生实际将用的完整组合。** 需 P5-69/70、P5-45 及相应接线/校准可用，绑定获批参数；这才是卡上主结论的对象。L0/L35 不代替它。
- **L37/L38：未来加入已批准且已实现的反思/淡化。** 不是现在可选的开关。曲线、尺度、数值路径和接线尚缺，见 [ADR 0038](../../docs/adr/0038-recall-affect-fading.md)。不实现 S3、符号倍率或新情绪通道。

同一世界可以重跑不同完整版本；每次产生新 run_id、新结果和证据索引，旧输入、旧失败与旧结果保留。若新版本改变解释/候选接口，另升输入映射版本，不能说“只有规律变了”。

## 4. 最小运行结构

只需要四个职责，未来均在卡内实验 crate，具体拆文件随实现而定：

1. **世界表**：人物身份、事件原因、时间、发生/可观察事实、外源/内部/工具结果分类，以及合成 z、a、μ、候选和分组真值。世界不得读取实验结论或人格标签。
2. **顺序驱动**：从明确的合成 genesis 开始，以稳定提交顺序调用已有阶段，完成一事件后才发布内存快照与实验 H/L。F/G/C 公式只调用拥有者实现。任何阶段故障记录原输入与失败，不能带着半份新状态前进。
3. **只读观察**：读取快照和账本；探针从克隆快照另起一次性实验分支，丢弃其后状态，不把探针结果送回主生活。纯投影读取不提交、无副作用。
4. **记录与重放**：完整事件/解释/资源/时间序列、每步必要摘要和检查点；按同一提交序列重放。I23 的 R/θ 重算与 I16 的 x/槽/消费状态重放分别记录，不能互相替代。

未来概念性顺序与 [v2.0 §2.4](../../docs/echo-core/echo-core-v2.0-first-principles.md) 一致：Γ → Φ → H 追加 → 读取真值 IRL/A/M → F_in → G → C → F_out → L → 提交 → 只读 J（若资源完整）。世界可以知道隐藏真相，但“尚未观察到的事”不进 z/证据；不能用全知 oracle 把未送达解释成拒绝。

真值记录沿已有 IDL 导入；本设计列出的实验清单字段不是新 wire 协议。分组身份、F 依据身份、作用消费身份分别记录，不能认为一次接触的所有消息都是独立经历，也不能把所有 F 报告压成一次。

## 5. 时间加速

加速只省略宿主等待，不改模拟时间单位、事件数、顺序、λ、折扣或求和次序。模拟秒显式转换到现有时间类型；日历日是 86400 模拟秒，不改系统时间。

| 时间 | 用途 | 规则 |
| --- | --- | --- |
| 模拟客观时间 | 发生/观察/处理时间；Φ 的实际经过时间 | 所有相关阶段使用冻结输入；停机后 Φ 仍按经过时间推进 |
| 模拟存在/运行时间 | θ 已结束段；将来 ADR 0038 的旧事年龄 | 按版本化的运行区间；不计关机/停机，未来研究睡眠也须按其合同排除，不以进程存活偷算 |
| 证据序号 | G/C 的计量与新近折扣 | 无新合格证据不增长；时间跳跃不能补出证据 |
| 宿主墙钟 | CPU 时间、吞吐和真实耗时 | 仅工程报告，不能叫“真实相处三年” |

同一时间的事件按脚本 ordinal 排序；观察点不得额外提交心跳、切分 Φ 或改变浮点路径。离线不生成思考，不制造缺席证据；恢复事实不进 C。真实缺席只在她运行且照料者离开时产生，按 V2-77 同段 C 一次、后续 F 报告单列，密疏报告不等于独立证据。

恢复/重放必须复用原时间事实。改变提交节奏是另一种世界干预，不能当作同一路径的等价加速。实现后的宿主耗时测量只证明运行器性能；真实等待/重启端到端体验仍 not_run，留原接线卡。

## 7. 实现与执行前的可审查产物

后继实现先产出机器可读事件表、探针表、全参数及来源清单、组合版本清单、逐项就绪矩阵。它们与本预注册的对应关系在**任何成长轨迹运行之前**复核、冻结提交与哈希；字段不能留空或偷偷补默认值。缺少规律参数时只完成世界和运行器，不跑结论。

实现适配、机械编码检查与正式轨迹运行分别授权和登记；本轮三者均未做。轻档设计检查不冒充 AC2 验收。未来全运行按重档，串行 CPU 工作；无模型、无 GPU、无模型 API 费用，耗时/内存/证据体积待工程实测，不预造性能数字。

原始证据归 `nanake-lab/nemu-evidence/P5-30/<prereg-version>/<law-binding>/<run-id>/`；主仓库仅报告、汇总与路径/SHA-256/私仓提交索引。运行器只接受自己新建的临时 EXPERIMENT 根目录，不提供导入用户谱系入口；不能扫描用户存储找样本。
