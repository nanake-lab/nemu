## 派卡后的决定

| 决定 | 本次实现与证据 |
| --- | --- |
| ADR 0043 §4.1、0047，默认先问 | 由版本化作用域给出可挽回性。不可挽回行动有一律不做、先问、直接做三档。审批请求在 W02 登记后才返回给调用者展示，保存当时的 action_id、审批 ID、身份、时间和原样载荷摘要；拒绝或超时发布取消和原因。“关游戏”用可挽回的合成作用域验证档位，未实际关闭应用。 |
| ADR 0047，先消费再发送 | W02 一次提交 DISPATCHING、签发 ID 消费记录和预算占用。发送前重新查验入口、身份与凭证；结果未知只接受核对或迟到结果。 |
| ADR 0045 D1、0046，云端认知禁止发起行动 | 读回 Q 里的本地来源，并校验载体回执及快照绑定。只有远端回执、或同时带远端和本地结果的计划，均在行动层拒绝。 |
| ADR 0045 D9，设置可调整 | 不可挽回默认先问；审批默认 60 秒，源自 CONTRACTS §6。凭证有效期、并发上限及预算额度默认待用户定。前两项未配置时拒绝签发，预算通过版本化 ExecutionBudget 输入。结果未知时禁止自动重发。测试使用的数值只限于临时夹具。 |
| 卡外 W02 目录与索引 | 由 Claude 授权、用户在派卡会话转达。`core-runtime/src/action/` 调用已有 W02，按 #238 的外层提交边界接线。`action-gate` 用 trait 表达持久化需求。待发列表枚举 Q；索引缺行和过时由诊断接口记录。W02 对整库损坏的恢复校验仍在存储层。 |
