# R-KAPPA-01 开发日志

## 四项不同的要求（开工记录，2026-10-28 Perth）

1. **状态数值有界**：x 各坐标处于 [-1,1]。正式内核的投影可直接测；这不排除长期饱和或反馈闭环。
2. **重复内容不能成为新的独立成长证据**：EV2/EV3/EV4/EV10 与 I24/I25 的证据归组及来源要求。κ 只改 F 的驱动，不替代 G/C 的证据规则。本轮固定 R/θ 的夹具不能证明完整成长正确；只分析已有实现边界。
3. **重复反馈不能令系统长期陷入无法被后续信息改变的状态**：需要区分固定输入序列的收缩与 x→产物→评价→F 的闭环。本轮测合成反馈和反证后的直接状态变化；没有真实调制行为通路的测量，不声称认知或行动改善，也不声称普遍无自锁。
4. **没有外源输入时按时回到静息附近**：ADR 0026 §6.3 的准确适用域是没有新外源事件且没有其他外部事件的纯内生区间，包含自己的行动结果；有 B_N、τ、λ_min、ε 与 T_x 条件。本轮保留时间衰减、行动期限及资源条件，检验候选是否与此保证冲突，不把它暗中降格成“停止一切活动后才回落”。

## 问题与基线

研究重复反馈是否需要统一 κ^n 折扣，能否局部保留真实新发现的直接作用。数值响应下降不等于认知受损；更大幅度不作为成功指标。

基线 main：`f24f1256259c998bc213a9dc93103fcfb9cfe89a`。已读取最新 AGENTS、ARCHITECTURE、CONTRACTS、Echo Core README、echo-core-work 技能、v2.0 与 ADR 0005、0008–0011；正在核对 ADR 0026、P5-10 源码与已有试验。主工作区有其他未提交内容，独立 worktree 不带入这些内容。未找到已有 DEVLOG 约定，按用户要求建立本文件并由任务入口关联。

## 运行前登记

- A：原样调用 main 的正式 `core_kernel::fast` 路径。预期重复驱动收敛且晚出现的同强度自致结果受发出轮次折扣。
- B：仅在独立探针中取消自致类别折扣；来源、n、合法 κ 和其他条件不变。预期保留晚期作用，但重复同向反馈可维持偏离。B 是消融，不作为修复。
- C：内部记录照旧；仅对有确定性核验凭据、尚未消费的行动结果免除类别折扣。识别器不得读合成世界隐藏真值；不能通过文本变化、action_id 或模型自称新颖获得资格。去重键、依据、版本和每次接受/拒绝记录可重放。预期保留可核验新结果的直接作用而不放大重复；也预期持续有效新结果可能推翻原统一回落保证。未知/无法核验保持 A。
- 反驳条件：A 的实际调用不表现上述差异则先否定复现；C 接受重复、伪造或过期结果则否定识别方案；若 C 没有消除“仅因晚出现而变小”的直接驱动差异则否定收益；若 C 破坏统一回落，则不能宣称在保留旧要求下修复成功。任何冻结夹具结果不外推到成长、模型能力或完整闭环。
- 核心场景仅两类：S1 同一经历的回忆/改写/取回，含文本不断变化而评价同向的反例；S2 没有新用户输入但不断得到可核验的新结果，含一次条件改变与真实反证。共同初态、评价幅度、时间和资源预算。合成真值只用于独立评分。
- 本轮预算：CPU 单进程；每组每条轨迹最多 256 个内部轮次、每轮最多 1 个行动结果，至少覆盖旧回落期限，停止刺激后的恢复也记录；最多两种 S1 表面形式和一条 S2 主轨迹。固定一套参数，不扫参。机制断言与关键拒绝测试，最多 1 次主实验及确有实现错误后的带编号修复运行；所有失败原始日志保留。编译最多 15 分钟，运行/测试各最多 2 分钟，证据总量目标 < 10 MB。无 GPU、无模型、无用户数据。

### 重复反馈通过哪条路径维持状态

S1 内部记录与取回结果都经过 A/M→已有 R⁺ 的 evaluate_effects→compute_drive→apply_drive。预先记录的 a_成事=.2，倾向贡献 sμr=.01，原始天性脉冲 .21、learned 脉冲 .1。B 每轮两次同向驱动补回时间衰减；结果提交后的成事坐标满足 `y_next = exp(-1)*y + .21*exp(-.2)+.21`，不动点 .6042098344，与实测相符。A/C 乘 κ^n 后，尾部驱动可求和并回落。早期 A 也能从初态 .25 上升到 .4572320111，因此机制并非让内部感受完全无作用。

完全重复的内部文本只有 1 种，变化设想有 256 种；新颖文本并不产生新依据。如果只按全文去重，后者每轮仍有 .21 脉冲，即便把重复工具结果全挡住，内部路径的不动点 `.21/(1-exp(-1)) = .3322151084` 仍大于 ε。这里是由已测驱动导出的反例，没有增加第四组或另建心理评分。它排除“文本去重足以控制同向反馈”，**不等于证明 B 对任意未来反证都无法改变**。本夹具的文本/评价预先生成，未运行真实 x→m→模型的闭环。

### 新结果会不会仅因晚出现而失去直接作用

会丢失大部分**直接 F 作用**。相同初态、相同投影时间、同一个评价/μ 的配对回归，仅把合法 ActionResult 的 n_issued 从 0 换到 120：成事驱动从 .21000000000000002 变为 1.5798644075051546e-37，比例 2^-120 = 7.52316384526264e-37；learned 驱动同比例变化。B 的原始分类仍为 ActionResult、κ 仍是 .5，但生成副本仅取消分类乘数，恢复同样的早期作用。

在 S2 中，C 的新证书不读隐藏真值或模型自述，去重状态从 1 个已知问题增至 257 个；S1 则一直只有 1 个。这里“此前未知”严格指该规范问题的有效答案尚未在可重放已知集中出现；**不声称模型数学上不会推导它、不声称它没有被其他定理蕴含，也不声称每个新问题都重要**。整数证书核验可以实际实现，任意自然语言的“有效新信息”不能由它代替。

### 候选失去的保证及最小反例

在 t=121.2s > T_ret，令 x 恰在静息点；第 120 轮新请求在 121s 登记、123s 到期，121.2s 提交合法且第一次见到的证书。没有任何外源事件。A 的脉冲为 1.504632769052528e-37，C 的脉冲为 .2，直接违反 `所有 t≥T_ret 时距离≤.05`。r=M=1、τ=2、前 N 轮提交时限及所有其他条件都满足。

这是**机制冲突**，不是识别误报或缺 runtime 导致：只要允许在任意晚的时刻出现一个大于 ε 的未折扣合法脉冲，就不能同时保证从最后外源输入起固定时间后永远留在 ε 内。即使有完美新颖识别也如此；不需要无穷多结果、不需要饱和、不需要冻结之外的成长效应。该最小例是 S2 的子情形，回归中可直接运行。

停止全部驱动 10 秒后，B 的 S1 距离降到 2.7431e-5，B/C 的 S2 降到 1.4364e-5。这只能说明保留的时间衰减仍有效，**不能替代持续活动期间的原统一回落保证**。有限窗口通过也不能证明所有未来时刻。

## 设计决定：现行机制暂时保留

**完成的决定：不把 C 作为满足现行全部要求的修复采纳。** 已排除 B 的全面取消折扣、仅按文本去重，以及“有效新行动结果无限期免折扣且仍保留原统一回落保证”这一组合。C 的局部收益成立，但在当前保证下失败，失败归因于机制目标冲突；其窄域识别可运行，生产接线仍未具备。

这不证明几何 κ^n 是控制重复反馈的唯一办法。盒投影已经提供有界性，G/C 的证据规则负责独立成长证据；κ 额外提供的是包括自己行动结果在内的可求和驱动尾部与有条件的定时回落。本轮没有寻找全部替代形式，也不做全面审计。

- **保留的保证与已知代价：** 正式代码保持不变；按既有 ADR 0026 条件保留回落推导。已知代价是晚期真实新结果的直接 F 作用也随发出轮次减弱。事实记录/检索不因此被删去，认知能力损失没有证据。
- **C 保留的局部性质：** 相同参数/固定事件序列及相同去重初态下，F 仍不读 x，盒界、单脉冲界、时间衰减、期限、来源与计数转移不变；重复内部内容仍折扣。它没有解决内部思考的全部限制，也没有证明完整反馈闭环不自锁。
- **C 新增的假设：** 每类结果需有确定性验证器、规范问题身份、请求绑定和完整已知集；正反结果一视同仁。此原型的已知集/完成集显式保存、重放重建，但不是生产 H/Q 原子事务。迁移、来源更正、别名语义和无限历史索引还需各自契约；当前没有偷偷把它们接入生产。不把一次验证成功当作 EV4 的可比因果证据。
- **成长边界：** R/θ 在本轮固定。现有 main 的 core-policy 不导出证据规律 G，core-runtime 是骨架；不能用“不调用成长”证明 AC2-03/10/11/14、EV2/3/4 正确。候选回溯引起的 R 变化也未模拟。
- **重新开放条件：** (a) 有一个可实现、可重放且仍满足同一 ε/T_ret 及持续活动条件的更小机制，并给出反例驱动的测试；不能只凭更大状态幅度。(b) 用户明确决定新信息可以延长状态偏离，允许替换原统一保证，再按 ADR 提交 C 的窄域版本。模型行为收益可以支持这项取舍，但不能消除上述数学冲突。

**下一步具体位置（本轮不执行）：** 若选择 (b)，先在新 ADR 中明确替换 `ADR 0026 §2.5、§6.3 和 COG-A12` 的“所有纯内生区间统一回落”，改成在停止有效新信息输入后的条件回落，并保留重复反馈回路的独立检查；同时澄清 v2.0 §6 超过 T_x 的归属。随后才考虑在 `core-kernel/src/fast/drive.rs::class_weight/compute_drive` 增加由运行时验证的有限能力输入；核验依据与一次性消费由后续 P5-38/P5-19 的 H/Q 提交路径绑定，来源枚举和 C 的外源限制不改。先改保证再接线，不能先把 ActionResult 改标成外源，也不能把 κ 改成 1。当前这一步没有批准、没有实施。

不安排本机模型试验：当前决定取决于明确的保证冲突，模型行为差异不会使 C 重新满足原命题；完整 runtime 也不在本轮范围。到此停止，不自动扩展其他 Echo Core 问题。
