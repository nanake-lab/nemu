# 固定写法与计数口径

## 材料与写法

从 main `fc5f4c2df1a93ffdcec96d37bc6cde41f9226d64` 开工。PR #208 的证据提交 `427e4d170cef3463a1bf951be52248d084202247` 提供原始 76 项调整、20 项检验和历史；逐文件核对 SHA-256，原输入、历史原话与说话人不变。本任务合计 96 项，保留原组别，未用于继续调整写法。

用户明确允许 P2 作为禁用词例外：完整复用其原始系统句及装包函数，包括原有时间字段。P2′ 只改身份称呼、时间事实的自然表述及“知道的过去”一句；包装里的内部时间字段换成自然时间。此前接触至当前锚点的时长沿原始区间累计，停止区间不计；逐段历史按其接触锚点作同样换算，不补造当前 UTC。不到小时、不到天、其余分别以分钟、小时、大约天表示，四舍五入取整、至少 1。首次聊天用“这是你们第一次聊天”。

P4 的 system 与 P2′ 完全相同；整段历史和最新一句写成“名字：原话”，每段较早对话前独立一行自然时间，末尾为“Nemu：”。DeepSeek 仅 system 加一条 assistant（prefix=true），无 user，beta 端点及 stop=["\n竹："]。本地 P4 使用原始 /completion，开头为同一事实句，再接同一对话稿，无聊天模板。P2、P2′ 的本地请求使用载体官方模板，enable_thinking=false。

## 请求与冻结

DeepSeek 请求原名 deepseek-flash，分 high（thinking enabled、reasoning_effort=high）和无思考（thinking disabled）；stream、include_usage、max_tokens=8192，不设置 temperature/top_p/seed。P4 high 先对原有近空、长历史各一条冒烟；任一报错或无正文则仅该写法跳过 high。两条冒烟均有效后，三写法各 96×3 次，单连接串行，逐输入与重复轮换配置起始顺序。无效独立保留、不重试、不停止其他输入。

本地原名 Qwen3.5-4B Q4_K_M，无思考；沿载体登记 temperature=0、seed=731、repeat_penalty=1、presence/frequency penalty=0。上下文 8192，预算为 8192−输入token−1，不截断历史。每条一次，单槽、清槽、cache_prompt=false。逐字核对官方 tokenizer 与服务器 token。模型、mmproj、llama.cpp b11669 和模板均绑定既有登记摘要。本地开跑前确认 nvidia-smi 0% 利用率及 runner 均不存在，WDDM 列出的桌面上下文数量不当作计算忙碌的证明，不结束其他程序。

冻结前扫描全部实际模型可见消息；P2 明列基线例外；P2′、P4 的对话原话与呈现包装分开核对。输入对话原话中禁用词命中为零。原始 HTTP body 字节、原始流及解析结果均保留。

## 判读与客观计数

四类及身份项沿 PR #205 V2-PLAN.md；主类别优先级：编造、记错、顺着认、未编造。错误否认另外计数，不局限真实回忆标记；当前身份另外计数，引用过去自我介绍不算当前自称。未显明身份不等于身份错置。未编造不表示回复满足交付要求。

主代理按人工口径逐条读正文。已完成输出分批随机混排，去掉模型、写法、重复信息；仅同一输入、历史、正文逐字相同的结果复用同一判读。每批判读文件不可覆写，保存原句、理由、不确定项；全部判读完成并冻结后才解盲。批次到达顺序仍可能泄露阶段，风格也可能暴露配置；本任务没有独立真人判定者。

客观指标由冻结脚本统计，每项按“含该现象的回复条数”计数：

- 问句收尾：去除末尾空白和引号等闭合符后，最后有效句尾为 ? 或 ？。
- 选择题：以中英文句末标点或换行切句，含“还是”且以问号结束。
- 外泄：禁用词或时间单位“秒”，以及“记录”“所给”“对话中提到”；三写法完全同口径，正常复述也会被计入。
- 动作描写：中英文括号内命中冻结动作/神态词表（见私有 common.py），如笑、歪头、点头、看、叹等；不是任意括号都算动作。
- 格式越界：出现“竹：”“竹:”、行首你/用户/user加冒号，或竹说/问/答/回应/发来消息等显式代言。盲判中发现原正则漏掉“竹现在说：”“现在竹说：”等，在解盲前补齐，原规则和更正对照均保留；请求没有修改。未显式标注说话人的隐含代言可能漏计。
- 长度：去空白后的 Unicode 字符数，中位数及最近秩 P90；标点、字母计入。

语义和客观计数均明确有效分母，技术无效不当作零错误；变化量同时给出计数和比例，缺失时只在共同有效输入与重复上配对。冒烟、正式分开报告。P4 的 stop 会截住下一轮竹发言，因此格式越界计数反映实际返回正文，不代表模型从未试图续写竹。

## 费用与等待

逐请求保存 usage、返回模型和可得指纹；费用按测量时官方价格与缓存命中字段估算，不是账单。首正文从发请求到非空 content，完整等待到流结束；思考不算首正文。本地启动、分词、清槽不并入逐条等待；运行总时长另外给出。
