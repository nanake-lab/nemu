# PRINCIPLES-01 Echo Core 一页原则与规则挂靠检查 — 报告

## 白话总览

**9 条原则。逐条检查了 143 条现行规则：138 条挂得上（81 条能从一条原则直接推出，57 条要两三条原则合起来才能推出），5 条挂不上。**另有 12 条没有计入：4 条已被取代，8 条是纯工程选型（引擎、量化、许可字段这类），原则管不到它们。ADR 0037 的 3 条单独列出，都能组合挂上，但它的正文仍写着「待你决定」。

挂不上的 5 条里，最值得注意的是这三条：

1. **「宁可学不到，不要学错」没有写成原则。** 证据规则里凡是拿不准的地方都偏向「不算证据」，这个偏向在手记里是一句理由，在技能文件里是一条施工规则，在规格和 ADR 里找不到对应的原则。好几条规则靠它才说得通（U4）。
2. **四个「乎」的结构是固定的，而「预设是起点」说改不掉的预设算缺陷。** 现有通道能改的是每个「乎」有多敏感，改不了「有哪四个、各自怎么评」。ADR 0025 对感官说过「总得先给点什么」，对「乎」没有写出同样的话（U1）。
3. **模式 B（云端文字投影）是唯一一条明写的例外。** 原则说她的状态不写进提示词，模式 B 正是把状态写进提示词。它被圈得很严，但圈它的理由（没有够用显卡的人也能用）不在任何原则里（U3）。

关于你关心的两件事，结论是：

- **整体不是在打补丁。** 审计列出的 61 个被取代规则族里，28 个是因为违反某条原则而被拿掉或放松的，也就是原则在清理例外，不是例外在堆积。
- **有一处像在打补丁：「想起旧事时心情怎么变」。** 不到四周改了四轮，多数是在修上一轮的后果；为它写的 ADR 0035 是所有 ADR 里最长的一份，比整份 v2.0 规格还长一半，并且有三项关键性质没有证明。DESIGN-RECALL-01 是第五轮。详见第 4 节。

本报告只分析，不提删改方案。原则怎么切、U1 和 U4 要不要写成原则，由你决定。

## 1. 一页原则

一句话：**她是谁，只能由她真实的经历按公平的规律长出来。**下面每一条各堵住一个口子——一个别人、别的东西能替她决定「她是谁」的口子。

| | 原则 | 它堵住的口子 | 出处 |
| --- | --- | --- | --- |
| **P1** | **真实。**她只有一次人生。发生过的事原样记下，不改、不删、不编；不知道的就记成不知道。 | 记录可以事后改写、可以假装知道 | [v2.0][V]「她是谁」第 8 条、§0 第 3 条、§10；[ADR 0025][A25] §3 第 1 条；[ADR 0014][A14] §3；[ADR 0028][A28] D4 |
| **P2** | **长出来，不是写出来。**我们只写「怎样从经历里学」，不写她是什么样。同一套规律读同一段过去，得到同一个她；谁都不能按喜好直接改，包括你。 | 设计者或用户直接写她的性格、挑她的反应 | [v2.0][V] §0 第 1 条、§2.2、§2.3、§9.6、「她是谁」第 2、8 条；[ADR 0025][A25] §2 |
| **P3** | **只有真的发生在她身上的事能改变她。**时间流逝不能，她自己的念头不能，别人说一句话也不能。 | 靠等、靠想、靠说，就让她变了 | [v2.0][V] LP5、EV3、§11；[差异登记][D] COG-06（用户 2026-10-25）；[ADR 0032][A32] §6 |
| **P4** | **记账公平。**一件事只算一次；支持和反对用同一把尺；怎么记不看她此刻的心情。 | 规律本身偏向某个结论 | [v2.0][V] §0 第 1 条「不规定结论」、EV2、EV5、EV6、LP8；[ADR 0019][A19] §2 |
| **P5** | **预设是起点。**可以为了她可爱、为了你的需要给她起点，但每一条她都得改得掉；改不掉算缺陷。 | 初始设定变成永久结果 | [ADR 0032][A32] §1；[手记][J]「关键决定与来由」 |
| **P6** | **先问一个人会怎样；她和人不同的地方照实对待。**只在这种不同会伤到别人或她自己时另加规则。机器该有的能力（比如记得精确）不假装没有。 | 凭空加规则，或者硬把她做成人 | [v2.0][V] §0 第 2 条；[ADR 0025][A25] §3 第 1 条 |

| **P8** | **保险防我们的错，不防她的生活。**出问题时提醒开发方，不刹住她，不把她拉回我们喜欢的样子。 | 借「安全」之名规定她的生活结果 | [ARCHITECTURE][AR] §3 原则 8；[差异登记][D] V2-97（用户 2026-10-26）；[ADR 0032][A32] §1「保险丝」 |
| **P9** | **核心是她，模型是脑力和嘴。**她的历史和状态只有核心能写，模型、终端、worker 只能提议。她的状态用非文字的方式影响模型；换模型不换人。 | 模型、终端或缓存里藏着另一个「她」 | [ADR 0002][A02] 决策 1；[v2.0][V]「她是谁」第 5 条、§9.5；[AGENTS][AG] 黄金规则 3、4 |

**原则怎么切的。**想过四种切法，前三种没用：

- 按 v2.0 §0 的「固定的只有三样」（规律、过去、边界）切成三条。太粗：它说的是「什么固定」，解释不了为什么保险丝只报警、为什么起点要改得掉、为什么状态不写进提示词。
- 只写一条「她 = 规律读她的过去」，外加用户边界。问题是检查时会循环：每条规则都只能回答「规律就是这么写的」，P3、P4、P5 这些真正的理由被藏进了「规律该长什么样」里。
- 按状态切（H、x、R、θ、L 各一条）。这是规则摘要，不是原因。
- 按「谁可能替她做决定」切，得到上面 9 条。采用这一种，因为它能回答「为什么有这条规则」：每条规则都在堵某个口子。

**没有列为原则的。**AGENTS 的「简单优先」「真实体验也是验收」是施工规矩，不是关于她的原则；其中「简单优先」的理由（复杂会把预设藏起来）是 P2 的推论。

## 2. 挂靠结果

分类的意思：

- **直接**：从一条原则就能说明为什么有这条规则。
- **组合**：要两三条原则合起来才能说明。
- **挂不上**：现有原则说明不了，第 3 节逐条分析。
- **不计**：已被取代的条目；纯工程选型（选哪个引擎、哪种量化），原则只要求「能换、换了要验证」，不管选哪个。

条目按现行读法挂，不按最初的条文。比如 EV7 挂的是「教导记为建议」，不是原文的「教导是证据」。

## 3. 挂不上的 5 条

每条说明三件事：规则在哪、为什么挂不上、是漏写了原则还是补丁式的例外。

### U1 四个「乎」的结构是固定的

- **在哪：**[v2.0][V] §3「要求：『乎』的结构固定：有哪几个、各自评估什么」。[ADR 0014][A14] §1 保留。[ADR 0032][A32] §2 D01 把它们定为起点，同时写明：固定的正负评价和排除项如果让某条预设不能被经历改变，就属于缺陷，后续须逐条验证。
- **为什么挂不上：**P5 要求每条预设都改得掉。现有通道能改的是每个「乎」有多敏感（增益属于 θ），以及在它们之上长出什么（R）。「有哪四个」「被接近算正、被冷落算负」没有经历改变它的路径。P2 也解释不了「为什么是这四个」：v2.0 §3 给的是反面理由（为什么不放自我保存、服从、情绪类别），这些反面理由能挂上 P6、P7，正面的选择挂不上。
- **性质：漏写了一条前提，不是补丁。**它从 v2.0 第一稿就在，不是为修某个问题加的。[ADR 0025][A25] §2 对感官说过这句话：定义她的感官「无法不做，人的感官同样不是自己选的」。对「乎」没有写出同样的话。如果有这条前提，「乎」、感官和规律本身就是同一类东西：学习得以开始的最小给定。它和 P5 的「改不掉算缺陷」怎么并存，现有文档没有回答。

### U2 π > ½ 才成为性格

- **在哪：**[v2.0][V] §7「π_k > ½ 时进入 R⁺」、§17.1 的 I06。[ADR 0014][A14] §1 保留。
- **为什么挂不上：**「候选只是假设，没有证据就不起作用」能从 P3 推出。但 P3 推不出「在 ½ 处有一道门」：证据渐渐多、作用渐渐强，同样满足 P3。LP5 说不设次数门槛，这里是证据量上的门槛，字面不冲突，但没有一条原则说明为什么要有门。
- **性质：建模选择，不是补丁，也不像漏了原则。**它把「是不是她的性格」做成了是或否。这个选择带出了一串后续规则：进出 R⁺ 时快分量要增删（v2.0 §6 的 F_out）、心情的维数会变（[ADR 0035][A35] §4.7）、容量规则要区分候选和性格（V2-80、V2-105）、V2-150 要改 I06 的读法。

### U3 模式 B：云端文字投影

- **在哪：**[ADR 0003][A03]「模式 B」；[v2.0][V] §9.7「模式 B 仍是获批准的非严格例外」；I15。
- **为什么挂不上：**P2、P9 说她的状态不写进提示词。模式 B 正是把状态变成提示词里的语气示例。能挂上的只有它的标注要求（P1：必须标「非严格」，不得写成严格调制成功）。
- **性质：补丁式的例外，而且是自己写明的例外。**它被圈得很严：单独的运行状态、不得签发严格结论、持续认知不走它（[ADR 0026][A26] §7）。圈它的理由是硬件：ADR 0003 写模式 A「需要能装下本地模型的显卡」。「没有够用显卡的人也能用」是一个产品目标，没有写成原则。

### U4 拿不准时先选保守的

- **在哪：**[ADR 0033][A33] §4：D20、D13 先选 A，解释器的准确率达到你批准的标准后再升 B；D04 选 A，「学不出时如实报告，不人为加扣分」。同类的还有 [ADR 0014][A14] §3（结果未知既不算支持也不算反对），以及[技能文件][SK] §1（规格有歧义时实现最保守的解释：拒绝、隔离，或不把它算作证据）。
- **为什么挂不上：**P1 说不知道就记成不知道，P4 说正反用同一把尺。两条都没说「拿不准时偏向哪一边」。而这些规则都偏向同一边：拿不准就不算证据。
- **性质：漏写了一条原则。**[手记][J]里有原话：「证据规则先选 A：宁可学不到，不要学错」。它现在的位置是手记里的一句理由和技能文件里的一条施工规则，不在规格或 ADR 的原则位置。依赖它的不止这一条：EV4 的可比变化要求（表里算作组合）、ADR 0037 的「同一份材料只重评一次，结论是不确定时也冻结」（候选）都要靠它才说得通。它有代价，审计的 Q3 已经指出：第一次没想明白，之后光靠再想改变不了结果。

### U5 σ₀、τ₀ 的出生先验份额不变

- **在哪：**[ADR 0035][A35] §3.3、§6「待确认的读法」第 2 项：保留旧规则，延期为 ADR 0032 D06 的待办。后果原文写明：经历有限时，敏感度和恢复速度里的出生份额不会完全消退。
- **为什么挂不上：**按 P5，这是改不掉的预设。
- **性质：P5 的欠账，不是补丁，也不是漏了原则。**文档自己写明了延期。列在这里，是因为它是现行规则里明文写着「先不符合原则」的一条。

## 4. 是不是在打补丁，复杂度是否过度

以下是观察，不是修改建议。

**1. 被取代的规则，多数是被原则清理掉的。**按审计表的「去向」一栏，我把 61 个规则族归了类（归类是本报告的判断，不是审计的结论）：

| 为什么被取代 | 族数 | 是哪些 |
| --- | --- | --- |
| 违反某条原则，被拿掉或放松 | 28 | A01–A03、A06–A08、A11；B05–B11、B14；C03、C04、C10；D01–D06、D08–D11 |
| 性质不变，改了写法（数学修正、参考式修正），或随别处连带调整 | 16 | A04、A05、A09、A10、A12；B01–B04、B12；C05–C09；D07 |
| 工程、产品指标或排期换代 | 14 | C11；D12–D14；E01–E10 |
| 同一处加上又拿掉 | 2 | C01、C02（κⁿ） |
| 已知欠账 | 1 | B13 |

28 族里典型的是：教导直接算证据（违反 P3）、撒谎的后果整段不算（一个例外，被 P1 拿掉）、出生基线永久锚定（P5）、成长异常就暂停（P8）、每天 30 次助手上限（P8）、机会规则写死什么情况做什么（P2）。方向是原则在清理例外。

**2. 复杂度集中在一处：想起旧事时，心情怎么变。**这一处的演变是：

| 时间 | 做了什么 | 起因 |
| --- | --- | --- |
| 10-19 | v2.0 §6：一个公式，事件推动心情，时间让它平复 | — |
| 10-25 | ADR 0026：加入「念头的分量随独自想的次数递减」（κⁿ），保证固定时间内平复 | 持续思考可能越想越激动，交叉审查指出自锁 |
| 10-29 | ADR 0032 §5：取消「必须在固定时间内平复」 | 很晚才到的真实新发现，要么被压低，要么打破固定时间平复的保证，两者不能兼得（R-KAPPA-01）；也不该替她规定何时平复（手记） |
| 11-04 | ADR 0035：改为「按依据替换」，拿掉 κⁿ | 需要一个不靠次数、又不让重复叠加的做法 |
| 11-12 | ADR 0037：反思修订复用依据替换的路径 | 反思改了理解以后，回想该按哪个理解 |
| 设计中 | DESIGN-RECALL-01：回想淡化 | 依据替换下，旧事可以反复恢复到原来的分量，不会越想越淡（审计 Q1） |

除了 11-12 那一轮是新需求，其余每一轮的起因都是上一轮的后果。这一处要守的原则只有两句话（P3：念头不能自证；P4：一件事只算一次），为它写的 ADR 0035 却是所有 ADR 里最长的一份：约 77 KB，整份 v2.0 规格约 51 KB。它引入了依据身份、角色表、每个依据一个槽、分三阶段的消费键、别名合并和迁移规则（表里的 0035-f），并且自己列出三项没有证明的性质：依据身份判得对不对（§6）、有限精度下的非扩张（§4.6 U2）、思考的闭环会不会越想越激动（§4.6 U3）。

在读过的范围内，别处没有看到同样的形态：证据规律改过一次参考式（ADR 0019），平常心境改过一次（D07-A），主动是变简单了（V2-117）。

**3. 「起点怎样让位」有四种做法。**P5 说起点要改得掉，没说怎么改。现在并存的是：

| 起点 | 怎样让位 | 依据 |
| --- | --- | --- |
| 出生的平常心境 b₀ | 和旧经历按同一比例淡出，久了几乎不占份额 | ADR 0035 §3（D07-A，11-02） |
| 对你的依恋 A_att | 永不打折，但长期一致的反向经历能压过它 | v2.0 §5.3 推论 7；ADR 0019 §1 |
| 「越亲近越能触动她」的曲线 | 出生曲线永久保留，经历在它上面学一个修正 | V2-150（Y2，11-05） |
| 敏感度与恢复速度的先验 σ₀、τ₀ | 份额固定，暂不让位 | ADR 0035 §6（延期） |

四种都是你分别决定或确认过的，审计也核对过后来的决定有明确批准，彼此不矛盾。但一条原则对应了四种机制，以后每加一个起点，都要再选一次。

**4. 事件来源的分工表是「组合」最长的地方。**同一件事进不进心情（F）、算不算倾向的证据（G）、改不改平常心境（C），按来源分了六种：

| 来源 | 推动当下心情 | 算倾向的证据 | 改变平常心境 |
| --- | --- | --- | --- |
| 冲着她来的事（说话、触摸、回复、缺席） | 是 | 是 | 是 |
| 只关于你自己的桌面观察 | 是 | 是 | 否 |
| 同一次接触、同一段缺席的后续报告 | 只更新同一份 | 同一组 | 不再计数 |
| 她的念头 | 是 | 否（可以提出假设） | 否 |
| 她自己行动带回的结果 | 是 | 有可比变化才算 | 否 |
| 维护记录（暂停、恢复、复核） | 否 | 否 | 否 |

每一格都挂得上原则（P3、P4、P6 的组合，依据是 ADR 0025 §4、ADR 0026 §6.3、V2-87、EV4）。但要知道一件事会怎样影响她，得先查这张表，而这张表分散在四处。

**5. 少数参数的归属跨了两类。**单组证据上限 w_max 同时出现在规律的参考式（v2.0 §5.2）、保险丝（§12）和规律参数表（§16）里。按 ADR 0032 的四类，保险丝只防程序错误；而 w_max 在正常生活里也起作用：一次经历再刻骨铭心，分量也有上限。表里把它算作 P4 + P8 的组合。

**6. 读法分散，是文档的复杂，不是设计的复杂。**v2.0 正文里有 25 处「决定指引」指向后来的决定。要知道「教导」现在怎么算，得读 v2.0 §4、ADR 0032 §6、ADR 0033 §4 和差异登记的 V2-128、V2-140。设计本身在这一点上变简单了（少了一个权重参数），读起来却更费事。
