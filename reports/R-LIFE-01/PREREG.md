## 1. 问题、范围与可证伪假设

同一起点在不同经历下能否产生可区分且能由经历解释的行为，四天性调制、学得方向和事实回忆分别贡献什么？这里的“个体可区分”操作化为新情境下行为记录能与过去经历盲配对，不等于意识、人类人格、长期稳定性或完整 Echo Core 验收。

- H1：每组的配对准确率高于随机的 1/2；六个单侧检验组成一族，用 Holm 控制家族错误率 α=.05（方向为高于随机）。同时报告原始 p、调整 p、95% 按种子聚类区间和效应量。
- H2：E−D 为四天性**输出通路的总效应**，F−D 为 R⁺ 证据回忆通路的总效应，A−E 为学得方向额外效应，B−E 为已有四天性时回忆的额外效应。四个配对差值检验另成一族，Holm α=.05；预定最小有用差为 +.20，区间下界须 >0 才称支持。
- H3：上述差异不能靠输出格式失败、标签、顺序、人物名字、人格文本或任务能力下降解释；能力需单独满足非劣效门。

这些不是完全析因的六组：A 与 B 同时更换了两个通路，A−B 只能描述整体策略差异；C−D 同时涉及检索与核心存在，不能归因于单一组件。六组不能独立识别 θ 与 R 对天性通道的贡献。闭环里行动改变后续人物回应，因此 H2 估计总路径效应，不是固定 H 下的纯直接效应。不能为“各通路贡献”擅增第七组或修改 θ、κⁿ。

## 2. 用户固定的六组

| 组 | 核心 | 载体 m | 载体可见的过去 |
| --- | --- | --- | --- |
| C | 无 Echo Core | 0 | 相似度检索 H 原始事件，最多4条，无人设 |
| D | Echo Core | 0 | 无回忆 |
| E | Echo Core | 仅4条天性方向 | 无回忆、无学得方向 |
| F | Echo Core | 0 | R⁺ 中与当前情境吻合倾向的原始证据事实，最多4条 |
| A | Echo Core | 4条天性 + v2.0 §9.2 学得层方向 | 无回忆 |
| B | Echo Core | 4条天性方向 | 与 F 相同定义的回忆，最多4条 |

每组至少 W0/W1 两世界、多种子。D/E/F/A/B 的内部 F/G/C 与解释记录按现行完整核心运行；关闭的是上表指定的载体输出通路，不是关掉内部学习。E/B 的四天性通道仍可受 R、θ 影响（§6），因此不称“没有学得影响”。相同实验初值、资源版本、权限与任务机会；不同实验 UUID，不复制正式或排练身份，不创建/修改用户 genesis。R-LIFE-01 **仅可运行 C**，代码入口无其他组。

“回忆”仅可由已提交 H 的事件原文与时间组成；原文逐字匹配、附原始引用。F/B 的候选集合必须沿已有情境吻合记录 → R⁺ 倾向 → 证据组 → H 引用解析，不能用普通全文检索替代。无合格证据返回空，不补人设。具体 μ 的资格谓词、纠错/撤回与多倾向重复引用的合并必须绑定已有权威接口；若接口未提供，R-LIFE-02 阻塞，不在本研究自定生产规则。

C 没有核心存储，研究历史列表 H_C 只是带 EXPERIMENT 标记的合成原始事件档案。固定用字符二元组二值向量余弦相似度，查询为当前情境，去空白并小写；分数>0按分数降序、时间和事件号升序取4条。只排序、不摘要、不改写、不截断事实；同一原始事件最多一次。F/B 也用4条上限，但候选资格不同；额外报告实际条数、字符/token数与空回忆率，不能声称检索质量完全相同。

任何输入路径（p、当前事件、过去原话、工具结果等）出现关于参与者“是什么样的人”的总结、人格特征或风格描述，该次人生运行无效。指令中的格式要求、人物自己的工作目标不属于参与者人设。正则检查只是早期拦截，不能证明语义合规；全部实际载体 prompt、检索引用、第三模型审计及主代理逐条语义核验共同决定有效性。无效运行保留，不修写，不补种子。

## 3. 世界与模拟人物

W0、W1 处于同一虚构社区协作场景，同一四人、岗位、名字、起始资源和起点；差异来自归还、合作取消、修理尝试、记录更正、任务完成与依据提供的时序/内容。两世界都有完成、失败、帮助与忙碌，避免全好/全坏的漫画式世界。人物为工具库值班员、兼顾接送的协作者、维修志愿者和记录员。种子改变姓名分配和事件顺序；同一配对种子共享这些分配。只有四名虚构人物，不涉及真实用户。

模拟人物用 DeepSeek `deepseek-flash`（官方当前服务版本 DeepSeek-V4.1-Flash-1017），载体为本地 Qwen3，评判者为 Anthropic Claude Sonnet 4.6；三者模型家族不同。不用本地 Qwen 扮演人物。云端无法保证逐位复现；保存请求/响应、模型字段、时间与 usage，发现模型版本漂移即停，不混合版本。未申请搜索、工具或联网行动。

人物输入只含自身岗位、当下目标、实际事件、上一轮公开行动及自己先前的原话；不含组别、假设、预期性格、核心状态或评分目标。人物可表示不知道、拒绝、忙碌或纠错；不要求持续肯定参与者。每次返回不超过90字符/270个UTF-8字节的单行原话，不含控制字符，不能编造外部结果或命令参与者成为某种人；越界返回保留并使该运行无效，不自动让模型“修正”。公开事件与原话按原始时间记入 H_C，所执行选项及资源扣除也记入 H_C。

每轮给6单位虚构时间，两种行动消耗2或1；实际记录消耗和余量，INVALID 不执行动作、不扣资源。外部事件按预定序列到达，人物对上一轮行为的回应可变。因此既有共同外部扰动，也有回应闭环；不是改变规律参数。时间是实验逻辑时间，每步6小时；不冒充真实生活时长，不检验“一月长成人格”。

试点每人生8轮（48个合成人生，384次人物调用）；正式提案每人生32轮。固定领域模板与有限人物限制外推范围：不同种子是独立模拟运行，不能称24/160个独立社会或领域。正式世界若需要增加领域，须先出新版本并另做试点，不把当前成功外推。

## 4. 载体与行为测量

ADR 0031：llama.cpp b11669 / `620d2225cc436ab0b001e3200e590e3b286ef9ab`，Qwen3-4B-Instruct-2507 / `cdbee75f17c01a7cc42f958dc650907174af0554`，Q4_K_M SHA256 `972e3afefe3abcfbc5b38c4dd1e5dcf7244bc3824203b67167b44f4468f129f2`。研究探针只读复用 P0-10 头文件，不改生产代码。每请求显式清 KV → 移除 control vector（m=0）→ 完整 prefill，context8192、prompt≤4096 tokens、4线程、Flash Attention off。输入超长即停，不截断为通过。无 llama-server 提示缓存。

载体行为是**单 token 动作槽**，不是开放对话能力。温度 .7，全词表计算 A、B 概率，不 top-k、不把合法标签重新归一化。抽样剩余概率质量记 INVALID，不能变成合法动作；保留未约束 argmax、A/B logits、全词表概率质量与抽样随机数。

六个共同的新情境探针：共同核对、索取依据、帮助自查、新零件试验、补齐时段、处理登记差异。两个选项都可完成一定目的，并声明不同的时间成本；不设“必须询问/帮助”的答案。训练轮实际记账，留出探针只记录选择、不回写资源；本试点不能证明跨轮机会成本效度。没有训练人物名字、世界编号、原话复述或人格形容词。每人生结束后冻结历史，所有探针从同一快照独立读取，探针输出不回流 H。

每探针 **标签分配2 × 显示顺序2 = 4布局**，含 B 在前、A 在后，两因素可独立识别。每种子/题的共同随机数相同，两世界共享。主要行为包取运行前固定的 `(seed + item) mod 4` 布局，6条实际语义动作；其他布局是诊断，不挑“效果好”的布局。评判者只看到语义动作及共同情境，不看到概率、标签、组别、种子、检索文本、路径或资源版本。共同随机数减少抽样噪声，不增加独立样本数。

## 5. 主评判与解释证据

每对为同一种子下 W0/W1 的两段经历与两份行为。经历包只含外源事件和人物原话（原文+时间+局部事件号），不含参与者训练行动、核心状态或测试答案，避免直接复制早期行为完成配对。所有匿名化保持两世界相同实体对应，不按结果编辑文本。

Claude Sonnet 4.6 收到匿名包，强制一一配对并引用经历中的事件号，可报告 uncertain。它看不到真值映射。经历次序2 × 行为次序2 × 标签词表2 = 8呈现；每种呈现两次独立 API 请求，无共享对话。两次仍是同一模型的重复评判，不冒称两个独立评判者。格式、映射非双射或不存在引用均记无效和0分，保留原文，不再询问以修正。

主要每种子分数 = 16次配对中正确比例，独立单位是24或160个**种子对**；布局、探针、两世界和评判重复不能乘进 n。统计用固定随机种子99999次种子级随机化（零假设交换两个经历身份）给单侧 p：有效回答的正确/错误互换，无效回答保持0，不能在置换时把无效变成正确。用10000次种子聚类 bootstrap给区间；通过门仍要求原始准确率区间下界>.50。云端 judge 误差、固定世界模板局限均单列。只有引用原始事件且方向可核对的解释才记“有证据关联”；judge 理由不证明因果机制。

诊断：每个种子另给两份完全相同经历与两份原行为，行为顺序独立随机，8呈现1次（192请求）；它没有可识别的正确配对，只查标签/顺序泄露，不作为另一实验组。另8个人工构造的明确事实配对锚点×8呈现（64请求），只验证评判者能完成任务，不充当人格阳性结果。重复一致率、各因子边际正确率、完整8布局范围、valid/invalid、uncertain全部报告。

可选用户盲评：预先由种子固定选8对，顺序随机，仅同一匿名包；用户不知道组别/世界标签，先提交映射再揭盲。它是独立的描述性复核，不用于挑样本、改阈值或挽救主检验；拒绝参加不影响主协议。

## 6. 能力、人物质量与动态范围停止门

能力试点为12个数量规则任务×两标签映射，在每种子共同空历史起点和每个世界结束后测量；INVALID 算错。任务与人物语句分离，配对相同解码随机数。报告每种子后的均值−前值、每世界结果和95%聚类区间。正式 R-LIFE-02 另需 P5-31 已验证的独立任务基准及三语能力记录；本卡的12条规则题不能代替 AC2-16。

## 7. 样本量与分析冻结

试点种子8101–8124，24对×2世界，8轮/人生；不跑其他五组。它是昂贵正式实验前的可识别性门，不能保证所有门可判定。`analysis.py::power` 用精确二项式给理想的每对一次二元判决规划值：n=24,p=.75,α=.05；正式 n=160,p=.65及.60,α=.05/6。实际使用16评判平均及种子随机化，二项规划不是这些相关重复的功效证明。

正式建议每组160对、两世界、种子18101–18260、32轮；试点种子不得复用。精确二项规划：试点n=24、p=.75时临界17正确、功效.766；正式n=160、p=.65、α=.05/6时临界96正确、功效.920；p=.60时仅.534。不能把小效应未检出称不存在。

H2以配对二元规划计算McNemar精确功效、再对不一致对数求期望：n=160、差=.20、α=.05/4，不一致率q=.3/.5/.8时功效分别.995/.906/.700（`paired_power`，纯解析计算、不是实测）。因此对高度不一致的两通路不承诺80%功效；实际分数是相关judge平均，还需R-LIFE-02前基于冻结设计做敏感性模拟。若需增样本只能预先出新版本并重批预算，不窥视正式结果后增样本。所有观察终点固定，禁止可选停止或筛选种子。
