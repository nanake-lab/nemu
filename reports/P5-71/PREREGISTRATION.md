## 2. 分析单位、输入与资源

这是确定性机制反驳实验，不估计人群效果。一组固定世界及其配对分支是一个分析单位；事件、坐标、语言改写、前缀和重复运行不是独立样本。不计算 p 值、置信区间或统计功效。有限轨迹不证明全时间稳定或一般识别能力。

### 2.1 规模约定

- 不使用随机抽样，`S=1`，种子标识 `P5-71-v1-enumerated`。各表的笛卡尔积全部运行；顺序为行号、参数升序、分支书写顺序、事件序号、坐标 0…3。
- E07 的 W 是参数组合数，B 是配对分支数，N 是每分支历史操作数；无作用占位也算操作，不能重锚。只读观测点不增加 N。E09/交互的额外世界数在相应节规定。表中未写 B 时为 1。注明最长 N 的短脚本用同刻无作用占位补齐，不增添证据。
- 每条轨迹比较每个前缀（含空前缀），同时执行增量和从 genesis 重放整个前缀；不只比最终快照。无事件读出从最后合法锚点投影，读取不写回。
- 合成时钟是单一 epoch 的整数纳秒，通常第 i 条在 `i×10^9 ns`；只有指定的零时距/间隔/停机夹具例外。无实时时钟调用。E07 默认四坐标输入 `[a,a,a,a]`；E09 默认仅坐标 0 非零，另作四种坐标置换。
- 每个合格独立外源输入加 1 份质量；重复、排除来源、缺解释不增加质量。来源、资格、根是冻结合成输入；另保存不交给 DUT 的真值表。这不是自然语言识别器测量。

## 3. 版本、独立 oracle 与判据

### 3.1 每项比较

E07 每个可运行行比较旧固定 n_b、D07-A、D07-B 三版本，再独立运行该行列出的每个单一变异（从 A 改一处，不组合掩盖失败）。E09 每行比较旧 κ、A1、A2、B 四版本，再各跑单一变异；A0 只在指定无输入/分解行作必失败参考。各版本接收同一原始 H、解释和时刻，不要求合法行为代价或内部表示相同。

交互比较 `(旧C,旧F)、(A,旧F)、(旧C,A1)、(A,A1)、(B,A1)、(A,A2)、(A,B)` 七组合；变异从 `(A,A1)` 单独产生。每项保留正向新证据与不应新发的重复。缺可调用生产接口的子项为 not_run，不用模拟组件冒充 DUT。

### 3.2 oracle 独立性

1. 在 `tests/` 下单独编写 oracle，按 ADR/证明写输入契约、手算见证及独立实现，再接 DUT 适配器。不 import/include、调用或复制 DUT 的递推、更新、目标选择、资格筛选，也不复用 P5-69/P5-70 的已有 oracle。允许共用生成 IDL 和纯 I/O；数值位检查独立，不能让共享规范化隐藏错误。
2. oracle 从冻结输入、资源和原始历史自行推进。不得用 DUT 输出生成预期值；对 DUT 输出的 P/S/U 作误差检查之外，必须独立算出它们并逐步比较，避免只验证自洽。
3. 加减乘除由精确有理数与独立 ties-to-even 舍入模拟，含 +0 规范化和渐进下溢。只允许共用锁定版本的底层超越函数原语，不共用 Φ/递推流程。原 Φ 另作 B1 兼容参考，不是唯一 oracle；两边同库不证明超越函数精度。
4. 结构等式用完整字段的 `to_bits` 或规范字节，容差为零：增量/重算、幂等、禁止更新、资格集合、引用、首次作用及同锚无输入 Φ。不能只比 Debug 文本、净 x 或近似数值。
5. P07/P09 实数等式与 d_◇ 用精确有理数。浮点解析主张只用 ADR §§3.2、3.4、3.5、4.6 的逐步舍入包络，独立传播误差；不引入自由 `epsilon`。未闭合包络不临时放宽，记录该子项缺口。库 exp 的舍入单列，不混作递推误差。
6. 引用检查让 θ₀…θ₃ 的实际 g 与 R⁺ 作用值不同；分别只错 θ、只错 R、只错解释记录。每一步在独立 H 映射查证，不能只看末条或不同哈希。
7. 独立交叉审查核对依赖边界、运算次序和变异灵敏度。oracle 有错也保留失败，修订后再次审查，不用双方一致掩盖共享错误。

### 3.3 标签与见证

| 标签 | 冻结条件 |
| --- | --- |
| passed | 指定版本在该子项所有冻结输入、所有前缀满足适用判据；正例有有效更新/作用；该项可运行最小变异被指定读数检出。只给该版本、子项与输入域通过。 |
| failed | 一个满足前提的反例违反判据，或应检出的变异存活。旧参考/变异失败与所选规律分开；A1/A2 已知代价、B 的惯性不自动判新规律失败。 |
| not_run | 未批准执行、缺接口/资源/接线、预算不足、运行中断或明确交接。记录原因、完成前缀和接手卡，未完成不能通过。 |
| non_identifiable | 已运行但观察不能区分两个结论不同的机制/事实；必须给两个相容见证。未知新颖性、旧分解未知是预期项；不能替代测试缺失或数值错误。 |

失败先保存完整轨迹，取最早失败前缀，再依序删除非必需单条事件、未涉及坐标/根；保持前提有效和原判据仍失败，迭代至此删除序下 1-minimal。只删原输入，不搜新参数替代失败；原例、缩减过程、最小见证与位差全部保留。
